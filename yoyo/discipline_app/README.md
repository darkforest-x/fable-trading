自用真机包会嵌入个人服务令牌。面向客户的分发构建必须移除它并改为独立授权；不将自用包放到官网或上传 TestFlight。

## 实盘操作与保护

在 App 选择方向、止损、仓位比例与杠杆。设置中的「开仓二次确认」默认关闭，点击开仓会先进行服务端预检，成功后直接提交；开启该选项则展示计划并要求二次确认。平仓始终先选择当前剩余仓位的比例，默认 50%，可拖到 100% 全平；点击面板内的平仓按钮才提交。用户直接点击是本次指令授权，API 的 confirmed_live 标记不代表必须显示弹窗。预览 45 秒过期且只能使用一次。服务端重新检查规则；若数量、名义金额、保证金或风险超过已预览值，要求重新确认。

市价采用有价格边界的 FOK（全部成交或取消）；限价采用常规挂单，未成交时留在交易所等待，可在 App 手动撤销。入场附带初始止损与两档止盈，但 OKX 附带保护仅在主单完全成交后建立；首次部分成交需要 Mac 服务在线，根据累计成交补齐独立保护。后续成交用持久化保护代次合并，先验证新止损再撤旧保护。成交均价、实际费用、订单状态及保护回读分别核对，不能以受理回执冒充成交或保护生效。

同向加仓沿用当前止损与杠杆，按剩余仓位和新增成交的加权均价重算 R 与止盈；合并后的计划风险不超过净值 5%，所属币种额度仍受约束。加仓也占用一次开仓额度。每次基线确定后，1R 按该基线固定；以实际成交均价和费用计算保护目标。1R 收紧成本保本止损，3R 平原始仓位 60%，5R 平余仓；取整尾数进入最后一档。原始数量若无法分成两笔交易所最小委托，开仓前拒绝。保本价包含手续费和滑点预留，不能保证资金费或跳空后仍然零亏损。

已建立的交易所止损止盈在 Mac 离线后仍由 OKX 管理；新的 1R 止损修改、应急处理与状态同步需要 Mac 持续在线。保护单缺失或异常持续超过等待窗口时，服务尝试以只平仓指令退出该笔余仓，不触碰其他来源仓位。退出也可能失败，App 会保持异常状态并禁止新开仓，不能视为最大损失保证。

订单和保护修改使用持久化 outbox：先保存尝试记录，再发送；超时后按原编号查询，不盲目重发。未核对回执、费用不匹配、账户模式改变、过期行情或账户状态均禁止新开仓。其他合约的外部交易不触发这些限制；同一合约外部交易的归属冲突仍须核对，不能合并操作。平仓亏损以交易所完整仓位结算的净盈亏（含手续费、资金费等）判定；结算不完整时不释放开仓门。

App 不能阻止本人使用 OKX 官方 App、其他 API 或修改服务器文件。统计仅覆盖本 App 管理的交易；当前净值读取 OKX USDT 账户，不伪造历史累计收益率。日界线为北京时间 00:00；首日以及离线跨日后以首次可核验净值建立当日预算，以当时 App 累计已实现与浮动盈亏建立计量基线。旧版当日升级保留已记录的当日 App 结算和费用；若有尚未平仓的跨日仓位，因旧账本没有零点估值，其浮盈从升级时开始计量，不回填虚构的历史价。

## 账户与连接

服务地址固定为 `https://discipline.spikeok.com`，产品界面不提供地址输入。首次设备授权在设置的二级入口填写，不能嵌入安装包；后续自动恢复授权。开发测试只能用构建变量 `VITE_SPIKE_SERVICE_URL` 指向隔离的 loopback fixture；发行构建不设置该变量。

设置 → 管理交易账户 → 添加账户，可填写名称及 API Key / Secret / Passphrase。核验仅 GET；账户需满足原有合约/双向模式及权限限制。每个请求通过 `X-Spike-Account` 明确选定账户，未知 ID 拒绝；无全局活动账户指针。每个 OKX UID 对应唯一账本，重复 API 不能重置风控。最多保存 8 个账户，原主账户保留 `live.sqlite3`，新增账户文件存于 `accounts/<identity>/`。切换只改变当前视图和下单目标，所有账户的保护线程持续运行。

合约列表包含搜索和 OKX 公共币种图标；图标缺失时显示文字缩写。下架或非有效 USDT 永续合约不可新开仓，已有持仓仍保留退出所需元数据。价格展示跟随合约最小价格单位，低价币不会固定显示为 0.00。

## 已确认规则

| 项目 | 规则 |
|---|---|
| 保证金模式 | 全仓 |
| 单笔风险 | 合并仓位计划风险不超过账户净值 5%，含成本预留 |
| 交易所杠杆上限 | BTC/ETH 100x，其他币 20x，仍受交易所上限限制 |
| 保证金占比 | BTC、ETH 各自最多净值 10%，山寨合计最多 5%；各自池内持仓与挂单共享额度 |
| 名义仓位 | BTC、ETH 各自最多净值 10 倍，山寨合计最多 5 倍；费用与价格偏差预留可能使可开金额略低于上限 |
| 同时持仓 | 最多 3 笔；同币同向可在剩余额度内加仓并合并 |
| 每日开仓 | 基础 3 次；整笔净盈利平仓奖励 1 次。待成交暂占额度，确认零成交取消或拒绝后返还；部分成交仍计 1 次 |
| 停手 | App 连续 3 笔整笔净亏损，或 App 当日已实现与浮动净亏损达到当日基准净值 17% |
| 冷静 | 连续 3 笔整笔净亏损触发 24 小时；盈利或部分止盈不触发 |
| 自动保护 | 1R 成本保本，3R 平原始 60%，5R 平余仓 |
| 成本预留 | 每边手续费 0.05%，滑点 0.1%；实际费率超过预留则拒绝 |
