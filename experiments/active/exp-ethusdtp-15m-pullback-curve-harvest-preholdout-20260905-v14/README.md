# ETHUSDT.P 15m pullback-curve harvest V14

V13 proved that an adverse-colour streak can bank real profit without moving
the stop, but it cut too much size before later super-trends became observable.
V14 replaces that trigger with a causal peak-to-close pullback curve.

The harvest arms only after +2 ATR MFE.  Four increasingly deep pullback levels
release 5/5/10/20% at the next open.  Once +8 ATR MFE has been observed, total
banked size is capped at 10%, so at least 90% remains on the unchanged SMA60/ATR
runner.  A profit release never changes any stop.

Repository holdout rows are physically excluded and this experiment is not
eligible for production or automatic promotion.
