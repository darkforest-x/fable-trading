# A 股日线多头 IMACD：冻结实验设计

2026-09-09，Owner 明确授权独立 A 股多头/日线版本、宽止损、趋势退出和参数回测。
本授权只用于本实验，不改币圈 Pine、Spike 扫描通知、模型、ACTIVE、执行器或订单。

## 问题与预注册

在同一历史股票池、同一资金与成交约束下，哪些参数在后续时间段比起点更稳健？
“最优”只表示下面有限候选中的验证期选择，不表示全市场或未来全局最优。
先提交本计划、数据读取器和回测器，再运行批量数据构建和参数比较。
采用按顺序单变量坐标比较，每个试验相对本阶段起点只改一个字段；所有失败结果保留。

## 数据和时间

- 官方 BaoStock 0.9.3，独立 `/tmp/spike-ashare-bs093` 依赖目标，主环境不变。
- 历史证券池：2020-01-02 `query_all_stock`，只沪深 A 股。各板块按
  SHA256(`spike-ashare-v1|` + code) 排序，沪主板100、深主板100、创业板80、科创板最多80。
- 不按历史/当日涨幅、是否存活、未来数据完整程度补换证券。退市、失败、停牌均单独披露。
- 原始日线及后复权日线：2015-01-01～2025-12-31。2015～2019只作初始化。
- 开发：2020～2021；验证/选配置：2022～2023；一次最终样本外：2024～2025。
  每段从现金开始，跨段持仓不继承。已有历史价格可初始化均线，未来收益不进入特征。
- 不读取或评分项目 holdout（2026-05-04及之后），本实验 holdout 消耗为0。
- 样本代表2020年已上市群体，不冒充全A股覆盖；较晚IPO、北交所不属于这轮样本。

## 冻结信号与参数搜索

基础公式沿用 LazyBear IMACD：SMA种子SMMA(high/low)、2EMA(hlc3)-EMA(EMA)，md、SMA(md,9)。
ATR14同样SMA种子，六均线SMA/EMA20、60、120。索引至少max(340,10×MA长度)才允许信号。
双线近零连续达到门槛时冻结ATR容差；主线向上离开冻结带才是启动；其他离开只结束蓄势。
均线带宽使用启动前12根的平均值除各自ATR，不用启动K线改写整理过程。

基础配置：MA34、signal9、focus12、band0.10；quality1；structure10、buffer0.5ATR；
stopFloor3ATR；trail4ATR。只做多，止盈无固定R倍数上限。

开发期按以下固定顺序逐字段比较，其余参数冻结为上一阶段胜出值：

1. 初始止损最小ATR距离：2 / 3 / 4。
2. 趋势ATR距离：3 / 4 / 5 / 6。
3. 近零持续根数：8 / 12 / 18 / 24。
4. 近零ATR容差：0 / 0.05 / 0.10 / 0.15。
5. 启动质量：0仅近零释放；1加收盘高于六均线且此前平均带宽≤3ATR；2在1上加收盘突破原整理上沿。
6. IMACD长度：26 / 34 / 45 / 55。
7. 近期结构窗口：5 / 10 / 20。

开发胜出优先净收益，再最大回撤较小，再原始参数顺序；候选至少30笔自然平仓，否则仅探索记录。
验证仅比较起点和上述7个阶段终点，按相同口径选一个；冻结JSON后才运行2024～2025。
另列原始近零参数、1ATR紧止损的机械化对照，但紧止损不是可被选中的交付配置。
所有候选都保留交易次数、胜率、PF、净收益、回撤，不能只报告冠军。

## 成交与持有时序

- 每个日线收盘完成信号；下一交易日开盘买，绝不按已经知道结果的信号收盘成交。
- 真实价格用于100股数量/科创板至少200股/涨跌幅/费用，后复权价格用于信号和收益连续坐标。
- 买入日不允许卖出；当日越过初始止损也只能申请下一交易日退出。
- 新入场只考虑次日，不追逐开盘涨停或缺失/停牌后的延迟启动；买入开盘触涨停则跳过。
- 已持仓遇停牌或开盘封跌停，退出申请保留，次日继续；不把不可成交的止损价当成交价。
- 初始结构为信号日最近N根低点（含信号日）−0.5ATR；开盘已低于该结构则取消。
  验证后初始止损=min(冻结结构,实际入场−stopFloor×信号ATR)，向外按真实0.01元最小价位取整。
- 初始止损从买入后的交易日起按当日low检查，跳空越过按开盘，不按理想止损成交。
- 最高收盘达到入场+1.5R后才开启趋势跟踪。每天先检查昨日已生效的跟踪线；收盘失守则次日开盘退出。
  之后才更新最高收盘；新线=max(旧线,初始止损,最高收盘−trailATR×当前ATR)，只收紧、不放松，
  候选必须低于当前收盘才上移。R从入场冻结，不事后缩小分母。
- 持仓中不叠加仓位；退出日收盘如有新启动可申请次日再入场。未触退出可一直持有；无最大持仓期限。

## 资金、成本、比较与诚实边界

- 虚拟资金100万元，最多10笔同时持仓，每笔初始资金风险0.75%，单股资金上限15%，不借款不杠杆。
  同日信号按证券代码排序分配，不能根据未来涨幅挑单。
- 独立A股成本对象：佣金双边各0.025%、每笔至少5元；过户费2022-04-29之前0.002%、之后0.001%；
  印花税仅卖出，2023-08-28前0.1%、之后0.05%；每次买卖另加0.05%滑点，压力测试滑点0.10%。
  不修改仓库原有0.2%数字资产成本契约。
- 参考官方涨跌幅历史：主板一般10%，ST在本样本期5%；创业板2020-08-24起20%，科创板20%。
  入场排除当天ST/无成交，持仓中变ST不能删掉持仓。日线无法证明涨跌停排队成交，采用保守近似。
- 后复权收益隐含分红再投资，现金分红税、权益发放到账日、精确盘中成交队列未逐项模拟；均须披露。
- 对照：相同股票池的等权持有、沪深300指数，以及同股票×同季度×事前ATR波动桶的随机入场，
  同样的成本/止损/跟踪/资金约束。随机对照固定种子，至少49轮；日期块置换检验10000次。
- 参数本身不是预测概率；AUC只在明确有可比较的连续评分时计算，否则注明不适用。
  报告top-decile若使用形成质量排序须明确固定评分，禁止把收益拿来排序。
- 样本外同时报告收益、最大回撤、换手/交易数、胜率、PF、持仓天数及板块拆分；选股幸存偏差、
  数据缺失和末端未平仓不得隐藏。不能以4张成功图代替完整样本。
- 输出独立Pine指标、冻结参数、完整结果表、成功和失败全局案例图、Markdown报告并转换HTML交付。
  Pine的日线成交参考不等于A股真实成交撮合，Python为本轮成交约束回测账本。

## 首次选参前的实现校正

- 历史池实际350只：沪主板100、深主板100、创业板80、科创板70；最后一类是当日数量上限，不补换。
- 开盘退出可释放当日开盘买入资金，盘中止损不能。滑点作为额外现金成本，避免拟合成交价格越过法定涨跌停。
- 期末未平仓按最后已知收盘价预留退出成本估值；若末日缺少价格，披露陈旧天数并另列零回收压力下界。
  所有期末估值均排除在自然平仓笔数、胜率和PF之外；不把停牌误称为已经零价成交。
- BaoStock单进程匿名logout会注销其他匿名连接，因此每个取数进程保持一个会话，结束仅关闭连接。
  原始失败与修正前不完整元数据均隔离保留；只对相同冻结代码做技术重试。上市/退市元数据另外审计，不参与选股。
- 最终评估绑定代码与数据字节哈希，开始读取之前记录运行次数。同一冻结配置的中断恢复单独披露，不再次选择参数。
- TradingView编译/样式检查与量化评分分开记录。技术验收可能显示当前图表，但不使用它选参数或报告收益。
