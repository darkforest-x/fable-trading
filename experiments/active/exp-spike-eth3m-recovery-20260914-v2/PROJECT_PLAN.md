# ETH 3m V8：首笔风险1U的回本循环 v2

Owner 本轮原话："我们就用ETHUSDT.p，三分钟级别……1000U……1R等于1U……你可以自己再去找一下最好的方案，参数什么的，自己去优化。"

这是对退出参数和资金参数联合研究的明确授权。本轮不改 V8 信号、初始止损或20bp往返成本；不下单、不 promote。此前 holdout 批准用于此前冻结配置；本配置只使用2026-05-01以前的已有历史，holdout消耗0次。

## 定义与算术

- 基础风险1U固定，账户1000U；每笔价格R为该笔入场到初始止损的距离。风险金额不是保证金。
- 翻倍：理想无费用全止损时风险1、2、4、8、16、32U。
- 累计净亏损×2：理想序列1、2、6、18、54、162U；费用使真实序列不同。
- 与用户前四项一致的阶乘参考：1、2、6、24、120、720U；后两项是研究假设，并非用户给定。
- 累计净亏损回收重置、单笔净赚重置、价格保本或净赚重置三种对照；原地保本不等于扣费保本。
- 任何自然退出净亏损均增加亏损层数；六层或容量不足结束该轮，保留现金亏损，下一信号回到1U。账户连亏计数跨轮连续，不因重置归零。

## 预登记搜索

45退出组：固定毛TP为无/1/2/3/4R；保护为无、价格保本、费用覆盖保本。后两者分别测试0.5/1/1.5/2R触发，价格保本用毛浮盈，费用覆盖保护用扣20bp后的浮盈。保留原始2R收盘启动4ATR跟踪与原始V6反向次开退出。触及在K线收盘观察，保护从下一根生效。不能称为盘中瞬时保本。

每退出组19资金组：固定1U；上一笔乘1.5/2；净债务乘1/1.5/2；阶乘。除固定组外与三种重置交叉，共855配置。搜索固定6层、10倍名义杠杆上限。每次先做容量判断，拒单不占影子仓位；手续费预留不重复扣款。容量条件为 max(名义仓位/杠杆+费用,风险+费用) <= 入场现金。不是逐标记价格强平模型。

开发期2023-08至2024-12；选定配置冻结并提交后评估2025年、2026-01至04月。整段连续现金另列，不用于重新挑参数。以上历史以前已有研究观察，不能称为盲测或全新样本外。

硬门：开发期末现金>1000U，真实连续净亏损<=6次，自然交易>=100且>=同退出固定1U交易数50%，活跃月份>=同退出固定组75%。若有通过者，按期末现金最高、回撤最低、最高风险最低、policy_id排序。若没有，仅用参与度达标组同排序选一个收益诊断配置，并选真实连亏最短/现金最高的诊断配置；均不得宣称达标方案。参数敏感性仅开发期单项修改：杠杆3/5/10/20、层数3/4/5/6、净亏损或亏损止损升级；不据此重选验证配置。

匹配对照：同ETH、同UTC月份、同方向、当前ATR/close相对于此前120bar的三分位桶，每自然成交匹配9次随机入场，用同初始止损与退出/成本。报告逐笔净R差、按目标风险加权的现金差和月份区块符号置换；它不是可执行的随机资金账户。固定种子20260914，9999次置换。开发期 p 值经历选择，仅诊断；小月份样本不作确认结论。
