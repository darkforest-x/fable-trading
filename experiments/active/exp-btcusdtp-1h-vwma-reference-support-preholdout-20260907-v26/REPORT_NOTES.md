# V26 report contract and source notes

Audience: technical, preserving the existing methods-first experiment series.
Delivery: one portable HTML in local Codex, as required by the repository;
canonical artifact and shared renderer, no Sites publication or duplicate app.
Question: does a fixed40 volume-weighted entry reference create a different,
sufficiently distributed opportunity cohort before any economic labels?

Technical specification mapping:

1. Title and technical summary: support passed, no profit inference.
2. Scope and metric definitions before comparisons: full UTC decision grid,
   two directions and shape-qualified subpopulation, not executed positions.
3. Key findings: exact total/fold/direction table, overlap changes.
4. Methods: one reference weighting variable, old all-field parity first.
5. Visual evidence: 24 monthly net differences, retaining both base counts.
6. Validation: provenance, independent saved-hour audit and synthetic checks.
7. Limitations/robustness: known-false vs unknown; reused development period;
   missing economic labels; no random control attribution yet.
8. Next steps/further questions: separately frozen background and persistence
   comparison, no deployment based on larger signal counts.

Chart contract: comparison family, native bar on full-width report row;
24 chronological UTC months, delta=VWMA accepted minus SMA accepted.
Zero line, one blue root, signed values/month ordering as non-color cues.
Both arms, total clock denominator, abstain and unknown retained in snapshot.
Actual SQLite join over frozen counts; no outcome-selected records or gaps
filled with synthetic signals. Exact fold/support lookup stays in tables;
no redundant charts for four threshold lookups. Adjacent narrative explains
that net increase is not higher win rate. Portable verifier owns final QA;
structural_only must not be called browser/mobile validation.

Evidence: V26 started, baseline_reproduced, support_frozen, summary,
seven CSV.gz output artifacts, ten pinned original inputs, twelve builder
sources and independent saved-hour audit. Official VWMA defines volume
weighting, not profitability; HL2 deliberately keeps original source rather
than its example close default. Source paths live in artifact metadata.

CLI, tests and immutable CSVs replace a duplicate notebook. No fitting,
label construction or new data fetch in this stage. AUC, permutation p,
top-decile gross/net, win rate and matched economic excess are not applicable
without outcomes; equal-volume identity and corrupted-input rejection are
the equivalent strict implementation null controls, not a profit test.
