# V12 report design

## Audience and delivery

Technical experiment report for the owner: actual cost-adjusted outcomes, exact
entry/exit rules and failure mechanisms. One offline portable canonical HTML
report, with repository-required source Markdown and supporting audit notebook.
No new website, external publication, dashboard or second HTML/chart runtime.
Use the installed Data Analytics official package and its semantic fallback.

## Reading path and required structure

Title and technical summary; frozen-boundary rules and definitions before the
numbers; development scope and original baseline parity; full case/control
financial comparison; four time folds; pairedD/I and change distribution;
entry-known MA geometry with separate full251/matched154/unmatched97/control462
denominators; saved losers/lost winners and failure examples; single-position,
cost stress and fixed single-feature checks; uncertainty and validation limits;
evidence-grounded next question and repository-required reproduction commands.
Each peer section is one native Markdown block, with one appropriate source.
This maps technical-spec scope/methods before findings to prevent ambiguous
denominators; open questions are integrated with next steps, not omitted.

## Chart contract

Question: how much does the additional frozen-MA exit change each of the original
251 cases? Native full-width categorical bar counts over all saved paired D,
using the inherited actual SQLite signed bins with separate zero and unknown.
Do not trim tails or show only structurally exited trades. Unequal/open-ended
bins are discrete labelled categories, NOT equal-width numeric density.
Y counts start at0; signed bp labels preserve direction without colour dependence.
Single approved blue root, direct counts, no redundant colour legend. Source rows
retain old/new means, totals and unknown counts. Final surface is canonical HTML,
not an interim widget or screenshot. Adjacent narrative explains interpretation.

Four-fold, control, geometry and failure tables are exact repeated-field lookups;
a smooth line over four half-years would imply unsupported continuity. Saved
24-month ledgers remain inspectable evidence. No extra speculative chart, no
outcome-selected geometry chart used as an entry filter.

## Evidence and QA

SOURCE:v12_summary maps saved summary, v12_mechanics maps all paired cases,
v12_geometry maps the pre-outcome entry_geometry ledger. Chart source retains
actual SQL and file identity. Complete authored prose must survive packaging.
Review source/canonical/HTML parity and independent financial arithmetic. Official
portable pipeline may return structural_only without an installed Chromium;
then no browser/mobile/source-dialog visual claim, no browser install. Notebook
may use plain-Python top-down execution if Jupyter dependencies remain missing;
explicitly distinguish it from a kernel/full-schema pass.
