## 指标

每个 研究×臂×周期×方向×时段（全期 / 前段 entry<2025-09-10 / 后段 entry≥2025-09-10），只用目标与随机均已平仓的配对：

- 目标与随机的平均净R、平均净bp；R 超额与 bp 超额。bp 两侧成本相同，因此净 bp 超额等于毛 bp 超额。
- 目标与随机的中位初始风险（bp）、平均成本R（0.2%/风险比例）。随机风险由 `control_net_return / control_net_r` 反推（净R为0的行不参与风险中位数）。
- 分解：R 超额 = 毛R超额 −（目标成本R − 随机成本R）；报告“成本R差贡献”。
- 推断：按目标入场 UTC 月分块 bootstrap 2000 次给 95% 区间；月和符号翻转 10000 次给单侧 p。种子固定 922115。

## 预注册判定

- **bp 确认**：全期 bp 超额 95% 下界 > 0、单侧 p < 0.01，且后段 bp 超额点估计 > 0。
- **仅 R 显著**：R 超额单侧 p < 0.01，但未达到 bp 确认。
- **不显著**：两者都不满足。

判定只作用于“信号相对随机是否有入场能力”，不代表扣费后盈利，也不改变任何默认、Pine、仓位或账户。非方向性审计：没有模型/排序分数，AUC/top-decile/单特征基线不适用；零假设就是原研究的同币同月同波动桶随机入场，本轮只换度量单位。
