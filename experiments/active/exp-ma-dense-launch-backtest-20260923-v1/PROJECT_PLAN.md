# 均线密集启动规则：BTC / ETH 近两年回测

唯一键：`ma-dense-launch-backtest-20260923-v1`。Owner 2026-09-23：“你先用代码回测一下这套规则吧 拿btcusdt.p ethusdt.p 近2年的数据”。

## 问题

冻结的 Grade-A 密集启动规则（已移植为 Pine V1/V2）在 BTC、ETH 永续近两年、六个周期上，按原始出场与成本，能产生多少信号、结果如何，相对同条件随机入场是否有优势。

## 固定范围

- 标的：OKX `BTC-USDT-SWAP`、`ETH-USDT-SWAP`（即 TradingView 的 BTCUSDT.P / ETHUSDT.P 对应合约）。
- 数据：`data/kline_lowtf_20260922` 的官方 1m 归档＋已确认 API 尾段（2023-12-31 至 2026-09-22 14:00Z，0 缺分钟），按 UTC 完整桶聚合 1m/3m/5m/15m/30m/60m。
- 窗口：确认收盘在 `[2024-09-23T00:00Z, 2026-09-22T14:00Z)`（近两年）；更早数据只作均线与 ATR 预热。
- 规则：`yoyo/evaluation/ma_dense_launch_v1_reference.py` 的两组硬条件、第一道最近邻相似度（≤0.5）与第二道六轴质量分（≥0.3611898959），参考数据用 `reference_pack.json`。核心 4 根与 5 根都评估；同一确认根两者都成立时取第一道距离更小者（与研究 `pick_4_5` 一致）。
- 去重：同标的、同周期、同方向，核心结束时间 4 小时内按质量分最高保留一条（研究的跨所 NMS 在单一交易所下等价）。
- 出场与成本：下一根开盘入场；多头止损取核心最低、空头取核心最高；目标为入场 ±3R；12 小时未触发按收盘平仓；同一根同时触及按先止损计；固定往返 0.2%。

## 两个臂

1. `grade_a`：通过两组硬条件、相似度与质量分（研究口径，等同 Pine V2 默认）。
2. `hard_only`：只通过两组硬条件（等同 Pine V1 与 V2 关闭“只显示 A 级”）。

## 零假设

每笔配一个同标的、同周期、同 UTC 月、同因果 ATR/close 波动桶、同方向的随机入场，止损距离按该笔的初始风险比例给出，出场与成本相同；种子固定 923101，不重抽。报告配对超额 R 与 bp，按 UTC 周分块做符号翻转单侧 p 与月块 bootstrap 区间。

## 预注册判定

任一臂要算“有效”，需同时满足：扣费后平均净 bp > 0，且相对随机的 bp 超额单侧 p < 0.01。否则记为无效。本轮不 promote、不改默认、不下单。

## 边界

- 只有两个标的、六个周期，信号可能很少；少于 20 笔的格子只报描述性数字，不做推断。
- 这是研究回放，不是 TradingView 原生运行；Pine 与 Python 的一致性另由 `tests/evaluation/test_ma_dense_launch_v*.py` 覆盖。
