# Next experiment — freeze the exit event, not another filter

Status: planned, not run. This is a response to V36's observed mechanism, not a
new independent hypothesis discovered without outcome exposure. No profit claim.

## Frozen comparison

- Original V36 63 case requests and 108 assigned controls, with exact stored IDs,
  prices, source hashes and original 36 complete matched groups. Preserve the 27
  unmatched cases in full-cohort economics. Do not redraw controls or select the
  38 problematic events as a new trading universe.
- Flow gate OFF in both arms. Change ONE execution setting: `colour` opposite
  state versus existing `transition_colour` (first observe aligned native5m
  colour, then exit on a subsequent new opposite colour). Inspect the existing
  engine's precise arming semantics before use; its name is not evidence.
- Identical next actual 5m open, original K2 extreme stop, 72h maximum hold,
  native5m SMA40(HL2), source2023-2024, split-boundary exclusions and .002 cost.
  No fixed TP, break-even, widening stop, partial exit, threshold search or new
  entry filters. Unknown/censored price paths remain unknown in both arms.
- Hash/freeze builder, settings and tests in main BEFORE replay. Store output in
  a separately registered experiment. Never overwrite V36 files.

## Required evidence

1. Synthetic initially-opposite, aligned-at-entry, never-aligned, genuine-flip,
   hard-stop-before-arm, gap-stop, simultaneous-exit and missing-bar cases. Use
   only completed lower-timeframe bars and exact event clocks.
2. Full four-halfyear table for both arms, actual gross/net, wins, PF, hold time,
   exit causes and cost decomposition, plus all original three-control paired
   excesses. Same 24-month inference contract as V36, explicitly exploratory.
3. Describe the predeclared 38 no-new-flip events AND other25 and their controls;
   report worsened trades, not only recovered trends. These post-result groups
   diagnose a mechanism and are not entry features.
4. Recompute independent single-position ledgers per arm. Longer holds may block
   later trades; event-level arithmetic alone cannot represent an account.
5. Keep the old V6 and other narrower-cohort transition-exit failures visible.
   This is not a never-tested universal exit idea.

## Decision boundary

63 candidates and57.14% matching coverage already fail the existing sample and
coverage gates. No result in this cohort alone can authorize deployment. Test
whether a verifiable event-semantic conflict explains lost opportunity; reject
if longer holding merely increases stop losses. Expanding samples or changing
barriers/costs requires a separately frozen, authorized scope, not relaxing the
current acceptance rules. No TradingView/ACTIVE/live account changes.
