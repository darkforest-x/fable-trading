# ETH 最近两个月：V9 开仓与同级／小级别 YOLO

## 问题与授权

Owner 在本对话要求 ETHUSDT.P 最近两个月回测，在开仓时检测 YOLO，并比较模型识别与 V9 胜率的关系；进一步选择“所有V9周期＋各自/小级别检测”。本研究使用已明确告知的 OKX ETH-USDT-SWAP、Spike 当前 close 1280 权重，保持 V9 退出与 0.002 成本。滚动区间为北京时间 2026-07-15 00:00 至 2026-09-15 12:00；这不是两个自然月。统一冻结截止，不随运行时间延长。

原话及权限边界见 authorization.json。本精确研究配置首次 holdout 消耗，各周期／过滤配置首次消费；该历史已被多轮旧研究暴露，不是盲样本外。必要的 preceding 720 bars 仅作指标预热，不在此区间之外做收益筛选。新训练、优化阈值、实盘、通知、ACTIVE 均不在本次范围。

2. 模型只读各自最后一根已收盘 K：`input_right_close <= V9_signal_close = scheduled_entry_time`。同级输入为信号 bar 及以前；小级别为该时点最近完整子 bar。只推理 W18/W19，conf .25、NMS .70、1280、原配色和 close 六均线、core4/5、post2–9 不变。不增加过去端点搜索或开仓后等待。
3. 主检测定义：至少一个通过原结构合同、方向与 V9 相同的框。没有形态人工 Gold，因此“V9 信号检出比例”不是形态 precision/recall；小级别检出也不证明与大级别是同一形态。保留所有原始框、方向、分数、核心、模型输入像素 SHA、两个时钟。
4. 主比较固定在相同的原始 V9 实际交易上：全部、同级检出／未检出、小级别检出／未检出、两者均检出。退出和费用完全相同。这是条件相关性，不能将删掉交易的累计收益叫作新单仓策略收益。
5. 另跑严格次级单仓回放：原 V9、V9∩同级、V9∩小级别、V9∩两者。准入改变，原始 V6 反向退出流保留；因空仓可能出现新增交易，须报告原赢家保留／丢失和新增事件。每组独立账户，禁止跨周期加成实际账户。

## 数据与对照

每个原生周期额外取入场起点以前720根，确认完整后才能计算；不填缺口，不替换交易所。交易起点空仓；pre-start仅计算状态，不允许历史持仓进入研究区间，明确这是窗口内独立回测。截止未平仓记 censored，列出且排除实际净胜率分母。实际下一开盘缺失则保留为未成交信号，不捏造价格。

每个实际交易固定一个随机入场：同交易所、ETH、同周期、同方向、同自然月、同 ATR/close 固定桶（.005/.01/.02/.05/.1），排除自身，种子915151；选择只看当时变量，原初始止损／反向退出／跟踪／成本都不变。失败或删失控制不重抽。配对超额只使用共同已平仓分母。随机对照回答与同条件一般市场入场比较，YOLO相关性主对照仍是原V9未检出交易。

## 统计与证据边界

每组报告 n、检出率、净胜率（net_r>0）、毛／净R、PF、净收益bp、随机匹配数与超额。按多空及7/15–8/15、8/15–截止作描述拆分，不据此再选周期或阈值。每笔而不是每张图是统计单位。

主关系检验是每周期同级／小级别命中和净赢的相关性，共14项；报告2×2表、胜率差及95%区间，按UTC ISO周块 bootstrap，另给Fisher确切检验作为不考虑时序的描述项，14项Holm校正。检出过少、全部命中或无命中记无法估计，不强凑p值。全期约9周，跨周持仓与跨周期重叠保留在局限中。置换仅用于排序关系：在同周期方向内打乱固定检测分数，9999次；不是随机分配的因果实验。

次级分数诊断在原V9已平仓交易计算 YOLO confidence 与净赢 AUC、置信分最高10%的毛／净收益与置换p；未检出记0且显式记录ties。单特征基线用当时 RV，不搜索方向／阈值；恒定分数时top-decile无信息不据此裁决。信号过少的周期只做描述，不宣称已验证优势。不得把高胜率、AUC或单次盈利直接当成生产准入。
