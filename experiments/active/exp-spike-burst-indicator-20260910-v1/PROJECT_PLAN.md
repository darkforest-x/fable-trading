# SPIKE 强劲爆发 V1 · 独立指标规格

Owner 2026-09-10明确将下一步研究改为“单独针对强劲爆发做指标”，并开启目标模式。本轮交付功能与时序验收，不搜索收益参数、不改原IMACD/Spike监控/Bark/YOLO/订单。历史数据权限沿用Owner任意时间授权；真实图表只做工程曝光，逐次登记，不称全新样本外。

## 冻结形态（工程默认，非最优参数）

- 普通时间K线；IMACD34/9、ATR14，SMA/EMA20/60/120。预热max(340,10×IMACD长度)。
- 双线近零：max(abs(md),abs(sb)) <= 0.10×前根ATR。连续12根达标后冻结近零阈值。整段近零高低点只包含释放前K线。
- 释放前12根，六均线带宽/各根ATR的平均值<=3，15对均线交织总次数>=2。资格于释放收盘锁定；爆发K不能让自身变密集。
- 主线离开冻结近零带，开启6根窗口（释放当根+随后5根）。若主线回到带内/反向、收盘破反侧整理边界，则取消。每段最多一个爆发；有活动趋势参考时不叠加新段，不同根既退出又进入。
- 本根同时满足：量比>=4（成交量/前20根中位数）、TR/前根ATR>=3、实体占振幅>=55%、方向侧收盘位置>=75%、同向实体、收盘站在冻结箱沿及六MA之外、IMACD主线同向且高于/低于信号线并继续增强。只要求在箱外，不强制本根才穿越箱沿。
- 默认只提示多头，设置可选双向或空头。无YOLO等待或高周期强制过滤；缺成交量、无效尺度不出爆发。
- 箭头标在真正满足上述条件的收盘K线上，绝不回填原释放根。报警与箭头同布尔量。

## 风险参考与显示

- 信号收盘价是观察参考，不是成交价；初始止损=近期5根反侧极值±0.2ATR，距离至少2ATR，最小跳动向外取整。冻结初始止损和R；无效风险参考不能隐藏有效爆发信号，单独标不可用。
- 信号根高低点不算入场后收益。自下一根起先检查上一收盘已生效的保护位；多头max(初损,前根跟踪线)，空头min。跳空使用较差开盘作为路径参考。
- 收盘浮盈达到2R后启用收盘价外4ATR的单向跟踪：多头max(前保护,本根收盘-4ATR)，空头min。本根更新的线从下一根生效。止损优先于本根峰值/里程碑计算；退出后冻结，不重新复活。
- 无固定止盈；展示初始风险%、已确认峰值R、当前/退出参考R，清楚标注峰值不是兑现收益。3/5/10R只在后续已收盘K确实达到后提示。
- 主图六条细MA、淡整理区、清晰爆发标签与关键K线亮色、初始风险带/唯一保护线；副图保留零轴和蓝橙双线，无柱。深浅主题使用chart.fg_color/bg_color。

## 工程验收中显式修订：价格先行路径（第二版规格）

首次真实工程图发现USELESS强阳早于MD离零，而原规格把这种先行放量排除。Owner明确要强劲爆发，独立指标无需复刻旧IMACD时序，因此增加价格先行路径；这是已看实例后的形态设计修订，不可称事前盲测或盈利改善。未变任何阈值、止损或通知规则，也未计算收益选择。

当**前一根已确认12根近零资格和释放前密集条件**满足，本根满足完全相同的量价/实体/箱沿/六MA门槛，即可先行发箭头：多头MD>=0且MD>=SB、ZLEMA本根上升；空头镜像。不必先等MD离开容差带。检查在本根高低点并入整理区之前进行。与原释放后6根路径共用一次性段身份，有活动趋势参考不重复发。标签注明价格先行或释放确认；两者仍在当前根收盘确认。首次工程曝光及本修订后二次曝光分开登记，收益验收次数仍0。
