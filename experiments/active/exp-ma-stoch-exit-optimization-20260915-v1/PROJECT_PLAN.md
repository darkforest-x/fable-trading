# MA Shift × Stoch：退出、止盈、止损优化 v1

## 授权与边界

Owner在同一对话问「退出逻辑，止盈止损逻辑能优化？」。按此要求做离线退出优化；15m SMA40/hl2颜色＋5m翻身Stoch5/3/3超买超卖箭头入场、next-open时钟、单仓及20bp成本不变。不开实盘、不改监控、不改已交付月度配置。优化目标异步询问未回复时按扣费净权益优先，同时报告回撤与连续亏损；不以高胜率自动胜出。

本轮不使用任何holdout价格或账本来调参。已有近月结果只说明原始方案失败，不能作为新退出的选择依据。本精确配置holdout消费0次；如以后评价近月，需冻结后单独授权并记录，且该月非盲样本外。

## 预设方案：一次只在参照方案上改一项

baseline为原超买超卖反向箭头全平。下列16个候选包含baseline，不搜索更多组合。

|方案|相对谁|改变|
|baseline|原规则|无|
|reverse_kd|baseline|任何反向K/D交叉均退出，入场阈值不变|
|reverse_ma|baseline|额外在15m方向反向时退出|
|time_6 / time_12 / time_24|baseline|额外持仓6/12/24根5m后退出|
|stop_1 / stop_2 / stop_3|baseline|加入1/2/3 ATR初始硬止损|
|tp_1 / tp_2 / tp_3|stop_2|加入1/2/3 R全平目标|
|break_even|stop_2|收盘浮盈达到1R后，次bar保护到入场价加方向×0.2%|
|partial_1r|stop_2|1R限价平原始50%，其余反向箭头/原止损退出|
|trail_1 / trail_2|stop_2|收盘浮盈达到1R后，按收盘价距离1/2个入场ATR跟踪|

保留所有候选结果，包括失败。保本、分批、跟踪在这一轮不组合，以免同一次比较同时改变多个组件。
ATR采用独立、显式Wilder14：首14根真实波幅均值播种，随后递推(前ATR×13+当前TR)/14；需要high/low/close和前close，只用信号bar及之前。这是新退出的研究定义，不修改本仓两个既有ATR实现。入场ATR冻结；R仅用于有初始止损的候选，等于入场到原止损的价格距离。价格按ETH tick .01做不乐观取整，成本不变。

## 执行顺序

每bar先处理已生效的保护：跳空越止损以开盘成交；已挂目标若开盘越过，以开盘成交。再处理前bar收盘生成的反向/颜色/时间退出；已空仓才按冻结入场流允许新仓。当根盘中已有的止损和目标都被OHLC覆盖而先后未知时，stop-first。部分目标只成交一次，份额合计为原仓100%。盘中止损/目标平仓后不能用当根收盘信号回填在该根开盘重入。

所有原反向超买超卖箭头仍可全平；reverse_kd只是放宽退出交叉阈值。每根收盘检查BE或trail，新的保护只在下一根生效。跟踪只收紧；部分退出不重加仓。初始1000U、每笔入场前权益1x名义，不用倍投/额外杠杆。

## 选择和验证

先按开发净MTM权益从高到低排列（完全相等时先低回撤、再少交易、再方案ID固定字典顺序）。开发至少30笔已平仓的候选才可被选；若所有都亏仍只冻结“开发最少亏”的候选，不称其盈利。

验证只运行baseline、固定stop_2锚点、开发预选的一种候选（相同者去重），不在验证里重新选一套。报告开发与验证的净权益、毛/净bp、胜率、PF、回撤、最长连亏、最大单笔损失和末仓；正式推荐须验证净收益>0且匹配随机入场正超额的日块p<.01，否则只报告相对改善或失败。

每组每个已平目标一次抽取同ETH同方向同UTC日、同SMA20(TR)/close固定桶(.001/.002/.004/.008)的随机入场；种子9152401，退出/障碍/成本同组。控制不要求原入场箭头/MA，不按未来结果重抽；删失单列。控制可能重叠，不冒充可合并账户。配对超额按UTC日块符号置换9999次，仅描述交换对称零假设，不证明因果。16组开发比较只探索，不将开发p当独立发现；验证不重选。

没有预测概率和预定排序分数，AUC/top-decile不适用，以全部冻结交易、原规则/单组件锚点和匹配控制代替。每种退出改变空仓机会，因此必须从同一候选信号流完整串行回放，不能只给原116笔替换结局。
