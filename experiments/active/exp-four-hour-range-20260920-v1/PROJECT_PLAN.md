# 首4小时区间假突破回归：BTC/ETH 永续固定规则预注册

记录时间：2026-09-20。Owner在规则分析后要求写代码并回测BTCUSDT.P、ETHUSDT.P。来源为Data Trader视频 https://www.youtube.com/watch?v=O5eC5lY7ZXY 。这是一项新策略族的固定基线，不沿用视频展示胜率，不修改SPIKE。

## 固定规则

- 默认同源OKX BTC-USDT-SWAP及ETH-USDT-SWAP，5分钟标准OHLC；尽量覆盖共同近三年。具体数据起止、预热、SHA在config与来源收据冻结，源不足不得静默换交易所。
- 基准区间为America/New_York日历00:00到04:00的高低点；04:00后可用。夏令时切换日按当地墙钟，分别有36或60根5m，普通日48根。此为明确实现口径，不声称等同任意交易所原生4H。
- 区间就绪后，一根已收盘5m的close严格低于L，开始向下突破事件；严格高于H则为向上。没有open条件、指标或额外趋势过滤。触边等号不确认。
- 本次事件从第一根区间外收盘的bar开始，完整计其影线及之后bar极值；直到首次close严格收回L/H内部。若从一侧直接跳到另一侧外收盘，替换为当前bar起点的新方向事件。回归候选产生后事件清空，下一候选须重新离开。
- 下破回归做多、上破回归做空。确认收盘后下一5m开盘成交，必须同一纽约日；开盘若已经越过冻结止损、风险非正则取消。开盘跳出区间但仍有正风险不额外过滤，另记entry_inside_range。
- 每币单仓、不加仓。持仓中的新候选丢弃、不排队；原仓在确认bar内退出时，该bar的新确认可在下一开盘成交。状态照常更新。
- 止损为本次突破至回归bar的最低/最高价，无缓冲、无事后摆动确认、无主观订单块替代。按实际成交价到止损距离计算固定2R。该2R来自Owner当前策略请求；不调原有生产参数。
- 跳空越SL按开盘价止损；越TP按目标价保守成交；同bar双触按SL先并单列。所有日期统一纽约日末最后5m收盘强平，此为补齐视频未定义部分的日内实现假设。
- 成本固定为入场名义金额20bp，沿用项目既有口径。无资金费数据时明确未计资金费，不改低成本。无杠杆、账户仓位、复利假设；R为每笔初始价格风险单位。
- 数据末端不完整日的持仓只能标记data_end/censored，不冒充策略日末正常平仓。正式评估使用完整纽约日，预计不会发生此类截断。

## 假设与检验

问题：固定规则在两币中是否产生正净期望，且具有匹配随机入场之上的增量？本轮没有优化变量；只实现上述一种已说明的规则。Pine交付为独立新脚本，旧SPIKE不动。

按时间划前约两年与后一年，后段历史复核不是未看过的盲样本。不给任何事后优选阈值。主确认族为BTC/ETH后段相对匹配对照的两项检验，Holm调整；全期与方向/月份等为描述性。

随机入场匹配同币、同方向、同纽约年月、同纽约小时、同因果波动五分桶及同早/后段；每笔最多50个、不放回，不足如实记录，禁止根据未来结果重新抽样。沿用真实交易当时已知的风险百分比、固定2R、20bp成本、纽约日末退出。控制在已完整形成首4H的交易时段抽取，真实入场本身排除；控制可与其他交易重叠，所以仅是择时零假设，不是可执行组合。

波动仅服务对照匹配，不是入场过滤：已收盘5m TR的14根均值除以close14根均值；桶阈值来自严格之前30天的分位数，入场只读前一根已收盘bar。预热至少31天。

按纽约日历月聚类：10000次块bootstrap给平均净R和配对超额95%区间，20000次月块sign-flip提供单侧配对零假设p。小p不能代替绝对净盈利，也不构成随机试验的因果证明。报告控制覆盖、独立月份与唯一控制时间，禁止伪重复。

必报候选/成交/跳过、毛/净胜率、毛/净R、净bp、PF、已闭合与5m收盘估值回撤、最长连续亏损、止损距离与成本R、退出原因、双触数、前后段/多空/月度及匹配对照。固定规则无预测分数，AUC与预测top-decile不适用；不得事后按盈利排序冒充预测。首次版本无历史同版回测，参照为匹配随机单价格入场零假设。
