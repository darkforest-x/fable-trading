# 20 张程序合成均线启动样本

这是 2026-09-21 按 Owner 要求制作的样式确认包，所有价格均由程序生成，不是真实币种或行情。

- 双击 index.html 打开 20 张交互图库；方向键翻页，空格切换完整 / 早期视图。
- full/：20 张完整走势，1600×900。
- early/：同 20 张的 T+3 前缀，纵轴只按当时数据计算。
- ohlc/：20 份合成 OHLCV 及 SMA/EMA 20、60、120 数值。ts 是人工索引，不是市场时间。
- overview_1.jpg、overview_2.jpg：各 10 张总览。
- manifest.json、receipt.json、qa_receipt.json：逐图参数、生成版本与技术校验。

五类结构各四例：安静横盘、回落修复、小波浪横盘、波动收缩、启动前浅下探。先生成连续价格路径，再计算均线；未手画均线。

红圈只方便人工看图，不是 YOLO 框或已确认标签。这一批刻意生成理想正例，未包含失败突破、复杂背景和真实分布，尚未构成可直接训练的数据集。没有训练模型，没有评估准确率或收益。
