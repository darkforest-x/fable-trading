# BTCUSDT.P 15m / 5m causal failure map

This preregistered diagnostic uses only 2023 outcomes. It joins the frozen
accepted K1-to-K2 ledger to features available no later than the next-open
entry decision, then checks whether each segment improves over the baseline in
both 2023H1 and 2023H2.

Continuous thresholds come from the outcome-blind 2023H1 feature distribution.
A 20,000-resample max-statistic permutation null measures the multiple-search
effect. This study cannot change the trading rule itself. Any nominated segment
must become a separate, preregistered, single-variable experiment and be rerun
before cooldown on 2024 data. Audit and repository holdout remain closed.
