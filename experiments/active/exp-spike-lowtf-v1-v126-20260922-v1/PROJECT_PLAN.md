# SPIKE V1 与 V12.6：OKX ETH/BTC 1m、3m、5m 对照回放

唯一键：`spike-lowtf-v1-v126-20260922-v1`。Owner 2026-09-22 原话：“分别测试一下 v1 v12.6 的小级别 1min 3min 5min”，随后“v1回测一下近2个月的行情呢”“截至今天”。

## 问题

在同一份 OKX 数据、同一时间窗、同一成本下，原版 SPIKE V1 与当前 V12.6 在 1m/3m/5m 上各自的扣费结果如何；两者信号质量相对匹配随机入场是否有差异；最近两个月单独如何。

这是描述性对照研究，不选参数、不训练、不改 Pine/TradingView、不改监控或真实账户。training/production eligible 均为 false。

## 固定范围

- 标的：OKX `ETH-USDT-SWAP`（tick 0.01）、`BTC-USDT-SWAP`（tick 0.1）。只选这两个流动性最高的合约，是为避免在小周期扫全市场；不按结果增减标的。
- 数据：OKX 官方月度 1m 归档（UTC+8 月份 2024-01 至 2026-08，`src.data.fetch_okx` 归档模式），加公开 `history-candles` 1m 已确认 K 线补 2026-08-31T16:00Z 至 END。3m/5m/15m 由同一份 1m 按 UTC epoch 完整桶聚合；不完整桶丢弃并形成时间缺口。
- 窗口：信号收盘 `[2024-02-01T00:00Z, 2026-09-22T14:00Z)`；此前 1m 仅作预热。时间切分：前段 `< 2025-09-10`，后段 `>= 2025-09-10`（沿用 V12.6 研究切点）。“近两个月”固定为 `[2026-07-22T14:00Z, END)`，后段的子集。未平仓按 END 删失，不计输赢。
- 均为只做多，下一根开盘成交，固定往返 0.2%（20bp）入场名义成本；不建模资金费、滑点、强平。

## 三个臂

1. `v1_native`：冻结 V1 Pine 回放（`spike_burst_replay`，Pine SHA `18bbb695…`），按连续段逐段运行；每个 burst 独立成交，使用 V1 自带保护线退出。完全沿用 2026-09-11 两年全市场账本 `_trade_rows` 的规则，只改窗口参数，以测试证明同窗口逐行一致。
2. `v1_common`：同一批 V1 burst 信号，改用 V12.6 研究回放同一套退出引擎（5 根极值 +0.2ATR、至少 2ATR 初始止损；收盘 2R 启动 4ATR 追踪；原始未过滤 V9 反向信号次开退出），单仓串行占用。
3. `v126`：V12.6 研究移植（`spike_v126_engine`：默认线性双轨、主三点＋局部 C、图表与上级各 24 条持线、先框后突破与先突破后 V9 两种配对、每框一次）。上级周期按 Pine `f_v11` 自动映射：1m→5m，3m→15m，5m→15m。V9 过滤按 Pine 默认：BB200/700/712、V8 距离、USDC/量比>50/UTC 周日；H1 SMA60 只对 15m 生效，故本研究不用；M15 EMA120 只对 5m 生效（已完成 15m，1200 根连续，收盘严格高于）。退出引擎与 `v1_common` 相同，单仓串行。

`v1_common` 与 `v126` 只差入场信号，是本轮主要对比。`v1_native` 用于延续最初 V1 口径。

## 零假设与统计

- 匹配随机：`v1_common` 与 `v126` 每笔交易在同流（标的×周期）、同 UTC 月、同前后段、同因果 ATR14/close 波动桶中确定性抽一根 bar，同一退出与成本。种子 922113，不因删失或亏损重抽。小周期 ATR/close 远低于 15m 研究用的 0.5% 起点，因此固定使用 `[0.0005, 0.001, 0.002, 0.004, 0.008]` 分桶。
- `v1_native` 的保护线依赖 V1 自身状态，随机入场无法套用同一退出，因此不配随机对照；以 `v1_common` 的随机对照作为 V1 信号的零假设。
- 每个 臂×周期×范围（全部/ETH/BTC）×时段（全期/前段/后段/近两个月）报告：闭合/删失笔数、扣费胜率（净R>0）、平均净R、平均净bp、合计净R、PF(R)、净>5R 与 >10R 笔数、中位初始风险比例及其对应的成本R。随机对照报告配对超额R，按 UTC 月块 bootstrap 2000 次给 95% 区间，并做月度符号翻转单侧 p。
- 项目验收门（任一臂要被视作可用）：后段净收益为正，且相对匹配随机超额单侧 p<0.01。本轮预期为描述性，不据此 promote。
- 无模型与排序分数：val AUC、top-decile、单特征基线不适用；上述同成本随机入场与同退出双臂对照即零假设。
