## 冻结边界

原文件 `yoyo/evaluation/pine/spike_burst_v3_early_warning.pine`，SHA256 `d604051c0c633e3ee9dac4c23bbae51ce20fe9365da60aa33a760e08cf4ea882`。新文件为 `spike_burst_v3_layered_display.pine`，独立研究版。

全部特征、ALERT STATE、REFERENCE STATE、常数、原参数、风险函数、盈亏框、六均线、双线零轴和 alertcondition 保持原字节。新增显示变量只读取原事件与参考状态，不能反馈检测或改变事件时点。只增加“低干扰 / 完整显示”选项。

低干扰突出 `referenceStarted` 观察起点；确认仅在当前参考仍活动且 `parentBar == entryBar` 时升级该参考。其他新预警或确认是补充观察/补充确认，保留真实当前收盘价、时间和父身份，不能自动叫重复机会或替代当前参考确认。完整显示恢复原标签及染色。

所有原事件在低干扰主图保留连续的小标记，不依赖最近 label 对象；文字与 tooltip 受 TradingView 300 个共享 label 限额约束，旧标签可回收。副图点和 Data Window 原事件保持。主图仅观察起点/所属确认用亮色 K 线。单个参考不是账户仓位，不能用它代替及时召回。

## 验收

- 源码哈希、原核心字节和 alertcondition 精确守恒。
- 合成事件覆盖同根/延迟确认、另一父、退出根、风险不可用、前缀稳定与质量重置。
- 独立检查 plot 预算、原信号标记及 label 回收限制。
- 原生 Pine 编译与图表视觉单独验收。当前 Mac TradingView 报账号在另一台 PC 活跃，不接管或断开那个会话。静态测试不能冒充原生通过，也不能声称已保存到用户 TV。

- 源码/测试/计划先提交，再发布 MD 与 HTML 验证说明。不得替换线上指标、通知或执行配置。

这只是可回退的展示改进；用户的主要目标仍保持进行中。
