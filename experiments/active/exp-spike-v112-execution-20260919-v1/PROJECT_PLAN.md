# V11.2 入场时效、止损锚点与追踪激活：三项独立消融

2026-09-19，Owner 在固定 50 笔诊断后说“去研究吧”，授权离线研究此前提出的入场/止损/浮盈保护机制。本计划在运行候选前冻结；不是新盲测，不改生产。

## 问题与分组

所有组来自原框内首次突破事件，同币同周期独立串行，不因过滤拒绝而允许同框重试。

- baseline：原下一开盘入场、当根重新计算止损、收盘 2R 激活 4ATR 跟踪、原反向确认下一开盘退出、往返 0.2%。
- age6：只接受原 V9 信号后不超过 6 根的首次突破。6 来自既有 V10.4 窗口，不搜索新阈值。其他完全同 baseline；目的为检验之前仅筛账本的时效线索在完整串行下是否成立。
- parent_stop：联合下一开盘入场，唯一变化为初始止损采用原 V9 信号按已发表函数计算出的原始止损价格；重算入场到止损风险。2R 仍按本组实际初始风险，4ATR、反向退出、成本不变。父信号当根与联合同根时自然等于基线；不按后来结果选择止损，不随意取两种止损中有利者。无效锚点明确记账、不回退。
- wick_arm：唯一变化为存活 K 的最高价达到原始 2R 即激活追踪；保护价仍为该根收盘减 4ATR，只收紧、下一根生效。旧保护先检查，同根先触旧止损不能用未来高点救回。不是盘中即时移动止损或 2R 保本。

不组合这三项，不搜索倍数，不根据 50 笔表现挑选最终方案。未授权上线或真金操作。

## 控制与计量

每组按原固定种子为实际成交选同币、同月、同时间段、同 ATR/价格桶随机入场；相同事件共用随机点，失败不补抽。随机交易用对应组退出和成本。parent_stop 控制把相同父信号年龄平移到随机入场之前，锚点用那个历史位置的相同止损公式；它不是随机点上真的出现 V9。若锚点无效，记 unmatched，不能静默用联合止损代替；披露匹配率。

保留固定原基线入场的单笔反事实账本，区分同入场退出效应与串行新增/删除效应。age6 被过滤的机会在机会口径记零，在成交口径不算交易。

主表同时给：净收益 bp、按各自初始风险的净 R、按原联合初始风险换算的净 R。改止损会改 R 分母；仅原生 R 改善不能认作价格收益改善。报告胜率、毛/净、匹配随机及超额、救回亏损与少赚赢家、原净 >=10R 大单保留。累计跨币收益只是事件和，不是账户收益。

全期用原连续回放复现；分段比较中，早期退出跨过切点的交易单列排除，随机控制也不得跨切点。后段只取切点后产生的信号。没有训练。

## 预先判定

每个候选/周期分别判断：全期与后段平均净 R 和净 bp 都正；相对于基线，前段和后段净 bp 均改善；全期同币环境匹配超额为正，月块符号置换 p 经 3 候选×2 周期 Bonferroni 校正后 <0.01；配对覆盖至少 90%。这仅是离线研究门，不是实盘许可。

报告全部表与失败结果。另用 2000 次 UTC 月块 bootstrap 给均值差区间；不得把单笔独立重采样冒充跨币独立证据。无分类/排序模型，AUC 和 top-decile 不适用，以原策略和匹配随机为零假设对照。已有 50 笔逐一回看只是解释，不参与筛选。
