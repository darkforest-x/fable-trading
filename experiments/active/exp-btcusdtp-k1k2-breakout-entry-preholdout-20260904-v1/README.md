# BTCUSDT.P independent 15m / 5m direction-breakout entry experiment

This stage changes only the post-K2 entry rule. Alternative arms wait 15,
30, 60, or 120 clock minutes for the first completed directional candle whose
close breaks the K2 high for a long or K2 low for a short and remains beyond
the contemporaneous MA. Entry is the following open.

The original K2 opposite extreme remains the stop. Signal morphology,
MA/gap/score parameters, 3R target, 12-hour horizon, 1.5R protection,
six-hour cooldown, risk gates, and 20bp round-trip cost remain frozen.
Development is 2023-2024; audit and holdout remain closed behind the same
registered gates.
