# ChartArt v1.2 只做多：BTC / ETH 永续 15m

Owner request（2026-09-17）：“这个策略是什么逻辑，回测一下 btcusdt.p ethusdt.p 15min 级别”。
作者在 v1.2 说明里声称“改成只做多后回测更成功”，本轮就是检验这句话在 OKX 两个永续上是否成立、
以及它成立时是不是只因为多头 beta。

## 冻结比较

唯一变量是**平仓信号做什么**：v1.2 `strategy.close` 回到空仓，v1.1 反手做空。
入场条件、RSI6/BB200×2 特征、下一根 open 成交、0.2% 往返成本、逐笔记账全部共用同一份代码，
两臂差异不可能来自重建差异。无独立 TP/SL，不加金字塔，不加 ICT/V9 过滤，不做参数搜索。

`strategy.cancel` 不构成第三种状态：入场 stop 挂在已被收盘价穿越的下轨下方，模拟器在创建时即激活，
下一根 open 成交发生在下一根收盘计算（也就是 cancel 执行）之前。

## 数据与统计

只读 `data/kline_deep/` 的 OKX BTC/ETH USDT 永续 15m，时间戳优先解析，
end 冻结在 2026-05-01T00:00Z，**不解析 holdout（≥2026-05-04）字节**，本轮无 holdout 入口。
三个窗口 full(2022-07-01) / long(2024-01-01) / jan_apr(2026-01-01) 互相包含，
**不是三次独立检验**，long / jan_apr 与 v1.1 旧轮同窗同源文件，可直接对照。

方向性策略必须带对照组，这里给三层：
匹配随机入场（同币 × 同 UTC 月 × 前一根 BB 宽度桶，20 个固定 seed，出场用同一条平仓规则）验证入场择时；
**买入持有**验证是否跑赢单纯持有；**持仓占比**说明这条规则到底暴露了多少时间。
配对差按周块符号置换 4000 次给 p 值。无概率模型，故无 val AUC / top-decile，不编造。
