# Telegram 简讯配图

Owner 于 2026-09-08 要求“tg 推送信号简单一点 加个图最好了”。改为三行摘要和 TradingView 按钮，每个新可见启动信号配 1080×1080 图，包含真实 K 线、六均线、目标箭头与价位、IMACD 双线和零轴蓄势区。

沿用 15m/1H/4H、v3 visible focusRelease、12 根、0.10 ATR、所有已持久化启用时刻、30 分钟新鲜度和独立 Bark 队列。渲染只用信号当根及之前；新 PNG 与首次 event/outbox 原子写入。渲染失败在外部请求前降级；不确定发送不重发。旧历史不生成新通知，无测试或启动推送。

验收：未来扰动图像逐字节一致、目标价格/时间/指标错误拒绝、并发/事务回滚、429 同图重试、超时/5xx/缺回执不改发文字、Bark 独立；真实历史信号仅做本地预览。源码先提交，再用 acceptance 收集服务升级前后，核对旧回执与三个启用时刻不变、运行版本及完整扫描健康。正式预览与验收脚本均保留在本目录。

这是展示/通知工程修改，不是交易系统评估。沿用 Owner 全日期授权，本配置第 1 次 live-observation 使用；未训练/调参/评分收益，AUC、收益、置换 p、随机入场不适用，采用上述未来扰动与故障注入对照。升级需要 RAM 行情重新预热，可在期间持续发送仍新鲜的真实新信号；不能把服务确认当成手机已阅读。
