## 唯一变化轴与有限搜索

本研究不是全局最优证明。对每条 stream，按顺序进行四个单变量步骤，所有选择只看开发期账户末值，平手优先风险更低/层数更少。任何失败也保留完整结果。后续步骤只改一个值，不反复迭代直到出现盈利。

1. 固定首笔计划止损10U、倍数2、盈利一次复位、10倍名义敞口上限；比较最大层级1至8（level0为首笔，level3代表1/2/4/8），另列固定风险基线level0。
2. 固定第一步最佳层级，比较 win（任意净盈利复位）与 recovery（本轮累计净盈利回本才复位）。
3. 固定最佳层级/复位，比较首笔计划止损金额1/2/5/10/20/50U。
4. 固定上述政策，比较名义仓位/当前余额上限3/5/10/20倍。该值是模拟开仓容量，不能冒称历史真实可用杠杆或完整强平模型。

将最终倍投政策与相同底注/敞口上限的固定风险基线，以及不交易1000U现金基线并列。即使最好的倍投也亏损，不隐藏、不扩大搜索、不按验证/holdout反向选择。只有开发选择且后续稳定优于基线才可称“本轮有证据支持的候选”；否则只报告开发冠军和失败原因。

## 仓位、时间与停止语义

倍增的是计划初始止损金额，不是保证金或ETH数量。notional = base_risk_usdt * 2**level / initial_risk_frac。风险金额基于初始1000U固定，不复利。

只有已成交上一笔净亏损且退出原因含 stop 才进一级；盈利跟踪止损不进级；反向退出亏损保持层级。最大层亏损后认亏重启level0，但账户亏损不能归零删除。盈利一次复位与累计回本复位只在第二步比较。

入场时要求 notional/leverage_cap + 0.002*notional <= 当前余额，且计划止损金额+全额成本 <= 当前余额。全额成本仅预留，net_return 已扣成本，不再重复扣。容量不足拒绝该次交易，层级不变，不利用拒绝单未来结果更新层级；冻结 V8 影子持仓继续走完，之后才接受下一影子入场。该口径可因果实现，但不是“拒单后扫描所有闲置期间新信号”的另一种策略。

余额归零后为吸收态；没有补充本金。拒单次数、最大实际/请求层级、最高实际敞口、认亏重启次数、自然平仓数和边界标记必须披露。退出时点为具体open的gap/opposite按open记，普通盘中stop保守记在该bar收盘后；定仓不读取该单收益。

## 对照、统计和不确定性

方向性比较使用同ETH、同UTC月、同此前120bar波动桶的匹配随机入场；同V6反向、结构止损、跟踪和固定费用。预先固定9个种子，缺样保留。随机对照按实际接受交易的计划风险金额加权，只是配对事件反事实，不冒充可交易随机账户。每张正式窗口结果表附加权随机对照；不给没有对照的数据写alpha结论。

报告每窗口账户末值/净收益、已实现或窗口末标记回撤、自然平仓胜率/PF、底注和层级、拒单、零余额、matched随机净P&L及差额。按UTC月聚合配对差做固定种子9999次符号置换，双侧p，缺失和小月份样本如实记录。风险最高10%交易列毛/净收益与其余交易，说明这是仓位分配描述而非训练排序器。val AUC不适用于没有预测分数的仓位政策；不把AUC编造成模型验收。

## 限制与诚实声明

交易级现金账本只知道入场和最终退出，没有完整逐bar浮动权益、标记价格、历史分层维持保证金、真实资金费和滑点成交。故“归零”不等于交易所历史爆仓，“没归零”不证明避免强平，回撤只是已实现/末端标记口径的下界。杠杆容量不构成杠杆实盘建议；真实交易可能更早终止。固定0.2%成本不修改，本轮不另拟费用敏感性以免多变量。
