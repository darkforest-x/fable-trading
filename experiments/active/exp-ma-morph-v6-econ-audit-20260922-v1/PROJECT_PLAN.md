## 预注册分析

1. 复算两段 top10 的毛/净 bp、胜率，与原报告对账。
2. 单调性：各段按分数十分位的平均净 bp，Spearman(分数, 净bp)。
3. 集中度：top10 去掉最好 1/3/5 笔后的均值、中位数、最大单币占比、币种数。
4. 时间聚类推断：以 UTC 日为块 bootstrap 2000 次给 top10 平均净 bp 与“相对随机超额 bp”的 95% 区间；按 ISO 周符号翻转 10000 次给超额的单侧 p。
5. 分层：周期（1m/3m/其他）与方向，仅描述。
6. 合并验证+测试（均为训练期之后，各自段内排名）。

## 预注册判定（合并验证+测试 top10）

**稳健为正**需同时满足：平均净 bp > 0 且日块 95% 下界 > 0；相对随机超额 bp 的周块单侧 p < 0.01；去掉最好 3 笔后平均净 bp 仍 > 0。否则为“不稳健”。任一结论都不 promote、不部署、不改 Pine/监控/账户。
