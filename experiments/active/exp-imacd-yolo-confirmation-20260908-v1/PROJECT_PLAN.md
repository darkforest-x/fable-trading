# IMACD → Grade-A YOLO：延迟确认工程试验 V1

Owner本轮要求：“把我们之前最好的yolo模型拿来检测，先是我们指标出信号后，然后一段时间内模型检测也通过了才行，你看看行不行”。本配置一次冻结、一次检验，交付检测接线、通过率、等待与成交时钟代价；不把模型通过解释为已证明会涨/跌或能赚钱。

## 选择权重的证据

使用当前console与Grade-A研究绑定的close源、full40、native1280 YOLO11s：`analysis/output/ma_launch_owner_grade_a8000_neg24000_v1/ma_launch_owner_grade_a8000_neg24000_v1_y11s_ft1280_full40/weights/best.pt`，SHA256 `862705b999594355c1133640acc540f4de19b561889e89d9e050ddad5c6db838`。

它是已有研究基线，不能称全版本收益最优。旧`models/owner_best.pt`实际指向7月的owner_short_star_v10；HL2配对比较未过联合门。本权重训练可见窗最晚2025-11-29，验证窗最晚2026-05-03；训练原生为15m、白底1280×742、close源SMA/EMA20/60/120，不能直接拿TV界面截图送模型。

## 固定单一候选

- 指标：当前可见focusRelease（MA34、signal9、focus12、ATRband0.10），复用已测试的monitor-parity状态机；不追加此前失败的形成/箱体/高周期过滤。
- 候选：箭头收盘p形成，冻结其蓄势区`[focus_start,p-1]`。
- 等待：原生15m检测端点p..p+9，包含当根收盘即时确认，最多135分钟。这是本轮试验预算，**不是**由模型post≤9严格推导的最优上限；post的起点是模型核心末根。
- 模型：W18/W19、conf0.25、NMS IoU0.70、imgsz1280、MPS float32、batch16、rect=True、max_det300、非跨类NMS；类别dense_long/short。不训练、不更改阈值。
- 匹配：同币、同向、核心4/5根且post2..9，核心区间与`[focus_start,p]`至少共用一根真实K线。闭区间时间边界接触不算。允许核心早于箭头；保存交集根数、占比、核心相对箭头位置。此为宽松时间关联，不是人工确认同一形态。
- 失效：从p到确认根，只要`side*md<=0`或md未知就永久取消；同根失效优先。不因后续恢复复活。
- 去重：同一候选取最早可用模型端点，同端点依次confidence降序、window_len升序、detection_id升序；不挑追价更少的后续框。记录跨候选复用核心。
- 成交时钟：只观察原箭头p+1开盘和确认e+1开盘的差；正值表示沿信号方向追价。不得沿用p的成交价或盈亏比。此处不计算止盈止损、收益或杠杆。
- 该工程试验不叠加旧语义门。旧V12f融合只有5个语义确认，与本轮IMACD和蓄势区匹配协议不同，不能直接移植其结论。

## 验证与零假设

合成测试先于市场推理：时钟、真实K线交集、core/post边界、等待上限、同根失效优先、恢复不复活、去重、原/延迟开盘价、输入未来扰动与截断像素一致。

主表按币列原箭头、完整观察、确认、过期、失效、截断、通过率、等待与追价；保存每个候选与原始框。独立联结核对唯一身份、可见时间、方向、结构、交集、下一开盘位移。用原始有效窗口和模型框固定、仅在同币同月内打乱候选方向10000次(seed20260908)，检验条件化方向关联；不翻转后重跑md失效造成必然零对照。

这是工程接线试验，没有人工真假形态金标，也没有交易退出合同。正类率指模型确认率，不等于行情成功率。AUC、净收益、胜率、最大回撤、top-decile和收益随机入场对照不适用，不能捏造；对应的零假设是上述条件化方向关联。模型减少通知数不等于证明减少错误通知。
