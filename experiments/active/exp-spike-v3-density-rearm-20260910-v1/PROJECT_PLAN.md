# V3 第七项固定假设：均线密集阶段单次资格与重新蓄势

## 授权、对照与交付边界

沿用 Owner 的目标模式降噪、尽量保留正确启动及任意日期研究授权。只比较原版 SPIKE V1、固定 V3 与本项 G；不把 V2 当基准，不叠加 A—F 过滤，不修改已保存的 V4 确认信号显示、通知、实盘或其他任务。此前十三项单门与 A—F 六项结构门均未同时通过目标。本项是第七次顺序探索，历史已被反复观察，不能称盲 OOS、最优参数或保证保留正确启动。该新 G 配置第一次使用授权 holdout，须在最终报告明确记录。

先提交 detector、runner、合成测试、本计划和实际通过的独立 preflight JSON，再读取历史作 prepare；源码必须逐字节等于 HEAD。全市场候选/父子时钟/标签/共同随机日程一次冻结后才能 evaluate。阶段不可覆盖或重跑，不以调整参数修复不达标的结果。MD 完成立即转 HTML，报告和图例完整保留漏报。

## 唯一变量：新增一个密集阶段的信号资格状态

原 `prog_dense` 已是前 12 条观测的均线宽度/交叉摘要，条件为原 `pastWidth<=3` 且 `pastCrosses>=2`。本项直接沿用，不再要求连续十二个密集摘要，不使用盈亏、参考仓位、旧箱底、未来趋势分段作为解锁条件。

1. 每个连续小时数据段初始化 `armed=True`，接受第一条符合原 V3 上升沿及冷却要求的父事件，标为 `bootstrap`。不能冒称已观察到该段的新密集形成。研究期起点不重置，必须从源预热历史逐根递推。
2. 接受原父 t 后消耗资格，记录 owner/structure 身份，冻结 t 之前 12 根的原 high/low 作为归属证据；原突破门、质量确认门均不改变。后续候选被门挡住仍消费原条件边沿，但不消耗 accepted-only 冷却。
3. 锁定之后必须先观察到有效 `prog_dense=False`。此后有效 `prog_dense=True`，且其前 12 条原 width/flips 观测行 `[i-12,i)` 均在 owner 之后（`i-12>owner_i`），才恢复一次资格。false 后已经持续 true 时，可在支持窗口首次满足该条件的当根恢复，不强求该根另有 false→true 边沿。这十二条观测不等于全部 MA 计算依赖独立，MA/flip 本身仍含更早记忆。
4. 密集有效性须明确：当前 ready、pastWidth/pastCrosses 有限，同连续小时段的前十二条 width/flips 观测齐全有限。缺失不得当作离开密集，也不得跨缺口凑窗口。新密集可以在旧箱顶之上，毋须回到旧箱底；重新密集摘要高点不能替代原 V3 候选的 prior12 突破线。
5. 恢复资格不补发持续为真的旧突破条件，仍须原 raw rising edge 和 12 根 accepted-only 冷却。可同根恢复并接受原来就在该根发生的新边沿。接受后再次消耗资格。
6. 子确认只属于实际被接受的父，继续原冻结 parent_high 和 age 0..3 条件；不另套密集资格、不前移确认、不延长等待。缺口清除父、冷却及资格状态，按原 V3 新段 bootstrap。

必须保存逐根 `armed`、有效性、已见离开密集、rearm 观测窗口/时钟、owner、structure_id、bootstrap、候选边沿和拒绝原因。图中公开事件按当时真实时间画，不能以最终所属结构倒画箭头。原 V3 与 G 必须独立逐根重跑，不能筛选缓存 V3 事件替代，因为被拒绝事件不更新 G 的接受冷却。

## 固定数据、分母和统计验收

认证上一项 F 的准备与验收回执及原始引用，使用 278 个历史 OKX 山寨 1H 多头合约，不含 BTC/ETH；UTC `[2026-07-10,2026-09-09)` 共 61 天、含预热 837239 条源 bar。原 14904 标签不变，研究内 8046 锚点 = 1660 正 / 6240 负 / 146 未知，大幅正例 947。原 V3 父 10386、子 3809、同根合并标签 12042、及时正命中 1463、大幅及时命中 798 必须认证一致。

四项主门不变：合并标签 <=6021；保留原及时正命中 >=1317/1463；947 大幅正例及时捕获 >=758；共同随机匹配超额 >0 且七假设 Holm p<.01。及时仍为原锚点 t..t+1，旧父还在延续、已经有参考仓、随后确认、同结构包含该锚点都不能补入分子。阶段资格只是待检验的去重定义，不是真实趋势金标。减少标签不等于减少亏损交易。

经济只用实际接受父，子确认是升级。原 next-open、过去 5 根结构低点减 0.2ATR 与 2ATR 下限取宽、向外 tick、收盘 2R 激活 4ATR 跟踪次根生效、20bp 往返、无固定 TP 均不变。不得借最新 V4 的确认展示改变研究经济起点或分母；本项经济仍为 V3 父事件口径，不能称 V4 确认价实盘收益。重叠独立事件不是账户 NAV 或账户最大回撤。

随机对照同币×UTC 周×因果 ATR 桶最多 3 个，排除 V3/G 当前及过去 12 根已出现父子事件，不看未来事件、收益；相同位置共享对照。A—F 原 p 冻结加入 Holm7；原 V1 保留历史结果及其原随机，必须标明不属于新共同匹配。缓存复用须验证源特征 SHA、tick、周期、截止和执行源码契约一致，不能把不同入场/控制时钟当同路径。

## 事前承认的风险与合成验证
