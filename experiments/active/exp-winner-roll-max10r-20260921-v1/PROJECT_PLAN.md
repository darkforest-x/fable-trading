# 大于10R历史多单：100U、最多两次加仓的条件最大值

Owner于2026-09-21明确先做全量V9中原始净收益大于10R的多单，不跑全部12,230笔。冻结筛选367笔、209资产、339行情流；每笔独立100U，不把跨交易收益复利。此前选择最多两次加仓仍有效。Owner要求搜索最大利润，授权事后优化初仓、加仓时点/数量及退出位置；这是历史标签，不作为可执行信号。

## 固定边界

- 源：V9全量统计`statistics/full_v1/trades.csv.gz`，SHA由原统计receipt核对；原冻结cache按receipt逐流认证。保持原始入场和时间周期。
- 时域：原entry_i至exit_i之前的完整bar。原退出bar可能在open或根内已退出，故不使用其后未知高点。入口必须与cache时间及价格相等。
- 每个退出候选使用该根high平仓，同时强制整个退出根low也能存活，因此不假定high先发生。所有候选bar的OHLC、连续性必须有效，缺数据明确失败。
- 只加多头仓位，不减仓再开、不逆势摊低成本。最多两次在更高开盘价加仓。对所有允许候选穷举，数量在固定线性条件模型内优化；保留0/1/2次对照。
- 继承上一跨币研究的40倍上限、5%平坦MMR、双边各0.1%费用、零资金费及last-price代理；额外明确预留0.1%清算费与0.01U严格正缓冲。连续数量、不设历史未知订单上限，故非真实交易所可执行证明。
- 开仓时全部仓位权益必须足够初始保证金；持有过程中权益须高于维持保证金加清算费预留和缓冲。收益本金均只在原100U内滚动，无外部追加。
- 除数量与时机的事后优化外，不修改旧源、Pine、生产配置、障碍参数或原R账本。无训练/实盘。

## 验证及交付

先提交builder、协议、测试，再运行市场数据。合成路径用独立线性规划检验固定时点数量优化；小路径穷举对照全局时点选择。每条选中路径再独立重算手续费、资金、初始保证金及各bar最低维持余量。产出逐笔、逐币最高值、逐腿账本、0/1/2次同口径对照、输入SHA与运行收据。

先验只选赢家且使用未来，所以AUC、置换p、胜率和top-decile不能解释为预测能力。匹配随机策略显著性不适用于这个容量标签；严格算法零假设对照为独立LP/穷举，经济对照为同单不加仓的同一事后优化上限。报告不得借条件收益宣称alpha。
