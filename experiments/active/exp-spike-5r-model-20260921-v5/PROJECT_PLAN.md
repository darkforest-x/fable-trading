# SPIKE 5R Model V5：仅改变预测目标的前推比较

## 已有授权与唯一改动

Owner于2026-09-21在既有离线训练“继续”之后提出“或者大于 5r”。本轮把V4固定两模型的标签由最终扣费净R严格>10改为严格>5。训练例外仅限同一SHA数据、同20因果特征+周期、同两模型；不会改变全局P0/P1、YOLO资格或生产指针。旧V4源码、预测、报告和授权全部保留。

**不是把止盈改成5R，也不是把盘中最高浮盈当已兑现利润。** 原V9入场、初始风险R分母、反向退出、2R收盘/4ATR保护、原空头和20bp往返成本均不变。未知与删失仍未知，不计负类；父表label_gt10原样保存，新内存列label_gt5只由有效已结束路径net_r>5产生。

## 预先固定的方法

源为全49,207原V9多头候选、3,531个已认证流：49,070闭合、137删失；1,703严格>5，448严格>10。共同目标期2025-10-01至2026-09-10：独立候选29,118/闭合28,982，其中789>5、246>10；原串行闭合24,568，其中662>5、206>10。这里只是母体统计，不是模型结果。

其余协议逐项沿用V4 PROJECT_PLAN：四个季度2025Q4/2026Q1/Q2/Q3；每季Q取[Q-12m,Q-3m)9个月成熟标签训练，exit_time+周期<=Q-3m；[Q-3m,Q)3个月全候选仅用于无标签分数分位；相同模型冻结预测下一季度，不再拟合。20特征用训练中位数补缺，逻辑回归训练StandardScaler，固定周期one-hot。L2逻辑回归C1、max_iter2000；LightGBM7叶/深3/150树/0.03/最少200每叶；无调参、无重加权，seed921401。

每个模型比较过去校准分数最高1/5/10/20%四档，至少100个有限分数，含等号；分布变化允许实际覆盖偏离名义。单特征负参考风险同4档，旧V2.1过去三月同周期风险低10%，原版，共14路径。

## 比较口径与触发条件

主指标最终净R>5命中率，同时列样本数、覆盖率、原赢家交集召回、新增/丢失赢家、普通盈利率、平均净R及毛/净bp。所有评价按时间，不随机分组。ROC-AUC/PR-AUC、top-decile毛净和匹配随机仅作研究证据。

保留完全相同的月块bootstrap、同流同方向同月同ATR桶随机对照与月块符号置换，不因删失重抽对照；8个模型门槛分别作Holm校正。研究门：全OOF命中率差95%下界>0、随机尾部及净R两种Holm p<.01、均净bp>0、原赢家保留率>=10%。所有单项失败记录，不代表生产准入。

若任何新模型独立候选策略>5命中率高于基准、至少10个赢家且召回>=10%，则从源起点重放全部14路径，首个OOF季度前统一使用原版准入保留持仓上下文。每流原版parity与共同候选经济parity必须成立。未触发则保留全部独立失败结果，不强行串行。

**二乘二比较**：冻结旧V4（训练>10）与新V5（训练>5）的实际串行路径，都分别用>5和>10计分。由此分开“成功标准降低”和“重新训练改善”。旧模型不重训、旧交易不重跑，核对冻结receipts与逐流文件后重计统计。新旧无关风险对照必须一致。>10仅为副指标，不据其追选参数。所有季度及后两季度同表记录，资产/周期/月分组供诊断，不生成按历史赢家选币名单。
