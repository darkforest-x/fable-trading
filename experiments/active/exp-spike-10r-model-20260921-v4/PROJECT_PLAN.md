# SPIKE 10R Model V4：原始全信号的季度概率排序

## Owner授权与唯一介入

2026-09-21，助手完成V3/V3.1并明确询问“是否批准仅这批数据的离线训练例外”，Owner回复“继续”。这批准前一版`NEXT_MODEL_PROPOSAL.md`中的两个固定模型，仅对既有20因果特征及周期作离线训练。新实验不改变全局P0/P1、YOLO资格、生产指针、Pine、账户或promote；父产物的全局training_eligible=false不更改，本实验用明确SHA允许清单限定例外。独立变量仍为多头准入，原R分母、障碍、退出和20bp成本不变。

## 先固定再训练

- 全49,207原V9多头候选，49,070闭合/448严格净R>10，137删失。保留原失败和未开仓候选；无效、删失不作负类。源dataset receipt SHA写入config与授权记录，复核3531流血缘。
- 每个目标季度Q仅使用前12完整月。为确保设门槛的样本未被模型拟合，前9月`[Q-12m,Q-3m)`训练，后3月`[Q-3m,Q)`仅计算分数分位数。训练标签必须在`Q-3m`时已结束，exit_time+周期<=切点，entry_time<切点。模型不在设门槛后重新拟合。
- 固定四个目标季度：2025Q4、2026Q1、Q2、Q3（Q3至源末端2026-09-10）。不存在随机切分；同一币跨交易所相关样本的未成熟标签也被切断。
- 两模型：L2逻辑回归C=1/max_iter=2000；LightGBM binary，7叶/深度3/150轮/学习率0.03/每叶至少200。固定种子921401、2线程、无类别重加权、无早停或调参。20特征仅用训练段中位数填缺失（全缺列填0），逻辑回归按训练段标准化；周期固定30/60/240 one-hot，不输入币名、事件ID、实际填单风险、未来MFE或退出信息。
- 每季度模型给校准块无标签打分，分别以99/95/90/80分位门槛筛入。比较含等号，门槛至少100条有限分数；目标月不重标分位，不保证实际覆盖等于1/5/10/20%。所有候选（含未知标签）均可贡献校准分数。模型概率未另作监督校准，Brier/logloss/固定概率分箱用于检验概率是否可信。
- 单特征对照：负reference_risk_fraction，同样季度校准及4档门槛；另报旧V2.1过去3月同周期低风险10%和原版。风险分数不是概率。所有方案用完全相同的目标季度母体。

## 评价与实际执行复核

主指标为最终净R>10命中率，连同覆盖率、尾部召回、赢家数及每币/周期/月稳定性。报告全时间外预测期、每季度，以及最后两个季度的共同时间窗，后者只是稳定性描述，不按其结果再选择。ROC-AUC、PR-AUC、概率校准、前十分位毛/净bp和同stream/月/ATR桶随机对照列全；批量前十分位是排序诊断，不能冒充实时门槛。

月块bootstrap给相对原版10R率差区间；月块符号置换检查匹配随机的10R和净R优势；8个模型门槛用Holm分别校正。研究准入需全目标期率差下界>0、两种校正p<.01、均净bp>0、真实赢家召回>=10%，并通过串行复核。仍不构成生产准入。

预先定义串行触发条件：任意模型门槛在独立候选中相对原版提高10R点估计且至少10个赢家、至少10%召回，就重放**全部8个模型门槛**及原版/4个单特征门槛/旧V2.1，避免只回放表现最好的一行。若均不满足则不支付串行成本，保留失败。

串行从源起点重放以保留持仓上下文：目标首季前所有方案使用原版准入，首季起才过滤多头；空头和原始反向退出全程不变。报告只包含目标期事件。记录逐流原版parity与候选经济parity；召回严格用event_key赢家交集，并另列新开赢家。
