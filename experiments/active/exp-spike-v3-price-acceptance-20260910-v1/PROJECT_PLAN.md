# V3 第六项固定假设：突破后一根收盘价格接受

## 授权与边界

沿用Owner要求目标模式降低噪音、尽量保留正确启动及全部日期可研究的授权。固定原版SPIKE V1与当前V3对照；忽略V2作为比较版本。13项原门与A—E结构门未同时通过。F为第六项顺序探索，已见历史、不称盲OOS或最优参数。单个新配置第1次使用授权holdout。不改线上Pine/通知/执行/其他任务，不训练或promote。

先提交本计划、detector、runner、测试与已落盘预审回执，核对HEAD准确字节后prepare。prepare先冻结全部事件及共同随机日程，evaluate只跑一次。报告源码先提交，MD立即转HTML，所有失败与未知保留。

## 唯一变化：把原V3父的公开接受推迟一根并检查固定边界

原V3候选发现序列逐字节保持，rawedge、接受原候选后12根冷却、原0..3根子确认均由原V3 detector产生。F不反馈改变这些原始发现，所有原发现仍保存在研究产物。t是原候选父：

1. 在t冻结其原前12根最高价`frozen_parent_high`，记录原发现时间、价格和原身份。
2. 只在完整、连续的t+1根收盘检查`close[t+1] > frozen_parent_high[t]`；等于或低于拒绝。不要求t+1最低价未跌破、不要求比t收盘更高、不加量/ATR/均线/4H门。
3. 没有t+1、时钟中断、或t+1的OHLC非有限/非正/几何破损，即未知/不可判定（明确原因），不算拒绝或成功过滤；这是完整价格数据要求，不因volume/ATR/ready不足额外加门。不等t+2、t+3补考，未来子确认不得复活拒绝候选。
4. 通过时F公开接受事件发生在t+1收盘，F信号价是该收盘价；原t发现时间/价保存在独立字段，不能回填接受箭头。下一可执行入场为t+2开盘，原执行器在F接受根计算过去窗口与止损，风险参数、费用、退出算法不变。
5. 原子确认若在t或t+1已经实际出现，F在t+1接受时携带“已有质量确认”状态，与接受标记同根合并；保存其原真实确认时间/价、F公开时间/价，不能称原子确认当时已可交易。原子在t+2/t+3才出现，则在原实际收盘升级已接受F父；不重新接受、不重置参考、不重复经济开仓。拒绝/未知原父的子确认不进入F公开事件。这个合并是等待一根的时序结果，不是另加质量过滤。
6. F字段至少保留原candidate_i、candidate_time/close、frozen_high、acceptance_i/time/close、原child_i/time/close、publication_i/time/close、status(accepted/rejected/unknown)、delay_bars与reason；完整逐根状态允许从前缀重现，不能用t+1数据修改t时已经存在的状态。

## 固定数据、指标与时序

认证E输入：278个历史OKX合约1H多头，不含BTC/ETH，UTC [2026-07-10,2026-09-09) 61天，837239源bar含预热。原14904标签字节不变，研究8046锚点=1660正例/6240负例/146未知，947大幅正例。原V3父10386、子3809、合并标签12042、及时正例1463、大幅命中798固定。

公开F接受及升级按其真实发生时钟是否在研究期统计，同时另报按原候选时钟分组的通过/拒绝/未知及跨边界数，不能把期末未知当假启动被滤除。warmup候选可以在研究起点产生接受，研究最后候选t+1不在研究区间的另记，不移动研究截止。

四项必要门保持：同根合并公开标签<=6021且减少>=50%；原1463及时命中保留>=1317(90%)；947大幅正例及时命中>=758(80%)；共同随机匹配超额>0且六假设Holm p<.01。事前预审明确“未知不算成功过滤”：降噪主门还必须将unknown父所属的原同根合并标签数加回F公开标签，保守计数仍<=6021且相对原12042减少>=50%，与raw门同时满足；未知不能帮助过门。不改变原分母和其他三门。及时仍要求锚点t..t+1有真实F接受；旧父已晚1根则新接受晚2根，必须算漏报。原观察发现/已有参考/晚确认不修补分子。另报父接受数减少，以及公开标签减少中有多少来自拒绝、时移越界、早确认合并，不能将合并或时移越界误报为消除了亏损开单。

经济只算F接受父；次根开盘，同5根结构低点减0.2ATR与2ATR取宽、向外tick、收盘2R启动4ATR跟踪次根生效、20bp往返，无固定TP。已变晚的入场不能复用t原候选的执行结果；缓存必须严格源/tick/决策位置/截止/执行代码一致。原V3实际事件不变；原V1保持认证历史对照及历史随机，不伪称共同新匹配。

共同控制仍同币×UTC周×因果ATR桶最多3个，排除V3/F当前和过去12根公开父子事件，不看未来事件/收益。同位置共享控制。A—E原p保持冻结，F加入Holm6；之前13项与反复观察偏差仍披露。不改目标、排序选币、标签与成本追达标。

固定HYPE/NEAR/PEPE完整96根图标示原V1、V3与F真实发现/接受/确认时间和后续走势，不按结果挑例。全期、前31/后30天、逐周/固定夜报告召回、净胜率/毛净bp/配对超额/置换p、量比/TR描述AUC与top10%单特征对照。未训练故val AUC不适用；重叠事件不是账户NAV/MDD。失败不部署。

## 最小验证

合成测试覆盖大于/等于/低于固定边界、突破根之后高点不得改边界、盘中跌破但收盘站回可通过、下一根收盘低于原t价但高于边界仍通过、缺口/期末未知、原候选序列与冷却完全不变、t/t+1旧子随接受同根公开且保留原真实时钟、t+2/t+3后续升级、拒绝父的子不复活、未确认也可接受、前缀/未来扰动稳定、公开价与经济next-open、候选跨研究边界与未知不偷计降噪。

不得将待定候选在t标为已拒绝/已接受再声称无重绘；逐根公开状态只能在t+1改变。研究候选表可在最终状态记录t+1裁决，但必须有明确decision_time，不能作为t的特征。
