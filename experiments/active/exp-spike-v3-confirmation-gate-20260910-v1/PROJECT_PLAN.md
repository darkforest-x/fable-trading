# V3 第三项独立结构假设：确认后才取得同段抑制权

## 授权、来源与研究顺序

Owner 2026-09-10 要求开启目标模式，尽可能减少信号并保留正确启动；比较原版 SPIKE 强劲爆发 V1 与当前 V3，忽略中间版本。本项沿用该离线研究授权及全部日期授权，不改线上监控、通知、ACTIVE、实盘和其他会话研究。

这是两项固定结构实验之后的第三项探索假设，不是盲测。A 在已有信号收盘参考内抑制新预警，B 要求完整近零箱体，均未达到预登记目标。源码审计发现 A 的未确认父预警即使超过确认窗仍继续占用，这给予弱观察事件长期抑制权。C 只改变抑制权的取得与释放时机，不改价格、量能、密集、冷却、风险与成本阈值。

本计划、builder、detector 与测试须在读取 C 市场检测与评分前提交。先全局 prepare 冻结检测日程和对照，再 evaluate。每个固定新配置第1次消耗 >=2026-05-04 的 holdout；已有研究结果用于形成新假设，不能据此称独立样本外，不再删除或重跑旧产物。

## 固定状态机

- 空闲时沿用 V3 early 条件的真实上升沿及 accepted-only 12 根冷却，接受父预警即显示，按其收盘与原风险 helper 建立临时参考，但没有抑制权。
- 每根先用上根保护判断临时/已确认参考退出，收盘 ATR 更新只对下一根生效；退出不会让同根重开。
- 父预警在 age0..3 获得原 V3 确认且原参考仍存活时，发质量升级并获得抑制权；不改参考入场价、初始止损或跟踪参数。
- age4 仍未确认，取消临时参考和父等待状态，明确记为未确认过期，不能伪装止损或成交退出。
- 已退出父在原0..3根内后来获确认，仅作为历史升级，不复活参考、不取得抑制权。
- 获确认且参考仍存活期间压住后续父预警；每个 raw 条件边沿仍逐根更新，拒绝事件不更改冷却时间。结束后从下一根恢复资格；缺口清除状态。
- 只有上述抑制所有权机制变化。MD34/SB9、近12根突破、密集12/3ATR/交织2、三根量比1.5/净推进1.5ATR、确认0..3、冷却12全部保持。A/B 不与 C 打包。
