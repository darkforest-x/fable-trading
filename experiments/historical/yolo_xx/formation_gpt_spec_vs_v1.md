# Formation：按 GPT 原案重做，与 v1 的错误实现对照

**Phase 3 / stage 2** · 2026-08-06
**性质**：只读实验。未训练 YOLO、未改权重/阈值、未用盈亏标签、未消耗 holdout。
**按本仓口径：给数字，不下判决。**

---

## 1. 一个实现偏差的更正

GPT V4 §7 Layer 3 原文：

```
完整形态：
    T0 -------- T100
生成前置窗口：
    T0-T30
    T0-T50
    T0-T70
标签：未来是否形成经典形态
模型学习：当前状态 -> 未来形成概率
```

**GPT 的意思**：一个形态从开始到完成占 T0→T100，取它的**前 30%/50%/70%** 作输入——
模型**看着形态长了一部分**，预测它会不会长成经典形态。

**v1 做的**：窗口结束于形态出现点**之前** 30/50/70 根 bar——
模型**完全看不到形态**，预测未来会不会冒出一个。

两者不是同一个问题的变体。v1 问的是「现在风平浪静，7.5 小时后会不会出形态」，
GPT 问的是「均线已经在聚拢，会不会聚成真的」。**v1 的难得多，且不是 GPT 要的。**

---

## 2. 一个必须先知道的事实：形态很短

owner 框的横向跨度（307 个有框 A 级样本）：

| 统计量 | bar 数 | 时长 |
|---|---|---|
| 中位 | **10.8** | **2.7 小时** |
| p25 / p75 | 8.3 / 13.0 | — |
| 最大 | 24.8 | 6.2 小时 |

GPT 画 `T0 -------- T100` 时似乎设想形态是一段很长的过程；实际它只有 10 根 bar。
因此 T0-T30 距形态完成只有 **8 根（2 小时）**，T0-T70 只有 3 根（45 分钟）。

这也意味着：**T0-T30 的窗口里已经能看到形态的前三成**，
本实验测的更接近「部分形态识别」，而非「凭空预测形态出现」。

## 4. 读数

### 4.1 GPT 原案更强，且 T0–T30 是今天最高的可信数字

0.7417 [0.689, 0.788]，κ 0.295。相对 v1 最好成绩（0.6453）高 **+0.096**。
与 v1 的 CI **不重叠上界**（0.703 vs 0.689 边界接近但方向明确）。

### 4.2 三个切点之间不单调，且 CI 互相重叠

T30 0.7417 > T70 0.6922 > T50 0.6643。若「越接近完成越容易」，应单调递增，实际不是。
三者 CI 大幅重叠（[0.689,0.788] / [0.607,0.721] / [0.637,0.748]），
**不能从本数据判定哪个切点更优**。唯一稳的结论是三者都优于随机。

### 4.3 提前量与准确度的权衡是真实的

| 提前量 | AUC |
|---|---|
| 2 小时（GPT T30） | 0.7417 |
| 7.5 小时（v1） | 0.6453 |
| 17.5 小时（v1） | 0.5638 |

跨越两种实现看，**提前量越长，准确度越低**，这条关系比单个数字更稳。
2 小时的提前量对 15m bar 的策略是否够用，属 owner 判断。

## 5. 限制

1. **T0–T30 的窗口含形态前三成**，故本实验不是纯粹的「事前预测」，
   而是「部分形态 → 完整形态」的预测。与 v1 的「无形态 → 有形态」是不同任务，
   两表并列仅供参照，不构成同一量纲的比较。
2. 形态跨度中位仅 10.8 根，三个切点之间实际只差 3–8 根 bar，
   图像差异很小——这可能正是三者不单调的原因。
3. val 侧正样本 124 条，每折约 25 个。
4. 负样本沿用随机位置构造，PU 污染率经审计为 4.0%（见 `pu_contamination_audit.md`），
   对 AUC 影响小于其标准差。
5. 「A 级」目标本身建立在 owner 可见未来的标注上。
6. 单人评分，重测 κ 0.700 为标签噪声上限。
7. 全程未用收益类信息。

## 7. 下一步选项（不含判决）

1. **细化切点**：当前只测了 30/50/70 三档且不单调。可按**绝对 bar 数**而非百分比切
   （形态跨度差异大，百分比切点在 8 根和 13 根的形态上含义不同）。
2. **扩正样本**：val 侧 124 条是硬约束。
3. **检验 T0–T30 的实用性**：2 小时提前量下，把它接到 Layer 4（启动判断）看是否可用。
4. **回答一个未解问题**：T0–T30 究竟在识别「形态的前三成」还是「形态之前的市场状态」？
   可通过遮挡实验区分（把窗口右侧 8 根涂白后重测）。
