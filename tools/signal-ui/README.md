# Signal center controls

Bootstrap 5.3.8 controls are compiled under `#signals-view.signal-workspace`.
Only form controls/selects, buttons, button groups and navigation are included.
There is no reset, CDN request, Bootstrap JS or Python dependency change.

Rebuild with `npm ci --ignore-scripts` and `npm run build` in this directory.
The compiled CSS is shipped by the existing content-versioned asset loader.
The Bootstrap MIT license is in `yoyo/monitor/static/bootstrap-LICENSE.txt`.

Source: https://getbootstrap.com/docs/5.3/customize/optimize/
