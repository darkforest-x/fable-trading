BTCUSDT.P K1→K2：K2 极值外 ATR 止损缓冲实验（15m / 5m）

日期：2026-09-04

实验：exp-btcusdtp-k1k2-stop-buffer-preholdout-20260904-v1

状态：REJECTED；两周期均保留 0 ATR 缓冲，audit 未打开，holdout 读取 0 行

结论先行

“很多止损后来又走到 3R”不等于“把止损放宽就能救回来”。在冻结信号、下一根开盘入场、3R 目标、12 小时持有、1.5R 盈利保护和 20bp 往返成本后，只把 K2 极值外缓冲从 0 增至 0.10/0.20/0.30/0.50 ATR：

  • 15m 的最佳臂仍是 0 ATR：稳健分 -16.35bp、均值净收益 -13.51bp。其余四臂稳健分为 -19.15 至 -23.07bp。
  • 5m 的最佳臂也仍是 0 ATR：稳健分 -17.68bp、均值净收益 -17.32bp。其余四臂稳健分为 -18.21 至 -20.48bp。
  • 真实执行中，宽止损让更多窄风险候选通过经济门，15m 交易数从 345 增至 521，5m 从 755 增至 1,250；但新增密度没有变成毛收益，反而稀释了优势。
  • 锁定完全相同的原始交易 cohort 后只重算止损和 3R 目标，结果仍恶化。这排除了“只是新增劣质信号拖累”的单一解释。

因此本轮不打开 2025-01 至 2026-02 的非纯净 audit，更不读取 2026-05-04 起的最终 holdout。下一实验应只改变入场确认时机，而不是继续扩大结构止损。

冻结规则

信号形态

  • K1：方向实体真实贯穿 SMA(HL2)。
  • K2：影线触及均线；实体和收盘完整留在交易方向一侧。
  • K1→K2 路径、K 线颜色、均线侧颜色及 12 项等权因果形态分沿用上一轮，不重调。
  • 15m：SMA120，K1→K2 距离 2–8 根，分数下限 0.40。
  • 5m：SMA40，K1→K2 距离 6–24 根，分数下限 0.40。

执行与唯一变量

  • 入场：K2 完成后的下一根开盘。
  • 基准止损：多头 K2 最低点、空头 K2 最高点。
  • 唯一变量 k2_stop_buffer_atr ∈ {0, 0.10, 0.20, 0.30, 0.50}：多头止损再下移、空头止损再上移相应 ATR14。
  • 止盈：固定 3R；止损变宽时目标同步远离，这是 R 倍数执行的必要结果。
  • 保护：收盘达到 1.5R 后启用冻结的成本覆盖保护。
  • 持有：12 小时；同根碰 TP/SL 时保守按 SL；超时按末根收盘。
  • 成本：往返 0.20% = 20bp；未另计 funding 或 20bp 之外的滑点。
  • 经济门：风险 0.15–2.50 ATR，fee_to_risk ≤ 1.25；15m/5m 冷却均为 6 小时。

缓冲降低费用相对风险，从而放行更多候选；这些更早出现的候选又占用 6 小时冷却，挤掉原交易。即使部分新增交易毛收益为正，其量级仍远小于 20bp 成本，不能形成可交易优势。

3. 匹配随机对照只证明“相对少亏”，不证明系统赚钱

15m 基准相对同月、同 UTC 六小时块、同 ATR 五分位的随机入场超额 +9.27bp，配对符号翻转 p=0.0066；这是一个真实的相对形态信息。但绝对净收益仍为 -13.51bp，意味着随机环境更差，形态优势不足以覆盖交易成本。5m 的相对超额只有 +2.34bp，p=0.0966，也不显著。

随着缓冲增加，15m 的匹配超额从 +9.27bp 单调式衰减到 -1.39bp；5m 也总体衰减至 +0.27bp。止损缓冲没有增强形态本身，只是在扩大风险和成交池。

失败归因与下一假设

  1. 主因不是止损离 K2 太近。 固定 cohort 下宽止损仍差，且两个周期都呈跨半年失败。
  2. 原始形态在 15m 有相对信息，但强度小于摩擦。 需要减少低质量入场，而不是用更大风险承接它们。
  3. 5m 的形态分排序近似随机。 后续不能只提高 score floor；应验证 K2 后是否真正出现方向确认。
  4. 下一轮只改入场确认。 预注册“在固定分钟窗内首次收盘突破 K2 方向极值，下一根开盘入场；确认前触及原止损则取消”，保持原止损、3R、保护、成本等不变。15m 和 5m 使用同一时钟长度、各自换算成 bar 数。

风险与诚实声明

  • development 被用于选参，表中 p 值是描述性证据，不是最终确认。
  • 2025–2026-02 audit 因开发门失败而没有打开；2026-05-04 后 holdout 读取为 0 行。因此这里不能声称“近半年实盘有效”或“最终失败”。
  • 数据只有 BTC-USDT-SWAP；结论不能自动推广至 ETH 或其他币。
  • 20bp 固定成本未拆分 maker/taker，也未另加 funding；降低假设成本会机械改善净收益，但不是策略优势。
  • 固定 cohort 反事实会保留那些在宽缓冲真实执行中可能因门禁/冷却消失的交易，因此只用于机制归因，不用于选择。
  • 本轮没有修改 TradingView Pine、ACTIVE、frozen、forward log、部署、消息或真实订单。
