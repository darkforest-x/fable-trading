结论

本轮只改变一件事：收盘浮盈达到多少 R 后，从下一根 K 线起把止损抬到覆盖 20bp 往返成本的位置。测试 0.75、1.00、1.25、1.50、2.00、2.50R 和完全关闭保护；信号、立即次开盘入场、K2 极值止损、3R 止盈、12 小时持有上限、6 小时冷却和成本全部冻结。

保护过早不是当前系统亏损的主因。 15m 关闭保护相对 1.5R 只改善平均净值 0.28bp，稳健分反而略差；5m 关闭保护改善平均净值 0.41bp、稳健分 0.37bp，远低于预注册的 +2bp 移动门。两个周期均保留 1.5R，并因绝对净值仍显著为负而禁止读取 audit。

数据与冻结规则

  • 数据：OKX BTC-USDT-SWAP；5m 原始快照 341,567 行，SHA256 767f67c2…eed5ac，物理截止 2026-02-28。
  • development：2023-01-01 至 2025-01-01，四个连续半年折；15m 形态候选 1,661，成交 345；5m 候选 9,343，成交 755。
  • 15m：SMA120、K1→K2 gap 2–8、score ≥0.40；5m：SMA40、gap 6–24、score ≥0.40。
  • 选择门：相对 1.5R 的稳健分至少 +2bp，最差折不得恶化超过 3bp，并满足样本门。开发成功还要求平均净值与稳健分 >0、最差折 >-5bp、四折毛收益均 >0。
  • audit 读取 0 行；仓库最终 holdout（≥2026-05-04）读取 0 行。

为什么“更多赢家还能走远”仍然没有转化为收益

关闭保护确实让 TP 数增加：15m 从 79 增至 95，5m 从 141 增至 215；但它也把原本以近成本价离场的交易重新暴露给完整结构止损，SL 分别从 221 增至 240、454 增至 534。赢家尾部变长和失败尾部同时变坏，最后每笔只增加 0.28bp / 0.41bp。

这说明用户观察到的“部分盈利交易能走得更远”是真实路径现象，但调整保护触发点无法提取它：当前 3R 是整单一次性退出，保护只决定未到 3R 的回撤损失。要检验赢家尾部，下一步应直接改变 target R，而不是继续微调保护。

四折也不支持某个隐藏稳定峰值。基准 15m 净 bp 为 -7.70 / -20.54 / -7.91 / -18.82；5m 为 -21.07 / -16.26 / -16.91 / -15.34，均至少一折毛收益不为正。关闭保护的最差折还恶化到 -22.21bp（15m），没有跨期稳健性。

排序基线

保护臂不改变信号排序。冻结基准的 15m AUC 为 0.549，top-decile 毛 / 净为 +14.71 / -5.29bp，置换 p=0.206，单特征 top-decile 净 -10.98bp；5m AUC 0.489，top-decile 毛 / 净 +0.91 / -19.09bp，p=0.655，单特征为 -21.02bp。形态分仍没有提供足以覆盖成本的排序能力。

决策与下一实验

  • 15m 与 5m 都保留 1.5R 保护；不打开 audit。
  • 不再搜索保护触发细粒度参数，避免围绕噪声过拟合。
  • 下一轮只改变固定止盈倍数：2R / 3R / 4R / 5R / 6R；其余规则保持不动。若固定目标仍失败，再独立预注册 runner，而不把两种修改混为一个实验。
