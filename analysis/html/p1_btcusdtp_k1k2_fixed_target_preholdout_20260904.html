结论

用户关于“许多盈利交易在 3R 后仍能走远”的观察成立，但不能直接推出整单止盈应抬高。本轮只把固定目标从 3R 改为 2/4/5/6/8R，其余全部冻结。

  • 15m：3R 仍是稳健分最高点；4R 近似持平，5R 起显著变差。
  • 5m：2R 和 8R 各有局部改善，但相对 3R 的稳健分只提高 1.23bp 和 1.17bp，均未达到预注册 +2bp 门；所有目标扣 20bp 后仍为负。
  • 因此不打开 audit。下一步不再继续扩大固定目标，而是单独测试“3R 先兑现一部分 + 剩余仓位跑 runner”，以分离确定收益和长尾收益。

数据与冻结规则

  • 数据：OKX BTC-USDT-SWAP；原生 5m 快照 341,567 行，SHA256 767f67c2…eed5ac，物理截止 2026-02-28。
  • development：2023–2024 四个连续半年折；15m 候选 1,661、成交 345；5m 候选 9,343、成交 755。
  • 信号：15m SMA120、gap 2–8、score ≥0.40；5m SMA40、gap 6–24、score ≥0.40。
  • 执行冻结：K2 后下一根开盘入场、K2 对侧极值止损、1.5R 收盘触发费用保护、12 小时、6 小时冷却、20bp 往返成本。
  • 移动门：稳健分相对 3R 至少 +2bp，最差折不得恶化超过 3bp；开发成功还要求净值和稳健分 >0、最差折 >-5bp、四折毛收益均 >0。
  • audit 读取 0 行；最终 holdout（≥2026-05-04）读取 0 行。

长尾为何存在，却不能靠整单抬目标兑现

以 3R 基准交易为条件，15m 的 79 笔 TP 中，未来 12 小时价格路径有 79.7% / 58.2% / 48.1% 曾达到 4R / 5R / 6R；5m 的 141 笔 TP 中对应 85.8% / 74.5% / 65.2%。这验证了图上的长尾观察。

但这些是先知道已经到 3R 后的条件统计，而且 horizon_hit_* 还会继续观察原交易已经退出后的价格。把整单目标直接改到 8R，会让原本确定的 3R TP 在途中重新分类为保护退出或超时：15m TP 79→10、保护退出 39→94，毛收益反而从 +6.49 降到 -1.14bp；5m TP 141→49、保护退出 158→244，毛收益只升到 +4.14bp，仍远不足覆盖 20bp。

时间折也显示 5m 8R 的改善并非完全虚构：四折净值从 -20.29 到 -13.75bp，后两折更好；但四折仍全负且相对基准稳健改善只有 1.17bp。它值得作为 runner 尾部目标的先验，不够资格直接替换 3R。

排序基线

目标不改变信号排序。3R 基准 15m AUC 0.549，top-decile 毛 / 净 +14.71 / -5.29bp，置换 p=0.206，单特征 top-decile -10.98bp；5m AUC 0.489，top-decile毛 / 净 +0.91 / -19.09bp，p=0.655，单特征 -21.02bp。当前首要限制仍是入场池毛优势不足，不只是止盈位置。

决策与下一实验

  • runner 比例必须独立预注册，不能根据本轮某几笔漂亮走势人工挑选。
