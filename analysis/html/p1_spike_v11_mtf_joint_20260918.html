结论一句话：未通过，而且 V11 没有比 V10.4 更好。 15m：V11 每笔 −0.048R（V10.4 −0.056R），后段 −0.254R；1h：V11 每笔 +0.062R（V10.4 +0.088R），后段 −0.126R（V10.4 −0.077R）。 V11 − V10.4 的每笔差：15m +0.008R [−0.021, +0.041]，1h −0.026R [−0.071, +0.034]，都在 0 附近。 新加进来的「突破+spike（上级突破）」前段每笔还行（15m +0.27R、1h +0.21R），后段最差（15m −0.29R、1h −0.42R），不是最强信号。

1. 规则

  • 突破+spike（上级突破） = 本图（15m）自己出了 V9 多头确认（SPIKE），同时上级（1h）下降线收盘突破； 两者间隔 ≤6 根本图 K，第二个事件当根要过和 V10.4 一样的检查（六线之上、动量、BB/标的/量比/时段、离六线 ≤3ATR、站上启动区间）。 本图没有自己的 SPIKE 时，上级突破只是提示，不算信号。一个 SPIKE 只算一次（本周期线和上级线共用）。
  • 时间：上级 K 收盘后才算突破——1h 的 19:00 那根要到 20:00 收盘后，15m 从 20:00 那根开始才看得见，不回填。
  • 上级周期找线规则与本周期相同（参数全默认）；已突破的线立即退出上级候选池。
  • 出场、成本、每币一笔与 V10.4 回测完全相同（次根开盘入场、5 根低点/2ATR 止损、2R 后 4ATR 追踪、V9 空头确认平仓、往返 0.2%）。

2. 数据与复现

  • 数据：本地 Binance 5m 档案 638 个永续，15m/1h/4h 都由同一份 5m 聚合；信号收盘 2024-09-10 → 2026-05-01，后段从 2025-09-10 起。 批量前检查所有文件没有 2026-05-01 之后的行；holdout 未读。你截图里的 HYPE 2026-09-17 在 holdout 期内，本地没有，这次核对不了。
  • 复现核对：同一次运行里的 V10.4 与 V9 多头两臂，和六周期报告的原账本逐笔比对（15m 4,711 + 23,223 笔、1h 1,476 + 6,565 笔），0 差异。
  • 上级突破数量：15m 这边能看到的 1h 突破 23,307 次、1h 这边的 4h 突破 6,178 次（窗口内）。

6. 解读

  • 上级突破给 15m/1h 各多出约 13%–14% 的联合信号，它们和原来的联合一样跟着大盘走：前段赚、后段亏，择时上没有更好。
  • 1h 上 V11 比 V10.4 略差，是因为新增的（上级突破）那类后段亏得多，把原来 1h 的「比随机好」冲淡了（p 从 0.009 变成 0.113）。
  • 必报项里的 AUC / top-decile 不适用（无模型打分）；对照 = 匹配随机做多 + V9 多头 + V10.4 同引擎基线。
