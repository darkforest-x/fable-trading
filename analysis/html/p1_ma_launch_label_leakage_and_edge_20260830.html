MA 密集启动：标签泄漏与真实 edge（2026-08-30）

结论先行

mAP 0.91 的那个检测器，学的不是形态，是「价格最后两根有没有动」。

把标签从「启动成功」换成「最终赚钱 vs 最终亏钱」之后，同一套配方的 mAP50 从 0.912 掉到 0.400， 提案相对匹配对照组的 edge 从 +0.238 ATR 变成 −0.024 ATR（95%CI 横跨零点）。

而且用更严的基线一测，15m 检测器是负贡献：闭着眼做筛选门放行的每一个事件， 净收益 +0.059 ATR；让模型挑一遍之后变成 −0.029 ATR。那点 edge 全属于筛选门，不属于模型。

解读：每个数字变化的归因

1. 0.912 → 0.400 的落差来自标签，不是周期也不是数据量。

冻结筛选门要求 post1/post2/post3/post5 进度达标。实测 1,043 个正例：


post1  中位 +1.06 ATR   最小 −0.00   低于 0 的比例 0.0%
post2  中位 +1.91 ATR   最小 +1.00   低于 0 的比例 0.0%
post5  中位 +2.85 ATR   最小 +1.75   低于 0 的比例 0.0%

零例外，最小值精确卡在门槛上。而负例 abs_close_progress_atr_core_plus_2 ≈ 0.0。 正例=已经动了 ≥1 ATR，负例=完全没动，且模型输入窗口含核心后 2–9 根， 这个差别直接画在图上。0.91 测的是「最后两根多长」。

换成结果标签后正负例都在启动，捷径失效 → 0.400。

2. 8 倍渲染只值 +0.05 mAP，且第 3 轮见顶。

5m ×1 (3,812 张) mAP50 0.400；5m ×8 (29,619 张) 0.450，但最佳 epoch 从 16 提前到 3， 之后一路掉到 0.273。8 张渲染是同一形态的 8 个水平位置，不含新信息，只是让模型更快背完。 15m 那两个也是同样形状：40 轮里第 4–6 轮见顶，后 34 轮全是退化。

3. +0.238 ATR 的 edge 属于筛选门。

匹配对照组是随机时点入场，而模型的池子天生是「门放行的事件」——门保证了入场时已朝正确方向走了 中位 1.91 ATR。把对照组换成「门放行的全部事件」，模型的贡献变成 −0.088 ATR。

4. 置信度不是质量排序。

与 2026-08-28 的审计一致（episode 最高分主要反映重复检出次数，rho=0.859）。 本轮更直接：conf 与净收益、与胜率都无相关，最高分那档净收益仍是 −0.385 ATR。

匹配随机对照组（方向性实验必备）

已在上表给出。补充设计说明：

  • 对照抽样在同一源文件内进行，同年同月、同 ATR 三分位、同方向，避免跨币/跨时段比较
  • 每个真实提案配 20 次随机入场，取其均值配对，再对配对差做 4,000 次 bootstrap
  • 强制 ATR/price ≥ 1bp 下限。首次运行未设下限时，停牌冻结报价的 bar 使 ATR≈0， 报出 edge = 2.9e30 ATR——那是除法产物不是交易

风险与诚实声明

  1. 5m ×8 只跑了 19/40 轮就被 owner 终止，其最佳 epoch 3 / mAP50 0.4498 是前 19 轮内的最优。 剩余 21 轮理论上仍可能翻盘，但曲线已连续下滑 16 轮（0.450→0.273），翻盘概率低。不是完整实验。
  1. 15m 和 5m 不是同一个可交易对象。 ATR、障碍、确认窗都基于「一根 K」， 5m 的一根只有 15m 的三分之一。两者的 mAP 不可直接比较；本报告只在标签变量上做对照。
  1. 5m 的 edge = 0 是「未能证明有 edge」，不是「证明没有 edge」。 n=367 个提案， CI [−0.336, +0.309] 足够宽，容得下一个小的真实 edge。要收窄需要更多样本或更强的检验。
  1. 本轮未消耗 holdout。 所有窗口 < 2026-05-04，抽查 40 个正例窗口越界数为 0。 未训练/调参/改阈值/promote/部署/下单。
  1. 数据集里发现并删除了矛盾样本：20 组逐字节相同的图，其中 3 组同一张图既被标成正例又被标成负例 （相邻核心检测落在同一窗口，结果一个止盈一个止损）。矛盾组整组删除而非二选一。
  1. 净收益评估用的是各模型自己的 val split，不是共同数据。15m 两个模型共用同一 val（可比）， 5m 是另一个 val（与 15m 不可比）。
