1. Owner 参考图到底定义了什么

截图左上角明确是“20 / 60 / 120”双均线，仓库渲染合同对应六条线：

  • SMA20 / SMA60 / SMA120；
  • EMA20 / EMA60 / EMA120。

需要同时满足的视觉因素不是“六条线距离近”一个变量，而是：

  1. 六线带宽窄：(max(MA)-min(MA))/close；
  2. 六条线在近 12 根内反复换序/交叉；
  3. K 线实体近 12 根内反复接触、完整穿过均线束；
  4. 密集具有持续性，而不是偶然一根重合；
  5. 当前在收紧或尚未大幅散开。

全部特征只使用当前决策 bar 及以前数据，方向无关，不读取上涨/下跌结果。最终显式权重为：

分量 权重
六线窄带0.35
六线交叉/换序0.30
K 线实体与均线束交互0.25
密集持续率0.05
继续收紧0.05

斜率一致性只保留为诊断，权重固定为 0，避免“六线平行上涨/下跌”反而拿高分。

3. 数据质量与路径修复

positive_manifest.jsonl 中 1,345 行里有 1,339 条 source_csv 文件名已经过期：系统重装和 继续 fetch 后，文件尾部的行数后缀变了。代码没有相信旧路径，也没有按币名随便选文件，而是：

  1. 枚举该 symbol 唯一的 okx_{symbol}_15m_*.csv；
  2. 在原 source_owner_global[1] 索引处读取时间；
  3. 必须与 source_owner_cut_time 完全相等才接受；
  4. 0 个或多个匹配都 fail closed。

结果：1,345/1,345 全部评分；215 个 symbol 只计算 215 次时间序列。1,339 条 stale name 全部通过 索引时间一致性找回，另 6 条原文件名直接匹配。完整 2,525 也达到 2,525/2,525。

反证集是 owner_side_short_tip_v1b_detect1000 中已完成人工判断的 390 条：keep 71、drop 319。 它与 104 个 ⭐ 阈值校准集分开，且没有用于拟合分数或门限。

其他必报诊断：

  • keep/drop AUC：0.4887；
  • keep 平均分 − drop 平均分：−0.00641；
  • 标签置换零假设：keep/drop 与分数可交换，10,000 次，seed=20260821；
  • 单侧 keep score > drop score：p=0.6352；
  • A+B precision Wilson 95% CI：[14.20%, 23.05%]，下界没有超过 base rate。

结论：旧“只看带宽”的规则会反向筛选；新分数在标杆视觉上更合理，但跨到独立 short-tip proposal 后仍没有区分力。允许做排序页面，不允许做自动删图门。

本实验是标签/形态质量审计，不是方向收益实验，因此 val AUC、top-decile 收益、成本、胜率和 匹配随机入场对照按字面均不适用；不得编造。上述标签置换是同等严格的零假设对照。

  4. 新候选只进 candidate_review，不直接当正例；方向和核心边界仍由 Owner 确认。
  5. 生成新版本 manifest，不覆盖旧数据；重验 split 依赖、图像/标签 SHA、无未来和类别比例。
  6. 只有 Owner 明确批准后，才能把新版本 training_eligible 改为 true，再讨论 3060 单变量训练。

10. 风险与诚实声明

  1. 单张截图不足以唯一确定决策 bar、触碰容差和窗口长度；当前参数由仓库六均线合同、旧严格带宽 和 pre-holdout ⭐ 标杆确定，后续不能因上涨结果随意修改。
  2. 390 条反证来自 short-tip detector proposal，与 1,345 个旧 Owner box 不是完全同分布；失败足以 否决“自动过滤”，但不能证明排序对旧框毫无辅助价值。
  3. 104 个 ⭐ 用来定阈值，所以 ⭐ recall 是校准描述，不是独立泛化指标。
  4. 当前行情只证明“参考时段会得高分”，不证明“高分必涨”、方向可判或扣成本后能赚钱。
  5. 2,525 中 long/short 是方向协议裁决，不等于这次重新确认每个样本质量；页面仍需 Owner 决定。
  6. 本轮没有生成新训练版本；原 1,345、原标签和 eligibility 全部保持不变。
