为什么盈亏框要同步改起点

只隐藏预警、继续沿用预警价格，会让确认标签旁的盈亏框使用当时尚未确认的入场位置。本版从确认收盘才建立风险参考，并用确认当时的 ATR 和近期极值计算初始风险；当前和峰值 R 从 0 开始，随后才逐根跟踪。

止损倍数、风险取整、跳空保护、移动保护算法保持。起始时刻不同，入场价、止损价、R 和保护触及时间会变化，不能套用原预警回测的收益数字。3R 仍只是观察位，不是固定止盈。
