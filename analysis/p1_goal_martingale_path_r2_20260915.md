## 因果性规则（本轮的核心约束）

每笔交易 t 的特征只允许使用**严格早于 t 自身 `signal_close_time`** 的信息：

- `breadth_Nd`：在 `[t.signal_close_time − N天, t.signal_close_time)` 区间内
  产生过信号的**不同标的数**。衡量"全市场同时在出信号"的广度。
- `heat_K`：**退出时间严格早于** `t.signal_close_time` 的最近 K 笔交易的平均净 R。
  只用已平仓、因而当时可观测的交易；不含任何同时持仓中的单子。

两类特征都不接触 t 自己的结果，也不接触任何未平仓头寸。

## 解读

- **heat_30 是本轮唯一 CI 不含 0 的结果，而且在负侧。** 在策略刚经历一段最差表现之后
  开仓，前向净 R 是 −0.338，去掉 2026-04 后 −0.350。倍投假设的是"亏完之后赢面变大"，
  数据说的是相反的：**亏损聚集**。这与第 1 轮引用的 ETH 3m 最长 27 连亏是同一件事的
  两种度量。
- **heat_100 是一个典型陷阱**：原始 +0.651 看起来支持亏后加码，CI 宽到 [−0.43, +2.79]，
  去掉一个月后变 −0.229。只看均值不看 CI 和月度分解，会得出完全相反的结论。
- **breadth 门的失败方式值得记住**：上 1/3 和下 1/3 都为负，而全池为正——因为收益
  不在某个分位段里，而在某个**时间段**里。截面特征切不出时间段。
- **对倍投的直接含义**：倍投需要"亏后赢面不变或变大"。本轮测到的是"亏后更差"。
  在亏损聚集的序列上做倍投，是把最大回撤放大到爆仓，不是把它抹平。

## 零假设对照说明

本轮检验的是"条件均值是否 > 0"，不是排序模型，因此 AUC / top-decile / 单特征基线
按字面不适用。同等严格的零假设对照：月块 bootstrap 20000 次（保留月内序列相关）
+ 单侧 H0: 均值 ≤ 0 + 家族内 Holm 校正（族=10）+ **留一月稳健性检验**
（去掉 2026-04 重跑同一方法）。最后这一项是本轮最有信息量的对照——它把
"效应"和"一个月的行情"分开了。

**匹配随机对照仍未做**（与第 1 轮同一原因：源账本无对照组，本轮不重跑回测）。
因此本轮不声称任何门相对随机入场有超额，只声称它们相对自身对照组和留一月检验不成立。
