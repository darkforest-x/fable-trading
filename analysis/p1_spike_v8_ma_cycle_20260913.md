# V8：均线压缩、启动、扩散、再盘整的验证

## 结论先看

这套固定状态定义能解释 COMP 三笔交易的部分区别，但**没有通过“减少噪音且保留大趋势”的硬过滤验收**。最近一年，只保留原 V8 确认时处于同向“启动中”的交易，净胜率从28.86%升至29.74%，平均净R从-0.08383改善至-0.05433，仍未转正；原319笔已实现10R只剩71笔。匹配同币、同月、同方向和因果波动桶后，这点整体改善也没有显示为稳定的配对优势。

更完整的排列并不自动解决问题。只保留当时已同向扩散的交易，平均净R为-0.07718，原10R只剩64笔。等待未来扩散又是另一种决策：必须按之后的真实确认时点重新计算入场，不能拿后面的形态替之前的箭头背书。

**本轮保留研究结果和图表，不把该状态机接成线上 V8 过滤器，也不把它称为已验证的市场阶段识别器。** 它没有人工逐段金标，不能声称“真实阶段识别率80%”。固定代理定义的不足和失败例子都保留在下文。

这是一份**原入场结果分层诊断**。删除一部分交易后的净R合计，不是重新运行仓位状态机的账户收益；本轮没有生成一个可用资金曲线，也没有优化止损或仓位。

## 二、固定定义：允许先启动，后建立排列

六线为SMA/EMA 20、60、120。每一周期的中心是该组SMA与EMA均值，斜率看当前中心减3根前中心。排列分数比较跨周期的12对均线，不要求同一周期的EMA必须高于或低于SMA。

| 阶段 | 固定、当时可知的判定 |
|---|---|
| 压缩就绪 | 六线最高与最低之差除以价格，不高于自身严格此前256根的20%分位，连续3根才形成有效episode。最近一次合格压缩之后超过12根仍未启动则过期。 |
| 启动转换 | 之前已有有效压缩；三组3根斜率同向；开盘和收盘均在线束外、允许影线回踩；收盘突破严格此前12根高低区间。冻结这份价格边界。**不要求完整排列，也不要求总带宽当根扩大。** |
| 启动中 | 转换之后尚未扩散或失败。多头收盘回到/跌穿冻结上边界，空头收盘回到/涨穿冻结下边界即失败；不能在同一根重新计数成新启动。 |
| 排列扩散 | 同向跨周期排序至少9/12；快中、中慢两组中心间距均同向为正，而且分别比3根前更大。12/12另记里程碑。 |
| 重新收拢 | 进入扩散后，带宽低于该段因果运行最大值的70%、斜率不再全同向，连续3根成立。固定原型需新3根合格压缩才开启下一episode。 |

价格、MA、ATR无效，时间不连续或声明数据缺口都会重置状态及滚动历史。未知、等待新整理、过期、失败和方向不匹配均保留。缓存MA本身继承原合同，本轮没有重新播种，也不声称与在线Pine逐字节一致。

256、20%、3根、12根、9/12、70%都是本轮事先固定的假设，**不是搜索出的最优参数**。图中背景是每根收盘后的代理状态，不是事后手工给整个趋势涂色。关于实时未收盘值与把未来事件画回过去的区别，参见[TradingView官方重绘说明](https://www.tradingview.com/pine-script-docs/concepts/repainting/)；本轮另有截断前缀不变测试。

## 九、如何使用本轮结果

1. **不直接加硬门。** 本轮启动中、扩散、静态压缩或完整排列都没有证明兼顾净优势与原大趋势保留；不能用减少交易的数量冒充降噪成功。
