# SPIKE V9 与 V1：已有全量结果对读

日期：2026-09-15。范围为 Binance / OKX / Gate 现有冻结历史池，30m、1H、4H，UTC `[2024-09-10, 2026-09-10)`；不含 ETH 3m / 5m。此次仅引用已经发布的汇总，不重放行情、不新增配置或 holdout 评分。V9 尚未加入按币种胜率、平均净 R、PF 的黑名单。

**V9 累计净 R 与实现净 10R 的笔数更多；两种 V1 的平均净 R 和 PF(R) 更高。但原版 V1 的利润由 RAVE 极少数交易支撑，V9 后一年整体亏损，现有结果不足以认定哪一个具有稳定盈利优势。**

## 为什么列两种 V1

原版 V1 沿用自身的信号收盘保护位及原生保护退出，仅做多。统一退出 V1 使用同一组 6,185 条 V1 冻结入口，换用通用风控：下一开盘入场、5 bar 结构止损加 0.2 ATR 缓冲、至少 2 ATR 初始风险、收盘达到 2R 后启用 4 ATR 跟踪、原始反向信号下一开盘退出。之前币种排名报告使用的是统一退出 V1。

V9 沿用通用风控，入场来自 V8 多空规则，再加底层 USDC、量比大于 50、UTC 周日过滤。因此同日历和同成本并不意味着单变量对照：原生 V1 与 V9 的初始 R、出场、方向、信号集合均有差异；统一退出 V1 与 V9 仍有方向及入场规则差异。全部结果固定扣除名义往返 0.2% 成本，均未启用此次讨论过的 MFE / BE 改动。

## 完整两年

| 指标 | 原版 V1（只做多） | V1 统一退出（只做多） | V9（多空） |
| --- | ---: | ---: | ---: |
| 已平仓笔数 | 6,116 | 6,138 | 81,854 |
| 未结束笔数 | 69 | 47 | 428 |
| 累计净 R | +854.70 | +1,060.98 | +2,758.17 |
| 平均净 R / 笔 | +0.1397 | +0.1729 | +0.0337 |
| 净胜率 | 28.14% | 29.05% | 30.88% |
| PF(R) | 1.184 | 1.259 | 1.050 |
| PF(名义收益) | 1.026 | 1.089 | 1.049 |
| 实现净 R ≥ 10 的笔数 | 53 | 51 | 462 |

净胜率指已平仓净 R > 0；PF(R) 为正净 R 之和除以负净 R 绝对值之和。未结束样本不计已实现收益；净 10R 不是 MFE 触达 10R。V9 交易数远多于 V1，累计 R 不能单独衡量交易效率，也不能换算为账户收益率。

V1 的净 R 主要集中在 1H；V9 三周期全期净 R 都为正，但其后一年 30m 为 −2,757.97R，1H 为 +355.94R，4H 为 +312.84R。不能把事后选择正收益周期视为已验证的优化。

## 集中度与可比性

原版 V1 的 RAVE 仅 7 笔，就贡献 +1,193.73R；剔除这 7 笔，其余 6,109 笔合计 −339.03R。统一退出 V1 中 RAVE 同样贡献 +1,193.67R，其余资产 −132.69R。因此 V1 高平均 R 与高 PF 必须连同极端赢家集中度一起解读。此处是事后分解，不是可执行的选币规则。

V9 去掉最大单笔赢家后仍 +2,623.52R，但这只是单笔集中度诊断，不等价于 V1 的“剔除整个 RAVE 资产”，也不能消除 V9 后一年亏损的事实。

## 对照与风险与诚实声明

V9 已有匹配随机入场证据：全期 81,703 个共同平仓配对，策略均值 +0.03414R、随机 −0.02867R、超额 +0.06281R，月块单侧 p=0.01699；后一年 49,874 配对，策略 −0.04121R、随机 −0.06001R、超额 +0.01880R，95% 区间 [−0.02119,+0.05411]，p=0.19240。两项均未达到项目 p<0.01 门槛。没有把该随机组套到原版 V1：原版保护退出和初始 R 不同，本次未取得同契约随机入场对照，所以不宣称两版本的 alpha 孰优。

本次是既有策略汇总的描述性对读，没有训练分类器或排序模型；val AUC、top-decile 毛/净收益、单特征分类基线不适用。上面已有随机入场检验按原报告引用，未重算或补造 V1 对照。

事件累计 R 不是账户曲线，未统一资金、并发仓位、复利、资金费率或成交容量。固定 0.2% 成本无法证明极端交易的实际成交能力。V1 与 V9 均保留研究未确定状态；本次不修改策略、TradingView 或生产配置。
