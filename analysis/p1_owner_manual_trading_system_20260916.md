# 人工交易手册：均线密集、V9与YOLO怎样一起用

版本：2026-09-16 · Manual-v2。适用对象：你亲自看图、选择机会、计算仓位、下单和管理持仓。本文将上一版研究框架改写为操作手册；旧账本分析仍保留。

**核心流程：看到候选 → 人工确认均线密集与启动 → 写出入场和失效价格 → 算仓位 → 手动下单并确认保护 → 按同一张交易卡退出 → 记录实际净收益。** YOLO与指标提供信息，最终交易决定由你做。交易所的保护委托负责你来不及点击时的止损。

本金和盯盘时长尚未提供，以下采用可调整的练习默认值：每笔含费风险0.25%，主交易周期先用1H；只有能持续管理15m收盘时才另开15m练习组。周期、次数、人工筛选和风险比例都是本手册的提案，未经历史验证，不等于原V9已经验证过这套人工组合。可先用模拟单执行相同流程。

## 2. 桌面怎么摆：每个工具只回答一个问题

| 工具 | 你用它回答什么 | 对应动作 |
| --- | --- | --- |
| 均线密集图 | 现在有没有值得研究的紧凑结构，还是早已发散？ | 标出启动前的整理范围及上下边界 |
| YOLO检测结果 | 它圈中了哪里、什么方向、什么时候才检测到？ | 打开原图亲自核对；记同意、不同意、未检出、未运行 |

| V9风险显示／ATR14 | 原始失效位置在哪里，持仓保护怎样推进？ | 写下实际止损价；实际成交后重算自己的R |
| Stoch、BB反转 | 是否出现另一类完整反转组合？ | 只用于独立反转卡，不指挥趋势单临时退出 |

六均线沿用当前V9：**收盘价的SMA20、EMA20、SMA60、EMA60、SMA120、EMA120**。不要临时换成另一套参数来解释已经开的单。普通时间K线、交易所、合约和周期必须对得上。

建议先把观察列表控制在BTC、ETH和盘前已选的少量熟悉标的，第一轮最多5个；这是注意力管理提案，不表示它们已被证明更赚钱。盘中看到涨跌榜才临时追入的新标的，先加入下一次观察，不立即获得开单资格。

**周期在盘前写死。** 本稿以4H作背景、1H作入场和持仓管理周期。若你的实际习惯是15m，就把15m作为独立组，并按15m管理到平仓。5m可以看成交细节，不能用它的一根反箭头改变1H趋势单的退出。

每根交易周期收盘需要检查一次；交易所硬止损全天保留。如果每天只能看几次，应另选能管理的周期，不能声称执行了逐1H更新的跟踪规则。离屏安排也在开单前选择：默认“值守单”，若将错过下一次计划检查，离屏前结束仓位；如预先选择“受保护离屏单”，离屏期间冻结最后已确认的真实SL、停止新开，回来后用当时可见最新收盘更新。期间若已出现本卡的反向退出条件，按回来后的实际价格处理并记录延迟。两类分开统计；受保护离屏单不冒称全时逐根4ATR跟踪。

## 3. 主练单型：均线密集后的有效启动

这一版只把一个单型放进主练清单：**整理／密集 → 已确认的方向启动 → 趋势跟随。** 不把“跌很多了”“涨太多了”“刚亏想赚回来”列成第二种入场理由。

### 3.1 先找形态，画得出边界才继续

你需要能在入场前的图上指出：整理段在哪里、六线是否确实靠近、上下边界在哪里、哪根是启动确认。不要把启动后已经走远的一段行情一并框入“密集”。

人工复核四个问题：

1. 整理核心能否指认，还是必须缩放图表、加上后来走势才显得好看？
2. 价格是否已经收在六线束和整理范围的方向一侧，还是只有影线刺出去、实体仍纠缠？
3. 最新启动是否有V9同向的已收盘确认，还是只有一个未收盘候选？
4. 当前价格是否已经远离原计划，以致止损距离和潜在空间都变了？

这些问题让你检查图形和执行条件。人工画的范围与“形态清楚”仍含主观判断，必须截图留存；不能把你的主观筛选结果算成原V9未筛选的回测收益。若不能清楚描述，就记“看不懂，跳过”，不现场补理由。

### 3.2 YOLO怎么帮助你，而不是替你下决定

| 当下情况 | 你的动作 |
| --- | --- |
| YOLO有框，你也认同形态 | 加入候选，继续检查启动、价格、止损与仓位 |
| YOLO有框，你认为框错、方向错或形态已走完 | 拒绝，留截图和理由，不因为模型分数高而勉强做 |
| YOLO没有检出，但你看得清且V9确认合格 | 可以继续人工检查；记录“人工认同、YOLO未检出”，不自动升级风险 |
| YOLO未运行、过期、方向支持未知 | 记录“不可用／未知”，不能记成模型否定；你不能独立判断时跳过 |
| YOLO在原V9之后才确认 | 用此刻的价格重新检查；同一信号只对应一次风险事件，追加通知不补仓 |

模型置信度不等于赚钱概率。部分YOLO形态需要后续已收盘K线才可识别，只能从实际可见的检测时刻使用；历史框画在过去，不代表过去那个时刻已收到提醒。当前追加通知最多等待9根K线，不代表允许你在第9根无条件追单。另有Local Signal V2研究协议，其窗口、方向与当前通知模型不能混用。

已有研究中YOLO硬筛选漏过大赢家，所以本稿保留人工判断并分组记录，不把“必须YOLO通过”写成已验证规则。你也不能因为“图看起来特别像”把仓位翻倍。

### 3.3 入场采用一条明确流程

**主流程采用确认后开单，不在未收盘时抢预测箭头。** 等交易周期收盘，确认原V9信号仍存在；检查当前买一／卖一附近可成交价，填好下单卡后再手动发单。实际成交与信号收盘之间的延迟如实记录。

初始止损先固定，再算仓位。V9参考基准为：多头取“含信号根最近5根最低−0.2ATR”与“信号收盘−2ATR”的较低者；空头对称取较高者，按最小报价单位向外取整。人工图表另加ATR14，平滑选择RMA／Wilder，采用同一交易周期已收盘读数，整轮不换来源；这作为Manual-v2的ATR口径，不宣称与所有旧引擎预热逐点一致。你可以从对应信号的风险信息核对，但不能照抄另一笔仍在跟踪的旧参考仓位。

**人工不追价的暂定边界**：从确认收盘价向不利方向移动超过“确认价到初始SL距离”的0.25倍，就取消本次开单。以一整个交易周期为最长期限；先触及失效SL、出现反向结束事件或到期，均取消。空头反向计算。0.25R与一期有效期是新拟的执行约束，不是原V9规则或历史最优值。

若价格向有利方向回落，仍要重新确认结构没有失效、当前价在止损正确一侧，再按实际价格算量。若已经错过有效期，本版不靠“等回踩”把旧信号续期；回踩入场另列待研究单型。

若你用限价单，未成交就没有持仓；部分成交只按已成交量保护，取消其余量，先把这一笔管理清楚。本版不保留一边等待补成交、一边已经开始另一套退出的复杂状态。

### 3.4 有障碍就少做，理由必须在开单前写

盘前标注附近明显前高／前低、整理边界和更高周期冲突。若你因为空间不足或背景冲突拒绝，写明具体价位与理由并留图；不要只给“感觉一般”或星级分数。

高周期一致、前方空间、人工形态筛选都可能同时删掉赢家，因此本轮把它们作为事前决策标签，并保存被拒候选。我们尚未证明某个“至少2R到压力”的统一硬门有效，不用虚构精确胜率来支撑主观判断。

## 4. 下单前先算这一单最多允许亏多少

**练习预算：每单含预计成本的正常止损损失≤参考权益0.25%。** 所有持仓开放风险合计≤0.5%；BTC与ETH等相关同向仓合计≤0.25%。以日初和当前权益较低值作预算参考，转入资金不临时放大当日额度。总名义仓位暂不超过参考权益1倍。

为便于手算，本版开放风险暂按各未平仓的初始含费预算累计，直到该仓完全结束；上移止损或出现浮盈不释放新开仓额度，也不拿浮盈抵扣另一笔风险。这是保守的额度管理方式。

这些是谨慎起点，不能保证跳价后损失不超标。0.25%是风险金额占权益，不是保证金占权益，也不是价格止损距离。界面杠杆只影响保证金占用，不能替代仓位计算。

设权益E、单笔预算B=E×0.25%、实际计划入场P、止损S、价格止损比例d=绝对值(P−S)/P、预计往返手续费／滑点／不利资金费比例c：

**允许名义仓位N≤B／(d+c)**，再受总名义与相关仓预算限制。USDT线性合约的理论币数量为N／P；实际张数按当前合约面值和最小步长向下取整。币本位合约另算，本手册算例不直接套用。

### 人工算例：同样一笔ETH，先写损失再写仓位

假设权益10,000U，计划做多价格3,000，止损2,940，预计往返总成本0.2%：预算25U，d=2%，允许名义仓位约1,136.36U，理论数量约0.37879ETH。按实际交易单位向下取整；取整前理论价格止损损失22.73U，预计成本2.27U，合计25U。

若界面选择2倍杠杆，初始保证金粗算约568.18U；它不表示本单可以亏568U。费率、资金费、最低保证金和实际成交以账户为准，此处不是当前ETH行情或实盘订单建议。

数量在成交后要复核：滑点使正常止损预算超限时，人工减到预算以内；不能为保留原仓位把止损挪远。未成交部分先取消。若SL落在当前价错误一侧或无法建立有效保护，本次不继续持有裸风险。

## 5. 在欧易页面上按什么顺序做

1. 核对合约、方向、持仓模式、单位和本次数量；本稿倾向逐仓、界面不超过3倍的练习设置，实际以你确认的账户方案为准。
2. 填好计划价格、初始止损和最大损失；确认不是把“保证金金额”误当成“名义仓位”。
3. 手动发入场单。检查真实成交均价与数量、是否部分成交，以及是否还有未成交委托。
4. 确认已成交仓位有足额的交易所止损保护。若附带止损支持当前模式，可预设，但成交后仍核对是否真正生效。
5. 检查触发基准是最新价、标记价还是指数价，并在日志记下；图表和止损观察基准不同，会出现看图像没到却触发的情况。
6. 止损草案优先选择触发后市价平仓，以退出为主要目标；可能发生滑点。止损限价单可能触发却不成交，不能把“已挂委托”当成“亏损已封顶”。
7. 通过持仓平仓功能或当前模式支持的只减仓设置管理退出，确认退出不会开出反向新仓。保护数量随真实剩余仓位核对。
8. 保存下单卡与截图，按预先写好的值守／离屏安排管理。不能确认保护成功时，立即人工处理退出，不把重试保护当作无限持有裸仓的理由。

触发价只启动委托，实际成交价另算；具体支持功能以你账户界面为准。参考[OKX止盈止损说明](https://www.okx.com/en-gb/help/how-to-set-up-profit-and-stop-loss-of-contract-transactions)、[触发基准与滑点](https://www.okx.com/en-gb/help/how-do-i-modify-take-profit-tp-and-stop-loss-sl)、[只减仓订单说明](https://www.okx.com/en-gb/help/x-basic-order-types)。

## 6. 趋势单开进去之后，只按这张持仓卡管理

实际价格1R=实际入场价到冻结初始SL的距离；金额R再乘初始数量。原图的收盘参考价、参考R和你的实际R分别记录。达到2R与否，按你的实际入场算。

| 持仓阶段／事件 | 人工动作 |
| --- | --- |
| 浮亏、尚未触及初始SL | 不加仓摊平，不扩大SL；等原规则或账户风险事件 |
| 盘中触发有效SL | 由真实保护单执行，核对成交与剩余数量；不等收盘再认错 |
| 盈利达到1R | 记录进展，不因为整数出现就自动平仓或移保本 |
| 交易周期收盘首次达到2R | 开始逐根收盘计算4ATR保护；仅收紧，不直接改成“赚2R必平” |
| 跟踪启动后的每根收盘 | 按新收盘和固定RMA14的ATR读数更新保护，提交成功后核对；记录修改时刻 |
| 同一交易周期出现已收盘的反向V9完整确认（三角） | 人工核对后平旧仓；不自动反手，新仓重做全部检查 |
| 单独出现Stoch反箭头／YOLO未确认 | 作为观察记录，不临时替换趋势单退出规则 |
| 账户停机线或保护故障 | 账户规则优先，人工有序退出风险仓位，记录例外原因 |

**4ATR如何手动算**：多头新保护=原有效保护与“最新确认收盘−4×ATR14”两者较高值；空头取原保护与“收盘＋4×ATR14”的较低值。按报价单位向外取整。2R一旦在收盘触发，后续即使回落仍继续按该规则更新。新保护从你修改成功时才生效，不能回填到刚结束K线的盘中。

例如前述多单实际入场3,000、SL2,940，价格1R=60。某根收盘3,150，浮盈2.5R，ATR=35，则候选保护3,010；若旧保护2,940，更新为3,010。若你操作时现价已经穿过新保护，应按当前可成交价退出并记录延迟，不能记作已在3,010止盈。

原V9数据窗口可查看“冻结初始止损”“本根有效保护”“V6参考结束事件（1保护／2反向）”。**图上的参考仓位可能比你更早进入、或者已经结束，不能直接当你的真实仓位。** 人工ATR从同周期单独显示的ATR14、RMA平滑读取，避免依赖图上看不见的内部变量；[TradingView官方ATR说明](https://www.tradingview.com/support/solutions/43000501823-average-true-range-atr/)可核对设置。数据窗口的V6参考结束事件只用于理解原指标，不当作交易所成交。Manual-v2明确用可见的反向V9确认退出；它与原回测“即使被V9入场过滤的原V6反向也退出”不同，因此本手册不承诺复制原回测退出结果。

这张卡不加固定平半规则，让主练趋势单的退出身份清楚。若你确实需要分批缓解持仓压力，应下一版本预先写明比例和触发，不在某一笔浮盈时临时决定。

## 7. BB＋Stoch反转保留为另一张卡

当前主练是均线密集启动。你近期的ETH5m反转想法继续保留，但要独立标记为“人工反转练习”，其既有回测仍亏，不能把它称为已经盈利的备用方案。

开单前由你逐一切到V1的5m、15m、30m、1H图：任一周期有最新已收盘确认或正常活动参考仓位，就不开新的反转单；任何一个状态看不清，也不把它当成“没有”。这项检查可以人工完成，不必等待自动门禁开发。若你的图上没有V1，不能拿V9状态替代。

多头要求整根含影线位于BB200/2下轨之外且原Stoch5/3/3出现绿箭头；空头对称。必须同时满足，只有超买／超卖或单箭头不够。初始价格止损为实际入场的3%，仓位仍按0.25%含费风险倒算。

人工退出：实时触及对侧BB时平50%；确认实际成交后，尾仓止损才移至开仓价。出现整根反向出轨＋反向Stoch组合时处理尾仓。价格BE仍可能产生费用亏损；按实际退出数量计算全单净收益。

盘中BB会变化，手动点击会有延迟，不能沿用回测中的理想触轨成交价。漏掉触轨要记录漏执行，不能回看影线补记盈利；无法持续盯5m时，本次不开这类单。同一标的已有趋势仓时不另外做反向B，同一笔仓位也不能改名成B来推迟原有退出。

## 8. 人工停机规则：保护账户和判断能力

| 暂定约束 | 具体动作 |
| --- | --- |
| 当天最多3个新风险事件 | 没有合格机会可以0单，限额不是任务量 |
| 两次止损连续发生 | 至少离屏60分钟，恢复后必须有新完整信号；冷静期中的旧提醒仍按原有效期，不续期 |
| 任一平仓后 | 至少等一根完整15m；不能立即追同一根波动重开 |
| 日权益亏损0.75%／周亏损1.5% | 停止新开，并有序退出剩余风险仓位；按含浮盈亏且剔除外部资金流的权益变化判断 |
| 现金流调整后权益较峰值回撤4% | 停止真钱尝试，回到复盘与模拟；不靠提高杠杆恢复 |
| 出现一次扩大SL、亏损加码或保护裸奔 | 当天暂停新开，先处理已有风险，再查明原因 |

日／周以北京时间自然日／周一00:00为边界，另记日初／周初权益和期间净转入。现金流调整权益变化=当前权益−期初权益−期间净转入；账户百分比基准预先固定。期内大额转入或转出使基准难以比较时，暂停并重新记录新阶段，不凭感觉重置亏损额度。总权益峰值回撤也用同一现金流调整口径。

这批数值是执行提案，不是由旧账本证明的最优阈值。触及停机线后平仓仍可能滑点，不能许诺刚好停在该百分比；保持保护直到仓位确认平掉，再检查遗留委托。

## 9. 每天照着走的节奏

**盘前10—15分钟**：写交易周期和观察列表；看4H背景；查看账户权益、已有仓位与剩余风险预算；确认今天可管理持仓的时间。看不懂、没时间、订单状态不清楚，都可以空仓。

**有提醒时**：先打开图，再看消息。对照信号时间、周期和标的，确认不是重复的YOLO追加提醒；完成形态检查和下单卡。主观拒绝也保存记录。

**持仓时**：硬止损盘中保留；每根交易周期收盘做一次趋势卡检查。修改保护后看交易所确认，不只看图上线移动了。不得因为一直盯盈亏而把1H单改成5m单。

**收工10分钟**：对账实际成交、手续费和资金费；保存入场与离场截图；给交易标记“守规则盈利／守规则亏损／违规盈利／违规亏损”。违规盈利也要记录违规，不能把一次赚到钱变成新规则。净损益按实际成交价计算毛盈亏，再加有符号手续费、资金费及其他实际费用；滑点已体现在成交价中，不再扣第二遍。

**每周30分钟**：分别看趋势／反转、周期、人工与YOLO一致性；关注净收益、费用R、大赢家依赖和违规次数。先回答“做到了没有”，再问“这套筛选有没有价值”。本周交易规则不中途改，拟议变化放到下一版本。

## 11. 怎样检验“人工判断是否帮了忙”

前30条候选先检查你是否能稳定识别、填卡、算仓位、确认保护和遵守退出；不是30笔必须下单，更不是30笔就宣布盈利。模拟也要按当时实际可见时间与可成交价格记账。

同时保留所有合格V9候选、你接受或拒绝的事前理由。以后才有可能在同周期、同成本和相同风险口径下比较“原候选”与“人工选出的候选”。拒绝单没有成交，结果只能作独立的规则化影子跟踪，不能把事后最佳价格当假想收益。

YOLO同意／未检出分组、高周期一致性、不同方向和周期分别记，不根据已经揭晓的结局补标签。人工执行组合没有新的回测，不能继承原V9全量R合计，也不能继承BB模拟成交。

本稿建议冻结后每个准备使用的单型至少记录100条连续有效执行样本并覆盖3个月，取较晚满足者；样本不足时继续观察，不为了凑数提高频率。这不是证明盈利的充分条件，仍要看净结果、波动、成本与规则执行是否稳定。你的实际本金、最大可接受回撤与可投入时间补齐后，再确定个人执行档位。
