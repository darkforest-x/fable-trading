## 默认配置与行为

| 模块 | 默认 | 因果行为 |
|---|---:|---|
| V1+ 总开关 | 开 | 关闭时对照当前 V1 display 派生版的确认、风险和 2R/4ATR 跟踪；不是旧账本的冻结仅多头配置。 |
| 联合过热 | 开；RV>50 且 TR/前 ATR>10 | 仅两项同时超过才拒绝新参考，并消费该原始事件，不能在旧箱体上延迟入场。 |
| 风险宽度上限 | 关；30% | 仅拒绝新参考；不把原有 5 根结构 + 0.2ATR、且至少 2ATR 的止损挤窄。 |
| 分段保护 | 开；1R、2R、成本缓冲 0.20% | 1R 后将保护提至 -0.5R；2R 后尝试信号收盘的成本缓冲参考。它只是价格估计，不是手续费或成交保证。 |
| 回踩确认 | 关（直接确认） | 开启后冻结原始 side、箱体、均线边缘和 ATR；多头下影线区间、空头上影线区间必须与冻结边缘 ±0.25ATR 带实际相交，再由更后一根方向收盘重夺边缘且突破回踩根方向极值。最多 6 根；反向 raw、箱体破坏或超时取消。无等待/预警标签。 |
| 早期结构失败 | 关；8 根 | 前 8 个完成 K 内，收盘回冻结箱体并且 MD 不维持方向（多头：MD<=0 或 <=信号或未上升；空头镜像）时，以确认收盘结束。 |
| 停滞保护 | 关；12 根 | 距离上次创出持有期间更有利收盘达到 12 根时，收盘后把下一根保护候选收紧至收盘外 2ATR；无固定 14 天或其他时间强平。 |
| 同向冷却 | 0 根 | 只挡同向新参考。独立原始反向确认仍先结束旧参考，即使新的风险被过滤或在回踩等待。 |

所有保护先检查上一根已生效的止损。若触及，跳空按开盘和旧保护的更不利价格结束，
不会使用止损 K 的 MFE，也不会在当根新计算的线位退出。新保护均在收盘确认后计算、下一根才生效；
多头向下 tick、空头向上 tick，且单调收紧。成本缓冲或其他候选若落在已确认 close 的错误侧，则跳过；
阶段 latch 仍记录已经发生的门槛，避免随后回退重算。
