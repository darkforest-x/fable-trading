## 要解释的差

| | 我 2026-07-30 | P2-L2 2026-08-03 |
|---|---|---|
| 数据 | `data/judgment_v10_wide.csv` 18,379 行 / 232 币 | `data/p1/p1_short_l2_preholdout_aade2a334448d644.csv` 18,103 行 / 230 币 |
| 时间 | 2026-02-01 → 2026-05-03 | 同 |
| 特征语义 | `legacy_unaligned` | `side_aligned_v1` |
| 成本 | 目标内含 10bp taker(`net_barrier_taker`) | 10bp taker **+ 5bp 滑点压力** = 15bp |
| 模型 | 固定 250 轮,`num_leaves=31`,`min_data_in_leaf=80`,无早停 | 600 轮上限 + 早停 50,`num_leaves=15`,`min_child_samples=30`,`lambda_l2=1.0`,**实际停在第 1 轮 / 1 棵树 / 15 个叶** |
| 切分 | 15 折 CPCV(6 选 2,含 purge/embargo) | 5 折 walkforward |
| 指标 | 顶档**相对池均值的提升**中位数 | 顶档**绝对** pressure-net |

## 事先声明的立场

## 方法:单变量阶梯(铁律 4)

从我的配置出发,每步**只改一个变量**,一路走到 P2 的配置。每步同时报两个指标,
让"换指标"这件事本身可见,而不是混在别的变化里。

```
S0  我的配置 · 我的池          ← 复现 +23.49bp
S1  = S0,换成 P1 immutable 池   → 隔离【数据 + 特征语义】
S2  = S1,换成 5 折 walkforward  → 隔离【切分方案】
S3  = S2,加 5bp 滑点压力         → 隔离【成本口径】
S4  = S3,换成 P2 的 LGBM 参数    → 隔离【模型配置(含早停)】
```

S4 应当落在 P2 报告的量级附近。**若不落在,说明还有第五个未识别的变量,必须明说。**

## 判据(现在写死)

1. **"已解释"的定义**:四个增量的代数和覆盖 S0→S4 总差的 **≥80%**;
   残差 >20% 即记为**未解释**,并写明它有多大。
2. **主因认定**:哪一步让符号翻转,哪一步就是主因;若无单步翻转,报最大绝对增量。
3. **每一步的数都写进报告,无论对我有利与否。** 失败与反直觉结果一并记录。
4. 复现命令与随机种子写入报告;`seed=20260730`(我原配置)与 `seed=42`(P2)分别标注。

## 边界(不得违反)

- **只用 pre-holdout**(两个数据集都是 `< 2026-05-04`)。**不读 holdout,计数仍为 9。**
- 不改 `models/ACTIVE`、不 promote、不建 `active_bundle.json`、不改生产阈值或成本常数。
- 不 deploy、不碰 trading client、不下单、不动 `forward_log`。
- 训练的模型是**一次性研究产物**,不落盘为 artifact,不进 `models/`。
- 本实验**不改变 P2 的 rejected 结论**;它只解释差异来源。

## 已知的、本实验不覆盖的

- P2 的 `exact top-decile` 对边界并列用等权 fractional weight;我的是硬 `>= quantile`。
  在 P2 模型只有 15 个不同分值时这个差别很大,**但它随"模型配置"一起进 S4**,
  不单独隔离 —— 因此若 S4 是主因,归因只能说"模型配置 + 并列处理"合并所致。
- P1 与 v10 两个池的候选并非完全同一批(18,103 vs 18,379)。差集本身不在本实验范围。
