# 倍投可行路径搜索 · 第 3 轮：全仓库普查 + 破产概率

2026-09-15｜`exp-goal-martingale-path-20260915-v1`｜目标模式第 3 轮｜holdout 消耗 0 次

前两轮否掉了 ETH×V8 和全市场 V1。本轮把问题一次问完：
**这个仓库做过的全部工作里，存不存在一个可以承载倍投的正期望配置？**
以及 **在同一批数据上，倍投、固定仓位、顺势加码谁更好？**

## 先看结论

1. **扫描 35523 个账本文件、116 个实验，42 个可检验格子：10 个均值净 R 为正，
   0 个 CI 下界 > 0，0 个通过 Holm 校正。**
2. **有效样本量是 21 个月，不是 70 万笔。** 最大的格子有 858599 笔交易，CI 依然含 0——
   因为方差来自月与月之间的行情差异，加交易笔数不会让它变窄。
   这解释了为什么仓库跑了上百个实验仍然没有结论。
3. **倍投的破产率是 95%–100%。** 12 个倍投组合里 11 个破产率 100%，最好的一个 95.2%；
   `P(期末>1000U)` 除一个 0.14 外全部为 **0.0000**。
4. **顺势加码（anti-martingale）在同一数据上全面占优**：破产率 9.5%、中位期末 2704U，
   比固定仓位（14.4%、1042U）**破产率更低且期末更高**。这不是权衡，是支配。
5. **要让倍投的破产率降到 5% 以下，需要每笔净 R 再加 +0.8。**
   而最优格子 95%CI 最乐观端对应的加成只有 +0.352——**即使真实 edge 落在 CI 上界，
   倍投的破产率仍是 72%。**

## 普查方法与选择规则（先定后看）

仓库有 35523 个候选账本文件。**看完数字再挑账本必然造出假阳性**，因此规则在跑之前定死：

- 每个实验目录只取 **1 个**账本 = 文件名含 trade/ledger/fill 且**体积最大**的那个；
- 必须同时有逐笔净 R 列和入场时间列；
- 非删失、入场严格早于 2026-05-04（holdout 边界）、且 ≥100 笔；
- 两阶段：stage-1 用 5000 次月块 bootstrap 筛，stage-2 用 20000 次复核幸存者；
  **Holm 按 stage-1 的完整族大小校正，不是按幸存者数量。**

结果：116 个实验有账本，42 个通过资格检查（跳过：60 个无净 R 列、13 个笔数不足、1 个无时间列）。
**stage-1 幸存者 0 个，因此没有 stage-2。**

## 解读

- **"有效样本量 21 个月"是本轮最重要的结构性发现。** 仓库跑过上百个实验、上百万笔
  回测交易，但全部落在同一段 21 个月的行情上。加信号、加过滤、加周期都不增加
  独立信息量。这是为什么所有 p 值都停在 0.2–0.5 而不往下走。
- **倍投失败的机制很具体**：胜率 31.2%、中位净 R −1.018，是"小赢少、亏得整"的分布，
  配上第 2 轮实测的亏损聚集，连亏段来得又长又密。倍投在连亏段里指数加码，
  在 300 笔内几乎必然撞到资金上限。
- **顺势加码占优的原因是对称的**：它在亏损段自动缩到底注（亏完就复位），
  在盈利段才放大。同一份亏损聚集性质，对倍投是毒药，对顺势加码是保护。
- **但顺势加码的 2704U 不能当收益预测**——见下节。

## 零假设对照说明与关键警告

**⚠ 顺势加码那个 2704U 建立在一个未证实的 +0.168 上。** 该格子 p=0.190、CI 含 0，
按本仓库的验收口径它**没有通过**。如果真实期望是 0，顺势加码同样不赚钱。

因此本轮**唯一稳健的结论是相对比较**：在同一份数据、同一个（未证实的）期望下，
倍投在三种方案中最差，且差距是数量级的。这个相对结论不依赖期望是否为正——
倍投在正期望和负期望下都更差，因为它的失败机制是亏损聚集，与期望符号无关。

本轮是诊断性实验，检验的是"条件均值是否 > 0"与"资金方案的路径性质"，
不是排序模型，AUC / top-decile / 单特征基线按字面不适用。同等严格的零假设对照：
月块 bootstrap（保留月内序列相关与亏损聚集）+ 单侧 H0: 均值 ≤ 0 + 全族 Holm 校正。

**匹配随机对照仍未做**（连续第 3 轮欠着）。因此本轮不声称任何配置相对随机入场有超额。

## 风险与诚实声明

- **本轮 holdout 消耗 0 次。** 所有账本均按 entry < 2026-05-04 截断后才参与统计。
- **"每实验取最大账本"是一条武断规则。** 它避免了挑选偏差，但也意味着某个实验
  内部可能存在更好的分支而本轮没测到。这是刻意的取舍：测全部 35523 个文件会让
  族大小爆炸到任何结果都无法幸存。**本轮的结论是"按此规则没有幸存者"，
  不是"仓库里绝对不存在正期望分支"。**
- 42 个格子之间**高度不独立**（很多是同一批底层交易的不同退出规则），
  Holm 在相关检验上偏保守。但由于幸存者为 0，保守方向不影响结论。
- 破产模拟固定 300 笔路径长度与 1000U 起始资金；换成更长路径倍投只会更差，
  换成更短路径三者差距缩小。**300 笔不是实盘时长的预测。**
- 模拟按"起始本金的固定比例"下注，未模拟保证金、资金费率、滑点与撮合失败。
  实盘这些只会让倍投更早触顶，不会更晚。
- 顺势加码本轮**只做了同一数据上的相对比较，没有做稳健性检验**。
  在真实期望为 0 的零假设下它是否仍占优，是下一轮的内容，**在那之前它不是建议**。
- 本轮未做视觉验收，HTML 仅静态转换。
