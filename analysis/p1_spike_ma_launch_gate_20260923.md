# 将 YOLO 训练选图规则叠加到 SPIKE：全币历史比较

结论：当前 SPIKE 原始多空信号与完整选图形态在同一收盘时点取交集，信号几乎消失，后段没有改善。硬规则全期59笔的正收益集中在早期；后段37笔仍亏损。完整相似度组全期只有6笔，不能支持稳定胜率判断。保留此次负面结果，不修改指标默认值。

实验：`exp-spike-ma-launch-gate-20260923-v1`。Owner 要求解释训练选图规则并实际适配测试；两个 Luna Max 子代理分别追溯训练链、检查 SPIKE 接点，并复核统计与结果。主线程完成实现和638币运行。

## 训练图片是怎样选出来的

当前 v6 A/B 数据集为 `datasets/ma_launch_owner1500_morph_v6`。1841个正事件：train1506、val175、test160；另配1841个明确非密集背景。A每个事件一个原版，B每个事件两个视图；共享验证/测试，物理PNG共9706个。这些正例沿用v4原图原框，是规则形态加后验3R精选，不是1841个人工逐样本金标。

原始链条：`ma_profit_miner.py:process_source` → `scan_weak_source` → `pick_4_5` → 源内去重 → strict profiles / `_score_all` → 跨源去重 → 收益筛选 → 数据渲染。必须区分四件事：

| 部分 | 实际作用 | 可直接作为实时特征吗 |
|---|---|---|
| 收拢和启动规则 | 4/5根核心、此前12根、之后5根已收盘确认 | 可以，但最早在核心后第5根收盘时知道 |
| 参考相似度/质量 | 与少量认可参考形态比较 | 可以用过去数据计算；不能当逐样本人审 |
| 后续先达3R的收益筛选 | 精选训练正例 | 不可以，是未来结果标签 |
| 未来最高分NMS、重裁/渲染 | 去重和生成图像 | 未来评分去重不可原样在线使用；渲染不是入场规则 |

具体阈值保持原值，单位为ATR：

- 六线为 **close 的 SMA/EMA20、60、120**；核心包络≤1.5，核心末六线宽度严格门≤0.95；最大实体≤1.2，核心净位移限制在约−0.6至+1.0。
- 收拢分支要求末/初宽度≤0.9且至少两次缩窄；交叉分支要求比值≤1.15且至少三次线对交叉。另有同向斜率、K线贴线、实体不能过远等条件。
- 前12根检查实体90分位≤1.1、累计路径≤5.5、末3根方向位移≤1，避免行情在核心之前已经走远。
- 核心后第1/2/3/5根方向进展至少0/1/1.25/1.75；至少3/5步向前，回撤≤0.75，限制逆向实体。这里的5根在当前决策时点均已收盘。
- 第一层用14项特征与4×10序列，特征/序列权重0.45/0.55，最近参考距离≤0.5。4/5核心先按第一层距离最小选择，再检查所选核心第二层，不因所选失败而回退另一核心。
- 第二层对7×22序列比较 lockstep/DTW/DDTW，权重0.35/0.40/0.25；再合并6轴质量，冻结门槛约0.36119。完整阈值见 `yoyo/evaluation/ma_dense_launch_v1_reference.py` 与冻结 `reference_pack.json`。

**一个实际口径差异**：数值选图用close均线，v6训练图片渲染用HL2均线，不能混为同一件事。v6负例要求全可见窗在close和HL2下均明确非密集、避开所有受保护形态候选；不能把未来亏损直接改成空标签。图像预热1200根、18/19根短窗、1280×742再补边至1280×768也不是选图硬阈值。

训练谱系和验证集来源见 `analysis/p1_ma_morphology_negatives_20260922.md`；本实验没有修改这些图片、标签或训练任务。

## 适配方式与数据

- 测当前V12.8继承的V12.6**原始多空**，保留H1方向许可；不是突破联合多头路径。原信号收盘判断，下一根开盘成交。
- 核心固定结束于当前决策的5根之前。15m图对应核心后75分钟确认，信号不回画到核心。入场后不使用3R筛选赢家。
- 四臂各自完整串行重放：原版、仅密集、全部硬规则、完整形态参考。过滤早期交易后允许后续原信号重新入场。原始未过滤反向信号仍可退出。
- 硬规则臂为4/5核心任一通过且完全不使用参考距离；完整臂才执行原矿工的先选核心再第二层。原计划中核心选择措辞范围不清，运行后补充 `INTERPRETATION.md` 明示，原计划/config/source哈希均未改。
- 638个Binance USDT永续本地官方5m归档，聚合完整15m桶。区间 `[2024-09-10,2026-05-01)` UTC，切点2025-09-10；跨切点持仓单列，不混入前后段。
- 退出固定原结构止损、2R启动4ATR追踪与原反向退出，往返成本0.2%（20bp）。没有更换止损、成本、止盈，**本回测不使用训练标签的固定3R退出**。
- 同币×方向×月份/时间段×因果波动桶随机对照；共用事件共用随机抽样，同退出/成本；失败或删失不重抽。随机结构风险不同，主单位为价格收益bp，R为补充。

638/638完成、无流错误；51370个基线候选，密集15135（29.46%）、硬规则59（0.115%）、完整参考6（0.0117%），MA支持未知0。核心匹配要求和SPIKE信号时间严格相交，这是**一种具体的同时成立接法**，不代表测试过全部延迟/状态保持接法。

## 风险与诚实声明

- 本结论限于638币15m、原始双向SPIKE与冻结形态在同一时点相交。不能声称所有周期、全部集成方式或独立形态信号都被否定。
- 规则/参考样例在2026年选定，回放更早行情是追溯研究；时间分段不能消除设计时看过历史的可能。固定当前归档币池仍有上市/退市覆盖限制。
- 参考包4位小数有量化误差，既有参考例核对差异约5e−5；不是旧全精度矿工逐字节等价。在线适配主动去掉未来最高分NMS和3R标签。
- Python依当前V12.6规则重算基线；没有已有V12.6 raw多空父成交账本，也没有原生TradingView逐事件parity，不能称与历史父账本或实盘完全一致。
- 候选许可、成交、fill和删失保存；复用引擎没有输出每个未入场的占仓/风险无效细分状态，不能声称这些原因逐条已审计。相同入场退出一致和人工构造串行测试通过。
- 固定形态门不是排序模型，**val AUC、top-decile收益不适用**。这里用全部入场收益、同时间块匹配随机、周块p和单特征密集基线；无伪造AUC。
- 20bp为固定往返成本模型，不逐币重建资金费、订单簿冲击或账户资金约束。R加总不能当账户回报/最大回撤。
- `training_eligible=false`、`production_eligible=false`，没有新训练、promote、监控或账户修改。
