# SPIKE V12.6：联合时重检 H1 SMA60 的全量研究

日期：2026-09-22。唯一键：`spike-v126-htf-recheck-20260922-v1`。

## 结论

**这项建议未提高扣费盈利胜率，不采用为 V12.6 默认条件。** 638/638 流完成、零回放错误；18,956 个联合候选中仅22个被拒绝。全期胜率28.6786%→28.6696%，后段24.3752%→24.3456%；平均净R也均变差。被删22笔中8笔盈利、14笔亏损，合计净+6.3989R，且含2笔净>5R；没有新增成交。不能将其包装成100%胜率模型。

这是默认15m条件的Python研究回放，**没有原生TradingView完整事件对账，pivot平局语义仍未核实**，因此总体研究登记为inconclusive，并明确当前候选不支持采用。以上不是原生V12.6的实盘胜率。未改Pine/TradingView脚本、通知、ACTIVE、仓位或真实订单；训练/生产资格仍false。

## 授权与唯一变量

Owner先明确“优先提高扣费后的盈利胜率，同时保留大盈利机会”，随后同意按建议进行。本轮只增加：每框首次break+spike联合确认时，15m收盘价必须严格高于该15m开盘时已知的、连续60个已完成H1收盘的SMA60；相等/未知拒绝。V9原本已有相同H1方向门，因此这次只研究联合时重复检查的增量。

默认线性raw/soft、major三点与local C合并池、图表/H1各24条持线证据、先框后突破与先突破后V9两种配对共同生成候选。拒绝仍消费该次候选；两臂独立重算单币串行持仓。未改任何TP/SL、阈值预设或成本；未引入BTC门、RSI7退出或训练模型。5m EMA120不在本轮收益结论内。

V9收盘风险框仅服务信号配对；联合交易从下一根实际open独立入场。初始止损沿用5根极值+0.2ATR、至少2ATR；收盘2R启动4ATR追踪；原始未过滤反向信号次开退出；固定往返20bp（0.2%）。净R=净价格收益/入场时固定风险比例，**R求和不是账户复利收益**。

## 风险与诚实声明

1. 原生Pine pivot平局行为仍未验证，严格pivot约定会影响线集合；诊断中全图raw major有77,577个单边规则额外候选，local有341,481个，H1对应10,135/49,865。它们不是受影响交易数，不可换算一致率。`joined`的内部trace未完整回写；静态复核未找到它改变本轮候选的路径，但仍不称完整原生parity。
2. 数据是Binance归档、冻结tick元数据、不同上币时长与流动性；不是当前OKX盘口复现。研究中已观察历史的时间拆分不等于新鲜前向验证；不外推5m/其他周期。
3. 沿用固定20bp，未新建独立滑点、资金费、成交深度、杠杆强平与多币组合资金模型；不能换算成每单账户+200%或2万滚到500万。
4. 只研究多头联合入场的一个条件，无新模型训练，无100%未来胜率证据。没有以少交易、盘中MFE、参照池改变或保留历史大赢家来替代净收益。
