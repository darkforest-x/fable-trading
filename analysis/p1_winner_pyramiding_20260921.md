## 可执行规则

1. 原始确认信号在次开入场，固定初始价格风险 r0=P0−S0，后续不因均价变化重置 R。
2. 第一根比前收盘低的已完成 1h K 线开始回踩，冻结此前运行高点 H；累积回踩低点 L，后续收盘突破 H 才确认。每次确认都重置结构时钟，即使该组不加仓或资金不足。
3. 全仓止损尝试提高到 L 减一跳；必须真正提高。收盘才知道的新止损只作用于下一根，不能倒填同根已发生的低点。
4. 确认收盘至少达到 P0+2r0，下一根开盘高于上次实际成交，才允许计算新增仓位。开盘保护止损优先于反向退出，反向退出优先于加仓。机会只消费一次。
5. Q 为已有总数量，C 为各腿入场名义金额之和，S 为共同止损，P 为拟加仓价：

   ```text
   Hnet = Q*S - C - 0.002*C
   F = max(此前已承诺止损净利润, 0.5*Hnet, 0)
   q_risk = max(0, (Hnet-F)/(P-S+0.002*P))
   equity = 100 + Q*P - C - 0.001*C
   q_funding = max(0, (1*equity-Q*P)/(P*(1+1*0.001)))
   q_add = min(q_risk, q_funding)
   ```

   数量无效或没有余量则跳过。利润承诺在新增成交后重算，不能提前承诺尚未扣掉新增风险的利润。此处“保留利润”仅指**按共同止损价精确成交的模型场景**，不是保证现实成交。

6. 原始反向信号次开退出、有效止损触发或缺数据截尾结束路径。不限次数不等于不断追涨；每一笔仍需新的完整结构。
