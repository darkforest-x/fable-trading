# SPIKE 10R V3 / V3.1：全原始信号的10R命中率研究

日期：2026-09-21。状态：**两项新方案均拒绝准入；目前没有证据证明固定双条件或逐月选择能稳定提高10R命中率。** 全原信号已补齐，Python研究与串行验证已完成。后续离线分类模型只是待授权提案，未启动训练。

## 目标纠正与结论

Owner明确“需要从原始所有的信号中，提高出10r的胜率，想尽一切办法”。本轮主指标是**筛选后最终扣费净R>10的比例**，普通赚钱胜率不是优化目标。全部亏单、未达10R、原持仓期间没开的候选都在母体内。10R是未来结果标签，不能用它决定此前是否入场；没有改变原R分母或缩小止损造高R。

- 全量3,531流、49,207原V9做多候选，0无效开仓，137删失，49,070已结束，其中448个>10R，基础命中率0.91298%。涉及815资产、3,169有多头候选流，另362流没有多头候选，仍逐流认证完成。
- 旧实际开仓表仅41,814行、41,700已结束、367个>10R；7,393个原候选不在该表中。这解释了母体扩展后的赢家数量变化，不是策略凭空多赚了81笔。
- V3：20因果特征、120单条件、6,840双条件，共6,960规则；只在较早已结束样本选择，后段固定复核。早段最佳组合22/774=2.842%，后段独立候选14/1558=0.899%，实际串行14/1551=0.903%，未复现。
- V3.1：在看到V3失败后另立计划，每月仅用过去6完整月、已知退出的交易选择同一规则族；后段独立14/1680=0.833%，串行13/1657=0.785%，未提高10R命中率。
- 新规则中较有信息的是风险比例。E在后段串行93/6161=1.5095%，相对原版0.821%有点估计提升，但95%率差区间含0、均净-3.04bp、匹配随机未过门；且它没有超过上一轮风险最低10%方案的1.721%命中率。不能声称找到高胜率策略。

## 数据、标签和时序

范围2024-09-10至2026-09-10 UTC；Binance/OKX/Gate，30m/1h/4h。固定切点2025-09-10，早段要求入场和退出都在切点前，跨界单列。后段原候选已结束30,115、250个10R；原串行25,567、210个10R。AUC的正类是严格`net_r>10`，不是`>=10`，更不是毛MFE>10。

每个原始信号用原next-open、5bar极值、0.2ATR缓冲/2ATR下限、2R收盘启动4ATR追踪、原raw反向退出、20bp往返成本独立重放。实际开仓价格只用于结果，不进入特征。所有共享原交易（含删失）逐笔对账，原串行全流再验证。独立路径可能重叠，合计R不可当账户收益，更不可直接换算100U滚仓余额。

V3阈值每月/周期只取此前3完整月原候选特征，至少100条；不足时不入场。20轴覆盖价格风险比例、ATR、风险/ATR、量能、TR扩张、K线形状、均线宽度/距离/排列/斜率、过去突破/动量、相对波动、效率和区间；每列窗口与缺口处理在源码docstring。信号特征不包含未来退出、MFE或实际次开风险。

较早候选已结束18,539、185个10R。规则选择用10R命中率Wilson下界排序，仅作小样本惩罚分数，不把二项独立假设当最终置信区间。至少250条、15个10R、10%赢家召回、6活跃月、20资产、5正例资产月；分别比较最低1/5/10/20%覆盖档，实际覆盖可高于下限。保留全6,960早段失败记录。选择文件保存后，评估前还按早段数据重算一致性，防止事后改选。

所有历史此前已暴露；这属于**按时间隔离的探索复核，不是未看过数据的盲验证**。V3.1进一步在V3失败后提出，校正p值不能消除整个研究过程的后验选择风险。

## WIF与失败解读

原示例`okx_60m_d567226c051c9c20:20551:1`仍为净14.3299R。信号参考风险2.8531%、风险/ATR2.9772、均线排列分数0.5、离rope上沿1.9183ATR。**旧风险十分位、所有5个新预选规则和逐月方案均拒绝这笔WIF**；不能为保留这张已知赢家截图反调参数。

低风险比例可能让10R所需的价格涨幅较小，但也会漏掉风险较宽的大行情。早段条件组合的优势未在后段重现，可能涉及稀有结果噪声与行情差异；此表不能确定唯一因果解释。V3.1仍不稳，说明“每月重新挑过去最佳”本身也不是解决办法。普通胜率变好、少做交易或全期收益正，都不能替代10R命中率的稳定提升。

## 风险与诚实声明

1. 基础10R事件不足1%，同资产跨venue/周期及重叠路径相关，49,070不是49,070个独立试验。月块置信区间仍有区块数较少与跨月持仓相关的限制。
2. 多次研究已看过历史。前后时间切分、Holm和随机对照减轻部分误判，不能把已暴露历史恢复成盲样本；只把本轮作为研究证据。
3. 母体是冻结V9池，不是所有真实市场可交易资产的无偏全集；原数据源、下架/缺失和幸存者范围限制仍在。未新拉行情或静默换来源。
4. 固定20bp成本没有额外建模资金费、深度、实际滑点、杠杆或强平；结果不保证不爆仓，也不代表100U可以滚到某个余额。
5. 137个未结束结果未被伪装成负例或成功；CSV单独保留。前段阈值预热造成一部分时间不交易，后段比较也保留原完整母体。

方法依据：[TradingView关于策略前视与选择偏差的说明](https://www.tradingview.com/pine-script-docs/concepts/strategies/)、[Bailey等关于回测过拟合](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)。这些资料不证明本策略有效。
