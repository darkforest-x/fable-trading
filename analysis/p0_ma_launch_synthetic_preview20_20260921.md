# 均线密集启动的程序合成样式预览（20 例）

## 目的与范围

Owner 要求“程序合成类似的 K 线与均线，用来确认样式”。本轮交付的是 20 张只用于视觉和形态沟通的程序合成样本：先生成连续 OHLC，再由同一条 `close` 计算 SMA/EMA 20、60、120；没有外部或真实价格输入。

这不是 Gold 数据集、标签审核、训练、模型评估或交易研究。全部案例为 LONG 正向原型，`training_eligible=false`、`production_eligible=false`、`owner_confirmed=false`。

## 版本与生成口径

- `preview_v1/` 保留，不覆盖。
- 主交付为 `preview_v2/`。v2 修复 T0 的 close 连续性：后段对齐启动前的实际合成 close，而不是回到独立基准；随后用同一最终对数涨幅的前置部分，使早期视图在 T+3 已有可见启动。
- 完整图保留较长启动前背景；早期图只到 `onset_i=900` 的 T+3，manifest 中 20 例的 `early_view.end_i_inclusive` 都是 903。

生成代码先提交于 `7a6e6c7b108e9981e46001f21680a02083be747c`，再生成 v2。以下命令在仓库根目录与现有项目 venv 中运行；请使用新输出目录，保留已有 `preview_v2/`：

```bash
.venv/bin/python -m yoyo.datasets.ma_launch_synthetic_preview20 --plan-name plan_v2.json --output-name preview_repro_01
```

## 非方向性零假设对照与不适用指标

本轮没有收益、交易、真实标签、训练样本或模型输出；因此 val AUC、置换检验 p、top-decile 毛/净收益、胜率、单特征基线、匹配随机入场对照均不适用，不能编造数值。

本轮使用数值一致性和输入扰动对照：按独立递推与窗口求和重新计算六均线，检查它们是否与 CSV 一致；再物理移除 T+3 后所有价格，检查早期图是否仍逐字节相同。两项检查均通过，反驳了“均线与 close 不一致”及“早期像素依赖后续价格”这两种具体故障假设。seed 和哈希负责追溯，不能单独证明语义正确。这不是统计显著性检验，也不支持形态有效性。

## 风险与诚实声明

这些路径由本轮视觉目标构造，既有选择偏向也全为多头，不含真实市场噪声、币种差异、反例或人工金标。12.3690%–24.8640% 是预设后的图形幅度，不能解释为可获利幅度；MA 收拢也不能证明检测器可识别、标签一致或信号具有泛化能力。人工 `ts` 仅为内部毫秒索引，不能冒充真实行情时间。

上述 QA 只证明合成输入、派生均线、前缀因果像素和图像文件的内部一致性，不能把“通过”外推为样式已获 Owner 接受，更不能外推为真实行情或模型证据。
