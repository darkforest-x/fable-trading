# External Rank Pressure

## 技术摘要：四币均值共振没有改善入场质量

**V21 不采用，盈利目标仍未达成。** 在固定的2023—2024年 BTCUSDT.P 小时级开发样本中，加入 ETH、SOL、BNB、XRP 的历史位置均值同向门后，251个原始机会留下96笔；每笔平均净收益由 **−16.7690bp 降至 −21.3286bp**，胜率由21.91%降至13.54%。成本仍为每笔0.2%，没有修改退出、止损或手续费假设。1bp=0.01%，这些数不是账户收益率。

这不是“过滤得还不够严格”就能概括的问题：规则挡掉原55笔赢家中的42笔，却仍留下196笔原亏单中的83笔。接受组的质量比被拒绝组更差。它描述外部币已经处于什么价格位置，不一定适合寻找 BTC 刚穿越均线、切换方向的那一刻；后一句是机制解释，不能当逐笔因果证明。

全机会平均亏损确实缩小，但大部分来自不再交易。匹配对照净优势的增量只有+1.1819bp，95%区间跨零；唯一盈利的半年度依赖少数大赢家。未更新 TradingView，未训练或切换实盘配置。

## 固定比较：交易、机会、对照是三个不同分母

本轮只改一个变量：**是否允许原 K1 入场**。原始251个大实体或吞没穿均线的 BTC 小时机会、462个自身时刻的随机对照、154组三对照及97个未匹配机会全部保留。评估按2023上/下半年、2024上/下半年切分，72小时标签窗口不跨切点；这些都是已反复研究过的开发数据，不是新样本外验证。

- 交易均值：只除以真正完成的交易数，基准251、候选96。
- 全机会均值：不交易记0，本轮251个机会全已知；不会把155次放弃假装成155笔零收益成交。
- D：同一个机会“候选净收益−基准净收益”，251对；衡量整套参加/放弃策略的变化。
- I：同154匹配组的病例D减去对照D；另外97个I仍未知，不删除、不填0。
- 单仓：每个方案重新计算占仓后允许的交易，候选95笔；不能沿用旧单仓掩码。

原退出保持 V18：完整原生15分钟 SMA40/HL2 从同向变反向最终退出；盈利的真实5分钟反色事件按原规则兑现50%；原亏损启动失败需两根5分钟确认；K1极值硬止损、72小时上限及20bp往返成本不变。本轮复用已保存且逐字节锁定的旧退出路径，**没有重新模拟原始分钟内成交**。

## 源码与时钟：这是均值方向门，不是多数投票或资金流

依据 ChartPrime [Multi Asset Histogram 源码](https://www.tradingview.com/script/KkoxM97D-Multi-Asset-Histogram-ChartPrime/)，每币取当前小时HL2，与此前50根HL2逐一比较：大于或相等加1，小于减1。四币原始分数等权均值再除50；自身方向乘均值大于0才允许。长度50为源码默认，**没有“最优”证据**。

原公式的两个特征完整保留：相等价格偏多；均值可被少数强分数拉动。96个接受事件中，27个并无至少3/4币同向，仅28个四币全同向。例如2023年3月11日07:00 UTC空头K1，四币分数依次10、8、8、−28，归一均值−0.01，故允许做空，即使三个币为正分。这不是实现错误，本轮也没有事后换成多数门。

研究适配明确偏离原图表：只用四个预定外部币、不含BTC；要求51根连续完整小时、不用原`nz`补零；对K1开盘T仅取外部小时[T−1h,T)，可用时刻T，而BTC入场为T+1h。四币缺任一个就未知，没有前填或模糊最近匹配。它避开跨所瞬时同步的隐含假设，但并未证明实时馈送延迟一定小于一小时。原图同周期请求可能随实时行情变化，需区分图上显示与已确认可用信息。[TradingView 数据请求说明](https://www.tradingview.com/pine-script-docs/concepts/other-timeframes-and-data/)

BTC执行仍是原OKX数据的已保存路径；Binance四币只作额外输入，未静默换执行价。此前BTC15m ETH多因子、ETH15m BTC均线组、山寨日线广度已做过，跨资产家族不新；本轮只是这个明确公式与原251小时K1的独立对比。

## 风险与诚实声明

1. 总体仍净亏，三个半年度净亏，一个正段集中于少数赢家；不满足稳定正收益。
2. 原开发期已经反复读取，不是独立验收；匹配61.35%不足90%，不能删掉未匹配机会制造覆盖率。
3. 四币高度共享市场风险；它们不是四份独立验证。固定存活主流币面板不能外推为全币种有效。
4. 本次没有调整成本、止损、时间切分、入场源或止盈逻辑；没有读2025+价格、没有消耗新holdout。
5. 静态位置同向可能不适合抓启动，是与本结果一致的解释，不是已证明的通用定律。多空对照均未证明盈利，不能直接反转该规则。
6. HTML按官方便携报告流程交付，15块、2个原生图表；验证和打包通过，最终为`structural_only`。本机没有可用的无头Chromium，因此未验证浏览器、手机视口或来源弹窗交互，没有为此安装浏览器或绕过本地预览策略。没有保存TradingView或接入实盘。
