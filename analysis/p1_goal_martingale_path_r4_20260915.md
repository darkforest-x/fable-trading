第 3 轮在"最优格子"（均值净 R +0.168）上得出倍投最差、顺势加码占优。
但 +0.168 本身 p=0.190、CI 含 0。**如果排序只在这个未证实的 edge 下成立，它就没有价值。**

## 先看结论

1. **"倍投是三者中最差"在全部 6 个格子成立**（3 个期望档 × 2 种序列生成方式）。
   **这个结论与 edge 无关，可以定论。**
2. **"顺势加码占优"依赖 edge，零期望下它输给固定仓位**（37.9% vs 33.3% 破产率，
   iid 下 58.2% vs 10.9%）。**第 3 轮那个 2704U 的警告被证实了，它不是建议。**
3. **在真实的负期望（−0.620，第 1 轮实测的 ETH 3m）下，三个方案全部崩溃**
   （破产率 85.8%–100%）。**没有任何资金方案能救负期望信号。**
4. **亏损聚集的代价是可量化的**：零期望下固定仓位的破产率，月块序列 33.3% 对
   iid 序列 10.9%——**聚集让破产率翻了三倍。**

## 方法：只改一个变量

**变量一：期望档。** 分布形状用整体平移固定住，只移动均值：

| 档 | 平移量 | 平移后均值净 R | 依据 |
|---|---:|---:|---|
| null | −0.168 | **0.000** | 无 edge 的零假设 |
| observed | 0 | +0.168 | 第 3 轮的假设（普查最优格子） |
| realistic | −0.788 | **−0.620** | 第 1 轮实测 ETH 3m，1453 笔 |

**变量二（独立分解）：序列来源。**

- `month-block`：整月重抽 → **保留亏损聚集**（第 2 轮实测 heat_30 下 1/3 前向净 R −0.338）
- `iid`：逐笔重抽 → **打散亏损聚集**

两者之差 = 各方案的结果里有多少是**聚集**造成的，而不是阶梯本身造成的。

固定：底注 1%、最大 4 层、1000U、300 笔、20000 条路径。

## 解读

- **倍投的劣势是结构性的，不是运气也不是参数。** 它在正期望、零期望、负期望三档下
  都是最差，在保留聚集和打散聚集两种序列下都是最差。原因是阶梯与亏损方向同向：
  连亏时下注指数增长，撞资金上限的时间只取决于连亏长度，与期望符号无关。
- **顺势加码只在有 edge 时占优**：observed 档保留聚集时它最好（0.095），
  但 null 档它输给固定仓位（0.379 vs 0.333），iid null 档输得更多（0.582 vs 0.109）。
  它本质上是"把 edge 放大"，没有 edge 就只是把方差放大。
- **顺势加码在 iid 零期望下反而比月块更差**（0.582 vs 0.379），这个反直觉值得记住：
  打散之后连胜段变短，阶梯刚升上去就被打回，在零期望下这是纯粹的方差放大；
  月块保留了真实的趋势段，阶梯反而有东西可骑。**同一个方案，序列性质决定它是
  放大器还是绞肉机。**
- **负期望档是最重要的一张表**：三个方案破产率 85.8%–100%。
  **这封死了"用资金管理补救 ETH 3m"这条路**——第 1 轮测到的 −0.620 是实测值，
  不是假设。

## 零假设对照说明

本轮**本身就是零假设对照实验**：null 档（期望严格为 0）是对 observed 档的直接对照，
realistic 档是对两者的下界对照。这正是"非方向性实验需给出同等严格的零假设对照"
那条要求的字面执行——把真实数据的期望抹平后重跑同一方法，看结论还剩什么。

收益类指标（top-decile、匹配随机入场超额）对资金方案模拟不适用：这里没有预测排序，
比较的是同一批交易在不同下注规则下的路径性质。AUC / 单特征基线同样不适用。

## 风险与诚实声明

- **本轮 holdout 消耗 0 次。** 源账本按 entry < 2026-05-04 截断。
- **平移法假设分布形状与期望无关。** 真实世界里期望变化通常伴随形状变化
  （胜率、尾部同时变），所以三个档是**受控对照**，不是三种真实市场的预测。
- 只测了底注 1%、最大 4 层一组阶梯参数。第 3 轮已扫过 1%/2%/5% × 3/4/5 层，
  倍投在全部 12 组里破产率 ≥95%，因此本轮不重复扫参；**但本轮的排序结论
  严格来说只在 1%/4 层这一点上验证过跨期望档的稳定性。**
- 模拟不含保证金、资金费率、滑点与撮合失败。这些只会让倍投更早触顶。
- `realistic` 档用 ETH 3m 的 −0.620，但序列形状来自 v1-plus-backtest 的分布。
  这是刻意的混合（只改期望这一个变量），**不是 ETH 3m 的真实路径模拟。**
- 300 笔路径长度固定；更长的路径对倍投更不利，更短则三者差距收窄。
- 本轮未做视觉验收，HTML 仅静态转换。

**结论：在这个仓库现有的全部信号上，不存在能让倍投盈利的路径。**
不是参数没调对——倍投的失败机制（连亏时指数加码）与 edge 符号无关，
而现有信号的 edge 在 21 个月的有效样本下无法与 0 区分。
