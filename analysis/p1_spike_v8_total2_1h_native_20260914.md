## 交易原则

| 项目 | 本次固定规则 |
|---|---|
| 信号 | 冻结 V8，允许多空；保留 V6 结构/量价确认、BB200 压缩准入和距离六线不超过 3ATR 的门槛 |
| BB 压缩 | 信号前 12 根中存在连续 3 根带宽低于此前 500 根的第 10 百分位；完整预热至少 712 根连续 K 线 |
| 入场 | 确认收盘后提交，下一根开盘模拟成交 |
| 初始 SL | 信号收盘冻结：最近 5 根极值外侧 0.2ATR，距离至少 2ATR；按指数最小报价刻度向外取整 |
| 1R | 实际模拟入场价到冻结 SL 的距离，不是账户百分比 |
| 趋势保护 | 收盘浮盈达到 2R 后，以收盘价外侧 4ATR 保护，只收紧；新保护从下一根生效 |
| 反向信号 | 原始 V6 反向确认可结束旧仓，即使新方向没通过 V8 入场门；合格 V8 反向仅执行一次反转 |
| 止盈 | 无固定止盈、无分批减仓、无 1R 保本 |
| 成本 | 原生策略佣金为 0；另外扣固定往返 0.20% 作敏感性分析：成本 R = 0.002 × 入场价 ÷ 初始风险距离 |

这是一份独立原生模拟器。信号块与原 V8 逐行相同，仅声明由 indicator 改为 strategy；与 Python 历史账本的撮合路径尚未完成逐笔 parity，不能把两个执行器的差别称作策略提升。

## 数据、对照与适用边界

- 原生策略仅计算当前账户实际加载的小时历史；并未宣称跑完两年或三年。完整预热之前的根数不能算作有效检验区间。
- 当前 Data Window 有 Vol 字段，但其历史聚合方式、更新频率与单个永续合约的每小时成交量是否等价，尚无足够证据。不能仅因有数值就宣布量价门已经适配市值指数。
- 使用一个虚拟指数单位、初始资金 1、零保证金率，只为避免万亿级指数数值触发原生资金不足而隐藏交易。原生美元盈亏、账户收益率和账户回撤没有交易经济意义，不予报告。
- 固定 0.20% 成本仅为指数路径敏感性；无实际交易品种、费率、资金费、滑点及组合映射，不能兑现成账户收益。
- 原生 OHLC 撮合依赖 TradingView 的 bar 内路径假设，跳空、同根止损与反向信号排序可能影响结果。[原生策略机制](https://www.tradingview.com/pine-script-docs/concepts/strategies/)。
- 未提供同币 × 同时间块 × 同波动桶的匹配随机入场对照，未做置换检验，不能主张独立于市场 beta 的入场优势。该条是未满足的策略验收条件，不以原生报告替代。
- 本轮没有训练预测器、概率评分或排序模型，val AUC、top-decile 毛/净收益不适用。胜率仅能是这段历史的描述值，不能据少量样本推断总体胜率；无亏损样本时 PF 不可估计。

## 风险与诚实声明
