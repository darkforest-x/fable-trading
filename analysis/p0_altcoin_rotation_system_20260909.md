OKX实测是**两个匿名公开接口连通性测试**，不是完整CLI、情绪工具或盈利能力验收。没有安装或调用可能读取本地凭据的交易CLI。官方情绪能力另有认证要求，当前未连接。[OKX官方源码](https://github.com/okx/agent-trade-kit/tree/c4e54501e6f30e300b548cedcfa3843c58729be7)、[市场筛选实现](https://github.com/okx/agent-trade-kit/blob/c4e54501e6f30e300b548cedcfa3843c58729be7/packages/core/src/tools/market-filter.ts)、[CoinAnk官方说明](https://github.com/coinank/coinank-openapi-skill/blob/f811cdb36d51309573234f86b3f19fe3c228905d/README.md)。

OI需要单独澄清：未平仓量下降与价格上涨，可以包含空头回补；下降与价格下跌，可以包含多头退出。它们都是需要其他数据验证的解释，**单凭OI不能识别谁主动开仓或平仓**。以美元计的OI还可能仅因价格上涨而增大。本系统保留基础资产数量、估算报价名义额、独立事件时间；一次快照不声称OI增减，费率周期缺失不默认8小时。[CME关于OI的定义](https://www.cmegroup.com/education/courses/introduction-to-futures/open-interest)。

## 整个系统怎样使用

| 层级 | 实际功能 | 如何帮助筛选 |
|---|---|---|
| 市场环境 | BTC趋势、ETH/BTC、覆盖样本均线上方占比 | 区分环境支持、分化或防御；不把几个暴涨币当成全面山寨季 |
| 日线候选 | 7/30日相对BTC收益、均线、历史成交额中位数、板块统计 | 先找持续变强且可研究的标的 |
| 4h结构 | 前20根平台、放量突破、锚点后的首次缩量回踩、延伸与失效 | 在结构出现时记下真实可知时点，不事后移动起点 |
| 15m观察 | 独立短周期结构与数据完整性 | 缺数据或失效会退回复核，不冒充条件齐备 |
| 事件风险 | 公告/生效/审核三种时间；迁移、攻击、解锁等记录 | 新事件使旧审核失效，未知覆盖不等于安全 |
| 风险示例 | 结构失效距离、已有现货成本常数、每1万资金示例 | 量化距离与名义仓位关系，不生成订单或组合配置 |
| 留痕 | 派生快照、输入摘要、配置/源码/事件版本、状态转移与CSV | 同一快照重复观察不重复记事件，失败保留上次结果 |

箱体规则的实际边界：20根高低价只是候选平台，并未验证多次触碰、波动收缩或吸筹。“待突破”表示没有有效突破锚点，不能解读成已经证明在蓄势。2倍量、12根锚点期限等均是未经收益优化的工程假设。未来若要验证其预测能力，需要另立时间切分与匹配对照实验。
