## 冻结扫描合同

| 项目 | 本轮固定口径 |
|---|---|
| 行情源 | 本地冻结 Binance 官方 `data.binance.vision` USD-M 15m 月归档；无网络行情读取 |
| 日期资格 | 每个合约日必须恰好有 96 根唯一、连续、已确认 15m K 线 |
| 日涨跌幅 | 当日最后一根 close / 第一根 open - 1 |
| 日榜 | 严格正收益取 G1–G5，严格负收益取 L1–L5；同收益按合约名；零收益和反方向不补位 |
| 月份 | 2025-10 起向前，完整月为原子单位；首次达到 5,000 后停止 |
| 模型 | Grade-A 8,000 正 + 24,000 负，full40，native 1280；权重 SHA `862705b9...db838` |
| 输入 | W18；可见六均线最小 envelope/ATR ≤ 1.5 的因果预筛 |
| 推理 | RTX 3060；conf 0.25、NMS 0.70；核心 4/5 根、确认 2–9 根 |
| 归属 | 核心末端必须落在被排名 UTC 日；确认窗最多读取次日 9 根，不进入 validation/holdout |
| 语义门 | 冻结 causal morphology gate；实际方向与方向翻转均计算 |
| 去重 | 同合约同方向核心末端距离不足 5 根合并；最后再跨日、跨月去重 |
| 新颖性 | 精确坐标 + 解码输入像素 SHA；另排除同方向训练正例 5-bar 邻域 |
| 用途 | P1 候选发现与人工复核；不是验证集、回测、实时选币或自动 Gold 扩容 |

每日榜只有在当天收盘后才完整可知。因此本轮的合法含义是“从已经完成的大涨/大跌路径中挖
训练候选”，不能解释成模型在当日开盘前知道榜单，也不能把方向一致率当成胜率。扫描最晚月
2025-10 结束于当前 checkpoint 首个 validation 输入 `2025-12-02T22:00:00Z` 之前，并早于
项目 holdout `2026-05-04T00:00:00Z`；这是训练时代的候选挖掘，不是泛化评估。

## 非方向性零假设与独立验收

本轮是候选覆盖/数据质量工作，没有未来收益标签，也没有定义 TP/SL。因此 val AUC、收益置换
p、top-decile 毛收益、扣 0.2% 往返成本后的净收益、胜率、单特征基线，以及同币 × 同时间块 ×
同波动桶的匹配随机入场收益均 **不适用**。这些指标不能留空后暗示成功，也不能用日方向一致率
替代。模型检测数量只回答“有多少待审提案”，不回答“能不能赚钱”。

对应的严格零假设是：固定每个结构框、K 线、窗口右端和全部阈值，只翻转 LONG/SHORT 后重跑
同一因果语义门。如果方向符号或红绿 K 线语义整体接反，实际方向不应系统性优于翻转方向。

| 配对方向检验 | 结果 |
|---|---:|
| 固定结构框配对数 | 25,932 |
| 实际方向通过 | 8,600 |
| 翻转方向通过 | 8 |
| 仅实际方向通过 / 仅翻转通过 | 8,600 / 8 |
| exact two-sided paired p | 浮点记录下溢为 0；log-space `log10(p)=-2564.09` |

该检验强烈排除全局方向接反，但不能给 1,652 个候选自动贴 Gold：语义门本身按方向定义，且
与模型共享行情。Owner 逐样本视觉/协议裁决仍不可替代。

## 执行中发现的问题与追加协议

1. **SMA120 合法 warmup NaN。** 月任务包整帧检查最初把尚未形成 SMA120 的合法历史行拒绝；
   修为全帧禁 `inf`、每个实际 W18 slice 必须全 finite，并加回归测试。
2. **榜单一侧不足 5 个。** 2024-11-06 只有 3 个严格负收益合约，触发 fail-closed。追加协议固定
   “每侧最多 5 个严格同号收益；零收益和反方向不回填；不跳过该日”。全期共 132 个 underflow 日。
3. **共享 renderer 路径漂移。** 另一项 main 工作给 renderer 增加可选参数。先对已有 4,964 个
   唯一输入比较旧/新默认输出，像素与 transform 4,964/4,964 一致；正式运行改为直接加载预注册
   Git blob，未回退共享文件。
4. **Binance 历史 CSV 有两种格式。** 全 58 月预检的 13,014 份归档中，11,780 份带表头、
   1,234 份为 12 列无表头；追加双解析并保持时间/完整性/holdout 门不变。正式用到 12,691 份。
5. **最终 CSV 嵌套列表序列化失败。** 5,083 张图完成后，旧 helper 把 list 强转 dict。修为保留
   原容器类型的确定性 JSON；首轮图片和 JSONL 移入 `results/failures/`，重建后 5,083/5,083
   图片 SHA、相对路径及 JSONL 字节完全一致。
6. **verifier 把裸画布尺寸当成交付图尺寸。** 裸输入为 742×1280，审核图另有 86 像素标题栏，
   实际为 828×1280。没有把常量改成 828 了事，而是升级为逐张复合渲染后全像素比较；第二次
   完整 verifier PASS。
7. **原总览累计曲线顺序反了。** 队列计数正确，只有旧 `overview.png` 把 newest-first 行重复
   反转。原图保留作审计，另生成有输入/输出 SHA 回执的
   `overview_scan_order_corrected.png`；本报告只展示修正版，检测图和队列未改。

四份数据协议修订均为追加式文件，原预注册没有覆盖；后两项 verifier/总览修复只改变验收和
展示，不改变检测事件集合。

## 风险与诚实声明

1. **榜单是事后分层。** 同日排名不能进入同日实时选币或因果回测；若将来研究交易价值，排名窗
   必须先于交易窗闭合。
2. **训练时代不等于独立验证。** “不在 manifest”只排除精确输入和近邻正例，不能排除相似市场
   状态、同币远邻或视觉模板记忆。
3. **发现 sampler 有意不完备。** W18-only 与回看先导月后冻结的 envelope 预筛节省了约 74.65%
   端点；本轮不能声称覆盖所有模型可能出框的位置，也没有估计召回率。
4. **模型 + 规则不能自证标签。** 1,652 个语义通过只是高优先级正候选；3,401 个规则拒绝也只是
   hard-negative 候选。两者都必须由 Owner 审核后才能进入数据集。
5. **历史合约宇宙有存活/可得性偏差。** 只声称覆盖冻结 admitted/archive 清单；可能缺已下架或
   当时存在但本地未归档的合约。
6. **无成交量门。** 日榜会偏向新币、小币和事件币，极端日收益不能外推为容量或可成交性。
7. **完成态检测不是 tip。** 允许核心后 2–9 根确认；若未来接实盘，时间必须记完整检测窗右端，
   并重新获得 Owner 对延迟预算和执行架构的批准。
8. **没有经济验收。** 未定义障碍、成本或匹配随机入场对照，任何“看起来很漂亮”的图都不是净
   收益证据，也不改变生产 `detector=none`。
9. **未动生产与训练。** 没有 label/dataset 自动写入、训练、调门、promote、部署、消息或订单。
