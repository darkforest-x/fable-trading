# V8 ETH 3分钟：浮盈触及1R后推入场价保本

## 问题与固定口径

Owner针对原报告的ETH 3m后段111笔平仓（胜率32.43%、PF0.851、平均净R -0.237）提出：浮盈到1R就将止损移至入场价是否改善。原报告为 `analysis/p1_spike_v8_lowtf_20260913.md`，冻结primary在 `experiments/active/exp-spike-v8-lowtf-20260913-v1/results/run_20260913_v3`；v4仅复用这些primary结果。

本轮只改变退出保护：多头high达到入场价+初始风险、空头low达到入场价-初始风险，在该根收盘获知，从下一根起将保护位至少推进到入场价。已有更紧的跟踪止损不能被放松；本根原有止损先检查，跳空按实际可用开盘处理。触及1R不是在1R止盈，也不减仓。

3分钟OHLC不能告诉我们同根先到1R还是先回到入场价。主结果不是实时tick级即时保本回放；有歧义的K线单独统计。TradingView也需要借助更小周期的Bar Magnifier补充盘内成交路径，而不能从一根OHLC直接恢复所有先后顺序。[TradingView官方说明](https://www.tradingview.com/support/solutions/43000669285-what-is-bar-magnifier-backtesting-mode/)

沿用原0.2%往返成本，价格保本不等于净收益0。每笔价格风险不同，相同0.2%成本占用的R也不同。

## 研究边界

- 仅OKX ETHUSDT永续3分钟；开发与2026-05-04起的原后段分开。
- Owner已明确允许可用日期并提出本项退出变化；这是新配置的已授权holdout-era使用第1次，底层历史此前已被研究，不是新盲样本。
- 固定原交易入场逐笔配对，回答退出变化本身；另跑完整串行版本，回答提前空仓后新信号可入场的变化。两种分母不能混用。
- PF沿用原报告的净价格收益正负合计比值，另报净R。账户沿用每笔净价格收益串行复利，只统计平仓权益回撤，不等于账户固定风险百分比，也不是逐K盯市回撤。
- 不搜索触发阈值，不改Pine、线上入场、Bark、YOLO、执行器或持仓。

## 结果

**这组ETH 3m数据中，1R后推入场价保本没有改善净收益。** 固定原111笔入场，合计净R由-26.28变为-41.13；重新串行执行后，交易增至119笔，合计-35.47R。完整串行回撤略小，但收益、胜率及10R保留均变差，不接入线上。

### 原111笔完全相同的入场

时间为2026-05-04至2026-07-30，沿用原报告后段。

| 指标 | 原V8 | 触及1R后推保本 |
|---|---:|---:|
| 平仓交易 | 111 | 111 |
| 净胜率 | 32.43% | 24.32% |
| PF（净价格收益口径） | 0.851 | 0.777 |
| 合计净R | -26.28 | -41.13 |
| 平均净R | -0.237 | -0.371 |
| 原单流平仓复利收益 | -6.46% | -8.36% |
| 平仓权益最大回撤 | 14.21% | 15.18% |
| 已实现至少10R | 2 | 1 |

没有将原入场时间换成提前保本出场后的新机会，因此这张表直接隔离退出变化。全部原交易均保留，一一配对，没有仅挑选曾到1R的交易报收益。

111笔中59笔在原有效止损触发前，观察到满足1R启用条件；29笔最终由入场价保护位成交。19笔原亏损被减轻，9笔原盈利变成净亏损，其中1笔原13.09R大赢家丢失。按净R差绝对值1e-8区分舍入噪声：82笔不变，19笔改善，10笔恶化。

- 改善部分合计挽回15.78R。
- 恶化部分合计损失30.63R。
- 净差为-14.84R。其中一笔13.09R大赢家被截断，就贡献了-14.57R的差距；这个小样本对尾部交易极其敏感。

这里“挽回”指减少亏损，不是19笔都变成净盈利。保本成交扣成本后的净亏损中位数为0.717R。

### 一笔具体的大趋势损失

北京时间2026-05-16 12:33，原空头入场2223.33，初始止损2226.35，1R价格风险只有3.02。保本规则在12:45按2223.33退出，毛收益为0；固定0.2%往返成本为每单位价格4.44666，因此成本为4.44666/3.02=1.4724R。

这笔从原来的净盈利13.0938R变为净亏1.4724R。不是“保本止损滑了1.47R”，而是小初始风险把同一固定成本放大到R单位。另一笔北京时间2026-07-14 18:06的多头仍保留净12.5005R。

## 对照与统计的适用范围

这是退出政策的同入场配对实验，对照是同币、同方向、同一入场、同初始风险和同成本的冻结原V8；同时保留完整串行路径。不新增入场筛选器，因此未重新抽取随机市场入场，不能借本轮声称策略有超额入场优势。原低周期报告的随机入场对照结论仍需独立看待。

没有新分类器或排序分数，val AUC、top-decile收益与单特征排序不适用。替代零假设为原入场配对净R差的月块符号翻转检验。后段仅2026-05、06、07三个UTC月；各月平均净R差分别-0.3211、-0.0095、-0.0393。固定种子20,000次双侧符号翻转p=0.25594，信息量很有限；不显著不是证明等价，不能据此推广到所有币种、周期或即时保本。

## 风险与诚实声明

- 固定0.2%是原回测合同，不是已核实的个人实际费率；未完整计入资金费、真实滑点与盘口冲击。本次没有降低成本来挑一个好看结果。
- 3分钟OHLC仅支持本次收盘观察、下一根生效的保本规则；没有tick级即时改单证据。
- 后段仅111笔原交易、三个UTC月和两笔10R，单笔尾部对比较影响很大。早期历史和后段都变差，仍不能推出任何市场上1R保本永远无效。
- 这里1R是价格风险，没有测试账户3%/5%/10%仓位，也没有实际下单。线上规则保持原状。

## 结论与记录

不建议把这项1R价格保本规则直接加入当前ETH 3m V8。它确实减少部分原亏损，却损失更多原盈利；完整串行回撤的小幅下降没有抵消净收益和大趋势保留的下降。本轮不继续搜索0.95R或其他触发阈值。
