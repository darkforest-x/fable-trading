## 结论

本轮把用户看到的长赢家尾部做成可执行的分批退出：首次触及 3R 时，保留 0%、10%、25%、50%、75% 或 100% 仓位继续看 8R；其余仓位在 3R 兑现。信号、入场、K2 止损、1.5R 收盘保护、12 小时、冷却和一次性加权 20bp 成本全部冻结。

结果没有隐藏的“最佳分批比例”：

- 15m 每增加 runner 都单调变差；0% runner（3R 全平）最好。
- 5m 每增加 runner 都单调改善，但 100% runner 也只把稳健分提高 1.17bp、平均净值提高 1.46bp，没达到 +2bp 移动门，且仍为 -15.86bp/笔。
- 所有中间比例都是 3R 和 8R 两个端点的加权组合，无法凭空创造超过较好端点的平均收益。退出结构至此不能修复当前入场池，audit 与最终 holdout 都不应消耗。

## 端点与实现校验

新状态机在真实 2023–2024 全账本上做了两个逐笔退化检查：

- 0% runner 对原 3R：15m 345/345、5m 755/755 setup 一致；最大毛收益误差分别 `2.0e-16`、`1.0e-16`，outcome 100% 一致。
- 100% runner 对原 8R：同样全部 setup 与 outcome 一致；最大毛收益误差约 `1.0e-16`。

首次核对曾发现收益一致但 ambiguous 碰撞标签漂移，已在重跑前修正并补回归测试。这不改变 PnL，却避免把同根止损/目标冲突误分类为普通失败。

## 为什么中间比例不能创造 edge

在相同入场、相同路径、相同两个障碍和按仓位比例计费的前提下，runner 比例为 `f` 的单笔收益严格等于 `3R 全平收益 × (1-f) + 8R 全平收益 × f`；没到 3R 的交易两个端点本来就相同。因此全池平均收益也是两个端点的仿射组合。

这解释了观测曲线：15m 的 8R 端点比 3R 差，所以所有分批都随 `f` 单调变差；5m 的 8R 端点略好，所以随 `f` 单调改善，但上限就是已经失败的 8R。分批可以改变收益分布与心理体验，不能在该状态机下提高平均值超过较好端点。

四折也没有反例。15m 从 0% 到 100% runner 的每一折都恶化；5m 每一折都改善，但 100% 时仍为 -20.29 / -16.09 / -14.40 / -13.75bp。没有任何时期转正。

## 排序基线与真正问题

退出不改变信号排序。3R 基准 15m AUC 0.549、top-decile 净 -5.29bp、置换 p=0.206；5m AUC 0.489、top-decile 净 -19.09bp、p=0.655。连续的止损缓冲、两类确认入场、保护、固定目标与 runner 都未产生扣成本优势，证据一致指向：**问题在信号/入场池的毛优势不足，而不是 TP/SL 框怎么画或退出比例怎么分。**
