# SPIKE“跑赢随机”结论的收益率（bp）复核

日期：2026-09-22。实验：`exp-spike-bp-random-audit-20260922-v1`。状态：**完成；32 个结论单元没有一个在 bp 口径通过，V10.4 1h 联合仍是最强候选但未达 p<0.01**。

## 结论

- 复核 V10.4 六周期联合（`joint`、`v9_long`）、V9 全量（`v9`、`v8`，30m/1H/4H，多空分列）、V12.6 15m（两臂）共 357,863 个已平仓匹配对。按预注册规则，**bp 确认 0 个**，仅 R 显著 1 个（V8 30m 合计，历史对照臂），其余 31 个不显著。
- **小周期那种 R 口径假象在 15m 以上基本不存在**：随机入场止损同样更窄（如 1h 联合 400bp 对 298bp），但止损远大于 20bp 成本，成本R差只贡献 0.010–0.035R。原来的 R 超额主要不是成本造成的。
- **但换成 bp 后证据变弱**：bp 按收益率计，高波动币种权重更大、尾部更厚，区间明显变宽。V10.4 1h 联合：R 超额 +0.244（本次 p=0.011，原报告 0.009），bp 超额 +69.9bp [−20.7, +182.8]，p=0.105。前段 +113.1bp、后段 +25.4bp，方向一致但都不显著。
- **按两种口径看，方向都一致为正的只有 V10.4 联合 1h 与 30m**（前后段 R 与 bp 均为正）。其余结论在后段 bp 转负：V9 30m 前段 +56.8bp（p=0.022）→ 后段 −3.4bp；V12.6 15m 前段 +20.6bp → 后段 −8.9bp；V10.4 联合 15m 前段 +56.6bp（p=0.004）→ 后段 −25.6bp。
- V9 4H 相对随机为负（R −0.138，bp −2.1），即 4H 的正净收益来自整体行情而不是挑点，与原报告一致。

本轮只换度量单位，不重放行情、不改原账本、不改任何默认/Pine/仓位/账户。

## 零假设与不适用指标

本轮是非方向性审计：没有模型或排序分数，val AUC、top-decile、单特征基线不适用；也不报告新的净收益，因为没有新交易。零假设就是各原研究的同币同月同波动桶随机入场（同退出、同成本），本轮只把比较单位从 R 换成 bp。代码测试构造了“毛收益路径完全相同、只有随机止损减半”的对照：bp 超额严格为 0，R 超额为正且等于成本R差（`tests/evaluation/test_spike_bp_random_audit.py`）。

## 解读

1. **R 与 bp 回答的是两个不同问题。** R 等于按固定风险下单（每笔亏 1R 相同），bp 等于按固定名义下单。SPIKE 的实际仓位按风险定，所以 R 是更贴近实盘的口径；bp 只用来检查 R 超额是否被止损宽窄放大。在 15m 以上，成本放大部分只有 0.01–0.035R，R 结论基本不是假象。
2. **bp 区间变宽主要因为尾部。** 按收益率计，少数高波动币大涨大跌主导均值，月块区间宽到跨0。这说明“挑点能力”在两种加权下不稳健，至少不能按 p<0.01 宣称成立。
3. **后段衰减是更主要的问题。** V9 30m、V10.4 15m、V12.6 15m 都是前段在两种口径均较强、后段转负；只有 V10.4 联合 1h/30m 前后段两种口径都为正。
4. **4H 的净盈利来自行情。** V9 4H 目标与随机同样约 +120bp，相对随机无超额。
