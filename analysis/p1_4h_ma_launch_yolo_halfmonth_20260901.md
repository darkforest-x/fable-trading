# 4h YOLO 全币种最近半个月检测实验（2026-09-01）

## 结论先行

按 Owner 要求，本轮在刚冻结的 OKX 全量合资格 USDT 永续宇宙上，把观察区间从最近 6 个已确认
4h 端点扩大为 **90 个端点（15 天）**。模型、权重、confidence、NMS、W18/W19、core4/5、
post2–9、同币 5-bar 去重门和行情字节全部不变。

最终结果不是“半个月只有 4 个”：

| 口径 | 结果 |
|---|---:|
| 15 天去重事件 | **221** |
| 有事件的币种 | **182 / 273（66.7%）** |
| LONG / SHORT | **171 / 50** |
| 平均每日事件 | **14.7** |
| 最新 `09-01 20:00 CST` 端点仍成立 | **4** |

所以此前的 4 个只是“最后一根收盘时仍出框”，而不是半个月累计数量。15 天内共检测到 221 个
事件，但其中 **140 个（63.3%）集中在 08-20～08-22 三天，且 138 个为 LONG**。去掉这三天后，
剩余 81 个事件为 33 LONG / 48 SHORT。这个同步爆发是明显的市场状态集中，不能把 221 个当成
221 个相互独立、已验证有收益的交易机会。

## 为什么“当前 4 个”和“半个月 221 个”不矛盾

扫描每个币的每个 4h 端点时，模型同时看 W18 与 W19，因此一个真实形态通常产生多张重复框；
相邻端点也可能连续命中。完整漏斗为：

| 阶段 | 数量 | 说明 |
|---|---:|---|
| 合资格币种 | 274 | 当时全部 live、有效 ticker 的加密资产 USDT 永续 |
| 有足够历史 | 273 | DOS 仅 132 根，失败关闭 |
| 模型输入 | 49,064 | 最近 90 个已确认端点 × W18/W19；新币 warmup 不足部分跳过 |
| YOLO 原始框 | 2,038 | 已经过冻结 conf=0.25 模型门 |
| 结构合法框 | 1,764 | 拒绝 post 超合同 272 个、core 超合同 2 个 |
| 同币 5-bar 去重事件 | 221 | 171 LONG / 50 SHORT |
| 最新端点仍成立 | 4 | 3 LONG / 1 SHORT |

`1,764 → 221` 不是删除有效信号，而是合并 W18/W19 和连续端点对同一事件的重复观察。221 个事件
的候选成员总和仍恰好是 1,764，重复归属为 0。

## 风险与诚实声明

- **15m → 4h 仍是分布外。** W18/19 从 4.5–4.75 小时变成 72–76 小时，core4/5 变成
  16–20 小时，post2–9 变成 8–36 小时。221 是 OOD 检测事件，不是 4h 模型精度证明。
- **高度同步，可能是共同 beta。** 63.3% 事件挤在三天，且几乎全为 LONG；未做匹配随机对照前，
  不能把这种市场共振归功于检测器。
- **当前宇宙有存续偏差。** 扫的是 09-01 仍 live 的合约；半个月内已经下架的合约不在宇宙，
  新上市币又可能因 warmup 不足少扫或被排除。
- **边界删失。** 08-18 的 9 个事件在第一个扫描端点已经存在；它们的真实开始时间可能更早。
- **方向并非全部稳定。** MERL、COMP 两个事件在同一 5-bar 邻域里出现过双方向类别。
- **confidence 不是胜率。** 即使 SPK 为 0.9553，也不能读成 95.53% 胜率；LA 当前 0.2682 更接近
  阈值噪声区。
- **交互式实验无预先 source commit。** 合同在推理前冻结，数据、权重和像素均可回放，但相关
  scanner 是本次对话中形成的未提交代码，不能冒充已提交 builder 产出的正式可复现实验。
- 未训练、未 promote、未切换 ACTIVE/frozen、未写 forward、未部署、未发 Telegram、未下单；
  `production_eligible=false`。
