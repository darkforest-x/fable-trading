# 首4小时区间假突破回归：BTC、ETH三年固定规则回测

日期：2026-09-20。实验：`exp-four-hour-range-20260920-v1`。

结论：**当前固定版本在BTC、ETH上扣除20bp往返成本后均为负期望，不能据此采用为实盘策略。** BTC扣费前已略亏；ETH毛收益为正，但远不足以覆盖成本。前两年、后一年以及多空方向均为净亏。代码实现完成，负面结果保留，不以调参后替换本版结论。

## 规则与研究口径

原始资料：[Data Trader视频](https://www.youtube.com/watch?v=O5eC5lY7ZXY)。本轮按此前核对的close-based定义实现：5m收盘先在区间外，再严格收回内部；不是要求open和close同时完全在外。影线单独越界不触发。

1. 标的为OKX `BTC-USDT-SWAP`、`ETH-USDT-SWAP`，对应TV `OKX:BTCUSDT.P`、`OKX:ETHUSDT.P`。用户未指定交易所，沿用会话默认OKX。
2. 区间是纽约日历00:00–04:00墙钟高低点，由5m重建；不是把交易所原生4H改个显示时区。春秋DST日分别36/60根，平日48根。
3. 首根区间外close开始记录完整影线极值，首次严格回归产生候选，下一根开盘成交。若跳到另一侧外收盘则重新开始另一方向事件。边界等号保留事件，不确认回归。
4. 止损固定在此次突破至回归bar的最低/最高，止盈为实际开盘价计算2R。不用订单块替代，不加趋势/波动/止损宽度过滤。
5. 每币单仓、不加仓；持仓中候选丢弃。日末纽约23:55 bar收盘强平，这是为补齐视频缺省而明确增加的假设。
6. 跳空越SL按开盘价、越TP按目标价；同5m双触按SL先。开盘跳出区间但SL风险仍有效时允许，BTC/ETH各2笔，不偷偷过滤。
7. 固定成本为入场名义金额0.002，包含研究使用的费用/执行摩擦预算；没有逐笔实际费率、额外资金费、杠杆清算或账户复利模型。

纽约IANA时区自动处理夏令时、以及Pine订单成交设置依据[TradingView时间文档](https://www.tradingview.com/pine-script-docs/concepts/time/)与[策略文档](https://www.tradingview.com/pine-script-docs/concepts/strategies/)。

## 为什么亏

BTC毛价格收益平均每笔−2.64bp，本身没有正收益；ETH仅+1.86bp。固定成本20bp后分别成为−22.64/−18.14bp。亏损在等风险R和等名义金额bp两种权重下同时成立。

BTC/ETH止损距离中位0.4695%/0.6712%，平均成本却达0.7093R/0.4394R，因为极窄止损显著抬高成本/R。BTC有130笔、ETH29笔风险低于0.1%；其中完整命中2R却净亏的分别40/11笔。

最极端BTC空单：2025-09-19 08:25Z，入117058.1、SL117068.8、TP117036.7，止损只有10.7美元。毛+2R，但风险0.00914076%，20bp成本=21.880019R，净−19.880019R。独立逐笔复核确认不是成交bug。这里没有假设账户愿意为这么窄的止损使用极高杠杆。

| 稳定性/风险 | BTC | ETH |
|---|---:|---:|
| 最大已闭合回撤R | 1695.91 | 856.55 |
| 最大5m收盘估值回撤R | 1695.91 | 858.48 |
| 最长连续净亏 | 18笔 | 14笔 |
| 持仓时间中位 | 110分钟 | 115分钟 |
| 正收益月份，含首尾部分月 | 0/37 | 2/37 |
| 2R目标仍在参考区间内的比例 | 45.52% | 47.82% |

超过一半交易的2R目标越过另一侧区间。这一几何矛盾值得研究，但本轮没有事后加过滤。完整按月、年、多空、目标内外分组及相应随机对照在`run_v1/grouped_metrics.csv`。

## 风险与诚实声明

- 没有优化或验证最优参数；只有一种固定规则、两个币与一种来源。纽约00–04、close-only、日末强平都是本实现的明确边界，不泛化成视频所有主观变体的结果。
- OHLC不能恢复每根真实路径；仅3笔实际双触被保守处理。没有订单队列、盘口冲击、资金费、杠杆限额、复利或清算模拟。
- 20bp是研究成本假设，不是声称每个账户实际收费都等于它。未授权降低成本、改止损或筛掉窄风险交易。
- 累积R不是账户收益率，极窄风险会放大R单位成本；同时给出净bp以避免单一权重误导。回撤只在5m收盘估值，不是tick级账户最大回撤。
- 随机控制会重叠且月间仍可能相关，月块区间不是未来盈利保证；后段历史不是未见盲样本。
- 测试通过证明实现行为，不证明交易优势。training_eligible=false，production_eligible=false；无训练、ACTIVE切换或真实订单。
