# SPIKE V3：突破前均线收拢，能否减少假启动

**D 没有同时达到少提示与保留正确启动的固定目标。** 合并标签减少40.77%，V3原及时正例保留52.02%，大幅行情及时召回44.98%。父预警相对匹配随机的平均超额为-109.59bp，四假设Holm p=1.00000。这是固定历史事件研究，不是账户收益或已部署策略。
