# SPIKE V1 与 V12.6：OKX ETH/BTC 1m、3m、5m 对照回放

日期：2026-09-22。实验：`exp-spike-lowtf-v1-v126-20260922-v1`。状态：**完成；两个版本在三个小周期都不能盈利，也没有可靠跑赢随机入场**。

## 结论

- 同一份 OKX 1m 数据、同一时间窗（2024-02-01 至 2026-09-22 14:00 UTC）、同一 0.2% 往返成本下，V1 与 V12.6 在 1m/3m/5m 的全期、前段、后段全部净亏。只有 V1 原版 5m 前段 65 笔 +4.76R 是正数，后段 44 笔 −34.91R。
- **扣费前也几乎没有优势**：V12.6 平均毛收益 1m +0.7bp、3m −0.5bp、5m +3.6bp；V1 原版 −5.9bp、−20.6bp、+14.5bp。0.2% 成本在这些周期平均相当于每笔 0.33–1.32R（中位止损只有 19–88bp），所以净R被成本主导。
- **按收益率（bp）计，两者都没有跑赢同币同月同波动桶的随机入场**：全期超额 V12.6 为 −2.3/−1.6/−3.4bp，V1 同退出为 −7.9/−15.2/+8.9bp，月块区间全部跨0，单侧 p 0.31–0.96。预注册的 R 口径超额在 V12.6 1m、V1 1m 上 p<0.01，但那是随机入场止损更窄、成本折成R更大造成的假象（见“零假设”一节），不是入场能力。
- **近两个月（2026-07-22 至 09-22）**：V1 原版 1m 18 笔 −12.18R、3m 14 笔 −4.63R、5m 8 笔 −6.73R，合计 40 笔 −23.54R；V12.6 同期 1m 151 笔 −265.14R、3m 73 笔 −69.86R、5m 27 笔 −5.65R。
- V1 在小周期信号很少（两个币合计 1m 280 笔、3m 163、5m 109，约32个月）；V12.6 多得多（2731/1043/491），但单笔更差。两者都没有兑现净 >10R 的 V1 交易；V12.6 共 23 笔 >10R，不足以覆盖成本。

本轮不改 Pine/TradingView、监控、仓位或真实账户；训练与生产资格仍为 false。

## 解读

1. **小周期的主要问题是成本相对止损太大。** 1m V12.6 中位止损 18.9bp，0.2% 往返成本就是 1.06R；即使扣费前打平（+0.7bp），扣费后每笔也亏约 1.25R。周期越大成本R越小，均净R从 −1.25（1m）改善到 −0.45（5m），但 5m 仍亏。
2. **扣费前也没有优势。** V12.6 三个周期毛收益在 ±4bp 以内；V1 3m 为 −20.6bp，5m +14.5bp 但只有 109 笔、后段转负。bp 口径相对随机的超额全部跨0。
3. **V1 与 V12.6 在小周期的差别主要是频率，不是质量。** V12.6 1m 每币每天约 1.4 次候选，V1 约 0.15 次；bp 口径下两者都不比随机好，不能说哪个版本信号更好。
4. **V1 在 30m/1H/4H 的历史利润不能迁移到小周期。** 对话中引用的 V1 两年账本（三所、30m/1H/4H）近两个月 +551.3R，主要来自 2026-08 的山寨行情且没有随机对照；本轮 ETH/BTC 小周期同期 −23.54R。两者币池与周期都不同，不是同一问题的两种答案。

## 风险与诚实声明

- 只测 ETH、BTC 两个合约，约 32 个月；不代表山寨或全市场小周期。前后段都是已研究过的历史，不是盲测或前向。
- V12.6 是 Python 研究移植，TradingView 原生 pivot 平局语义未核实，不称与图表一致；小周期上的 HTF 映射、M15 EMA120 门按 Pine 源码实现，未做原生逐事件对账。
- 固定 20bp 往返成本，没有额外滑点、资金费或 1m 盘口冲击；真实小周期成交通常更差，结论只会更负。
- bp 超额是看到 R 偏差后才补充的诊断，已明确标注；预注册的 R 结果完整保留且未删改。
- V1 原版没有同退出随机对照，以 V1 同退出的随机对照为零假设；两者平均收益接近。
- 近两个月样本极小（V1 共 40 笔），p 值和均值都不稳定。
