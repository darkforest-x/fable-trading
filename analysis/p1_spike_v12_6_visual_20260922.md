# SPIKE V12.6：自适应趋势线与K线着色（2026-09-22）

新建 TradingView 私有脚本 **SPIKE V12.6 · 自适应视觉** revision 1，保留 V12.5 源文件与私有脚本。当前交付为同账号 Chrome 网页图表；未声称桌面端已有实例自动升级。

## 与 V12.5 对照

| 项目 | V12.5 | V12.6 |
|---|---|---|
| 本周期/上级趋势线 | 白色/淡蓝色固定默认 | 默认按图表背景亮度用黑/白；可关闭自动改用自定义色 |
| 历史区域 | 局部整理，历史淡化 | 完整保留原有局部整理、历史透明度和40组资源上限 |
| 突破K线 | 无独立连续着色 | 确认突破当根起默认3根，可调1–20；默认同对应线色，可自定义 |
| 精简模式 | 无 | 仅六均线＋本周期/上级主趋势线及历史线；隐藏标签、ABC、BB、风险图形、上级均线、面板和IMACD |
| Pin Bar | 无独立几何着色 | 默认开启，长下影青绿、长上影粉红；可独立关、改色、设优先级 |
| 信号/配对/风控/预警条件 | 原规则 | 不变；预警标题版本文字改为V12.6 |

K线着色在精简模式仍受独立开关控制，关闭两项着色即恢复原始蜡烛配色。Pine 无法由输入开关动态移除副图容器；精简模式清空副图内容，空白区域需用户折叠。默认精简关闭，最终图表恢复默认配置和原白色背景。

## 因果与形态语义

着色使用已确认突破事件的冻结线；本图用 `.copy()` 独立保存几何，上级使用已知时间锚点。仅在本图K线收盘计算，默认3根包含确认当根；此前用于确认的K线不补色。收盘回到线或线下、线值非正或数据断档取消。8根内同B位置/价格的重复事件沿用首次窗口，避免重启成一长串颜色；不同几何但相同B也会合并，这是与当前bk显示分组一致的边界，不宣称逐候选逐一着色。上级突破从本图获知时开始，不回画到尚不可知的上级起点。

Pin Bar 是独立视觉形状定义：实体≤全长30%，主影线≥60%，另一侧≤20%，全长≥4个最小跳动；只看已收盘OHLC。默认突破颜色优先，其次Pin Bar，最后旧V9确认色；另可勾选Pin Bar优先。没有叠加枢轴、流动性水平或胜率判断，不能把着色等同反转/扫单/入场。

实现参考官方 [chart colors](https://www.tradingview.com/pine-script-docs/concepts/chart-information/) 与 [plotcandle](https://www.tradingview.com/pine-script-docs/visuals/bar-plotting/) 文档。背景RGB亮度只决定黑白基础色，原历史透明度单独生效。

## PEPE止损问题

截图入场约0.000002620、止损0.000002590，对应初始价差约1.145%。当前多头初始止损为 `floor_to_tick(min(最近5根最低价−0.2×当前ATR14, 入场收盘价−2×当前ATR14))`，不是SMA120或上级均线止损。持仓从下一根开始先检测旧保护；未止损且收盘达到2R才启动 `close−4×当前ATR14` 跟踪，保护只收紧、不放宽。图中-1R与初始保护触及相符，但尚未逐K定位。

紫线在15m图是上一根已完成1h SMA60，5m图是上一根已完成15m EMA120；均为方向过滤/显示，不参与止损。本周期SMA120同样未参与止损。因此存在“短周期保护触及，较慢均线支撑尚未失效”的规则不一致可能，但不能凭后续涨幅判定所有此类止损错误。

截图缺日期与入场K时间，本地同价格多次出现，当前TV布局为OKX PEPE15m也不足以证明同一历史事件。已向owner索取入场时间。未用Binance的1000PEPEUSDT交易冒充OKX样本，也未重跑全量去猜日期。
