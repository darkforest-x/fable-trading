## 执行原则

AI 负责把自然语言和同频道最近消息转换成结构化动作：
`open`、`cancel`、`partial_close`、`update_sl`、`update_tp`、`close`、`hold`。

代码不依赖每一句固定文案，但在调用交易 API 前必须校验：

- 只继承同一 Discord 频道的最近交易上下文。
- 取消操作只撤未成交挂单，不平仓。
- 部分/全部平仓只使用 reduce-only。
- 修改止损前必须存在对应持仓。
- 离线补抓历史消息只分析，不执行。
- 无法唯一确定品种时跳过，不猜测。

## 已观察到的注意点

- 飞扬经常先发布限价策略，随后用极短消息修改或取消，因此频道上下文是必要条件。
- 同一条消息可能包含两个动作，例如“止盈 50% + 剩余止损移到成本价”，需要顺序执行两个 API 操作。
- 个别历史策略存在明显笔误，例如 BNB 止损 `6719` 随后修正为 `719`。价格偏离和止损方向校验必须保留。
- “触发入场价”“触发成本价”通常是状态汇报，不应重复开仓或重复平仓。
