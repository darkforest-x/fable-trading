# A flat external position needs receipt reconciliation, not another close order

- **Problem**: A manual SAND lot remained `exit_needed` after the exchange position had been enlarged externally and then fully closed. Its canceled OCO sent management into the normal exit path, where the stale owned quantity blocked every new manual preview indefinitely.
- **Dead end**: A generic “reconciliation pending” message and a preview retry cannot repair a stale lot. Clearing errors, deleting the lot, relaxing ownership checks or posting another exit would conceal the cause or affect a new owner position.
- **Effective path**: Require one known owned lot, a terminal owned OCO, two flat account reads bound to the original account, no pending instrument orders, and a completed reduce-only close after entry. Record the receipts and end the local lot without exchange POSTs. Mixed-lot closing price and PnL remain unattributed. Missing, conflicting or failed reads still block.
- **General rule**: Reconcile positive evidence before attempting discretionary mutation. Manual and automatic workers need separate revision contracts; an automatic-only update must not silently invalidate the manual worker. UI connectivity, execution readiness and order confirmation are separate states; name the blocking instrument and provide a relevant destination instead of an endless retry button.

The owner’s risk, quantity approval, freshness and individual-confirmation rules are unchanged. OKX fields follow [Trade / order history](https://www.okx.com/docs-v5/en/#order-book-trading-trade-get-order-history-last-7-days).
