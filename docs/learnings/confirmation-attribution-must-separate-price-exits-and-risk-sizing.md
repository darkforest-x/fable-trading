# 确认入场的收益归因必须分开价格、退出与风险缩放

- **问题**：等待突破确认后，胜率和每笔净R改变了。需要判断筛掉坏机会的好处，是否足以支付更差的入场价格。
- **死胡同**：只比较确认前后均R，会同时混入不同成交集合、不同价格、不同退出路径和不同R分母。只保留信号与随机对照都确认成功的交易，还会丢掉大量已知零成交机会。回看“最终会确认的信号如果提前买入”不能被包装成可执行策略。
- **有效路径**：按原启动事件联结立即和确认结果；到期/取消记零成交，未解决结果单独排除。用原锚点风险固定金额单位，依次分解取消机会、入场价差、退出价差与费用名义本金变化，最后单列按新止损距离调整数量的影响。全部分项逐笔加回最终净R差。随机锚点应用同一确认过程，不成功不补抽；逐币占仓变化另列，不能将独立重叠事件之和视为账户收益。
- **通用规则**：比较任何等待确认策略时，先固定事件谱系、风险金额和零成交分母。确认后才能知道的样本标签只能用于归因，不能倒推成更早的入场信号；实际下一开盘价与确认收盘时可见特征必须分开。
