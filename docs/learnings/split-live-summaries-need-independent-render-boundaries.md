# 实时摘要并排时，布局边界与刷新边界要分开

- **问题**：首页实盘摘要原来占满整行，Owner 要求左半展示共振监控、右半保留两个独立账户，且不能挤占更多图表高度。
- **死胡同**：前一稿只压缩两张账户卡片的高度，仍把整行都分配给账户，未满足信息分区要求。将共振实时数值直接插入新外层容器模板也不可取：现有分区更新器按整段模板比较，会连带重建账户控件。
- **有效路径**：先取得 Stitch 的左右等宽设计图和代码，再使用不变的外层容器。共振只更新自己的文本、周期和状态；账户继续独立轮询与局部更新。右半改为两条紧凑摘要，手机沿用账户切换。真实浏览器验证周期切换后结算展开状态与焦点仍保留。
- **通用规则**：合并视觉布局时先核对各数据源的刷新边界，避免一个来源刷新导致另一个来源的交互状态丢失。显示数值必须同时绑定周期、新鲜度和统计范围；未知值不能替代为零，同向比例要说明参照方向。
- **牵连**：`market-sync.js`、`market-accounts.css/js`、`market-terminal.js`；Stitch 项目 `8978791379095391159` / 页面 `ce937c6c3f794297a3e408a802e8ddda`。保留只读数据接口和执行状态语义，不改变交易控制、阈值或实盘运行。
