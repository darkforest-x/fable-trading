# 策略入场门槛不能回退到模型分类阈值

- **问题**：live-wick 小册正文和模拟执行用评分 ≥0.5，概览却显示 ≥0.2262；同一概览还继承了普通账户的 +0.17% 保护偏移，而插针策略应在 1.618 原位保护。
- **死胡同**：只核对开仓代码或正文无法发现概览遗漏策略分支；把 0.76 高分保证金加权线当成入场线又会引入另一处错义。字段都叫“评分”不代表用途相同。
- **有效路径**：分别对照运行接口、开仓条件与实际 DOM，确认 model.threshold 是通用信号分类线，live-wick.min_score 才是入场线。概览显式读取对应账户，缺配置保留空缺；插针流程说明同步使用 1.618、零偏移。所有账户概览回归与五个 live 小册浏览器验收覆盖了这处遗漏。
- **通用规则**：新增策略时要检查概览、详细规则和执行三处的数据归属；展示层不能用一个看似合理的默认值掩盖缺失分支。设计生成物只提供视觉参考，策略条件仍以已核实的执行定义为准。
