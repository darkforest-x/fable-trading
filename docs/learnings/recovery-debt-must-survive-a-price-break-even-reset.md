# 仓位复位不能把尚未回收的净亏损当成已回本

- **问题**：Owner把“浮盈1R后移到开仓价”理解为赢了、下一笔回1U，并希望放大某一笔的3R收益追回旧亏损。账户是否回本与单笔价格是否保本不是同一状态。
- **死胡同**：把价格保本退出标成赢，再从零计算下一轮，会掩盖旧亏损和手续费；只优化最大连亏也可能选出现金几乎耗尽的配置。ETH3m研究中最短开发连亏9次的配置只剩21.69U。
- **有效路径**：分别记录价格毛R、扣费净R、本轮净现金、全账户现金；轮次复位保留真实现金损失，并独立统计跨轮连亏。855组中加码开发第一的连续账户588笔价格保本全部净亏，1000U降至10.31U；相同退出固定1U也亏，不能把局部回本周期当成账户正期望。
- **通用规则**：若旧净亏损为D、本笔总成本为C、价格风险金额为B，要锁住整轮不亏，保护退出的毛R至少为(D+C)/B；开仓价对应0毛R，并不满足该条件。该式仅为账目门槛，不保证价格触及或订单成交。先验证不加码时的净收益和容量，再比较回本机制。
- **牵连**：`analysis/p1_spike_eth3m_recovery_20260914.md`、`yoyo/evaluation/spike_recovery_cash.py`；所有费用、跳空与实际成交仍影响净账。动态整轮回本保护尚未在本实验验证，holdout消耗0次。
