# Calibrated score attribution needs both model stages

- **问题**：三笔 BTC 上方 1.618 空单全部盈利，冻结评分却仅约 10%，需要定位具体扣分来源。
- **死胡同**：只列原始逻辑回归的负系数会把拒绝全部归咎于特征；实际这些样本的特征合计均在加分。三笔原始概率为 27.20%、30.21%、22.82%，后续校准才压至 10.55%、10.75%、10.23%。
- **有效路径**：逐层重建标准化、原始线性项、sigmoid 校准和经济门槛，验证输出与冻结预测一致，再核对校准样本。BTC 此季度校准只有 7 周、53 次触达、5 个先到近侧目标的正类；斜率0.146与截距-1.994使概率集中约10%。本周43.13%的门槛对应校准前99.99922%，但删掉校准也救不了三笔，因为原始分仍低于门槛。
- **通用规则**：解释最终决策时同时报告参考概率、特征净贡献、校准变化及门槛。对数几率贡献可相加；把单项替换为均值后的概率变化不可相加，相关特征的数值贡献也不是市场因果。不能只靠近期三笔盈利判定校准错误或直接调参。
