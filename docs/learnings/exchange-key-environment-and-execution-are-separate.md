# Exchange key environment and execution readiness are separate

- **问题**：Owner 最初选择模拟 API，OKX 返回 50101；随后明确纠正为实盘接入。
- **死胡同**：不能在模拟认证失败后自动尝试实盘，也不能把认证成功当成委托和保护单链路已经完成。
- **有效路径**：先返回环境不匹配，在 Owner 明确纠正后使用独立只读实盘探针；仅允许白名单 GET，无下单、改仓或切换账户模式方法。核验成功与执行启用分别展示。
- **通用规则**：环境来自明确意图；能力来自实际实现和验收。两者不能通过一次成功的账户请求合并推断。
- **牵连**：`yoyo/discipline_app/okx_demo.py`、`api.py`、独立私有运行目录。手机只收到脱敏核验状态，实盘凭据不进入仓库或客户端。该次核验成功，执行链路仍未接通。
