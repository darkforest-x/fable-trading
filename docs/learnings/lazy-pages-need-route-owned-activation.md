# 懒加载完成不能夺回用户已经离开的页面

- **问题**：全站脚本改为按页加载后，资源到达顺序与点击顺序可能不同；前一页迟到后可能重启其轮询或重绘。
- **死胡同**：只动态插入 script，再在 onload 无条件激活页面，会让旧导航回调改变当前页面；移除 script 标签也无法卸载已执行模块。
- **有效路径**：资源 Promise 去重、失败允许重试，共享依赖先于消费者执行；激活由导航代际负责，仅当前代际启用页面。离开时停止页面任务，加载反馈也归属于当前导航。
- **通用规则**：代码加载生命周期和页面激活生命周期必须分开；测试乱序完成、共同依赖及失败重试。
- **牵连**：static/module-loader.js、app.js、frontend_module_loader.test.cjs。
