# 退出根未更新浮盈，不等于退出前从未涨过

- **问题**：逐笔解释止损时，原回放先检查当前止损并退出，再更新本根MFE。因此入场当根止损的MFE可为0，即便止损前有过浮盈。
- **死胡同**：直接把退出根最高价补进MFE，会把止损之后的上涨算成持仓收益；直接沿用0，又可能把未记录误当成没有发生。二者都不能凭一根OHLC确定先后。
- **有效路径**：保持原账本和执行不动，用原始5分钟序列定位首次止损触及。此前完整5m的高点形成确定下界，触及5m的高点只形成可能上界；开盘已越过止损时，不纳入该根后续高点。29币570笔中512笔价格止损均有完整5m，只有2笔下界高于原MFE：UNI 15m的0变0.00855R、BTC 4h的0变0.50688R；此池上下界最终均相等，亏单到1R/2R分类没有因此改变。
- **通用规则**：先读执行事件顺序，区分原指标定义与经济路径。缺失5m时保留未知；上下界重合才给确定值。5m只能约束该段路径，不能证明成交滑点、盘口或更细先后。
