# 已知弃权记零，未知门控不能冒充空仓

- **问题**：V30 比较冻结分类器过滤前后的固定时钟结果；部分标签或分类状态可能未知。如何同时保留原机会集合、不凭空补出收益？
- **死胡同**：统一删除缺失标签会错误删除无需成交的已知弃权；统一把缺失记零又会把无法判断的门控冒充成功避险。仅比较留下来的交易均值还忽略了不交易的机会成本。
- **有效路径**：分别保存 observed label 和 policy payoff。已知 accepted 使用已知标签，否则未知；已知 abstain 为零，即使其未使用的未来标签缺失；unknown gate 始终未知。policy delta 仍需原始 baseline label 已知。条件交易比较保留原三个未过滤控制，机会策略比较才对每个控制在其自身时钟应用门控。
- **通用规则**：先画出“决策是否已知 × 是否成交 × 结果是否已知”的状态表，再计算均值；未知不是交易动作，非交易也不是零收益的成交样本。
- **牵连**：`yoyo/evaluation/hourly_impulse_classifier_economics.py` 与纯合成测试；V30 默认 10/100、原 251 母事件 / 744 控制、4h 主指标及 20bp 成本阈值不变。这里的 policy payoff 是研究记账，不是账户净值或可执行成交利润。
