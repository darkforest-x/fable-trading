# 精简显示时也要延续已确认的历史保留口径

- **问题**：周一高低点极简 v1.12 删除了其他显示，但从原始 v1 带回了 `keepWeeks=12`；Owner 随后要求保留历史每一周。
- **死胡同**：把 12 改成 250 仍然删除旧周；取消删除却无限创建线对象，会触发 TradingView 的 500 条线回收上限。两种办法都不能保证拖回旧日期仍看到对应区间。
- **有效路径**：v1.13 复用 V2.13 已验证的记录与绘图分离方式。保留每个已加载周的极值、极值时间和结束时间，重画当前可见范围；不再有周数输入和历史记录淘汰。单屏超过 250 周时在 Pine 日志提示放大，保持主图只有高低线。
- **通用规则**：精简功能前先核对已确认的历史保留要求；删除界面元素不应恢复旧版的数据截断策略。图形句柄上限与历史记录保留分开验收。
- **牵连**：`yoyo/evaluation/pine/monday_range_v1_12.pine`（原版保留）、`yoyo/evaluation/pine/monday_range_v1_13.pine`。已有方法见 [历史数据与绘图保留分离](pine-history-retention-is-separate-from-drawing-retention.md)。平台可加载的 K 线范围仍决定可计算的历史起点。
