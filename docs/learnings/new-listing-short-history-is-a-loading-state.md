# 新上市合约的短历史是预热状态，不是计算失败

- **问题**：V12.8 监控首次全市场扫描时，CYPH 等新上市合约只有一根 4H K 线，冻结 V9 布林压缩函数拼接出两元素数组，与单行索引不匹配。
- **死胡同**：把这类异常当成数据源失效，或为了避错补造 K 线。输入本身合法；也不能仅凭 V12.8 扫描报错就认定是新方向门引起，原 V9 同一输入也失败。
- **有效路径**：用原始 checkpoint 在两个版本复现相同异常，定位到至少需要两行的冻结压缩核；V12.8 适配入口对零/单行合法历史返回 loading，保留真实 OHLC、无信号、ready=false。四周期边界测试确认不会虚构入场，也不改动历史研究内核。
- **通用规则**：按“有效但不足以决策”和“数据非法”区分短历史；初始化边界必须覆盖零、一、足量三类输入。
- **牵连**：`yoyo/monitor/v128_signals.py`、`tests/monitor/test_v128_signals.py`；不改变准入阈值或数据源。
