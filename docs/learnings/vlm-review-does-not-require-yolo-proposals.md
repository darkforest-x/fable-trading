# VLM 形态复核不要求候选一定来自 YOLO

- **问题**：2026-09-23 阅读工业 YOLO＋VLM 对比文章后，需要判断交易研究能否去掉 YOLO。当前已有 SPIKE 数值候选与智谱视觉研究工作台，不能把文章的工业流程当成本项目必须照搬的架构。
- **死胡同**：把选择缩成“继续训练 YOLO 或换一个更大视觉模型”，忽略我们原本持有 OHLC、均线与信号时间；文章未披露具体 VLM、硬件、提示词、公开测试集，其耗时与准确率不能迁移为本仓证据。此前只有少量工作台调用与单例回归，未证明 VLM 的识别或交易优势。
- **有效路径**：架构分析将候选生成与形态复核分开。建议先冻结现有 SPIKE 候选，离线比较原候选与同批候选经固定 VLM 复核后的结果；YOLO 可以保留作独立识别对照，无须成为 VLM 上游。本轮仅完成资料核对和方案分析，没有执行新盲测或确认此方案有效。
- **通用规则**：先定义决策时点和待判状态，再选输入表示与模型。形态盲测使用同一批无未来真实图、独立事件及时间隔离、重复一致性和打乱标签对照，并抽查候选池外漏检；固定比例样本的精确率不能直接外推实盘。认形有效后才检验原成本下的净收益、匹配随机超额与高 R 保留率，模型自报信心不等于胜率。
- **牵连**：`yoyo/vision_research/zhipu.py` 的右端状态任务、`yoyo/vision_research/schemas.py`、现有实验 `experiments/active/exp-spike-gemini-vision-20260923-v1/`；P0/P1、新训练、生产准入与逐样本金标要求均不变。已有相关原则见 [视觉解释需要任务盲测](visual-narratives-need-task-specific-blind-validation.md)。
