# 路由恢复必须处理缺省字段

- **问题**：信号页从 `side=short` 回到裸 `#signals` 后仍筛选空头；页签切换用 replaceState，浏览器返回无法回到上一个面板。
- **死胡同**：只验证有值参数，虽然挡住非法值，却把缺省字段解释成“保留上次状态”；单看刷新后的页面发现不了。
- **有效路径**：在同一会话中复现“带筛选地址 → 默认地址”，恢复时对每个字段赋有效值或明确默认值；工作区 pane/layout 变化建立历史步骤。
- **通用规则**：URL 是完整状态描述，缺省不能隐式继承另一次访问；默认地址和非法参数都要在非默认状态之后测试。
- **牵连**：`app.js`、`workspace-navigation.js`；只涉及浏览状态，不记忆或恢复交易确认。
