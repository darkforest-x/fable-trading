# 同一题多份一致答案，不是多出几个目标框

- **问题**：旧审核库存整理器保留全部人工答案时，把多份一致答案中的框拼接，导致一个事件可能导出重复正框。当前真实快照每题仅一份答案，现有计数不受影响。
- **死胡同**：将“保留全部标注记录”实现成“合并全部有效框”。重复提交或重复复核是监督记录数量，不能当作图像中目标数量。
- **有效路径**：保留每份答案ID及原始JSON；事件级结果先校验完整框集合等价，只选一份完整几何集合。不一致则隔离，不能最后一次答案覆盖之前答案，也不能按单框去重拆坏多框标注。
- **通用规则**：分别记录标注记录数、事件数和目标框数。多份一致标注只增加一致性证据，不增加训练目标。
- **牵连**：`yoyo/datasets/historical_review_inventory.py`、`tests/test_historical_review_inventory.py`及`owner_review_export.py`的一致性判断。本轮加入两份一致答案只产生一个完整框集合的反例测试。
