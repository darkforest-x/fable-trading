# 刷新期间的忙碌状态必须反映在可见控件上

- **问题**：模拟开单页面每 5 秒刷新行情，内部 `busy=true` 后没有立即渲染；仍显示可点击的平仓按钮，实际点击被防重复操作的 guard 静默丢弃。浏览器验收曾等待平仓表单超时，账本没有新增成交。
- **死胡同**：只加后端幂等性或等待更久无法修复点击没有发起动作的问题；正常网络下的瞬时单元测试也看不到这段窗口。
- **有效路径**：刷新开始时立即渲染 busy 状态，按钮与字段明确禁用，结束后恢复。用延迟返回的 GET 固定该窗口，检查刷新前后 DOM 的可交互状态，再实际走通开平仓。
- **通用规则**：事件 guard、可见 loading 状态和 HTML disabled 必须对应同一份状态；测试网络等待期间的行为，不能只看请求开始前和完成后。
- **牵连**：`yoyo/monitor/static/paper-desk.js`、`tests/monitor/frontend_paper_desk.test.cjs`。不改变账本、报价有效期或模拟成交规则。
