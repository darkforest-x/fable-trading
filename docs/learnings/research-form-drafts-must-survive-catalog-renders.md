# 研究表单草稿不能由目录重绘覆盖

- **问题**：流程目录刷新、提交失败或切换回测与模拟时，表单重建会重置运行方式、观察周期和未保存计划；数据集重置筛选后，汇总按钮仍可能保留旧状态。
- **死胡同**：仅保留某个输入框的文字不足以保留整张表单；只更新结果列表也不能保证分类按钮、下拉框和筛选摘要一致。
- **有效路径**：将编辑草稿与目录记录分开保存，保留草稿对应版本以让并发冲突继续被服务拒绝；从统一状态生成运行表单与筛选界面，不适用的隐藏字段同时禁用；对刷新、失败和重置进行行为回归。
- **通用规则**：每次重绘先明确哪些内容来自服务、哪些属于用户尚未提交的选择；一个状态变化应更新全部依赖它的控件，不能只改局部文字。
- **牵连**：`yoyo/monitor/static/platform.js`、`datasets.js` 及相应前端测试；保持现有运行资格、固定回测周期与默认 OKX USDT 永续范围。
