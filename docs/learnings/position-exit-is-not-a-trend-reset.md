# 持仓退出不等于趋势重置

- **问题**：趋势策略在同一震荡区间反复产生 K1/K2。旧实现用 `positionSide == 0` 同时表示“没有持仓”和“可以寻找新趋势”，止损或超时后立即重新开闸。
- **死胡同**：提高 K1 实体、斜率、均线距离、效率或结构阈值只能零散减少候选，无法阻止同一个市场 episode 在每次平仓后重新获得资格；参数再严也没有修复状态语义。
- **有效路径**：把持仓生命周期与趋势 episode 账本拆成两个独立状态机。接受首个信号后标记 `regimeConsumed`；任何仓位退出都不得改它，只有反向强趋势或连续中性状态才能创建新 regime 并重置资格。
- **通用规则**：去重键必须绑定业务 episode，而不是绑定一次动作的生命周期；诊断重复事件时第一步检查“什么状态变化让系统重新获得资格”。
- **牵连**：`scripts/research_btcusdtp_15m_trend_regime_episode.py`、Pine V4/V5、`strong_dwell_bars=12`、`neutral_dwell_bars=8`；不改变执行和真实订单。
