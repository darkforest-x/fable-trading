# 图表周期必须贯通到同一种原生时间边界

- **问题**：模拟盘菜单增加 12H 时，历史快照、实时流、翻页、缓存、成交标记和均线各有周期映射；只改菜单会回退到其他周期或让均线把每根 K 线都判成缺口。
- **死胡同**：单独用 urllib 直连 OKX 返回 403，不能据此判定项目行情源不可用。按现有客户端路径读取成功；也不能把 `12H` 与 `12Hutc` 当成相同数据，它们的开盘边界不同。
- **有效路径**：沿用页面日线的 UTC 口径，将展示值 12H 显式映射到 OKX `12Hutc`，历史、实时 REST 和 WebSocket 一致；以 43,200,000 毫秒校验时间戳，并在缓存恢复和分页时拒绝另一种原生周期。预加载与 URL 解析使用同一份可选周期集合。
- **通用规则**：增加图表周期先确认原生标识、时区和步长，再沿冷启动、实时合并、持久缓存和绘制链路逐项核对；用错误边界的反例验证拒收，而非只验证菜单文本。
- **牵连**：`yoyo/monitor/monday_candles.py`、`monday_chart_history.py` 及 `static/` 下的 paper、startup、feed、history、cache、range/reclaim chart 模块；本次仅扩展按需图表，不扩大扫描周期或改变策略。
