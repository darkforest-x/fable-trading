# 比较趋势退出先固定入场风险与保护生效时钟

- **问题**：小止损图形能显示很高R，但无法证明能实际持有整个趋势；比较退出时很容易同时换风险或偷用当根极值。
- **死胡同**：本轮不复用只接受next-open中性退出的旧组合引擎来接盘中stop/TP；那样会把不同成交合同混为一谈。先用同根high提高移动止损再用low触发，也无法由OHLC确定先后。
- **有效路径**：全部退出使用同一next-open入场与2信号ATR初始风险。旧保护先执行，收盘产生的新保护下一根生效；止损缺口用更差open，同根不明先后保守SL。intrabar出场的未知high不计为已证实MFE。各退出共用随机control起点。
- **通用规则**：高盈亏比必须区分路径上界、实际退出和成本后权益。相同风险和信息时钟先固定，再讨论能否拿住赢家。
- **牵连**：yoyo/evaluation/altcoin_accounting.py、altcoin_trend_research.py；仍不含资金费率、常规滑点/冲击与清算。
