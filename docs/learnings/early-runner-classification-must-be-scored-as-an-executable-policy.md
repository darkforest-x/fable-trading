# 早期更高的趋势分类 AUC 不等于可盈利的动态止损

- **问题**：进场 2–12 根后，路径特征预测最终 `runner_armed` 的跨期 AUC 已升到约 0.67–0.71，似乎足以自动砍掉不会跑趋势的仓位。
- **死胡同**：只汇报早期分类 AUC、precision 或 recall，忽略被拒交易已经承担的入场成本和前几根价格路径，也忽略分类后只能下一根开盘退出。
- **有效路径**：对每个 checkpoint 冻结开发期模型和保留阈值，把拒绝决定延后一根开盘真实成交，并将其与未修改 runner 在 2024 和 2025–2026P1 逐期重放。分类确实更容易，但所有 60 个 checkpoint×阈值×时期组合的净均值仍为负；开发期较好的 2-bar/q50 在后两期分别为 -18.31bp 与 -17.62bp。
- **通用规则**：管理模型必须用完整的可执行策略 PnL 验收；模型指标只说明状态可分，不说明当前成交位置、成本与退出规则能把可分性货币化。
- **牵连**：`scripts/research_btcusdtp_15m_runner_isolation.py`；2/4/8/12-bar checkpoints；下一开盘退出；20bp 往返成本；时间冻结 replay。
