# 固定入口本身缺乏持续性时，不能把平均亏损全归因于退出

- **问题**：1h 大实体/吞没穿线后，小周期退出反复亏损，但部分截图在退出后继续走大趋势，容易归因于“止盈太早、止损太紧”。
- **死胡同**：在同一批入口上继续扫退出比例或确认根数；只看事后成功趋势，忽略等待期间反向的入口。V19 风险减半138次中100次恶化，仍未形成正收益。
- **有效路径**：V24 保留全251入口，先冻结随机背景，再完全脱离旧退出路径，用固定1/4/12/24h OPEN观察；只将预定4h作主检验。4h毛均约+1.01bp，不足20bp成本；成本阈值均−18.99bp，四半年皆负。配对超额+4.74bp的区间跨零。说明当前入口不能仅靠“统一延持”获得已证明的优势，而非证明一切状态依赖退出都不可能有效。
- **通用规则**：先把入口方向持续性与退出执行分开测；固定时钟不能用旧止损时刻截断，未知不能按零，四个时钟不算四倍样本。检查自身是否覆盖成本与是否优于同期背景两件事；之后才提出新的事前可观测入口条件，不把“后来走出趋势”当因子。
