# 信号止损比随机入场宽时，R 口径的"超额随机"会凭空变显著

- **问题**：2026-09-22 SPIKE V1/V12.6 在 OKX ETH/BTC 1m/3m/5m 回放。所有臂净亏，但预注册的"相对匹配随机超额R"在 V12.6 1m 为 +0.40R（p<0.001）、V1 同退出 1m 为 +2.00R（p<0.001），看起来像信号有入场能力。
- **死胡同**：直接信 R 超额与月块 p。随机入场用的是同一止损公式，但随机 bar 多落在安静时段，初始风险更窄：V12.6 1m 中位 18.9bp 对 14.1bp，V1 1m 34.1bp 对 15.6bp。固定 20bp 成本折成 R 后，随机平均成本 1.83R/2.79R，信号只有 1.32R/0.77R。R 超额量到的主要是"成本税"差异，同币同月同 ATR 桶匹配并没有把止损宽度对齐（ATR 桶是 bar 波动，止损还取决于 5 根极值与 2ATR 下限）。
- **有效路径**：并排列出目标与随机的中位风险和平均成本R；改用尺度不变的收益率 bp（净或毛）求配对超额。结果全期 bp 超额 V12.6 1m −2.3bp [−5.4, 0.7]、V1 1m −7.9bp [−16.7, 1.8]，p 0.92/0.94。报告中保留预注册的 R 表，并把 bp 表标为看到偏差后补充的诊断。
- **通用规则**：凡是用"同一止损公式"给随机入场配对，先比较两边的初始风险分布；只要系统性不同，R 口径的均值差就混入成本与赔率尺度差。以 bp 或毛收益作主比较，或把随机入场的止损距离强制设成目标的风险比例后再比 R。止损越窄（小周期），偏差越大。
- **适用范围（同日复核）**：`exp-spike-bp-random-audit-20260922-v1` 在 V10.4/V9/V12.6 的 15m–4h 账本上复查，随机止损同样更窄（如 1h 400bp 对 298bp），但成本R差只贡献 0.010–0.035R；偏差主要是小周期问题。bp 口径在大周期区间变宽的原因是尾部加权，而不是成本。见 `analysis/p1_spike_bp_random_audit_20260922.md`。
