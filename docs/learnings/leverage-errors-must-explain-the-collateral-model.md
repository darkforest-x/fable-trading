# Leverage errors must explain the collateral model

- **问题**：独立手机端按交易所上限默认 100x，但已有模拟账本仍执行逐仓 2% 规则，宽止损被拒；空止损只返回“数值无效”。
- **死胡同**：隐藏待生效条或降低仓位比例不能解除逐仓风险达到保证金的约束；直接删校验会掩盖强平先于止损的风险。
- **有效路径**：保留服务端约束，用委托价除以每单位止损距离和成本，给出严格小于临界值的整数杠杆上限。字段校验注明字段名，失败不消耗开仓次数。
- **通用规则**：先区分生效政策、保证金模式和名义敞口，再解释拒单；设计中的新政策不等于账本当前政策。
- **牵连**：`yoyo/discipline_app/policy.py`、`book.py`、`tests/discipline_app/test_service.py`；36 项测试通过，实盘强平模型仍未实现。
