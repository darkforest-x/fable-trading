# 历史开单列表必须复用全量账本查询与持仓投影

- **问题**：信号中心已有全量 R 统计和模拟持仓路径，但只有卡片，难以逐行回看参考入场、止损和退出。
- **死胡同**：仅把卡片上的信号收盘价改名为开仓价，或在当前页卡片上做历史筛选，会分别混淆确认与入场、遗漏更早记录。本次未采用这两条路径；先核对现有接口与真实字段。
- **有效路径**：列表与卡片消费同一份服务端筛选、排序和分页结果，入口共用查询状态。入场价与时间只读 `performance.entry_price/entry_time_ms`，运行中用 `current_r`，结束用 `exit_r`；未知保持缺失，不借用收盘价或峰值 R。展开详情按记录 ID 保留，查询变化即清除。
- **通用规则**：给信号页补交易历史时，先区分信号确认、模拟路径和账户成交，再核实全量分页与字段来源。不同展示方式应共享一份查询和数据，避免形成第二套统计口径。
- **牵连**：`yoyo/monitor/static/app.js`、`index.html`、`signal-history.css`、`tests/monitor/frontend_cards.test.cjs`。本次仅改展示层，保留后端成本和运行规则；未提交订单。旧 V1 测试夹具使用 `notification_policy:v1_bark_arm`，与当前 V12.8 初始化键不同，相关失败单独记录，不通过放宽生产初始化门消除。
