# 量能指标的资金流名称，不能代替数据来源

- **问题**：Liquidity Flow Surge Profile 标清算，HTF Matrix标delta，但公开路径只是成交量与K线涨跌代理；VTR Pro的量峰只染色，不参与带突破条件。
- **死胡同**：按营销名称把清算、CVD、强量峰直接算三票共振，会重复计量普通OHLCV，还会把可视样式条件误当交易过滤。
- **有效路径**：逐项追原始字段、方向分配、累积窗口以及信号布尔表达式。明确哪些是真实成交/主动方向、哪些是形状分量或成交量峰值，注明颜色与触发各自条件。
- **通用规则**：任何订单流共振先问“具体读取了哪个外部事件字段”；没有主动成交或清算数据就只能叫代理。代理可验证，但不能凭名字得到真实性和独立性。
