# 巡检恢复以连续覆盖证据验收，不能靠清除失败状态

- **问题**：容量验收中的日线公开接口短暂失败，原任务保留七个错误；补跑成功后，原始失败记录仍令一次性验收拒绝启用。
- **死胡同**：直接清零失败数会改写历史证据；只看补跑成功数，也不能证明遗漏的收盘端点已补齐。
- **有效路径**：保留原试验回执与错误，单独核对补跑的同计划游标、每段保存的端点数量、相邻区间连续性及最后游标对应的持久化结果。上市历史不足单列，且必须用上市时间验证，不能伪装为已覆盖。只有容量与覆盖共同达标才启用。
- **通用规则**：恢复显示可以覆盖当前状态，原始任务证据必须不变。启用判断读取真实账本，不能信任旧的进度摘要或 transient worker heartbeat；进程所有权以同一文件锁交接。
- **牵连**：`yoyo/yolo_workbench/store.py`、`finalize.py`、`patrol.py`；只涉及观察巡检，不改变训练、执行和实盘准入。
