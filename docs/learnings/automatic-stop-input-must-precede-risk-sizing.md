# 结构止损必须先确定，再由风险预算裁剪数量

- **问题**：1.618 快捷开单复用了按保证金额度反推 1R 止损的入口；没有读取插针，额度不足时连初始止损也为空。
- **死胡同**：继续调用旧反推接口，或只换按钮文案，无法保留影线极值。把开仓阻断复用到只读取值，也会让行情默认值依赖账户是否允许开仓。
- **有效路径**：按当前图表周期，从本周周一区间完成后的连续已收盘 K 线取最近影线触价极值；先填止损，再复用已有显式止损的 1R、保证金、名义仓位和最小数量约束。只读取值可在开仓被阻断时运行，提交门保持独立。历史缺口不能冒充“最近”，无合格影线不回退反推价格；手动输入与上下文切换使迟到响应失效。
- **通用规则**：先判定止损是策略输入还是风险预算的输出。前者不能为了凑足 1R 而移动；低于额度时允许实际风险小于 1R。复用时间周期还要核对交易所切日边界，App 的 OKX 1D 使用 UTC+8。
- **牵连**：`yoyo/data/monday_wick.py`、`yoyo/discipline_app/wick_stop.py`、`mobile/src/useAutoStop.ts`、`mobile/src/App.tsx`；原账户策略与实际下单规则未修改，读取与回归均不发送实盘交易指令。
