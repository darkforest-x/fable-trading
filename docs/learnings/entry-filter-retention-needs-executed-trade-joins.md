# 过滤信号的保留率必须按实际成交重新联结

- **问题**：WVF 入场过滤后信号数下降，但“通过筛选的原版大行情”不等于组合实际吃到的大行情。
- **死胡同**：把原版成交清单按过滤条件删行，直接统计剩余收益。它忽略了被删入场释放仓位后，后面原本因持仓而不能成交的信号会变成新交易。
- **有效路径**：三组使用同一份原始 V6 信号、原始反向退出和相同成本，各自完整回放单仓状态；按币种、周期、时间折、方向、实际入场时间联结。验证段 B12/C24 相对原版分别产生 71/70 笔不同入场键，所以同时报告“保留原版赢家”及“本组实际全部赢家”。
- **通用规则**：任何入场过滤改变持仓占用时，都必须重放状态，再计算保留率；不能把过滤器当作对已成交清单的静态筛选。MFE 与已实现净 R 也分别统计。
- **牵连**：`yoyo/evaluation/spike_v6_wvf_study.py`、`yoyo/evaluation/spike_v6_wvf_study_post.py`；实验 `exp-spike-v6-wvf-20260912-v1`。三组退出始终保留原版未过滤的反向确认，避免同时改变入场与退出两个变量。
