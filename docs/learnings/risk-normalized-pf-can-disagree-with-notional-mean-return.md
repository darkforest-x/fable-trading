# 净 R 盈利因子与平均百分比收益可以异号

- **问题**：A 股 V1 日线 276 笔自然平仓的净 R PF 为 1.0819、累计净 R 为 +15.2965，但平均净收益率为 −0.993%；V8 日线也同时出现正累计净 R 与负平均百分比收益。表面上像统计冲突。
- **死胡同**：只挑 PF 大于 1 或累计 R 正值宣称盈利，会把不同资金权重混为一谈；把两列强行改到同号则会污染原始统计。
- **有效路径**：回到已冻结逐笔恒等式：净 R = 净收益率 /（初始风险 / 入场价格）。每笔初始风险比例不同，净 R 合计和等额名义本金的百分比收益均值使用不同权重。分别复算并并列保留；本轮四组百分比均值与匹配随机超额都为负，日线微正 R 不能代替这一结论。
- **通用规则**：比较 PF、R、百分比均值和账户收益前，先写清每列的分母、仓位权重、自然平仓与截尾口径。没有共享资金撮合账时，任何一列都不能自动叫账户收益。
