# 全屏报警要隔离普通弹窗样式，并按实际动画验收

- **问题**：虽然原报警的 dialog 已覆盖视口，中央浅色卡片和微弱光晕仍没有全屏警报的视觉效果。改成红色后，全站 glass 规则又强制加回白边和圆角；扩散光环还撑出了 320px 视口。
- **死胡同**：把容器尺寸等于视口当作全屏体验，把存在 keyframes 当作动画足够明显。局部图标发光无法形成整屏冲击感；只看一张静态截图也无法验证强弱节奏、重复动画和关闭清理。
- **有效路径**：Stitch 先确认整页构图，再给全局报警单独的颜色和动效边界，让普通 sheet 规则排除它。用自托管 Motion 的 transform/opacity 驱动大面积红光、扫光和抽象扩散波，正文保持稳定；视觉层在视口内裁切。动态检查不同相位、实际播放、移动端布局、减少动态偏好和确认后的动画清理。
- **通用规则**：通知的紧迫感要通过整个画面的时间变化表达，而不能仅靠增加一个图标。验收同时覆盖静态构图、至少一个完整周期、全部退出路径；增强强度时保持文字对比和连续亮度变化。
- **牵连**：`spike-alarm.js`、`spike-alarm.css`、`glass-system.css`；Motion 的取消生命周期、原有 SSE/音频契约，以及页面小屏滚动边界。
