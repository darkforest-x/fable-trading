# 共振票数不是信息量：先检查它是否重复了基线状态机

**日期**：2026-09-05  
**类型**：架构决策 / 反直觉实验结论

- **问题**：ETHUSDT.P 15m V16 已经是稀疏趋势策略，但仍希望用 1h、4h、BTC、量能、波动与
  结构“共振”减少盘整交易。直觉上，满足的条件越多，信号应该越可靠。
- **死胡同**：把多个同方向布尔条件直接投票。V16 入场本来就要求 EMA30/SMA60 价差、EMA30
  斜率和 12 根趋势 dwell；ETH 1h/4h 及 BTC 15m/1h 同向多数只是用不同窗口重述“现在在顺趋势”。
  V17 的 3/6 票保留 91/182 笔，成本后反而从 `-22.32` 降到 `-29.61bp/笔`；4/6 票虽然样本内
  `+33.36bp/笔`，却只有 28 笔，家族置换 `p=0.2283`，没有资格作为门。
- **有效路径**：先列出基线已经编码的状态，再把候选轴分成“重复方向”与“新增状态”。每个轴必须
  单独与基线同表比较，并同时过时间 fold、匹配随机、右尾保留和多重检验；只有相对正交的轴才进入
  下一轮单变量 transport。V17 中只有波动扩张表现出这种可能性，因此没有把整个投票包搬进 V18。
- **通用规则**：**共振的价值来自条件独立性，不来自勾选数量。** 若候选只是在不同周期重复基线
  已有的趋势方向，它至多改变样本量，不应被默认视为额外证据。组合前先做条件增量表；相关布尔门
  不得靠多数票绕过单轴失败。
