# 收回确认必须同步移动入场时钟

- **问题**：首次触价研究加入“5m 插针收回”后，什么价格和区间可以算作入场后的收益？
- **死胡同**：若先用完整 5m 收盘筛选成功收回的事件，再沿用触价位或触价后下一分钟价格，筛选就使用了入场后的信息；确认 K 线自身的反弹被错误兑现。即使代码不直接调用未来收益，也会产生前视。
- **有效路径**：先固定影线定义：开盘和收盘严格位于价位原侧，极值严格穿过价位；完整 5m 收盘后才确认，从下一根 5m 开盘测量。未筛选对照也等待相同确认时刻，从而分开入场延迟与筛选差异。随机对照使用同一 5m 时钟、信号前特征和相同成本；直接从 1m 切片独立复算影线、时序和收益。
- **通用规则**：任何“确认后交易”规则，都要把最晚确认信息的可见时刻写进入场定义，并从收益窗口剔除确认过程。信号更漂亮不代表确认后仍有足够利润。
- **牵连**：`yoyo/evaluation/key_level_wick_reclaim.py`；`experiments/active/exp-btc-key-level-wick-reclaim-20261016-v2/config.json`；原 0.2% 成本、时间切分与价位首次触及身份保持不变。本轮只测试首次触及同根 5m 收回，不扩写成所有反复回踩或任意长影线策略。
