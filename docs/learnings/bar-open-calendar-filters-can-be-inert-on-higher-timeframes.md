# 时间周期切换会让按开盘小时编写的过滤器失效

- **问题**：2026-09-14 审阅 release-20260201-回放样式 的 ETH 永续 4H 表现。源码有凌晨 3 点加仓和 21–23 点禁入，容易误以为这些规则在所有周期上都有效。
- **死胡同**：仅按注释中的“香港时间”解释 `hour`，或把 4H 理解为只给同一策略降噪，会忽略时间网格改变了实际触发集合。未运行新的市场实验。
- **有效路径**：先核对 TV 当前周期、源码和实际属性，再把时间条件展开成 bar 开盘时刻。`hour` 与裸 `dayofweek` 用交易所时区；显式 `hour(time, "UTC+8")` 才是香港时区。对 UTC 整四小时网格，UTC 和 UTC+8 开盘小时都只取 0/4/8/12/16/20，因此 3 点加仓与 21–22 点禁入均不触发，周四加仓仍可能触发。图表右下角 UTC+8 不改变 Pine 的裸时间变量。
- **通用规则**：跨周期比较前列出每个时间过滤器的可达值；时间尺度、可触发规则集合和执行延迟是三个不同变化。不可把高周期表现变化全部归因于市场噪声减少。
