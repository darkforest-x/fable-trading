# 最新开仓不能从按退出时间截断的历史页推断

- **问题**：模拟盘壁纸要跟随最新资金交易，而持仓加最近 100 条已结束记录并不一定含最新资金开仓。
- **死胡同**：对前端收到的记录按 fill_ms 排序，只能找到当前返回页里的最新记录。后续大量影子交易退出时，最新资金交易可能已经被 exit_ms 排序的分页挤出去。
- **有效路径**：在后端现有完整账本读结果中独立选取 taken=1 且 notional>0 的最大 (fill_ms, id)，返回 latest_funded。前端优先合并该字段，历史选择固定到具体 ID；补充 101 条影子记录挤出资金交易的回归测试。仅增加读取字段，不更改撮合、费用或账户净值。
- **通用规则**：产品语义是最新某类事件时，必须核对接口的排序键、筛选口径及分页截断，不能把列表第一页当完整事实集合。
- **牵连**：`yoyo/monitor/monday_reclaim_paper.py`、`yoyo/monitor/static/reclaim-chart.js`、`tests/monitor/test_monday_reclaim_paper.py`。
