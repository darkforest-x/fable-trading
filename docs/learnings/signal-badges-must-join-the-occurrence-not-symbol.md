# Signal badges must join the occurrence, not only the symbol

- **问题**：顶部触价币种来自行情流，模型评分来自另一条异步处理流；同币种可能跨周、跨方向出现多个事件。
- **死胡同**：按币名拿最近一条评分或借用当前模拟账户持仓评分，会把旧事件、另一方向甚至另一个账户的数据贴到当前触价上。
- **有效路径**：按纽约周、币种、方向、触价K线时间精确匹配原始信号；不依赖账户是否分配资金。保留0分，区分短期待评分、缺失、评分失败和不参与评分；四位小数仅为显示，提示保留原值且不宣称胜率。
- **通用规则**：异步来源的视觉信息必须先对齐事件身份，再格式化；找不到同一事件时保持缺失，不能用相邻事件补齐。
- **牵连**：`reclaim-watchlist.js`、`monday-list-model.js`、模拟盘信号快照与精确匹配回归测试。
