# R 阈值的浮点等号也会推迟跟踪启动

- **问题**：PEPE 浮盈达到 5R 后仍打初始止损的案例中，发现十进制恰好 5R 被浮点计算成略低于 5，因而尚未启动跟踪。
- **死胡同**：只校验价格止损是否碰到 tick，或把未启动全部归因为“只有影线超过 5R”。价格比较正确并不能保证除以风险后的 R 阈值比较正确。
- **有效路径**：保留现有指标对应的冻结账本；单独以极小容差筛查，并逐个用十进制入场价、整 tick 初始止损、15m 收盘价证明触发点恰好为 5R。原方案 9 笔信号提前启动，其中仅 1 笔改变兑现，累计净 R 差 +1.01724；不能借此推翻整体亏损结论。
- **通用规则**：价格障碍、指标阈值和 R 阈值是独立数值边界，均需做等于阈值的测试。诊断版本与原始账本分开，实际 Pine 修订仍须单独版本和原生复核。
- **牵连**：`yoyo/evaluation/pepe_range_native.cpp` 中 R 触发比较；`yoyo/evaluation/pepe_range_recovery.py` 的十进制敏感性核验；`results/recovery_v1/arming_boundary_audit.json`。本次未修改原指标和既有参数网格。
