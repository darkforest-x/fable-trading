# 先突破后确认需要持续状态，不能只记最近事件时间

- **问题**：V9 框内规则只覆盖 V9→突破，漏掉突破后连续站在线上→V9。
- **死胡同**：扩大六根配对窗口既会纳入跌回线下的失败突破，也无法表达“持续在线上”。本轮不采用这种替代。
- **有效路径**：独立保存冻结线与突破时点，逐根收盘验证；第一次失守永久销毁证据。新 V9 当根只消费仍存活的证据，按框去重，并与旧窗口规则隔离消费状态。
- **通用规则**：路径条件必须逐步验证；两个端点在线上不能证明中间一直在线上。
- **牵连**：本周期与已收盘上级证据、数据断档、寿命、候选池清理、已用机会去重。收益改善需要另行验证。
