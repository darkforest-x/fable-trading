# 共享玻璃变量不能代替共享导航组件

- **问题**：1.618 与信号中心虽引用相同玻璃变量，SPIKE 入口仍一小一大、一白一蓝。浏览器实测旧首页入口约 70px，信号页 112px。
- **死胡同**：只收敛透明度、阴影和边框，仍让首页隐藏全局导航并渲染自己的字形闪电与菜单。两个 DOM 拥有者保留了不同尺寸、字体和交互；不同底色又会透过同一玻璃放大差异。
- **有效路径**：删除首页独立菜单及专用事件监听，让它直接显示全局导航。统一 SVG 图标与中性底色，并为行情条、历史回放和专注模式适配同一个入口。线上跨路由实测位置、112×44 尺寸、字体、玻璃背景、边框、阴影与滤镜完全相等。
- **通用规则**：跨页面视觉不一致先查实际 DOM 拥有者、可见性覆盖与背后底色，再查设计变量。验收要在相同主题、视口和交互状态比较计算样式；焦点环动画不能误当成材质差异。
- **牵连**：`index.html`、`spike-navigation.css`、`design-tokens.css`、`monday-reclaim-paper.js/.css`、`strategy-backtest.css`。Stitch 先行；保留手机回放顶栏空间、Escape 焦点回归和双击专注模式。
