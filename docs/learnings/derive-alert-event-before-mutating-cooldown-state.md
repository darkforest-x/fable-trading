# 冷却状态应在事件布尔值固定后更新

- **问题**：Notion 动能1.0能画动能标签，但底部“首次触发” alertcondition 在触发根不能为真。
- **死胡同**：把看得到 label 当作相同名字的报警也正常；忽略脚本按顺序赋值的语义。
- **有效路径**：源码先更新 lastOscUpBar，再用同一 bar_index 计算冷却条件，差值变成0。先计算事件布尔量，再用同一布尔量画标签、报警、更新状态。上方独立的 osc>=90 报警不受这个问题影响，不能统称所有报警失效。
- **通用规则**：同一事件的输出共用更新前固定的布尔值；用事件时间序列验证，不凭图上出现标记判断报警正确。
- **牵连**：原 Notion 源快照 `experiments/active/exp-useless-multiscale-case-20260909-v1/source_momentum_v1.pine`。本轮只核查和复现，未改用户 Notion 或已安装 Pine。
