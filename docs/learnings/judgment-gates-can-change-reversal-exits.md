# 判断门会同时改变入场与反转退出

- **问题**：六均线交叉门在 2023 把收益大幅提高，同时交易数减少、持仓中位数从 46 根升到
  144 根。若只看通过候选与胜率，很容易把全部改善归因于“筛掉了坏入场”。
- **死胡同**：把门控后的动态账本当成原账本的交易子集。策略以反向信号执行平仓并反手；拒绝一条
  反向信号不仅不新开仓，也会让旧仓继续持有，因此后续 entry、exit、cooldown 和复利路径全变。
- **有效路径**：所有判断门都跑完整状态机，并同时报告接受候选数、交易数、持仓 bars、反转退出数、
  去最大交易收益与逐年结果；若要声称“入场因子”，另做保持原退出信号不变的 entry-only 消融。
- **通用规则**：有反手语义的策略测试任何 signal gate，第一步先问“被拒绝的反向信号是否仍平仓”；
  未冻结这一契约前，只能称为信号资格策略，不得称为纯入场筛选。
- **牵连**：`scripts/optimize_pine_eth_15m_cross_count_tbsl.py`、
  `scripts/replay_pine_eth_15m_judgment_gate.py`、`opposite_signal_action="reverse"`。
