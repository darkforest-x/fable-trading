# 持仓等待小周期恢复，不等于空仓等待入场确认

- **问题**：1h K2 可以已拒绝小时均线，但入场时原生5min仍反向；旧系统随后立即按反色退出。
- **死胡同**：仅改成等真正同向→反向才平仓。V5让K2胜率4/55变8/55，但净均值仅−22.92到−22.45bp；9笔未恢复方向便先触及硬止损，增加的损失抵消了其余改善。
- **有效路径**：分别核对“已持仓但尚未武装退出”和“仍空仓未满足入场”两本账，再做同母机会的单变量比较。V5的33个初始反向、24个后来恢复、9个未恢复三者信息时点不同；只有第一个可在原入场时使用。
- **通用规则**：看到确认前亏损，下一假设应比较入场时机而非无限延长持仓。保留未入场零值、未知值、错过赢家和共同截止时间。不能把事后24个恢复者筛出来当已验证入场策略，更不能只报胜率翻倍。
- **牵连**：V5 `results/summary.json` 与逐笔配对；原固定20bp、K1极值止损和母72h时限。直接K1仅4/251初始反向，故这个修正不是直接系统整体亏损的主要解释。
