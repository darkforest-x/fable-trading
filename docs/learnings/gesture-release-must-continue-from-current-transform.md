# 释放手势必须接续当前位置，不能先归零再关闭

- **问题**：抽屉拖下 100 像素后松手，会向上回弹，再淡出；切页手势释放后又等待出场和重新入场两段动画。
- **死胡同**：缩短动画时间无法消除方向反转。原代码先把拖动偏移设为零，再开启仅移动 24 像素的关闭动画；React 重挂载与模糊背景进一步增加切页负担。
- **有效路径**：每帧只写一次位移，关闭从当前偏移连续滑出；短拖回弹，明确向下的快滑可关闭。只在手势开始读取尺寸，菜单释放立即切页，保留实例；去除抽屉、遮罩和导航底板的动态模糊采样。输入、滑杆、图表手势和提交中的关闭锁继续独立。
- **通用规则**：记录松手前后实际合成位移，验证方向连续，再谈时长和缓动；确认取消、减少动态效果、键盘焦点与忙碌状态，而非只看单张截图。
- **牵连**：`Dialog.tsx`、`sheetGesture.ts`、`useSwipeNav.ts`、`performance.css`。Stitch 本次 300 秒超时，Owner 明确豁免后沿用已确认样式；没有把超时当成设计完成。
