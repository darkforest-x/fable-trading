# 启动进展不能借用颜色状态或影线时钟

- **问题**：在既有逐5分钟变色退出中加入“一小时没启动就退出”，很容易把管理均线缺失、盘中冲高或边界收盘错当作启动证据。
- **死胡同**：复用入场前seed颜色、持仓MFE或同一根high来判断0.5R，会统计尚未持有或无法确认的价格；把颜色reset同时重置进展，会让已启动交易重新触发超时。只比较被提前平掉的单又会遗漏删掉的盈利机会。
- **有效路径**：另建只接受持仓后完整raw5收盘的累积标记，E+5到E+60闭区间；到过固定0.5初始R即永久停用deadline。先处理已触发止损、真实open的gap和原退出，再检查超时。原价缺失是未知，管理色缺失不伪造价缺失；对照保留全部原始母机会，未改变的单为零差。
- **通用规则**：新增时钟先写明观测完成时间、触发顺序和退出成交时间；“原规则退出”与“新增早退”有可检验的单调性：只可提前，不可延后。规则未触发时全部旧结果列应恒等，不只比较净收益。
- **牵连**：yoyo/layers/l3_backtest/hourly_impulse.py；V11 PROJECT_PLAN和合成边界测试。该工程结论不表示60min/0.5R有效，更不代表盈利；需在相同251母和固定154组三对照中单独回放验证。
