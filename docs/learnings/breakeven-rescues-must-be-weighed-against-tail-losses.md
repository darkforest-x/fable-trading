# 保本救回的单数必须与截断大赢家的金额一起计算

- **问题**：PEPE 的 3R 含成本保本救回 190 笔亏损，看起来像明显改进；但整体改善只有 37.36R，2026 年反而下降 23.16R。
- **死胡同**：用“多少笔不亏了”衡量保本，或看到胜率从 12.7% 升到 22.8% 就接受升级。大量新增赢单来自保本价向盈利方向按 tick 取整后的微利，少数被截断的趋势赢家足以抵消大部分收益。
- **有效路径**：固定入场、风险、成本和时间边界，逐单配对原退出与新退出。190 笔改善 +282.58R，27 笔恶化 -245.22R；原来兑现 10R 的 54 笔只剩 44 笔，兑现 20R 的 15 笔只剩 13 笔。另将双方共有的 5R 浮点修正 +1.02R 独立于保本收益。
- **通用规则**：退出优化必须同时列出救回亏损的金额、牺牲赢家的金额、长尾保留率与时间分段；新增胜率和事后最高 R 都不能替代净收益检验。
- **牵连**：`experiments/active/exp-pepe-range-be3-20261020-v1/` 与 `yoyo/evaluation/pepe_range_breakeven.py`。本轮仅15m收盘触发、下一5m生效；未检验盘中触发或其他阈值，不修改原Pine默认值。
