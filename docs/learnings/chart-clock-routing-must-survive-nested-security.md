# Bind chart-selected entry clocks to main_period across nested requests

- **Problem**: The owner removed V2.9's entry-timeframe selector. A5m chart must use5m entry arrows, a15m chart must use15m arrows, and other charts must show confirmation context without trade frames. The trade engine itself always executes in a requested5m context.
- **Dead end**: Replacing the input with `timeframe.period` risks binding the router to the engine's5m request. A15m chart can then appear correctly labeled while admitting5m trades. Gating drawings alone also retains unnecessary trade computation on unsupported chart periods.
- **Effective path**: V2.10 uses `timeframe.main_period`, explicitly permits only `"5"` and `"15"`, and combines that permission with the existing default-off user switch before requesting the trade engine. It retains the entire source below `txStopBars` byte-for-byte, including H1 watch, repeated independent admission, structure stops,15m management and viewport rendering. Unsupported periods use the existing cleanup path.
- **Evidence**: Native PEPE15m common interval contains18 ended trades, no off-quarter entry; time/price/exit signatures10213286820/2766965/5107601820 match V2.9's15m mode. Native5m contains112 ended trades,79 off-quarter entries; signatures377951785130/102975343/189007839100 match V2.9's5m mode. Native1H with the user switch on reports enabled=false, frames=0, hasTx=false. Source default remains off; the unnecessary selector is absent from native settings.
- **General rule**: Separate chart identity from requested execution context, and verify actual event timestamps rather than captions alone. Changing the display routing must not change stop or management clocks. Different available history lengths do not invalidate parity on the same completed interval.
- **Scope**: `yoyo/evaluation/pine/monday_range_v2_10.pine`; prior versions/private scripts preserved. No orders, alerts or trading-admission filters changed. Official reference: https://www.tradingview.com/pine-script-docs/concepts/chart-information/.
