# 基础币数量已定义仓位时，杠杆只改变保证金

- **问题**：Notion 任务 54 的手动模拟开单需要支持选择杠杆，已有账本和开仓数量以基础币计量。
- **死胡同**：不能再将基础币数量或价差盈亏乘以杠杆，否则同一仓位会重复放大风险；也不能把手续费改按保证金计算。本次没有采用这两种写法，以相同数量、不同杠杆的多空对照检查防止它们进入实现。
- **有效路径**：开仓保存固定整数杠杆，保证金为入场名义金额除以杠杆，部分平仓按剩余数量释放；盈亏仍为方向乘以价差乘以数量，费用仍按成交额。旧仓位迁移为 1 倍；旧请求回执只在读取时补默认值，保留原始记录与重试幂等性。
- **通用规则**：先确定输入是基础币数量、名义金额还是保证金，再决定杠杆作用在哪个转换步骤。用相同完整仓位在不同杠杆下的手续费和绝对盈亏一致、保证金不同作为验收不变量。
- **牵连**：`yoyo/research_workspace/paper_desk.py`、`paper_desk_api.py`、`yoyo/monitor/static/paper-desk.js` 及对应测试。1–125 倍只是本地模拟范围，不代表交易所各合约上限；仍未模拟资金费、维持保证金及强平，未授权任何真金操作。
