# 压缩记忆窗必须包含完整的连续压缩段

- **问题**：研究“启动前12根内有连续3根压缩”时，用三连压缩结束标记再向前滚动12根，会误纳入从第14根开始的压缩。
- **死胡同**：只检查结束标记是否在窗口内，或者在测试中手工把最终压缩许可设为 true；这并没有验证整段是否符合语义。
- **有效路径**：直接检查信号前 `[t-12,t-1]` 内完整的三根连续段。测试允许最左三根、拒绝越过左边界的三根、拒绝依赖当前信号根的三根，并检查离散压缩不能替代连续段。
- **通用规则**：把用户说的“此前N根内形成某结构”写成完整结构的起止边界，而不是仅限制检测标记的日期。信号当根可能已经释放扩张，应保留此前的压缩记忆。
- **牵连**：`yoyo/evaluation/spike_v6_bb_squeeze.py`、`tests/test_spike_v6_bb_squeeze.py`；BB200研究的3根连续/12根历史定义。此修正在读取组合收益前完成，不是看到赢家后调整窗口。
