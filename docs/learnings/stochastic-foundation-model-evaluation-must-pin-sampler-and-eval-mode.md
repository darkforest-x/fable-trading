- **问题**：同一组 K 线经过 Kronos 会因温度、top-p、采样条数、随机种子和模块模式而得到不同路径；只写模型名不能复现特征。
- **死胡同**：照抄 README 的 `T=1.0, sample_count=1`，依赖进程随机状态，并假设 `from_pretrained()` 会自动切到推理模式。
- **有效路径**：固定代码、模型与 tokenizer 修订和哈希，显式调用两次 `eval()`，固定所有随机种子，并把完整采样配置写入可拒绝漂移的合同。
- **通用规则**：凡是从概率生成模型派生数值特征，采样器与运行模式都是模型身份的一部分；没有它们的结果只能归属于一次不可复现的抽样。
- **牵连**：Kronos 历史六特征、任何生成式时序模型、蒙特卡洛路径、批处理恢复、跨机复现和性能基准都必须带相同运行收据。
