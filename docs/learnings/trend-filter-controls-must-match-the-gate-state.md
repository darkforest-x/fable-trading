# 趋势过滤的随机对照必须匹配门控状态

- **问题**：评估只允许顺 VIDYA 当前方向入场的过滤器时，普通的同币、同方向、同周和同波动桶随机入场，仍可能落在相反趋势状态，无法把过滤器的挑选作用与趋势状态本身区分开。
- **死胡同**：直接沿用不含趋势状态的基线对照，会把“只在某状态交易”的收益差异一起算成筛选效果；这回答的是状态分布与入场选择的组合问题，而非门控候选相对同条件随机入场的增量。此处没有把这种比较冒充为门控检验。
- **有效路径**：在信号收盘时记录因果可见的 VIDYA 状态；只从同币、同方向、同 UTC 周、同研究 fold、同 ATR/close 桶且同 VIDYA 状态的时间点抽取随机入场，并重放相同的序列退出和成本。无门控分支仍与冻结 V12.9 成交账本逐笔核对。
- **通用规则**：门控改变候选资格时，对照组也要满足同一时点可观察的资格状态；其余匹配维度再用于控制时间、波动和品种差异。所有资格都用入场时已知信息定义。
