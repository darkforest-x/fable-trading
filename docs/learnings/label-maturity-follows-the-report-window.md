# 标签成熟门必须对应当前报告的截止点

- **问题**：前段随机对照需要在 split 前结束，但把同一门带入全期汇总，会错误删除已经在全期结束前平仓的对照。
- **死胡同**：全期直接复用前段成熟过滤，虽然更保守，却改变了全期应有的匹配样本集合。
- **有效路径**：只在 earlier 报告应用 split；full 和月度按已闭合的全期账本计。用一笔跨 split 的随机对照验证前段排除、全期保留；保留修正前 summary_v2，最终使用 summary_v3。
- **通用规则**：先确定这个表的观测截止时点，再判断标签是否成熟，不把一个时间门应用于所有视图。
- **牵连**：V12.6 报告聚合器。只修正全期/月度随机参照集合，不改回放、真实策略收益、后段检验或成本。
