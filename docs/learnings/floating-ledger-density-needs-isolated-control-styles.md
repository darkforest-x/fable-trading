# 悬浮交易簿的密度要隔离旧标签栏样式

- **问题**：1.618 模拟盘交易簿顶部占约 175px，300px 宽的面板里近半空间被标题、标签、搜索及说明占用；触价评分只有展开详情后才能看到。
- **死胡同**：组件已有较小 padding，单看本地 CSS 会误以为布局紧凑。通用 `.rp-tabs` 同时命中多个旧页面样式，叠加了不透明底色、边框和间距；压低触控高度也会损害手机操作。
- **有效路径**：读取实际 computed style 和边界，给交易簿使用独立 `.rp-ledger-tabs`，标题与搜索合并，说明移至列表尾部。保留 44px 控件，将顶部压到 107px。原始评分在折叠行显示，严格用数值 `>0.5` 强调；浅色模式使用有默认值的主题变量。
- **通用规则**：跨页面复用短类名时先检查完整级联。信息密度优先通过合并层级、去重和重新分配空间改善；视觉阈值须与交易门槛分离，并覆盖等值、缺失值和舍入边界。
