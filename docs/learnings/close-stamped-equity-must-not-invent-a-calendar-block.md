# 零点收盘不能凭空增加一个独立月份

- **问题**：按月份聚类比较两个交易组合时，上一年最后一根K线的收盘时间恰好是1月1日00:00，直接按收盘时间分月会让一年出现13个统计块。
- **死胡同**：直接strftime收盘索引，把年末最后一根的净值变化放进下一年，会改变置换p值分辨率；本轮合成检查在真实行情评估前捕获该边界。
- **有效路径**：收盘净值差按该K线所属月份聚合，即分组键取close_time−1ns。验证2025全年恰有12个月块，并验证各月增量之和等于相同初始资金的最终净值差。
- **通用规则**：统计分组需说明时间戳表示区间起点还是终点；切点的单根观测不能增加虚假的独立样本量。
- **牵连**：`imacd_startup_research.monthly_increment`，统一54袖套逐K现金/持仓权益；匹配随机alpha与过滤相对P00增益分别检验。
