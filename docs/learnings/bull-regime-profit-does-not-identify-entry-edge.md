# 强势阶段赚到的钱不能单独证明入场优势

- **问题**：本轮固定Donchian在2023—2024组合+19.20%、强势时段贡献+10.37pp，单看这两项很容易宣布适合下一轮山寨季。
- **死胡同**：事后挑上涨月份会把市场普涨当作信号贡献；仅把市场状态事前定义也不够，均线上方的状态仍可能滞后于拐点，2025同一强势规则下D贡献-2.22pp。
- **有效路径**：固定状态定义、保留全部月份，并用同币/同月/同因果波动桶/同状态/同决策小时随机时点、同退出和风险预算对照。开发随机D组合+23.55%，验证随机+3.01%而D为-2.87%；两折月均等风险配对超额分别-26.41/-24.75bp。三政策都保留未通过，未改参数重搜。
- **通用规则**：应对未来行情的证据必须同时回答“上涨时参与多少”和“相同市场条件下选时是否增加价值”；低资金占用带来的低回撤也不能冒充入场预测优势。
- **牵连**：`experiments/active/exp-altseason-donchian-ewmac-20260910-v1/results/manifest.json`、`analysis/p1_altseason_donchian_ewmac_20260910.md`。52币便利/幸存者池、0.2%静态成本未含资金费，2023—2025并非研究者盲测；结论仅适用于这三个固定改编。
