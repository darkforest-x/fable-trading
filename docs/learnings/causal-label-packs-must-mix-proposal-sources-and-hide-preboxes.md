# 因果标注集必须混合提议源并隐藏部分预框

- **问题**：用旧检测器为新周期任务批量预标，容易把旧模型的漏检、开火密度和时间尺度偏差复制成新模型的“真值”；若图片右侧还带有未来 K 线，人工框会继续变成事后标签。
- **死胡同**：只收集旧模型命中的窗口，或直接把旧模型框当金标。这样得到的是 teacher imitation 数据，不是在验证 ETH 3m/5m/10m 的盘口可见目标；提高置信度也不能消除选择偏差。
- **有效路径**：模型侧候选图固定以候选 bar 为最后一根，只渲染当时可见的 200 根 K 线；候选同时来自旧模型 exact-tip、因果数值规则、未来跌幅发现样本和按月份/波动/趋势分层的随机背景。旧模型只产生 Label Studio prediction，并随机隐藏一部分预框。人工最终验真可使用含未来的独立复核视图，但必须按[人工验真可以看未来，但模型输入必须从截止时刻重渲染](human-review-may-see-future-but-model-input-must-be-re-rendered.md)重新生成模型侧训练图。
- **通用规则**：跨周期或跨品种迁移时，旧模型只能做提议器，不能定义采样全集或标签；至少保留一条独立正例发现路径、一条匹配背景路径，并对预框做盲化子集。候选选择和人工标签可以使用未来结果做 target discovery，但未来信息不得进入模型侧图片、特征或预标推理。
- **牵连**：`scripts/build_eth_short_tip_label_pack.py`、`datasets/eth_short_tip_label2000/manifest.csv`、后续 ETH short 金标审计与 train/accept 时间切分。标注完成后应先按 source 和 `v10_prebox_visible` 分组报告正例率、改框率和拒绝率，再决定是否扩大到近两年原生 3m/5m 数据。
