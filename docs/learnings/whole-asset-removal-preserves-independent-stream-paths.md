# 整币删除能复用独立交易流，但名单不能由被评分的未来决定

- **问题**：Owner 想按胜率、平均净 R、PF 排除币种；已有完整串行账本，是否必须重新逐 bar 回放？
- **死胡同**：不能照搬单条入场过滤的“从旧交易表删行”。过滤某些信号会改变持仓及重入；也不能仅因整币删除可计算，就把用全期成绩选出的名单当成当时可执行。
- **有效路径**：先确认每个交易流独立、没有共享资金/总仓位/相关性约束，再将某个底层资产的所有流整组移除。其余流的入场、出场及匹配随机控制完全保留，净 R 严格满足保留加删除等于原账本。另将评分窗口固定在测试窗之前，只用已结束交易生成名单。
- **通用规则**：先画清被删除对象与保留对象之间是否存在状态依赖；没有依赖才能做精确账本子集统计。统计可复用与选择是否因果是两条独立检查，不能互相代替。
- **牵连**：`yoyo/evaluation/spike_v9_asset_exclusions.py`；`analysis/p1_spike_v9_asset_exclusions_20260915.md`。本轮三条 V9 名单事后都有改善，前一年定名单后一年却都恶化；前视原则见 [排名窗必须提前结束](symbol-ranking-window-must-end-before-the-trading-window.md)。存在共享账户或动态名单时，本结论不适用。
