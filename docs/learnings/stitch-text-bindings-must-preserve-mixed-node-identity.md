# 设计稿的数据绑定必须识别图标旁的原始文本节点

- **问题**：Pro 已接入真实后台，但部分状态标题仍显示 DMA、硬件健康分等设计样例；负涨幅还可能被原稿的青色类覆盖。
- **死胡同**：只登记叶子元素会漏掉图标与文字混排的节点；直接覆盖父元素会删除原有图标和组件结构。追加错误颜色也不能保证覆盖原有的强调色。
- **有效路径**：挂载前登记叶子文本与混排文字节点的原始身份，后续按原始标签更新文字，保留其父组件。加载阶段先去掉无依据的成功断言；状态颜色互斥切换，浏览器核对计算样式。
- **通用规则**：保真接入须分别核对原始结构、字段语义、等待状态和状态样式；接口返回成功不能证明页面中的示例文案已经被替换。
- **牵连**：`yoyo/monitor/static/pro/core.js`、`app.js`、`runtime.js`、`market.js`；Stitch 原始 HTML、DESIGN.md 和旧版页面保持不变。
