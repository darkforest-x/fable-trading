# 临时预警参考不应自动获得长期抑制后续提示的权利

- **问题**：V3 同段去重方案 A 在早预警出现时就建立长期参考占用；父事件超过三根仍未确认，参考却继续阻止后来新的预警。
- **死胡同**：只延长冷却或看参考是否存活，会把“尚待确认的观察机会”和“已经确认的趋势”混成同一状态。弱预警可能先压住后来的强突破，该强突破收盘又提高旧参考的保护线；旧参考之后退出时才出现晚箭头。不能简单说它永远不再提示，也不能把确认当成重新成交。
- **有效路径**：在第三项固定研究假设 C 中，将 `reference_active` 与 `suppression_active` 分开。观察仍即时留下记录；三根内确认且参考存活才取得抑制权。未确认到 age4 取消临时参考，取消不生成止损成交。确认不改旧 entry/risk，已死父的后来确认也不能复活。合成测试验证生命周期；是否减少噪音且保留启动仍由另行冻结的市场评估决定。
- **通用规则**：每个资源占用状态都应明确“谁授予、何时过期、何种证据可升级”。观察、确认、成交、提示抑制不能共用一个含义不明的 active 标志。
