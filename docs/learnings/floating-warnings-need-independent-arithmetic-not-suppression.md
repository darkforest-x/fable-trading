# 浮点警告应以独立算术核对，不能直接屏蔽

- **问题**：ETH 4h 随机对照的月簇符号翻转检验，在本机 NumPy 矩阵乘法中报告 divide-by-zero、overflow 和 invalid，输入却都是有限小数。
- **死胡同**：仅凭输出 p 值看起来正常就忽略警告，会把潜在错误留在统计结论里；直接重跑交易又不能定位这个独立的统计运算问题。
- **有效路径**：读取冻结交易账本，保持同一随机种子、同一符号矩阵和同一月份向量，将矩阵乘法独立改算为逐项乘积求和。检查输入和两种输出全部有限，最大差异小于 1.4e-17，两段 p 值逐个一致，再替换求和路径并保留旧输出。
- **通用规则**：数值库报警时，先检验有限性、量级和独立公式；只有证明影响范围后才能说结果没有变化，不要用过滤警告代替验证。
- **牵连**：`yoyo/evaluation/pine_allin_eth4h_replay.py`、`yoyo/evaluation/pine_allin_eth4h_verify.py`、本轮 `results/independent_validation.json`。未修改交易信号或收益账本。
