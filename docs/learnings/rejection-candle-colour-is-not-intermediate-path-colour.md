# 拒绝影线自身变色不等于中间路径失效

- **问题**：K2 的实体在均线正确侧，长拒绝影线却可让 HL2 落到另一侧；如果先检查变色，就拒绝源码允许的 K2。
- **死胡同**：把“严格中间 K 线必须同色”无差别套到 K2，或用截图颜色代替源码判断顺序，会悄悄新增信号过滤器。
- **有效路径**：按 owner Pine f_findBestK1 的真实几何先判断候选是否为 K2。只有不合格的候选才成为后续等待的中间棒，再检查收盘与 HL2 颜色。
- **通用规则**：形态里不同位置的 K 线有不同职责，转写状态机前先区分候选确认棒与严格中间棒；同名“颜色”不能默认同一门槛。
- **牵连**：owner-causal-v2 Pine lines98--174、yoyo/data/hourly_impulse_k2.py 的边界测试；gap1--8 是明确研究变化，不冒充旧 gap2--8 回放。
