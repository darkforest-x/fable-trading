# 统一表格组件之前，先统一各来源的行结构

- **问题**：研究工作台的新回测表正常，历史实验 CSV 对照却全显示“未记录”；HTTP 和目录读取都成功。
- **死胡同**：只检查表格数量、列名与行数，无法证明每个单元格被正确读取。旧目录返回数组行，新任务返回以列名为键的对象行，而前端统一使用 `row[column]`。
- **有效路径**：在 CSV 接入层就转换成列名对象，与新运行保持同一契约；缺失单元格保留 null，重复列名或超宽行明确拒绝。测试断言实际字段与值，再用浏览器打开真实历史实验的对照表核验。
- **通用规则**：合并多个结果来源时，用同一真实字段从文件走到最终页面；结构数量检查不能替代数值显示检查。
