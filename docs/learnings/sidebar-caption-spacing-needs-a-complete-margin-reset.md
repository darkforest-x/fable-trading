# 侧栏分组标题要先清除旧外边距，再调整对齐

- **问题**：2026-10-15，工作台的“日常交易”“学习与复盘”标题夹在图标和菜单文字之间，与首项的距离也过大。浏览器确认 `.sidebar-label` 的 `margin:0 12px 14px` 与 `.nav-group-label` 的 `padding:0 12px 7px` 同时生效。
- **死胡同**：没有试错改版。只检查最后加载的规则会漏掉仍然生效的旧 margin；继续加 padding 或统一缩小整个菜单，会保留错位来源并影响点击区域。
- **有效路径**：在当前分组标题规则显式清零 margin，左内边距按菜单的 12px 内边距 + 18px 图标 + 12px 间隙计算为 42px；使用 16px 行高、4px 底内边距和正常字间距。1280px 桌面与 390px 手机菜单实测，三个标题的文字左缘均与菜单文字同为 58px，标题盒与首项之间为 4px。16 项已有导航、平台与主题检查通过。
- **通用规则**：排查组件间距时先看浏览器计算样式和实际几何位置，检查 margin、padding 与父级 gap 是否叠加；让修正落在当前组件规则里，并核对窄屏覆盖。
- **牵连**：`yoyo/monitor/static/styles.css` 提供旧标题样式；修正在 `yoyo/monitor/static/workbench-polish.css`，没有改菜单路由或交易逻辑。
