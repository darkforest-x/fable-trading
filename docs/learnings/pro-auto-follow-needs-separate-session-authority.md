# 自动跟单不能伪装成逐笔人工确认

- **问题**：Pro 需要复杂实盘委托与自动跟单，既有均线执行器只接受 Owner 对单笔检测订单的确认。
- **死胡同**：给旧订单接口自动补一个确认字段，或者让两个执行器共用账户，都会把新的持续授权混进原来的逐笔授权，仓位和保护单的归属也会失真。
- **有效路径**：Pro 使用独立账户、SQLite 队列和单写者。启用预览绑定账户 UID、配置版本、规则、有效期、委托上限和累计批准风险。配置 CAS 更新同时撤销新开仓授权。旧模型与未通过准入的来源只观察，不能借新界面自动 promote。只读网关不创建可写交易客户端。
- **通用规则**：扩展执行能力前先明确授权单位及账户写者，再实现按钮。启动服务、保存配置和读取行情都不等于授权交易。
- **牵连**：`yoyo/monitor/pro/live_store.py`、`live_api.py`、`live_worker.py`；旧手动执行器与 Standard 均未改动。测试使用隔离状态和假交易所，没有实盘写入验收。
