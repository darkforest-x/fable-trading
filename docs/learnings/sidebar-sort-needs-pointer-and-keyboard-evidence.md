# 菜单拖动要验证按钮内部的实际命中

- **问题**：侧栏菜单既是导航按钮，又要支持手动排序并在刷新后保持。
- **死胡同**：在按钮外层设置 HTML draggable，属性虽已生效，浏览器实际拖动嵌套按钮仍没有改变顺序；静态检查不能证明交互成功。
- **有效路径**：仅在排序模式捕获指针，超过移动阈值后按释放位置排序；同时保留上下移动按钮、Alt 加方向键及默认顺序恢复。排序期间拦截导航点击，移动原节点保留事件绑定；偏好只接受已知分组和菜单 ID。浏览器实测拖动模拟开单到组内首位、移动分组、刷新保留和窄屏抽屉无横向溢出。
- **通用规则**：对复用已有按钮的拖动交互，验收应从按钮内容开始拖，而非只检查容器属性；始终保留键盘或点击替代方式。
- **牵连**：`yoyo/monitor/static/sidebar-order.js`、`sidebar-order.css`、`tests/monitor/frontend_sidebar_order.test.cjs`。
