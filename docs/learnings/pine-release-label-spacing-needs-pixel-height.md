# 副图启动点与说明文字应按行高分离

- **问题**：IMACD 启动处同时画菱形和有色尖角标签，二者共享 md 坐标；再叠三层粗光晕，在大趋势压缩的零轴区域合成了难辨的形状。
- **死胡同**：原来的菱形、标签尖角和光晕各自强化同一事件，整体却失去轮廓。未采用的数值偏移方案（md ± ATR）也会随副图量程放大而重新挤回零轴。
- **有效路径**：一个小圆点承担事件锚点；透明标签背景隐藏重复尖角，用多空方向相应的前/后空行把说明推离曲线，光晕线宽缩至 6/4/2。坐标与数据仍使用原来的 time/md，方向及持续根数保留在文字中。
- **通用规则**：修复注释重叠先区分“数据锚点”和“屏幕文字占位”，不要为显示间距改变信号数值或用价格尺度决定文字边距；必须在实际平台双方向看图验收。
