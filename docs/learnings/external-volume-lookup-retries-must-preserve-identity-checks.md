# 外盘身份查询的有限重试不能放松身份核对

- **问题**：大量小文件写入 NTFS 外盘期间，已迁移图片的网页读取出现瞬时 HTTP 409；第二次捕获到的响应正文明确为“无法核实外接数据盘身份”，重试恢复。首次 409 未保留正文，原因仍不能确认。
- **死胡同**：把这个响应等同于 UUID 不一致或文件损坏，会把查询失败与核对失败混为一谈；直接跳过身份检查或缓存“盘已连接”，则会漏掉拔盘、换盘。
- **有效路径**：对 `diskutil` 查询异常只重试一次，每次都重新确认挂载；拿到 UUID 后仍必须严格相等。查询持续失败、查询间拔盘、身份不符都拒绝访问。日志只记录异常类型，以便区分超时与其他查询错误，不输出系统查询全文。
- **通用规则**：只对可识别的查询故障做有限重试，不能把失败变成默认成功。恢复可用性与维持身份约束必须同时验收。
- **牵连**：`yoyo/data/external_storage.py`、`tests/test_partial_external_dataset_storage.py`；本次文件验收遵从 Owner 要求，不计算内容哈希。
