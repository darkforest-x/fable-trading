# 多周期预热要按被请求周期的根数核对

- **问题**：把已有 IMACD 指标切到 OKX:XAUUSDT.P 日线，默认模式正常显示，但自动共振面板显示“高 1W 数据不足”。同一脚本切回 4 小时，共振面板能显示日线方向。
- **死胡同**：把“日线已有完整曲线”直接当作“周线可以参与共振”，会把没有信号误判为策略不适配黄金。此次没有降低预热阈值试出信号；单看主图是否画出均线也不能验证高周期就绪。
- **有效路径**：先保留源码和参数，打开周期状态，在日线与 4 小时之间做对照；再追踪 `hIndex >= max(340, lengthMA * 10)`。它检查被请求高周期的 bar_index，而非图表累计根数。默认长度 34 下，日线自动请求周线，需要至少第 341 根已确认周 K。当前 UI 直接验证了周线不足，而日线高周期可用。
- **通用规则**：移植多周期指标到新上市品种时，先列出本周期与每个被请求周期各自需要的历史长度，区分没有形态、预热未完成、数据源缺失和运行错误。不要用未来数据、未收盘高周期或未经验证的短预热绕过门槛。
- **牵连**：`yoyo/evaluation/pine/imacd_dense_mtf_v2_1.pine` 的 `warmup`、`autoHtf`、`hKnown` 与 `showPanelDetails`；2026-09-08 的 TradingView 黄金兼容性验收。此结论解释当前行为，不改变原信号规则，也不是收益实验。
