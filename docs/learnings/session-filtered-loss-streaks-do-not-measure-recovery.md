# 时段过滤缩短连亏，不等于倍投已经回本

- **问题**：ETH3m V8 只在 ICT New York 时段开仓，费用保本的两种盘内路径下，完整历史最长连续净亏均降到 5 次，是否足以支持倍投？
- **死胡同**：只数完整止损或把保本算作整轮胜利，会把“上一单未亏”误当成“前面亏损已赚回”。只看有限资金账户的短连亏还会遗漏容量拒单和提前停机。相反，仅因净收益为负而不报告连亏改善，也会丢掉用户假设中真实存在的效果。
- **有效路径**：先按真实计划开仓时刻过滤，再重建单仓顺序，排除的信号不占仓。完整自然序列统计与有限现金账户分开；逐笔区分费用保本、净盈利、净亏损、完整初始止损，并保留累计未回本金额。2023-08 至 2026-04，纽约两种盘内假设分别有 335/334 笔，最长连续净亏都是 5；每笔毛 R 约 +0.044/+0.052，扣冻结成本后却为 -0.452/-0.444。固定 1U 风险期末 848.58/851.64U；亏后翻倍则在剩余 486.45/422.45U 时遇到下一档 512U 价格风险，停止继续加码。保本中断了连亏，但并未消除债务。
- **通用规则**：评估时段或保本过滤，同时验证完整期逐笔净收益、观测连亏、每轮债务与现金容量。以开发期预选、后期固定评估控制事后挑选；保本不能清债，跳过信号不能重置统计；历史最长连亏不是未来上限。
