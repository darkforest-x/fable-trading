# Cursor 分页必须与后台刷新串行

- **问题**：历史 raw 页面正在请求更早 cursor 页时，15 秒顶页刷新仍会并发请求同一信号族；超时后刷新可覆盖分页错误，使界面停在旧边界却没有原因。
- **死胡同**：只保留已加载数组不能避免服务端同步任务重叠，浏览器 abort 也不会取消已开始的 HTTP 处理。
- **有效路径**：分页期间把后台刷新压缩为一个队列标记，页请求结束后再刷新；分页错误使用独立状态槽。历史 raw 初始与定时刷新只请求可见的 raw 家族和 status，不读取隐藏的 YOLO 空列表。
- **通用规则**：cursor 页面和自动刷新共享同一后端资源时，先定义单一请求所有权与可见错误状态；不要把客户端取消当成服务器取消。
- **牵连**：`yoyo/monitor/static/app.js`、`tests/monitor/frontend_cards.test.cjs`；500 条页面和事件内容保持不变。
