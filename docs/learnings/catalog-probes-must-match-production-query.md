# 目录探针必须使用采集器实际请求参数

- **问题**：Gate无参数合约目录可用，但采集器添加limit=1000后返回400，导致整批数据尚未开始就中止。
- **死胡同**：把“探针成功”概括成“接口已验证”，忽略探针与正式请求参数不同；运行期间直接修改公共源码还会破坏正在执行采集器的源码SHA归属。
- **有效路径**：保存原错误；用有效无参数请求单独构建冻结目录、记录原始响应和生成器SHA，再让已提交采集器读取该目录。不静默换数据源，也不将协议错误当成市场无数据。
- **通用规则**：验证对象是完整HTTP方法、路径、参数、分页边界和返回结构，不只是接口域名。长任务运行期间修复共享代码前，先检查正在运行进程的来源契约。
- **牵连**：`yoyo/data/altseason_gate_catalog.py`、`yoyo/data/altseason_sources.py`，实验`exp-altseason-multivenue-20260910-v1`。
