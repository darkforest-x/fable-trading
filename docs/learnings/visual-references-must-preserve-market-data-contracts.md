# A visual reference cannot redefine the market universe or indicator semantics

- **Problem**: A terminal redesign reused the reference's MA7/30/120 and capped the displayed universe at 40 while loading quotes for only a few rows. The page matched the broad silhouette but violated the product's six-line and all-market contracts.
- **Dead end**: Refining colors, adding chart controls and passing pure formatting tests did not reveal the missing universe or source mismatch. Merely adding a descending-sort button would have ranked an incomplete set of quotes.
- **Effective path**: First inspect the actual source contracts. The scanner already returns warmed SMA/EMA 20/60/120 values, and the public quote cache already contains a complete fresh ticker snapshot. Expose a whitelisted read-only bulk catalog, rank the full set, retain missing/stale values as unknown, and render source-owned indicators without reseeding. Verify real browser rows and six-series readouts alongside data tests; preserve the visible list anchor and chart range during polling.
- **General rule**: Before copying a design, inventory the product's series, units, freshness, universe size and user-controlled state. A screenshot is authority for composition, not for replacing those domain facts. A full-universe operation must receive full-universe data before rendering or sorting.
- **Related code and constraints**: `yoyo/research_workspace/paper_desk_api.py`, `yoyo/monitor/static/market-terminal.js`, `chart-style.js`, `yolo-detect.js`. Public display must not create execution receipts or alter trading parameters. Daily aggregates remain explicit when source history is insufficient; complete daily bars require six closed UTC 4H components.
