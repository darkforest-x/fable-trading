# 先拆开初始风险、收益框边界和参考终止条件

- **问题**：Owner在NEAR30m等图上看到红绿框过窄，并把几根K后结束的框理解为3R止盈。旧脚本用释放K线极值确定风险，3R只是收益框初始高度下限；实际冻结还取决于触损、主线回零、结构破坏或新段接管。
- **死胡同**：直接把3R改成10R只会放大预测面积；事后把止损移到更远结构或把触损后的行情计入最大R，则会制造未能持有的盈利。把整个蓄势区反侧一律当止损也可能产生极大风险距离。
- **有效路径**：先用精确信号OHLC复原截图，再独立修改两项显示约定：释放时冻结近期结构与ATR、入场时冻结初始R；默认收益框只显示入场后实际走出的最大有利空间。保留旧模式以便比较，明确触损和参考冻结状态。检查实际Pine函数的多空、跳空、零风险、取整、止损优先、永久冻结边界。
- **通用规则**：任何盈亏比图都应回答三个不同问题：一开始承担多大风险、后来实际走多远、何时停止记账。放宽止损需显示百分比和ATR距离，不能等同于提高收益。参数是工程约定还是经时间外验证得到，必须说明。
- **牵连**：`yoyo/evaluation/pine/imacd_dense_mtf_v2_7.pine`、`build_imacd_v27_contract_probe.py`、`tests/test_imacd_pine_v27_contract.py`；不改变原始信号、通知或实盘执行。11个定向样本仅做宽度审计，不提供收益结论。
