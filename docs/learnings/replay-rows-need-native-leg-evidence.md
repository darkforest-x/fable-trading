# 回测行的入场说明和成交标记必须沿原成交谱系联结

- **问题**：资金账本只保留事件、结算收益和柱结束时间；直接画时间箭头会被读成价格，直接按策略名称补说明又会混淆主单与加仓单。HEMI 回看暴露了这两个展示层缺口。
- **死胡同**：事件键相同不代表同一成交腿；只用币种或事件联结会把主单评分／成交价贴到子单。把 1m 首次触价当成原框架精确时刻也会改变冻结研究的含义。仅把箭头文字改成“时间”无法修复错误的横纵坐标。
- **有效路径**：使用事件、方向、原入场／退出记账边界、保存的未杠杆净收益和允许的成交腿联结已有投影；歧义或缺失明确显示未留存。图表再读取原两条路径的成交文件，按旧结果的较差路径核对退出，保留原成交价及原周期区间。价格通过价格轴定位；横段及端帽表达区间，已知收盘退出保留时点。分数只读取历史值，主单与逆向 5% 加仓分开标识。
- **通用规则**：资金账本、入场条件、框架成交和图表属于不同投影。跨投影必须验证身份与时间语义；不存在的字段保持未知，不由当前规则、当前行情或结果反推。
