# 能确定何时入场，不等于证明这次入场有交易优势

- **问题**：V38 等待原生 5m 同向颜色后，63 个 K1/K2 请求有 38 个符合入场时钟，15 个先触及原止损，10 个观察截止仍未确认；容易把 15 个直接叫作避免的亏损。
- **死胡同**：把未持仓期间触及参考止损，替换成原策略实际亏损，或只计算存活确认者的表现。两者都跳过了原退出路径、等待价格改变与相同规则对照；本轮未做这样的经济计算。
- **有效路径**：独立保存 171 个请求及全部观察 trace，先完成时序审计。完整形态/对照的确认比例分别 38/63 与 65/108，接近只说明这道机制并非形态独有；不能由确认比例推断收益优势存在或不存在。
- **通用规则**：先区分可观察状态、策略决定、实际成交、净收益四个层次。确认率与失效率是状态指标；经济增量需要冻结有效期与持仓截止，再对所有原请求和原对照重算。
- **牵连**：V38 summary、events/status_counts/trace；60 分钟是行政观察截止，10/19 个 pending 不是现金收益 0。V37 仍拒绝，未把审计通过升级为盈利通过。
