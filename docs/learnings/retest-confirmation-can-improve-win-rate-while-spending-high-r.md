# 回踩确认可能提高胜率，却把高R花在等待里

- **问题**：Owner提出SPIKE信号后等突破、回踩守住、再突破才进，目标是降频、胜率与高R共同改善。
- **死胡同**：只报少做约85%–88%和全窗胜率上涨，就会掩盖追价风险。把“后来确认成功的那批锚点本来收益很高”解释成当时能知道该早进，仍然是前视。原赢家再入场也不等于保住赢家的R。
- **有效路径**：固定旧绝对stop/退出/成本，真实次开重算R，同时按原风险单位算收益、对比同锚点立即路径、匹配同确认随机请求、分开前后段。当前定义中位等6–7根，入价多付0.60–0.68个原R，风险距离扩大60%–68%；四格≥5R密度均降，后段四格均净R负。15m全期胜率改善成立，但联合目标没有达成。
- **通用规则**：确认的经济账要同时包含避开的坏单、错过的好单、买晚付出的价格和风险距离；不能只用胜率或少交易裁决。后验同锚点对比只解释成本，不是可实施的早入场筛选器；随机无确认不能重抽。
