# 交易减少可以让账户少亏，同时每笔期望更差

- **问题**：MA/Stoch退出第二轮中，6ATR止损＋2R止盈、取消反向箭头平仓的候选，在3—4月从原规则−34.91%改善为−26.10%，但每笔净均值反而由−26.21bp降至−45.86bp。
- **死胡同**：只报告总账户改善8.81个百分点，会把交易减少156→60笔、持仓延长和费用次数降低造成的总效果误读为入场优势增强；开发+7.88%也不能掩盖复查仍亏26.10%的事实。
- **有效路径**：同时报告账户收益、每笔毛净、笔数、持仓和匹配随机入场。该候选开发35笔，最长持仓16455分钟、最差单笔−10.22%；复查60笔、最差−3.67%、9连止损。相对随机净超额两段仍负（−26.90/−22.93bp），只保留“相对改善”而拒绝稳定盈利主张。
- **通用规则**：退出改变交易占用时，必须先分清“少做负期望交易”和“每次交易的优势提升”。总账户曲线、逐笔期望和匹配对照应同时出现，不用其中任何一项替代另外两项。
