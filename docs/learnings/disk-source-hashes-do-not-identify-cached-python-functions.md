# 磁盘源码哈希不能单独证明常驻Python进程执行了该版本

- **问题**：常驻观察服务导入函数后，磁盘源码被修改并提交；再次读磁盘哈希可能让旧内存函数声称执行新版本。
- **死胡同**：只比较磁盘文件与HEAD，能证明文件已提交，不能证明进程重新导入过这些文件。
- **有效路径**：模块加载时固定完整源码摘要；每次扫描先比较磁盘与加载摘要，不一致则要求重启；扫描结束再检查未发生中途变化。
- **通用规则**：常驻服务的运行身份要绑定加载版本，文件版本与运行版本不能混为一谈。
- **牵连**：yoyo/rotation/pipeline.py、CLI本地服务、来源收据与配置授权。
