# Pine 选中态会掩盖旧实例的蜡烛覆盖问题

- **问题**：同一张 TradingView 图上，点中 K 线或指标时自定义蜡烛的实体、影线和边框看起来正确，点空白处后却重新混入原生红绿样式。
- **死胡同**：继续修改 `plotcandle` 的颜色、影线和边框参数，或只看源码已保存的新版本。TradingView 的选中态会临时把对象提到视觉前层；同时，保存 Pine 新版本不会自动替换图表上仍挂载的历史实例，因此选中截图会给出“代码已经生效”的假象。
- **有效路径**：直接检查图表实例对应的 Pine 历史版本，移除旧 5.0 实例并挂载已编译的 6.0；再检查“视觉顺序”，确认“置于顶层”已生效。最后必须取消选择、点击空白处并整页刷新，三种状态下分别核对实体、影线和边框。
- **通用规则**：遇到“选中正常、取消选择异常”，第一步检查挂载实例版本与持久视觉顺序，不先改色值；Pine 视觉验收必须覆盖选中态、空白态和重载态。
- **牵连**：TradingView 私有脚本历史版本、图表布局中的指标实例、`indicator(..., behind_chart=false)`、视觉顺序；不涉及信号阈值、回测结果、ACTIVE 模型或实盘执行。
