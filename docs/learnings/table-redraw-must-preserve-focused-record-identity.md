# 列表重绘要保留焦点对应的记录身份

- **问题**：实验对照复选框每次 change 都重建整表；实页勾选后 activeElement 变为 BODY。刷新和翻页同样可能丢失阅读位置。
- **死胡同**：仅保存选中集合只保住数据，不能保住键盘位置；按行号恢复焦点会在排序或筛选后指向另一条记录。
- **有效路径**：重绘前保存控件种类及记录键，重绘后只恢复同身份控件。主动翻页则聚焦新页首条记录，表格滚动位置避开固定顶栏；记录消失时不选择替代行。
- **通用规则**：数据状态、DOM 身份和用户焦点是三个独立状态，重绘时分别处理。
- **牵连**：`yoyo/monitor/static/research.js`、`research.css`；因子、实验、任务列表共用此规则。实页验证复选框焦点、第二页首条身份和表格距顶端 80px。
