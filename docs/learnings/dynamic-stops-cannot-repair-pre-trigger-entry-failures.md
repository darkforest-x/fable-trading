# 动态止损不能修复发生在触发点之前的入场失败

- **问题**：K1→K2 交易在固定止损下为负，直觉上可以用阶梯止损、ATR trail 或结构收复来减少扫损；但最好方案只改善 0.66bp/笔，仍为 -15.42bp/笔。
- **死胡同**：只比较不同 trail 的最终均值，或只数“止损后后来到过 TP”的比例。前者看不见管理器根本碰不到哪些路径，后者忽略反弹前还会继续逆向走多远，也会把提高胜率误当成提高期望。
- **有效路径**：先按管理器触发前的 MFE 把基线拆成互斥路径，再把每个候选的逐笔差额归回这些路径；对事后恢复单额外测量“到目标前最大逆向距离 / ATR”。本例 50/100 笔在 1.5R 触发前已经止损，影线阶梯救回回吐的 +5.13bp 又被截断 3R 赢家的 -5.28bp 抵消；后来到 3R 的止损单需要额外空间中位数 0.855 ATR，0.25 ATR 只保住 4/25。
- **通用规则**：优化出场前，先回答三件事：损失有多少发生在候选规则触发前；被救路径与被截断赢家各贡献多少；任何“后来恢复”在恢复前需要承受多少额外 MAE。若主要损失在触发前，停止搜 trail 参数，转向入场池优势或可向前预测的拒绝门。
