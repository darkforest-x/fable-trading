# 复制账户界面时复用展示层，保留数据身份隔离

- **问题**：均线密集只有逐笔弹窗，无法集中看持仓和历史；直接共用信号中心数据源会重新混入另一个账户和 2%/125U 风险口径。
- **死胡同**：仅复制账户标题，或只展示系统账本，会遗漏用户自行管理的仓位/挂单，造成账户状态误判。
- **有效路径**：复用安全字段序列化、缓存失效和样式，独立 ManualDashboard/runtime 与 `/api/manual-live/dashboard`，固定 3% 总权益。交易所持仓、挂单、最近 7 天订单与系统确认记录分栏展示；历史接口失败不清空持仓；前端拒绝错误账户 scope，自动轮询且在离页时中止旧请求。
- **通用规则**：显示可见性不等于执行管理权限。全部账户仓位可只读展示，只有确认队列与账本关联的新单归系统管理。
- **牵连**：`manual_dashboard.py`、`manual-account.js`、`yolo-detect.js`；账户身份不写入前端，既有仓位仍由 Owner 管理。
