# 被过滤的样本可能缺少加分，而非受到更多扣分

- **问题**：BTC 近侧重建模型对当周三笔已知盈利做空仅放行第二笔，需要定位另外两笔的扣分原因。
- **死胡同**：只展示被拒绝样本的负贡献排名，容易把第一笔解释为“被更多坏特征压低”；实际第一、第二笔负贡献合计几乎相同，分别 −0.14151R、−0.14212R。
- **有效路径**：对同一冻结模型、同一输出单位同时保留基准、正负贡献总和及通过样本的逐特征差。第一笔主要少了第二笔在 24 小时走势和区间宽度/ATR 上的正贡献；第三笔主要多了 4 小时走势的负贡献。基准 −0.21982R，最终第一/第三仅为 −0.00785/−0.01525R，属于零门槛附近拒绝。
- **通用规则**：解释过滤原因先核对输出单位、门槛距离和加总恒等式，再看绝对负贡献与相对通过样本差异；SHAP 差值不能当作删特征或调整市场条件的实际因果效果。
- **牵连**：`yoyo/evaluation/major_1618_v2_explain.py`；`exp-btc-eth-xau-1618-models-20261031-v2/diagnostics_three_btc_shorts/`；冻结 2026Q4 BTC 净R树模型、无校准与序号特征，native 与 SHAP0.52 逐贡献误差0，加总误差1.39e-16R。
