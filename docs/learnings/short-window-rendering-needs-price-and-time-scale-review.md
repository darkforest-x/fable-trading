# 短窗训练图需要同时检查价格轴和时间轴尺度

- **问题**：Owner 发现 1,506 个盈利事件生成的训练图过扁。原 PNG 是 1280×742，预览等比例缩小，但旧渲染器的 6% 价格跨度下限压缩了低波动的 1m/3m 图；18–19 根 K 线铺满横轴又使蜡烛过宽。
- **死胡同**：只验证 PNG 哈希、标签坐标、因果截止和旧版本像素一致，并将低波动样本的扁平外观当作保留历史规格的限制。上述证据证明了实现一致，不能证明图像尺度适合新数据分布。
- **有效路径**：先检查原 PNG 与预览缩放，再把同一事件、同一可见右端、同一均线支持窗口固定，只改变价格轴生成诊断对照。XMR 3m 原图全部走势仅占 742 像素中的 132 像素。训练尚未启动；对照图单独存放，不改冻结训练数据。
- **通用规则**：跨周期或缩短窗口后，必须重新检查价格跨度、每根 K 线宽度、图形占用高度和实际推理界面的匹配。局部自动缩放也会放大均线间距，不能仅因更醒目就直接认定为正确；用同事件对照区分文件缩放与坐标尺度。
- **牵连**：`yoyo/layers/l1_detection/render.py` 的 `MIN_REL_SPAN`、`make_chart_transform()`；`yoyo/datasets/ma_profit_dataset.py` 的可见窗口；诊断工具 `yoyo/datasets/ma_profit_scale_review.py`。保持因果右端，渲染修订应另建数据版本并重算标签，不能覆盖旧数据或修改交易障碍。
