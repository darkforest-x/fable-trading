# 状态过滤的随机对照要检查共同资格与实际暴露

- **问题**：信号和随机时点各自应用同一个状态过滤器，并不保证两边有相近的参与率。此次中等推进组，原配对池中信号资格51215个，随机资格17152个。
- **死胡同**：把相对基线的超额改善直接叫作“信号赚得更多”。1H中等推进在2025年起的共同成熟比较中，增量超额为372.29R，但信号自身比基线少3.07R；变化主要体现为随机对照收益减少375.35R。自身超额的置信区间仍跨零。
- **有效路径**：在首次查看完整主结果数值前追加敏感性，要求信号与原固定随机锚点都属于同一事前状态，再重建双方队列；不补抽、不按盈亏筛选。全期中等压缩组在这一口径下信号189.93R、随机275.41R，中等推进137.77R对83.03R但区间跨零。后半段36项状态比较没有校正后显著为正的结果，同时保留实际成交数和整根K线暴露代理。
- **通用规则**：先明确比较的是完整流程利润、每个原机会的收益，还是相同市场状态下的时点优势。共同状态匹配只是诊断样本，不是能提前观察随机锚点的实盘规则；实际成交数和持有时长仍可能不同，不能称为完全等暴露alpha。
- **牵连**：`spike_v131_state_matched.py` 与 `state_match_preinspection.json`；追加时主结果文件已生成但尚未读取数值，主实验分组、对照抽样、前期选组和原结果均保留。历史重复研究，未证明实盘优势。
