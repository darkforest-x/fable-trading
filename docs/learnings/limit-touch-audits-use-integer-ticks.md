# 限价触价核验应比较整数报价单位

- **问题**：ETH 回踩研究的 random-188 原生订单在 2280.95 首次触价成交，独立核验却晚判一根；`floor/ceil * tick` 的二进制浮点结果为 2280.9500000000003。
- **死胡同**：直接比较浮点 high >= limit 会把完全相同的交易所价格判作未触及；修改原生成交或删掉这一笔会掩盖核验错误。
- **有效路径**：核验 OHLC 与限价统一转成整数 tick 比较。保留首次失败日志和原生全部成交；只重跑独立核验，要求输入、配置、原生代码不变且重建候选逐字段完全相同。新增这一精确反例的原生成交测试。
- **通用规则**：触价、最小风险及报价合法性属于离散价格契约，不能交给未经归一化的浮点大小比较；分析修复不等于执行结果失效。
