# 退出后的 MFE 不是可直接兑现的止盈目标

- **问题**：大量 3R 盈利单在未来 12 小时继续达到 5R 或 6R，看图很容易得出“把止盈直接抬高即可”的结论。
- **死胡同**：用已经到达 3R 的赢家作条件样本，并继续观察交易退出后的 `horizon_mfe_r`；这同时含有赢家筛选和退出后未来，不能证明整单在当时应放弃 3R。
- **有效路径**：冻结信号、入场、止损、保护和时限，只改变固定目标并重新走完整路径。15m 从 3R 抬到 8R 后 TP 79→10、保护退出 39→94，毛收益 +6.49→-1.14bp；5m TP 141→49、保护退出 158→244，毛收益虽升到 +4.14bp但仍不覆盖 20bp，稳健改善仅 1.17bp。
- **通用规则**：先区分“路径在退出后还走多远”和“持仓能否按同一规则活到那里”。长尾假设更适合用预注册的部分止盈 + runner 检验，让已实现收益与尾部风险分开；不能拿 post-exit MFE 当可实现收益。
- **牵连**：`target_r`、`horizon_mfe_r`、`horizon_hit_4r/5r/6r`、1.5R 保护状态机和 20bp 成本；仅用 2023–2024 development，audit 与 holdout 未开。
