# 抽屉关闭必须从手指当前位移开始

- **问题**：网页快捷开单下拉没有跟手感觉，原实现只记录 pointerdown 与 pointerup 的距离，达到阈值便直接 hidden，完全没有拖动阶段。
- **死胡同**：单纯加关闭动画仍然不会跟手；在 pointermove 上保留 transform 缓动，会让面板持续落后于手指。直接写布局共用的 inline transform 又会被移动端 transform:none!important 和定期布局复位覆盖。
- **有效路径**：使用独立的 CSS 位移变量与每帧合并写入，拖动阶段取消过渡；遮罩同步按距离减淡。释放时先提交当前位移，再切入过渡并关闭或回弹，交易组件在退出结束后释放。回弹被再次按住时读取当前实际矩阵作为新起点。拖动仅绑定抓手和标题，正文继续原生滚动；取消、失去捕获和导航清理各有明确路径。
- **通用规则**：直接操控阶段与松手后的动画阶段必须分开；减弱动态效果只跳过惯性动画，不能取消直接跟手。验收实际位移、滚动所有者、关闭时序、重抓回弹与事件取消，不能仅检查最终 hidden 状态。
- **牵连**：`yoyo/monitor/static/monday-quick.js`、`monday-fib.css`；手机为可见视口的75%，桌面尺寸不变。320/390宽度下下拉20/45/90px均等量移动；真实浏览器触屏事件下拉100px同样等量移动；键盘可见高度400px时抽屉300px。
