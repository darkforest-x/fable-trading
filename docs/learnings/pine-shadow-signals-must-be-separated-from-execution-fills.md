# Pine 参考持有状态与真实成交账户必须分开重放

- **问题**：Pine 用信号收盘计算 R，并在参考持有段压制新箭头；回测应使用下一根可成交价格，两者可能不同。
- **死胡同**：把 Pine 的参考入场直接当成交会高估可实现性；反过来把真实成交的退出时点写回箭头状态，又会改变原指标候选，比较的已经不是同一个指标。
- **有效路径**：先独立重放冻结 Pine 的候选状态，再由独立执行路径计算开盘成交、实际风险、下根生效保护和账户接纳。保存两套时钟，不因账户拒单改变原箭头。
- **通用规则**：评估含持有状态的指标时，先问该状态是否参与后续信号生成；如参与，指标参考状态与成交账户都要保存，不能让一个替代另一个。
