# Confirmation-only charts must price their risk from the confirmation

- **问题**：V4 的分层文字影响读图。Owner 要求只显示确认；旧风险框却在较早预警处开启，隐藏预警后会把更低的入场价及确认前涨幅混入读者看到的确认收益。
- **死胡同**：只隐藏预警标签，或者只显示 parentBar 等于 entryBar 的所属确认。前者留下错误的价格关联，后者在延迟确认时会漏画，因为原候选根与实际确认根不同。
- **有效路径**：保留候选与确认判定原样，所有确认在实际当前根直接绘制。风险参考仅在空闲后的确认收盘开启，取确认当时价格、ATR 与近期极值，初始峰值归零。已有参考不因后续确认重置；信号显示独立于参考持有状态。
- **通用规则**：当图表只留下后一级事件时，逐一核对箭头、价格、风险分母和峰值的起始时刻。隐藏前一级文字不能把前一级可得价格变成后一级可得价格。算法相同不代表风险路径数值相同。
- **牵连**：`yoyo/evaluation/pine/spike_burst_v4.pine`、`tests/test_spike_burst_v4_release.py`；不改监控服务和通知规则。原 Pine 的保护事件时刻随参考起点改变，不能宣称所有事件输出不变。
