# 多周期的大赢家可能只是同一段行情的重复证据

- **问题**：2026-09-25切出SPIKE最近两个月账本，ETH5m有净+28.8592R、ETH1h有净+18.0178R的大赢家；另有联合信号盈利，容易被理解为多个独立验证。
- **死胡同**：将每个周期、普通与联合账本的收益相加，或把正收益组数视为独立成功次数。逐笔时间对齐表明，两笔ETH大赢家都来自8月19日开始的同一段上涨；49笔联合记录中37笔与普通账本同币同周期同方向同时间入场。
- **有效路径**：保留各自账本，对齐事件时间，单列重叠入场；同时报告样本数、中位浮盈、去掉最佳单后的描述性总R。ETH5m其余42笔为-47.5290R，ETH1h其余2笔为-1.9684R。删除最佳单只检查收益集中度，不是交易规则。
- **通用规则**：比较多周期或多类信号时先数独立行情事件，再解释尾部收益。不得把跨周期相关交易合成未经定义仓位与风险约束的账户曲线；不得把机械账本当作未执行的人工筛选成绩。
