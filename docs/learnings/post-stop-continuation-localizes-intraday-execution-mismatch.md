# 止损后延续率可以定位小周期执行几何错配

- **问题**：小周期 K1→K2 策略大量失败，单看 `SL` 数量无法区分“方向判断错”与“方向对但 K2 极值止损太贴”。
- **死胡同**：继续提高形态分数或直接把 3R 止盈抬到 5R，都绕开了入场后的第一段路径；更高 TP 无法挽回已被提前扫出的交易，而且把止损后的未来走势当成可获得收益会制造反事实利润。
- **有效路径**：交易仍按冻结止损真实退出，同时只做诊断性地追踪同一 12 小时 OHLC 路径的后续 MFE。15min 有 61/132（46.2%）、5min 有 152/277（54.9%）的止损随后仍触及原 3R，且最紧的 K2 止损距离桶最差，因此下一假设被定位到止损/入场几何，而不是继续收紧颜色与形态门。
- **通用规则**：对低周期 barrier 策略，失败归因至少要把止损按“止损前 MFE”分段，并报告止损后冻结时限内的延续率；它只用于选择下一项单变量实验，绝不能当成未止损收益。先验证止损或入场，再独立验证 runner/TP。
- **牵连**：精确 K2 高低点止损、ATR14 止损距离、3R、12 小时时限、同根止损优先；修改任何 SL/TP 障碍参数仍需 Owner 明确批准。
