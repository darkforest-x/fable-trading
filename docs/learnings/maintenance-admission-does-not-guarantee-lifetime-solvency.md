# 加仓时维持保证金准入不等于整个持仓期安全

- **问题**：WIF滚仓V0.3按保护价、当前成交价与标记价差、一跳缓冲限制数量，七次加仓仍不能确认最终止损可执行。
- **死胡同**：把加仓当时计算出的正维持余量解释成之后直到退出都有保护。数量二分会贴着最大允许数量成交，正数可能只比零大几个分币。
- **证据**：2026-08-22 01:00 UTC 最后一腿成交后，压力维持余量约0.0128U；04:00资金费约3.9395U，已经超过该余量。05:00小时价格和标记价同时覆盖止损/维持阈值，先后未知。最终362088数量还超过当前单笔市价270000限制；独立账本相等并不证明整仓能按一个价格退出。
- **有效路径**：区分“成交时准入”和“持仓过程控制”，逐次记资金费与压力余量。遇到不可排序的双边界穿越，最终余额保留空值，理想止损账本另列。要验证持续保护，需要先定义、冻结新的过程规则与费用/价差/拆单预算，再研究；不能看见失败后回填减仓。
- **通用规则**：安全是随时间变化的状态，不是建仓时的布尔标签。定量缓冲须有时间尺度和会消耗它的来源；一跳只是价格单位，不是资金费或执行时间预算。
