# 大趋势的退出费用随退出名义金额增长

- **问题**：按入场名义统一扣固定往返成本，对大涨数倍的多头趋势交易可能低估费用；资金费还可能在开平仓边界附近发生。
- **死胡同**：把固定20bp研究合同称作已扣完整实际成本，或将未取到资金费当作零。尤其不能用“有历史费率文件”证明交易期间结算记录完整。
- **有效路径**：保留原合同对照，同时以相同成交和数量计算入场费率×入场名义加退出费率×退出名义；另报固定40/60bp压力。历史实现资金费单列，缺失保持未知，缺结算标记价格时注明小时开盘代理。开平仓与结算时间边界不清晰的费用给区间。
- **通用规则**：先分清静态交易路径的成本归因与重新按净现金复利的账户回测；前者不得冒称后者。名义金额、时间归属、缺失覆盖是三项独立检查。
- **牵连**：`yoyo/data/altseason_funding.py`、`yoyo/evaluation/altseason_costs.py`；这里只分析离线成本，没有实际交易或收费档位保证。
