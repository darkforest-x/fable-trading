# 日内胜率排名先固定事件时钟和盈利定义

- **问题**：Task62 Owner问一天中何时胜率最高。已有26种退出，若混用信号K线时间、实际入场时间、目标兑现和含费保本小盈利，会得到不同冠军。
- **死胡同**：直接对所有策略的净正收益比例取最大，会选出23–24点的0.5R含费保本：29/57净赢，但29笔全是保护止损，合计只赚0.14544点，零笔目标；整组净亏306.80312点。这是已核对的定义陷阱，不是新的数值误差修复。把同周匹配随机也称为同小时随机，会进一步夸大时段证据。
- **有效路径**：先固定上一轮候选20R＋5R推开仓价，再按北京时间实际入场分组，保留所有平仓单为分母，另列目标兑现与保护盈利。09–10点10/115最高；换成提前10分钟的信号K线时钟则10–11点12/140最高。分年显示09点2025年6/33、2026年1/49；原同周随机只作队列对照，单列真正同小时配对的稀疏数量。
- **通用规则**：问“什么时间最好”时，先明确事件时间、退出规则与赢的含义，再给样本量、目标兑现和分年稳定性。近零的正收益不能代表大盈利兑现，事后24小时冠军不能直接变成交易过滤门。
