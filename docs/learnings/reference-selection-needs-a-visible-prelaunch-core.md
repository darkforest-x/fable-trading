# 参考图的清晰度要审框内核心，不能由框外大涨大跌代替

- **问题**：视觉研究默认多头图不够典型，空头框被要求靠右；Owner 明确只框启动前均线密集区。
- **死胡同**：旧池里“规则通过”或后面大涨大跌，并不保证框内仍是密集核心。一些候选框已落在缓慢离束过程，统一右移会进一步把启动混进去；较短窗口也不会自动修正语义。
- **有效路径**：先看原图，再逐事件确定核心末根与启动首根。FIL/TRUST 保留启动前右边界、左界收紧一根；替换不清楚的样本。用冻结的原始 OHLC 前缀重算六均线，FIL/TRUST 无框图与原图 SHA 完全一致后再画新框；保存独立版本和新旧坐标，不改旧标签。生成器首轮使用了 Python 3.11 才提供的哈希 API，在本仓 3.9 报错、未产出图片；修复并提交后重建成功。
- **通用规则**：外侧走势只能解释背景，不能替框内结构背书。“向右一点”必须落成逐图 K 线边界；确认协议也不等于确认新样本。参考库更新要保存旧版本，识别记录继续绑定原版本。
- **牵连**：`yoyo/vision_research/reference_pack.py`、实验目录下 `references_v3.json` / `default_references_v3/`、全局参考库 revision；研究示例，训练与生产资格仍为 false。
