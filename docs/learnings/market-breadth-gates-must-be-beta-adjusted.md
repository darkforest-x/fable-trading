# 市场广度门槛必须先扣除同期市场 beta

- **问题**：候选在广度上升时的原始均值 R 可能改善，看起来适合直接做成信号过滤；但这种改善也可能来自当月所有随机入场都更容易上涨，而不是策略更会选择启动点。
- **死胡同**：只比较过滤前后的候选收益、胜率和信号数。这样会把行情月份选择误认成信号择时优势，也会忽略被过滤掉的孤立单币 10R 尾部。
- **有效路径**：对每笔候选按同币、同日历月、同波动桶匹配随机入场，并同时核对目标与对照的净 R、月块 sign-flip p 和原始 10R 保留率。本轮 `joint_delta_60m > 0` 虽令 V1 30m 原始均值 R 转正，但其 matched edge 反而从 0.073R 降至 0.057R；跨周期结果还发生方向翻转，因此拒绝统一硬门槛。
- **通用规则**：任何全市场状态变量先作为标签或排序字段；只有在匹配随机对照仍有稳定增量、预注册检验通过且保留目标尾部后，才考虑用它删除信号。广度跃迁与绝对高广度应分开验证。
