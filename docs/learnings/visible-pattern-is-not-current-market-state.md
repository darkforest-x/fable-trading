# Seeing a pattern somewhere in a chart is not detecting the current market state

- **Problem**: The vision workbench called an old RAY consolidation and launch a match even though the displayed right edge had already moved away. Its instruction asked for a visible pattern without anchoring the assessment to the observation's right edge.
- **Dead end**: Fresh OHLC, a live snapshot ID and an unexpired 12-bar recheck window did not make the selected pattern current. A user could also pan away from the latest bar while the underlying snapshot remained fresh. Merely adding more references or changing visual styles would not fix either mismatch.
- **Effective path**: Anchor new requests to the rightmost visible state, send immutable observation time context, and require a separate state classification. Only a current launch may match; an extended/absent setup cannot match or carry a historical core box. Check the complete latest candle is in the captured logical viewport before calling the provider, and compare the declared viewport count/time with the saved snapshot on the server. Keep old whole-chart results visibly labelled as legacy rather than rewriting them.
- **General rule**: Specify the detection target and the time it refers to independently of input freshness and request eligibility. A core box belongs before the launch, so it must not be forced onto the final candle. Client-declared viewport metadata does not attest screenshot pixels, and a model's state label does not independently prove its visual judgment.
- **Scope**: `yoyo/vision_research/{schemas.py,zhipu.py,server.py,static/chart.js,static/app.js}`. Version 0.4.0 keeps the existing signal expiry, snapshot TTL, credentials and reference library. On identical candidate/reference hashes, legacy RAY run `f8f15d72ef114697a7a2a3cf142afddf` was rechecked as uploaded historical pixels in run `94ed016f2a2642dbb08e6bcb163818c2`: `extended/no_match`, no box, original run unchanged. This is one regression example, not recognition-quality or trading validation. 194 Python tests and 5 Node viewport tests passed; a real browser panned away from the tail was blocked before inference.
