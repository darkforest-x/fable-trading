# 收回形态的随机对照还要匹配离参考线的距离

- **问题**：12h 1.618 纯插针在收盘后 3 天的全样本平均反向价格变化为 -0.279%，但同币、同周、同方向、相近历史波动的匹配比较却出现 +1.959 个百分点的优势。相对优势和绝对表现明显背离。
- **死胡同**：不能因为同币同周波动匹配和周聚类检验的 p 值很小，就认定影线有预测价值；候选时点的价位本身也可能不同。原始结果保留，未用更严格匹配覆盖它。
- **有效路径**：在完全相同的 1,868 个信号上，只改变随机对照的收盘离线距离约束（按过去 14 根 TR 标准化，固定分桶）。原对照均值 -1.206%，距离匹配后 +0.148%；信号均值均为 +0.215%。超额从 +1.421 缩至 +0.066 个百分点，后者周聚类 95% 区间 [-0.145,+0.279]，平均变化的符号翻转检验 p=0.569。另保留“已触及”“相邻 24h”“非收回时点”三个单约束敏感性，避免只展示一种有利对照。
- **通用规则**：事件以相对价位定义时，随机对照除币、市场时段和波动外，还要检查位置、距离和事件阶段。先固定共同事件集合，再比较对照构成；匹配覆盖下降必须报告。这是事后诊断，不把它包装成样本外验证，也不把价格变化当成交收益。
