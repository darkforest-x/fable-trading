# 卡片交互要匹配完整事件身份

- **问题**：新增周期后，卡片预览与刷新焦点恢复需要稳定回到同一合约、同一周期、同一事件。
- **死胡同**：只按 id 和 kind 找卡片隐含了上游 id 永远全局唯一；复用 id 的回归夹具暴露出不同周期或合约会误匹配。展示标签正确并不能证明点击目标也正确。
- **有效路径**：渲染预览入口时携带合约和周期，点击、刷新后焦点恢复及返回卡片都使用同一完整身份；测试显式构造同 id/kind、不同合约/周期，检查请求和焦点目标。
- **通用规则**：多维数据卡片的渲染键、选择键和操作键必须表达同一个业务身份，不能仅凭某层的局部 id。
- **牵连**：`yoyo/monitor/static/app.js`、`tests/monitor/frontend_cards.test.cjs`；不改变后端事件 id。
