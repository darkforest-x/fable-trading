# 跨平台交付证券代码必须带交易所限定符

- **问题**：A 股检测清单中的 18 个六位代码在两套行情源里均能匹配，但用户在自己的搜索入口里全部搜不到；纯代码有效不等于跨平台可检索。
- **死胡同**：把 `600336`、`000682` 当成通用标识，并把“普通用户”默认解释为已有内地沪深 A 股账户。不同软件可能要求 `SH/SZ`、`SSE/SZSE` 或 `.SS/.SZ`，不支持内地 A 股的平台则会整批返回空结果。
- **有效路径**：先用独立行情源核对代码—名称—交易所三元组，确认是标识展示问题而非数据错配；随后交付 `SH600336` / `SZ000682` 这类交易所限定键，并按具体平台给出 `SSE:600336` / `SZSE:000682` 或 `600336.SS` / `000682.SZ` 映射。
- **通用规则**：任何跨市场、跨软件的证券清单，第一列都应是 venue-qualified identifier；同时明确账户/产品覆盖范围。若整批代码都搜不到，先查搜索市场和符号格式，不要先推断整批退市。
- **牵连**：A 股信号 CSV 的 `market` + `code` 字段、Telegram caption、报告表格、用户实际使用的行情软件或券商；交易所可检索不等于具体账户可交易。
