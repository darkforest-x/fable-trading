# 历史 K 线加载不等于历史信号已经加载

- **问题**：云带图能回看到八月，但参考框只来自监控保存的最近两周事件，较早合格信号没有框。Owner随后明确把止损改回关键K极值并撤销云带位置过滤，EDGE八月三十日因而有有效参考计划。
- **死胡同**：只补K线或把最近信号列表画得更远，都不会生成缺失的历史信号；只用屏幕前50根重新初始化EMA，又会让同一历史时点的云带随回看范围漂移。审查中排除了这个初始化方式。
- **有效路径**：按图中已加载的纽约周区间，用共同的信号与参考计划函数补算；复用缓存的完整连续12H指标前缀，并优先沿用已记录的EMA点与原始事件。仅在原生数据缺口或预热不足时请求一页历史；缺数据返回可重试状态。补算缓存与实时事件、通知去重分开，切周期/关闭图表时取消旧请求。
- **通用规则**：历史可视化应分别核对原始行情、指标预热、区间锚点和派生信号四种覆盖范围。回看结果必须说明来源，并复用当前规则，不能靠后来价格走势补画交易。
- **牵连**：`cloud_signal_history.py`、`cloud-signal-chart.js`；Owner最终规则为`confirmation-wick-extreme-v2`与`ema-direction-only-v2`。EDGE确认入场0.355、关键K低点0.3493、目标0.4232816，对应参考11.98R；不是实际收益。27项Python、19项前端检查及公开页面验收覆盖此次修改。
