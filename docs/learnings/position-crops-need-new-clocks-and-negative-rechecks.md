# 真正移动窗口必须同步修正可见时钟和负例标签证据

- **问题**：修正 v6 固定后5根的位置锚点，不能只把 post 参数改成多个值：原负例可能在新增后文里启动，旧信号时间也不再代表新图的可用时间。
- **死胡同**：复用旧空标签、保留同一 decision 时间、只移动矩形，分别会造成漏标、前视或框与行情脱离。只检查图像数量、复现哈希和固定时钟的一致性，无法验收“位置真正变化”这个用户要求。
- **有效路径**：三种窗口用11前/5后、8前/8后、5前/11后，固定每事件可见根数；从原P9实际TXT反解核心bar/价格边界，再投影至新图。逐视图按右端收盘登记可见时间，沿用最少5根原确认信息。负例以三窗并集重新执行原阈值与保护区检查，新增明显启动或不确定窗口退出新训练集，原P9评估成员及像素保持不变。
- **通用规则**：将产品要求写成可证伪的验收条件：每事件3种不同post、相同可见长度、同一物理框、逐图真实可见时钟；再用“仅修改该窗口之后的价格”和“旧负例在新增区域出现启动”做反例测试。实现通过不等于需求通过。
- **牵连**：`ma_morphology_positions.py`、`ma_morphology_training_package.py`、`ma_morphology_assembly.py`、`ma_morphology_background.py`及位置回归测试。较晚窗口仍是延迟形态识别，不能冒充核心刚结束时可得的盘口信号；位置修复本身不证明识别效果或盈利。
