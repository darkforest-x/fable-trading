# 过去的高波动排名可能剔除从安静中启动的长尾行情

- **问题**：Owner要捕获高波动山寨的大趋势，用交易前上周ATR/价格前25%排名可以避免今日涨幅倒选，但它是否保留真正启动未知。
- **死胡同**：把“通常很波动的币”当作“这根开始扩张”的同一指标；只查看高波动池内部收益无法发现被筛掉的赢家。用期末浮盈描述所有大赢家还会混淆兑现路径。
- **有效路径**：固定基准事件，按symbol/周期/折/signal_i/side做全集与预先可用排名子集的身份联结。近期1H≥5R事件18保留6，遗漏XRP自然退出48.05R；4H四个全部遗漏，但其中三笔是边界盯市（含ZEC37.14R），不是全部自然退出。图中同时标截止、自然退出、失败及遗漏，事后选择不用于成功率估计。
- **通用规则**：候选池过滤必须报告同一事件集的长尾保留率和遗漏案例。币层波动水平与bar层相对扩张独立检验；遗漏大赢家不自动证明取消过滤后的组合有效，不能据此继续在已看区间调参。
