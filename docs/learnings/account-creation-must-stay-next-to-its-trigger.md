# 新建表单必须留在触发按钮附近

- **问题**：模拟交易点击“新建账户”后看似无反应；表单实际出现在长图表和交易区之后。
- **死胡同**：只核对点击处理器或表单 HTML 存在，无法判断用户能否看到结果。此前行情模块重排工具栏与交易槽，却把新建表单留在底部通用槽。
- **有效路径**：沿最终 DOM 的重排过程定位表单，将其放到顶部通知槽；展开时滚入视口并聚焦名称，保留交易图表节点。
- **通用规则**：重排布局后验证操作结果与按钮的空间关系，尤其是非弹窗的新增、编辑和错误状态。
- **牵连**：`yoyo/monitor/static/paper-desk-market.js`、`paper-desk.js`；不改变账户创建、报价和成交契约。
