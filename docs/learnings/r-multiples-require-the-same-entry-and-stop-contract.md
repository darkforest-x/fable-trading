# 比较 R 倍数之前必须对齐入场与初始止损

- **问题**：Owner 认为 Pine 初始止损太小，而此前研究中的趋势收益和图上 3R/10R 容易被当成同一个交易合同。
- **死胡同**：直接用“触达很多 R”证明止损合理，忽略分母大小；或把研究的下一根开盘、2 ATR 止损结果套到图上的信号收盘、单根极值止损，都会造成错误比较。
- **有效路径**：先读 Pine 初始化与冻结逻辑，再按原箭头精确收盘 K 线核对风险。2026-09-09 14:46 的可量化样本中，15m/1H/4H 的止损距离中位分别约 0.453/0.436/0.437 ATR，统一 0.2% 研究成本分别约占 0.741/0.430/0.176R。此诊断只说明风险尺度，未验证放宽后的胜率或收益。
- **通用规则**：任何 R 比较同时记录入场时刻、价格、冻结止损、费用和持仓退出规则。止损变宽必须在相同账户风险下缩小仓位，再用完整失败与成功样本比较；图上的最大浮盈不是可实现收益。
- **牵连**：`yoyo/evaluation/pine/imacd_dense_mtf_v2_6.pine`、`yoyo/evaluation/altcoin_accounting.py`；诊断证据位于 `output/qa/spike_stop_review_20260909/`。4H 仅 5 个样本，0.2% 不是账户实测费率，本轮没有修改止损参数。
