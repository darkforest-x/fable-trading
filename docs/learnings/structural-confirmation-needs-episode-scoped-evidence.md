# 结构条件要保存同一段的证据，而不是强迫所有条件同根发生

- **问题**：Owner 的“实体站上六条均线”允许发生在旧确认之前或之后。若直接把 `bodyAboveSix` 与旧信号做当根 AND，会把结构要求误译为单根形态。
- **死胡同**：改成“过去任意一根曾站上”也不正确：很久以前或上一段结构的支撑会泄漏到新候选；把最终信号画回早先证据根，更会让历史图提前知道未来。
- **有效路径**：先定义可识别的蓄势段、释放窗口和失效边界，把实体证据与旧确认分别记入同一结构。最终只在当前收盘已知条件齐备时出一次信号。收盘重回均线带时撤销支撑；新段、缺口、反向释放、结构低点失守或到期清理旧等待。近零容差在蓄势成熟后冻结，等待期间不能切回动态 ATR 容差。
- **通用规则**：遇到“之前之后都可以”的形态描述，先写事件作用域、有效期、撤销与最终输出时间，再写布尔表达式。用先 A 后 B、先 B 后 A、不同段 A/B、失效重建、前缀一致性验证语义；这些软件测试不证明收益或覆盖率。
