# 确认后入场、核心外止损，会把 3R 目标推得更远

- **问题**：Owner 指出启动形态出现时行情可能已经走完，希望只保留可盈利的 3R 事件。需要辨明“后来有盈利”和“确认后还能实现 3R”是不是同一标签。
- **死胡同**：只看形态之后最高涨幅，或把 TIMEOUT 全部解释成亏损，都不能说明可成交收益；不断扩样也不能自动修复入场偏晚。不能为了提高胜率，把入场倒填到确认窗之前。
- **有效路径**：冻结完整确认窗后下一根开盘入场、核心高低点止损、12h 期限与 0.2% 成本，先解析事件，再统计入场到止损的相对距离。首批 1,176 个独立 15m 候选中 501 个净盈利，但仅 60 个先达 3R；774 个 TIMEOUT 中 441 个仍净盈利。全池中位风险距离 3.301%，因此中位 3R 目标需要入场后再走约 9.904%。这是当前标签几何的描述，不是确认延迟导致低收益的因果实验。
- **通用规则**：筛选高 R 事件之前，先冻结可用信息的右端、成交时点、止损位置和期限；同时报告普通盈利率、达标率、风险距离分布。需要更早入场时另立因果规格，不能移动旧标签的成交时间来美化结果。
