# 边框显粗时先检查同价位描边叠加

- **问题**：V5 的 sl 侧比其他框边明显，虽然 box 边框已为 1 像素。
- **死胡同**：只调整 box 的宽度，或只把保护线从 2 改成 1，仍留下框边、初始止损和保护线的重复描边。
- **有效路径**：保留价格序列和填色，只在框开启时隐藏重复的初始描边；保护线与初始止损重合时也不重复画，移动后恢复 1 像素线。
- **通用规则**：同一位置的颜色深浅和视觉厚度取决于所有图层，不能只看被用户点名的对象参数。
- **牵连**：yoyo/evaluation/pine/spike_burst_v5.pine 的 pProtect、pInitial、rrShow；风险计算和数据窗口值不变。
