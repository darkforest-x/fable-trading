# 重新蓄势要数清原始观测，不能重复累计滚动摘要

- **问题**：希望“上一段启动之后，重新形成 12 根均线密集才允许再报”，但原 `prog_dense` 本身已经总结此前 12 条均线宽度和交叉观测。
- **死胡同**：再要求连续 12 个 `prog_dense=True`，看起来仍叫“12 根密集”，实际叠成更长的支持窗口，悄悄改变等待时间与形态定义；只数 True 次数也可能反复借用上一段的同一批观测。
- **有效路径**：G 研究方案直接沿用既有密集摘要。接受后先观察有效非密集，再等密集有效且其前 12 条 width/flips 观测行全部晚于旧 owner，恢复一次资格。无效值不当非密集；重新进入密集已经持续若干根时，支持窗口第一次满足条件也可恢复。该状态机先经合成前缀和边界验证，尚不能据此声称减少市场误报。
- **通用规则**：给滚动特征再套“持续 N 根”之前，画出每个摘要使用的原始行区间。区分观测行不重叠与全部计算依赖独立：均线含更早记忆，flip 也引用前一根，不能把新窗口称为统计独立样本。
