# 关闭保本可以提高胜率，同时降低单位期望

- **问题**：ETH4h大量保本单扣费后小亏，Owner授权保本开关对照，需要判断关闭后能否捕获更多趋势。
- **死胡同**：只看胜率会得到反结论；只对照两版实际成交也会混入仓位占用和冷却导致的不同入场集合。
- **有效路径**：源码c38098d先冻结，在2021–2024同87个可入场原始信号上独立回放，使用完全相同的匹配控制身份。关闭保本使净胜率11.49%→19.54%，但平均净收益82.23→31.11bp，平均持仓104.87→187.63小时。原44个保本事件里，关闭后7个净赢、37个净亏，其中36个毛亏接近3%硬止损。全组合开发期收益10.88%→7.28%，回撤6.67%→12.68%。按预登记规则保留保本；不因已暴露后段关闭保本表现较好就反选。
- **通用规则**：评估退出改动时，固定入场事件的反事实用于机制解释，全组合用于资金与占用效果，两者都要看；胜率变化不能替代单位期望和尾部损失。该小样本对照不证明所有市场都应保本。
