# 涨幅榜币的大幅冲高是榜单本身的属性，不是择时优势

- **问题**：Owner 提出在 ETH 1H 绿勾时取 OKX 当时 24h 涨幅榜，看它们 16h 最大涨幅。近3个月 22 次，榜单前10平均 16h 最大涨幅 +8.05%，远高于 ETH +1.14%，看起来是“绿勾时买榜单币”的证据。
- **死胡同**：拿榜单最大涨幅只和 ETH 或同刻全市场（+3.18%）比，会把“榜单币波动大、刚在动量里”当成信号价值；和同波动的榜外币比（+4.39%）仍然显著更高，也只能证明“榜单”有用，不能证明“绿勾时点”有用。只看最大涨幅还会掩盖回撤和持有结果：平均最大回撤 −6.55%，16h 收盘扣费 −0.75%，比全市场更差；MMT 最高 +64%，收盘 −34%。
- **有效路径**：把三个问题拆成三组对照，用同一套事件配对。同刻全市场回答选币是否强于市场，同刻波动匹配回答是否只是波动高，同月同6h时段的普通小时按同规则重排榜单回答 ETH 绿勾是否加分。普通时刻的榜单是 +8.13%，不低于绿勾时点，择时贡献为零（8/22）。最大涨幅、最大回撤和到期净收益分开报告。
- **通用规则**：凡是“信号出现时某个名单的路径极值很大”，先在非信号时刻用同一名单规则复算同一极值。路径极值天然随波动放大，没有可执行退出规则时，它不是收益。
