# 长区间检测图必须保证模型窗口仍在全景画布内

- **问题**：短扫描只看最近 6 个 4h 端点，固定“最近 80 根”全景一定包含检测框；扩到 90 个端点
  后，最早约 10 个端点已经落到固定画布左侧。模型输入、预测和框坐标都正确，但交付全景会把旧框
  裁掉，让“有信号却看不到框”看起来像推理错误。
- **死胡同**：只在投影时把负 x 坐标钳到 0 会画出贴边假框，既不对应模型原像素，也掩盖了真正
  问题；把所有图无条件扩成完整 300 根又会让短扫描的 K 线过细，降低可读性。
- **有效路径**：全景默认仍取最近 80 根，但起点不得晚于该事件的 `window_start_i`：
  `min(latest_80_start, scored_window_start)`。因此短扫描像素保持原样，旧事件则按需扩展上下文；模型
  实际评分的 W18/W19 inset 与原始 `cx/cy/w/h` 均不改变。旧交付图先移入备份目录，再原子替换
  为动态上下文版本，保留审计线索。
- **通用规则**：任何“历史事件 + 最新行情”的复合图，都要显式断言事件窗口落在展示域内；不能
  假设短期任务采用的固定 context 在扩大时间范围后仍成立。
- **牵连**：`scripts/scan_4h_ma_launch_yolo_latest.py` 的 `delivery_context_start()` / 
  `render_event()`、15 天 4h YOLO 交付图、逐像素 chart replay；检测权重、阈值、输入图与事件结果
  均不受影响。
