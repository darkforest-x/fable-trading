# 影线挂单回测必须计入失败收复

- **问题**：K2 收盘后可确认“影线触均线且实体留在趋势侧”，但若把成交价事后改成该根影线中的均线价，会得到不真实的入场改善。
- **死胡同**：先用 K2 收盘条件筛出成功收复的 K 线，再假设此前已在影线处成交。这个账本只保留成功 K2，所有触线后收盘失败、实盘同样会成交的挂单都被删除，形成条件选择偏差；15m OHLC 还无法恢复同根内触线、止损和收盘的先后顺序。
- **有效路径**：K1 完成后，用上一根已完成均线生成可交易挂单；之后每个触线都必须进入账本。可采用小探针，K2 收盘有效后下一开盘加仓，无效则下一开盘退出探针；同根路径未知时用 stop-first，并以同 venue 的 1m 数据做次级验证。
- **通用规则**：任何“确认后却按确认前价格成交”的回测，第一步都要列出确认失败但订单已触发的事件。缺少这些事件时，入场优势一律视为不可交易。
- **牵连**：K1→K2 影线入场、`next_bar_open` 基线、15m/1m 数据契约、成交成本、失败触线账本和 Pine alert 时点。
