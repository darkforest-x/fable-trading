# Maximum VLM quality is a model-specific request contract

- **Problem**: Selecting the newest flagship model while retaining a legacy non-thinking 4096-token adapter does not implement the owner's highest-quality request.
- **Dead end**: Raising every numeric parameter or combining `reasoning_effort` and `thinking_budget` is not a quality strategy. Qwen3.8 rejects that combination; temperature is not a quality level, and `max_tokens` and `max_completion_tokens` have different scopes.
- **Effective path**: Check the official model and API contracts together. Use Qwen3.8-Max `xhigh`, the legal 131072-token complete-output ceiling, and 16777216 pixels per image. Receive SSE, preserve its original body, separate reasoning from the answer, and require both a completed stream and valid decision semantics. Keep a text-only credential probe small. Display the actual preset in model settings, and permit saving it before a key is available.
- **General rule**: Bind model identity, reasoning, output, image handling, transport and parsing as one versioned policy. Maximum permitted budgets are ceilings, not promised consumption or measured chart accuracy. Missing credentials must block calls instead of switching providers.
