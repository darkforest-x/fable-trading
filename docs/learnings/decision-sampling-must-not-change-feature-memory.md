# 降低决策频率必须与特征记忆分开

- **问题**：原生5min SMA40改为15min SMA40后，无法知道结果变化来自少检查，还是均线记忆由200分钟变为600分钟。
- **死胡同**：只改management_minutes为15，或把5min数据先抽成15min行再喂旧引擎，前者混淆变量，后者会把数据缺失检查、可见时间和相邻关系一起改坏。
- **有效路径**：保留完整原生5min特征流，新增独立decision_minutes。每5min执行风险和质量检查，每15min才采样有效颜色；中途有效颜色不能重新武装，缺失却必须清链。初始状态取真实入场时的已完成5min，首段按入场相位特殊处理。
- **通用规则**：先分别写出特征时钟、数据可用时钟、决策时钟和风险执行时钟，再改代码。用“中途无效→恢复同色→检查点反色”验证系统没有偷偷重武装；用默认路径全列parity验证旧策略没变。
- **牵连**：V9 PROJECT_PLAN，L3 hourly_impulse.py，transition_cadence合成测试；此设计仅使实验可解释，尚不构成收益证据。
