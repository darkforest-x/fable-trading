# 盘中浮盈超过4R仍可能没有启动收盘2R追踪

- **问题**：SPIKE V12.8 五年代码复盘出现“曾浮盈4R以上，最终初始止损”的单子，容易被误认为止损引擎错误。
- **死胡同**：仅凭 MFE 大于2R，就推断移动止损已经启动；把盘中影线与收盘确认混为同一事件，会错误重建保护价。
- **有效路径**：同时审计持仓极值和每根持仓收盘。Binance ETHUSDT 5m 普通信号于2024-12-06 03:45北京时间下一开盘做空3843.84，初始止损3894.06，风险50.22。曾有完整持仓K线低至3615，已知MFE4.55675R，但整个持仓最大收盘浮盈仅1.88570R；原2R收盘启动条件从未成立，最后净亏1.15308R。预挂毛4R限价是另外一条退出政策，同入场回放净3.84692R。
- **通用规则**：逐笔复盘必须分别记录盘中触达、收盘确认和下根生效的保护价；只有收盘能触发的规则不能用影线代替。指标截图上的R、实际成交风险R、扣费后R也必须分别命名。
- **牵连**：`experiments/active/exp-spike-manual-system-20260925-v1/diagnostics_v1/examples.csv`、`yoyo/evaluation/spike_manual_four_r.py`。案例用于解释状态机，不证明统一4R止盈有效；本研究六组普通账本统一4R退出没有稳定优势。
