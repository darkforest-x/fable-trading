# IMACD 金叉与蓝柱过零是一个事件，不能重复计票

- **问题**：Owner 的 Impulse MACD V5 把主线/信号线交叉标为买卖，需要判断它是否同时证明方向与动能。
- **死胡同**：把“金叉 + 蓝柱翻正”看成两项确认，或把金叉直接等同于多头启动。前者是同一公式的两种绘图，后者忽略 md 的零轴位置；没有采用这两种解释去回测。
- **有效路径**：先写 sh=md−SMA9(md)，严格交叉定义就是 sh 从非正到正。把交叉拆成 md<0、md=0、md>0 三类，再讨论用途。负动量进入带内 md=0 也能金叉；SMA 窗口淘汰旧值甚至能让 md 下降时金叉。
- **通用规则**：研究多指标共振之前，先代数化每个触发条件，消除重复信号，并区分当前状态、状态变化与价格未来结果。
