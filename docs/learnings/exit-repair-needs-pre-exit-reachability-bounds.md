# 研究退出前先区分没到过目标和到过后回吐

- **问题**：原始信号最终净5R命中率低，究竟需要更会选信号，还是只需更会留住利润？单看最终R或含退出根high的毛MFE无法回答。
- **死胡同**：把所有失败都归因于退出太晚，或把整根退出K线的最高价当成止损之前可兑现的利润，都会把未来路径顺序当成已知。直接优化止盈还会把不同标签和不同策略混到一起。
- **有效路径**：固定原始入场/退出，将同成本净峰值分为严格下界与上界：已安全经过的K线high可入下界；开盘反向退出后high不可入；盘中止损根high只入上界；删失保持未知。49,070笔已结束中，44,079笔原退出前上界也未过净5R，3,256笔明确到过后回吐，1,703笔最终兑现，32笔仅退出根可能到过。
- **通用规则**：先以同一风险分母、成本及固定观察终点做可达性分解，再决定检验入场还是退出。此次明确到过4,959笔，加模糊上界4,991笔，占已结束约10.1%；不能把这个机会率当成交收益，也不能将其当作延长持仓后新策略的上界。
- **牵连**：`yoyo/evaluation/spike_5r_followthrough.py:path_bounds`、`experiments/active/exp-spike-5r-followthrough-20260921-v6/results_v1/path_groups.csv`、`analysis/p1_spike_5r_followthrough_20260921.md`。该诊断不修改止盈，不证明30%高R目标成立。
