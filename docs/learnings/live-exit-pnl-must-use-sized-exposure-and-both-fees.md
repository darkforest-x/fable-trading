# 实时止盈止损净收益要从完整仓位与双边费用计算

- **问题**：全仓开仓只输入价格和杠杆，Owner 需要在输入止盈止损时看到对应 USDT 收益／损失，且不能打断手机输入或触发下单。
- **死胡同**：把价差直接乘资金再乘杠杆，会忽略按基础币计量的仓位；在已放大数量上再乘杠杆会重复放大。只扣开仓费会把手续费尚未覆盖的近距离止盈显示成盈利。复用提交报价／整页 render 会让估算影响确认流程或丢失光标。
- **有效路径**：沿用后端全仓公式：数量为可用资金除以“入场价 ×（1 / 杠杆 + 开仓费率）”，向下保留 12 位；净收益为方向符号乘价差乘数量，再减入场、出场两边名义金额的费用。限价使用委托价，市价使用新鲜卖一／买一；行情缓存独立于下单快照，只更新 output。账户后台刷新保留编辑中的输入节点；无资金、错向输入、过期行情不显示金额。
- **通用规则**：展示衍生金额前先明确它是毛收益、净收益还是保证金收益率；数量已包含杠杆时不再次放大。输入反馈与有副作用的提交流程分开，用固定数值、失败行情和延迟响应验证。
- **牵连**：`yoyo/monitor/static/paper-desk.js`、`paper-desk.css`、`tests/monitor/frontend_paper_desk.test.cjs`。51 项前端检查通过；1,000 USDT / 10× / 入场 80,960 / 止盈 81,964 / 止损 80,678 对应约 +102.86 / −54.25 USDT，沿用每边 0.1% 模拟费率。实际触价成交可能偏离设定价格，展示值不是成交保证。
