# A composite label cutoff does not enforce every shape requirement

- **问题**：Owner定义“持续反向推进、回撤较小”，首版综合质量分筛出220候选，但高分不能保证每项语义都满足。
- **死胡同**：只看综合分或继续训练更复杂模型，会把标签边界问题当成特征问题。四段中两段推进仍可由幅度、效率等分项补偿；慢启动后趋势也可能过线。不能反过来把审核提示自动当作负例。
- **有效路径**：冻结原标签和模型，独立核查分项与价格路径。33例只有两段推进、12例回撤大于最终推进、3例多数时间未处有利方向，去重46例优先核对；174例无提示也未升级为人工金标。用信号截止图和未来展开图并排，交由Owner确认边界，两个时点的纵轴也独立。
- **通用规则**：复合评分适合排序；若语义有必要条件，必须分别核对，并区分“需要复核”和“已经错标”。标签使用未来合法，但特征和信号时图轴必须止于决策点。先解决具体反例，再决定是否另建标签版本。
