# 花 holdout 之前先算它能分辨多大的效应

- **问题**:holdout #9(中波动带 × 高置信)未通过,当时归因为"配置不行"。
  九次消耗里有多次是同样的模式:训练池过线 → holdout 塌 → 记一笔"样本外失效"。
- **死胡同**:把每次失败都当成过拟合的证据,于是不断换配置再试。
  换配置解决不了尺子问题——**测不出来和不存在,在数据上长得一模一样**。
- **有效路径**:在申请消耗之前,先算**最小可分辨效应(MDE)**。方差取自训练池
  (免费,不碰 holdout),holdout 只以**候选数**入场:

  ```
  MDE = (z_{α/2} + z_β) · σ / √n          p<0.01, 功效 0.80 → 系数 3.417
  每笔净收益 σ:现行障碍 2.531%,纯持 4.802%,配对差 4.112%

  n=1739(holdout 候选数)→ 单样本 ≥39.4bp,配对 ≥33.7bp
  要证的效应:裸池 +4.5bp,去障碍增量 +3.8bp     ← 差 9 倍
  ```

  **结论不是"该配置无效",是"这次消耗从一开始就不可能给出答案"。**
- **更狠的推论**:同一套算术套到判断层上——顶档只占 1/10,双样本检验:

  ```
  顶档要比全池高 40bp 才能证实 → 需总候选  33,668 笔
                 20bp          →         134,671 笔
                  5bp          →       2,154,730 笔
  现有候选池                    →           5,802 笔
  ```

  而整个池子的**毛收益才 11.7bp**。要求一个筛选层做出比总收益还大 3 倍的提升,
  才够被现有样本量证实——**这个要求本身不成立**。
- **通用规则**:任何"样本外失效"的结论,先问**样本外有没有能力复现**。
  报告里出现"未通过 / 塌了 / 不显著"时,**必须同时给出该样本量的 MDE**;
  效应小于 MDE 时正确措辞是"**无法判定**",不是"无效"、更不是"反选"。
  推论:提升样本量与提升模型是**同等优先级**的工作,有时前者更优先——
  在 MDE 降到效应量以下之前,再好的模型改进也无法被证明。
