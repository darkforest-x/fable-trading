# 公网页面的图表外链属于访问设备

- **问题**：周一触价列表需要复用 TG 的“查看图表”链接，同时保留点击行情切换背景的能力。公网服务所在 Mac 与访问页面的设备不能混为一谈。
- **死胡同**：已有 `/api/tradingview/open` 操作的是服务宿主的桌面，不是访问者的桌面；公网入口明确拒绝它。本机桥接代码也记录了 TradingView 登录协议不能应用图表参数，因此不能靠改成自定义协议便宣称已完成币种跳转。
- **有效路径**：从 `monday_fib.py` 核对 TG 实际 URL，保留 OKX 永续代码与 `interval=15`，用标准链接交给访问设备处理。币名链接与背景按钮作为同级元素，刷新后按币种和操作类型恢复焦点。Chrome 实测打开 OKX:BTCUSDT.P 的 15 分钟图，未验证原生客户端接管。
- **通用规则**：先区分链接目标、打开设备、最终应用三个事实。验证页面币种与周期，不能将生成了 URL、接口返回成功或启动了应用等同于桌面正确切图。
- **牵连**：`yoyo/monitor/static/monday-fib.js`、`monday-fib.css`、`yoyo/monitor/monday_fib.py`、`yoyo/monitor/tradingview.py`；既有公网桌面接口隔离保持有效。
