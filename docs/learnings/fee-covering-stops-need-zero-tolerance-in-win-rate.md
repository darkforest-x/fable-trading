# 含费保本的浮点尾差不能算胜单

- **问题**：Notion #62分钟回放中，64条含费保本路径在理论净收益零附近留有浮点尾差；`net > 0`会把正尾差算作盈利。
- **死胡同**：只核对累计净收益无法发现该问题，因为正负尾差对总金额几乎没有影响，却会改变胜率。
- **有效路径**：独立符号价格审计额外统计绝对净值小于1e-8的非零路径，胜率及PF的正负分类使用同一容差。原始金额保持不变，修正前汇总保留。
- **通用规则**：保本策略必须分别审计金额恒等式与胜负分类；价格精度不等于浮点运算精度。
- **牵连**：`yoyo/evaluation/eth_stoch_confirm_exits.py`的metrics，行为测试及独立审计；这不是手续费或策略参数改动，不改变排名及亏损结论。
