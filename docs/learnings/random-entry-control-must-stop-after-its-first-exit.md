# 随机入场对照必须在第一笔退出后停止

- **问题**：复用单仓串行回测引擎生成随机入场对照，可能让一次强制入场在平仓后重新接收普通信号，导致同一个对照变成多笔交易。
- **死胡同**：仅在反手开仓处检查forced标志不足以隔离对照；状态恢复为空仓后，普通入场分支仍会重新开仓。结果即使成本正确，也已经换了对照单位。
- **有效路径**：把强制入场限定到唯一signal_i，第一次完整退出后结束单笔回放，并在消费方断言对照平仓数至多为一。该问题在本轮真实回放前修正，未用错误版本生成收益结果。
- **通用规则**：统计单位为一笔入场时，控制引擎的生命周期也必须是一笔；不能只检查第一笔入口或最终收益公式。份额退出仍属于同一笔，后续重新入场则不属于。
- **牵连**：`yoyo/evaluation/ma_shift_stoch.py` 的 `replay_one` 与 `_replay`；`ma_shift_stoch_study.py` 的控制消费断言。期末仍未平仓的控制标记删失，不因缺少结局重抽。
