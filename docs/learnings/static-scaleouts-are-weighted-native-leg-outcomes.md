# 固定止损的静态分批，是原生单档结果的仓位加权

- **问题**：比较两批、三批、五批止盈时，容易把次数当成新增收益来源，或把2小时最高浮盈当成可以成交的退出价。
- **死胡同**：对每个比例重造回测引擎、用止盈后的截断peak_r估计后续空间，或把止损之后才出现的高低点算作持仓利润，都会破坏比较口径。
- **有效路径**：冻结入场、原始风险、120分钟期限和20bp成本；各单档通过Nautilus限价与保护止损成交，再按原始仓位比例加权。三腿多空原生成交、截止时刻、原始风险分母及费用守恒验证通过。另从原始OHLC算止损前MFE，止损当根单独给上下界。
- **通用规则**：当余仓止损与时间期限不随止盈改变、费用线性且没有资金约束时，静态分批总R是单档总R的凸组合，不可能超过其中全样本最好的单档。它能改变结果分布和胜率，不会凭分批次数创造额外期望。若推保本或联动止损，则必须另用事件引擎验证，不能套此等式。
- **牵连**：`yoyo/evaluation/range_twohour_mfe.py`、`tests/evaluation/test_range_twohour_mfe.py`、`experiments/active/exp-range-v231-2h-mfe-20261022-v1/`。2021–2026历史已经暴露；原始信号与匹配随机保留；截止附近一笔BTC从已登记分钟尾段补足2h，未补造行情。
