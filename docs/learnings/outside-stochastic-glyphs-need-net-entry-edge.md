# 区间外勾叉的高目标盈亏比，不代表入场有净优势

- **问题**：Owner 根据 LPT 1H 两次上方1.618红叉，询问小止损高盈亏比以及指标共振。第二次叉后大跌容易让人忽略第一次叉后仍继续创新高。
- **死胡同**：把止损压窄并保留远处周一边界目标。固定0.5%时计划RR中位14.08，实际平均赢/亏为7.74，但胜率只有7.25%，扣手续费与滑点后每笔-0.511R；即使不计成本，平均价格收益仍负。逐项加放量、RSI极值/背离、BB回收、4H方向，也没有一组在2025年后转正。
- **有效路径**：先复现Pine默认显示门：已完成纽约周一、H1 Stoch5/3/3收盘勾叉、对应影线严格越界、周二至周五；再按下一5m开盘和同一目标，以原生VectorBT分别测试止损。638合约53,068次信号配同币/月/ATR档随机对照，区分计划RR、实际盈亏比、净R与资金收益。较早历史的4H顺势过滤盈利，后段却转负，不能以合并历史的微小正数作结论。
- **通用规则**：高盈亏比方案先检查胜率是否足以覆盖实际平均亏损及成本，再检查匹配对照与后段。若入场本身没有优势，改止损通常只是在胜率和赔率之间交换；下一轮应明确提出新的入场假设，而不能默认叠更多指标会成功。
- **牵连**：`yoyo/evaluation/h1_outside_glyph_signals.py`、`yoyo/evaluation/h1_outside_glyph_study.py`；实验 `exp-h1-outside-glyph-stops-20261102-v1`，生成前代码 `50f3ba28c5`。止盈为近侧周一边界、最长7天，maker2bp/taker5bp、市价每次滑点5bp；资金费与资金账户未建模。结果只否决本轮具体规则，不代表所有区间反转策略无效。
