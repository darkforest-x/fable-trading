# 统计检验通过断言，也不能忽略数值内核警告

- **问题**：四阶段入场研究的周块符号翻转测试虽然通过，但本机锁定NumPy的矩阵乘法对全零和小整数输入发出除零、溢出和无效值警告。
- **死胡同**：仅凭最终p值位于0至1或测试通过就继续运行，无法区分平台浮点状态异常与实际非有限结果；也不应为一个评估内核修改跨机依赖契约。
- **有效路径**：将小型矩阵乘法替换为明确的逐元素乘积再求和，显式拒绝非有限模拟值；在浮点警告提升为异常的条件下验证全零差异p=1，以及两周同正收益的精确零假设概率约为0.5。保留原随机种子、抽样次数和检验定义。
- **通用规则**：数值告警出现时，用可手算的小例子核对统计量；消除或解释警告后再解释显著性。警告本身不证明既有输出已错，测试通过也不证明数值路径可靠。
- **牵连**：`spike_v131_entry_stages_summary.py::signflip`及对应测试；未改NumPy或其他依赖。全量回放不使用此统计内核，修改仅发生在正式汇总执行前。
