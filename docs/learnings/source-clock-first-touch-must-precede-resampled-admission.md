# Locate first touches before admitting resampled candles

- **Problem:** Case4 uses UTC4h candles but completed America/New_York Monday anchors. Winter Monday closes Tuesday05UTC, inside the04..08UTC candle. An hourly prefix test copied into4h logic can wrongly reject valid histories or skip the actual first touch.
- **Dead end:** Counting complete4h slots from Monday assumes that the session boundary aligns with the signal grid. Merely dropping the straddling candle can silently promote a later touch to first touch; accepting it would let a partially unfinished Monday define its own level.
- **Effective path:** Compute the completed Monday anchor from source5m data, locate the first postMonday5m touch per week and side, then map that timestamp onto the4h grid. Require a fully postMonday pin plus three complete contiguous confirmations. A first touch inside the straddling candle consumes the opportunity without producing a signal. Check the crypto known prefix in source5m units; preserve spot observed-only limitations.
- **General rule:** Session clocks and aggregation clocks are separate contracts. Establish event order on the finest existing source clock before applying coarse-candle eligibility. Normalize datetime units before comparing integer durations; pandas can supply microseconds while Timedelta.value is nanoseconds.
