# 超额改善不等于被匹配的交易改善

- **问题**：V18 两根快反色确认相对 V17 的全251病例均净提高0.3092bp，154组匹配超额也提高0.6462bp，容易被同时正号误导。
- **死胡同**：只并列全池 D 与匹配 I，不检查它们不同的分母；或者只报新超额+5.6715bp。这会隐藏匹配病例本身均净从−16.0467降到−16.3418bp。
- **有效路径**：固定原154组三对照，分解 I=病例变化−自身控制变化。病例−0.2950bp，控制−0.9412bp，因此 I 正是因为控制恶化更多。保留97个匹配未知；不把全251的小幅改善套在154子集上。
- **通用规则**：任何相对收益改善，都先列同一分母的病例前后、控制前后、两者之差，再看绝对净收益、时间稳定性与区间。两边都亏不能被相对正号洗白。
- **牵连**：`experiments/active/exp-btcusdtp-1h-failed-confirm-preholdout-20260906-v18/results/summary.json` 的 arms.*.matching 与 effects；冻结154/251=61.35%覆盖仍不满足90%门。
