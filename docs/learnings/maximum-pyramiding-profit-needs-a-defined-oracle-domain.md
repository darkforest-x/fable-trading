# 最大滚仓收益必须先定义事后优化的可行域

- **问题**：Owner要的是已知盈利交易中100U最多两次加仓能达到的最大资金；此前报固定保利润策略的实际退出或最高浮盈，未回答最大化问题。
- **死胡同**：把原始R乘本金忽略了风险单位与账户仓位；把既定策略的最高浮盈当成最优忽略了初仓、加仓时机及数量；只要求高点高于买价也不够，手续费可能使新增一单位的净收益为负。
- **有效路径**：先固定原入场、完整bar时域、候选open/high、开仓保证金和每根low的维持约束。在零资金费、同线性费用、平坦MMR、连续数量和严格递增加仓价的限定模型里，早买一单位在共同后续路径上比晚买更便宜、保证金余量更大；以全剩余路径约束逐腿求最大量，再穷举完整时点。独立LP和小路径穷举验证，选中账本再逐bar核算。原cache行号与原交易行号可能不同，必须按UTC时间联结并核对距离，不能直接iloc原ordinal。
- **通用规则**：先区分“固定规则结果”“未来已知的条件最优标签”和“真实交易所可执行最大值”。没有历史mark、funding、risk tiers和订单规格时，只能交付条件标签。加仓边际净收益非正就不加；带资金费或分档约束不可沿用简单贪心最优证明。
