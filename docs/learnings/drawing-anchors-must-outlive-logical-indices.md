# Drawing anchors must outlive logical indices

- **问题**：The same candle changes logical index when older history is prepended or the rolling window advances. User-drawn measurements, trend lines and channels must remain tied to the chosen market position across those changes and timeframe switches.
- **死胡同**：Persisting pixels or current indices would make drawings drift. Reusing an endpoint's old interval volume after a timeframe change would also claim precision that the newly loaded candles do not support. These approaches were excluded before implementation.
- **有效路径**：Persist UTC-second/price anchors per symbol, reproject through the current candle-time index and series price scale, and interpolate fractional logical coordinates around LWC 4.2's integer coordinate conversion. Derive channel offset from three reprojected anchors so its boundaries remain parallel. Build volume/missing/gap prefixes on data receipt; measurement reads inclusive endpoint-candle volume and explicitly identifies incomplete coverage or a forming last candle.
- **通用规则**：Persist market coordinates, not viewport coordinates. Calculate measurement facts from the current data coverage, independently of the geometry used to paint them. Match volume units to the source field: OKX SWAP candle `r[5]` is contracts, not USDT turnover.
- **牵连**：`yoyo/monitor/static/chart-drawings.js`, `reclaim-chart.js`, `range-chart.js`; `tests/monitor/frontend_chart_drawings.test.cjs`; raw browser checks in `output/playwright/chart-drawings-20261027/`. [LWC 4.2 time scale API](https://tradingview.github.io/lightweight-charts/docs/4.2/api/interfaces/ITimeScaleApi), [series API](https://tradingview.github.io/lightweight-charts/docs/4.2/api/interfaces/ISeriesApi).
