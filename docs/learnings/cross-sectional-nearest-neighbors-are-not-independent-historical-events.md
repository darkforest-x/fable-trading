# 跨币最近邻不能冒充独立历史事件

- **问题**：用一个 BTC 4h 启动窗扫描多币宇宙时，多头最近邻前四名里有 DOGE、LTC、ETH 三个与参考在同一根 2026-08-19 12:00 UTC 启动。逐样本看都很像，但它们主要是同一次市场共振的横截面回声，不是三次独立历史复现。
- **死胡同**：只做“同币相邻 bar 去重”能清掉滑窗重复，却仍会把同一市场冲击在不同币上的同步投影逐个计数；按 top-N 行数汇报“历史上出现 N 次”会夸大时间独立性。反过来扫描后临时删掉同日币种也会改变已冻结的排名规则。
- **有效路径**：保留冻结 top-N 与原始距离，避免事后改榜；另加一个不参与选择的市场时间簇审计，把 24 小时内的跨币锚点作为同一“市场 episode”展示。于是可以同时诚实回答“有多少个相似币窗”和“来自多少个独立时间簇”。
- **通用规则**：任何跨资产 motif / 最近邻检索，第一张结果表同时报告样本数、同币排除区和跨币时间簇数；样本级相似度不能直接当独立事件数、显著性样本量或自然基率。
- **牵连**：相似度 top-N、event dedup、置换/随机对照的有效样本解释，以及面向 Owner 的候选计数；若未来要让时间簇参与准入，必须在扫描前预注册，不能看完榜后补规则。
