# Compile the generated JavaScript, not only the Python chart builder

- **问题**：A Python chart builder passed compilation and its data checks, but the real browser displayed an empty chart book with `missing ) after argument list`.
- **死胡同**：Python compilation checks only the template producer. Nested quotes in a Python string, a JavaScript string and an HTML inline event handler were transformed into invalid JavaScript after generation.
- **有效路径**：Inspect the browser error, extract the final inline script, and run `node --check` on those exact generated bytes. Replace inline event-handler interpolation with `data-case` attributes and `addEventListener`. Add the generated-JavaScript check to the focused regression suite, then verify actual canvases and screenshots in a browser.
- **通用规则**：When one language emits another, validate the emitted artifact in its own runtime. A producer's successful syntax check is not proof that its generated program parses or renders.
- **牵连**：`yoyo/evaluation/spike_coin_be_charts.py`, `tests/evaluation/test_spike_coin_be_charts.py`, and the local TradingView Lightweight Charts review page. The repair changes presentation only, not source candles, trade ledgers or strategy outcomes.
