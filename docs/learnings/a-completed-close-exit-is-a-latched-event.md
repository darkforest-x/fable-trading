# 收盘确认的退出是已发生的事件，不是下一开盘重新投票

- **问题**：V12 将信号小时的均线固定为结构边界，使用持仓后的 5 分钟收盘确认失效、下一根真实开盘退出。两个时间点之间可能跳空或反弹。
- **死胡同**：若下一开盘重新比较价格与边界，会取消已经确认的收盘退出；若直接按触发收盘成交，又把尚不可成交的观察时刻当成执行时刻。两种写法都不再是预注册的策略。这里是实现审查发现的风险，不是已运行失败的收益实验。
- **有效路径**：把已完成收盘触发保存为挂起事件，下一真实开盘只处理成交与优先级。原有行情有效性、跳空止损、变色退出和总期限优先；管理均线暂缺只重置原来的变色状态，不抹去有效价格收盘事件。影线触及初始止损时，止损已先于该根收盘发生。
- **通用规则**：跨观察和成交时钟的策略先明确事件是否可撤销；若不可撤销，保存触发证据及可用时间，并测试下一开盘反弹、源数据缺口、同刻原规则退出和未来影线扰动。
