# 浮盈变止损必须先证明浮盈发生在退出之前

- **问题**：Owner 要统计 SPIKE V12.8 近两个月有多少单曾经浮盈、最后止损。K 线 OHLC 同时给出最高价和最低价，却没有给出二者发生顺序；图表参考价与研究成交价也不同。
- **死胡同**：直接对入场至退出的全段求最高/最低价，会把止损成交之后的价格当成持仓浮盈。只读旧 `mfe_r` 又容易遗漏止损当根开盘已经出现的、可确定先于盘中触价的浮盈。把所有止损当亏损，还会混入盈利的追踪止损。
- **有效路径**：保留旧成交与止损优先规则；建立“退出前已观察到的 MFE”下界，包括完整存活 K 线与允许的退出开盘。仅盘中触止损的当根极值可作为上界，差额标注时序不明；开盘跳空止损和反向次开成交后不再观察当根高低点。分别统计价格浮盈与覆盖固定往返费用的浮盈、所有亏损退出与净亏的保护止损。盘中摸到 2R 与收盘达到 2R 启动追踪也分开。
- **通用规则**：在计算“本可赚多少”之前先写清成交时点、可观察价格集合和同根时序；同时写清分母是信号、成交、闭合成交还是图表参考框。MFE 是事后描述，不能直接当成可兑现收益或入场特征。
- **牵连**：`yoyo/evaluation/spike_v1_v8_be05.py` 的固定成交退出；`yoyo/evaluation/pine/spike_burst_v12_8.pine` 的 `f_path`；`yoyo/evaluation/spike_v128_recent_report.py`；`experiments/active/exp-spike-v128-recent-20260923-v1/PROJECT_PLAN.md`。本轮未改止损、2R/4ATR、20bp 或真实仓位。
