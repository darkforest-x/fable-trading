# 交易回放需要独立图表区域，不能靠平移避让悬浮列表

- **问题**：回测交易列表、实时账户信息和开平仓长标签叠在同一张 K 线上，用户无法快速对应成交位置与价格。
- **死胡同**：旧实现根据悬浮列表宽度额外平移图表，只补偿横向遮挡；仍然保留无关实时信息，手机上也无法解决文字与蜡烛互相遮挡。
- **有效路径**：先按 Stitch 设计划分顶部交易摘要、桌面侧栏和独立图表区域；手机选择交易后收起列表。图内只用编号标注，摘要读取同一份原始成交价格与时间区间，实际成交线段不移动。图表按可用宽度选择附近 K 线数量，长持仓仍同时包含两端。
- **通用规则**：先为图表分配真实可用空间，再决定视窗；信息精简应搬移重复文字，不能伪造更精确的成交时间。验收必须覆盖同 K 开平、跨日区间、不同显示周期和返回行情时的状态恢复。
