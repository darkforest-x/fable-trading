# 小量级非零指标必须用保量级格式展示

- **问题**：LightGBM gain 的真实值为 `0.013939...`、`0.006868...`，报告用固定一位小数格式后全部显示为 `0.0`，让读者误以为模型没有使用这些特征。
- **死胡同**：继续用统一的 `:.1f` 展示所有数值，或只依赖 CSV 让读者自行核对。前者抹掉量级，后者让主报告与证据互相矛盾。
- **有效路径**：对 gain 使用六位有效数字而非固定小数位，并加入覆盖小非零值、零值和缺失值的单元测试；这样既保留量级，也不会制造无意义的长尾小数。
- **通用规则**：报告生成器必须按指标量级选择格式；任何非零审计指标在主表里被舍入成零都应视为展示失败，并用最小非零回归样例锁住。
