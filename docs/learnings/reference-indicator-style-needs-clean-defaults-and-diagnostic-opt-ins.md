# 参考指标的默认视觉应克制，诊断层应按需开启

- **问题**：形态指标虽然把均线、评分、仓位框和状态表都画全了，但默认全部展开会遮挡 K 线，也偏离 owner 给出的参考指标样式。
- **死胡同**：把“功能完整”直接等同于“所有图层默认可见”。这适合调试，不适合日常盯盘；缩小窗口也无法解决颜色冲突、标签堆叠和信息层级混乱。
- **有效路径**：先锁定参考指标的稳定视觉语法——青色/橙色 K 线、单根细 SMA40、微型关键点和低对比关系线——再把六均线带、HUD、预览点和仓位框保留为可选诊断层。样式修改与形态、间距、入场、止损和告警逻辑分离，并用静态检查固定默认值与色板。
- **通用规则**：复刻参考指标时，先提取“默认可见层、色板、线宽、标记密度”四项视觉契约；研究辅助信息默认关闭，但不要删除。
- **牵连**：`experiments/active/exp-two-key-candle-feature-atlas-v3/pine/fable_two_key_candle_sma40_retest_v1.pine`、`scripts/validate_two_key_candle_pine_indicator.py`、TradingView Basic 套餐的指标数量上限；不涉及 1h 形态参数、holdout、阈值或实盘执行。
