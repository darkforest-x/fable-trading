# 派生审核图相同，不等于原人工框可以合并

- **问题**：整理旧2513框与最新HL2事件时，旧池17组审核图完全重复，也同时属于别名候选。如果按图片SHA直接删重，会丢掉原框身份和已有人工答案。
- **死胡同**：把相同像素、同币相近时间和相交上下文都叫“重复”。中央截取可以把两个原框压成同一张审核图；不同交易所的同币同期走势也可能相似。这些证据都不能自动转移人工裁决。
- **有效路径**：分别记录原框ID、原几何、源交易所、核心区间、可见依赖和图片SHA。原框和答案全部保留；重叠只形成后台复核关系，已提交/无目标/矛盾/未审独立记状态。
- **通用规则**：先确定要去重的是图片、形态事件还是人工工作记录。只有同一层的身份和证据相符，才讨论合并；派生图相同不能覆盖原人工证据。
