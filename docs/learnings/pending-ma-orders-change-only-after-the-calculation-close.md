# 均线挂单只能在计算柱结束后修改

- **问题**：15m 均线回踩需要动态限价，但新均线值不能反过来决定同一根 K 线已经发生的成交；回到周一区间的失效与入场也有先后顺序。
- **死胡同**：先在完整 OHLC 上找均线触碰、再把找到的价格交给框架，已经替框架提前决定成交；只按最后收盘统一取消，则会抹掉盘中先成交后止损的真实亏损路径。
- **有效路径**：信号层只输出已收盘时点的挂单/调价/累计新低取消事件。原限价先由 Nautilus 撮合，收盘后才改未成交单；成交即冻结止损。区间边界失效在显式 O-H-L-C 原生执行段中检查，只取消仍在等待的单。
- **通用规则**：分清信息可得时点、订单生效时点、原生撮合时点；不能用事后失效删除已经成交的交易。OHLC 顺序是假设，必须披露，不能说成真实逐笔行情。
- **牵连**：`yoyo/layers/l3_backtest/nautilus_independent.py` 的 `entry_updates`、`cancel_boundary`，以及 `tests/evaluation/test_nautilus_pending_ma.py`。2026-10-24 的20项原生回归检查通过；真实历史结果另由实验登记。
