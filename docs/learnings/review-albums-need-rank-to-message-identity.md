# 批量复盘图的排名必须联结到每条远端消息

- **问题**：把448笔赢家中的前50笔发到群里，原盲审编号不代表收益排名，重复曝光卡也不是新交易；相册发送成功还需要核实每张是否送达。
- **死胡同**：直接拿盲审文件夹前50张，会混入对照组和重复卡；只记录“相册已发送”，无法回答某一排名对应哪笔交易、哪张图、哪条消息。
- **有效路径**：从有哈希的私有映射筛出448个不重复赢家，以最终净R降序和event_key稳定排序，再保存rank/event_key/visual_id/图片SHA；每批10张的返回Message按顺序联结rank与message_id。发送前持久化pending，模糊回执停止，不自动重发。
- **通用规则**：排名展示、研究样本身份、视觉卡身份、远端消息身份是四个不同字段，交付前冻结它们的映射；不要用文件名顺序替代排序规则。
- **牵连**：`yoyo/evaluation/spike_10r_top50_charts.py`、`yoyo/evaluation/spike_10r_top50_telegram.py`；本轮用photo相册方便群内查看，不宣称TG压缩后字节等同本地PNG。原始图另存本地，历史复盘图不进入盲审或训练输入。
