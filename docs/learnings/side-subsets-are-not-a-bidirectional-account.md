# 分方向的交易子集不是双向策略账户

- **问题**：按策略和方向分组后重算复利与回撤，会把双向持仓序列拆成两个假想账户；再把其中一个数字写成策略回撤，会丢掉真实的交替盈亏顺序。
- **有效路径**：胜率、PF 和单笔 R 可以按方向拆分；账户余额必须限定同一交易所、合约、周期、连续区间和策略，合并该策略的多空交易并按实际入场时间排序。未平仓截尾不冒充已实现交易。
- **边界**：本轮只计算独立单币 1x 名义仓位的平仓余额曲线，不能当作全市场共享资金账户或盘中盯市回撤。单笔净收益不大于 -100% 时标明破产模型缺失，禁止继续复利负余额。
- **证据**：`tests/evaluation/test_spike_v7_v1_report.py` 验证先 +10%、再 -20% 的多空序列最终为 -12%、平仓回撤 20%；后续未实现标记不改变这两个值。
- **牵连**：`yoyo/evaluation/spike_v7_v1_report.py` 的 `independent_account`，独立账户明细与原始方向子集统计分别输出。
