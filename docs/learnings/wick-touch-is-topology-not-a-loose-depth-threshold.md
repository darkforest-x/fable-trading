# “影线踩线”是几何拓扑，不是一个宽松的 touch-depth 阈值

**日期**：2026-09-04
**类型**：形态语义缺陷 / 反直觉回测结论

- **问题**：Owner 定义的 K2 是“影线踩在均线上”，但 Pine v8 `Core recall`
  把它编码成 `touch_depth_atr >= -0.05`。这会放进两类非等价形态：K2 极值根本
  没有到达 SMA40，以及 SMA40 直接穿过 K2 实体。两者都不是“影线回踩、实体拒绝”。

- **死胡同**：只把 `k2_wick_share` 从 0.25 提到 0.60。影线再长也不能证明它碰到了
  均线，也不能证明实体没穿线。本轮 49 笔中，`wick_share < 0.60` 仍包含 12 笔赢家，
  因此粗暴抬高影线比例会同时砍掉真信号，还没有修复核心语义。

- **有效路径**：先将自然语言拆成两个不变量：

  1. K2 极值必须真正到达 SMA40，即 `touch_depth_atr >= 0`；
  2. K2 实体必须完整留在趋势一侧，均线只能穿过拒绝影线。

  当只看“实际到达均线”时，通过/不通过为 45/4 笔，未到达的 4 笔全败；
  加上“实体留在趋势侧”后，通过组 36 笔中 17 胜、+13.8bp/笔、PF 1.462，
  不通过组 13 笔仅 2 胜、-36.0bp/笔、PF 0.256。这是 holdout 后验诊断，只能生成
  下一个预注册假设，不能在同一快照上宣布新策略通过。

- **通用规则**：形态规则里的“穿越”“影线触及”“实体留在一侧”都是**拓扑关系**。
  先用 OHLC 与参考线的大小关系把拓扑编对，再用 ATR 阈值控制容差和强度。
  不能用一个可为负的距离阈值代替“已经相交”，也不能用影线比例代替实体与均线的关系。
