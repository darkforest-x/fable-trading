# 复刻 Pine 外观要读取用户保存的样式，不能只看源码

- **问题**：用户要求沿用自己的 IMACD 默认样式；旧源码的主线声明为 histogram，但实际添加到图表后是蓝色实线。
- **死胡同**：先把源码默认值当成用户习惯，再自行配色和精简柱图，虽然编译正常，仍然没有满足用户的外观要求。源码只能证明初始声明，不能证明 TradingView 保存的样式覆盖。
- **有效路径**：只读打开用户原脚本，临时添加参考实例，逐项查看“样式”中的线型、颜色、粗细与不透明度。实际主线为 #2962FF、40% 不透明度、2px 实线，信号线为 #FF9800、100%、2px；零轴为 #787B86、50%、1px。将这些值固化进新脚本，再按用户明确要求移除柱图。并排检查后移除临时参考实例。
- **通用规则**：用户说“我设置的样式”时，先检查账户保存的样式覆盖，再决定代码默认值。Pine 的 transparency 与 UI 不透明度互补，40% 不透明度对应 color.new(..., 60)。复刻默认样式不等于改参考脚本。
- **牵连**：`yoyo/evaluation/pine/imacd_dense_mtf_v1_2.pine`；TradingView 原脚本 `zzc-20251222-1.0-Impulse MACD` 第 6 版只读；新系统原账户脚本保存为第 3 版，核心计算与警报保持一致。
