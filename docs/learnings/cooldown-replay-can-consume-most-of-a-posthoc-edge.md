# 冷却重放可以吃掉大部分事后分组优势

- **问题**：15m `gap >= 5` 在 2023 已成交账本中两个半年至少各改善 18.02bp/笔，合并净 +5.63bp；但把相同门槛放回候选生成点并在 2024 重跑后，净收益仅比基线改善 1.91bp、稳健分改善 2.83bp，仍为负。
- **死胡同**：把跨时间同向、甚至通过多重搜索置换的账本子集当成接近可执行的候选。时间稳定性与多重检验只能限制统计碰巧，不能修复状态机占位错误。
- **有效路径**：核对交易身份变化而不只比较均值。基线 194 笔中只有 70 笔保留，124 笔被删，同时释放的六小时冷却位引入 60 笔新交易；这些替代交易把事后显示的约 18bp 稳定改善压缩到不足 3bp。
- **通用规则**：有 cooldown/互斥状态的系统中，分段发现之后的第一张验收表必须包含 retained/removed/added 三类身份计数；若新增交易占候选很大比例，事后子集效应大小只能用于提名，不能用于收益预期。
- **牵连**：BTCUSDT.P 15m gap 2–8→5–8、六小时 cooldown、2023 failure map、2024 exact replay、匹配随机对照；audit 与 holdout 未开启。
