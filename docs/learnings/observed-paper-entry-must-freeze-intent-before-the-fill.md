# 到达后模拟必须先保存意图，再等待未来入场

- **问题**：V13.1 信号在确认收盘后才被程序发现，信号中心的次开盘参考价格可能早已错过；直接累计其收益，不能回答延迟后的执行效果。
- **死胡同**：直接复制事件的 performance、把 detected_at 改成成交时点，都会保留已经不可获得的历史价格。让所有周期共用旧 4ATR 适配器也不成立：V13.1 的 1H 是 2ATR，因此本次只接 15m。合约代码的外观不能证明资产类别。
- **有效路径**：沿用独立 worker，在保留信号和闭合行情前缀后记录实际 observed_ms，再预定严格晚于它的下一开盘；后续以精确对应 K 线的 open 模拟，沿用原止损并重算风险。缺 bar 截尾，风险失效拒绝，不补造入场。原次开盘仅从对应行情取作价差诊断，不读 performance 决定成交。多空及资产类别独立汇总；类别冻结登记时 OKX instCategory，新上市未知就保留未知。10 条多空退出路径与 canonical V13 回放对照，44 条现有记录同入场核对价格全部一致、净 R 最大误差 6.3e-15；这证明退出适配一致，不证明新的前向盈利。
- **通用规则**：先分开信号时钟、观察时钟、预定执行时钟和数据到达时钟。只有入场意图已在当时保存，后到的闭合行情才可结算该模拟。价格差不是盘口滑点，累计 R 不是账户收益；成本、资金费和退出延迟的建模范围必须随运行保存。
- **牵连**：`yoyo/research_workspace/paper_v131.py`、`paper_source.py`、`paper_store.py`、`strategies.py`；原 30 分钟新鲜度、2R/4ATR、20bp 不变。新运行从创建时起积累，源代码变更仍停止旧运行，production_eligible=false。
