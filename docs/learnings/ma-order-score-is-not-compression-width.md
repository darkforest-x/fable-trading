# 均线排列分数不能替代密集宽度

- **问题**：为 SPIKE V1/V8 筛选 ChartPrime 辅助指标时，Composite Trend Oscillator 的 Trend Strength 分数接近零容易被误读为「均线压缩」。
- **死胡同**：把多个指标同时变绿视为独立共振，或把排列分数的零轴区域直接当作 BB/六线的密集区域。它们回答的问题不同。
- **有效路径**：核对发布者公开 `get_score` / `net_score`：Trend Strength 根据不同周期滤波值的两两次序评分。次序不变时，把相互距离放大并不会改变原始次序分数。手工四值反例 `[100.002,100.004,100.001,100.003]` 和 `[120,140,110,130]` 按该次序算法都为0分，宽度分别0.003和30；这是公式示例，不是市场回测，也不是完整滤波序列。
- **通用规则**：宽度度量整理压缩，次序度量排列，分数变化度量排列形成；须分别记录。候选组合可研究「真实压缩已发生，排列随后转向并扩散」，不能只要求分数在零附近或多个均线类工具同色。收益改善尚未验证。
- **牵连**：V8 现有 BB200 准入与六线结构不应被次序分数替换；Volatility 模式另有带宽缩放，不可与 Trend Strength 的幅值混用。当前未修改策略、参数或通知。
