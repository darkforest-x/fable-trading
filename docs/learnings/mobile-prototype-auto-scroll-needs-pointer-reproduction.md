# 手机框架出现位移时，先区分自动滚动与实际指针操作

- **问题**：2026-10-18，独立合约原型经浏览器定位器点击后，手机状态栏被裁切，隐藏键盘露出底部；同时输入框失焦时立即收键盘，会使随键盘移动的导航按钮在 click 前换位置。
- **死胡同**：只给应用内容增加裁切、涂白安全区或取消 blur，不能消除设备容器的 scrollTop；后者还会留下失焦后不收键盘的行为。不能因为页面截图异常，就修改受保护的手机模板或认定真实设备存在同一问题。
- **有效路径**：分别检查 DOM 容器滚动量，并用 CUA 原生 AX 点击重放相同步骤。定位器点击后的 device-screen scrollTop 曾达 65.5；刷新后用实际指针完成输入聚焦、导航切换和返回示例按钮，所有容器 scrollTop 均为 0。应用按钮在 pointerdown 阻止提前转移焦点，由 click 先收键盘再切页；输入 blur 规则保留。模板文件未修改。
- **通用规则**：自动化操作会引入滚动和焦点副作用。先用实际指针复现，并区分模拟器容器、应用滚动区和输入焦点；再修正归属明确的行为，不用截图掩盖真实状态。
