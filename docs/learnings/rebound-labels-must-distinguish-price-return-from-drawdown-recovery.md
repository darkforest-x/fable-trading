# 回到原价和回收实际跌幅是两种反弹标签

- **问题**：报警后选接针候选，需要区分“快回到报警前附近”与“从深针底部大幅反弹”。固定5%下探门槛再要求收盘回到参考价97.5%，不能代表任意深度的针都回收一半跌幅。
- **死胡同**：把FHE从约0.0154弹回0.023以上仍记为没有恢复，会让一个合法但更严格的标签冒充Owner所说的反弹。反过来直接覆盖旧标签、只保留更好成绩，也会变成看结果调定义。
- **有效路径**：保留V1近原价标签，单独登记V2按实际15分钟最低点计算回收一半跌幅。报警、候选、事前特征、排序和匹配控制逐项保持一致；V2明确为看过V1后新增的描述性指标。五分钟边界上下界仍保留，没有假装知道针底成交或盘中先后。
- **通用规则**：定义恢复之前，先写清参照价、实际最低点、恢复幅度及截止时点，用原始案例检查语义。不同参照的结果不能互相替代，也不能把未来针底标签当成可事前挂出的成交价。
- **牵连**：`exp-alarm-laggard-selection-20261029-v1`与`exp-alarm-laggard-recovery-20261029-v2`；13项合成因果/时序测试通过，V2逐候选特征和选择与V1一致。两种口径均没有确认优于随机候选的优势，原FHE仍未进入固定前50名单。
