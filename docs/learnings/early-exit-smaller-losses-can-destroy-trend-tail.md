# 提前退出减少单笔亏损，也可能破坏趋势尾部

- **问题**：趋势信号入场后两三根不推进或回到均线带，是否应当更早认错？
- **死胡同**：只看平均亏损变小或回撤下降，就把早退称作优化。早退也会截断后续趋势，并释放仓位接受原策略原本不会开的新单。
- **有效路径**：固定入场、初始风险和成本，完整重放退出与重入；同时追踪原基线完全相同入场的实际10R赢家，而不是用新增赢家补足数量后声称原趋势没丢。开发期必须只读取分割前的完整前缀，不能把分割后才退出的旧持仓收益用于选择。
- **本轮开发证据**：V8两根不推进退出将平均亏损从-1.020R缩小为-0.744R，却只保留原198笔10R中的143笔，并增加2450笔交易。四条候选的同池独立账户平均收益均下降；没有一条通过事前选择规则。验证结果另见最终报告，不能由开发结果代替。
- **通用规则**：把亏损幅度、尾部保留、重入次数及同一账户集合的收益放在一起评价。更小的止损损失是路径变化，不自动等于更好的系统。
