# 显式下钻到某笔交易时，禁用列表的默认焦点

- **问题**：从盈亏日历点进具体交易，需要同时打开既有历史回放；旧列表打开逻辑会在异步读取完成后自动选中 Top 1。
- **死胡同**：只按币种打开列表，或先显示指定交易再沿用默认自动选择，都会丢失原交易身份；同币也可能有多笔交易。
- **有效路径**：日明细保留原资金账本的策略与交易 ID，按 UTC 结算日筛选且不重新编号。显式传入交易时立即定焦并关闭默认自动选择；分页、重试和恢复读取均不得覆盖该焦点。
- **通用规则**：默认选择仅在没有用户显式选择时执行；异步响应还须通过策略/请求代次检查。金额下钻须先核对明细总额与来源汇总一致。
