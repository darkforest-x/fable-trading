# 短窗上"有用"的入场门，长窗上可能把每笔期望做得更差

- **问题**：RSI 区域门在 4.4 个月（75→58 笔）上把总亏从 −11.02R 减到 −8.41R，每笔 −0.1469→−0.1450R，
  看起来至少是中性偏好。把同一个门放到 28 个月（652→486 笔），每笔变成 −0.0995→−0.1176R，
  **方向反过来了**。四个门（RSI 线、◈ 同根、◈ 20 根窗、SAR 方向）在长窗上无一例外让每笔更差。
- **死胡同**：用总净 R 判断门的好坏。门必然减少交易，总亏也就必然变小；短窗里这个机械效应
  足以盖过每笔期望的变化，见
  [`fewer-trades-can-improve-equity-with-worse-per-trade-expectancy.md`](fewer-trades-can-improve-equity-with-worse-per-trade-expectancy.md)。
  短窗的每笔差值（+0.0019R）本身也远小于其噪声，把它当"中性偏好"就是把噪声读成了信号。
- **有效路径**：先把窗口拉到手上能合法拿到的最长 pre-holdout 段，再看**每笔净 R** 和
  与占仓无关的事件级标签置换。长窗里四个门的置换 p 是 0.49/0.74/0.65/0.56，全部无信息；
  短窗那点差值在长窗上消失并反号。
- **通用规则**：门的验收指标是每笔期望，不是总额；窗口不够长时不要下"中性/略好"的结论，
  写"分辨不出"。评估门之前先估一下这个窗口能分辨多大的每笔差异。

  `exp-eth-bb-stoch-longrun-diagnosis-20260916-v1`（28 个月）的同门对照。
