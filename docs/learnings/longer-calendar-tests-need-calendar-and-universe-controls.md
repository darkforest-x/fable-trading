# 拉长时段研究后仍要拆开年份和币池构成

- **问题**：近两个月选出的 SPIKE 北京时间时段，在 2023 年至 2026 年扩窗后仍可能有正的合并均值，但不能因此认定长期时段优势。
- **死胡同**：只增加历史长度或交易笔数，仍把不同时期、不同上市币池混在一个平均数里；较新币种主要出现在较晚年份，两条变化没有被控制。
- **有效路径**：固定旧候选，再做实际入场时间的逐年统计与起点前已存在币种的敏感性检查。15m 普通回踩 20–24 点全池 2256 笔为 +0.1191R/笔，但 2023 年 270 笔为 -0.3900R、2026 年至截止日 775 笔为 +0.2914R；固定 135 币全期 761 笔为 -0.0189R。它们说明结论对年份和样本构成敏感，并没有识别出某一条单独的因果机制。
- **通用规则**：时段排名同时保留分年、固定币池、样本数和同钟面对照；全期冠军只作探索候选。48 个主要时段比较的 Holm 校正 p 值均为 1，不能把拉长历史当成策略已经验证。
