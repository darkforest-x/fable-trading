# 极简首先减少重复决策，不能清空用户状态

- **问题**：市场同屏重复记录入口、范围与排序分两层、正常状态占据整块侧栏；其他页面又重复标题、页内索引和筛选面板，真正内容被挤到下方。
- **死胡同**：此前保留原结构只调整颜色、间距与按钮外观，仍要求用户在同级入口之间做重复判断。单纯把整块筛选隐藏又会连搜索和生效条件一起藏掉。
- **有效路径**：合并行情与范围控制，移除重复入口和自动索引；次级操作按需展开。搜索、筛选结果和异常状态继续可见。折叠只改变原控件的 hidden 状态，保留监听器、输入值、图表节点和交易确认归属。测试验证关闭后条件仍生效、打开后原节点与值未变。
- **通用规则**：先画主要任务与入口归属，再删除重复决策；每个折叠都检查“当前条件是否可见、状态是否保留、风险是否仍明确”，不能以少几个按钮替代这些验证。
- **牵连**：`workspace-panels.js`、`workspace-layouts.js`、`workspace-minimal.css/js`、`market-terminal.js`、`market-sync.js`、`yolo-detect.js`、`DESIGN.md`；六均线、全市场排序、交易确认和新鲜度门未改变。
