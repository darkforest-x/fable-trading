# Extending a backtest past its end must keep the universe its cross-sectional features were counted on

- **Problem**: The owner asked for an October 2026 run of the live-wick accounts. The frozen Monday 1618 ledger ends in late September, so the 5m series were extended with Binance daily archives and the events and entry scores were rebuilt with the unchanged code. The first rebuild agreed with the saved scores only roughly (median |diff| 0.106, then 0.003 after the first fix), and October had 1 survivor instead of the usual dozen or so.
- **Dead ends**:
  - Taking "same code, same data" as proof. Two separate causes were hiding behind it, and only the per-feature comparison against the saved event features found them.
  - First cause: the framework environment runs pandas 3, which parses the touch times at microsecond resolution. `astype('int64')` then returns microseconds, so the 24h window in `cluster24` covered 1000 days (about +400 symbols per event). This was already known (see [timezone-normalization-does-not-normalize-datetime-resolution.md](timezone-normalization-does-not-normalize-datetime-resolution.md)) but came back because the code ran in a different interpreter than the one that wrote the original.
  - Second cause: using every symbol in the data group (626) as the population. The score model's `cluster24` ("other symbols touching the same side in the prior 24h") was counted on the 536-symbol snapshot of the backtest. The 95 later listings added about 9 symbols per event, which pushed scores down and flipped about 0.4 percent of the 0.5 decisions.
- **What worked**: Treat parity on events that already have a stored value as the gate before reading any new-period number. Compare feature by feature, not only the final score. That showed the exact matches (approach, Monday close side, opp_first, the bar features) and singled out `cluster24`. Pin the universe as a committed list next to the config, then convert epochs with `.dt.as_unit('ns')`. After that, the stored scores reproduce (median diff 0, max 0.0017 from the three 1m symbols not extended, 0.5 / 0.6 agreement 100 percent). The same E20 fills match the saved stop grid trade by trade (33/33, 0 bp).
- **General rule**: When a backtest is extended to new dates, any feature that counts across symbols (clusters, ranks, breadth) depends on the population as much as on the code. Copy the original universe into the experiment, keep later listings out of both trading and counting, and rebuild a stretch of already-scored history as a parity check before trusting the new stretch.
