# 星号转发壳不会可靠导出私有运行钩子

- **问题**：仓库迁移后，旧脚本从兼容转发模块导入下划线开头的设备解析函数，导入阶段就失败；模型本身尚未运行，入口已经断开。
- **死胡同**：假设 `from canonical import *` 会把私有名称一并转发。Python 默认排除下划线名称，因此兼容壳看似覆盖模块，实际没有覆盖私有运行钩子。
- **有效路径**：把跨模块确实需要的设备解析器提升为规范层的公开函数，调用方只依赖公开名，并增加入口导入检查。
- **通用规则**：任何穿过兼容转发壳的依赖都必须是公开 API；新增或迁移壳后，至少执行一次所有 CLI 入口的无副作用 import smoke。
- **牵连**：`yoyo/layers/l1_detection/candidates.py`、`scripts/check_symbol.py`、`src/` 旧路径转发壳、层间 import 守门测试。
