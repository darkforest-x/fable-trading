# 今日列表不能只过滤最近一页

- **问题**：触价和已结束列表需要按北京时间展示今日记录，跨日未平仓触价需要保留，往日记录移入历史入口。
- **死胡同**：检查发现原接口仅返回最近 100 条。在浏览器直接按日期过滤这一页，会漏掉较早但仍持仓的触价，也不能访问更早历史；替换原有数组又会影响顶部币种评分与 K 线选单。
- **有效路径**：保留近期图表投影，另加今日记录投影与按需分页历史接口。已结束按最终退出时间归日，触价按触价时间归日。跨日例外通过精确 signal_id 联结有真实成交且剩余本金大于零的资金持仓，排除影子、未成交挂单和零余仓。
- **通用规则**：日期分组先明确时区、业务时间字段和跨日例外，再决定查询边界；分页窗口不等于完整账本。展示筛选不能改变账户累计统计或其他视图的数据契约。
- **牵连**：`yoyo/monitor/monday_reclaim_paper.py`、`static/monday-reclaim-paper.js`；今日为 Asia/Shanghai 的 `[00:00, 次日 00:00)`，历史入口只读，原交易逻辑不变。
