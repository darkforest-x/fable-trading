# 不同周期的连续段编号不能直接比较

- **问题**：匹配控制用小时 segment_id 与 5min segment_id 比较，试图确认信号、颜色与成交来自连续行情。
- **死胡同**：默认两种聚合得到的递增编号代表同一段。一小时内缺两根分隔开的 5min 时，原始段号增加两次，小时聚合只增加一次；后续正常行情也会永久被拒绝。
- **有效路径**：将小时开始映射到原始 5min 的段号，再在同一个原始编号空间检查颜色与成交；小时段号仅管小时滚动窗口。用一小时内两个缺口的合成回归钉住。
- **通用规则**：跨分辨率联结比较实体身份前，先证明编号由同一命名空间派生；不能拿局部累计数当全局身份。
- **牵连**：V3 control matching 的 known_ltf_colour、entry_segment_valid 与源数据连续性检查。
