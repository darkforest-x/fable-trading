# 盲重复必须保持相同的预框暴露状态

- **问题**：校准包既要用盲重复测 Owner 标注一致性，又要用一半显示、一半隐藏的 v10 预框测锚定偏差；两种实验若在同一事件上随任务随机化，会互相污染。
- **死胡同**：把“是否显示预框”按 task_id 独立抽签。这样同一事件的原任务和盲重复可能一张有框、一张无框；标签不同无法归因于人工不一致，也无法干净归因于预框锚定。
- **有效路径**：先在唯一 `event_id` 层冻结预框可见性，再复制成盲重复任务；重复任务只随机化位置和 task_id，像素与预框状态保持完全一致。用文件哈希断言每组重复图片相同，预框显隐实验则在不同唯一事件之间比较。
- **通用规则**：任何盲重复测量都必须先列出全部实验干预（预框、提示词、缩放、未来窗、图片版本），并在 repeat group 内逐项固定；只允许任务顺序和匿名编号变化。
- **牵连**：`scripts/build_eth_3m_dual_view_calibration.py`、`analysis/output/eth_3m_calibration240_preview/private_manifest.csv`、后续 Label Studio 导入与一致率/锚定偏差分析。
