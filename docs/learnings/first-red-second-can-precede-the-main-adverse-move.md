# 第一根秒线阴线可能出现在主升段之前

- **问题**：Owner 看到 WEN 在上方 1.618 已做空、秒线却继续上涨，提出等第一根 1s 阴线再入场；需要区分点位改善、见顶确认与整套策略收益。
- **死胡同**：只看 WEN 的明显改善，或使用阴线开盘价、最高价作为等待后的成交价，不能验证这个规则。阴线只有收完才可知，且亏损筛选样本无法统计漏掉的盈利单。
- **有效路径**：复用修正前视后的 60m 原生框架账本，先按原结果固定最近三个月最差三笔空单，再取同交易所逐笔档案。触价后首根阴线收完，取随后第一笔成交作为价格参考。WEN 的下一秒开盘相对原位提高 3.04%；BTR、BR 分别提高 0.44%、0.28%，ONE 降低 0.11%。后三笔只等待 1.48–4.51 秒，之后价格仍上涨。没有计算新策略盈亏或改动原账本。
- **通用规则**：把“价格更好”与“方向反转”分开检验。秒线确认必须标记可知时间，再考虑可成交报价、延迟与 taker 成本；首次红 K 也可能是主升浪开始时的噪声。策略有效性必须回到全信号与对照，不能只挑亏损案例。
- **牵连**：`yoyo/evaluation/monday_seconds_entry_audit.py`；`experiments/active/exp-monday-seconds-entry-audit-20261028-v1/summary.json`。三例触价 5m OHLC 全部吻合；BR 成交量吻合，BTR、ONE 档案成交量分别差 0.000420%、0.000918%，原因未查明并保留，不宣称三例均通过 OHLCV 一致性。历史原亏损按入场名义金额计算，资金容量未参与此筛选。
