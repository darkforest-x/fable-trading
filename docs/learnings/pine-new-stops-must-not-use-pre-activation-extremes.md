# 新止损只能由生效后的价格触发

- **问题**：ETH BB × Stoch 指标首次碰对侧 BB 平半并移保本。K 线的 high/low 是整根累计值，无法代表保本生效以后的区间。
- **死胡同**：草稿先用整根 high/low 判断碰轨，再用同一组极值判断保本，会把止盈前的低点误判成止盈后的回撤。实时成交参考若沿用 bar open，也会把之前的开盘价错套到刚生效的保本单。动态 BB 还会使旧极值与新轨道错误配对。
- **有效路径**：实时用当前 update 的 close 与当时 BB/有效止损比较，下一 update 才检查新保本；数值事件用 UDT 的 varip 字段保留。历史明确只作 OHLC 近似：先旧止损，再碰轨；新保本同根只以触轨后必然发生的收盘回穿确认。用“先低后高且收在保本上方”的反例与跳空样例检查共享转移函数。
- **通用规则**：新增或移动一个阈值时，先标记生效时点，再核对观察值的时间范围；累计极值不能自动用作后续事件证据。实时无法重建的历史路径须声明近似，不能承诺刷新前后一致。
- **牵连**：`yoyo/evaluation/pine/eth_bb_stoch_reversal_v1.pine` 的 `f_step`；初始止损1.5%与首次平半50%均为 Owner 授权；本次未读取研究行情或回测。
