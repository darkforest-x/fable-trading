# 派生事件图库不能假设源事件已有 chart 字段

- **问题**：语义门结果直接由候选账本重新去重，事件具备完整 K 线索引、方向和框坐标，但没有旧扫描器写入的 `chart` 路径；全局未来图库在生成第一张图前因 `KeyError: chart` 失败。
- **死胡同**：把 `chart` 当作事件身份的一部分，等于把可复算的检测事实绑死在某一轮展示产物上；为绕过错误去改冻结 `summary.json` 又会破坏评分回执，并让纯展示修复看起来像结果变更。
- **有效路径**：图库优先保留已有源文件名；缺失时只用已经冻结的 `order + symbol + side` 派生稳定文件名。修复前确认 staging 已清理且一张图都未写，再单独提交 delivery fix；语义门、候选、阈值、事件和评分回执均不重算。
- **通用规则**：派生视图只依赖事件的语义身份与可重放坐标；图片路径是输出属性，不是输入前提。展示层故障必须用独立回执记录修复前后 builder hash，并明确是否写出过部分产物、是否触发过模型或评分重跑。
