# 先数清拒绝集合，再判断放宽过滤是否还能降噪

- **问题**：突破后下一根必须收在原箱顶之上的过滤损失了许多及时启动；改成只拒绝跌破箱底，看似可以保留回踩并继续明显减信号。
- **死胡同**：只看几个回踩后大涨的例子，直接把“箱内可接受”当成兼顾召回与降噪的办法。这个结论缺少所有候选的集合大小，成功案例也不是候选胜率分母。
- **有效路径**：冻结原候选当时的箱体，先在不读标签的步骤把所有下一根收盘分成 above/inside/below/unknown，再按旧真实事件时钟联结正标签。10386 个候选中只有 25 个 below，3419 个 inside；原 F 丢失的 292 个及时正命中全为 inside。因此仅放宽到“箱内允许”最多只直接拒绝 25 个已知候选，不能据此承诺大幅减信号；这不是其收益测试。
- **通用规则**：任何“放宽后两全其美”的提议，先核对新拒绝集合的绝对数、未知数与固定目标的数量上限。候选分布、标签锚点覆盖、交易胜率三种单位分开，不能互换分母。
- **牵连**：`yoyo/evaluation/spike_burst_v3_retest_diagnostic.py`、`experiments/active/exp-spike-v3-retest-diagnostic-20260910-v1/results/`。本诊断复用已经授权且已观察的历史，不是新盲样本外验证，也没有上线新过滤。
