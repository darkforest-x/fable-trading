# 止盈止损的最优参数必须绑定仓位口径

- **问题**：PEPE 同一冻结网格的 2400 组全历史净 R 全负，但其中 4 组等名义金额累计净收益为正。
- **死胡同**：看到净 R 排名就说所有参数都不赚钱，或把固定金额累计盈亏当成等风险账户收益。每笔风险距离不同，两种加权方式并不等价。
- **有效路径**：预先固定等初始风险净 R 为主目标，同时保留等金额结果。分开报告最佳参数、时间分段和匹配对照，并逐笔复核全部等金额正候选。本轮等金额最高配置每单 1000 USDT 名义金额累计 +174.22 USDT，但净 R 为 -114.85R；主目标最优仍为 -35.39R。
- **通用规则**：优化前先说明每单固定风险还是固定金额；独立重叠交易的累计指标不等于账户收益率。出现口径相反时必须同时报告，不挑有利口径替换原先目标。
- **牵连**：`experiments/active/exp-pepe-range-exits-20261020-v1/config.json`、`results/notional_selection.json`、`results/diagnostics.json`；`yoyo/evaluation/pepe_range_diagnostics.py`。等金额补充比较标记为探索性，不改变原参数网格和主目标。
