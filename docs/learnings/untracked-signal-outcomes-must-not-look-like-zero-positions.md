# 未跟踪的信号状态不能显示成零持仓

- **问题**：V9 切换后仅记录启动价与初始止损参考，不跟踪持仓路径。62 条信号的接口 `unknown=62`，但前端只展示 `active=0`、`closed=0`，使完整的事件记录看起来像统计故障或零持仓。
- **死胡同**：只检查信号数量或把缺失 R 显示成破折号，仍遗漏状态分母；“等待计算”还会暗示存在计算队列。没有执行路径和退出数据时，不能用当前价格或旧版退出规则补造 V9 的 R。本轮在读源码后排除了这些做法，未运行收益计算。
- **有效路径**：先确认生产者显式声明 `performance=not_tracked`，再核对只读接口的未知数量。用全量统计独立显示未知状态；整组未知时持仓/退出数量显示不可用，并在统计区说明 V9 尚未跟踪。混合数据仍保留已知状态和有证据的 R，空筛选单独说明无信号。
- **通用规则**：协议切换必须同时核对事件、状态与指标能力。零表示已经测量且为零；未知必须保留在分母和界面中，不能被隐藏的分类吞掉。可用性判断取自完整统计，不能由某一页是否有记录决定。
- **牵连**：`yoyo/monitor/v9_signals.py`、`yoyo/monitor/signal_analytics.py`、`yoyo/monitor/static/app.js`、`yoyo/monitor/static/index.html`、`tests/monitor/frontend_cards.test.cjs`。本次仅修正显示，未接入 V9 持仓收益引擎，未改变通知或交易规则。相关：[全量统计必须先于分页](signal-r-statistics-must-precede-pagination.md)。
