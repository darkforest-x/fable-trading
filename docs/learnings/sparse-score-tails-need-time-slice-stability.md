# 稀疏高分尾部必须逐时间片验证稳定性

- **问题**：训练分数 q99 在 2024 与 2025–2026P1 汇总上都出现正均值，看起来像把 q90 调高就能得到答案。
- **死胡同**：用两个汇总期的正值掩盖样本稀少和时间集中。q99 每期只有 25/21 笔；拆成半年后，2024H2 已为 -1.18bp，2026H1 为 -47.39bp，正收益主要来自少数早期右尾赢家。该阈值又是在看过结果后挑出的，不能当确认。
- **有效路径**：所有事后密度曲线保留 `posthoc` 标识；把训练绝对阈值原样应用到后续期，再拆成至少半年片并列出事件数、均值和 PF。只允许把稳定且达到最低样本量的坐标登记为未来前向假设。
- **通用规则**：任何“阈值越高越好”的结论都必须同时展示选择率、绝对笔数和逐时间片符号；只要符号反转或单片样本过少，就不改默认参数。
- **牵连**：`posthoc_density_quality_curve.csv`、`posthoc_q99_halfyear_stability.csv`；q90 是预注册门，q95/q97.5/q99 仅为诊断；不触碰 TradingView、ACTIVE 或 holdout。
