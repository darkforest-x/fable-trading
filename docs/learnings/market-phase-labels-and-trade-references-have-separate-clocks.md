# 市场阶段有标签，不等于旧交易仍可用于确认收益

- **问题**：给原 V8 信号补上“压缩、启动、扩散、再盘整”后，如何验证循环，而不把后面的扩散和盈利倒填到之前的箭头？
- **死胡同**：直接把未来 48 根出现扩散的样本归入原入场组，会用未来挑赢家。另一种更隐蔽的错误是保留未执行信号，却因其没有退出时间和止损，反而判为“确认前未失效”；它根本没有原入场价和初始 R 基准。把不同 episode 的扩散接在一起同样会制造虚假的确认。
- **有效路径**：所有原事件先记录原确认收盘可知的状态，只有这一份状态能分层原交易收益。未来里程碑另表记录，必须同 episode、方向一致，并明确原交易是否执行、入场与初始风险是否存在、原退出或初始 SL 是否已先发生、下一开盘是否连续可用。未执行事件仍进入形态覆盖分母，但不进入以原 R 表达的确认成本分母。
- **通用规则**：状态机至少有三个独立身份：市场 episode、信号事件、执行交易。先锁定各自身份和时钟，再计算转移与收益；未知、失败、过期、未执行、区间结束未观察到都保留。等待更完整形态的价格代价不是新策略实际收益。
- **牵连**：`yoyo/evaluation/spike_v8_ma_cycle_study.py`、`yoyo/evaluation/spike_v8_ma_cycle_summary.py`、实验 `exp-spike-v8-ma-cycle-20260913-v1`。这条记录说明验证方法，不表示该状态规则已经提高 V8 收益。
