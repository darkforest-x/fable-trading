# 人工审核的负担与模型输入必须分别设计

- **问题**：裸短窗盲审让 Owner 每张填写方向、核心起止、纵坐标和框义，实际审核负担过重；Owner 明确需要未来 K 线辅助判断形态是否启动。
- **死胡同**：为了维持同一种审核模式，把训练信息限制原样施加给人工，或用越来越详细的表单来换取“标注质量”。这会阻碍真正的人工裁决；若再把拒绝某个框直接当整图负例，还会引入新错标。
- **有效路径**：训练输入固定，审核未来另建目录及 manifest，并逐字节核对原输入；展示原提案让 Owner 用三按钮初审，纠正操作按需展开。显式记录 assisted 协议及看见的 40 根后文，不沿用旧盲审 κ 的含义。拒绝提案保留为待纠错，仅明确“整图无目标形态”才进入后续负例资格审查。
- **通用规则**：先让人只做机器无法替代的判断，再由系统记录坐标、来源与版本。降低操作成本不等于降低证据标准：审核方式变化必须改变答案协议和统计解释。
