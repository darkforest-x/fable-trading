# 数到第几个振荡器信号，不等于限制利润回吐幅度

- **问题**：2026-09-20，Owner针对突破＋SPIKE大赢家回吐，提出第7个RSI大菱形全平。
- **死胡同**：把事件序号当成价格保护，以为等到第7次反向信号就能锁住一定比例浮盈；或把此前第5个菱形入场、四次减仓的独立策略结果直接搬到联合信号退出。
- **有效路径**：先区分指标连续同色计数与入场后累计计数，明确周期、确认时间、亏损时行为和重置规则。RSI只能作为新增退出触发；保留既有价格保护，先到先执行，再固定相同入场检验净收益、回吐和大赢家损失。两套计数与周期尚待Owner明确，不能以默认选项视为答复。
- **通用规则**：事件时钟控制“何时出现信号”，价格保护控制“在哪个价格退出”；前者不直接约束回撤，后者也不保证跳空后的成交价。更少回吐和更多净收益是两个需要分别验收的目标，计算兑现率时必须保留原策略机会的同一分母。
