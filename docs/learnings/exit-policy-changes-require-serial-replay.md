# 修改退出政策必须重放后续持仓占用

- **问题**：研究 SPIKE 浮盈 4R 是否应止盈时，同一笔原入场的反事实结果与整套策略的结果不是同一个量。
- **死胡同**：把原逐笔利润截为 4R，或按事后最大浮盈判定一定成交，会忽略止损与止盈同根的顺序歧义，也会漏掉提前退出后重新可交易的信号。复用原退出的 MFE 函数还会漏记目标成交本身，或误计成交后的整根极值。
- **有效路径**：冻结原入场、初始风险、费用与移动止损，仅加入预先挂出的目标；逐根处理开盘、既有止损、待执行反向退出和目标，冲突保守按止损先。分别保留同入场配对结果与从预热开始的完整串行账本；目标成交的已知浮盈仅计算此前完整持仓 K 线及成交点。
- **通用规则**：改变任何退出规则，先验证单笔事件顺序，再独立重算所有后续信号的仓位占用；不要把事后 MFE 当成可成交价格或当时可用的入场条件。
- **牵连**：`yoyo/evaluation/spike_manual_four_r.py`、`yoyo/evaluation/spike_manual_system_study.py` 及对应测试。原往返成本 0.2%、收盘 2R 启动 4ATR 追踪、下一开盘执行规则不变。本研究不构成原生 TradingView 全事件对齐或实盘准入。
