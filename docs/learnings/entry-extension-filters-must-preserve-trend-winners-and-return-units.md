# 入场推进上限必须同时核对漏掉的趋势赢家与两种收益单位

- **问题**：逐笔复盘发现部分联合突破比父V9晚很多、入场更贵；是否直接过滤已经推进太远的信号就能改善策略？
- **死胡同**：PENDLE 1h等待33根、父信号后推进6.77份收盘风险距离，确实被E<=1挡掉；但同一门也挡掉PUMP 1h的+5.68R和ENA 15m的+7.16R。把一个典型亏单的修复当成通用规律会忽略延续趋势。15m全期净R合计增加19.18R，净bp合计却减少568.27bp，不能只报“赚得更多”。
- **有效路径**：先冻结一个阈值，用父信号当时的收盘到原止损尺度计算E；不读次根开盘或父未来收益。从全部571个首破候选独立串行重放，基线570入场完全复现，过滤后450入场/448闭合，共享交易和随机控制不变。分开统计避亏、漏盈、占仓新增、总额与每笔均值，并检查后段。三个周期都未通过预注册筛查；1h后段仍负，4h后段恶化。
- **通用规则**：因果可计算不等于有预测优势。任何“晚/远”入场门先保证首破消费与完整候选，再做赢家/亏单守恒，使用R和价格收益双口径、时间分段与匹配随机对照。阈值失败就记录失败；不在同一已见档案继续移动阈值直到获利。全期4h均值因分母缩小而上升，更不能掩盖总收益未升和后段更差。
- **牵连**：`yoyo/evaluation/spike_v112_entry_extension.py`、`experiments/active/exp-spike-v112-entry-extension-20260920-v1/PROJECT_PLAN.md`、`analysis/p1_spike_v112_entry_extension_20260920.md`；原20bp成本、退出和生产默认均不变。本结论只否定该冻结规则的准入，不是否定所有择时研究。
