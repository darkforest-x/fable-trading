# 有效样本量是独立月份数，不是交易笔数——加回测笔数不会让 CI 变窄

- **问题**：仓库跑过上百个实验、几百万笔回测交易，但没有一个配置的结论是显著的。
  直觉归因是"信号不够好"或"过滤不够狠"，于是继续加信号、加过滤、加周期。
- **死胡同**：按笔数思考。`exp-spike-v7-v1-compare` 有 **858599 笔**交易、
  `exp-spike-v8-six-filters` 有 **694902 笔**——按独立同分布的直觉，这种样本量下
  均值的标准误应该小到可以忽略。实际上它们的月块 bootstrap 95%CI 宽度仍有 0.21R，
  照样含 0。在这个前提下继续做实验，无论怎么改都得不到显著结果。
- **有效路径**：做全仓库普查时把**月数**和笔数并列打出来，发现 42 个可检验格子的
  月数**全部是 21**。收益由行情段决定，月与月之间才是近似独立的抽样单位；
  同一个月里的几万笔交易高度相关，提供的独立信息接近 1 个观测。
  所以有效样本量 ≈ 21，不是 85 万。这解释了为什么所有 p 值都停在 0.2–0.5 不往下走。
  佐证：第 1 轮的全市场池总净 R +838，其中 2026-04 贡献 +1188、2026-08 贡献 +709，
  **去掉这两个月是 −1060**——25 个月里 19 个月为负。
- **通用规则**：报告任何池子级别的统计量时，**必须同时报独立时间块数量**
  （月数 / 独立行情段数），不能只报笔数。若要让结论变显著，需要的是
  **更多独立月份**（扩历史区间、扩到相关性低的市场），而不是更多信号、
  更多过滤或更多周期——后三者只是在同一段行情上重复采样。
  一切用月块 bootstrap 的 CI 宽度做判断，不要用 `n` 做判断。
