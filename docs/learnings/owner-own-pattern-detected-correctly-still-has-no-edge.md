# 按 owner 自己的定义把检测器做对了,回测仍然是硬币 —— 边不在形态里

**日期**:2026-07-27
**类型**:反直觉结论(v6 短检测器回测)

## 一句话

这一轮终于**不是**在优化我猜的目标:判据来自 owner 亲口描述(均线慢慢密集 + K线向下)、
用 owner 的 390 个 verdict 校准、正样本含 owner 自己打的 ⭐标杆。检测器确实变好了
(在 owner 认可的框上开火 9.9%→**28.2%**,池内精度 18.2%→33.3%)。
**但逐 bar 诚实回测:388 笔,毛 PF 0.832、胜率 17.5%(平衡 28.6%),任何成本口径都亏。**

## 关键证据:扫遍出场,胜率永远贴着盈亏平衡线

| 出场 | 胜率 | 盈亏平衡 | 净PF@taker |
|---|---|---|---|
| TP5/SL2/72 | 27.8% | 28.6% | 0.729 |
| TP3/SL1.5/72 | 30.2% | 33.3% | 0.778 |
| TP2/SL1/72 | 31.7% | 33.3% | 0.768 |
| TP1.5/SL1/24 | 39.9% | 40.0% | 0.732 |
| **TP1/SL1/24** | **51.3%** | **50.0%** | 0.743 |

**对称障碍下 51.3% vs 50% = 硬币。** 8 种出场全亏,且胜率始终≈平衡线
→ **不是出场没调对,是这些入场点不含方向信息。**

## 为什么这条比之前的否定更有分量

之前(IT-00~19)否定的是**我构造的**目标:机械 spread 阈值、我猜的锚点、我猜的像素假设。
可以辩解说"你没抓对 owner 的模式"。

这一轮把那个辩解堵死了:
- 判据 = owner 原话
- 阈值 = 用 owner 的 390 个 verdict 选出来的(精度 18.2%→42.7%)
- 正样本 = 含 owner 亲手标的 ⭐标杆
- 回测 = 逐 bar 重放,检测器只看得到过去

**形态被正确识别了,交易仍然是硬币。** → 边不在"能不能认出这个形态"上。

## 一个副产品发现:标签正确性和入场时机是**对立**的

owner 看样本说"标得太早",于是锚点后移到"跌破全均线 + 已跌1×ATR"。
**标签位置对了,入场也跟着变晚了**——进场时已经跌掉 1 个 ATR,启动那段被吃掉。
但扫出场证明:即使把 TP 缩到 1×ATR 迁就这个晚入场,**依然是硬币**。
所以"入场晚"不是主因,只是加剧。

## 教训

- **"检测器做对了" ≠ "策略能赚"**。这次两者第一次被干净地分开测量:
  检测指标(对 owner 眼的一致性)确实涨了 1.83 倍,经济指标纹丝不动。
  **以后这两个必须分别立项、分别报,不能用前者暗示后者。**
- **扫出场是廉价的证伪器**:8 组参数、几分钟,直接区分"出场没调好"和"入场没边"。
  遇到亏损策略先扫一遍,别急着调模型。
- **对称障碍下的胜率是最干净的方向性检验**:TP=SL 时平衡=50%,偏离多少就是多少边。
