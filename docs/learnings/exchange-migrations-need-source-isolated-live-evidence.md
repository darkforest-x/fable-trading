# 换交易所时，缓存和验证证据也必须分开

- **问题**：市场观察的币安接口持续返回 HTTP 451，页面只剩旧行情；Owner 要求换用 OKX。
- **死胡同**：只换请求地址、继续沿用旧库，会把不同交易所的价格、成交量与首次观察时间拼接成一段看似连续的证据。币安研究的分档阈值也不能自动成为 OKX 已验证结论。
- **有效路径**：保留旧研究库，新建 OKX 专用行情与观察库。适配已收盘 K 线、基础币成交量和报价币成交额，按上月数据选样；重新补齐计算窗口，再检查 30m/1h 的新鲜度与 50/50 覆盖。历史研究在页面单独折叠，注明旧分档在新源尚未验证。
- **通用规则**：交易所是数据谱系的一部分。切源先隔离存储、确认单位与收盘语义，再恢复提示；不要把“请求成功”当成“指标已就绪”。
- **牵连**：`yoyo/monitor/market_sync_okx.py`、`market_sync.py`、`server.py`；OKX `confirm=1`、`volCcy`、`volCcyQuote`，以及 `tests/monitor/test_market_context_okx.py`。
