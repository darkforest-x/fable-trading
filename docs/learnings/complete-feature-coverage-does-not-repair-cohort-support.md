# 特征对齐完整不能弥补候选和配对样本不足

- **问题**：V35 所有 1,001 个窗口都能对齐真实主动量，但原 251 个 K1 中只有 55 个 K2 请求，其中仅 31 个有原来的完整三对照。
- **死胡同**：把 100% 输入完整率当作可以继续优化共振门的依据；或者把 462 条控制记录当作每个母信号都有三条对照。实际 462 只覆盖 154 个母事件，另 97 个没有配对。
- **有效路径**：分别审计全 K1 母群、K2 请求子群、原母群配对覆盖，再按四个半年检查分母。缺失对照不补均值，也不能用控制里自行出现的 89 个 K2 请求直接对比案例的 55 个。
- **通用规则**：数据可用性、事件供给量、配对覆盖和净优势是四个不同门；前一门通过不能给后一门签字。先确定研究单位和完整对照，再读收益或筛参数。
- **牵连**：V4 原母群/原控制匹配；V35 summary.json 与 report_data.json。该发现只涉及时钟和身份，没有读取新收益，不推翻或美化旧负面回测。
