# UI inspection can prime Electron accessibility and hide cold-start failures

- **Problem**: spike-to-TradingView navigation passed live card tests but failed again for the owner. The original tests inspected the native app before using the bridge. On 2026-09-08, a clean cold start without inspection returned a stale window index (-1719); a second run with stage diagnostics expired in `window_ready`.
- **Dead ends**: More warm tests after CUA inspection kept passing, concealing the missing initialization. Treating -1719 as denied Automation permission also misdirected the owner: the concrete error was an invalid index into a changing window collection. A generic error message discarded the failing phase and made the two cases indistinguishable.
- **Effective path**: Add controlled stage diagnostics first, then quit the app and issue the request without any prior native UI inspection. Electron's documented `AXManualAccessibility=true` explicitly initializes its AX tree. Set it once and poll; Electron 41.7.1 applies a two-second debounce that repeated writes would reset. Retrying only stale AX reads also handles disappearing splash/popup windows without reissuing a chart navigation. Following the fix, a direct cold-start script, a cold live-service request for BICO 4H and a cold whole-card request for POET 15m succeeded. Native chart identity was checked only afterward. Distinct backend error messages and sanitized logs preserve the next failure's stage without copying UI or clipboard text.
- **General rule**: Include a clean application process in desktop automation acceptance. Inspection itself can mutate the conditions under test; a warm success is evidence only for the inspected state. Separate permission denials, stale object references, readiness deadlines and dispatch outcomes. Keep observation retries bounded and do not blindly repeat an action whose delivery is uncertain.
- **Scope**: `yoyo/monitor/tradingview.applescript`, `tradingview.py`, `tests/monitor/test_tradingview.py`; Desktop 3.4.1 / Electron 41.7.1 read from the installed bundle. The 15-second script and 25-second subprocess budgets remain. No TCC reset or new helper was used. The earlier [concrete-layout fix](desktop-chart-links-must-bind-a-concrete-layout.md) remains necessary but alone did not cover cold start.

Sources: [Electron public accessibility contract](https://www.electronjs.org/docs/latest/tutorial/accessibility#macos), [41.7.1 implementation and debounce](https://github.com/electron/electron/blob/fda774933622cbc110f34a43015cc1fe6f4f56b3/shell/browser/mac/electron_application.mm#L328).
