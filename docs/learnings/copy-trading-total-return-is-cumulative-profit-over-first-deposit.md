# 实盘榜的“总收益率”可能只是累计收益 ÷ 首笔入金，不是复利回报

- **问题**：2026-10-11 整理 Bit浪浪 视频时，标题写“956U 做到五千多倍”。实盘页截图：初始资金 $956、累计收益 $5,071,842、提现 $4,769,290、账户资产 $302,959、总收益率 530,062%、最大回撤 13.17%。
- **死胡同**：直接把 5,300 倍当成本金复利增长去理解，会推出“每笔都在滚仓”或“风险极高但没爆”之类的结论；把 13% 最大回撤当成对在场资金的回撤，会严重低估风险。这两种读法都没有先核对口径。
- **有效路径**：用面板自己的数字反算——5,071,842 ÷ 956 ≈ 5,305 倍 ≈ 530,500%，与 530,062% 只差截图时点，说明分母就是第一笔入金。再对照他自己讲的仓位法（账户只放 1/3、亏了从外面补、赚了提走），外部补进来的钱不进分母、利润不断被提走，所以这个倍数只等于“累计赚了多少钱”，看不出用了多少本金。回撤如果按 1 + 累计收益 ÷ 956 这条曲线计，分母被放大，对实际在场资金的回撤会小算很多（平台未披露口径，只能标“推测”）。
- **通用规则**：评估任何跟单平台/KOL 的收益率之前，先用面板上的“累计收益、初始资金、提现、余额”互相反算，确认总收益率和回撤的分母；只要存在补仓或提现，倍数就不能当复利回报，回撤也不能当在场资金回撤。再配合胜率算“保本盈亏比”（胜率 40% 要 1.5 倍）作为最低要求。
