- **问题**：Owner 询问原黑色均线是哪条，并要求蓄势区关键影线 K 线变亮；实现却连带加粗参考线、调淡其余均线，还给副图加了回踩信息与重复价格，导致用户要求还原。
- **死胡同**：以“更容易找到参考线”为理由扩张显示范围。准确识别 SMA20 只解决计算对象，不能推出需要把整条均线重新着色或加粗；副图已有明确设计，也不该被主图回踩功能顺带改变。
- **有效路径**：与请求前的 V2 逐项对照，六条均线颜色、透明度和宽度直接复用原绘图声明，删除额外选中参考线；副图恢复三行面板与原释放文字。仅将确认的关键 K 线实体、影线、边框变亮。已另行明确要求的可见零轴与主图信号点位保留，原系统计算与警报不动。
- **通用规则**：新增局部高亮先确定允许改变的绘图对象，计算参考与视觉强调分别授权。核对恢复时应逐项比较样式，不用整版回滚覆盖用户已明确要求的其他功能。
