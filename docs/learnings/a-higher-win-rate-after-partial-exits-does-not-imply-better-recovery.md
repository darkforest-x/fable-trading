# 分批后的高胜率，不能替代净期望和整轮回本

- **问题**：ETH3m V8大量交易曾浮盈再亏，提前兑现直觉上应更适合倍投，但胜率改善可能与资金结果相反。
- **死胡同**：将首批止盈命中算作整笔胜利，或只比较最终胜率，忽略大赢家被缩小、费用和提前退出后新增的交易。
- **有效路径**：冻结13组退出，以同入场、同初始风险、同成本的固定1U账户先比较；开发后冻结参考，再用相同退出比较资金倍率。完整初始止损、毛亏、净亏分开，逐片加权与整轮现金守恒独立核验。
- **实际证据**：开发期1R平70%并保护残仓使净胜率从25.43%提高到38.58%，但1000U期末从479.82U降到463.24U；自然笔数751变775，单笔平均净R近似，总损失因样本集合也改变。连续2023-08至2026-04固定1U全仓131.80U，半仓76.10U，七成71.85U。0.5R平半组开发完整初始止损最长6，净亏最长36。
- **通用规则**：退出收益必须用整笔原始仓位份额计量，倍投复位必须对齐明确的净盈利或整轮净债务条件；不能用少数完整止损证明账户连亏上限。胜率、单笔期望、成交集合、账户结果四项缺一不可。
- **边界与来源**：以上只针对既有OKX三分钟V8、固定20bp研究成本和预登记13组，不证明所有分批策略无效。报告 `analysis/p1_spike_eth3m_partial_tp_20260914.md`；实验 `experiments/active/exp-spike-eth3m-partial-tp-20260914-v1`，本配置holdout消耗0次。
