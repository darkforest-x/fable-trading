# 全屏抽屉的透明宿主不能继承卡片材质

- **问题**：75% 宽的策略抽屉打开后，剩余25%也变白，失去了底层行情上下文。
- **死胡同**：仅给新组件写透明背景仍会被全局 `dialog` 的 `!important` 毛玻璃卡片规则覆盖；增加抽屉透明度不能修复宿主的不透明背景。
- **有效路径**：把全屏语义宿主和实际阅读面板分开，宿主从通用卡片材质选择器排除，只在75%内层使用共享 `--glass-reading` token。浏览器分别验收宿主透明、面板alpha、背景可见、实际宽度、深浅色与手机。
- **浏览器边界**：WebKit 的计算样式包含 backdrop blur 不等于画面已模糊；透明 modal 宿主下的实际截图曾透出清晰背景文字。仅在小册打开时给 WebKit 的背景行情层加 blur，关闭时恢复；初始焦点放标题、保留按钮键盘焦点样式。
- **通用规则**：视口级弹窗出现意外白底时，先查看宿主及 `::backdrop` 的最终计算样式和全局选择器，明确材质属于哪一层。
