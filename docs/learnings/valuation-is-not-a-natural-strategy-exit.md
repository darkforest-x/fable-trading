# 期末估值不应混入策略的自然平仓数

- **问题**：回测结束时仍有持仓，缺少截止日行情就将其按零回收并计作自然止损，可能让参数排名主要取决于截止日停牌。
- **死胡同**：只排除名为period_end_valuation的记录，而漏掉其他terminal分支；保守估值并不因此成为已实现的交易事实。
- **有效路径**：所有期末处理带is_terminal标记，自然交易数、胜率和PF统一排除。主净值按最后已知价预留退出成本，披露陈旧天数；将零回收另列为压力下界。
- **通用规则**：持仓估值、实际可成交与策略退出是三个事实。可以给不确定性边界，但不能把边界当已发生的成交。
- **牵连**：`yoyo/evaluation/ashare_imacd.py`，A股历史退市/停牌数据，至少30笔自然平仓的开发期选参门槛。
