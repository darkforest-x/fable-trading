# 共享注册表差异也可能暴露禁入研究数据

- **问题**：V36 打包后检查共享注册表未提交差异，展示了其他任务的 holdout 截图结果。只检查代码搜索范围不够，git diff 的文本也是输入。
- **死胡同**：把只读仓库状态检查视为不可能接触价格，整份打印注册表或报告索引；其中可能直接含有价格和事后收益。
- **有效路径**：先用只含路径/行数的 diff 统计定位；再只显示本任务确定行段。共享文件选择性暂存也按已知修改位置截断，不展开其他任务正文。已发生的暴露保守登记，不把它加进授权白名单。
- **通用规则**：研究隔离覆盖所有文本通道，不只 CSV 加载器；数据门户、报告、索引和版本控制差异都要按当前研究范围收窄。
- **边界**：两次意外展示均未改变 V36 的2023–2024回测输入或规则，仍不得称整个调查无holdout暴露。
