# 成交量分布复现还要保留求和顺序

- **问题**：重建前端 80 档、70% 价值区时，公式相同，均匀分布测试却在成交量缩放后多扩展一档。
- **死胡同**：以为 NumPy 数组求和与原 Python 列表逐项求和可以直接互换。临界累计量接近总量的 70% 时，浮点舍入会改变循环是否再扩展一档；不能仅放宽断言。
- **有效路径**：用解析的均匀分布反例定位差异，保留前端列表累加、总和与相等时向左扩展的顺序。与前端同一输入逐项比较，13 个近期日分组的 POC／VAH／VAL 最大差异为 0；同时检查张数与基础币单位缩放，不把数学上的比例不变自动当成浮点实现保证。
- **通用规则**：重放带阈值分支的累计统计，先核对输入单位、累加顺序和相等时的裁决，再核对输出数值。
- **牵连**：`yoyo/evaluation/key_level_reactions.py`、`tests/evaluation/test_key_level_reactions.py`；前端参考 `yoyo/monitor/market_context.py`。这是计算一致性证据，不是关键位有交易优势的证据。
