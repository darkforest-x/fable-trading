# 新增信号过滤必须覆盖已保存事件的读取路径

- **问题**：12H 云带仍是多头颜色，但确认 K 线整根已经落在云带下方；只依据 EMA20 与 EMA50 的相对位置仍会出多单，空头同理。
- **死胡同**：检查发现仅修扫描入口无法让旧卡片、旧深链和历史参考框同步消失；直接删除旧事件又会破坏原始观察和通知去重证据。
- **有效路径**：以确认当根 high/low 与当时 EMA 为输入，使用严格不等式排除完全脱离错误一侧的 K 线；等号和影线触云保留。独立存版本化资格结果，读取列表时先过滤再计数、排序、分页，历史接口、深链与待发送通知使用相同资格。已有事件仅从缓存补齐输入，不覆盖其 payload、渠道状态或启动时刻。
- **通用规则**：增加资格条件时，列出生成、存储读取、直接访问和副作用四类入口；新规则应一致生效，但原始事件不应因规则改变而被抹除。确认后的未来行情不得改变当时资格。
- **牵连**：`cloud_signal_rules.py` 的 `12h-candle-cloud-contact-v1`、`cloud_signals.py`、`tests/monitor/test_cloud_signal_position.py`。本次1010条观察中39多/26空被排除，原始记录逐行相等；数量变化不等于收益改善。
