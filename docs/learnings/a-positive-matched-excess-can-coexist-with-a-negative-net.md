# 配对超额为正，和净收益为负，可以同时成立

- **问题**：BTC 5m 的 holdout 验收里，匹配随机对照的配对超额是 **+0.0298 R/笔**（保本含成本组 +0.0367），
  三条标准里唯一满足的一条；但总净 R 是 **−6.06R**、每笔 −0.0713R。
  "对照赢了"和"这策略亏钱"看起来矛盾，其实不矛盾。
- **死胡同**：把配对超额当成盈利证据。对照回答的是"这个入场时点是否优于同环境的随机入场"，
  它和随机入场比，**两边都扣同样的费用**；随机入场亏得更多，所以超额为正。
  这完全可以发生在一个整体负期望的策略上——**超额是相对量，净收益是绝对量。**
- **有效路径**：把两个问题分开问、分开报。①入场时点有没有信息 → 配对超额 + 置换 p；
  ②这套规则能不能赚钱 → 扣费后净 R 与盈亏平衡费率 f*。验收标准要求**两个都过**，
  才不会被单独一个正数带跑。本例①方向为正但 p=0.50（4 个月块，分辨率极低），②明确为负 → 未通过。
- **通用规则**：报告里不要只给"超额 +X R/笔，对照更差"就收尾。**必须同时给净 R 的符号**，
  并说明超额是与随机入场的相对差，不是账户收益。反过来也一样：净收益为负不代表入场毫无信息，
  那是两件事，混起来会同时丢掉"该放弃"和"该继续找"的判断依据。
