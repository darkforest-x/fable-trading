# 形态形成时的极值，不是等待入场后的止损失效

- **问题**：把 K2 后的小级别确认移到入场之前时，需要判定原止损是否已在等待期被破坏。K2 最后一个小级别 seed 同时提供初始颜色，容易被误当成第一根等待 bar。
- **死胡同**：如果统一对每根用于颜色的 bar 做触损判断，seed 的极值就可能撤销刚形成的原始 K2 请求。这不是更保守，而是把形成区间混入了尚未开始的等待期；它会改变信号定义。本轮在价格审计前识别此歧义，没有以错误版本评分实际收益。
- **有效路径**：先固定 E=K2 收盘。E 时只用新 OPEN 检查风险，用已闭合 seed 的颜色确认；不以 seed 极值撤销。C>E 才先验证完整等待 bar 是否触及固定止损，再查 C OPEN 和颜色。同一等待 bar 既触损又确认时，触损优先。
- **通用规则**：把形成期、待入场期、已持仓期的左闭右开区间分别写清，再复用 OHLC。共享一根数据不代表共享一种经济语义；必须用 seed-touch 与 wait-touch 两个对照测试钉住区别。
- **牵连**：`yoyo/data/k1k2_pending_entry.py`、`tests/test_k1k2_pending_entry.py`、V38 `PROJECT_PLAN.md`。60 分钟只是行政观察截止；未知和未确认不代表现金收益 0，实际收益需要另行冻结策略寿命与持仓截止规则。
