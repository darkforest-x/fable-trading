# 模型准入门槛应由未参与拟合的过去分数确定

- **问题**：稀有10R分类器要按分数挑前1%至20%的信号。训练分数的分布带有拟合乐观性，整批待评估分数排名又不能在当时知道。
- **死胡同**：在完整过去12个月拟合后，用其中最后3个月拟合内分数设门槛，虽未读取目标季度未来，仍可能因训练与部署分数分布不一致产生误导；另一个模型的校准门槛也不能在重新拟合后直接冒称同分布。
- **有效路径**：在同一个12月历史窗口内先分9月训练和3月无标签校准，训练标签严格在9月结束前成熟；校准和下一季度使用同一冻结模型。先冻结分数与门槛，再读下一季度结果。
- **通用规则**：分别写出特征时钟、标签成熟时钟、拟合时钟和门槛时钟。名义覆盖是过去分数分位，不保证目标期实际覆盖；两者都报告。
- **牵连**：`yoyo/evaluation/spike_10r_model_study.py`、`spike_10r_models.py`，`exp-spike-10r-model-20260921-v4/PROJECT_PLAN.md`。2026-09-21 Owner仅授权本数据两模型离线训练，生产准入规则未变。
