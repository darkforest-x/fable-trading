# 多周期过滤必须区分已同向、中性和反向

- **问题**：IMACD加入六均线密集后ETH4h改善，但高周期md或sh同向门把2026H1均值从正变负，误删大赢家。
- **死胡同**：默认“共振越多越好”，只盯留下交易的胜率/PF；它无法看见被拒绝的趋势利润。日线md=0并不等于支持，但也不等于反向趋势已经成立。
- **有效路径**：保持同一anchor和回零退出，按父子门逐笔追踪原赢家利润保留率。2026-01-20 ETH空头anchor时日md=0而sh>0，严格支持门拒绝了约29.80%趋势；独立追加“已知md=0也允许”保住它，同时保留2025-01-27约−12.26%的反例。新门在早期段未普遍改善，故仅为探索假设。
- **通用规则**：先列被过滤交易的完整净收益与当时已收盘大周期状态，再改过滤语义；未知状态不能冒充中性。区分背景许可、启动触发和等待确认，记录追加假设的历史暴露，不把追回已知赢家当盲测证明。
