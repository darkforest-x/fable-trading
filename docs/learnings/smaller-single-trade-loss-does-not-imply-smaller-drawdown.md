# 最大单笔损失缩小，不等于账户回撤缩小

- **问题**：2026-09-15 的 MA Shift/Stoch 退出开发实验中，加入2 ATR止损把2026年1—2月最大单笔净亏从7.66%缩到2.20%，账户回撤却从26.82%增至32.65%，净收益从−11.25%降至−31.10%。
- **死胡同**：只按“最坏一笔少亏多少”挑止损会得出改善结论；只比较胜率也无法看到提前止损增加交易、截断后续恢复，以及固定20bp费用的总影响。16组结果中原baseline扣费权益最高，但同样亏损，不能称作盈利最优策略。
- **有效路径**：在固定候选入场流上重新串行回放，分别汇报单笔损失、权益回撤、毛收益和净收益；止盈/保本/分批/跟踪各自只相对固定2 ATR锚点改变一项。开发排序冻结为baseline，验证仅评价预先固定的baseline和stop_2，不在验证再搜索。
- **通用规则**：保护单笔尾部损失和增加整套策略期望收益是两个目标；先固定目标、费用和时间切分，再查看净权益和对照组，不用一项风险指标替代策略是否有效。
