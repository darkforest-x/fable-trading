- **问题**：V17统计辅助模块在system python3成功导入，但仓库.venv因缺seaborn失败；沿用V16的“不可用”结论或用成功解释器替代所有命令都不准确。

- **有效路径**：固定辅助源码SHA、实际导入调用check_normality(plot=False)，保存解释器与数值库版本；诊断用现有system解释器，策略回放继续原.venv，不改依赖。27项system测试全过；.venv只对两项可选真实工具集成显式skip，25项纯数据与失败保护仍通过。缺工具的正式诊断失败关闭，不生成假诊断文件。
- **通用规则**：环境调查必须绑定到具体执行命令；历史缺依赖记录不是当前全机事实。可选环境集成与核心纯逻辑测试分开，让skip理由可见，不能跳掉核心校验或静默改变计算方法。
