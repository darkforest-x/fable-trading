# 入场过滤器会改写整条交易状态路径

- **问题**：给带持仓、反转、冷却和动态止损状态的趋势策略增加一个入场质量门后，V15 在最终样本段虽然只拒绝了少量候选，实际交易数却从 V12F 的 97 笔变成 98 笔，不能用“从旧交易表删除低分行”解释结果。
- **死胡同**：把入场过滤视为独立交易分类，只统计被拒绝交易本身的历史盈亏。这样会假设后续每个信号面对相同的持仓状态；但拒绝一次开仓可能让基线继续持仓、改变下一次反转是否发生、退出时间、冷却起点以及之后哪些信号有资格开仓，所以静态删行会得到错误的交易集合和收益路径。
- **有效路径**：对每个候选配置从原始 bar 与信号流完整重放状态机，再按 `signal_i + direction` 对基线和候选的实际交易做双向差集。V15 最终段拒绝了 2026-02-03 的一笔 `+11.47%` 净收益空头长 runner；不同持仓路径随后又产生 6 笔 V15-only 空头，合计 `-8.33%`，从而解释了交易数增加和收益下降同时出现。
- **通用规则**：只要策略存在持仓依赖、反转、冷却、移动止损或仓位复利，任何入场门、判断层或阈值实验都必须完整动态 replay；验收至少输出基线-only、候选-only 的逐笔路径差异账本，禁止用旧交易 CSV 静态过滤代替。
- **牵连**：`scripts/research_pine_eth_15m_trend_ensemble.py`、`trend_ensemble_path_differences.csv`、full-state gate、reversal/cooldown、break-even、复利仓位；与 [`judgment-gates-can-change-reversal-exits.md`](judgment-gates-can-change-reversal-exits.md) 一致，但本条进一步要求把差异账本作为标准产物。
