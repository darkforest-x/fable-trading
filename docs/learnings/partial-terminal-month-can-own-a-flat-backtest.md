# 部分末月可以独占一个接近零的回测结论

- **问题**：近半年回测全期均值略为正，但最后未完成月份只有两笔且两笔全赢，其净收益合计是全期净收益的 11.39 倍。
- **死胡同**：把日历表中最后一列当作与完整月份同等的“9 月表现”，或只报全期 +0.60bp/笔，会隐藏前 47 笔其实为 -6.51bp/笔以及 3–8 月六段只有两段为正。
- **有效路径**：保留预注册窗口作为唯一主结果，同时自动标识 terminal partial month，单列其样本数、贡献率、去掉该段后的同口径敏感性，并检查该段是否还能构造原定匹配控制。
- **通用规则**：滚动“近 N 月”回测若以月内日期结束，第一步分开完整历史与部分末月；主窗不许事后改，但必须报告末月贡献和去除敏感性，尤其当总体收益接近零时。
