# 几何合法不等于保持了训练形态语义

- **问题**：YOLO 预测框能映射成 4–5 根核心、后接 4–6 根确认 K，但 43 个实际事件里只有 2 个仍满足训练正例的完整形态契约。
- **死胡同**：只看置信度、mAP、框宽或统一左右平移。它们都不能判断框内六均线是否仍密集，也不能区分定位错与整张输入分布外。
- **有效路径**：把训练检索器的 14 项形态门和参考族距离原样复算到预测核心，再在同一输入中穷举所有允许核心。41 个失败事件均无替代合格核心，证明主要是语义越界而非定位误差。
- **通用规则**：检测器若只负责 proposal，结果层必须重新执行训练目标的语义验收契约；否则几何过滤通过只能叫“结构候选”，不能叫业务信号。排查时先做同契约复算，再讨论移框或阈值。
