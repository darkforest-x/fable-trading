# 资金费区间必须承认结算时钟和价格代理的不确定性

- **问题**：固定20bp的趋势回放没有完整资金费，且只知道K线内止损，不能准确知道是否跨过结算评估。
- **死胡同**：用当前资金费补过去、把桶收盘当精确退出时刻，或从组合最终收益直接减一笔平均资金费，都会给出不存在的精度。只覆盖首尾时间也不证明中间结算表完整。
- **有效路径**：先锁定原事件与原配对，再加入40/60bp、按两腿成交名义收费的单独敏感性。资金费用实际历史费率、对应合约精确时间的成交开盘代理mark，并对一分钟评估窗口及未知盘中退出列出现金流上下界；缺费率或代理价保持缺失。
- **通用规则**：现金成本的发生时钟也需要因果合同。没有重新计算资金账户、后续数量和清算，静态事件成本修正就不能叫完整资金费后复利收益。
- **牵连**：`yoyo/evaluation/altcoin_cost_diagnostics.py`；OKX资金费评估说明；当前20bp主比较合同保持不变。
