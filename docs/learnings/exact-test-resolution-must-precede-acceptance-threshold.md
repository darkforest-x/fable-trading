# 精确检验先算最小可达 p，再订验收门

- **问题**：V9 上级 SMA 研究预设三周期 Holm 校正 p<0.01，但后段只有8个自然月。月块符号穷举最多256种，最小单项 p=1/256，第一项 Holm 下界3/256=0.01171875。即使每月都改善也不可能过门；非零差异月更少时分辨率更差。
- **死胡同**：直接把 `not_accepted` 解读成均线门无效，会把实验设计的能力不足归罪于策略。看见收益以后改成周块、取消多重校正或放松阈值，又会污染原先固定的验收口径。本轮保留了原配置和初版统计，没有采用这些捷径。
- **有效路径**：在最终统计解释前算出理论下界；Luna Max独立核对；输出非零月数和最小可达p，并加已知8个同正差值的测试。将选参、实际收益差、区间、方向表现、共同预热及统计可识别性分别报告。本轮15m选SMA50有正改善但区间跨零，1h选SMA20仅移除4笔后段亏单，均不能升级为已证实效果。
- **通用规则**：预注册任何精确置换/符号检验前，先按有效独立块数与多重比较规则计算最小可达p；样本单位是时间块而非交易条数。分辨率不足必须在设计时增加未来观察或降低结论级别，不能在结果出来后换检验追过门。
