# 检测准确率达标不等于经济筛选有效

- **问题**：Local Signal V2 B2 在固定 30-bar 检测验收上通过，但这只能证明它能复现视觉事件，不能回答被筛出的候选是否比原候选池更有收益。
- **死胡同**：沿用检测层 precision/recall/F1，或拿旧检测器的历史回测补在新报告后面，都会把不同权重、不同样本集合和不同决策问题混成一个结论。只报 B2 筛选后的绝对收益也不够，因为候选池本身可能带有方向 beta。
- **有效路径**：在不读取 holdout 的前提下，把最新 B2 固定权重回放到冻结 short-L2 候选池；先排除同币所有 B2 validation 端点前后 72 bars，再用固定 conf、tip-edge、18-bar 因果去重和冻结 TP/SL/成本，最后同时比较未过滤池及同币×同月×ATR 桶匹配随机对照。结果显示整体经济筛选无效；最高置信度分层虽为正，但周块检验不显著，因此只可作为 P2 的候选特征线索。
- **通用规则**：L1 检测验收与经济验收必须分开。每个新检测权重都只能用自己的、无直接验证重叠的候选池回放；先报相对未过滤池和匹配随机的增量，再讨论绝对收益。任何事后 confidence 分层都不得直接变成生产阈值。
