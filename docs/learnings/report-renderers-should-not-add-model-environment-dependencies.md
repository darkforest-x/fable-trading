# 报告格式化不应为可选包改变模型环境

- **问题**：完整研究已完成，首次生成报告在pandas `to_markdown`处因缺少可选tabulate失败；纯数据契约测试没有覆盖实际表格格式化。
- **死胡同**：把pandas已安装当成Markdown依赖也已安装，或为一个简单表格顺手修改主环境依赖。
- **有效路径**：保留现有数值格式化，使用显式转义的Markdown管道表，覆盖竖线、换行和HTML字符；在现有环境做最小渲染测试。未改任何策略、结果或依赖。
- **通用规则**：报告构建器应有一条真实输出格式的冒烟用例；格式层缺包优先使用已有标准库功能，不牵动模型版本契约。
- **牵连**：`yoyo/evaluation/altcoin_trend_report.py::table`、`tests/test_altcoin_trend_report.py`；真实数据复算不受影响。
