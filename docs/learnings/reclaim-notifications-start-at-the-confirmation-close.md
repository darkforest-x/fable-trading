# 收回提醒的发送时效从确认 K 线收盘起算

月首周首次触及 1.618 和触价所在 1H 收盘是两个时点。沿用触价后 90 秒的发送期限时，整点前几分钟发生的有效触价在确认时已经过期。反过来改写触价记录的时效，又会改变已有读者看到的原始事件。

把该小时的收盘时间、发送期限和发送状态记在渠道通知队列里。读取已确认的收盘价后，以当前时间和订阅代数再次检查能否发送。渠道返回限流时，重试也须遵守同一个收盘期限。历史补录只用于展示。

复现时至少覆盖整点两侧、收盘等于触价位、收盘前切换订阅，以及收盘读取耗时跨过期限。相关实现在 `yoyo/monitor/month_first_week_1618_service.py`，回归在 `tests/monitor/test_month_first_week_1618.py`。
