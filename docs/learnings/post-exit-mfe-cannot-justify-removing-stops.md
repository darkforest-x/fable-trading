# 止损后的 MFE 不能直接证明当时不该止损

- **问题**：日线 K1→K2 的影线止损后，很多标的在完整 90 日观察窗内又走到 `+2R` 甚至 `+6R`，表面上像是只要放宽或取消止损就能抓住大趋势。
- **死胡同**：直接用止损后的最高/最低价评价退出，会忽略恢复前的最大浮亏、资金占用、何时才能因果识别恢复以及再次成交成本；它把一条事后可见路径误当成当时可执行的利润。
- **有效路径**：把该现象只当作“影线止损可能过紧”的假设来源，冻结入场不动，依次比较 ATR 风险下限、收盘确认、双收盘确认，再把选出的退出规则一次性搬到未参与选择的确认段。退出修复改善了开发段，但确认段 15 笔没有一笔在实际持有期达到首档 `+1.5R`，且显著落后匹配随机，因而把病因定位到入场不运输而非止盈过近。
- **通用规则**：先区分“退出后完整窗口 MFE”和“真实持有路径 MFE”；前者只能提出退出或 re-entry 假设，不能用来取消风险边界。任何退出修复都必须在冻结入场后重新做时间外确认。
- **牵连**：`scripts/research_altcoin_1d_k1k2_episode_runner.py`、`scripts/research_altcoin_1d_k1k2_risk_repair.py`、V2 的双收盘结构退出、2ATR 灾难止损、渐进 TP 与匹配随机对照。
