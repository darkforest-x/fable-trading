# BB边界的斜率同时包含中线平移和带宽收缩

- **问题**：Owner比较SPIKE V12.8两张ETH15m截图：09-23空头的上轨明显下压，09-09多头的下轨近乎水平，怀疑前者胜率更高。金色区只表示BB200带宽低于此前500根P10，不要求当前仍在收口。
- **死胡同**：仅按屏幕角度、通道整体方向或事后完整压缩段判断，会混入纵轴缩放、趋势平移与未来边界。直接把图中3.32R当赢单也不成立：截至本轮数据截止，09-23事件仍未平仓。
- **有效路径**：固定信号前12根，按当时ATR归一化回归斜率。设中线为M，半带宽为H，方向d为多头+1/空头−1；多头看下轨M−H，空头看上轨M+H。方向一致的反侧边界运动恒等于`d*slope(M)-slope(H)`。前项是顺势平移，后项是真正收缩，必须分开与原账本结果比较。两截图的原始入场/止损与同源OKX数据一致：2511.17/2483.76、2718.30/2740.36；边界速度0.017276与0.120805 ATR/根，而两者中线顺势项都为负。这个分解是机械事实，不是胜率验证。
- **通用规则**：看到“带状指标边缘很陡”时，先写出边缘=中心±宽度的分解，再固定可知端点、归一化尺度和独立结果口径。SMA窗口旧价格滚出也会改变中心和宽度，不能仅凭收口声称买卖压力增强。收益分层不是新过滤策略回测，浮盈也不是兑现收益。
