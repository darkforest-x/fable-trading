# 小周期变色是退出事件，不是保证兑现利润的止盈

- **问题**：1h 穿线后跟小周期颜色退出看起来能吃趋势，但开发期和冻结规则后续检验都净亏损。
- **死胡同**：把退出时钟从 15m 换成 5m，或把一次变色改为两根确认，能改变亏损分布，却没有自动产生入场优势。仅凭盈利截图延长所有持仓，会同时放大失败交易回撤。
- **有效路径**：同一批入场配对比较退出；分别记录毛亏、费用翻负、曾达 1R 后净亏和硬止损。1R 浮盈仅能在持仓后观测，用它启动分批兑现可以因果实现，却不能反过来用来挑选入场。
- **通用规则**：先证明信号有扣费后的方向优势，再分开验证落袋比例与余仓退出。不能把“做到了颜色翻转离场”或“比随机少亏”表述成“系统赚钱”。
- **牵连**：V1 共 48 项开发比较；原始 251 笔入场净亏 15.37bp/笔，斜率过滤候选 111 笔净亏 6.99bp/笔；冻结候选后续 74 笔净亏 12.14bp/笔。V2 分批兑现是待测假设，不是本笔记声称有效的方案。
