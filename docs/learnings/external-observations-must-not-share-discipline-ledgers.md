# 外部交易观测必须与 App 纪律账本分离

- **问题**：发现任意外部仓位或委托便全账户停手；即使移除这道门，使用账户总净值变化计算日亏仍会把外部交易亏损算进 App 纪律。
- **死胡同**：只删除 `foreign` 判断不够。把外部单塞进已有 `positions/pending/closed` 又会污染次数、保证金占用、连亏、盈利奖励和自动保护；把列表消失当成交或平仓也没有证据。
- **有效路径**：以持久化意图和 outbox 的精确 client ID 识别自有订单，外部观测单独落库并保留首次、最后观测与离开列表时间。日亏采用 App 交易累计已实现与浮动盈亏的日初差额，账户净值仍用于真实资金校验与预算基数。升级保留当日 App 结算与计数；旧版跨日仓位无日初行情时明确从升级观测时刻开始浮盈计量，不伪造午夜价格。
- **通用规则**：记录权限、交易控制权、纪律归属是三个独立概念。外部活动不能触发全账户纪律锁，但同一合约的共用杠杆/合并仓位仍需归属隔离，不能为解除显示警告而误动他单。
- **牵连**：`yoyo/discipline_app/external_records.py`、`live_book.py`、`book.py`、`mobile/src/ExternalActivity.tsx`、`tests/discipline_app/test_external_records.py`。测试覆盖重启、重复观测、资金变动隔离、App 日亏仍生效、同币冲突、外部 ID 不可平撤、币本位金额不冒充 USDT。
