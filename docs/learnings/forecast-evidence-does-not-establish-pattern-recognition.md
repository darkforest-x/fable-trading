# 预测能力与形态识别能力必须分别验证

- **问题**：2026-09-23 Owner 询问 Kronos 能否辅助识别均线密集。官方模型处理 OHLCVA 并生成未来路径；本仓目标是辨认 Owner 定义的收拢核心及启动结构，两者的标签与验收不同。
- **死胡同**：把官方预测基准当成已会识别我们的形态，或把 2026-07-30 六个预测特征未通过当成所有 Kronos 表征都无效。旧实验没有评估 Owner 金标上的形态识别，且后续审计发现其采样、置换与随机对照限制；不能向任一方向外推。
- **有效路径**：先区分当前均线几何、形态语义、未来交易结果。当前密集程度可直接由因果均线计算；Kronos 的冻结历史表征用于相似样本检索或额外识别特征，只是待验证候选，需要自行适配，不是官方现成功能。若以后批准实验，应在相同独立事件、相同时间切分与逐样本金标上，对照显式均线几何基线，报告精确率、召回率、误报与边界误差。收益另验，不用未来盈利决定形态正负。
- **通用规则**：先核对输入、训练目标、输出和本地标签是否对应，再决定基础模型能支持哪项任务。表征可能编码某种结构，不等于已经验证能可靠识别该结构。
- **牵连**：本次仅资料判断，没有运行新实验、训练或调整架构。沿用 [Kronos ADR](../decisions/0002-keep-kronos-as-a-pinned-research-sidecar.md) 的离线研究定位；[既有审计](../../analysis/p0_kronos_architecture_transfer_audit_20260901.md)保留旧负结果；[选图审计](../../analysis/p1_spike_ma_launch_gate_20260923.md)记录 close 选图与 HL2 渲染差异，正式比较前必须统一所比较的语义。输入与归一化截止决策时点；P0/P1、训练与生产门保持不变。历史文档的 holdout 限制已被 Owner 于 2026-09-19 取消，本笔记不恢复该限制。
