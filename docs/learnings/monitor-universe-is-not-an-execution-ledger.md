# A monitored universe must not be inferred from executed positions

- **问题**：模拟盘改成最新成交币种的全屏图后，只保留交易簿，用户找不到未成交的监控币种。
- **死胡同**：从持仓和最近成交拼列表只能找到产生过交易的币，不能代表 507 个监控合约；让图表必须接收有效成交对象，也会迫使未成交币种显示另一笔交易或空白。
- **有效路径**：监控池读取 Monday 的完整公开行情快照，持仓仅作为当前轨道的附加标记。图表币种与可选成交覆盖层分开；选择未成交币种加载其真实 K 线并清除旧覆盖层，跟随最新成交是独立模式。页面隐藏时两个读取循环都暂停。
- **通用规则**：先区分全集、筛选结果与事件记录。浏览对象的身份不能依赖它是否产生过交易或其他事件。
- **牵连**：`reclaim-watchlist.js`、`reclaim-chart.js`、`monday-reclaim-paper.js`；保留 stale/missing 状态，不以示例数据填空。
