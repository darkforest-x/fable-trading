# 小文本自动保存应在输入事件内完成

- **问题**：此前 RektProof 笔记、检索和计算共用计时器，快速跨视图操作会取消待保存笔记，见历史定位笔记 `shared-debounce-timers-can-cancel-unrelated-autosaves.md`。
- **死胡同**：只拆计时器仍需处理导航、导出与关闭前的所有刷新时机；输入框有文字不表示已写入存储。
- **有效路径**：短笔记在输入事件内立即写入本机存储，检索和计算才各自防抖；写入失败明确提示。以“输入 → 切检索并输入 → 刷新 → 返回”验收实际持久化。
- **通用规则**：按操作后果选择防抖边界；可延迟的展示工作不能控制数据提交，验收必须跨视图并重新加载。
- **牵连**：`yoyo/monitor/static/rektproof.js`。功能 QA 使用独立 `rp-qa=1` 存储，不往 owner 的学习记录写测试样本。
