# 官方归档和历史接口的价格冲突也要核对交易影响

- **问题**：延长 V2.31 到五年时，BTC/ETH 分钟归档分别缺 3/43 分钟。同一 OKX 历史接口可以补缺，但 ETH 2022-12-18 的 67 根相邻记录与归档不同，既有零成交平价，也有实际 OHLC 差异。
- **死胡同**：把“同一交易所官方来源”当成“每根历史报价必然完全相同”，会在补缺时悄悄混入修订价格；把缺口全部合成平价也没有数据依据。
- **有效路径**：保留已知归档行，仅用已确认的官方记录补缺，另存冲突的两套 OHLC。限制冲突日期，重算替代报价下的信号与对照波动桶，均完全一致；再确认全部信号及随机对照持仓均不穿过冲突及分型确认影响窗口。最近一年行情和交易身份与缓存逐条核对后复用旧成交。
- **通用规则**：补历史缺口时同时检查重合区；官方来源也可能有版本差异。价格差小不能替代影响检查，没受影响的缓存也不应全部重跑。
