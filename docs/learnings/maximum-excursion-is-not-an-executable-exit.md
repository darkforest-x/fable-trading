# 最大浮盈画框不能代替可执行的退出规则

- **问题**：BICO 1H 的绿色历史框显示194.48R，用户因此问如何在最高点止盈；脚本同时显示SMA20保护状态，却没有把保护失守接成这段跟踪的退出警报。
- **死胡同**：把框顶当收益，或看完整段走势后挑一条最合适均线，都不能回答当时如何操作。原脚本的保护失守只改状态，最大浮盈仍继续更新；更宽的跟踪框并不代表实际持仓和成交。
- **有效路径**：先冻结截图入场与初始风险，区分信号收盘、可执行入场、最大有利影线、退出确认和下一开盘参考成交。仅更换事先列出的退出规则，逐根因果回放，并在同一全局图标记实际模拟退出。独立复核原始15m到1H聚合与首次触发，避免把后来的回归保护线误当成一直持有。
- **通用规则**：所有R图先回答分母是否冻结、峰值何时停止更新、是否存在真正退出条件及通知。显示MFE时同时显示执行规则对应的退出R；单个事后赢家只能解释取舍，不能选最优参数。对照缺样必须按实际数量披露，同趋势相邻入场不能当独立重复。
