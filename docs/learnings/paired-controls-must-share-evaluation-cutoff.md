# 分期评估时，配对随机对照也必须遵守相同截止日

- **问题**：单根插针研究按时间切分并排除跨期信号，但特征分组若仅凭事件 ID 取回所有对照，对照可能在下一评估期才退出。
- **死胡同**：只给信号设置时间掩码，再按 `event_id` 拉回对照，看似配对完整，实际上放松了对照的观察边界。本次在首次完整特征读出前审查发现并修正，未据此发布结论。
- **有效路径**：每个分期先对整个信号与随机账本应用相同入场、退出时间约束，再按事件 ID 配对；不够三个完整对照的事件保留缺配状态。用于决定特征方向和分位阈值的记录必须在训练截止前已知结果。
- **通用规则**：检查时间切分时，沿着关联键检查附表和对照，不只检查主信号表。
