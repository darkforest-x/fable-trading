# 周线文字跟随当前使用区间，不跟随视口

- **问题**：历史周价格线需要保留，但名称和价格密集遮挡 K 线；纽约周一形成期间，页面仍使用最近完整周作显示参考。
- **死胡同**：直接用“不是本日历周”隐藏全部文字，会连用户当前使用的最近完整区间也一起隐藏；改为空名称还会破坏按标签选择四根主线的现有逻辑。
- **有效路径**：保留标签字段、价格、锚点、到期时间与历史淡化语义，仅给 API 当前选择的显示区间开放 inlineNameVisible / inlinePriceVisible。新周锚点就绪时，旧周文字随之关闭，线段继续保留。
- **通用规则**：显示简化应改变展示属性，不应删除用于筛选的数据；视口平移只改变可见范围，不能把可见最右一周重新认定为当前。
- **牵连**：`yoyo/monitor/static/monday-fib-chart.js` 的 `withWeeks`；`monday_chart_levels.py` 的 `read_display` 已有周一过渡规则；不修改区间价格或策略。
