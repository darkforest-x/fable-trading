# 改正框目标本体时必须重新打开负标签本体

- **问题**：正框从“K线 high-low 区域”改成“六均线密集结”后，旧 hard negatives 仍为空标签；同口径审计发现 29.04% hard negatives 的六均线包络不宽于正例中位数。
- **死胡同**：只重画正例并原样复用空负例，会让视觉上明显存在目标本体的图同时被监督为背景；反过来把所有密集 hard negatives 自动转正，又把“密集”偷换成“会启动”。
- **有效路径**：先拆开 L1 类定义：若 L1 定位任何密集结，密集 hard negatives 应有框而由 L2 判断启动；若 L1 只定位即将启动的结，负例可以为空，但必须冻结检测窗结束前可见的启动/释放条件。协议未裁决前只画反事实框，不改标签。
- **通用规则**：目标框的语义本体一旦改变，正负类必须一起重审；“背景”不是没有旧框，而是没有新定义下的目标。先写 L1/L2 职责，再决定 hard negative 是负类、正类、ignore 还是另一类。
- **牵连**：两层架构 L1 YOLO + L2 LightGBM、26,874 个旧负样本、`negative_review_manifest.jsonl`、Gold gate、协议确认不等于逐样本确认。
