# 币种命名不能证明行情来自哪家交易所

- **问题**：统一目录里，同样的 ETH_USDT 文件名可能来自不同交易所；目录迁移又可能隐藏原来的来源子目录。
- **死胡同**：看到 `_USDT` 就推断 OKX，会把无来源或跨来源的两份价格当成同一序列，即使逐行去重没有冲突也不成立。
- **有效路径**：保留原始相对子目录，从显式交易所名称或已有输入清单识别来源；无法唯一证明的来源留空。回测选择交易所后仍检查同时间价格冲突与连续性。
- **通用规则**：格式兼容、币名相同和内容碰巧一致都不能替代数据来源身份；来源未知时只登记，不自动跨源拼接。
- **牵连**：`yoyo/data/dataset_catalog.py`、混合输入目录与统一读取接口；精确字节共享只影响存储，不改变逻辑文件、标签或 split。
