# 早退能改善亏损形状，却可能摧毁趋势尾部期望

- **问题**：V7 的多数亏损来自初始止损，于是希望用“入场后 2–3 根未创新高/低”或“2–3 根内收回均线绳”更早离场。
- **死胡同**：只看平均亏损缩小或收盘回撤下降就接受早退。趋势策略的收益集中在少数长尾交易；早退还会释放持仓并触发额外重入，因此平均亏损变好不代表账户曲线变好。
- **有效路径**：固定 V7 入场、V6 执行、0.2% 成本和时间切分，只改变一种收盘确认、下一开盘执行的退出规则；在开发期同时要求账户收益不差、亏损或回撤改善、已实现 10R 保留率至少 95%。四个候选均未通过，开发期账户收益全部低于基线；复用历史验证段也全部低于基线。
- **通用规则**：趋势系统测试早退时，必须同时报告账户收益、重入数量和尾部赢家保留率；不能用更小的平均亏损单独裁决。开发门失败后仍可报告验证期作诊断，但不得据此回头选择规则。
- **牵连**：`yoyo/evaluation/spike_early_failure_exit_study.py`、`experiments/active/exp-spike-early-failure-exit-20260913-v1/results/full_v3/selected_rule.json`；本轮结论为拒绝，不改 V7/V8 生产退出。
