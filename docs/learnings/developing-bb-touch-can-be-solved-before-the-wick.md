# 盘中 BB 触轨价可以在影线出现前求解

- **问题**：策略要求价格碰到实时发展的 SMA 布林带立即平半；历史 high/low 对比该根最终 BB 会混用两个时点，收盘后再发市价单也不是影线触轨成交。
- **死胡同**：仅打开 calc_on_every_tick 不能补回历史 tick；把最终 BB 当已挂出的目标也包含未来的该根收盘价。此前指标 v1 只能声明历史近似，本次策略需要预先可挂出的价格。
- **有效路径**：长度 N 的窗口中前 N−1 个收盘已确定，仅当前价 x 可变。设其均值 m、总体标准差 s，解 x=BB(x) 得到上下触轨边界 `m ± k*s*sqrt(N/(N-1-k²))`，要求 N>1+k²。在上一根收盘用最近 N−1 个值为下一根挂限价；多头向上、空头向下按最小报价单位取整。用完整窗口直接重算总体 BB 作独立校验，2400 次人工比较通过，边界误差不超过1.43e-14。
- **通用规则**：指标阈值依赖正在运动的当前值时，先检查是否能代数求交点；能预先求解就交给已挂出的价格单执行，不把收盘知识倒灌到盘中。
- **牵连**：`yoyo/evaluation/pine/eth_bb_stoch_strategy_v2.pine`；`experiments/active/exp-eth-bb-stoch-strategy-20260916-v2/check_bb_touch.py`。仅适用于 SMA、总体标准差和当前 close 的这套 BB；同根止损与止盈先后仍取决于 TradingView 可用路径，数学等价不是收益验证。
