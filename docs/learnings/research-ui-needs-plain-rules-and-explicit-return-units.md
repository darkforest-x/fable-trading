# 研究页先讲触发和假设，再讲收益及证据来源

- **问题**：市场共振页把 z、量比、bp 与历史/前向统计并排展示，Owner无法直接判断“什么情况触发、假设怎么交易、结果代表什么”。
- **死胡同**：原界面虽然包含定义和停更提示，仍要求读者自行拼接规则并换算收益。只解释术语或只换单位，会继续混淆触发时的涨跌与入场后的收益。
- **有效路径**：先按当前选择生成三条同时满足的触发条件，再明确下一根开盘的方向、品种、持有时长和成本。历史结果、及时捕获与事后补算分开呈现；接口仍保留原始bp，仅展示时除以100变成百分比，收益之差用百分点。缺失数值不能经绝对值转换成为0。
- **通用规则**：更换研究界面表达时，同时核对单位、时间、方向和证据来源。用固定数值验证53.8bp→0.538%、-191bp→-1.91%，并验证切换方向/品种/时长后说明与结果一致。折叠专业说明时保持刷新后的展开状态。
- **牵连**：`yoyo/monitor/static/market-sync.js`、`market-sync.css`、`app.js` 和 `tests/monitor/frontend_market_sync.test.cjs`。仅改展示，触发参数、收益计算、成本、数据源和前向资格判定不变；高量筛选缺历史明细时继续显示不可统计。
