# 回标图形的位置过滤必须查原信号所属周

- **问题**：V2.41 给勾叉增加周一区间外显示过滤。同一个勾叉既可能在当前 K 线上直接绘制，也可能在 5m 复盘框确认后回标。
- **死胡同**：仅在两个 `plotchar` 上加条件会漏掉复盘标签；把当前 `monHigh/monLow` 用于后来重绘的全部标签，又会拿最新周判断旧信号。代码检查时排除了这两条路径，没有用收益回测替代显示验证。
- **有效路径**：普通勾叉使用逐 K 更新的当周范围；复盘标签按原信号时间定位 `MondayRange`，仅接受该周周一结束至下周周一前的来源 K 线。先用原始影线极值过滤，再施加标签的视觉偏移。
- **通用规则**：显示过滤先查清所有绘制入口及各自的时间坐标；延迟绘图使用来源时刻的数据，显示状态不回流到原信号、警报或交易状态。
- **牵连**：`yoyo/evaluation/pine/monday_range_v2_41.pine` 的 `markerOutside`、`markerHistoryAllows`、主图 `plotchar` 和 5m 复盘 `label.new`。
