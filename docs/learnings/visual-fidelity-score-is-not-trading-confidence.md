# 视觉相似度分不能当交易置信度

- **问题**：两组 owner 图例可以被 K1、K2、间隔路径、颜色、振荡器与结构状态高精度复刻，形态分达到 81.54/83.44；但需要判断“更像图例”是否意味着更高的事后收益。
- **死胡同**：继续提高形态门槛或叠加共同视觉条件。`anchor_score >=70` 的历史净收益为 -31.5bp、新鲜 pre-holdout 为 -54.4bp；`>=80` 的新鲜 4 笔全部止损。55 个因果单维选箱在 2025 的联合通过数为 0，说明维度更多、图例更像都没有补出独立收益信息。
- **有效路径**：把“识别目标”和“盈利目标”物理分层。相似度只回答候选是否符合 owner 的形态语言；收益必须另用时间外数据、匹配随机对照、成本、置信区间和多重检验裁决。图例只用于定义特征，不参与阈值收益选择。
- **通用规则**：凡是从少量成功截图或人工范例构造的分数，默认把它命名为 `similarity`/`fidelity`，禁止命名或解释为 `confidence`。第一项收益检验应是“分数排序在未参与定义的时间段是否单调优于匹配对照”，而不是继续调相似度权重。
