# 逐笔记录的主键不能复用周与币种分组键

- **问题**：周一日期与币种拼接作为唯一键，导致同周同币的第二笔或反方向交易覆盖第一笔。
- **死胡同**：仅给方向再加一段仍会覆盖同方向多笔；看到保存成功提示也不能证明旧记录还在。
- **有效路径**：每条记录分配独立 ID，周、币种、方向只用于属性与排序；更新、复制、未交易记录分别表达。旧记录迁移保留原键派生的稳定 ID，导入同时处理活动记录与回收站冲突。
- **通用规则**：先区分实体身份与分析分组；用同分组的两条不同记录验收，并检查删除、恢复和导入后的身份。
- **牵连**：`yoyo/monitor/static/rektproof.js`、`rektproof-core.js`；浏览器沙盒已验证同周 BTC 多空两条并存及回收站恢复，个人存储未用于写入测试。
