# 权益曲线抽样必须保留实际收盘时间

- **问题**：V2形成记忆研究复用V1报告抽样代码，审查发现每日最后一个权益值被pandas resample默认标为当天00:00，显示时钟比实际收盘提前，原始初始权益点也被覆盖。
- **死胡同**：仅验证组合终值、最大回撤和月度增量正确就认定显示曲线也正确。V1全量逐K组合和月检验不受影响，但展示抽样时间仍可能误导。
- **有效路径**：冻结运行前，将显示抽样改成按日选出原序列最后一个观察点，保留其原时间戳，额外保留真正的初始权益。用跨日合成序列断言每个显示点逐时间等于原序列，日末值不能冒充日初值。
- **通用规则**：降采样图表同时审核值与时间，特别区分周期标签和实际可观测时刻。计算正确与显示正确是两条验收轴。
- **牵连**：`yoyo/evaluation/imacd_formation_research.py`、对应tests；仅修本轮V2，V1历史产物保留原样。无价格读取、交易规则或在线修改。
