# 少做亏损交易不等于挑出了更好的趋势交易

- **问题**：V20结构门后全机会亏损明显减少、胜率及PF稍升，容易被误报成“共振有效”。
- **死胡同**：只看总亏损或获准子集的单个指标；原251机会与候选137成交本就不等量，1个未知还使可比较分母不同。全case均值减全部control均值也不等于固定配对I。
- **有效路径**：同时保留全机会D、真实成交质量及固定三控制I。获准每笔净−17.22bp比原−16.77bp略差；154配对中case改善+3.67bp、control改善+7.76bp，I为−4.09bp。少亏主要来自减少暴露，尚无更好选时证据。
- **通用规则**：判断过滤器，先问留下的单子是否更好、减少的盈利机会损失多少、随机同条件机会是否也同样改善。拒绝交易要重算单仓占用，未知不能补零；总事件bp不是账户收益。
- **牵连**：V20只改变持久结构方向门，V18退出、K1止损、72h和20bp不变；137接受中103净亏，91笔毛已亏，不能把失败全怪成本。详见`analysis/p1_btcusdtp_hourly_structure_v20_20260906.md`。
