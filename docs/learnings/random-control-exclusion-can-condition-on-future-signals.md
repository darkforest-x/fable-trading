# 随机对照的禁入区也可能偷看未来

- **问题**：同周随机入场匹配常排除信号前后若干根，以减少重叠；但随机时点之前并不知道随后会不会有信号。
- **死胡同**：以“特征都因果”为理由把这种对照账户描述为可前向策略，忽略样本能否入选本身用了未来事件存在性。
- **有效路径**：SPIKE 首次收益评估前审查即发现这一点，改为随机时点仅排除已发生的本根及过去12根信号。同周匹配依然诚实称回顾式条件抽样。
- **通用规则**：前视检查不仅检查输入特征，也检查候选资格、排除区、匹配条件与资金分配。未来价格没被读取不等于选择过程可前向运行。
