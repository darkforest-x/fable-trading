# 减亏半仓与余仓必须分账，已实现现金流不能冒充整笔已知

- **问题**：把小周期确认失败后的全平改成减半仓，看似只换份额，实则新增一个已成交现金流和一个仍在承受风险的余仓。
- **死胡同**：直接平均旧全平与旧趋势版收益会借用一个后来才出现、现已被提前减仓替代的盈利半仓；成交后跳过当前K线还会漏掉同根止损。已实现部分为真，也不等于整笔收益已知。
- **有效路径**：减仓时刻和价格严格锚旧全平；终场价格、时间、结果和MFE单独锚原慢周期路径，完全不借收益。两腿按原始名义仓位计价、费用按份额分摊。余仓被数据截断时整笔收益保持未知，已实现半仓单独保留。新分支用精确报价核算，旧分支保持数值一致。
- **通用规则**：任何分批退出先定义资金账本，再独立固定终场结构与成交时钟；既不能把减亏叫止盈，也不能以已知现金流填补未知余仓。
- **牵连**：`yoyo/layers/l3_backtest/hourly_impulse.py`、`tests/test_hourly_impulse_failed_reduce.py`、V19单变量实验；原始20bp往返成本、K1极值止损、72h期限不变。此笔记是执行语义结论，不是盈利结论。
