# 策略工厂的接入必须先保住交易契约

- **问题**：自动生成大量策略、显示高回测收益的工作流，能否直接承载 SPIKE 并提高盈利？
- **死胡同**：把“能生成 Pine、能显示 PF、能自动下单”当成保持原策略的证据。公开工厂模板固定退出、仓位和胜率门槛；只移植信号会改变低胜率、长尾趋势策略的收益结构。换回测引擎重复同一历史，也不能产生新的样本外证据。
- **有效路径**：先分清研究编排、信号状态机、撮合与风险、证据验收、订单执行五部分。对照原始源码和最新报告，逐项核对信号可知时刻、实际入场、参考 R 与成交 R、退出、并发资金和成本；将外部工厂用于编排与记录，保持现有交易契约作为基线。候选冻结后的新数据另行积累，历史开发结果不升级为前向实盘。
- **通用规则**：在问“接进去收益会不会更高”之前，先问接入前后是不是同一个策略、同一个资金模型和同一个样本外定义。先验证无变化移植，再对一个变量的增量作检验；吞吐量和排行榜不是盈利证据。
