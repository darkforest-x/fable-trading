# 倍投先定义止损金额与拒单状态，再比较收益

- **问题**：ETH V8 每笔结构止损距离不同，Owner 要研究止损后下一信号倍投。如果直接将合约数翻倍或把所有历史净R乘2，会混淆资金风险并算进有限本金实际开不出的仓位。
- **死胡同**：只对已完成交易收益加权，既没有保证金容量，也不区分止损亏损、反向退出亏损、盈利跟踪止损；如果用被拒绝单的未来输赢重置层级，还会让下一笔仓位偷看未发生的交易结果。没有采用这种算法作为正式结果。
- **有效路径**：先将 policy 明确为计划初始止损金额，再用 `notional=risk_cash/initial_risk_frac` 换算仓位；入场仅依据已知余额、止损距离、层级与固定费用预留。拒单保持账户和级别；封顶认亏只重置级别，不抹去余额亏损。用合成前缀不变性、10/20/40亏损扣70、拒单无未来结果、费用不重复扣等行为测试钉住语义。
- **通用规则**：仓位研究必须同时交付现金约束和状态转移。交易级现金账本的未归零，不等于经过交易所标记价格/维持保证金/持仓内浮亏检验；边界未平仓要显式标记，不得按未来是否自然平仓筛掉。
