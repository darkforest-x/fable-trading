# 单根插针的入场定义不能要求未来不再触线

- **问题**：Notion #72 用一张已经反转的 DOGE 图寻找“只有一根 5m 插针到 1.618”的同类，并要求收盘入场、针尖止损、远端区间 0.618 止盈。图形描述同时包含入场时可见信息与未来结果。
- **死胡同**：直接复用旧的所有收盘回收样本，不能单独回答影线触线的问题；反过来，若再要求后来没有第二根触线，就会事先删掉许多止损样本。后者是本次明确排除的方法，未把这种未来筛选用于历史执行。
- **有效路径**：冻结已完整收盘的纽约周一高低点；前一根未触线，当前根的影线触线、开收盘均在线内，即为可观察候选。允许未来再次触线，由原生框架决定止损或止盈。首次周内触线与后续独立插针分组保留；成功、失败、缺数据未决分别统计。未来价格扰动测试保证既有信号和特征不变。
- **通用规则**：对“只出现一次就反转”的历史形态，先写清决策时刻能观察到什么，再把“之后只出现一次”作为结果描述。高计划盈亏比也不是高胜率或正期望的证据。
