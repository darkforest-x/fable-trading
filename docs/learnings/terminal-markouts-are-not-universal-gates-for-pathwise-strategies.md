# 固定终点诊断不能成为所有路径策略的先决条件

- **问题**：连续的共振实验未通过固定四小时收益门，研究流程逐渐将其当成任何趋势退出研究的前提。
- **死胡同**：在同一批 K1 上不断增加过滤器，并把“固定终点没有正期望”泛化为“路径交易没有可能”。两条路径可以有相同起点和终点，却先后触发不同的止盈、止损；终点不识别这种差别。另一方面，假装此前没有做过动态退出，同样是在忽略负面证据。
- **有效路径**：逐一核对估计对象。V24/V30/V32 的固定终点失败保留；V1/V2/V8/V15–V19 的真实动态退出失败也保留。后续若改变入场家族或风险目标，另立事前实验合同，直接比较完整可执行路径与相同规则的背景对照，不要求它先通过与目标不等价的固定四小时诊断。
- **通用规则**：先问“此统计量是否真是用户交易目标的必要条件”。不等价时，把它作为诊断而非普遍否决门；不能事后降低旧门槛、挑更好的终点，或从最大浮盈倒推理想成交。
- **牵连**：`yoyo/evaluation/hourly_impulse_fixed_clock.py` 明确只使用两端 OPEN；V32 `PROJECT_PLAN.md` 将四小时门与下一步执行研究连接。多次复用开发数据仍不是独立验证；20bp、holdout、真实成交权限和原负面裁决不变。

数学反例（纯合成，不是行情或建议参数）：起点 100、四小时终点 100 的两条连续价格路径，A 先到 102 再回 100，B 先到 99 再回 100。固定持有的两笔毛收益都是 0；若事前固定 102 止盈和 99 止损，按首次触及执行，则 A 毛收益 +2%、B 毛收益 -1%。固定终点不识别路径收益。反过来，知道 A 的峰值也不能在真实入场时知道它将是 A；该反例仅否定两种估计对象等价，并不证明存在可盈利的规则。
