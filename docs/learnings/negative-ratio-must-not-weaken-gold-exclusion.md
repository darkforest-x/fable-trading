# 负例比例不能凌驾于金标禁入区

- **问题**：为1,360个时间合格正例配1:1同币同时间块背景时，验证集有2个正例找不到任何不碰Owner框±12根保护区的背景。
- **死胡同**：继续增加随机次数、允许跨币、缩小保护区或复用完全相同的负窗都能把表面比例补成1:1，但会把已知金标附近行情混入负类，或制造重复样本，数据数字更整齐而语义更差。
- **有效路径**：保持Owner禁入区、同币、同split、同W四项合同不变；先随机、再穷举安全位置，仍无解就诚实保留202/204，并在报告里单列未匹配原因。
- **通用规则**：配对数据集的目标比例是软目标，标签纯度和时间隔离是硬约束；任何无法满足硬约束的配对都应缺失而不是降级规则凑数。
- **牵连**：`scripts/build_owner_short_gold_center_dataset.py`、`datasets/owner_short_gold_center_v1/`、Owner全方向框保护区、150-bar purge、holdout禁读。
