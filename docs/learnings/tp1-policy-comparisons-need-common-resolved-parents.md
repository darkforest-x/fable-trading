# TP1 policies need identical resolved parent cohorts for return deltas

- **问题**: A tighter TP1-triggered stop makes some previously unresolved runners close. Comparing each policy's completed-trade average mixes an exit effect with a changed denominator.
- **死胡同**: The Monday bodyN3 hold-stop arm has18,698 completed altcoin parents and52 unresolved; breakeven has18,722 completed and28 unresolved. Subtracting their standalone means (-0.094484R and-0.104327R) is not the paired policy effect. Counting saved stops or the higher win rate also omits interrupted eventual winners.
- **有效路径**: Preserve immutable parent IDs, entry risk, costs and original target anchors. Report each policy's full coverage, then join only parents resolved by both policies and lying on the same chronological side. On18,698 shared parents, breakeven mean is-0.104707R, an effect of-0.010223R (-191.157R sum).5,257 original runner stops were protected but2,197 eventual far-target winners were cut; improvements total+2,744.911R versus deterioration-2,936.068R. One unchanged SUN target has a+2.91e-9R native rounding difference, not an additional saved stop. The95% weekly bootstrap interval[-0.025688,+0.005483] does not establish a negative population effect, but also supplies no evidence of an improvement.
- **通用规则**: Keep coverage and paired effects separate whenever policies change holding time. Apply the same intersection to random controls and chronological slices; retain censored parents and never declare a partially realized TP1 an entire winning trade. Report money/R lost from truncated winners alongside the number of protected losses. Positive win-rate changes are not a substitute for expectancy.
