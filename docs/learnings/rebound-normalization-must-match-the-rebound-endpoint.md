# 独立反弹的波动分母应对应反弹终点

- **问题**：Bybit BTC 15m 手画线的 A/B/C 间距、贴合与历史穿线都通过，却被反弹深度筛掉。
- **死胡同**：把责任归给周期大小、第三点或历史穿线均不符合原生诊断。放松所有触线容差会改掉无关条件。
- **有效路径**：原生单独打印每道条件，定位 AB=1.416ATR；分子是谷底→B反弹，分母却取 A 冲击点与 B 的较大ATR。V12 局部回踩族使用 B 点 ATR，保留 2ATR 阈值及旧口径开关，以正负合成序列与历史案例验证。
- **通用规则**：波动归一化必须与所测量的波段角色对应；极端起点波动不能自动代表后续反弹波动。单例只能证明规则含义，不证明收益优势。
- **牵连**：仅辅助结构族 AB 反弹分母；BC、原三主点族、V9 与风险成本规则不变。Bybit 原生诊断使用的都是当时及之前 OHLC。
