# 最新时间戳不能证明信号输入已经齐备

- **问题**：市场共振的新鲜度只读 BTC 最后一根 K 线时间；ETH 指标缺失或山寨不足时，页面仍可能显示行情正常，并把无法判断写成未满足条件。
- **死胡同**：请求成功、进程在线或 BTC 刚更新，都不能说明组合信号有完整输入；重试也不能修复交易所明确返回的地区限制。
- **有效路径**：保留既有时间门，同时检查 BTC/ETH 的因果指标及原协议要求的山寨数量；分别返回 stale、ready 和覆盖数。地区限制明确展示，保持来源，不静默混入别的交易所。
- **通用规则**：组合信号的健康状态取决于全部必要输入。缺数据属于未知，不是阴性结果；覆盖信息与策略门槛应分开。
- **牵连**：`yoyo/monitor/market_sync.py`、`tests/monitor/test_market_sync.py`、`tests/monitor/frontend_market_sync.test.cjs`。原 ≥10 山寨、新鲜度和策略条件均不变。
