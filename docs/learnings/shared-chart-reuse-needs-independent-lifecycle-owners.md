# 复用图表渲染器时，每个页面仍须独立拥有生命周期

- **问题**：将周一 1.618 图表复用到模拟盘时，原控制器只有一个 target、请求控制器和定时器；页面激活顺序可能让旧页面的 hide 清掉新页面图表。
- **死胡同**：只给复用组件换宿主节点，并不能隔离生命周期。两个页面共享同一个全局对象，即使 DOM 不同，暂停和销毁仍作用于最后一次 show 的对象。
- **有效路径**：保留原页面默认 API，增加控制器工厂。每个消费者拥有独立请求、缓存、定时器和实时订阅，共享渲染器通过每次 draw 的可选装饰回调接入成交图层。用同时创建两个实例、关闭一个不终止另一个请求的行为测试确认隔离。
- **通用规则**：复用带请求或实时订阅的可视组件前，先找到资源的拥有者以及销毁入口；复用代码不等于共享可变实例。
- **牵连**：`yoyo/monitor/static/monday-fib-chart.js`、`range-chart.js`、`reclaim-chart.js`、`tests/monitor/frontend_reclaim_chart.test.cjs`。
