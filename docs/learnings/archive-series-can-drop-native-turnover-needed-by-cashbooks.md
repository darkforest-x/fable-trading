# 长历史价格齐全，不等于容量账户的数据齐全

- **问题**：扩展 SPIKE 到三年时，本地有大量已认证 OHLCV series，但旧导出删掉了 quote_volume。现有资金账户按真实 USDT 成交额限制仓位，用这些 series 会缺少关键输入。
- **死胡同**：把价格乘成交量当作历史成交额，会混淆交易所的合约张数与基础币单位；即使基础币单位正确，也不能用一根收盘价还原整根成交的真实总额。
- **有效路径**：回到已保存且有 ZIP 与 CSV 哈希的币安官方月档，从原生第八列恢复 quote_volume；只把完整 UTC 四根15m合成1H，再与认证的原生1H尾段接续。旧 series 保持只读，断档拆段、分别预热。
- **通用规则**：复用数据前按新任务所需字段审核，而不只核对价格、行数和文件哈希。源文件有完整字段时优先恢复真实列；没有时降低可声称的评估范围，不造输入补齐。
- **牵连**：`yoyo/data/spike_burst_history.py`、`yoyo/evaluation/spike_burst_long_history.py`。目录快照不是历史退市全集，当前 tick 不是历史 tick 变更表；这些限制仍需单独披露。
