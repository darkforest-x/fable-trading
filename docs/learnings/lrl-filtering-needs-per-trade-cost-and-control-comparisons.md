# LRL过滤后的总亏损变小，不等于每笔交易变好

- **问题**：ETH原生3分钟iFVG＋LRL验证段只交易24笔，总净R比300笔基线少亏很多，容易把减少交易次数误认为出现了优势。
- **死胡同**：仅比较累计净R，或套用外部MNQ截图的80%胜率，均不能回答ETH候选质量。此次没有按结果调整过滤条件或成本；这些捷径不能形成验证证据。
- **有效路径**：冻结LRL门后同时列独立候选、单仓账本和匹配随机入场。验证LRL毛-4R、成本18.89R、净-22.89R；均净-0.954R，基线单仓为-0.619R。LRL对匹配随机增量-0.083R，按日聚类p=.6333，未建立增量优势。
- **通用规则**：过滤器回测先分清“少交易”和“每笔更好”；每笔以成本R=名义往返费率/结构止损比例解释，再比较同币、同时段、同波动对照。不能用总亏损下降直接宣布过滤有效。
