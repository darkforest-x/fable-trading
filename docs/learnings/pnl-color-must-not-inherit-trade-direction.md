# Signed P&L needs its own semantic color

- **问题**：交易簿把方向和盈亏放在同一个按 side 上色的容器内，多头亏损因继承方向色而显示绿色。
- **死胡同**：只改负号或深色主题的色值不能修复错误的颜色归属。把容器全部改红又会反向污染方向标识。
- **有效路径**：方向和带符号盈亏分别用独立 span；盈亏仅由对应数值正负决定。默认列表用剩余名义金额显示持仓，避免把数量误当金额。浏览器核对负盈亏计算颜色，并在最窄布局下允许完整金额换行。
- **通用规则**：方向、状态、盈亏是独立语义；紧凑排版不能让它们共享隐含的颜色或单位。
- **牵连**：monday-reclaim-paper.js/css；真实 WET、RE、AT、COAI、GRVT 负盈亏浏览器验收，单行标题栏高 52px，320px 无页面横向溢出。
