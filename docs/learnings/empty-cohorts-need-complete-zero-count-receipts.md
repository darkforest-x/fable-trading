# 合法的空队列也要生成完整零计数回执

- **问题**：严格匹配可能找不到任何随机对照。收益标签器在非空循环中才读取标签契约，空队列到了汇总阶段会引用尚未赋值的变量。
- **死胡同**：把空队列当作异常数据、补抽随机样本或跳过评估，会掩盖真实缺配，也可能改变冻结的实验范围。
- **有效路径**：在循环前读取固定契约；空输入仍输出空标签文件、零计数和其真实SHA。测试要求此路径不读取任何价格文件。非空收益解析代码保持一致。
- **通用规则**：凡允许严格过滤后零样本的批处理，先验证零行输入也能产出可审计的结果，不能靠循环内赋值初始化全批元数据。
- **牵连**：`yoyo/datasets/ma_profit_pipeline.py`的`label`；不会改变形态、止损、目标或费用口径。
