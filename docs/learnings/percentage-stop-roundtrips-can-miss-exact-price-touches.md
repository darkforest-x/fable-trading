# 百分比止盈止损转换必须保留价格边界的包含关系

- **问题**：把固定止盈价110转换为相对100的10%后，框架内部可重建为110.00000000000001；最高价恰好110时，原本应成交的触价被漏判。
- **死胡同**：只把最终成交价四舍五入无法修复漏掉的触发，因为错误发生在触发搜索之前。仅测试明显越过障碍的K线也发现不了这个问题。
- **有效路径**：先用单根100/110/99/105的OHLC复现漏判。把传给VectorBT原生止损内核的比例向内调整4个机器epsilon，并强制检查对应价格位移小于原价格量子四分之一；框架成交价仍回到原精度。精确触价、同K多空顺序、跳空止损和逐笔费用均由针对性夹具检查。
- **通用规则**：固定价格障碍进入百分比API时，先测试恰好相等的多空边界；误差处理必须受原价格精度约束，不能偷偷改变策略止损或止盈。
- **牵连**：`yoyo/evaluation/monday_vectorbt_engine.py`、`tests/evaluation/test_monday_vectorbt.py`；原O-H-L-C假设、独立交易口径和框架计算纪律不变。
