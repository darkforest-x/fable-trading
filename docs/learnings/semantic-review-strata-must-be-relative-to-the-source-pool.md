# 语义审核分层必须相对母池定义

- **问题**：审核包虽然从不同位置和波动窗口抽样，但固定绝对阈值把100个Positive位置全部归为`mid`，也把91%的Canary波动归为`low`；表面有分层字段，实际不能证明覆盖。
- **死胡同**：沿用为别的数据分布预设的绝对position/volatility阈值。阈值本身合法，却与当前W12–19局部窗的窄位置分布和市场波动尺度不匹配。
- **有效路径**：先在冻结母池上计算真实因果窗口位置与波动，再按母池三分位定义low/mid/high；抽样后同时报告母池、入选数和各桶计数，禁止只检查字段非空。
- **通用规则**：语义审计的分层门先检查每桶占比；若目的是覆盖而不是业务绝对门，默认使用冻结母池分位数，不复用其他实验的绝对阈值。
- **牵连**：`scripts/build_local_signal_v2_semantic_review.py`、`sampling_audit.json`、Positive/Canary分层抽样、holdout纪律。
