# 多空拆分的大幅提升不能取消小样本门

- **问题**：同一批 side-aligned 特征把 LONG 与 SHORT 放进一个收益回归器时，模型只有两棵树且筛选价值很弱；按方向拆开后，冻结 q90 的净收益突然大幅提高，容易被误判为已经找到可上线模型。
- **死胡同**：把多空映射到同一“顺交易方向”坐标后就假设它们共享同一条件收益函数；或者看到拆分后20个样本平均净收益很高，就忽略置换显著性与最小独立事件数。方向对齐只统一了符号，不会自动统一多空行情的波动结构、均线背景与特征—收益关系；小样本均值仍可能由少数极端收益抬高。
- **有效路径**：先逐分数复现混合模型，再只改“共享模型还是分方向模型”；LONG/SHORT分别用原时间切分训练、各自在 tune 固定 q90，并用各自 tune 经验百分位做合并排序。结果必须同时报告每侧样本数、top-decile、冻结门、匹配随机对照与置换检验。本轮经济均值与8/8匹配对照改善，但合并 p=0.072、选择数20且SHORT仅7，因此诚实判 FAIL。
- **通用规则**：任何 side-aligned 模型都先做 pooled-vs-per-side 单变量对照；分侧模型的原始分数不得直接混排，先做只依赖 tune 的尺度校准。无论 lift 多大，预注册的独立样本数与显著性门不能因结果漂亮而下调。
- **牵连**：`scripts/retrain_15m_ma_launch_l2_by_side.py`、`yoyo/layers/l2_judgment/features.py`、`yoyo/layers/l2_judgment/train.py`、`analysis/p3_15m_ma_launch_l2_side_split_20260901.md`；冻结合同为 TP5/SL2/72、0.2% 往返成本、完整暴露 dependency blocks、无 holdout。
