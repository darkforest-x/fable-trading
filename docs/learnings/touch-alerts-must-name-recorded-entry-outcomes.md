# 触价通知必须把评分和实际入场结果分开

- **问题**：TRUMP 触价收盘分 0.4380 达到通知门槛，但触价前分 0.4421 未达到 live-allin3 的 0.6 入场门槛，wick 的收盘分也未到 0.5。旧消息末尾的策略名加“模拟”使用户误以为已经持仓。
- **死胡同**：仅列出策略名和分数不能说明开仓；用“没有持仓行”反推满仓、收回或距离条件不合格，同样缺少证据。通知门槛和入场门槛并不是同一个数。
- **有效路径**：按完整触价身份关联保存的分数与 live 账户入场行，先显示触价提醒／已模拟开仓／live 未开。已知低于配置门槛才解释评分不足；有 taken=false 行才解释对应容量原因；其他无行情形只写无入场记录。空列表和只读门槛元数据不能绕过原通知门槛。标题与首行即使在锁屏折叠时也交代结果。
- **通用规则**：先核对发送资格、策略资格和执行记录三者；每一句“已开仓”都必须有执行记录支撑，原始评分不能替代回执。显示舍入也不能让未达门槛的分数看起来已达标。
- **牵连**：`yoyo/monitor/monday_fib.py`、`monday_reclaim_paper.py::notification_score`、TG/Bark 共用正文；原时效、去重和模拟交易规则不变。Bark 去掉正文与点击 TV 链接，保留复制币种；TG 保留原图表按钮。
