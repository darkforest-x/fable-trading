# 退出规则的结论属于特定入场集合

- **问题**：V7 的2/3根不推进或回绳早退已经失败，是否足以回答V8同一问题？两个版本共享执行器，并且V8内部仍调用名为v7_both的cohort。
- **死胡同**：凭共用函数、相同止损和成本就把V7结论升级成V8结论。V8的3ATR门改变实际持仓与后续重入路径；旧早退manifest没有绑定这道入场mask，其3531条流parity也只验证V7。
- **有效路径**：先核对实际admission mask、raw opposite feed、逐笔entry/exit与产物hash。复用执行器和四条规则，但独立注入V8的入场门并与已冻结V8基线做parity，保留原始反向信号退出。按开发前缀冻结决策后才评价复用验证。
- **通用规则**：退出研究的身份至少包括入场集合、状态机、成本和时间切分，不能仅以退出规则名字继承结论。Monte Carlo的0次超越也不得写成精确p=0或因果证实。
- **牵连**：`spike_early_failure_exit_study.py`、`spike_v8_replay.py`、2026-09-13 V7早退产物审计及V8补充验证；旧历史报告保留，新报告明确V7-only边界。
