# 成交柱结束时间不能画到下一根 K 线上

- **问题**：框架输出用 5 分钟柱结束时间记入场，原图表按开盘索引查找该时间，会把成交标记画到下一根柱。黄金休市也使“固定根数乘五分钟”不能用于跨休市的订单时间映射。
- **死胡同**：直接把所有原生成交时间当成真实逐笔时间，或统一用索引差换算时间，能产生看似精确却偏移的复盘图。
- **有效路径**：图表用 `entry_interval_start` 和 `exit_interval_start` 标注实际观察柱；原始柱结束时间保留在明细。黄金撤单与改单时间用清洗后的精确索引映射，加密仅在已验证连续的挂单片段内按索引偏移换算。首批 939 笔填单与原生成交柱结束时间逐一相等。
- **通用规则**：先区分观测区间、K 线标签时间和模拟事件时间，再画图与分期；OHLC 推演不能提供真实柱内逐笔时刻。
- **牵连**：`monday_ma6_order_timeline.py`、`monday_ma6_charts.py`、`monday_ma6_analysis.py`；本次只修复展示及统计时间锚，不重放已冻结成交。
