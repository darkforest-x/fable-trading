# 因果对照池凑不满时，正确结果是缺失估计

- **问题**：把 ATR 分桶改为只用前一月校准后，真实 10m/15m 的约十周短窗里有交易无法在“同月 × 同香港 6 小时段 × 前一月 ATR 五分位”找到 3 个唯一对照，整份审计因此中止。
- **死胡同**：退回当月全量分位会让月初交易看见月末分布；合并 ATR 桶、扩大时段或跨月补样又会在已经看过结果后改写零假设。两者都能制造完整表格，但不再是原来的因果对照。
- **有效路径**：保持冻结分层和唯一性约束不变，逐策略臂 fail-closed；仍报告策略逐笔结果，但把匹配对照、超额收益和 p 值显式记为“不可估”，连同原始不足原因落盘。其他凑得满的策略臂继续接受原有精确性检查。
- **通用规则**：因果匹配先定义可接受的对照，再问数据是否支持；数据不足时缺失的是推断资格，不是一个需要靠放宽口径补齐的数字。
- **牵连**：`scripts/analyze_pine_eth_actual_10m_vs_15m.py`、`scripts/build_pine_eth_15m_report.py`、`scripts/validate_pine_eth_15m.py`、短窗口 matched-control 结论；不改变策略、障碍、成本或 15m 冻结决策。
