# 信息过多时先减少默认展示，再调整字号

- **问题**：视觉识别工作台把来源地址、技术编号、资格状态和操作提示都摆在主界面，正文与控件出现大量 8–11px 小字。Owner 明确反馈字号太小、整体不够简洁。
- **死胡同**：初版通过缩小字体塞进三栏；浅色配色虽然提高了明暗区分，却没有解决阅读负担。继续加卡片、缩小字号或只换颜色都不能修复层级。
- **有效路径**：保留选图、发起识别、查看结果的主要路径，操作按钮靠近图表；参考图、规则和请求详情按需展开，资格放到设置页。正文与控件用 16px，常规辅助信息用 14px，同时减少阴影和重复说明。
- **通用规则**：空间不够时先判断信息何时需要出现，再确定字号与布局；不能用小字代替信息取舍。验收同时检查空态、真实结果、桌面和窄屏。
- **牵连**：`yoyo/vision_research/static/index.html`、`app.js`、`styles.css`；仅调整展示，不改变识别输入、后端接口或研究资格。
