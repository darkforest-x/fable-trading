# Pine 的窄影线圈要使用固定屏幕尺寸的空心字形

- **问题**：Owner 要求在 1.618 插针处画与截图一致的窄绿色椭圆；圈必须贴近单根影线，不能随横向缩放变成宽扁形。
- **死胡同**：四个整根 K 线时间锚点的曲线能闭合，但宽度跨两根 K 线，浅触价时明显扁平。把时间半径缩至 0.35 根后，TradingView 把中间时间吸附到图表列，原生截图出现偏向一侧的半圈。不能只凭价格坐标公式判断视觉效果。
- **有效路径**：原生验证空心竖椭圆字形 `⬯`，使用透明 label 背景、固定字号和截图取样色 `#00B43B`，中心落在关键位与影线极值之间；保留大小和显示开关。影线触价按收盘 OHLC 判断，实体贴线排除，不依赖原来的入场或勾叉模块。label 容量从已有模块预算中扣除，先删旧对象再创建，并随可见历史重新计算。
- **通用规则**：贴近单根 K 线的装饰标记先确认需要屏幕尺寸还是价格/时间尺寸；测试浅触、深穿、缩放及开关，不用分数时间坐标假装像素坐标。
