# 审核完成要以可评分且持久保存的答案为证据

- **问题**：盲审页面导入时 JS Date.parse 接受无时区或不存在的日期，但 Python 评分器
  拒绝；另外内置浏览器 Blob 导出提示成功，实际下载事件及落盘文件均未确认。
- **死胡同**：只凭按钮提示和已完成计数验收，或把 Date.parse 能解析等同于合法 ISO 日期。
  前者可能丢失数百项人工劳动，后者让整份“已完成”答案无法评分。
- **有效路径**：前后端统一带时区合法日历校验；只有显式保存且字段完整才计完成，修改答案
  撤销完成状态；另提供同源本机追加快照与恢复，以文件及回读内容验证保存，QA 使用独立目录。
- **通用规则**：人工标注工具同时验收字段可评分、状态正确、落盘可恢复三个环节。
  下载提示只证明前端触发意图，不证明持久保存；测试答案必须物理隔离于 Owner 答案。
- **牵连**：`yoyo/datasets/grade_a_calibration.py`、
  `yoyo/datasets/templates/grade_a_calibration.html`、`tests/test_grade_a_calibration.py`。
