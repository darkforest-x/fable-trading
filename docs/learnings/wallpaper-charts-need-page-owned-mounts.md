# 壁纸图表需要页面自己的挂载层

- **问题**：区间／信号切换虽然没有遮罩，仍像弹窗，占用了顶部空间。
- **死胡同**：把同一个 `dialog` 从 `showModal()` 改成 `show()`，再用 CSS 铺宽，并没有改变它的容器、关闭按钮、标题栏和布局尺寸；“没有模态遮罩”不等于“页面壁纸”。
- **有效路径**：保留同一个图表子树和事件监听，将其移入主页 `inset:0` 的壁纸层，控件独立悬浮。切回或离开页面时停止图表订阅、卸载，再将子树归还普通抽屉。设置、统计的样式以两个明确宿主共享，币种由主页持有。
- **通用规则**：先检查宿主与生命周期，再调整视觉。验收必须检查零打开的 dialog、画布边界等于视口、当前币种保持、往返切换及原抽屉不回归。切换数据上下文时立即清空旧统计，不能等网络回来。
