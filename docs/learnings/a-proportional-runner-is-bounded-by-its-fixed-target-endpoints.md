# 比例 runner 的平均收益受两个固定目标端点约束

- **问题**：3R 后保留部分仓位追 8R 看似可以同时得到稳定止盈和长尾，容易被当成独立的新 edge。
- **死胡同**：在已知 3R、8R 两个固定目标结果后继续细扫大量分批比例，期待中间点超过两端；若费用按仓位权重、路径与状态机不变，中间收益并没有新的非线性来源。
- **有效路径**：先写出逐笔恒等式 `runner(f)=(1-f)*exit3R+f*exit8R`，再用 0%/100% 端点逐笔 parity 和少量预注册比例验证。15m 两端 -13.51/-21.14bp，所有中间比例单调恶化；5m 两端 -17.32/-15.86bp，中间比例单调改善但无法越过 -15.86bp 上限。
- **通用规则**：固定两端、比例成交、一次加权成本下，runner 能改变分布却不能让平均收益超过较好端点。只有引入新的非线性决策（例如因果地选择哪些交易保留 runner）才可能改变上界，而那是新的信号/过滤实验，不是继续调比例。
- **牵连**：3R 首次止盈、8R runner、`runner_fraction`、加权成本、1.5R 保护；2023–2024 development 两周期均未过门，audit 与 holdout 未开。
