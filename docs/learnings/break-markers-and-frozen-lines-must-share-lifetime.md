# 突破标记与冻结趋势线必须共用生命周期

- **问题**：历史突破箭头仍在，只有最新突破线被重画；用户看到箭头却找不到被突破的线。
- **死胡同**：保留“最近突破线”只能解释最后一次信号，增加箭头或候选线数量不能修复历史对应关系。
- **有效路径**：将信号文字、当时冻结 A/B 线和可选锚点组成一个历史对象，创建与淘汰都整组执行，并预留平台对象容量。
- **通用规则**：图上可见的事件必须有同生命周期的依据；图形回收策略是证据链的一部分。
- **牵连**：SPIKE V12 的 standalone break、joint、上级来源与风险参考图形对象预算。V11.2 文件保留。
