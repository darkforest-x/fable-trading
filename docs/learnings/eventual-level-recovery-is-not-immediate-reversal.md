# 最终回归线位不能证明触价当时已经反转

- **问题**：9月16日大量下沿1.618事件三天后上涨，容易被表述成插针反转的高胜率。
- **死胡同**：只看期末回归或最大有利变化，会抹掉先跌破原插针低点的路径；同日数百币共振也不是数百次独立市场实验。
- **有效路径**：从触价柱收盘分开观察5分钟至72小时、整段不利极值、再次线外收盘和近侧周一边界的首次到达时间；匹配同币同日同滞后波动随机时点。下沿72小时96.39%上涨，但4小时仅37.35%，配对72小时均值还低于随机。
- **通用规则**：复盘先定义观察起点和每个时间尺度；价格正向比例、执行后胜率和账户收益三者不能替换。没有实际执行框架结果时，不把静态OHLC路径称作止损或盈利交易。
