# 突破位回踩不等于整理结构破坏

- **问题**：将旧确认接到“实体站上六线”的后续结构确认时，候选在一次普通回踩后被取消，真实正例仍然丢失。
- **死胡同**：用突破时的整理区上沿同时充当最终确认门槛和等待失效边界。这会要求等待期间每根收盘都守在突破位之上，与“允许信号后完成结构”矛盾。
- **有效路径**：分别冻结来源整理区的高低点。回到上沿以下允许继续等待；严格跌破下沿才判结构失效。最终确认仍须收回上沿上方，并完成实体和动能条件，不把后来信息回填到原信号。
- **通用规则**：确认门槛、回踩容忍与失效边界必须分开定义。若允许回踩，就不能把突破门槛原样复制为逐根失效线。用真实逐根来源链验证，并保留失败配置，而不是只用理想单边上行的合成数据。
- **牵连**：V5 增加原父事件的前 12 根低点簿记；旧 V4 入场质量、冷却、风险框与止损参数不变。此边界修复是软件语义回归，不证明收益改善。
