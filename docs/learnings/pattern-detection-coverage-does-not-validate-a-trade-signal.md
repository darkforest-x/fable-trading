# 形态检出覆盖不能代替交易信号有效性

- **问题**：ETH最近两个月原V9有162笔开仓，现有YOLO同级仅检出6笔、小级别10笔；1H→15m仅保留亏损单，却漏过净+18.16R的赢家。
- **死胡同**：把“V9信号都是该形态的真阳性”作为未验证前提，再把YOLO不检出叫漏检、把模型置信度当获胜概率。或者只看3m小级别命中原交易2赢1亏的66.7%，忽略这组本身净亏与单仓回放改变交易集合。
- **有效路径**：模型只看同一开仓可用时点的因果图，原交易分组与完整过滤回放分别汇报；同时保留命中数、成本后R、未命中赢家和匹配随机对照。1H门过滤后+16.19R变−0.76R，但只有3笔，不能由此反向选未命中策略。
- **通用规则**：先区分模型形态真值、策略开仓条件与最终盈利标签；没有独立人工Gold时只能称检出覆盖，不能称形态召回率或策略准确率。
