# 组合搜索框应由外层统一显示焦点

- **问题**：周一页面的搜索框点击后出现嵌套直角蓝框，圆角玻璃外壳也同时发光。
- **死胡同**：输入框基础样式已写 `outline:0`，但路由通用 `:is(button,a,input,.cv-canvas):focus-visible` 的选择器优先级更高，仍然覆盖重置。只调整圆角或边距无法消除双重焦点。
- **有效路径**：先在真实浏览器读取聚焦态 computed style，确认内框 outline 为 2px；由外层 `:focus-within` 提供统一圆角焦点，针对内层的 focus/focus-visible 重置轮廓，同时保留其他按钮和图表的键盘焦点。滚动列表也独立设置可见键盘焦点。
- **通用规则**：图标和输入框组成的复合控件只设一个视觉焦点宿主；排查基础态、聚焦态选择器优先级，而不是全局取消 outline。滚动区域独立于搜索区，数据重排按首个可见条目的位置恢复视口。
- **牵连**：`yoyo/monitor/static/monday-fib.css`、`monday-fib.js`；连续列表取消五行分页，轮询保持浏览位置，搜索和方向筛选重置到顶部。
