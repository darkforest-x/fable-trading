# 过滤后的盈利不能只与未过滤账户的盈利比较

- **问题**：1H趋势收益集中在少数资产，加入量能过滤后即使曲线改善，也可能只是交易次数减少或放出了仓位，未证明启动质量提高。
- **死胡同**：把全部随机入场与少量过滤信号比较，候选规模不同；从旧账户利润里减掉一笔大赢家，也没有模拟被释放的资金能参加哪些后续交易。
- **有效路径**：固定入场和退出，只分别加一个过滤条件；将通过过滤的原event_id联结同批随机控制，同时按同币同周保留相同数量原箭头随机稀释。剔除整个争议资产后从初始资金重跑配资，与静态贡献明确分开。
- **通用规则**：先区分信号质量、交易频率和仓位替代三个问题。控制0的账户覆盖率也要与任意控制可用率分列，不能被统计函数同名字段覆盖。
