# 先确认入场门剩下多少机会，再决定是否评价收益

- **问题**：已有稀疏的小时穿均线母信号，想通过此前20小时高低点突破筛掉盘整；继续直接按收益调窗口，容易把少数偶然赢家当成策略。
- **死胡同**：V1 曾在已选小时斜率过滤之后叠加 breakout20，仅剩16笔，样本门失败。不能把条件不同的旧失败忽略，也不能反复改变窗口直到回测好看。
- **有效路径**：V14 在原251病例、462自身控制、154固定三元对照上只加固定20小时严格突破，先冻结713条事前门和14973条自身完整小时来源，再数支持。病例只剩60，2024H1仅11，低于预设80/每半年12；因此在任何新收益计算之前停止这一项，不把未计算收益写成0，也不降低样本门。全部60与原母表事前 breakout20 标记一致。
- **通用规则**：给稀疏母信号增加过滤时，先固定母体、门定义、未知处理和最小支持；先做不接触收益表的支持检查。信号稀少本身不证明策略差，也不证明它精确；样本不足时应明确无法按既定标准检验，不能用收益排名反过来拯救参数。
- **牵连**：`yoyo/evaluation/hourly_impulse_prior_breakout_research.py`；V14 `PROJECT_PLAN.md`、固定20小时及80/12支持门。原匹配覆盖154/251仍不足90%，支持门通过也不等于盈利或上线验收。
