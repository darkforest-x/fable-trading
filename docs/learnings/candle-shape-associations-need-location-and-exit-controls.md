# K线形态关联必须同时检验位置、出场方式与风险尺度

- **问题**：历史关键位交易的胜率低，长影线或周边形态能否区分好坏信号？触价K与勾叉K并不总是同一根，费用相对初始风险也相差很大。
- **死胡同**：单看漂亮长影线、盈利样本或一个出场规则，容易把审美和窄止损放大的R误当预测力。本轮长影线组反而更差；BTC此前压缩组胜率较高，但只有9笔且ETH方向相反。
- **有效路径**：先冻结18个形态比较，逐笔提取触价前窗口、前一根ATR及入场时已知数据，再连接既有18套出场账本。分别检查净胜率、按价格计的净收益、初始风险、匹配随机、时间与方向，并按周重采样及多重比较校正。扫过前20根极值的关联比影线长度稳定，但BTC该组18套出场净R仍全负；36项校正后没有显著项。
- **通用规则**：把形态、所在位置和执行时点拆开；先问差异能否跨时间和出场存在，再问它是否足以扣费盈利。自然先触价后出勾叉的一组表现较好，不等于主动延迟所有信号会改善结果；不同样本与延迟干预不能混为一谈。
