# 拒单不能留下影子仓位，退出变化必须重新串行入场

- **问题**：V8首次倍投研究先生成串行交易机会，再套有限资金。新研究改变退出时机，并允许容量不足后重启，原串行交易表不再是完整的可交易信号集。
- **死胡同**：只对旧成交表换仓位，等于让没有实际开出的旧仓继续屏蔽后面的信号；把开发期仅两笔成交的方案称为最优，又会把资金停摆误当风控。
- **有效路径**：逐V8原始准入信号独立生成条件退出路径，账户按时间只接受实际可开的仓位；拒单不更新占仓时段，也不读取其未来盈亏。先以无限资金固定风险重现原串行基线，再加入资金容量与新退出。选择门同时限制真实连亏、样本数和活跃月份。
- **通用规则**：入场拒绝、退出时机、同bar方向互斥任一改变，都必须重放准入状态，不能只重加权旧成交列表。现金风险上限、轮次重置和市场连亏分别记账。
