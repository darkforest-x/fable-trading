# Hiding Pine table content does not remove its allocated footprint

- **问题**：四周期小图关掉后，26行合并表格仍在右上角留下大块空白；用户要求的开关没有完整释放图表空间。
- **死胡同**：只跳过绘图单元格，或者反复清空整表，不能同时保证紧凑布局和已合并标题的正确显示。
- **有效路径**：开关作为输入触发重算时，按显示模式创建18×26或1×2表格；只在小图模式合并单元格。独立信息开关控制剩下两行；两者关闭时背景透明。TV实测关闭后只保留紧凑日界信息，重新开启恢复四图。
- **通用规则**：隐藏内容与隐藏布局空间是两件事。验证开关必须检查关闭后的空间占用，再检查重新开启。
