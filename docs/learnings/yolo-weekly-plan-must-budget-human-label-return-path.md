# YOLO 排期先验证人工答案能回到训练，而不是用预框数量估计就绪程度

- **问题**：Owner 要求本周交付优化版；界面已有 2,513 个预框，但只有 20 份新人工答案，审核图还有超出短延迟协议的上下文。
- **死胡同**：把自动审计的 0 error、历史图片数量和预框任务数当作训练数据就绪；直接复用会回退 predictions 的旧导出器，人工删框会重新变成正例，直接训练审核主图还会改变未来可见范围。
- **有效路径**：先核验 live annotations，拿少量真实答案验证 human-only 导出、源坐标回算和合法窗口重建；再预算去重事件、背景与锁定验收，机器训练排在这条依赖链之后。对照两臂共用新的合法渲染，结论只归因于其中的标签差异。
- **通用规则**：有期限的模型迭代，先证明一份人工答案能完整、忠实且合法地进入训练；把预框、原始金标、派生框确认、训练资格分别计数。截止时间不能替代质量证据，未经测量的候选不能预先称为准确率提升。
