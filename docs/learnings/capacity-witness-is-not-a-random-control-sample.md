# 最大配对容量见证不是随机对照样本

- **问题**：旧六键配对只能覆盖 154/251 个 K1，需判断新的整体入口背景合同是否有足够对照。
- **死胡同**：换种子不能超过已经证明的旧容量上限；删去颜色/斜率配对键后把覆盖上升称为旧实验修复，同样改变了问题。MILP 最大组数的一个解也不是均匀随机样本。
- **有效路径**：另注册三键背景支持合同，先冻结所有资格边，再求精确容量；未知供给不填零，保留全部母。只将分配视为容量见证，经济标签前另冻结抽样方式。
- **通用规则**：先区分估计目标、可行容量和抽样分布，再讨论收益。计算器重新调用相同资格函数是内部一致性检查，不是独立算法验证。
- **牵连**：`yoyo/evaluation/hourly_impulse_background_support.py`、`hourly_impulse_matching_capacity.py`；V23 只读旧保存的事前特征，不读取新的未来标签，不追认 V10/V19 的匹配门。
