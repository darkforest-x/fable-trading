# 过滤器改善均值后必须重算去极值贡献

- **问题**：方向广度 5 日扩张门在独立币种集把基线 −140.16bp/笔改善到 +277.27bp/笔，并且剔除的 5 笔全部亏损；表面看像已经修复策略。
- **死胡同**：只看过滤前后均值、PF 或正时期占比，会把“准确删掉几笔坏单”和“保留下来的交易本身稳定有优势”混为一谈。17 笔候选中单笔 YGG 贡献了净收益总和的 113.9%，删去它后其余交易均值回到 −40.95bp。
- **有效路径**：同时报告被删除交易的独占增量、top-1/top-k 收益贡献、leave-one-winner-out 均值、按币/时期的正收益覆盖率和匹配随机聚类检验。由此可把广度扩张定位成有价值的第一层环境门，而不是已经完成的最终选股器。
- **通用规则**：任何稀疏趋势策略从负转正时，先问“删掉最大赢家后是否仍为正”；若答案是否定，下一步应增加独立样本覆盖并研究 runner 可达性，不能继续微调同一阈值或宣布通过。
