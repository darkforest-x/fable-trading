# 预热根数不等于特征已有效

## 问题
XAUUSD 固定规则适配器只检查 340 根预热，完全平价的合成报价在 ATR 为零时仍能进入近零蓄势状态；原 Pine 还要求密集带宽和信号线可用。

## 死胡同
普通随机价格上的前缀不变测试能够通过，却无法发现零分母边界与原指标语义不同。

## 有效路径
加入全平价独立反例，统一 ready 为根数足够且前窗带宽、信号线有效；近零状态更新也必须检查同一 ready。修正发生在任何长期市场收益计算之前。

## 通用规则
因果性、预热长度和数值有效性是三个独立条件。复用指标时必须同时验证，并用退化输入检验共同门是否遗漏。

## 牵连
只修正新研究适配器及合成测试，不改云端 Pine 或生产交易规则。
