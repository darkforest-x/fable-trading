# R 参考线和价格标签需要分别核算图元预算

- **问题**：V1/V6/V7 需入场就显示 1R/2R/3R，既有默认 60 组历史已占最多 180 条里程碑线、480 个标签。
- **死胡同**：给所有历史再加三个价格标签会超过 500；把所有参考线都限制为实时又让旧图缺失关键位置。达成里程碑的 slot0 是3R，但预设价位数组的 slot0 是1R，直接复用索引会删错。
- **有效路径**：每组保存三条预设线并同步历史回收，声明400条line额度覆盖最多360条；额外三个点位标签只给活动段，结束后回收。达成3R明确替换预设slot2，原1R/2R保留。预设3R文字显示时隐藏重复观察位文字。
- **通用规则**：按类型分别核对历史和活动图元的峰值；两个不同语义数组不要直接共用索引。静态契约只能验证源码结构，不能替代TradingView原生编译。
- **牵连**：三份Pine显示源码、显示契约测试；信号/止损状态机不变。当前另一设备占用TV会话，原生保存尚未完成。
