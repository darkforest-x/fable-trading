# 第二个信号门必须单独定义事件关联和可用时钟

- **问题**：Owner希望IMACD启动后等待YOLO均线密集确认；旧权重别名、模型核心位置、确认时间都可能被混为“同一信号”。
- **死胡同**：拿`owner_best`名字直接当最优模型，会加载更早临时权重；要求YOLO框住箭头那一根，会漏掉核心早于箭头的形态；把后续确认回填到原箭头价，会消除等待代价。仅以放行数下降判断去噪成功，则没有验证被挡掉的是否真是假信号。
- **有效路径**：依据当前研究契约和实际SHA选择Grade-A1280；预先固定核心与本次蓄势区的真实K线交集，以及独立的等待/失效规则。保存原箭头收盘、模型完整窗口收盘和各自下一根开盘价格。49个箭头中12个确认，7个当根已有确认，其余晚1/2/4根；因此“双确认”不必意味着人为多等固定根数。
- **通用规则**：串联检测器前，先分开回答“是不是关联同一事件”“每个判断何时真正可见”“在哪个价格才能使用”。通过率、模型置信度和条件化方向p值都不是盈利概率；行情成功和漏掉的大趋势需要另一个事先冻结的经济评价合同。
