# 出分时间应指向刚结束的 K 线

- **问题**：历史回测的成交区间、分数可知时间和加仓时间并不相同，图上的入场标记不能代替出分标记。
- **死胡同**：把收盘时间直接当作蜡烛开盘时间会指向下一根；把加仓成交时间当作出分时间会把继承的旧评分画晚。只避让锚点那一根蜡烛，也会让长标签压住邻近 K 线。
- **有效路径**：2026-10-31 的回测图读取保存的评分与原生成交证据。5m 首触评分使用原始收盘时间；加仓按 parent 找到两条原生路径一致的母单评分时间，缺证据则不猜。1m 图查找 `close_ms - 1` 所属蜡烛，并要求该蜡烛恰好在评分时间结束。文字按完整宽度避让所有 OHLC 包络，每次拖动、缩放和尺寸变化重新布局。
- **通用规则**：事件时间、行情开盘时间和成交时间应分别保存；图上锚定语义必须明确到“哪根结束时已知”。不从现有图形或邻近交易推测缺失的来源时间。
- **证据与牵连**：allin3 / LUNA2USDT / 286 的保存分数为 0.8345036568541999，出分时间为北京时间 2026-06-27 01:55，标记属于 01:54–01:55 蜡烛。`strategy_backtest_evidence.py` 提供时间证据，`reclaim-chart.js` 仅在 1m 绘制。相关 Python 20 项、前端 25 项检查通过；真实页面验证 320/390 手机宽度、深浅色、1m/5m 切换及平移缩放，未改评分或成交计算。
