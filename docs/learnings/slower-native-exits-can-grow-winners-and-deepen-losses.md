# 更慢的原生退出可以同时放大盈利与亏损，不能只看吃到的趋势

- **问题**：小时穿线后用更慢的小周期退出，是否能解决盈利被过早截断？
- **死胡同**：只看赢家扩大、胜率或PF改善会误判。V15固定原251机会，
  原生5m→15m使赢家均值96.41→130.17bp、PF0.625→0.666；但亏家
  均值−50.63→−66.91bp、硬止损14→63，最终净均值−14.31→−16.66bp。
  19笔亏转盈并不能抵消17笔盈转亏和170笔持续亏损的整体加深。
- **有效路径**：先冻结两个原生周期各自入场状态，再保持入场、风险、
  固定对照和完整分母；比较全部配对差值及单仓占用。15m亏损187笔中
  53笔持仓内MFE≥1R、134笔未到1R。将利润回吐与未充分启动分开诊断，
  但不把事后MFE用作事前选单；后续兑现利润规则必须重新逐路径回放。
- **通用规则**：改变管理周期时同时审赢家、亏家、硬止损、盈亏转换、
  尾部和对照改变量。native15 SMA40还改变聚合、初始化及均线记忆，
  不等于单纯降低检查频率；不要把参数名变化当实现变化。
- **牵连**：V15 builder2acc280；`yoyo/evaluation/hourly_impulse_native_exit_research.py`；
  `analysis/p1_btcusdtp_hourly_native_exit_v15_20260906.md`。
  数据仅重复使用2023–2024；原154/251匹配支持不足90%，不能宣称盈利确认。
