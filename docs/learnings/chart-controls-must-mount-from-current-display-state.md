# 图表重挂载时控件也必须使用当前显示状态

- **问题**：市场图表的 MA、成交量和价位显示开关保存在模块里，但重新进入页面时模板写死前两项开、后一项关；MA 依赖异步图表读取后才纠正，价位按钮没有同样的恢复。
- **死胡同**：只检查图表系列的 visible 设置会漏掉按钮和图例；控件存在、图表也正常，不代表二者状态一致。
- **有效路径**：创建模板时就从原 showMA / showVolume / showLevels 生成 aria-pressed 与图例 hidden 状态；维持原图表与数据逻辑，避免加载期间的错误反馈。
- **通用规则**：保留局部显示状态时，重挂载的控件、图例和画布必须从同一状态初始化，不能等网络返回才补齐。
- **牵连**：`market-terminal.js` 的创建模板；不改变均线计算、价位来源或默认六均线设置。
