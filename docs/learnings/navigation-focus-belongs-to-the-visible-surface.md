# 导航焦点必须属于当前可见界面

- **问题**：手机抽屉打开时焦点仍在背景，背景可滚动；全局 `/` 在实验页跳去信号中心，在书架页则试图聚焦隐藏搜索框。
- **死胡同**：仅加遮罩和 `aria-expanded` 不能隔离键盘；按页面名称维护搜索分支会漏掉新增页面。实页还发现点击当前菜单项后不切路由，焦点会遗留在已关闭抽屉内。
- **有效路径**：抽屉单独保存和恢复背景 inert 状态、限制 Tab、关闭时恢复入口焦点；菜单选页把焦点交给 main，包括同页选择。搜索只寻找当前可见视图中的可用搜索框，并避开编辑、输入法和弹窗。
- **通用规则**：先确定当前可交互的界面，再决定键盘操作的目标；隐藏不等于不可聚焦，遮罩不等于模态。
- **牵连**：`yoyo/monitor/static/workspace-display.js`、`app.js`；保持桌面折叠偏好和全屏生命周期独立。证据在 `output/playwright/frontend-polish-20261015/`。
