# 检测框一致不等于每张框强制同一像素高

- **问题**：均线密集框有的很窄、有的较高，担心不同尺寸会让 YOLO 学不准；旧框又因 K 线极值而高度漂移。
- **死胡同**：把所有框硬改成同一个归一化宽高，表面直方图整齐，但会在均线发散样本上切掉目标，在真正密集样本上塞入大量背景；只规定源图像素也忽略了 `imgsz` 和 scale 增强后模型实际看到的尺寸。
- **有效路径**：先冻结输入 W 和横向核心长度，使横向尺度稳定；纵向始终包住目标语义本身，再在 loader 的基准输入尺度定义最小像素高，同时报告最坏 scale 增强后的尺寸。这样只托住极薄小目标，不抹掉真实均线带宽差异。
- **通用规则**：检测框的“一致”应检查同一语义来源、同一 padding 规则和同一模型像素下限；只有目标本体尺寸本来固定时才要求所有框像素相等。任何最小尺寸都要同时写明 source px、baseline imgsz px 和最坏增强后 px。
- **牵连**：`yoyo/datasets/ma_launch_ma_box_review.py`、固定 W20、L4/L5/L6/L7、min16/24/32、`imgsz=960`、`scale=0.1`；另见 [候选语义不定义框几何](candidate-selection-semantics-do-not-define-box-geometry.md)。
