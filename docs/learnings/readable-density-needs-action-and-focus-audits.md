# 信息密度要用可操作的首屏衡量

- **问题**：同一套深色 token 已应用，实际页面仍有多层工具栏、重复标题、小字号、窄屏按钮被裁切；列表有数百个 Tab 停靠点，导航搜索框还会让 Shift+Tab 提前回绕。
- **死胡同**：只看整页横向溢出为零和静态截图，发现不了 `overflow:hidden` 内被裁掉的按钮。把每段内容都分成一个栏，也可能同时挤压主要任务。看到缺少卡片动作就补入口也不对：历史约定明确取消信号卡片 TradingView 跳转，应该修正残留提示。
- **有效路径**：先走真实流程，再分别测图表起点、卡片列数、工具栏子节点边界和键盘焦点。将筛选放到卡片上方、合并看图工具、允许收起币种栏、把低频命令收进设置；收起筛选仍显示条件，清空搜索不关闭抽屉。Tab 只进入一次全市场列表，方向键浏览，轮询保留正在浏览的焦点。
- **通用规则**：密度优化应减少重复层级，而不是缩小字体。验收至少同时检查主任务可见面积、控件裁切、键盘进入与离开、筛选回退和最窄屏。先查行为约定，别把已取消功能当成漏做。
- **牵连**：`market-terminal.*`、`workspace-terminal.css`、`workspace-display.js`、`workspace-panels.js`、`signal-workspace.js`、`chart-style.js`、`yolo-detect.js`。仅展示与交互；六均线原始值及交易规则不变。
