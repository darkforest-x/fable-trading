# 比较加仓次数时，结构时钟必须独立于成交次数

- **问题**：取消两次上限以后，如何判断第三次以后的仓位是否改善结果，而不是混入止损和选样变化。
- **死胡同**：各版本加仓后才重置突破高点，会使不加仓版、受资金限制版和连续加仓版看到不同的后续结构；收益差无法归因于次数。只挑截图中的大赢家还会预先排除失败路径。
- **有效路径**：结构事件无论成交与否都统一重置；三版本共用初次入场、结构止损、原始退出和成本。逐笔断言退出相同、前两次成交相同；只允许新增次数改变数量。原信号之外配同币同月同波动桶的随机入场，保留失配和截尾。
- **通用规则**：先冻结不依赖处理分组的市场时钟，再改变待比较的仓位变量。全仓止损净利润必须用加仓后的数量、成本与费用重算；准备加仓时不能先承诺尚未扣除新增风险的止损利润。
