# 过程标签不能自动变成入场硬门槛

- **问题**：截图里失败信号似乎有旧证据、确认时不推进，而成功反转有放量突破失败的前序过程。
- **死胡同**：直接把形态名字等同于收益优势，或只看过滤后胜率和总亏损下降。删除交易自然能减少总损失，也可能删除更重要的尾部赢家。
- **有效路径**：先固定同一批V8入场、成本和退出，用确认前信息独立打标，再看每笔净R、PF、相同入场的已实现10R保留率、月份/方向及近时对照。退出规则则另跑动态状态机。
- **本轮证据**：`exp-spike-v8-entry-process-20260913-v1/results/full_v1` 中，最近一年“最大推进不超过0.25ATR且滞后至少2根”过滤后平均净R仅从-0.08383到-0.08348，却删49/319笔已实现10R；改用确认收盘净推进反而使平均净R降到-0.08668。失败突破反转标签平均-0.06604R，但仍为负，且多空/周期效果不一。
- **通用规则**：形态可作可解释的结构标签；成为硬门槛必须同时证实收益质量和尾部保留。不得把若干好看的反转案例升级为“所有趋势都必须先失败一次”，也不得把时间上的证据年龄当作已经证明的证据失效。
- **边界**：两年复用非盲历史，30m/1H/4H，固定阈值的描述性同入场检验；未证明5m有效或无效，不改线上。
