# 视觉模型能解释图表，不等于已通过自定义形态识别验收

- **问题**：2026-09-23，Owner 询问 YOLO 训练不理想时能否直接用视觉大模型识别 K 线。本文记录选型与验证原则，未运行模型比较或交易实验。
- **死胡同**：不能把“看图生成完整研报”的演示当作形态检测证据。本轮读到的知乎文章没有独立金标测试集、误报漏报、边界误差或重复一致性；换模型也不会自动修复标签语义、未来可见性及事件重复问题。此前检索搜索摘要未找到确切型号，并不证明型号不存在；本轮通过官方模型概览及定价页找到了 GLM-5V-Turbo 原始文档。
- **有效路径**：先核实确切视觉 API 与计费单位，再在相同真实图片、参考样例和提示词下仅替换模型。允许不确定输出，要求可核验的核心首末 bar；比较误报漏报、拒判率、边界误差、重复一致性、延迟与实际 token 费用。参考样例与盲测集按事件及时间隔离，输入停在决策时点，待判图不带审核圈框或未来新闻；加入标签打乱对照。若只复核候选池，还要抽查池外图来测候选生成的漏检。
- **通用规则**：免自训不等于免金标验收。解释流畅度和模型自报置信度不能代替人工金标、准确率或交易胜率；模型候选标注不自动升级为 Owner 金标。识别通过之后，再用原成本和匹配随机对照检验交易价值。
- **牵连**：本轮没有改检测器、训练资格、生产资格或账户，也没有调用付费模型。价格、账号可用性和模型别名会变化，正式评估需保存请求参数、模型身份、图片哈希、响应及账单用量。
