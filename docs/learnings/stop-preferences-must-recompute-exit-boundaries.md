# 止损参数变化需要重新判断退出边界

- **问题**：信号中心支持用户调整止损比例，卡片、历史参考框和最高 R 必须使用同一个参数，但原始信号身份与异步历史缓存仍需保持稳定。
- **死胡同**：仅按风险距离缩放旧最高 R，会继续沿用旧止损时点；原本已经退出的单，在较宽止损下可能仍持有。直接改缓存里的信号也会把个人偏好混入公共来源数据。这两条路径均未采用。
- **有效路径**：保留原始信号和行情缓存，在绘制时统一投影止损与计划 R，再以新止损重新调用已有的已收盘 12H 浮盈区间计算。异步结果返回后仍读取当前偏好；切换信号时先清空上一笔的浮盈展示。
- **通用规则**：能改变终止条件的参数不能只改显示值。先明确哪些是不可变事实、哪些是用户配置、哪些结果必须重新求值，再复用原始输入。
- **牵连**：`cloud-stop-settings.js`、`cloud-signal-chart.js`、`cloud-signals.js`；回归覆盖默认已止损→放宽后仍持有、延迟历史与周期切换、参数变化不增加行情请求。这是参考展示计算，不是成交回测。
