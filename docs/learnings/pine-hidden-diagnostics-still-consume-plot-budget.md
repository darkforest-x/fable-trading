# Pine 隐藏诊断仍占用绘图预算

- **问题**：V12.8 增加 V13 回踩层后语法编译通过，但 TradingView 实际运行报 RE10140：74 个绘图输出超过 64 上限。
- **死胡同**：把旧输出设为隐藏或让条件始终为 false，并不能释放编译期输出额度；只数 `plot()` 行也会漏掉提醒和动态颜色等计数。
- **有效路径**：原生运行给出真实计数。保留原算法、历史趋势区域、可见图形和提醒，仅从新版本去掉十项旧数据窗口诊断输出，为新增七个序列与三个提醒腾出额度。原 V12.8 文件保持不变。
- **通用规则**：大型 Pine 脚本新增功能前先核输出预算，语法通过后仍须在原生图表运行。隐藏不是删除，绘图函数数也不是绘图计数。
- **牵连**：`yoyo/evaluation/spike_v130_delivery.py`；[TradingView 官方额度说明](https://www.tradingview.com/pine-script-docs/writing/limitations/#plot-limits)。首次失败截图和源版本均保留在 V13 交付实验与 git 中。
