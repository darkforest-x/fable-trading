# 提前退出提高胜率时，先核对它截掉了哪些大赢家

- **问题**：同一V8入场配合反向Stoch信号，5分钟共同窗口净胜率从33.3%升至42.4%，总净收益却从+11.89R降至−20.14R。
- **死胡同**：只数“浮盈变止损被救回几笔”或最长连亏，会遗漏为救这些交易而放弃的大盈利。新旧退出还改变后续入场准入，串行总R相减无法单独归因于退出。
- **有效路径**：同时做原始入场逐笔配对和各自串行回放。配对救回7筆原净亏，却把8笔原毛收益≥3R截成不足3R；其中一笔净9.11R变0.06R，解释了胜率与收益的分离。
- **通用规则**：出口优化先报告同入场收益差的完整分布、救回亏损单与截短大赢家，再报告串行净收益及有限本金账户。胜率、连亏、总净R是不同目标，不以单一指标替代全部结果。
- **牵连**：`analysis/p1_spike_fanshen_exit_multitf_20260914.md`、`yoyo/evaluation/spike_fanshen_study.py`；成本固定0.2%，共同窗口2026年1—4月，未消耗holdout。历史比较没有证明样本外优势。
