# 启动筛选失去蓄势资格后，强度单门不能替代结构

- **问题**：Owner纠正只应比较原版SPIKE强劲爆发V1和最新V3，并追问为什么信号剧增。原版先有近零蓄势和密集区，V3预警仅前12高点突破加两条快线，确认也未恢复完整蓄势结构；默认预警还带盈亏框。
- **死胡同**：把中间版本的去重当成最新版本降噪；或只盯80%广覆盖，忽略候选资格已从蓄势释放变成普通突破。恢复单根强度会少发，但不保证筛到更好的趋势。
- **有效路径**：明确原版基准，直接逐项列代码差异；冻结V3事件与控制，分别加回13个原版组成门，独立报告数量/覆盖/峰值捕获/净收益。确认加TR≥3提示少80.3%，净胜率29.50%→35.35%，却仅保留26.9%的原10R峰值事件，且随机超额仍负。近期密集恢复到预警少32.3%，质量也未提高。不能据此选择历史最好单项上线。
- **通用规则**：模式识别的“结构资格”与单根K线的“力度”要分开；候选展示与交易参考也要分开。边筛既有事件不等于完整重放：冷却、父子确认和后续替代信号不再生，必须如实说明。Owner指定原始比较基准时，中间版本不应抢占对照。
