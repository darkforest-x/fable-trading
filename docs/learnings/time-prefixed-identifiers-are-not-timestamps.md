# 日期开头的信号编号仍是编号，不是时间戳

- **问题**：V27独立审计把`2023-01-01T01:00:00+00:00_L`误作完整ISO时间，首轮真实审计中断。
- **死胡同**：用字符串前缀正则推断列类型，简单合成ID能通过；一到真实日期后缀ID就走错解析分支。增加重试或放宽日期解析都不会修复语义。
- **有效路径**：只把完整ISO格式识别为时钟，`_L/_S`及控制后缀保留字符串身份比较；加入真实形状的合成ID反例。失败收据留存，修复源码先提交再重跑审计，不改策略/输入/结果。
- **通用规则**：数据列语义优于内容外观。通用比较器必须区分完整时间值和包含时间的业务ID，测试ID形状要接近实际契约。
- **牵连**：V27 `audit_saved.py`、专属合成tests、`audit_attempt1_failure.json`；这是审计解析故障，不是策略收益失败或支持容量不足。
