# 双向 Fibonacci 的比例必须连同锚点和方向一起定义

- **问题**：梳理周一区间交易规则时，原文用“0.618 止盈”和“区间外 1.13”描述目标，但 v1.8 指标对每个比例同时绘制两个方向，比例名称不能唯一确定执行价格。
- **死胡同**：本轮没有运行交易实验。仅照抄图上的比例名无法消除歧义；指标默认显示某条线，也不能证明 Owner 已选定它作为入场或止盈条件。
- **有效路径**：先读实际公式。设周一高低点为 H、L，区间宽度 R=H−L，指标同时绘制 L+rR 与 H−rR。除重合情况外，同一 r 对应两个价格；例如 H=110、L=100 时，0.618 对应 106.18 和 103.82。执行定义需包含锚点、方向、比例及对应价格，并区分指标行为与 Owner 的策略决策。
- **通用规则**：把画线工具转成交易规则前，先检查价格生成公式，再确认锚点的冻结时间及多空方向。未明确的方向、入场点位和动态调整条件应保留为待确认，不凭显示默认值补全。
