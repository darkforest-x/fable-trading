# 降低入场周期不能同时改变跟踪更新时钟

- **问题**：将15m入场改为5m，原候选筛选器要求ATR为有限值，而旧ATR数组只在15m收盘有值，会误删其余5m入场。
- **死胡同**：只换信号数组会漏单；直接把前向填充后的ATR送给撮合器，又会把跟踪止损更新悄悄改成每5m一次。
- **有效路径**：候选上下文与管理上下文分离。候选读取最近一次已完成15m ATR，不能回填；原生退出引擎继续使用原稀疏15m更新事件。测试同根H1信号不入场、同向重复入场、非15m收盘候选和前缀稳定性。
- **通用规则**：多周期策略需要区分“当前可见的最近特征值”和“本根是否允许更新交易状态”，两者不能共用缺失值约定。
- **牵连**：`range_entry_clock.py`、`range_multicoin.py`；`range_framework.py`及原生退出引擎保持不变。
