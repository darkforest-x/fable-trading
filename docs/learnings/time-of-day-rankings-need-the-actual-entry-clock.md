# Time-of-day rankings need the actual entry clock

- **Problem**: The V2.37 two-year study asks which hours have the highest win rate, while many five-minute frames are published after their backmarked entry candle.
- **Dead end**: A single unlabeled hour table would confuse the visual reference with an executable decision. Selecting the full-sample winning hour would also mistake descriptive ranking for forward evidence. Neither interpretation is supported by the study.
- **Effective path**: Retain two explicit cohorts: exact chart references, including losses before publication, and entry at the first close when both arrows are known, with the same stop formula recomputed there. Group each by its own Shanghai entry close using predeclared two-hour bins. Report counts and uncertainty, and select the first year's winner before evaluating it in the second year. BTC five-minute full-sample leaders differ: 04:00–06:00 for chart references, 20:00–22:00 for confirmation-close entries; both full cohorts remain net negative.
- **General rule**: Match timestamps are part of the trading contract. Audit the event, reference-entry, publication and execution clocks before ranking hours or weekdays. A selected group's higher win rate does not establish positive expectancy or persistence.
- **Scope**: `yoyo/evaluation/range_v237_twoyear.py`; `experiments/active/exp-range-v237-twoyear-20261022-v1/`. Existing Nautilus execution, stop/trail thresholds and 20bp costs are unchanged. The delayed-entry lane is a research comparison, not a Pine or production modification. See [the three-clock distinction](candle-position-close-and-publication-are-distinct-clocks.md).
