# 同一策略用两种成交口径展示，会被当成数字错误

- **问题**：VIDYA 趋势线回踩在回测报告里是“确认收盘价入场、每边 0.05% + 0.01% 滑点”，每笔 +0.38R；搬进工作台时按本仓标准“下一根开盘成交、20bp”重算，变成 +0.30R。Owner 看到同名方案两个数字，判断为“数字有错”。
- **死胡同**：只在页面角落写一句口径说明。读者对照的是已经看过的报告数字，说明文字挡不住“同一个方案数字变了”的第一印象。
- **有效路径**：展示 owner 已审阅过的结果时，沿用原口径并逐项复现原数字（builder 内置报告的笔数与每笔平均 R，不一致即中止）；本仓标准口径的结果单独成表、在表头写明口径，不和原表混用同一个方案名。
- **通用规则**：一个数字一旦给 owner 看过，后续任何界面都先复现它；换口径时换表或换名，并在同一屏解释差异来源（成交点、成本），否则差异会被当成错误。
