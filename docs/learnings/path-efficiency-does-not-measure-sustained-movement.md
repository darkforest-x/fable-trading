# Directional path efficiency does not measure sustained movement

- **Problem**: The owner defined clean reversals as sustained reverse progress with small drawdowns. A label based on terminal displacement, close-path efficiency, and adverse excursion can rate a single jump followed by flat prices as highly as a steady trend with the same endpoint.
- **Dead end**: Directional efficiency is displacement divided by total absolute movement. Both a monotone trend and a one-step jump have efficiency one. Small drawdown does not resolve this ambiguity; neither path needs to retrace.
- **Effective path**: Before any model fitting or metric inspection, add a behavioral counterexample with equal endpoints and distinguish temporal persistence using four consecutive chronological blocks. Multiply the quality by the fraction of blocks making forward progress. Keep the original untrained labels in the experiment attempts directory. Then evaluate prediction separately: the resulting visually useful labels did not produce a useful model here (within-quarter AUC0.503; top-decile clean rate29.1% vs matched candidate control29.6%).
- **General rule**: Translate each adjective in a target definition into a separately falsifiable path behavior. Test equal-endpoint counterexamples before fitting. A good retrospective label and a predictable label are separate achievements; automatic candidates remain unconfirmed until reviewed.
- **Scope**: `yoyo/evaluation/clean_reversal_labels.py`, `tests/evaluation/test_clean_reversal_score.py`, `experiments/active/exp-clean-reversal-score-20261101-v1/config.json`. Future paths are labels only; causal features end at signal close. This is shape research, not a trade-PnL engine or a production model.
