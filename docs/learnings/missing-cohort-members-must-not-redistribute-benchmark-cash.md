# 缺失证券不能让冻结股票池的基准自动加仓

- **问题**：历史股票池冻结后，少数证券因源数据质量不可用。若基准按成功加载的证券数分配资金，余下股票会获得额外权重。
- **死胡同**：只在报告列出缺失代码，却用 `initial / len(loaded_frames)` 计算等权持有；文字披露并未修复比较组暴露变化。
- **有效路径**：策略与基准共用排除清单并绑定其哈希；基准分母保留冻结池数量，缺失份额留现金，缺失股票不补换。
- **通用规则**：数据质量筛选与投资分配是两个动作。冻结证券池后，先明确缺失权益如何计量，再算比较组收益；全段质量审计仍应披露其事后可用性筛选限制。
- **牵连**：`yoyo/evaluation/ashare_research.py`、`tests/test_ashare_research.py`、A股日线实验计划。无生产配置变更。
