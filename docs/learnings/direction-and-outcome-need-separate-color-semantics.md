# 多空方向与盈亏结果需要独立的颜色含义

- **问题**：信号卡同时用红绿方向标签、方向竖条和盈亏底色；盈利空头会同时呈现红与绿，阅读时无法快速判别颜色的含义。
- **死胡同**：把底色降低饱和度只减轻了视觉重量，没有消除同一种颜色代表两个变量的冲突。
- **有效路径**：卡片保持中性底色与细边，多头和空头用蓝／紫紧凑标签、趋势图标及文字标注；红绿只用于盈亏状态和当前／退出 R 数字。深浅主题分别设置对比度。
- **通用规则**：先明确每种视觉编码只表达哪个维度，再确定颜色；方向、状态与结果同时出现时不要依赖整卡着色承载全部信息。
- **牵连**：`yoyo/monitor/static/styles.css`、`yoyo/monitor/static/app.js`；信号检测、收益计算和通知规则不变。
