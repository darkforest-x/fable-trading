# 实际持仓时长是结果，不能把短持仓亏损直接变成可回收收益

- **问题**：旧 V1 账本中持仓不足 4 小时的交易合计约 -348.62R，容易被理解成剔除这些交易就能回收相同利润。
- **死胡同**：最终持仓时间取决于之后是否止损、反转和数据结束。入场时不能识别“会在四小时内止损”的那批交易。把这个分组变成“满四小时仍弱就退出”也不是等价规则：此前亏损已经发生，新规则会作用于另一批仍存活的交易，包含之后能走出趋势的单子。
- **有效路径**：先复算旧表并标明事后标签，再固定一个可执行退出：首次满四小时收盘，至今 MFE<1R 且毛浮盈≤0，下一根开盘退出；旧止损和反向退出优先。在 V8 3,531 流两年数据上分别比较同入场路径和完整串行回放。同入场净R减少 2,170.21R，原有 532 笔兑现≥10R只保留385；完整串行净R由 -2,021.78 降至 -3,917.36。静态“短持仓亏损”不能解释成该退出规则的收益承诺。
- **通用规则**：看到按持仓时长、最终 MFE、退出原因筛选的“可回收损失”，先画出信息可知时间，再定义当时可执行的替代动作；同事件归因与串行执行都要测，且记录牺牲的大趋势，而不只记录缩小了多少亏损。
