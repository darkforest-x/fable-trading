# 方向筛选要重放持仓占用，再用同方向对照判断优势

- **问题**：近期 15m 观察的盈利集中在空头，Owner 要求拆分历史多空并判断是否只做空更好。历史空头贡献 471.31R、多头 16.71R，但这是多个币种交易的算术和。
- **死胡同**：直接删除旧账本里的多单不能自动代表只做空策略；多单可能占用原本可做空的确认时点。把空头总收益较高直接解释为信号优势，也无法排除市场方向和交易周相关性。这两种捷径未作为本轮结论依据。
- **有效路径**：先认证 638 个原始候选、成交和随机对照文件，从预热期按确认时点重放单向准入，保留原始反向退出、止损、追踪及 20bp 成本。双向重放逐笔和汇总与原历史一致；本例单向重放没有新增或替换交易。空头平均净 0.0816R、PF 1.142，好于多头 0.0031R、PF 1.005，但 2023 和 2026 年空头为负。同币、同方向、同时间块、同波动桶对照只覆盖 13.6% 的空单，配对超额为 -6.58bp；前后两段均不显著。按交易周整块重采样的空头减多头平均净 R 区间为 [-0.129, 0.291]，不能认证稳定优势。
- **通用规则**：方向是准入条件，不是事后收益标签。先核对候选全集、暖启动持仓、同 bar 顺序、删去一侧后新增和被替换的交易；再分别报告效率、总净 R、年度反例与同方向匹配对照。以周聚类保留跨币同期相关性；对照不足就明确限制，不把点估计变成实盘裁决。
- **牵连**：`yoyo/evaluation/spike_v13_direction_split.py`；`experiments/active/exp-spike-v13-15m-direction-20261016-v1/results_v1/`；固定历史区间 2023-01-01 至 2026-09-23 04:00 UTC。AUC 和 top-decile 不适用于没有分类或排序模型的方向筛选。当前 OKX 观察与 Binance 历史不得合并成同一成交样本；生产资格仍为 false。
