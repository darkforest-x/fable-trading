# 两条路径盈亏相同，不代表平仓时间已经验证

- **问题**：2026-10-31 检查 spike / ENAUSDT / 129。网页将开平仓都画在北京时间 2026-06-03 00:40–00:45，原价分别为 0.09316776 / 0.08988，但 1m 走势在开仓之后没有于该区间回到止盈价。
- **死胡同**：把问题当成箭头横坐标偏移，或者认为 OHLC、OLHC 的净收益相同就验证了成交时间。图的区间与保存账本一致；收益一致没有约束资金何时释放，也没有证明区间内先开后平。
- **有效路径**：读取同一事件 `ENAUSDT:2026-06-01:-1`、同一变体 `near_P18` 的两条原生记录，再只读核对已缓存真实分钟线。OHLC 原记录在 00:45 收盘所属区间止盈，OLHC 在 01:00 收盘所属区间止盈，两者均为 348.95659701924404bp。`monday_limit_spike_opt.legs` 使用 `nl < no`，平收益时保留 OHLC 及其较早退出时间，显示层复用同一选择。分钟线在 00:40 已穿过目标价，00:43 才首次触及开仓价；00:43 / 00:44 的 low 为 0.09096 / 0.0921，均高于目标。开仓后首次再次穿过目标在 00:55–00:56（low=0.0894）。此为时间顺序矛盾的直接证据，不是一次重算交易盈亏。
- **通用规则**：盘中路径的保守性应分别检查价格收益与事件时序。较差收益相同不能默认较早退出同样保守。发现细粒度行情冲突时保留旧记录和来源，不能只移动箭头、无声改写账本或声称原收益已经通过分钟级验证；真实退出仍需按完整策略语义验证。
