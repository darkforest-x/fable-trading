# 滚动行情的视角必须锚定时间，不能只保存数组下标

- **问题**：2026-10-18 统一 K 线交互时，历史回放每次刷新都 `fitContent()`；滚动行情即使保存相同逻辑下标，也可能展示另一段时间。
- **死胡同**：只去掉 `fitContent()` 仍不够。头部裁剪会改变下标，按固定周期扣偏移又无法处理缺失 K 线；放大时只调用 `resize()` 还会改变可见根数，产生大段空白。
- **有效路径**：刷新前把视角两端插值为时间，刷新后按真实时间数组映射回来。尾部跟随单独保存可见宽度和右侧留白；完全离开已载入历史的视角拒绝恢复。尺寸变化先保存范围，调整画布后恢复同一范围。相同数据不重绘，尾部变化增量更新，历史修订与回退完整替换。
- **通用规则**：先区分用户在看历史还是跟随最新，再分别处理数据身份、时间范围、画布尺寸。不得通过额外读取未来数据来稳定视角。
- **牵连**：`yoyo/vision_research/static/chart-tools.js`、行情/巡检/区间图、研究图与回放。回放只消费服务端已披露前缀；研究截图的最后一根时间直接取真实末行，不能按首行和固定间隔推算。行为证据见 `tests/monitor/frontend_chart_tools.test.cjs`、`tests/vision_research/replay_chart_view.test.cjs`、`tests/vision_research/chart_capture.test.cjs`。
