# CSV 嵌套单元格序列化不能先把序列强转成字典

- **问题**：总队列同时含字典字段（语义检查/特征）和列表字段（类别、失败项、训练重合样本）。辅助函数先用 `dict(value)` 再 `json.dumps`，字典可用，但普通字符串列表会被误解为键值对序列，在 5,083 张图已完成后让 CSV 交付失败。
- **危险捷径**：删除列表列、把列表用逗号拼接，或捕获异常写 Python `repr`。这些做法会损失类型、遇到内容含逗号时不可逆，或让 CSV/JSONL 两种交付口径不一致。
- **有效路径**：确定性 JSON 序列化直接接收原对象；mapping 输出 JSON object，list/tuple 输出 JSON array，标量保持 CSV 标量。增加同时覆盖 dict/list/tuple 的回归测试，保留已完成模型分片和失败回执，再从聚合阶段重放。
- **通用规则**：序列化前不得为了“统一接口”改变容器类型。通用 helper 的输入类型应与实际调用面一致，并在大批量工作前用最小混合记录跑通每一种嵌套结构。
- **牵连**：review queue CSV/JSONL、语义失败项、类别列表、训练重合样本；不改变候选选择、图片像素、模型或训练资格。
