# 参数研究先复现默认事件，再显式注入候选

- **问题**：用户要求为高波动山寨优化现有 IMACD，多处 Pine/监控默认值容易被误当成已优化策略。
- **死胡同**：本轮未尝试直接改线上常量；审计发现34/9是继承值、12/0.10是显示默认。把这些值称为最优或通过修改运行模块生成候选，会同时改变基线与通知含义。
- **有效路径**：纯数据模块显式接不可变参数；默认结果与监控和旧研究逐字段一致，先通过合成prefix/缩放/冻结区间测试，再进行离线一因素比较。当前通知不读取研究参数。
- **通用规则**：参数来源是证据的一部分。先证明新实现重现旧事件，之后的差异才可归因于候选参数。
- **牵连**：yoyo/data/altcoin_features.py、tests/test_altcoin_features.py、exp-imacd-altcoin-trends-20260909-v1；不替代收益、样本外和执行检验。
