# 关键位触及后的最大反应不能当成挂单利润

- **问题**：前端已有周一区间、Fib、昨日 POC/VA、nPOC、上周高低，Owner希望判断是否能挂单吃短反应。线多、触及后能反弹，并不直接回答成交后是否能赚钱。
- **死胡同**：把触及K线的高低都放到成交之后，或把事后最大有利幅度当作止盈收益，会暗中假设成交顺序与完美退出；昨日POC/nPOC同源重复计数又会夸大样本量。
- **有效路径**：事前冻结价位生命周期、纽约日界与1小时主比较；完整形成窗才激活，每个来源价位只取首次触及，POC别名合并。1m定位后从下一分钟开盘测量，理想价位成交单列；按周聚类，与同币/同周/时段/因果波动桶/动量方向的随机入场比较。
- **证据**：OKX BTC五年5945次事件，1小时有利最大幅度中位29.38bp、逆向30.07bp，但平均毛反应0.05bp、扣20bp后-19.95bp；匹配超额-1.70bp，p=.2584。周一低点前段净+8.19bp、后段-22.68bp。15类全期1小时净反应都负，没有跨期通过门槛的类别。此结果只针对本次反应检验，不是否定一切止盈止损方案。
- **通用规则**：先冻结位置的可知时点与首次触及身份，再区分触价、理想成交、可执行入场和可兑现退出。MFE/MAE只能描述路径；没有退出合同，不能声称验证了“吃一点就跑”。
