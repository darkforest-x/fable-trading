# 触价复盘要把区间全景与触后局部价格尺度分开

- **问题**：月首周区间跨幅较大，既要展示四条价位及首周形成过程，也要看清触及后的反弹或继续突破。
- **死胡同**：初版全景和4小时局部图都强制把上下1.618纳入纵轴；BTC十月的局部K线被压到图底，约3%的反弹很难辨认。增加分辨率不能解决价格轴跨度造成的压缩。
- **有效路径**：全景保留四条线；局部纵轴只围绕实际OHLC及被触及价位，其他线在范围内才显示标签，并明确分图独立缩放。触及小时映射到所含展示K的中心，原始1小时区间写在图头。形成周结束后才画已确认实线，月底后改虚线。
- **通用规则**：先定义每个分图要回答的问题，再决定时间窗和价格范围；所有样本沿用同一规则，不能只放大成功例。向内及向外幅度同时给出，不能把事后极值当成成交或反转胜率。
