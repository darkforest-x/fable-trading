# 开盘已成交的半仓不能被同根K线后来的信息取消

- **问题**：V16在5分钟开盘兑现50%，又需用该根后续HLC检查余仓止损；错误排列会改变真实可见信息和成交顺序。
- **死胡同**：先检验完整当前OHLC再决定是否允许开盘半仓，会用未来坏数据取消本来可执行的成交。反过来，先半仓再处理此前源缺口或同刻原15分钟全平，也会凭空制造获利成交。这些错误路径在合成测试中被排除，未当作真实收益证据。
- **有效路径**：源连续/有效开盘 → 跳空止损 → 原慢周期全平 → 截止时间 → 开盘半仓 → 当前HLC/余仓止损。后续缺失保留已兑现半仓及其比例成本，但整单净利仍未知。精确20bp资格用十进制价格代数，不用先浮点除法再比较。
- **通用规则**：先标每条信息最早可见时刻和每笔成交占原名义仓位比例，再编排状态机；原始路径不变的半仓实验必须验证最终退出/占用一致以及加权收益恒等式。
- **牵连**：`yoyo/layers/l3_backtest/hourly_impulse.py`、`tests/test_hourly_impulse_dual_partial.py`、V16固定50%和20bp资格、原K1止损。此结论仅保证因果核算，不保证策略盈利。
