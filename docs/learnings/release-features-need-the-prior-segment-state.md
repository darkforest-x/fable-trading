# 释放根的形成特征必须保存上一段状态

- **问题**：为现有可见IMACD箭头增加离线形成特征时，释放根处理完会清空focus计数、起点和冻结带宽；直接读当前chart状态就失去启动前证据。
- **死胡同**：把收盘后状态当成事件附带证据，或者让释放大K进入形成窗口，都会改变“此前蓄势”的含义；本轮未用这些错误量评估行情。
- **有效路径**：事件保留释放前的run/start/band，逐根状态另列；首6根与末6根宽度、前12根距带距离截止于t−1，只有定向分离允许读t。通过与monitor.analyze逐根对照、未来扰动前缀不变、大K不反写形成等26个合成测试再冻结。
- **通用规则**：事件与状态并存时，给出明确的更新前/更新后契约，不能从已重置状态推断历史事件。
- **牵连**：`yoyo/evaluation/imacd_startup_quality.py`、`tests/test_imacd_startup_quality.py`；没有更改生产事件公式。
