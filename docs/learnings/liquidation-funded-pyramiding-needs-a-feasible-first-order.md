# 滚仓终值算得对，也可能连第一笔都开不出来

- **问题**：2026-09-21，Owner 追问截图交易用 100 USDT 滚仓的完整路径。此前助手用 `100 / (0.1402 - 0.1362) = 25000` 币推导约 3711 USDT 的毛终值，却没有先通过首单保证金与费用检查。虽然曾说明是理论情景，数字仍容易被理解为可执行计划。
- **死胡同**：把全部 100 USDT 除以价格止损距离，再把名义金额除以本金得到的 35.05 当成可用杠杆。该规模占满 100 USDT 初始保证金，另有 3.505 USDT 开仓费；到 0.1362，连维持保证金都尚未计入的权益已经为负。再按一个折扣缩仓，也不一定给初始止损留出了维持保证金空间。
- **有效路径**：先检验 `initial_margin + entry_fee + order_reserves <= cash`，再检验止损前的权益是否高于维护要求和强平预留；只有初仓成立才推后续。加仓逐步计算现金、未实现损益、可用抵押权益和新仓保证金，不能自动把逐仓浮盈当成可开新仓余额。
- **通用规则**：破产价、强平价、主动止损价分开记录。金额账本正确不等于订单可提交，更不等于价格路径能存活。当前报价与最高价只给终值情景，不能证明期间没被止损或强平。杠杆按钮值也不等于全程的名义敞口／实时权益。
