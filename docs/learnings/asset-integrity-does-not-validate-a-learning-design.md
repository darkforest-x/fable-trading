# 文件校验通过不能证明模型没有学习位置模板

- **问题**：固定 post5 被纠正为统一 R5/R8/R11 后，曾把双机文件一致和 107 项行为测试通过表述为准备完成。训练正框仍只有六组横向中心、两档宽度；旧 v6A 原始回放 773 框中 766 框位于 post5。
- **死胡同**：测试只证明代码实现了既定裁剪方案，却没有反驳方案本身提供了定位捷径。重复继承同一模板的验证图会重复训练偏差；同模型补边 mAP50 0.0865/0.99465 的历史失败也没有被提升为开训前必须解决的问题。
- **有效路径**：把完整性与学习设计分开审计。直接读真实 TXT，分训练/验证/测试统计横向位置和宽度；用仅训练标签拟合的裁剪元数据模板作为不看图的定位对照，并在测试集打乱视图编号做控制。当前测试横向 IoU 均值为 1.0，打乱后约 0.404；这不是类别、纵向定位或检测 mAP。另查困难负例覆盖、后验选样与逐样本确认、训练和推理输入契约。当前修正版测试困难负例为 0，不能证明实盘难例抑制能力。
- **通用规则**：每事件最多三张不等于所有事件使用同三个固定坐标。准备状态必须分别说明资产完整性与学习适用性；保留规则候选、人工金标、后验收益和实时可见时点的区别。既有补边/位移失败未闭合、独立位置挑战缺失、困难负例测试为空时，不得从测试项数或 mAP 单值宣告训练设计已验收。
