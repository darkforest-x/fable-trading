# 事后涨跌榜审图必须把选池前视与因果检测分开

- **问题**：按完整日涨跌幅选出当日 Top20，再回放 v10，可以高效检查模型在极端行情中的开火位置；但榜单本身使用了收盘后才知道的整日收益，不能被误读为可实时执行的选币策略。
- **死胡同**：只保证检测窗口不看未来，却不披露榜单选池的前视，会让审图页看起来像一份因果回测，进而夸大可交易性。
- **有效路径**：把两只时钟明确拆开。选池层标记为“事后完整日涨跌幅排名”；检测层仍逐根使用截至当前 bar 的 200 根窗口，并只接纳 tip/tip-1/tip-2 触边框。HTML、CSV 和说明中同时保留日期、日排名、日涨跌幅和实际信号时刻。
- **通用规则**：任何用未来结果定义样本池的 retrospective gallery 都只能用于模型行为审查，不能报告为策略回测或实时选币能力；若要做因果策略，候选排名也必须只使用信号时刻之前可见的数据。
- **牵连**：`scripts/scan_daily_movers_v10_html.py`、`analysis/output/v10_daily_movers_10d_report/`、v10 的 15m 因果扫描口径（200-bar 窗口、tip 三窗、conf=0.30）。
