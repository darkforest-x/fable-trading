# Pine 关键 K 高亮应复用原生实体几何

- **问题**：手机放大后，蓝色关键 K 的实体比原生 K 线宽、影线偏在实体左侧。
- **死胡同**：用时间中点加固定周期比例画实体矩形，只在个别缩放看似正确；TradingView 的 bar 时间定位和原生宽度并不等于手画时间框。单用 barcolor 又不会统一影线颜色。
- **有效路径**：实体交给 barcolor，让原生图表决定宽度与中心；透明实体的 plotcandle 只补影线。小周期在下一根才获得12H确认时，实体用 offset=-1，只补一条前根真实时间位置上的细影线，且不依赖交易框缓存。原生12H与5m截图验证了同一信号的实体和影线对齐。
- **通用规则**：已有原生几何时，强调样式优先改属性，不叠造近似形状；确认时点和高亮对象分别建模，不能用视觉回标冒充提前知道信号。
