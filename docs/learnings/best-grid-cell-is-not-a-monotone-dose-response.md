# 阈值网格里最严格的那格最好，不等于每个维度都是越强越好

- **问题**：全市场同步冲击 v2 的阈值网格里，最严格的 z3/量比3/同向75% 那格结果最好（1H 上涨后做多 ETH 12h +53.8bp）。直觉结论是“冲击越强、放量越大、同涨越多，后面越涨”，下一步就该把阈值再调高。
- **死胡同**：直接比较网格各格。各格的事件集合互相重叠，冷却期又让同一段行情在不同格里落在不同的 K 线上，所以格与格的差异混进了“哪根先触发”的偶然性，分不出到底是哪个维度在起作用。再调高阈值只会让样本更少，结果更随机。
- **有效路径**：v3 固定一个事件集合（最宽的那格），用 v2 自己的收益和对照，一次只按一个特征分三档。分档边界只用 2025 年前的事件确定，冻结后再用到 2025 年后。结果：1H 上三个特征都没有在两段里保持同一个排序（高减低：强度 −32→+47bp，量比 −10→+56bp，同向比例 −24→−73bp）。144 组对比里有 78 组两段同号，和随机差不多。最严格那格的优势，用单个维度都解释不了。
- **通用规则**：网格里出现“最好的一格”时，先在固定事件集合里逐个维度分层，确认存在单调的剂量效应，再去谈收紧阈值。分档边界要在选择期定好并冻结。另外要看两段时间是否同号，不能只看合并后的 p 值。
- **牵连**：`yoyo/evaluation/market_sync_shock_v3.py`、`experiments/active/exp-market-sync-shock-20261008-v3/`。唯一在两段里都单调的是 30m 上涨冲击的量比（高档 ETH 24h +75/+102bp），属于事后发现，需要前向样本验证。相关：[按方向拆开](pooled-long-and-short-shocks-cancel-an-asymmetric-edge.md)。
