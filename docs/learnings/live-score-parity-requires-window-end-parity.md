# 同一评分模型仍可能因特征窗口右端不同而改变含义

- **问题**：为周一1.618增加评分过滤时，旧研究缓存的部分量价输入使用触价当根最终收盘，现有网页评分使用触价之前已完成的5m和1h。相同系数不代表相同决策输入。
- **死胡同**：直接读取旧缓存、保留模型名称与门槛，会把事后可见的触价收盘冒充盘中评分。模型文件里的文字说明不能证明生成缓存时的实际索引。
- **有效路径**：沿用冻结系数和0.22621664169752762门槛，按现有网页公式重新构造触价前窗口；用公式逐特征对照和修改触价及未来行情的反事实测试核验。历史Binance成交额近似、市场覆盖和旧模型训练分布的差异另列，不宣称完整实盘重放。
- **通用规则**：模型一致性至少核对系数、特征公式、窗口右端和输入市场四项；缓存可复用的前提是这四项语义一致。
