# A backend signal is not proof of a TradingView arrow

- **问题**：2026-09-24 GEV-USDT-SWAP 30m Bark described a V12.8 short as an original arrow plus YOLO confirmation, while the native TradingView chart had no signal. Raw event `d1408acce0c386057fedeb00` and model event `8ecedbee762f61b25343363b` refer to the 15:00 Beijing open / 15:30 close, price 942.49, with zero extra model-wait bars.
- **死胡同**：Successful push delivery and replaying the backend's own 1,362 closed candles establish delivery and internal reproducibility, not native Pine parity. The two display switches that can hide ordinary arrows were both false on the inspected desktop V12.8 instance. CSV export required a paid plan and was not used. Restoring the maximized chart pane exposed the indicator panel and normal Data Window, which supplied the actual evidence.
- **有效路径**：Inspect the immutable event, replay its closed prefix, then read the same bar in native TradingView. Both sides had O/H/L/C 942.35/943.25/941.72/942.49. Native event code was 0, confirmation price absent, IMACD MD/SB 0/0; backend MD/SB were -0.0791107267/-0.0087900807. Native base metadata was unknown, whereas the OKX instrument supplied GEV to the backend. Pine explicitly rejects unknown `syminfo.basecurrency`, independently sufficient to block admission. The native panel's **last raw confirmation** also said BB failed, but that panel is not a time-stamped BB verdict for the selected 15:00 bar. Formula inspection did not find a sign/formula error; historical inputs, recurrence initialization and feed differences remain unresolved. Closed-prefix SHA-256 using `json.dumps(rows, sort_keys=True).encode()` was `e53f6947228750ca468dc86cf156d28fd702241bede93e82a231f0b1707de567`.
- **通用规则**：Source hashes and matching current OHLC do not establish cross-platform equivalence. Reconcile metadata, historical series, recurrence state, intermediate values and final gates before calling an event a native chart signal. A YOLO pass is a second backend observation, not a TradingView receipt. Notification text now says backend signal and explicitly states native chart signals have not been verified; this corrects provenance without relaxing any trading gate.
