# 赢家走得更远不等于全局止盈应该提高

- **问题**：BTCUSDT.P 15m 的 24 笔 3R 止盈中，19 笔随后到 4R、16 笔到 5R，看起来固定止盈明显过低。
- **死胡同**：只统计已经到达 3R 的赢家会条件化在成功路径上，完全看不见原本到 3R、却会在等待更高目标时回撤的交易；据此直接把全局 TP 改成 5R 会产生幸存者偏差。
- **有效路径**：保持入场、结构止损、保护、成本和 48 根时限不变，从入场重新回放 2R--6R 全部目标。5R 的开发期均值虽从 3R 的 -16.09bp 改善到 -13.70bp，但四个半年仍全负、稳健分数 -18.70bp、最差半年 -28.33bp，因此右尾真实却不足以修复系统。
- **通用规则**：看到“止盈后继续上涨”时，第一步不是查看赢家延伸比例，而是对全部固定入场做冻结条件的目标敏感性回放；若全局目标仍失败，再预注册部分止盈或 runner，不能用胜者路径代替策略级反事实。
- **牵连**：固定 TP、1.5R 收盘保护、12 小时时限、20bp 往返成本、同根止损优先、目标敏感性与幸存者偏差。
