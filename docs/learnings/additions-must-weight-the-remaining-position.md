# 加仓均价必须按剩余仓位加权，不能按历史累计开仓量

- **问题**：模拟账户需要同币多笔委托和加仓；部分平仓后再加仓会改变剩余持仓成本。
- **死胡同**：只删除“同合约禁止再开仓”的校验，或拿累计 quantity 加权，会让已结算的数量再次参与成本计算；把总手续费当剩余开仓费也会重复扣费。
- **有效路径**：同方向、同杠杆合并，以 remaining × entry_price 加上新增成交金额求均价；历史 fills 不改写，单独追踪剩余开仓费，平仓按比例释放。新仓位的保护触发时间不能早于最后一次加仓。
- **通用规则**：聚合持仓是当前状态，成交记录是历史事实；任何加仓、减仓都先区分剩余量和累计量，并在同一个写事务内更新。
