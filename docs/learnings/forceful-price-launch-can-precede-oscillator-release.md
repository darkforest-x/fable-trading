# 强劲价格启动可能早于平滑指标离零

- **问题**：用户要强劲爆发，初版却用IMACD离开近零容差做唯一资格。已见USELESS先放量阳线，MD尚在容差内；等MD释放时正好回落。
- **死胡同**：认为“等振荡指标确认”天然更安全，同时把先行大阳纳入不断更新的箱沿，会把真正突破重新解释成箱内行情。
- **有效路径**：先确认旧蓄势，再用当根价格强度检查冻结在上一根的箱沿。价格先行与指标释放路径共享同一段，保留明确时序标签，不事后回贴箭头。
- **通用规则**：先定义用户要的市场事件，再决定平滑指标是触发器还是背景。已看实例后改规则必须记为设计修订，不能冒充盲测盈利证据。
