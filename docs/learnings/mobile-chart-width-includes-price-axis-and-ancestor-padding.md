# Mobile chart width includes ancestor padding and the price axis

- **Problem**: In the simulated desk at a 390 px viewport, the outer workspace was 374 px wide but nested padding reduced the canvas to 298 px. Long profile prices then consumed a 132 px axis, leaving only 166 px for candles.
- **Dead end**: Making only the outer chart card full-width does not recover space consumed by inner wrappers or auto-sized price labels. Likewise, setting a canvas height without accounting for the shared fullscreen `height:auto!important` rule left a large blank area below the expanded plot.
- **Effective path**: Measure every ancestor and the actual Lightweight Charts table cells. Remove mobile wrapper padding, use an opt-in bounded axis formatter, and leave full OHLC and key-level prices in readouts. Preserve the logical candle range while changing the formatter at resize breakpoints. Give the expanded nested canvas an explicit viewport-derived height with matching precedence.
- **General rule**: Verify plot-cell width, not just container width, using live labels, both viewport sizes, and expanded mode. Display rounding must never change input prices, indicators, order parameters, or the user's viewed time range.
