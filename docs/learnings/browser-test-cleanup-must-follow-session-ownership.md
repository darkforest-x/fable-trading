# 测试浏览器按会话归属收尾，不能留到任务之外

- **问题**：多个网页验收各自创建headed Chrome会话，任务结束未关闭，累计八个独立实例，持续占用内存和CPU。
- **死胡同**：只关闭测试标签页或以“方便复查”为由保留浏览器，不能保证会话守护进程退出；全局killall又会误伤Owner日常浏览器。
- **有效路径**：联结Chrome临时profile、父进程cliDaemon和明确会话名，逐会话正常close，再验证实例退出。后台巡检独立核对PID、心跳和计划，不能把关浏览器等同于停服务。
- **通用规则**：浏览器归属在创建时记录，测试收尾用finally/退出清理，只关闭本任务拥有的临时资源。除Owner明确要求保留外，验收结束即清理并确认退出。
