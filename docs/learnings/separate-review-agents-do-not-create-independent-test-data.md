# 独立审核 agent 不会让反复研究过的数据变成独立证据

- **问题**：2026-09-10 评估外部“24/7 自动发现策略”方案。生成器与审核器分工有工程价值，但如果两者仍在反复筛选的同一段历史上用固定 Sharpe / t 值过门，审核通过并不构成新的盈利证据。
- **死胡同**：把增加 agent 数量、另一个模型同意结论、或者输出一个 confidence_percent 当成统计独立性。此次只做资料评估，未搭建或运行该方案；这是识别出的推理误区，不是新增实验结果。
- **有效路径**：分别检查实现独立性与数据独立性。前者要求审核者依据冻结源码和原始账本独立重算因果时钟、成本、匹配对照、现金与占仓约束；后者要求登记完整搜索历史、约束试验家族并核对数据是否已被用于选择。前者能发现错误，不能替代后者。本仓已有事件均值为正但现金账户为负的独立复核反例，也已有开发期搜索校正后优势不成立的记录。
- **通用规则**：采用自动研究流程前，先写清每个角色看到什么数据、尝试如何计数、谁能更改验收规则。把自动化优先用于查错和保留失败证据；新鲜前向验证与 owner 的 holdout / 上线授权仍按现有契约执行。本文未改动任何验收门、阈值或研究权限。
- **牵连**：[开发期搜索预算](development-search-budget-is-a-depletable-resource.md)、[事件收益与资金账户](overlapping-event-profit-cannot-pass-a-cash-portfolio-gate.md)、`experiments/registry.yaml`、`yoyo/evaluation/economic_gates.py`。
