# 交易知识库需要证据状态机而不只是笔记目录

- **问题**：交易想法、行情截图、回测、真实成交和复盘散落在聊天与文件里，同一个结论会被重复记录，也容易把事后盈利或外部观点误当成已验证策略。
- **死胡同**：只建一张“交易日志”表，或按 V1/V6/V7 建几个页面。前者混淆观察、研究与真实执行，后者会覆盖版本、丢失负面结果，也无法从规则追到证据和逐笔交易。
- **有效路径**：用策略作为中心节点，把资料、市场观察、单变量实验、逐笔交易、学习、项目和任务拆成独立数据库并建立双向关系；用唯一键去重，用“演化自”保存规则版本，用 Inbox → 假设 → 研究 → 前向 → Owner 实盘批准的状态门槛约束证据升级。
- **通用规则**：记录新交易信息前，先判断它属于来源、当时观察、可证伪假设、实验结果、真实执行还是复盘结论；保留原始时间和负面证据，价值不确定时降级记录，绝不自动晋级。
