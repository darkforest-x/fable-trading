# 显示规则切换后，预警与事件导出必须使用同一份最终事件

- **问题**：2026-09-19 审查 SPIKE V11.2。默认切到“多头框内”后，图上联合标签和任一来源预警使用新规则，但上级联合专用预警与事件码仍使用旧窗口规则。
- **死胡同**：只核对 Python 回测与旧账本、确认标签能画出来，不能证明预警会报出同一个事件；变量名称都含 joint，更容易被当成等价。
- **有效路径**：从规则选择器逐一追踪最终布尔值到绘图、alertcondition 和数据窗口。Pine 的 v112HtfShow 在框内模式取 v112BoxJointHtf；1912 行预警仍取 v11HtfJointEvent。构造“V9 框仍开着，首次上级突破在第 7 根后”的场景，新规则允许、旧 6 根窗口拒绝，因此两者不等价。任一来源预警使用 v11AnyJoint，已随新规则切换。本次仅确认源码分流问题，未在 TradingView 运行该场景，也未修改脚本。
- **通用规则**：多模式指标应先生成唯一的最终事件，再按来源派生标签、预警、导出和回放；对每种模式验证这些消费者的事件 ID 与确认时间一致。
