# 部分成交的入场单不能当作附带保护已经生效

- **问题**：复杂限价与冰山委托可能部分成交，OKX 附带 TP/SL 的转换与完整成交相关。
- **死胡同**：收到入场提交成功就把整片标成“受保护”，或对未知结果重发订单，会产生裸露仓位或重复成交。
- **有效路径**：写请求先落盘且不重放；按稳定客户端标识查询。部分成交先撤销剩余入场，父订单终态确认后只为实际成交量建立 OCO；核对数量、方向、止损和实际成交 3R/5R。明确终态的部分平仓可用新的标识处理剩余量，未知回执只能查询。全计划共同承担 3% 风险，不能给每片重新分配 1R。
- **通用规则**：提交回执、成交回执和保护生效回执是不同证据；状态机必须分别等待，并测试超时、重启、部分成交与拒单。
- **牵连**：`yoyo/monitor/pro/live_execution.py`、`tests/monitor/pro/test_live.py`；[OKX V5 Trade API](https://www.okx.com/docs-v5/en/)。测试不证明任何策略盈利，也不替代 Owner 的实盘启用确认。
