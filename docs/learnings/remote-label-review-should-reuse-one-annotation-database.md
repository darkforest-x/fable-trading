# 换电脑审核先复用同一标注服务，避免复制出第二份答案库

- **问题**：Owner 想在 3060 Windows 电脑调整 Mac Label Studio 中已有的预框，并保留已提交答案和未来参考图。
- **死胡同**：把换操作电脑等同于重装标注软件、迁移数据，或直接重跑历史 bootstrap。该脚本会准备旧包并重启 Docker；另有 native 与 Docker 同端口监听，模糊主机名还可能连错实例。
- **有效路径**：严格验证远端机器身份，核对 native 的真实 IPv4 监听、当前数据库和相对图片 URL；从 Windows 实际登录同一 LAN 地址，读取项目计数并对安全样本主图/未来图验 SHA，再创建桌面入口。答案仍由同一个服务保存。
- **通用规则**：跨设备审核先证明客户端到原服务的完整路径可用：身份、认证、正确项目、图片及可追溯进度。只有原服务无法满足需求时才考虑数据迁移；HTTP 验证不能冒充人工拖框提交。
- **牵连**：[3060 审核入口](../ops/YOLO_REVIEW_FROM_3060.md)、`scripts/start_label_studio_review.sh`、`label_studio_data/`、IPv4/IPv6 同端口实例辨认。服务留在 Mac 时必须明确告知开机和局域网依赖。
