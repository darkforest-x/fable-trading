# 收盘权益不能提前计入下一开盘成交

- **问题**：趋势规则在本根收盘触发、下一根开盘退出。若按相同时间戳提前结算，会把尚未发生的跳空盈亏写进上一根收盘权益，并提前释放现金。
- **死胡同**：只检查交易入场/退出价格和最终余额。最终净利润可以完全一致，中途最大回撤及同钟其他交易的可用资金却已经使用未来价格。
- **有效路径**：分别记录退出属于开盘、盘中未知路径还是收盘。先以本根真实收盘估值；下一开盘的退出到下一轮处理。盘中未知退出的资金只能在包围它的K线收盘释放。用下一开盘骤变、同钟另一候选的合成场景验证。
- **通用规则**：时间戳只是钟面，还要保留事件先后关系。交易价格对上不等于权益曲线及再投资时序正确。
- **牵连**：`yoyo/evaluation/altseason_portfolio.py`、`tests/test_altseason_portfolio.py`；收盘最大回撤不代表盘中最大回撤。
