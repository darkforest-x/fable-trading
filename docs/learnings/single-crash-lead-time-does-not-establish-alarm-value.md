# 单场更早报警不等于全期预警更有用

- **问题**：六币预警在8月22日比BTC早三分钟，看起来能为FHE深价单争取时间，但需要判断这种优势是否可重复。
- **死胡同**：只看该场事件，或把分钟ROC-AUC提高当成预警改进，会遗漏普通时段的报警负担。六币2025–2026年的AUC略高，但固定开发期报警预算后，两方法同样提前抓到8/25场，六币多报330次。
- **有效路径**：冻结开发期阈值，保留全时间报警，逐场一对一匹配，按周比较误报率差和召回率差。六币增加约0.518次非及时报警/天，95%周块区间约0.422–0.615；召回差区间跨零。保留原案例的212.608秒FHE触价提前量，同时拒绝该冻结版本优于BTC的结论。
- **通用规则**：分开回答市场严重阶段预警、目标币深跌与目标币恢复三个问题。单场目标币时间差可以支持继续提出假设，不能抵消全期新增误报，也不能证明挂单盈利。
- **牵连**：`experiments/active/exp-market-crash-alarm-20261029-v1/summary.json`、`validation.json`。2026年仅至9月30日，8月22日排除于主比较。匹配随机对照保留失败次数，六币合并对照仅92/499次满足约束，不能夸大其显著性。未改参数重跑，未进行交易回测或启用。
