# 只提前处理亏单，也可能几乎没有净收益增量

- **问题**：V12 冻结 K1 均线失效退出，在复用开发期提前结束20个原亏单，没有动到62个原赢家，表面上比 V11 的限时早退更合理，但全251净均值仍为−13.949bp。
- **死胡同**：把“这20个后来都亏”当作有效策略证据，或忽视原变色退出已经处理大多数路径。识别了坏单不等于比原退出成交得更好；10单少亏、10单多亏，没有一单变成盈利。
- **有效路径**：固定所有原机会并逐笔比较，两臂都亏的20单仅平均改善4.485bp，占全体7.97%，折算全体仅+0.357bp，月块区间跨零。其余231单仍净负，说明这一个附加出口不足以修好经济性。对照超额的上升主要来自对照更差，而非病例大幅改善，需同时报告。
- **通用规则**：退出机制至少分开报告影响覆盖、相同事件的成交差、赢家牺牲、全体净收益及相同支持对照。后验“坏单组”不能转成入场过滤；没有增量证据时，停止围绕该局部机制修阈值，另立因果、可预先计算的假设。
