# 本机设置必须明确跨进程持久性

- **问题**：视觉工作台把 API Key 只保存在进程内，用户每次服务升级或重启都要重新填写。
- **死胡同**：页面显示“已配置”只能证明当前进程有值，不能证明重启后仍有值；旧进程没有读回接口时，事后无法自动迁移已经丢失的设置。
- **有效路径**：Owner 授权本机保存后，将配置原子写入被 Git 忽略的私有文件，目录 0700、文件 0600；成功写盘后才更新进程，启动时加载。测试覆盖新进程读取、保存失败仍保留旧配置、API 与研究账本不返回密钥。
- **通用规则**：实现“保存设置”时先定义生命周期。重启保留需要验证跨进程读取，不能用同一页面的成功提示代替。
- **牵连**：`yoyo/vision_research/settings.py`、`server.py`、`tests/vision_research/test_app.py`；旧版仅内存 Key 需用户最后补填一次。
