# K线完整不等于币种覆盖完整

- **问题**：Owner要求全币种近两个月SPIKE统计，先前回答沿用BTC/ETH子样本。修正范围时找到旧638合约全市场回放，其K线覆盖完整，但2026-09-25官方USDT永续清单已为658个；新增20个中还有在5月至7月初上线、覆盖完整观察窗的合约。
- **死胡同**：将“已有缓存中的所有币”或“每个缓存币的K线无缺口”当成全市场完整性。两者只证明固定列表内部完整，无法发现名单以外的币；只保留当前TRADING也会删掉期间曾交易、现在SETTLING的合约。
- **有效路径**：冻结官方清单并与历史存档取并集，输出新增/消失/当前状态/实际行情边界。此次658个全部登记，651个覆盖完整窗口，6个窗口内新上市，1个待交易无行情；123个窗口内成交量全零，535个有过成交量。缺行情与零交易单独列出，不算亏损样本，也不从覆盖表消失。
- **通用规则**：任何“全币种”结论都先交代交易所、计价币、合约类型、清单时点与历史退市处理；币池完整性和每币时间覆盖分别验收。范围扩展不能沿用旧子样本胜率或把新旧账本相加。
- **牵连**：`experiments/active/exp-spike-market-two-months-20260925-v1/`；`data/research/spike_market_two_months_20260925/universe.json`与`manifest.json`。当前与存档清单的并集仍不等于所有历史上曾存在但两边都未保留的合约。
