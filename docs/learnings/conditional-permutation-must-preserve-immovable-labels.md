# 分层置换必须保留不能交换的小组标签

- **问题**：BB斜率分层检验按方向×UTC周交换高低组。15m以上有很多一周只有一笔、或同周全属同一组的情况；这些组没有可置换空间。
- **死胡同**：初稿在每轮置换时把所有行初始化成低组，只在可交换的小组里重新分配高组。这样会把不可交换组里原有的高组交易偷偷移到低组，改变分母和行情构成。所得p值不再对应原假设。该问题在正式市场统计前的代码审查中发现，未据此发布市场结论。
- **有效路径**：每轮从原标签副本开始，只对同时含高低组的方向×周小组置换；固定其他行。检验每轮高组总数不变，并报告真正参与置换的行数与覆盖率。周块bootstrap预先汇总每周高低组的收益和计数，以完整周为抽样单位。预声明七个周期的Holm家族不因大周期缺样而缩小。
- **通用规则**：分层随机化的首要不变量是组内计数与不可交换标签；只有随机种子固定不够。没有可交换小组应报告检验不可用，不能把计算不出来当p=0或证据支持。预声明的多重检验槽位也不能按结果可用性缩减。
- **牵连**：`yoyo/evaluation/spike_v128_bb_slope_stats.py`、`tests/evaluation/test_spike_v128_bb_slope_stats.py`。只修复统计方法，不改变信号、退出、费用或市场账本。
