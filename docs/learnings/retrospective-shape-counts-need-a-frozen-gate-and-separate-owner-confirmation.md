# 事后形态计数必须冻结检索门并把候选数与Owner确认数分开

- **问题**：给定一张 holdout 内的 ETH 参考图，统计全年有多少次同类形态。现有模型会输出大量候选，但它在最新 Owner 语义审核中接近随机，不能把预测框数直接叫作真实形态数。
- **死胡同**：直接用 YOLO 置信度或近邻距离定阈值会把模型密度当基率；看完全年结果再收紧阈值又会消费 holdout 并产生选择偏差。只按未来跌幅筛选也会把任何急跌都误称为目标平台形态。
- **有效路径**：先只从参考事件冻结两层合同：核心及均线束只用核心结束前数据，随后 3/5 根跌幅只作事后确认标签；再一次性扫全年、按时间邻近去重，并把机器候选与逐样本 Owner 裁决分栏。参考样本只确认类别语义，机器推定的核心边界仍保持几何未确认。
- **通用规则**：回答“历史上有多少这种图形”时，第一步不是跑现有分类器，而是预先登记数据范围、参考边界、核心门、事后确认门和去重半径；扫描后禁止改门槛。最终同时报告机器候选数、Owner 已确认数和待确认数。
- **牵连**：`scripts/find_eth_yearly_morphology.py`、`analysis/output/eth_yearly_morphology_gate_v1/`、holdout 使用记账、`production_eligible=false`、`training_eligible=false`。
