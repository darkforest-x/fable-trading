# 最长均线同侧区间是事后标签，当前连续长度才是当时状态

- **问题**：寻找ETH价格一直位于SMA120和EMA120同侧的最长段，容易把看到未来后选中的段理解成当时能够筛出的信号。
- **死胡同**：直接画最长一段并当作可捕获收益；把收盘、实体、影线条件混为一谈；跨缺根连接或把不同历史覆盖的最大值当成周期优劣。这些都改变了原问题。
- **有效路径**：固定120和三种独立严格比较；连续完整K线逐根枚举极大区间，标记文件与预热边界，完整采样后才聚合高周期。全覆盖榜与共同窗口榜并列。开始根也是收盘才确认，最终长度仅用于回顾标签。
- **通用规则**：先写清价格锚点、均线来源、相等处理、断流与删失规则，再排名；用于实时特征的只能是截至当根的连续长度，不是该段最终长度。
