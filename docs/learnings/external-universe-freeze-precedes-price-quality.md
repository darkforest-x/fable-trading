# 外部币池身份和资本分母必须先于价格质量冻结

- **问题**：扩展测试币种时，本地文件混有股票类永续、黄金、新币短历史和缺失区间；按数据完整度筛后再平分资金会改变问题。
- **死胡同**：把401个文件直接称401种加密币，或先要求一年历史再只对幸存者平均，都会把可用性选择伪装成跨币验证。
- **有效路径**：先用已有分类快照确定加密身份，与本地文件名交集，排除主研究和事后展示币并冻结分母；随后审计价格。被拒绝或尚未完成共同预热的成员保留现金袖套，不向剩余成员转移资本。
- **通用规则**：币池选择、历史可用性和资金配置是三份不同合同。任何缺失不能隐式通过dropna改变分母。
- **牵连**：`altcoin_transfer_research.py`；277品种身份快照；外部迁移只复用旧年锁定候选，不再搜索参数，仍有近期存续偏差。
