# 加仓前要重算整仓在统一止损处的净损益

- **问题**：2026-09-21，Owner 用一张 WIFUSD 1h 上涨截图询问如何滚仓。底仓盈利、底仓止损保本，都不能直接推出加仓后整笔交易仍保本。
- **死胡同**：本次未运行市场实验。设计时排除“止损提到第一笔入场价就可以用全部浮盈加仓”的推理：新仓的入场价更高，退回同一止损时会亏损；费用、资金费和滑点还会进一步消耗收益。不能用事后最高价证明当时可以加到相同仓位。
- **有效路径**：先用每一腿的真实数量与成交价，计算其在同一预设止损成交场景下的净损益，再求允许的新仓数量。计算还要受递减数量上限、总名义敞口和保证金限制。持仓中保留原始价格风险单位，不能随加仓均价重置 R。
- **通用规则**：多头线性合约先算 `P_stop = sum(q_i * (S_effective - entry_i)) - costs`。新仓允许损失只来自该场景下已经存在的利润余量。`S_effective` 是带成交假设的估算；止损可能滑穿，因此它不是现实损失的数学上限。另行记录当前浮盈退回止损会回吐多少。
- **牵连**：策略草案 `docs/protocol/winner_pyramiding_v0_1.md`；原始初始止损、0.2% 往返成本契约、逐次实盘授权、1h 收盘与下一时点成交语义。公式成立不等于滚仓能提高净收益，需与同信号、同移动止损、同初始风险的不加仓基线对比。
