# 辅助周期不参与评分，也必须进入可观察状态检查

- **问题**：轮动候选原先只根据日线与 4 小时条件显示 ready；15 分钟数据即使缺失、覆盖不足或已经失效，也不会影响该状态。
- **死胡同**：把“15 分钟仅作辅助、不要求出现相同形态”理解成“可以忽略它的数据质量”。这让评分口径和可观察状态混在一起：高分掩盖了所需上下文缺失。
- **有效路径**：保留原有 4 小时状态和分数，只给 ready 增加辅助周期可观察性检查。15 分钟 watch/breakout/pullback/extended 均可通过；缺失、insufficient_data、invalidated 转为 review 并逐项解释原因。已有事件、流动性等硬阻断仍优先。
- **通用规则**：特征是否加分，与该输入是否足以支持交付状态，是两个不同问题。辅助数据不必确认同一交易形态，但系统不能在它缺失或失效时把完整流程标成齐备。
- **牵连**：`yoyo/layers/l2_judgment/rotation_judgment.py`、`tests/test_rotation_logic.py`；本次只修状态完整性，不修改启发式收益参数，也未读取真实行情或 holdout。
