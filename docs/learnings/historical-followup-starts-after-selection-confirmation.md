# 历史候选的后续走势，应从筛选所需信息齐备后起算

- **问题**：Owner要求查看1,043个自动形态候选“找出来之后12小时”的走势，但清单记录的是历史形态核心，而非当时在线发现的时间。旧筛选使用了核心后第1、2、3、5根K线。
- **死胡同**：直接把核心最后一根当作已经发现信号的时刻，会把筛选本来就要求的前5根走势算成发现后的表现。这种口径会夸大启动后的可预测性；本次在绘图前排除了这种解释，没有据此计算交易成绩。
- **有效路径**：保留核心的原始起止索引，另标核心后第5根收盘为“最早确认时刻”。15分钟图从下一根起取48根，最后一根收盘必须恰好晚12小时。同时注明这是历史筛选的信息下限，并非在线检测日志证明的实际发现时间。
- **通用规则**：展示事件后果前，先区分形态发生、筛选条件齐备和实际检测三个时钟。未来窗口从声明的时钟边界起算；抽样必须先于后果读取，不能按涨跌或漂亮程度换样。
- **牵连**：`yoyo/datasets/ma_launch_owner_autofill10000.py`、`yoyo/datasets/ma_launch_owner_perfect_filter.py`、`experiments/active/exp-ma-launch-followup50-20260922-v1/plan.json`。审核未来图仍需与训练输入物理隔离；本例不构成交易收益验证。
