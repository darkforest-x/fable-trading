# 比较出场规则要固定入场，并数“结果翻转”而不是“变好/变坏”

- **问题**：给 VIDYA 方案 H 比较 22 种止损/保本规则时，第一版按“每笔 R 比原来高/低”计数。止损缓冲 0.5 ATR 显示 5 笔变好、48 笔变坏，但每笔平均反而 +0.09R，读起来自相矛盾。
- **原因**：止损距离一变，1R 的大小就变了。手续费按价格固定，摊到更小的 R 上就多出几百分之一 R，所以几乎每笔都“变坏一点点”；真正决定结果的只有少数几笔从亏变赚或从赚变亏。另外，如果按顺序重跑整条策略，出场早了会腾出原本因“已有持仓”被跳过的信号，入场集合也跟着变，差异里混进了入场效应。
- **死胡同**：拿“变好/变坏笔数”或整体胜率下结论；直接比较两次顺序回测的总收益。
- **有效路径**：
  1. 固定入场（同一组信号 K 线），用一个能逐笔复现引擎的模拟器跑基准和变体（builder 内置逐笔一致性检查，不一致就中止）。
  2. 报告逐笔配对的平均 ΔR 和 bootstrap 区间，再加上“亏→赚”“赚→亏”“赚得变少”三个翻转计数。
  3. 腾出信号的效果单独用顺序重跑表示。
  4. 匹配随机对照每笔抽 100 次：抽 20 次时，换种子后随机均值能差 0.06R，p 在 0.01 到 0.03 之间摆动。
- **通用规则**：出场规则只改出场，入场必须原样不动；凡是会改变 1R 大小的比较，用配对 ΔR 加结果翻转来读，不用“变好/变坏”计数。
