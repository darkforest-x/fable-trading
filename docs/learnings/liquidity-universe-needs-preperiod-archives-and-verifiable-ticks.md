# 历史流动性选池和成交步长需要分别验证

- **问题**：用三年前的流动性排名选前20进行策略验证，但今日交易所目录缺少已退市币，历史价格数据又不一定包含最小价格步长。
- **死胡同**：从当前exchangeInfo枚举标的会先删掉历史退市币；按K线小数位推测tick会把数据表现精度当成交易规则。公告搜索摘要也不能用空页面的SHA冒充完整公告正文证据。
- **有效路径**：枚举官方历史CDN目录，用评价期之前完整月份的真实quote_volume排名并冻结身份。每个价格ZIP验证官方CHECKSUM；另行绑定真实tick来源。价格可取得但tick不可验证的标的仍留在入选清单，回放覆盖明确缺失，不能按后来盈利替换标的。
- **通用规则**：选池时点、价格文件、品种身份、成交步长是四项独立证据。只有价格哈希不等于能精确模拟交易；缺一个维度就标明那个维度的限制。
- **牵连**：`yoyo/evaluation/spike_v1_triple_data.py`；`experiments/active/exp-spike-v1-triple-exit-20260914-v1/data/stream_manifest.json`；TOMO/MATIC缺tick，20个入选标的中18个可按本轮契约回放。
