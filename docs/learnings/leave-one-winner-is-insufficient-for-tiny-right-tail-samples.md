# 小样本右尾策略不能只做 leave-one-winner

- **问题**：趋势策略的收益天然由少数大赢家贡献。V4 只有 4 笔候选，最大赢家 CHZ 占总净收益
  `69.66%`；去掉它后均值仍为正，看似通过“去最大赢家”稳健性门。但前两大赢家合计占总收益
  `123.78%`，去掉两笔后剩余交易平均 `-977.76bp`，而且两笔赢家同时都是空单和右删失仓位。
- **死胡同**：机械套用 leave-one-out，然后把“去掉最大赢家仍盈利”写成不依赖单笔。
  当 `n` 很小且右尾由同一方向、同一时期或同一退出状态组成时，第二大赢家并不是独立佐证；
  leave-one-out 会留下同一混杂簇中的另一笔，产生虚假的稳健感。
- **有效路径**：同时报告 leave-top-1、leave-top-2（或预注册的最小 tail cluster）、
  最大赢家占比、前 k 大赢家占比，并按方向、时间折、资产和退出完整性拆分贡献。通过门还必须要求
  足够的独立盈利资产、每个时间折有样本，以及对匹配随机基线的正超额；这些条件缺一不可。
- **通用规则**：**leave-one-out 只检验一笔异常值，不能检验一个共同来源的赢家簇。**
  对 `n<20` 或前两笔贡献超过总收益的趋势策略，至少做 leave-top-2 与分组贡献审计；若赢家与
  方向、市场阶段或右删失状态完全重合，结论只能是“混杂未解除”，不能叫稳健盈利。
- **牵连**：山寨币趋势、跨币组合、稀疏日线信号、runner、方向 beta、时间折和资产独立性。
  验收表中的 leave-one-largest 应保留，但只能作为必要非充分条件，不能覆盖样本数、折稳定性、
  正币占比、匹配对照和闭合交易完整性门。
