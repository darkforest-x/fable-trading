# 指标编译成功不能证明识别了金标形态

- **问题**：Owner 要用指标识别此前 YOLO 人工打标形态，V1 却把单张截图解释成空头线下缓跌；通过编译和合成行情测试后，Owner 明确反馈效果不对。
- **死胡同**：先凭截图自定一套规则，再用按这些规则构造的合成正例验收。测试可以证明规则实现一致，却无法证明规则就是 Owner 的目标；空头专用规则也无法覆盖实际人工答案里的多头。
- **有效路径**：先追溯真实 annotation、原始框、对应 OHLC 与均线取价源，再在同一批人工框上对照事件位置、漏检与明确无目标图的误报。保留未确认预框、方向确认和正式金标准入之间的差别。框后确认使用真实观察时间，不向左回画成提前信号。
- **通用规则**：复刻视觉标注语义时，验收集来自原始人工裁决，不能由刚写出的指标规则自己生成。编译、因果性、金标召回和未知行情泛化是四个不同证据。
