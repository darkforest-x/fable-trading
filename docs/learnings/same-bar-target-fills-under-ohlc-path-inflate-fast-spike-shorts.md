# OHLC 固定路径会高估急速插针做空的同K止盈

- **问题**：复核 Codex 的 1.618 挂单收回（2026-10-24 快照），"从周一边界到 1.618 用时 <30 分钟"这组看起来极好：胜率 51%/64%，每笔 +164/+160bp，每年都为正。但按铁律，结果好得反常时第一假设是 bug 或回测假设。
- **死胡同**：只看两段一致、每年为正、比随机好 +100bp 就当真。原因是 Codex 用固定的 O-H-L-C 顺序处理每根 5m K 线。做空时，先在 H 成交，再把 L 当作在 H 之后，于是 L 碰到止盈就算同一根 K 线内止盈。可是急涨插针那根 K 线，价格多半是从下方先到 L、再冲到 H。急速组的做空单里有 32%/49% 是同K止盈，普通单只有 1.5%/4.5%，被高估的正是这部分。
- **有效路径**：按方向、按"是否同K止盈"拆开看：
  - 做多：同一根 K 线内止盈必须收盘价高于止盈价，收盘一定发生在最低点之后，所以和顺序假设无关、可信。急速组做多两段仍是胜率 47%/46%、+180/+60bp，比随机好 +116/+71bp。
  - 做空：要等框架按不利顺序重跑才能下结论。
  - 同时要记住：成交后的后续 K 线里，O-H-L-C 让做多先碰止盈、做空先碰保本，方向偏差正好相反。
- **通用规则**：凡是挂单入场、止盈可能在成交那根 K 线内触发的研究，先按方向统计同K止盈的占比。占比明显高于平均时，要么用不利顺序（做多 O-H-L-C、做空 O-L-H-C）重放，要么只在收盘价越过止盈的情况下才认可同K止盈，不能直接采信。
