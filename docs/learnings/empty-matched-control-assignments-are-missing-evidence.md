# 空匹配对照分配不是自动胜出

- **问题**：策略门要求在每个确定性 matched-control 分配中都胜过随机入场，但实现若只遍历实际存在的分配，零配对分配会被静默跳过，剩余少数分配全为正时仍可能误报通过。
- **死胡同**：用 `bool(usable) and all(...)` 检查“所有可用分配为正”。这只证明已观察子集，没有证明预注册的全部分配均有证据。
- **有效路径**：从预注册读取应有分配 ID 集合，逐个生成结果；零配对明确记为缺失，并要求分配覆盖完整后才计算“全部为正”的通过标志。
- **通用规则**：任何 `all()` 型实验门先核对期望集合与实际集合完全一致；缺失单元属于缺证据，不能用真空真值或过滤后的子集替代。
- **牵连**：`scripts/research_15m_ma_launch_l2_global_context.py`、L2 primary gate、matched-control 报告表与确定性分配数量。
