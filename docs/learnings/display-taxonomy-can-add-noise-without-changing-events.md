# 增加显示分类也可能增加交易图噪音

- **问题**：V4 没改变原信号，却为每个原事件添加“观察、参考升级、补充观察、补充确认”等解释，用户仍看到满图提示，难以分清是否需要再次开仓。
- **死胡同**：把较浅颜色和更细的分类当作简洁。文字数量没有减少，分类本身还需要用户学习；已有风险参考也不能证明新候选一定重复。
- **有效路径**：默认层只显示每段参考的起点及其所属确认，全部原候选放在完整模式与数据窗口核对。确认仍在真实当前根显示，不能将后来通过的信息回填起点。说明隐藏仅是显示选择，不是已经过滤了亏损信号。
- **通用规则**：先控制默认图面需要解释的对象数量，再考虑配色和分类；把研究诊断留在可选层。UI 简化、事件过滤、交易管理要分别给出证据。
- **牵连**：`spike_burst_v4.pine` 的默认标签、主/副图事件点、面板；原 V3 事件、风险和三条警报字节保持。默认历史文字仍受平台标签上限影响。
