# 高周期时段匹配不足时，缺失的检验不能被当成通过

- **问题**：六周期同一ICT时段、同UTC月/纽约小时/周末/波动桶匹配，在低周期能配齐5个随机入场，但4小时共同窗仅一笔交易且配不齐5个。
- **死胡同**：看到一笔盈利的100%胜率就排名，或把部分匹配均值混充完整对照，会把小样本、严格匹配和缺失值变成虚假的确定性。放宽匹配条件只为拿到漂亮p值又改变了预先定义的对照。
- **有效路径**：逐笔记录完整/部分/目标删失与重抽原因；完整匹配0笔时随机均值、超额和p都明确不可用。真实净收益仍完整报告，不因没有控制而丢弃交易；较长历史5笔仅2笔匹配也披露分母。
- **通用规则**：样本数、对照覆盖率和盈利集中度先于胜率排行。无法检验的配置保留为证据不足，而不是获准实盘或被判定没有效果。
