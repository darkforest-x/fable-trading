# 换入口均线时，旧对照资格不能原封不动继承

- **问题**：V26把SMA40入口改为VWMA40，母单251变288；原V10背景表同时含SMA贯穿排除、旧251时钟排除和5m源已知性，不能当通用背景表。
- **死胡同**：直接拿旧248组三控，或只换母单ID，会让对照仍受旧参考筛选。把所有旧颜色一起换成VWMA又会偷偷改变小周期退出上下文。两种捷径在源码审查时排除，未作为实际经济实验运行。
- **有效路径**：先精确UTC对齐并证明旧SMA全特征与共同OHLCV/ATR不变，再只重建1h MA/侧别/斜率/贯穿和新母时钟排除。原entry OPEN、raw段与5m SMA证据逐字段保留；旧1h参考用前缀隔离。V27获得284/288完整三控，但容量见证仍不是随机经济样本。
- **通用规则**：换参考先逐列区分“入口定义”“匹配资格”“退出可用性”；重算前两类的依赖项，第三类保持原语义。统计摘要里写死的旧251/226门也必须显式改为新288/260。
- **牵连**：`yoyo/evaluation/hourly_impulse_vwma_background.py`、V27配置与冻结V23三键图；这里只证明原5m已知性，不证明V18原生15m管理初态或可执行收益。
