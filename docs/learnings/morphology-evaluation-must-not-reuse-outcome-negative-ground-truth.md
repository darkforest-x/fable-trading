# 形态验收与收益评估必须使用各自合法的标签

- **问题**：纠正训练负例后，如果仍把完整候选池的非盈利事件当作空框真值去算 mAP，评估会继续奖励同一个语义错误。
- **死胡同**：仅换训练目录或类别名，沿用收益标记生成的验证空标签；这样一个识别到真实密集形态的框仍会被错误计为误报。
- **有效路径**：形态验证/测试改用有形态依据的正例和背景，按时间分别统计定位命中与背景误报。旧完整候选池只用于推理，预测完成后再联结未来收益及冻结的匹配随机入场对照；旧候选池里的亏损事件不参与形态误报计数。
- **通用规则**：训练语义变更时，顺着标签谱系审查训练、验证、测试和交付计算，不能只修训练集。病例对照式形态指标与条件候选池收益指标分别解释，均不能冒充实盘泛化。
