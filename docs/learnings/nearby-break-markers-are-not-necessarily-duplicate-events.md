# 相邻突破标记不等于重复事件

- **问题**：ONE 同一段上涨连续出现三个突破标记，画面像重复提示。
- **死胡同**：直接按时间去掉两条事件，会把不同 A/C 产生的真实不同斜率线误当重复，还会改变后续配对。
- **有效路径**：先核对 UID、A/B/C 与 raw/soft 来源；三条共用 B，但 A 不同、最后一条 C 也变了。仅在显示层将同 B 附近事件聚合，明确计数与代表线，提示保留每条锚点和时间，联合/报警保持原始事件。
- **通用规则**：视觉降噪与信号去重是不同操作；聚合标记必须解释成员与代表对象，不能把后来更好的线回填到首次信号时点。
- **牵连**：Pine V12 drawing history 的对象寿命、提示信息、八根显示分组窗口与首次几何；不涉及交易阈值。
