# 交易所杠杆与账户名义仓位必须分开约束

- **问题**：独立模拟 App 同时需要交易所 100x/20x 杠杆与账户 10/5 倍名义仓位上限，两者不能共用一个字段。
- **死胡同**：把 10/5 写成下单杠杆会改变需求；只限制单笔名义金额会让多币种、挂单和并发请求叠加绕过总量。沿用逐仓的“单仓保证金必须大于风险”检查，也不能表达全仓模式。
- **有效路径**：风险预算决定数量，再以所有持仓和挂单的归一化总名义额度裁剪，预留入场费和不利价差；成交前在同一 SQLite 事务中复核。旧账本明确解析为旧规则，新默认通过已有等待期生效，不暗改历史。
- **通用规则**：先分清配置杠杆、保证金模式、名义金额/净值及现金风险，再分别校验；说明开仓时限额无法保证行情变化后比例始终不超限。
- **牵连**：`yoyo/discipline_app/policy.py`、`book.py`、`tests/discipline_app/test_service.py`。仅模拟，未实现真实强平模型或实盘授权。
