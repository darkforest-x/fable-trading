# 延后入场必须按确认时刻排仓，并重算真正承担的风险

- **问题**：在SPIKE原信号后等待回踩再突破，不能直接过滤旧成交表。确认晚的旧信号可能被确认早的新信号占仓；延后价格也改变了止损距离。
- **死胡同**：沿原信号顺序挑交易会让尚未确认的机会抢先占仓；沿用旧R会把等待期间的涨幅算成可获得优势；用“原赢家也重新入场”当高R保留会掩盖追价后的缩水。
- **有效路径**：固定锚点、分bar因果阶段，按确认close→原锚点排序并在真实次开入场。保留原绝对stop，按新entry计算初始risk并重新应用原2R/4ATR退出。另列原锚点风险单位、追价代价和重新入场后仍达高R的交集。合成测试独立验证时间与风险，不先挑市场收益。
- **通用规则**：任何“先等确认”的研究都要同时重做成交时间、风险分母、占仓时序和随机对照的观察协议；无确认请求不能静默丢失或重新抽样。确认几何是否提高收益仍是待检验假设。
