# 未达收益目标不授权清空形态检测框

- **问题**：Owner 发现 MA3R 重做数据集的负例仍大量呈现均线密集。7824 个训练负例来自已经命中规则的候选，只因 SL/TIMEOUT 被写成空标签；其形态实际未判定。
- **死胡同**：把类别改名为 `profitable_dense`、在报告注明“非形态负例”、通过哈希与时序检查，并不能取得把 Owner 的形态检测任务改成收益筛选任务的授权。此前“补齐训练负例”的修复只补了数量，仍未修正语义。相似外观可以是难负例，但必须有可见的形态不成立依据；不能用未来收益代替该依据。
- **有效路径**：停止该 A/B 训练，保留历史数据和已产出权重作为被否决实验；把形态是否成立、核心边界和交易结果拆开。当前候选先恢复为形态待审状态，而不是反向批量改成正例。训练、验证、测试须执行同一标签语义；已确认形态不能因交易失败被清框。3R 盈利筛选可保留为独立事件属性与后续经济判断依据。
- **通用规则**：开训前逐类检查“为什么这张没有框”，不能只检查空标签数量。收益非赢家必须具有独立、适用当前形态协议的负例证据，才能进入检测背景；未判定者隔离。全图存在其他目标时也不能写空标签。难负例审核记录必须指向决策时点可见的具体差异。
