# 重叠事件盈利不能替实际账户通过收益门

- **问题**：趋势研究最初用开发/验证事件净均值验收盈利，没有要求同币单仓现金组合也盈利。
- **死胡同**：事件都按正确下一open及止损结算，并不意味着能同时买下它们。一次长持仓会挡住后续候选，未成交的赢家仍可抬高事件均值。独立复核的合成例子出现事件均值+613.33bp而实际账户约-0.03%。
- **有效路径**：把“选时研究事件”和“实际接受的持仓”分开计数；资金账本按现金约束和占仓筛选。研究门同时要求两折实际组合净收益为正，并用明确正事件/负账户的反例防回归。
- **通用规则**：声称策略可以盈利之前，先检查验收谓词读取的是可执行账户曲线，还是允许重叠的事件标签。
- **牵连**：`yoyo/evaluation/altseason_trend_research.py` 的 `gate_verdicts`；`tests/test_altseason_trend_research.py`。研究协议冻结前修复，未依据真实收益调参。
