# 账户胜率按完整仓位生命周期统计

- **问题**：账户支持加仓和分批平仓后，成交笔数不等于交易次数；展示层最近 500 笔成交与压缩后的资金曲线也不足以支持完整统计。
- **死胡同**：逐条平仓成交计算胜率会把一笔仓位拆成多笔，忽略开仓费则会把小幅毛盈利错误分类为盈利。用当前浮动权益计算历史回撤，或从压缩曲线反推最大回撤，也会改变指标含义。
- **有效路径**：在同一数据库读事务中读取账户全部成交和仓位。只有剩余数量精确归零的仓位进入胜负、平均盈亏及持仓时长；按 position_id 汇总生命周期全部毛收益减全部费用。账户已结算净收益另按全部成交汇总，保留未平仓仓位已产生的收益与费用。余额回撤在完整成交序列上逐事件累计高点，计算后才压缩展示曲线。
- **通用规则**：先定义统计单位与分母，再做卡片。持平计入已完成交易，零交易不显示虚构胜率，无亏损不输出无穷大比值。明确区分平均盈亏比和盈利因子，以及余额回撤和浮动权益回撤。
- **牵连**：`paper_desk_analytics.py` 的账户历史响应新增 lifetime statistics；前端统计独立于日历月份与曲线区间。194 项模拟交易 Python 检查及 100 项前端检查通过，三个正式账户只读金额对账通过。额外全仓门禁有 8 项失败，涉及规则文档、旧路径和产物登记字段，非本次统计模块变更。
