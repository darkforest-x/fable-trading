# A blank Stitch frame can be a paused browser document

- **问题**：2026-10-25 本次设计生成调用在 300 秒超时，列表仍为 185 张；网页刷新后画板内框停留在 about:blank。
- **死胡同**：重复读取空白 DOM、刷新或直接打开内框 URL 都无法证明生成状态；直接打开内框还因缺少父窗口通信而失败。
- **有效路径**：CDP 明确返回正在处理暂停的文档响应。关闭本任务临时页、重建控制会话仍未恢复；通过原生 Chrome 取消本任务的调试连接后，正常重新加载原项目，画板和本次完成日志出现。随后官方 MCP 列表变为 186 张，直读获得 b845bc7cedc348af88c7223b08929c3d 和 HTML/图片。
- **通用规则**：把生成、索引同步、网页加载三个状态分开检查。浏览器工具卡住文档时先修复本任务连接；不能将空白画板当作生成失败，也不能跳过明确的安全或权限拒绝。本次没有安全拒绝、没有禁用浏览器保护或扩展。
- **牵连**：docs/design/stitch-20261025-compact-charts/；[索引缺失不代表失败](generation-list-absence-is-not-generation-failure.md)。
