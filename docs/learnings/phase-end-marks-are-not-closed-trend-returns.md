# 数据尾端估值不是已完成的趋势收益

- **问题**：日线趋势策略在固定评估截止日仍可能持有 runner。若直接用截止日收盘价强制估值，
  这些未自然退出的仓位会进入均值、PF、胜率、置换检验和组合收益，看起来像完整交易。
  `exp-altcoin-1d-k1k2-early-launch-holdout-20260905-v4` 的两笔盈利正好全部属于这种情况，
  而两笔亏损全部是规则真实退出，导致收益状态与退出完整性完全混杂。
- **死胡同**：把 phase-end mark 当作普通 `timeout`，再用最大持有期、回测结束或
  “反正当前浮盈很大”解释它。这样会系统性奖励持仓更久、样本更靠近数据尾端的规则；
  延长 runner 甚至能在没有多一笔闭合交易的情况下改善 PF。
- **有效路径**：把交易拆成 `closed_by_rule`、`closed_by_max_horizon` 和
  `open_mark_to_market` 三类。开放仓位可以单列账面风险、MFE、当前捕获 R 和组合敞口，
  但不进入闭合交易的 PF、胜率、收益显著性或通过门。若需要给 runner 完整信用，必须在
  打开评估窗前预注册足够长的标签尾窗，并保证每个入场都有完整退出观察期。
- **通用规则**：**评估区间结束不是交易规则。** 固定窗口趋势实验必须先定义可判定集合；
  只有在同一预注册规则下已经自然退出或走完整最长持有期的交易，才是 completed return。
  右删失样本单独报告，不得与已完成亏损同表算胜率和 PF，也不得拿 mark-to-market 通过验收门。
- **牵连**：趋势 runner、最长持有期、walk-forward 折末、组合回测、匹配随机对照和
  permutation 都受影响。下一轮日线 K1→K2 必须先做源覆盖与尾窗 preflight；若最后一个允许
  入场日无法获得完整 90 日观察，就应前移 entry cutoff，而不是事后按最后收盘价结算。
