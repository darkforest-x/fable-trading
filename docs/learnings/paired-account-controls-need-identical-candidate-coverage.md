# 账户对照必须先对齐可匹配的候选集合

- **问题**：同币同周同波动桶的随机对照并非每个信号都有，尤其4H排除候选前后12根后，仅约20%—34%可匹配。完整策略账户与较小随机集合的账户比较，会混入候选覆盖、现金占用及持仓竞争的差异。
- **死胡同**：只报告全策略收益减随机账户收益，或因为事件层已经逐笔匹配，就认为账户层也自动公平。独立持仓约束会改变后来能成交的候选。
- **有效路径**：原完整账户保留；再用固定第0个有效控制的matched_event_id取原始策略交集，严格一对一，双方分别执行同一现金簿。不重新抽随机、不按收益选样本，同时报告覆盖比例。跨月匹配可能落在同周分界两侧，需区分日历NAV和入场批次。
- **通用规则**：先问“对照两边是否从相同机会集合出发”，再看净值差。配对子集结果不能外推缺匹配部分；匹配可用性本身就是条件选择。
- **牵连**：`yoyo/evaluation/altseason_paired_portfolio.py`。本轮4H密集突破完整账户约+14.06%，同候选配对子集约−3.20%，因此好看的完整账户收益不足以证明信号优于随机。
