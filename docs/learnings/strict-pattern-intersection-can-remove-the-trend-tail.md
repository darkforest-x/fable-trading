# 严格形态与既有信号相交，可能把大行情一起筛掉

2026-09-23：将训练选图的冻结形态硬条件加入原始SPIKE，638币15m候选51370→59，完整相似度后只剩6。硬条件全期+37.82R看似很好，但FIL与MINA在同一时刻的两笔贡献+44.11R；后段37笔平均−49.06bp，原版−10.15bp，后段原有134笔>10R全部丢失。

这不是“条件越多越精确”的证据。训练精选先要求收拢且已展开5根，SPIKE则有自身触发时钟。两者必须在同一根同时成立，会极度收窄事件集合；加未来3R标签更不能修复实时入口。少交易令总亏损减少也不等于每笔改善。

可复用方法：先写清核心、确认、原指标三种时间，分开密集单特征/全部硬门/参考质量，完整重放串行持仓，检查共同入场的结果是否一致；并列报告时间分段、匹配随机、稀疏样本及原大赢家保留率。全期好结果先查贡献集中度和跨币同一时刻聚集。

适用边界：这只否定当前同时取交集接法的通过资格；没有否定全部周期或状态保持接法。3笔/6笔不能证明规则总体胜率为0。本轮不改默认指标、不升级生产资格。
