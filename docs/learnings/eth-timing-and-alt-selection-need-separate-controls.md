# ETH 的局部反弹与山寨选币优势必须分开验证

- **问题**：ETH 1H 绿勾在2026年10月的5次信号中，固定持有16h有4次扣费盈利，看起来能作为山寨做多时机；需要判断是否能提前选出更值得买的币。
- **死胡同**：只看截图中的反弹，或事后列每次涨幅最大的山寨，都没有检验可执行规则。按2023—2024选出的高beta组合，全期均值仍为正，却在2025与2026两个后续年份都为负；只报全期会隐藏失效。
- **有效路径**：锁定ETH收盘信号、下一小时开盘成交、16h退出和20bp成本，把择时对照（同币同月/时段/因果波动桶随机时间）与选币对照（同刻可选山寨池等权，即随机3币期望）分开。52币固定池内冻结6个过去数据排名规则，早期选出后评价后期。ETH全期294次净胜率46.60%；优选高beta后期175次均值−0.1076%，相对同刻山寨池超额的95%区间跨零。完整保留10月7日ETH−4.43%、组合−5.96%的失败点。
- **通用规则**：先问“信号是否改善同一币的后续收益”，再问“选币是否改善同一时刻的市场收益”。价格曾反弹、16h到期盈利、超过市场和可承受回撤分别统计。展示当时规则生成的名单，不把事后赢家或当前存续池伪装成当时全市场。
- **牵连**：`yoyo/evaluation/eth_h1_alt_selection.py`；`experiments/active/exp-eth-h1-alt-selection-20261020-v1/`；54合约历史池及同源近期补齐。事件独立重叠，不是账户收益；无止损，不定义R；固定存续池、未计资金费和容量仍是限制。随机时间缺配对时，必须用相同配对集合计算均值差，不能把全组信号均值与子集随机均值相减。
