# OHLC开盘触发必须先于盘中止损优先规则

- **问题**：空单100入场、止损110、止盈90；后一根85开盘后升到115。开盘已经触发止盈，OHLC内核若在整段O-H上先检查止损，会错误选择后来到达的110。
- **死胡同**：仅把K线拆成O-H、H-L、L-C仍不充分，因为第一个段的开盘点和其后移动有先后关系；普通同K双触夹具没有覆盖开盘已经越过另一障碍的情况。
- **有效路径**：最小两根夹具复现。原生内核找到首次触发段后，先用VectorBT的get_stop_price_nb检查该段是否有开盘已触发的固定目标，再交Portfolio记账。对已计算结果只核对空单首段止损的真实开盘价，并仅将确受影响的独立交易交回修正后的框架；保留原账本与修正收据，不重放无关交易。
- **通用规则**：适配OHLC框架时，至少分别覆盖开盘越障碍、盘中单触、盘中双触和入场同K触发。框架默认优先级不能覆盖明确的开盘先后事实。
- **牵连**：`monday_vectorbt_engine.py`、`monday_vectorbt_open_audit.py`及对应回归夹具；参数网格、交易规则和费用保持原样。
