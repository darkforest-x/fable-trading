# 上级均线减少累计亏损，不等于改善单笔交易质量

- **问题**：Owner在ETH5m逆15m结构的空单复盘后，要求验证15m哪条线最适合过滤5m多空。单例中SMA120/EMA120都能挡空，不能据此选生产参数。
- **死胡同**：只看能救回那笔截图，或从后段/全历史最高值追选；只报累计亏损减少，也会把少交易误当成每笔更有优势。把EMA20与SMA20的长度相同当成跨周期等价也不成立。
- **有效路径**：固定29币与20bp成本，六条线加无过滤，各自完整双向串行回放；仅用已完成15m，与所有线共享预热时钟，前段选线、后段验证并带同币/同向/同月/同波动随机对照。
  - EMA20放行11943/11943原始候选，SMA20只拒绝6个，实测几乎不增加方向约束。
  - 前段选中SMA120，后段闭合4263→3339笔，累计净−923.96→−785.21R；但单笔净−17.63→−18.72bp，单笔表现变差。
  - 后段差值+138.76R，月块95%区间[−173.47,+361.13]，p=0.203125；29个原10R赢家只保留23个。未通过固定验证门。
  - EMA120后段描述性第一（−740.85R）且全期最好（−1695.17R），仍亏；它不是前段预选赢家，不能追认。ETH子组EMA120前后段R相对最好，但后段−16.33R与+23.60bp/笔异号，揭示风险/名义权重差异，不可只选好看的指标。
- **通用规则**：先定时钟、完整状态回放、开发选择和后段裁决；同时看总净R、单笔名义收益、漏掉的赢家与匹配对照。能过滤明显逆向单，只证明规则有作用，不证明它使策略可交易。
