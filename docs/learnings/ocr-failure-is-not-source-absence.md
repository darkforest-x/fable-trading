# OCR 读不出的表格，不等于原书没有这些数据

- **问题**：任务 #56 深化《Studies in Tape Reading》时，草稿因 PDF 196 的横置表格 OCR 混乱，将每笔股数与费用归为缺项。
- **死胡同**：继续解读 OCR 或用“无法核实”盖过图表，会把提取失败写成原书缺失。增加文字篇幅不能修复证据层的错误。
- **有效路径**：回到 PDF 195–196 的扫描图；将 196 页旋转渲染后，逐项确认 100/200 股、合计 2,700 股及原表汇总。11−7/8−3⅜−1/4=6½ 与印刷结果一致；原页只写 11 月 22、23 日，不能补年份。仍保留真正缺项：样本选择、逐笔费用分配、账户净值与盘中风险。点数不冒充现金或收益率。
- **通用规则**：图表无法从文字提取时，先检查原扫描的方向、清晰度、表头和单位，再区分“源数据缺失”“尚未提取”和“提取后无法调平”。复算和图像核对均不能替代交易有效性验证。
- **牵连**：`yoyo/monitor/static/trading-books.json`、`trading-book-figures/wyckoff-tape-1910-196.png`；图片仅旋转原扫描页，未补画缺失内容。测试：`node --test tests/monitor/frontend_trading_books.test.cjs`。
