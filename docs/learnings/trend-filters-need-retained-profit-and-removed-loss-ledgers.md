# 趋势过滤器要同时核对保留利润与移除亏损

- **问题**：用户认为零轴密集启动能拿大趋势，平均收益或低胜率结论没有指出完整系统中缺少哪一环。
- **死胡同**：只比较筛后PF，或将所有低胜率趋势策略判为无效。也不能为了一个被删大赢家临时改阈值。
- **有效路径**：固定同一批启动与退出，比较原赢家利润保留率和原亏损金额过滤率。现成六MA宽度≤3 ATR且交织≥2使ETH4h2025保留全部赢家、过滤约27%亏损金额；删最大赢家后净均值仍约+0.69%。同时BTC2024约55.19%赢家因为宽度3.33被删，否定跨币自动迁移。匹配同市场状态随机对照后收益归因仍需收缩。
- **通用规则**：筛选效果至少拆为误删赢家、过滤亏损、匹配超额、尾部依赖四项；前两项是事后诊断，绝不能被编码为入场特征。保留跨年、跨币反例，不能从正收益直接跳到可执行账户收益。
- **牵连**：`yoyo/evaluation/imacd_ma_mtf.py`，`yoyo/evaluation/imacd_ma_mtf_report.py`及V3完整账本；研究不修改生产阈值或成本，不promote。
