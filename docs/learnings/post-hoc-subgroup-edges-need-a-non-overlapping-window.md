# 事后切出来的子组优势，要换一段不重叠的时间再看一遍

- **问题**：SPIKE V12.9 在 OKX ETH 5m（2024-02 至 2026-10）上，整体扣成本后亏损，但切到空头时，相对匹配的随机做空高出 +36bp（CI 13.9~61.5，p<0.001），前后两半时间也都为正，看上去像一个独立的优势。
- **死胡同**：「两半时间都显著」并不等于复现了：两半来自同一个市场阶段、同一家交易所，而且「空头」这个子组是在 4 个分组 × 5 个时间窗都看过之后才挑出来的，本身就有多重比较的偏差。如果就此汇报「空头有效」，下一步就会围绕一个可能只是噪声的子组去优化。
- **有效路径**：没有新跑实验，直接读现成的币安 ETH 5m 五年账本（`exp-spike-manual-system-20260925-v1`，规则相同、对照方法相同），只看和 OKX 区间不重叠的 2021-09 至 2024-01：空头超额 +0.3bp（p 0.48），平均 -0.44R。同期的币安 2024-2026 段也只有 +14bp（p 0.14）。结论降级为「本区间的线索，没有复现」。
- **通用规则**：结果里冒出某个子组（方向、时段、币种）显著时，先找一段不重叠的历史窗口（最好换一家交易所），用同一规则、同一对照再算一遍，复现了才能叫优势；同时说明这个子组是在看了几个切分之后才挑出来的。
