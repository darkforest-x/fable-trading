# 状态探针的第一根必须有明确的历史起点

- **问题**：Pine 原生状态探针在“第12根蓄势合格”处失败；生产逻辑依赖前根ATR，而合成夹具第一根没有历史值，实际只累积了11根。
- **死胡同**：把断言失败直接归咎于生产状态机，或者移动期望值却不检查所有路径的时间对齐。
- **有效路径**：保留失败证据，给夹具增加一根明确的预备K线，场景与断言共用同一偏移；保持生产状态代码逐字提取，在TradingView实际执行35条断言。
- **通用规则**：验证使用历史引用的状态机时，先声明首个可用时刻和预热区间。生成探针不等于执行通过；修改夹具后必须重新编译、应用并读取图上结果。
- **牵连**：`build_spike_burst_state_probe.py`、独立SPIKE工程验收；没有放宽生产条件。
