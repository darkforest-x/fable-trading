# 反复生成的工作区差异清单会挤占运行数据库空间

- **问题**：清理旧临时清单后磁盘再次耗尽；市场监控与其他 SQLite 写者共享这个卷。约 100 MB 的 `tmp.*` 清单仍每隔几十秒出现。
- **死胡同**：只释放少量空间能短暂恢复数据库，但不能据此说磁盘问题已经根治。删除数据集或交易账本也没有必要。
- **有效路径**：核对时间序列、完整 NUL 分隔路径格式与文件占用。现场进程参数确认清单由 Codex 的 `codex-workspace-diff` 工作区差异采集流程生成；仅清理超过一天、无人打开的 62 份可再生路径清单，释放约 6.28 GB，并保存路径、大小和 SHA256。未修改应用本体，也未将持续生成问题标记为已解决。
- **通用规则**：数据库 I/O 故障应沿“剩余空间—增长目录—生成进程”排查。缓存清理是恢复手段；停止异常生成才是长期修复，二者必须分别汇报。
