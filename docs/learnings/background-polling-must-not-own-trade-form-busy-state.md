# 后台轮询不能占用交易表单的忙碌状态

- **问题**：行情每 5 秒刷新时若复用下单 busy 状态，按钮会周期性变灰，妨碍选币和填写委托价格。
- **死胡同**：只把“忙时不处理点击”改成“忙时禁用按钮”，解决了反馈不一致，却没有解决轮询抢占用户操作。
- **有效路径**：后台读取使用独立 refreshing 状态，不禁用表单；响应到达时若用户已开始报价预览、展开搜索或编辑表单，则跳过本次渲染。主动刷新和提交继续保留明确的 busy 反馈。
- **通用规则**：周期性读取不能取得交互锁；异步结果合并前重新检查用户是否进入了更新的交互状态。
- **牵连**：`yoyo/monitor/static/paper-desk.js` 和 `tests/monitor/frontend_paper_desk.test.cjs`；回归检查覆盖轮询在途期间发起预览、迟到响应不能清除确认面板。
