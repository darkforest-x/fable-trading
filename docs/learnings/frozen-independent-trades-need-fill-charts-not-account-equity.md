# 独立交易回测应先画成交图，不能套用账户收益图

- **问题**：Nautilus 已有交互可视化，但当前研究用 frozen account 隔离重叠交易资金约束，默认账户曲线不能表达独立 R 收益。
- **死胡同**：直接把 R 当作百分比输入原生复利曲线，或把冻结账户余额当成策略净值，会改变收益口径。原生成交悬停默认两位小数还会把 PEPE 显示为零。
- **有效路径**：复用原生 bars-with-fills 模板，以已保存的真实 native fills 和源 K 线提供只读视图；只修正微价格式和交易身份、最终 R 提示。明确区分成交方向、持仓方向、5m 收盘事件时间及事后交易结果。
- **通用规则**：可视化前先核对账户模型、收益单位和时间语义；已有模板不代表其默认统计适用于当前研究。
- **牵连**：`yoyo/evaluation/range_native_preview.py`；既有 `nautilus_independent.py` 的 frozen account 与独立重叠交易约定。
