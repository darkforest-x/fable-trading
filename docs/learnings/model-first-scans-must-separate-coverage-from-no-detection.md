# 全榜单模型扫描必须分开历史不足、无框和未经确认的检出

- **问题**：Owner要求用A模型扫描当天涨幅前20。如果把榜单每个币都硬凑成可评分图，或先规则过滤再调用模型，结果会误导为模型独立识别能力。
- **死胡同**：复用已有规则候选scanner虽方便，但会先依据close均线及后续形态筛选，既不符合A的HL2渲染也改变了扫描分母；把历史不足的窗口记成无框，则把数据不可用归为模型漏检。
- **有效路径**：冻结真实今日榜单、原生已确认K线及模型SHA；每个已收盘端点都渲染固定18/19根因果窗口，丢弃renderer为训练计算的假定核心框，保留YOLO所有原始框和零框。预热不足单独记状态。本轮60个周期流里7个缺少1200根历史，必须如实保留，不能补币或缩短预热。
- **通用规则**：模型扫描先固定“谁有机会被模型看到”的分母，再讨论模型检出。图集去重只用于显示，不把重叠窗口冒充独立事件；日内历史检出与最新窗口检出分列。保存PNG可以重编码，输入PNG字节SHA与保存文件SHA必须区分，并用解码像素证明两者内容一致。
- **牵连**：`yoyo/data/ma_gainers_inputs.py`、`yoyo/evaluation/ma_gainers_model_scan.py`、`yoyo/evaluation/ma_gainers_delivery.py`。当前榜单回看不证明当时可选中榜单，也不能替代人工形态金标或收益评估。
