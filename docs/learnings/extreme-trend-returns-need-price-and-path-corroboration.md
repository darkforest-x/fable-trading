# 极端趋势收益先核对报价和持有路径，再判断是否有策略优势

- **问题**：外部215币池年初1H组合出现+13.3%与+20.3%的大数，但事件均值在移除前三赢家后转负。RAVE一笔模拟交易超过+2700%／+4300%，BEAT超过+1300%，必须先怀疑单位、行情拼接、退出时钟或前视错误，不能直接宣布捕获了稳定大趋势。
- **死胡同**：只检查“退出价÷入场价−成本”仍不够；同一份错误价格能让收益算式与回测账本一起自洽。反过来，看到数值夸张就删除赢家也不成立，那会按已知结果改变样本。本轮的算术对账只作为第一层，未被当成价格真实性或策略有效性的证明。
- **有效路径**：冻结原案例与配置后，对九行结果依次检查源文件哈希、15m时间连续性、相邻open/前close的单位衔接、信号前缀、2ATR初始止损及首个退出条件，再用五个独立OKX公共历史锚点复核最异常的RAVE和BEAT。所有锚点与缓存相同、返回confirm=1；大变动发生在连续K线内部，而不是明显倍率跳点。由此只能排除所检查的不一致，不能把少数事后选中极端案例升级为收益优势。另从已保存袖套净值确认RAVE贡献了组合大部分涨幅，避免混用单笔收益与组合贡献。
- **通用规则**：遇到异常高收益，保留原结果并先做“价格单位—可用时钟—持有路径—独立报价”交叉核验。核验通过后，仍单独报告样本选择、赢家依赖和真实成交限制。`mean_net_ex_top3`仅是去掉三个事件后的均值；不重算仓位本金、重叠约束和后续入场，就不得称为去前三后的组合收益。公共历史回查也不等于历史首次可见档案。
- **牵连**：完整证据、五个公共URL、接收时间及范围限制见[极端案例审计](../../experiments/active/exp-imacd-altcoin-transfer-20260909-v1/EXTREME_CASE_AUDIT.md)。涉及 `yoyo/evaluation/altcoin_transfer_research.py`、`yoyo/evaluation/altcoin_accounting.py`、`yoyo/data/altcoin_features.py`；参数、成本、池子及上线状态均未改变。此笔记落实既有“结果好得反常先查泄漏/bug”规则，没有修订AGENTS.md。另见[池内绝对收益不能识别beta](pool-internal-metrics-cannot-see-beta.md)。
