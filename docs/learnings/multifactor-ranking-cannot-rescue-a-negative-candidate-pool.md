# 多因子排序不能自动救活负期望候选池

- **问题**：BTCUSDT.P 15m 高召回池加入 K1→K2 关系、趋势年龄、完整 1h、波动、量价、结构动量、ETH 共振、序列形态和时段共 104 个因果特征后，LightGBM 是否能筛出可交易子集。
- **死胡同**：把“信息更多”当作“边际优势更多”。14 个预注册因子包在 2023 expanding OOF 的入选均值全部为负；全特征、K1→K2、1h、ETH 与人工共振票数都没有正折。模型仍可在某一年找到表面更好的尾部，但跨期就反转，因为它是在负期望池内重排非平稳相关性。
- **有效路径**：先固定入场事件、SMA60 runner、成本、模型参数和训练分位，只改变特征包；再要求 OOF 正折、扣成本均值、PF、时间切片、匹配随机对照和多重检验同时成立。只要原始候选池和所有主要子组都持续负，就把结论定位为“事件语义/方向/时机需重构”，而不是继续堆特征。
- **通用规则**：做多因子前先回答两个问题：候选池是否至少在某些预先定义的时间折有净正子群；新增因子是否在相邻时间折保持同方向单调性。若两者都否，优先重构事件生成和标签，不继续扩大特征维度。
