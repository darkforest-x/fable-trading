# "波动"是两条方向相反的轴；混成一个词会让归因整个反过来

**日期**：2026-08-18
**类型**：反直觉结论（回应 owner「币种波动越高越好，尤其是盘行榜单」）

- **问题**：owner 从盘面观察到"高波动的币，检测器表现更好"。
  池内数字看上去完全支持：毛收益随 ATR 单调上升 +16.9 → +44.6bp。

- **死胡同**：把它当成**一个**变量去验。只要还在问"波动高不高"，
  两条互相抵消的效应就会被搅在一起，怎么切分位都得不到稳定答案——
  这正是 `p_20260728` 里"未匹配时最好是 q4、匹配后变 q3"那个抓不住的排名。

- **有效路径**：先承认"波动"在这里指**两件不同的事**，各自单独过匹配对照：

  | | 轴 1 **水平** | 轴 2 **变化** |
  |---|---|---|
  | 问 | 这个**币**平时躁不躁 | 这**一根**比它自己近期躁不躁 |
  | 量 | 上月 `atr_pct` 的跨币排名 | `atr_pct_ratio96` |
  | 结果 | **倒 U，榜单前 10% 超额胜率 t=1.32 ≈ 0** | **cq4−cq0 胜率 +9.21pp，p=5e-5** |

  关键判断是**换裁决单位**。P2-M 已证 TP/SL 精确落在 +5.000/−2.000 ATR，
  所以 bp 必然随 ATR 机械放大，**用 bp 判这道题永远判不清**。
  改用两个免疫尺度的量——**ATR 单位收益**和**胜率**——两条轴立刻分离，
  而且方向相反：最压缩那一档的胜率**比随机做空还低 2.16pp**。

- **通用规则**：**当一个自然语言词（"波动""趋势""放量"）在 cross-sectional 和
  time-series 两个方向上都成立时，默认它是两个变量，先拆再验。**
  拆的动作很便宜：一个是"币之间比"，一个是"这根和它自己比"。
  拆完必须换到**尺度不变的裁决量**（PF、胜率、ATR 单位），
  因为把两条轴粘在一起的往往正是尺度本身。
  推论：owner 的盘面直觉指对了位置但可能记错了名字——
  肉眼在图上看到的"波动大"，很可能是**刚刚扩张**，不是**一贯很高**。
