# 经济上相等的价格不能用浮点残差定义正风险

- **问题**：V11.2 原 V9 止损锚点实验的一个随机控制产生 −1.54e13R。GALA 15m 的随机入场价是 0.00334，锚点止损是 0.0033399999999999997，风险差仅 4.34e-13 tick；20bp 成本被这个近零分母放大。实际交易最小风险为 7 ticks，没有同类异常。
- **死胡同**：只检查 `entry - stop > 0` 在二进制浮点下不足以验证真实价格距离。看原生 R 的随机超额会把坏分母造成的巨额控制亏损当成策略优势；只裁掉异常收益又掩盖了实现错误。
- **有效路径**：从异常控制 key 反查随机入场与历史锚点，复现两者的价格和 tick 差。仅把不超过 `tick * 1e-8` 的正残差视为无效锚点；合法一 tick 风险继续保留。保留 run_v1 失败实现证据，提交修复后独立重跑 run_v2，核对实际交易不变和控制覆盖变化。
- **通用规则**：出现反常 R，先同时检查净价格收益与初始风险分母，再沿 key 追到原始价格及 tick。风险有效性需要价格精度语义，不能只依赖浮点正负；对照点必须用它自己的风险分母。
