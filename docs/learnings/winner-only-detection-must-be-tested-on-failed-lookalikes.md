# 只用赢家训练的检测器必须在失败的相似形态上验收

- **问题**：把形态正例筛成历史毛3R赢家后，只用1506个赢家训练，是否就能识别未来赢家？
- **死胡同**：把“训练图过去盈利”“框定位正确”或“正例召回高”当成盈利筛选已完成。A组在完整后段验证/测试池召回均100%，但失败候选也100%触发；赢家标签定义改变，并没有自动提供区分相似失败形态的学习证据。
- **有效路径**：保持失败/超时事件进入完整时间后段评估，按不依赖真值框IoU的模型分数排序，再扣20bp往返成本并与事先冻结的随机控制比较。A测试top10净均值-28.69bp，B为-4.78bp，均未达标；不删除负面结果，也不借测试结果调阈值挽救。
- **通用规则**：后验选赢家是监督样本构造，不能当作预测能力证据。先检查失败相似形态的触发率和完整池的经济结果。难负例或L2是否改善仍需新的独立实验；本轮没有证明其中任何一种修复必然有效。
- **牵连**：exp-ma-profit3r-20260922-v1 的 evaluation_owner1500_v4 与 control_comparison_owner1500_v4；A/B各40轮，B曝光量翻倍，不能将差异归因于纯位置变化。
