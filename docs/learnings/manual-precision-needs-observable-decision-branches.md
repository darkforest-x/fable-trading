# 人工流程的精度来自可观察分支，不来自随意补阈值

- **问题**：人工交易手册写了“顺势、受阻、失效”，实际看盘时仍无法区分正常回撤与必须退出，且把任意等待根数和减仓比例当作精细化。
- **死胡同**：不断添加数字与打分，让流程看起来明确，却把待研究参数包装成已成立规则；同一行情仍可被事后解释成任意状态。
- **有效路径**：把事实、解释、动作、推翻条件和下一检查点分开；明确各周期的作用、信号事件与参考段、持仓状态优先级，以及开仓前冻结的退出合同。风险预算与可选分批作为有来源的输入，不擅自填数。
- **通用规则**：先问“同一张截至此刻的图能否得到同一个状态和动作”，再研究参数取多少。字段应能留下证据和当时时钟；工作台做不到的自动化能力不能在流程里假定存在。
