# 阅读保存失败必须保留可恢复的编辑

- **问题**：部分阅读页面吞掉 localStorage 写入异常；防抖计时尚未落盘时切页也可能丢最后一次笔记。
- **死胡同**：把按钮提示为已保存、只在控制台记录异常，或读取失败后把空对象写回旧键，都会误导用户或覆盖原进度。
- **有效路径**：笔记输入立即更新内存并尝试落盘，成功与失败分别显示；失败提供重试和兼容原格式的导出。旧记录读取失败时阻止自动覆盖，保留原键与当前编辑。
- **通用规则**：已保存必须对应写入成功；异常分支也要提供恢复路径，不能只保证页面仍能编辑。
- **牵连**：static/reading-tools.js、langlang.js、orderflow.js、rektproof.js、trading-books.js。
