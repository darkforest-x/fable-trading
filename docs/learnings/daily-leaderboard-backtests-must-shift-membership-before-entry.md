# 每日涨幅榜的成员资格必须在交易日前冻结

- **问题**：用户想验证 SPIKE V8 是否能抓住每日强势山寨币；直接按当日最终涨幅 Top10 回测会把收盘后才知道的赢家当成开盘前可交易名单。
- **死胡同**：同日排行榜会让策略只面对已经证明上涨的币，描述性收益和信号命中率都会被事后选择夸大，无法回答隔日实际能否交易。
- **有效路径**：用完整 UTC 日 D 的开收收益在 D 收盘后排名，名单只允许在 D+1 生效。排名在 D+1 00:00 才刚刚可知，不能让 23:55--00:00 的信号无延迟成交在 00:00；5m 回测最早从 D+1 首根完整 K 收盘后的信号开始。另建同日最终 Top10 覆盖表，明确标为 post-hoc 漏抓诊断，不与因果 cohort 的收益合并。
- **通用规则**：凡是横截面榜单、热度榜、成交额榜或波动榜，排名窗必须在交易窗前闭合；报告应同时写出因果交易结果和事后诊断，但不得混用。
- **牵连**：`yoyo/evaluation/spike_v8_lowtf_study.py`、`experiments/active/exp-spike-v8-lowtf-20260913-v1/`、`analysis/p1_spike_v8_lowtf_20260913.md`；规则不改变 V8、通知或订单路径。
