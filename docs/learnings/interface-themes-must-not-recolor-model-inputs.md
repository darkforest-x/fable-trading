# 界面主题与模型输入图片必须分开

- **问题**：视觉研究工作台增加浅色模式时，卡片、表单和状态文字需要一起换色，但展示的图表也是随后提交给模型的输入。
- **死胡同**：本轮未采用全页面反色滤镜；它会连图表的红绿 K 线和参考图一起变色，使用户看到的画面与实际提交的图片不一致。只换页面背景也会留下深色表单与低对比度文字。
- **有效路径**：界面采用成套语义配色，图片及图片上的标记保留独立颜色。主题偏好通过独立脚本在样式加载前恢复，兼容现有禁止内联脚本的 CSP；浏览器只保存主题选择。
- **通用规则**：视觉模型工具的主题切换只改变界面，不改变研究输入；验收需同时检查浅深两套配色、刷新恢复和图片显示。
- **牵连**：`yoyo/vision_research/static/styles.css`、`theme.js`、`index.html`；`server.py` 的 CSP 与图片输入契约。
