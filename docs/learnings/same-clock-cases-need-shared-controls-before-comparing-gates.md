# 同一时钟的事件，不能把不同随机对照造成的差值解释成确认收益

- **问题**：IMACD 箭头与 YOLO 可以同根确认，也可以相隔数根确认。要验证后续是否走出预期，必须区分原箭头时钟 p 与实际确认时钟 e，并检查等待后还能获得的行情。
- **死胡同**：只数模型过滤掉多少候选不回答后续走势；在最终获确认的事件上从 p+1 回填入场会使用当时未知的确认结果。即便已经分清时钟，如果随机种子含 `anchor_kind`，p=e 的两个相同案例仍会抽到不同控制，少量控制的均值差可能让超额符号翻转。
- **有效路径**：冻结事件全集，分别保存 p+1 与 e+1 开盘至固定终点的价格路径；不因后续失效删除案例，不给不足观察窗的事件填收益。确认后的未来图单独存放，标明模型当时不可见。对同根事件逐条核对两套结果路径完全相同，并同时披露控制样本、完整覆盖率和抽样差异。当前实验保留预注册的 confirmation 主表，不按结果换种子或挑有利副表。
- **通用规则**：新增确认机制的经济价值应以真实可行动时钟衡量。下一轮若要比较两种门的差异，先冻结共享控制或更稳定的控制汇总方案；不要把独立抽样噪声解释成等待效果。图中成功案例说明可能发生什么，全体结果与失败案例才能说明出现频率。
