# 图上近期交易争议，先交付同源同窗口的逐笔账本

- **问题**：用户用最近一两周的图质疑长历史倍投结论；继续重复长历史账户余额，无法定位分歧来自入场、止损时序、费用还是样本窗口。
- **死胡同**：把资金容量筛选后仅有十几笔的账户结果，拿来代替用户要求的近期所有V8交易；即使账本算术正确，也没有回答用户要核对的对象。
- **有效路径**：先确认交易所、北京时间截止和最后完整K线；冻结规则后补齐同源数据。原始单仓状态从前史连续运行，分别交付全部V8信号、实际串行交易、未开仓原因、未平仓估值以及每根K线当时已生效的止损。每笔入场/退出再与独立回放核对；毛R与费用R分列。
- **通用规则**：对“这几天图上不是这样”的争议，第一份交付应是相同交易所与时区的逐笔价格证据，不是再次优化或重复总收益。最高浮盈所在退出bar若顺序未知，要给可辨识范围；不能把bar极值自动当作止损前可获得收益。
