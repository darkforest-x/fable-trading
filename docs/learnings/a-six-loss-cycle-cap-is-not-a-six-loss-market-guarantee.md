# 六层停止规则不能被写成市场最多连续亏六笔

- **问题**：Owner希望ETH V8倍投最多连续止损六次，并考虑在浮盈后把止损移到开仓价。
- **死胡同**：把亏损出口改名为保本、遇到保本单清零历史损失计数，或六次后暂停再重启，就声称交易序列不会七连亏。开仓价退出仍扣费，暂停后下一笔也仍可能亏；账面累计亏损没有消失。
- **有效路径**：分开定义完整初始止损、所有净亏、单轮倍投层数和本轮累计净盈亏。六层硬门能限制该轮新增交易，不能保证恢复交易后不会延续连亏。保护位和触发阈值只可能改变亏损分布，须在同成本、原始时间顺序中完整回放。
- **通用规则**：有限层数是执行规则，未来最大连亏是未知随机结果。保本按净盈亏核算，并区分单笔不亏与整轮回本；不以重置计数或少交易替代收益、参与率和损失尾部评估。
- **牵连**：`analysis/p1_spike_v8_eth3m_be_20260913.md`；原V8到1R后推开仓价的既有串行回放在开发及后段净胜率均下降。新成本保本阈值、分批止盈或固定止盈均尚非已验证方案。
