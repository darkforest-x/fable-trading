- **问题**：Liquidity Sweeps includes both a wick rejection and a breakout/retest mode; treating every event as a failed breakout reverses the interpretation of the latter.
- **死胡同**：The official Library prose calls a dashed event a failed retest, but a pattern name or marketing description does not establish executable direction. No strategy result can be inferred from the pictured subsequent movement.
- **有效路径**：Trace each stored level through the actual state transitions. In the official Library Pine v6 source read on 2026-09-20, an unbroken high swept above and closed below emits bearish; a high first closed above becomes broken, then a later low below with close above emits bullish. Low levels mirror these rules. Verify event time separately from the old pivot anchor.
