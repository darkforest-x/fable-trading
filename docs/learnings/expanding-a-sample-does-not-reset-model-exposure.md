# 扩大币池不能重置同一模型已经接触过数据的事实

- **问题**：BTC／ETH的1H、4H小样本不足，扩大到54币和更长日期时，需要区分新增证据、重复事件及模型原验证期。
- **死胡同**：给扩大评估另起一个实验ID，再把它称为“第1次holdout”或“半年独立样本”。实验目录不同并没有改变权重、阈值和已经看过的市场事件；训练截至某日也不等于模型验证／选择没有看到之后的数据。
- **有效路径**：先冻结旧池全部来源和扩大起止，不按新结果挑币；从训练manifest确认train及val可见时间，按时间分别统计，确认窗口和入场观察在分界处截断。报告明确同一1H／4H配置各第2次holdout评价，并把旧BTC／ETH14候选按event_id联结对照。未完成完整等待随访的边缘候选保留为censored，不算过滤失败。
- **通用规则**：增加样本前先回答“哪些是模型已验证过的时间、哪些是本配置重复事件、哪些是新覆盖”。计数以模型／规则配置和实际接触记录为准，不以实验文件夹编号归零。
- **牵连**：`experiments/active/exp-imacd-yolo-expanded-20260908-v1/PROJECT_PLAN.md`、`yoyo/evaluation/imacd_yolo_expanded.py`、旧timeframes实验及Grade-A训练manifest。扩大覆盖只加强已声明检验的证据；确认数量不自动变成收益或去噪证据。
