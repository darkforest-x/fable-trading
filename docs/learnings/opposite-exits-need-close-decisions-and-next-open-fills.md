# 反向信号平仓必须在信号收盘决定，下一开盘执行

- **问题**：把用户Stoch反向信号加到V8退出时，容易用下一根价格筛掉亏损退出，或让收盘信号抢在同根已触发的止损前成交。
- **死胡同**：先看下一根开盘是否盈利再决定上一根是否发退出；或把副图箭头和WVF过滤后的警报当作同一信号。前者引入一根未来信息，后者会改变空仓的离场时点。
- **有效路径**：先按当前bar的既有保护处理止损；未止损才在收盘判断反向箭头和当前扣费净R，下一根开盘执行。开盘穿越保护仍优先记止损，原V6反向退出保留既有优先级。图形多头信号不要求WVF，买入警报要求WVF绿色，分别冻结对照。
- **通用规则**：信号生成时间、利润门判断时间、实际成交时间分别记录。替代指标的SMA需要保持Pine最近N个非na值的语义，不能把calendar rolling的缺失处理默认为等价。
