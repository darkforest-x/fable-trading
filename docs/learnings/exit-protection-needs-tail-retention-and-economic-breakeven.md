# 退出保护要同时检查大赢家保留与经济保本

- **问题**：ETH15m＋ICT有浮盈回吐，能否通过提前保本、分批或缩窄跟踪提高净收益，同时降低连亏？
- **死胡同**：只统计救回多少亏损单或净胜率上升。2026前4月原版前三赢家贡献21.20R，约占总净22.74R的93.2%；3ATR跟踪虽救回1笔亏损，却少赚10.72R。含费保护价按tick取整留下0.000xR，也会被严格净正胜率计为盈利，不能据此认定已经赚够回本。
- **有效路径**：先冻结8个单机制修改，开发期独立前缀选择后提交，再读取后续年份；同时比较完整串行、原入场配对、匹配随机、每笔fills成本守恒与累计债务。净2R保护在后续两段有小幅改善，但开发与连续历史更差，保留为观察而非宣布新冠军。净1R保护虽把已观测最长净亏14降到6，连续仍净亏10.58R，说明缩短连亏不是回本充分条件。
- **通用规则**：先量化原利润对少数大单的依赖，再比较救回亏损与损失尾部收益。按金额认回本，按执行语义单列含费保本；不要从exit_reason的名字推断经济结果，也不要用价格取整微盈美化胜率。
