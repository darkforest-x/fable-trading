# 成本占R过滤可能同时删除小风险亏损与大R赢家

- **问题**：ETH 3m保本失败后，固定筛选费用不超过0.5R的交易，后段平均净R从负变微正，是否已找到低周期优化方案？
- **死胡同**：把胜率从32.43%升到36.54%、合计+0.79R当作新策略盈利证明。这个门筛选的是价格风险分母；原两笔10R也都依赖较小初始风险，全部被删除，且去最佳单后剩余交易仍为-7.55R。
- **有效路径**：固定0.2%成本、不改初始SL，对照开发与后段，同时看净R和名义收益PF、尾部保留与去最佳单敏感性。52笔后段PF(R)=1.020但PF(名义收益)=0.998；ETH 3m开发、ETH 5m两段仍负。结果只能归为历史子集诊断，不能promote。
- **通用规则**：当特征和结果共用初始风险分母时，先检查过滤是否只是改变R权重；既有成交子集不等于过滤后的完整交易状态路径。成本预算应来源于可执行费用，不得为过门随意扩大SL。
