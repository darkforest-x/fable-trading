# 长跑实验必须执行已提交 blob，而不是信任共享工作区路径

- **问题**：多小时扫描启动时已导入冻结 renderer，但暂停恢复期间另一项合法 main 工作给同一路径增加了可选参数。默认像素行为虽未变，工作区文件 SHA 已不再满足本实验预注册，直接恢复会在“回退别人代码”和“静默采用新来源”之间制造假二选一。
- **危险捷径**：忽略 SHA 继续跑、把新 SHA 直接改进旧预注册、或恢复用户文件到旧版本。它们会分别失去来源身份、事后改协议、或破坏并行工作。
- **有效路径**：从预注册 commit 直接读取 Git blob，先核对 blob SHA，再作为 Mac renderer 执行；CUDA 运行时也只由同一 commit 的逐文件 blob 构造。恢复前对 11 个月 4,964 个唯一有框输入比较冻结版与当前默认版，BGR 像素 SHA 和 `ChartTransform` 均 4,964/4,964 一致，并把隔离方式写入第二份追加协议。
- **通用规则**：路径不是运行时身份，工作区干净也不是长期不变保证。长跑、可恢复实验要把“版本声明”升级为“实际加载 commit-addressed blob”，并让本地复核、远端推理与最终 verifier 共用同一来源。
- **牵连**：共享 main、多会话并行、Mac/3060 像素 parity、断点续跑、预注册 SHA；不要求分支或 worktree，也不回退其他任务。
