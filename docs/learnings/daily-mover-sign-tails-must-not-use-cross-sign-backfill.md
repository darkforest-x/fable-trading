# 单边行情的涨跌榜缺席不能跨符号补位

- **问题**：历史每日榜固定要求严格正收益 Top5 与严格负收益 Top5。2024-11-06 的 314 个完整合约中，295 个上涨、3 个下跌、16 个零收益，合法行情本身就无法提供 5 个跌榜成员。
- **危险捷径**：用零收益或最小正收益补足 L4/L5、跳过整天、或在看到结果后换成无符号 top/bottom 5。三者分别改变“跌幅榜”语义、造成日期选择偏差、或把预注册变量悄悄换掉。
- **有效路径**：每侧独立取“最多 N 个”严格符号尾部；缺席就缺席，不跨符号、不用零收益补位、不跳过该日。把触发日的完整分布、缺席席位和失败回执写进追加协议，并先证明此前已完成分片没有同类缺席再复用。
- **通用规则**：横截面尾部配额是上限，不是市场必须满足的事实。涉及方向语义时，宁可诚实少样，也不能为固定样本数破坏类别定义；最终统计必须同时报告日数、实际席位和缺席席位。
- **牵连**：每日涨跌榜、极端单边行情、零收益合约、时间连续月扫描、候选池规模；不改变模型、阈值、holdout、标签或训练资格。
