# 回弹重抓要继承画面位置，但不能继承本次速滑距离

- **问题**：共用抽屉在减少动态效果模式下不跟手，回弹中重抓从零开始跳动。修正视觉起点后，浏览器验收又发现小幅重拖可能误关闭。
- **死胡同**：把回弹剩余位移同时当作新手势的滑动距离，会把“继承 20px 后再拖 20px”当成超过 28px 的快速下滑。减少动态效果时把 translate 设为 none，则连直接操控也被取消。
- **有效路径**：按住时读取当前渲染位置；逐帧合并位移写入，拖动期间无缓动。距离关闭依据抽屉当前位置，速滑关闭必须依据本次手指移动距离。释放后才过渡，取消归位；减少动态效果仅省略释放动画。正文与输入保持独立滚动，提交中不得启动或完成关闭。
- **通用规则**：视觉坐标与手势意图是两种状态。测试必须包括半途重抓、短促重拖、取消、输入和忙碌状态，不能只验最终关闭。
- **牵连**：`yoyo/discipline_app/mobile/src/sheetMotion.ts`、`Dialog.tsx`、`performance.css`；六类抽屉复用同一实现。`tests/discipline_app/sheet_motion.test.ts` 覆盖直接位移、减少动态效果、重抓与事件清理。
- **额外边界**：真实点击验收发现嵌在图表页面的抽屉被导航遮住；父页面的变换会建立独立层叠上下文，提高子抽屉的 z-index 无效。共用 Dialog 通过 portal 挂在 App 根节点，保留主题并脱离页面裁切；浏览器必须点击原先被遮挡的列表底部项，不能用强制点击掩盖层级问题。
