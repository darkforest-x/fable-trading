# 缩小止损后的大 R 数量，不能替代同批赢家留存

- **问题**：ETH 5m 入场止损从最近5根极值改为入场单根极值后，不保本组净20R交易从40笔增到45笔，但固定价格风险累计净R从−3747.09降至−4628.39。
- **死胡同**：只统计新方案有多少20R，会把分母缩小和新跨门槛交易误当成留住了原趋势赢家。北京时间2026-09-12 00:55空单的入场、出场价格相同，净收益仍224.4085bp，净R却从8.4843增到20.5188。
- **有效路径**：固定入场ID，只改结构窗口，保留0.05%缓冲与成本；复用旧账本，用已有Nautilus适配器撮合新增两组。原40笔净20R只有36笔留下，4笔变成初始止损，其中2026-01-31 13:30空单由净+105.27R变成−3.95R。再看相同名义本金收益与年度分段，区分退出变化、风险归一化和成本。新20R总数包含9笔新跨门槛者。
- **通用规则**：改止损后，先锁定相同入场集合和旧赢家ID，同时报告固定风险净R、相同名义本金收益、费用R、旧赢家留存及实际退出原因。成本不因价格止损变窄而降低；在固定价格风险下，增大的名义仓位会提高费用R。相对随机更好也不能抵消绝对收益为负。
- **牵连**：`yoyo/evaluation/range_entry_bar_stop.py`；`experiments/active/exp-eth-entrybar-stop-20261020-v1/`；3838信号及匹配随机，原往返成本0.2%，2024-08至2026-09已知历史。仅比较窗口5→1，不是零缓冲测试；独立R不是账户收益，没有提升默认或实盘资格。
