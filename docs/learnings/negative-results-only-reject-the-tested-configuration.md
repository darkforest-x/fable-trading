- **问题**：一次“预测路径派生六特征”的负结果容易被扩写成“Kronos 整个架构无用”，把不同接口和假设错误地绑在一起。
- **死胡同**：因为 `Kronos-only` 在旧实验 0/15 折为正，就永久否决 tokenizer token、重构残差和 causal hidden state 等从未测试过的表征。
- **有效路径**：保留原负结果不改，只把结论限定为当时的代码、采样器、候选池、特征定义和评估器；新接口必须作为新变量重新登记和检验。
- **通用规则**：负结果的外推边界由实际 intervention 决定，不由项目或模型名称决定；配置级失败不能自动升级为架构级失败。
- **牵连**：基础模型、特征消融、检测器版本、窗口设计和数据集裁决都要报告“排除了什么”与“没有排除什么”。
