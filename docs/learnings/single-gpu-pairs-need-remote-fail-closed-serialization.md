# 单 GPU 成对实验要在远端用退出回执串行

- **问题**：同一张 RTX 3060 要连续跑 960 与 1280 两个长实验；既不能并发抢显存，也不能依赖
  发起训练的 Mac 一直在线或不休眠。
- **死胡同**：先启动第一组、等人工或 Mac 本地轮询结束后再启动第二组，会把第二组是否执行绑定到
  客户端存活；直接同时启动则可能让两个 Ultralytics 进程竞争 GPU，破坏速度、显存和可比性。
- **有效路径**：先把第二组数据与合同完整校验并在 3060 上启动一个等待进程；它只轮询第一组的
  不可变 `.exit_code` 回执。仅当回执严格为 0 才进入第二组，否则写专用失败码并终止。
- **通用规则**：单 GPU 的成对长实验先全部远端落盘，再用“前序退出码为 0”作为后序唯一开门条件；
  等待发生在计算节点，且等待进程不得占用 GPU。
- **牵连**：`scripts/train_15m_ma_launch_t3_on_3060.sh`、远端 `launch_*.cmd`、
  `C:\\fable\\logs\\*.exit_code`、WMI detached process、每组独立数据目录。
