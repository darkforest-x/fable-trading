# 涨幅榜做多调不出退出；反向做空均值为正，但被轧空尾部吞掉

- **问题**：EXP-148 之后，Owner 要求研究涨幅榜币的退出方式和选币。近 3 个月共 1910 次新上榜（进入 Top10 且前 24h 不在榜），按时间切成开发段和验证段。
- **死胡同**：直接在做多方向上扫 TP/SL、跟踪止损、掉榜退出。26 种退出在两段全部为负（开发 −14 至 −89bp，验证 −31 至 −122bp），而且都不如同刻波动匹配币和同币平静时段对照。开发段选出的 3% 跟踪止损到验证段 −59bp。再按 11 个特征三分位选币，验证段 33 档全负，开发/验证排序 Spearman 为 0。固定持有 1–48h 的毛收益已经低于对照，入场本身没有正向信息，退出只能改变亏法。
- **有效路径**：先看各持有期的固定持有收益和对照，再决定是否调退出（见 [weak-entry-markouts-cannot-be-blamed-only-on-exits](weak-entry-markouts-cannot-be-blamed-only-on-exits.md)）。同一批事件反向做空，跌出 Top50 平仓（最长 48h），两段均值 +0.49%/+0.46%，胜率约 70%，超过对照 +74/+85bp。但相对 0 不显著（p .11/.24）：1% 分位约 −38%，最差 −142%/−210%，空头无止损时会亏损超过名义本金。加了止损的做空格子，在开发段又多为负。
- **通用规则**：方向性结果先报均值，同时报 1% 尾部、最差单笔和去掉最差 5 笔后的均值。做空强势币时，没有止损的正均值不能当成可交易结论，必须同时验证止损后的版本，并计入资金费。
