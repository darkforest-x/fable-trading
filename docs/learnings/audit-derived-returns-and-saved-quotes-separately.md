# 收益复算正确，不等于逐笔报价与裁决链都已验证

- **问题**：V28独立审计正确复算收益和月统计，却漏了保存的entry/endpoint报价、summary裁决与统计的连接、诊断哈希及顺序；合成把报价改负仍能通过初版。
- **死胡同**：用“独立复算通过”概括所有数据自由度，会把尚未验证的字段和时序也包装成可信。原reader仅在读OPEN前核archiveSHA，也不能反称原始读取为原子快照。
- **有效路径**：保持冻结实验不改，补端点字段和裁决/诊断链核验，保存独立audit_complete而不覆盖初版audit。另做源码先行的事后archive→保存OPEN逐值对照与前后哈希，明确只证明事后一致，不证明原run原子性。
- **通用规则**：审计声明拆成“公式”“保存字段”“ID连接”“时序”“源一致性”；每一项都要自己的反例。事后补审不得倒填成事前控制。
- **牵连**：V28 audit_saved、audit_source_prefix及其合成反例；没有重选信号/控制、重算新参数或修改原经济结论。
