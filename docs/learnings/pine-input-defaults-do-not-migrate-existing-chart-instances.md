# Pine 输入默认值不会迁移已有图表实例

- **问题**：源码把 HUD、标签和仓位框的默认值改成关闭并已保存新版本，但手机图表仍显示旧的大面板、中文标签和盈亏框。
- **死胡同**：只修改 `input.*` 的默认值并假设现有图表实例会自动采用。TradingView 会保留实例既有输入值，保存私有脚本也不等于把未挂载该源码的图表实例替换掉。
- **有效路径**：先用截图和图表指标图例区分“已保存源码”和“当前挂载实例”；对于必须消失的视觉元素，直接删除 `box.new`、`label.new`、`line.new` 渲染路径，而不是仅把开关默认设为 false。保存新版本后，现有旧实例要移除并重新添加，或在同一实例上执行更新。
- **通用规则**：Pine 视觉改版必须分别验收源码版本、官方编译、图表实例版本和实例输入状态；默认值变化不能当作实例迁移机制。
- **牵连**：`experiments/active/exp-two-key-candle-feature-atlas-v3/pine/fable_two_key_candle_sma40_retest_v1.pine`、TradingView 私有脚本版本、Basic 套餐指标数量上限和手机端图表实例；不涉及交易执行或 ACTIVE 模型。
