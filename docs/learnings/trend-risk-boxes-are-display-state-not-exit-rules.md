# 趋势盈亏框应独立读取状态，不能因取消固定止盈而消失

- **问题**：独立SPIKE爆发指标实现无固定止盈后，只剩淡色初始风险fill，用户看不到原有盈亏双框；信号当根因线读取前态而没有填充。
- **死胡同**：用保护线代替完整框，混淆了退出规则与展示需求；把3R观察框当止盈，则会违背用户拿住大趋势的目标。直接改已认证回测源还会使manifest不再对应原代码。
- **有效路径**：保持冻结源，另存同规则的显示发行文件。独立显示块读取收盘后的箭头、入场、初始止损和峰值，信号当根建框；3R标为观察位，随后扩展确认峰值，退出冻结，历史按组回收。移除显示块后与冻结源逐字节一致。
- **通用规则**：分别定义交易状态与观察图层；观察框不是委托价，也不等于已实现利润。用源码边界验证不改信号，再原生编译和截图验证可见性，不能用Python静态检查替代Pine编译。
- **牵连**：`yoyo/evaluation/pine/spike_burst_v1_display.pine`、`tests/test_spike_burst_display_contract.py`、`exp-spike-burst-risk-display-20260910-v1`。原始信号规则、宽止损、跟踪保护、副图及六均线均保留。
