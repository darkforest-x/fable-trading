# 扩充训练负例时，原验证集必须保留为固定对照

- **问题**：v6 延续训练要补 Grade-A 困难负例和三种位置图；如果同时把新增负例混入主验证集，前后指标变化就同时包含模型变化和评估样本变化。
- **死胡同**：把所有新图直接合成一个更大的 val，或把同事件三张图当成三个独立事件。这样即使 mAP 上升，也无法判断是否改善了原来的误检问题。
- **有效路径**：保留原 P9 正例及背景的像素、标签和时间切分，作为主 val/test；新增 Grade-A 留出负例单列 challenge，只评误检；P7/P11 单列同事件位置稳健性。训练集可以合入通过源版本、保护区、可见形态检查的 Grade-A 事件，旧验证事件不得回流训练。
- **通用规则**：改变训练样本组成前先冻结评估参照；新增评估人群另列，三种视图仍只算一个独立事件。空标签的依据必须覆盖可见图中的候选目标，不能只检查原中心框，也不能用未来亏损代替形态证据。
- **牵连**：`yoyo/datasets/ma_morphology_assembly.py`、`yoyo/datasets/ma_morphology_training_package.py`、`exp-ma-morphology-v6-threeview-20260925-v1/assembly_plan.json`。本轮只准备数据和运行包，不以数据检查代替真实回放验收或交易验收。
