# 分批止盈提高胜率，不代表入场已经有盈利优势

- **问题**：趋势策略的浮盈回吐确实存在，是否只需改为 1R/2R 分批兑现就能赚钱？
- **死胡同**：仅看被挽救的亏损单，遗漏同一规则从盈利单提前卖出的利润。把分批命中后的交易单独平均，依然属于事后条件筛选。
- **有效路径**：固定 111 笔 1h 入场，比较六种事先登记的真实仓位分批方案。1R 平半仓使胜率从 25.23% 到 31.53%，但平均净收益仅从 -10.76bp 到 -9.63bp，PF 仍约 0.76。必须同时核算获救亏损、被截断赢家和未达阈值交易。
- **通用规则**：落袋机制改善利润分布不等于创造信号优势；以同一批交易的扣费期望、跨时期表现和匹配对照为判断标准，而不是胜率或目标命中率。
