# 开单过滤少亏不等于留下的交易更好

- **问题**：BTC 全局均线门删掉约三分之一交易后，总亏损缩小，看起来像策略改善。
- **死胡同**：只比较过滤前后的累计 R 或回撤，会把减少负期望交易数量当成提高每笔优势。全样本挑一条亏得最少的均线，又会把市场分段差异隐藏掉。
- **有效路径**：退出、成本与风险保持不变，各门独立重放持仓占用；同时核对每笔净 R、净 bp、匹配同 BTC 状态的随机入场、被移除的大盈利单，并由前段选参数、后段验证。2026-09-22 当前 RSI7 的 15m 基线为 7,083 笔、-670.10R、-0.0946R/笔；固定 H1 SMA120 后为 4,672 笔、-552.28R、-0.1182R/笔，原 46 个 >10R 仅保留 34 个。累计少亏与每笔恶化同时成立。前段选中的 H1 SMA240 在后段也失败。
- **通用规则**：任何“是否开单”的门都先分开回答交易数量、每笔质量、总收益三个问题；减少暴露可以降低亏损，但不足以证明正期望。不要只从旧成交表删除行，拒绝旧单可能释放后续持仓机会。
- **牵连**：`analysis/p1_spike_joint_btc_gate_20260922.md`；`statistics_v1/attribution.csv` 的共享/移除/新增事件分解；`statistics_v1/selection.json` 的前段选择。结论限定于当前信号、归档、两周期和原 20bp 成本，不证明一切 BTC 状态变量无效。
