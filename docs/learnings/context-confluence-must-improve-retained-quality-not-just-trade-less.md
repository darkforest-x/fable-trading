# 共振过滤要提高留下的质量，不只是少交易少亏钱

- **问题**：趋势策略加入事前 4h 颜色和斜率后，信号更少，合计亏损也少了，容易被误称为改进。
- **死胡同**：只比较事件收益总和或筛选后的某个盈利子集，不看被剔除的交易、不匹配相同背景的随机入场。
- **有效路径**：V3 保留 105 笔均值 −16.56bp，剔除 143 笔均值 −11.80bp，留下的质量反而较差；相同 4h 背景的配对超额只有 +0.69bp。再限制追远虽改善均值，净收益和匹配覆盖仍未过门。
- **通用规则**：过滤实验同时报告保留、剔除、每原始候选贡献和同背景对照；少亏、每笔优势和可交易正期望是三件事。
- **牵连**：V3 frozen four-arm context study，20bp 成本、共同样本支持、完整三对照覆盖。
