# 刷新频率相同，不代表页面做了同样多的工作

- **问题**：市场行情与区间请求各自重建整页；YOLO 每五秒带回任务完整冻结配置，页面不可见部分也跟着读取。
- **死胡同**：只压缩 JSON 或等待请求完成后仍整体替换 HTML，不能减少解析、布局和焦点损失。只数 MutationObserver 的 root 变更，也会把一个正常区域替换误算为整页重建；跨新 K 线边界不能要求图表节点永远不变。
- **有效路径**：一次刷新收齐独立结果，按稳定区域比较原始标记，只替换变化部分。列表在 SQL 侧投影，冻结配置只走详情；版本响应和可见页签控制减少重复载荷。实测相同数据 13 个主要区域全保留；20 条任务列表从 282089 降到 11644 字节，未变响应 146 字节。
- **通用规则**：分别测网络字节、重复计算、实际 DOM 替换及用户状态保持；用同一数据窗口检验无变化路径，再检验真实新数据路径。
- **牵连**：`market-sync.js`、`yolo-detect.js`、`yolo_workbench/api.py` 与 `store.py`。不变更检测结果、巡检频率、信号和交易准入。
