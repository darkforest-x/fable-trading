# Pine 跨周期快照必须覆盖调用方的历史偏移

- **问题**：跳转日期或缩放触发重算后，12H 云带关键 K 仍在，但周区间线与参考框消失。
- **死胡同**：只在请求上下文的 islast / islastconfirmedhistory 复制数组，忽略外层为避免未收盘数据而读取 s[1]；末端状态变化时，前一个槽可能没有快照。仅检查信号标识正常无法证明绘图数据也存在。
- **有效路径**：在12H请求上下文末端三根显式创建有界深拷贝，条件 time >= last_bar_time - 2 * STEP；调用方仍只取已确认的槽，未改信号资格或确认时点。实际TV修复前图形缺失，修复后同一窗口恢复，BTC计划7.64R及确认后最高13.28R与网页一致。
- **通用规则**：稀疏快照优化必须先列出下游索引偏移，再保证对应历史槽被物化。绘图末端选择不得参与信号计算；复制容量要继续有界。
