# 显式无目标选择不能被默认预框盖过去

- **问题**：本次读取368份历史审核答案，45份勾选“无目标形态”却仍带矩形。预框自动带入时，普通提交会把未删除的框一并保存。
- **死胡同**：只要答案里有矩形就导成正例，会丢掉Owner明确的无目标选择；反过来不比较几何就批量删框，又可能掩盖Owner修改后的矛盾。
- **有效路径**：只读导出同时保存原答案与原预测。若无目标选择附带的框在类别、尺寸、旋转和几何上与原预框相同，记录为显式无目标，原预框保留在raw但不成为有效正框；如果框已被修改，则列为待核对冲突。拿不准、草稿、取消与空答案也各有状态；多答案逐条保留，不取最后一条冒充唯一裁决。
- **通用规则**：预填表单要区分系统默认值与人工显式决定，不能仅凭字段存在推断人工确认。导出的有效决定不等于训练资格，训练/金标资格仍需其余数据门验证。
- **牵连**：`yoyo/datasets/owner_review_export.py`、`tests/test_owner_review_export.py`、项目77的`no_box_reason`与`pattern`。导出不回写Label Studio；分页采集记录起止时间，不宣称数据库原子快照。
