# 盈利标签必须从完整信号可见之后开始计算

- **问题**：Owner要求筛选至少3R的盈利形态，但原Grade-A规则读核心后5根，旧图片却显示2至9根；原1043事件中44个甚至没有恰好post5的旧图。
- **死胡同**：若从核心末端计算盈利、再把已涨完的后续K线放入训练图，会把信号确认前的涨幅当成模型可以交易的利润。用盘中最大浮盈替代先止损/先止盈顺序，同样会制造假赢家。
- **有效路径**：先冻结完整规则可用时点c+5收盘，再用下一根open入场、已知核心极值止损、12小时内先到毛3R且扣20bp仍盈利的独立标签解析器。相同K线双触发保守止损，止损跳空按更差open，缺未来不写负例。原1043事件实测55个TP、296个SL、692个超时。55是本次新风险定义的结果，不能倒称历史策略胜率；其净R为2.7757至2.9841，不能称净3R。
- **通用规则**：先写清信号可用时点、成交时点、R分母与费用，再筛盈利；事件数量、图片数量、毛R和净R分别报告。各位置变体固定同一可见右端，未来价格只能进入标签文件。
- **牵连**：`yoyo/contracts/ma_profit_filter.py`、`yoyo/datasets/ma_profit_pipeline.py`、`experiments/active/exp-ma-profit3r-20260922-v1/legacy_outcomes/`；新模型必须在完整失败候选池上评估，纯赢家集合不能证明交易表现。
