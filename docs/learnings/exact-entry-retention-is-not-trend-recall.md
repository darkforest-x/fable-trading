# 同根入场留存不能代替整段行情召回率

- **问题**：V6/V7 的逐笔联结以市场、周期、方向和信号时间作为 identity。未联结的盈利 V6 交易被图例叫成“V7 漏掉的趋势”，但 V7 可能在另一根 K 线上进入同一段行情。
- **死胡同**：把联结缺失直接翻译成行情漏掉，看似直观，也方便挑案例；实际把“相同入场事件”和“同一行情段”两个统计单位混为一谈。换用准入布尔值也不能修复，因为准入并不保证真实执行。
- **有效路径**：保留严格的实际入场 identity 联结，但明确命名为“同根入场未保留”。另报各方案真实兑现至少 10R 的交易总数。没有预先定义独立行情段及覆盖条件时，不报告行情段级召回率，也不在图标题里声称整段漏掉。
- **通用规则**：解释召回、留存或漏检之前，先写清被联结的统计单位。不同时间的两次交易可能覆盖同一行情；同根信号也可能因已有仓位而未执行。
- **牵连**：`yoyo/evaluation/spike_v7_v1_report.py::exact_retention`、`spike_v7_v1_figures.py` 的案例命名和 `spike_v7_v1_delivery.py` 的解读。此修正只影响表述，不改变冻结规则、模拟交易或图例选择。
