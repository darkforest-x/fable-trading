# 训练选图流程不能直接当成指标的入场条件

- **问题**：将 YOLO 训练选图规则加到 SPIKE，看似只是复制布尔条件，但训练流程还包含事后收益保留、跨事件去重、不同核心的选择顺序及另一套图像均线。
- **死胡同**：用“未来达到3R”当实时门，或拿任一4/5核心最终过关替代先按第一道距离选核心，都会让实际交易条件偏离原规则。训练图的HL2也不能证明选图数值使用HL2；本轮代码证明原筛选用close。
- **有效路径**：把当根可见的形态条件与后验标签分开；保留原SPIKE收盘/次开时点，只改变入场许可，完整串行重放。4/5各自通过第一道hard+distance后，按distance选择，再检查所选核心第二道，不回退。与当前独立Pine的OR/4优先差异明确记录。未来最高分NMS不作为在线许可。
- **通用规则**：迁移数据构建规则时逐项标明“特征/标签/去重/渲染”，并固定先后顺序和可知时间。只比较阈值不等于比较了同一算法。图像预热长度也不自动成为指标形态门。
