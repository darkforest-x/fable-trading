# 历史交易导航必须同时锁定完整账本与原行情来源

- **问题**：策略列表需要按回测收益选出 Top 1 币种，并从任意历史成交定位全局 K 线。
- **死胡同**：现有策略小册的最近 50 笔不是完整排名输入；当前 OKX 图表也不能替代 Binance 历史回测行情。复用两者会分别造成排名偏差、成交时间与价格来源不一致。
- **有效路径**：从已登记的资金账本投影全部实际分配仓位的结算记录，剔除补款，先全量排序再分页；用策略及稳定账本行号找到原始行情 identity，再从登记文件读取时间窗口。图表缓存和异步请求同时绑定策略、交易、币种及周期，切换时取消旧读取，历史模式停止实时行情合并。
- **通用规则**：做历史图表导航时，先验证账本覆盖范围与行情身份。仅有时间和净盈亏的账本只能画时间标记，不能猜测成交价格；排名展示保留原研究的版本、成本与事后信息限制。
- **牵连**：`yoyo/monitor/strategy_backtest.py`、`static/strategy-backtest.js`、`static/reclaim-chart.js`、`static/monday-fib-chart.js`；输入为 `exp-strategy-booklet-paths-20261027-v1` 资金账本与 `exp-monday-limit-reclaim-20261024-v1/symbols` 来源登记。测试覆盖全量排名、分页、来源校验及过期异步响应。
