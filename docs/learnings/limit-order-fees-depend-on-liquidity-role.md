# 限价委托不等于 Maker，费用取决于成交时是否吃单

- **问题**：Owner 要求模拟挂单按 OKX 普通等级收费，而旧模拟所有成交都收 0.1%。
- **死胡同**：只把限价单费率改为 0.02%，会让穿过盘口立即成交的限价单也错误享受 Maker 费率；只改最终成交费则预留资金和止盈止损估算不一致。
- **有效路径**：提交时用冻结报价区分立即成交的 Taker 与进入等待的 Maker，分别采用 0.05% / 0.02%；保存每笔成交的费率和角色。预览、冻结资金、成交、预计平仓费分别使用对应口径；历史成交金额保留。
- **通用规则**：费用应附着于成交事实，不能由一个订单类型标签永久推断。费率改动必须同时检查资金预留和净盈亏展示。
- **牵连**：仅手动模拟账户，研究默认成本不变；[OKX 普通等级合约费用](https://www.okx.com/en-eu/help/how-to-calculate-the-contract-transaction-fee)，2026-10-15 核对。
