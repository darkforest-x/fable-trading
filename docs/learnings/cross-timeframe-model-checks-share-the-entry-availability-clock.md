# 跨周期模型确认必须共用开仓可用时间

- **问题**：Owner 要求比较 V9 各周期入场与同级／小级别 YOLO 检出、胜率的关系。YOLO 需要核心之后若干根确认 K，若只按信号 bar 的开盘标签对齐，很容易把开仓之后才闭合的子周期图像当成当时可见。
- **死胡同**：沿用在线“信号后等待9根”的确认流程会回答另一个问题；只删除原交易里的未检出行，也不能证明过滤后的单仓策略收益，因为空仓会放进新事件。本轮在设计阶段排除这两种做法，未先用真实结果试错。
- **有效路径**：先冻结 `V9 signal_close = scheduled_entry_time`，各图只取满足 `bar_open + own_duration <= entry_time` 的最新完整根；同级与小级别使用相同可用时钟。先保存模型原始框与像素身份，再接回未来收益。条件胜率使用同一批原始交易，过滤策略另跑完整串行回放，保留原始反向退出。
- **通用规则**：先问“这个检测在开仓时是否已经知道”，再问是否同方向；最后区分条件相关性与改变持仓路径后的策略结果。两个裁剪图不是两个独立交易，小级别检出不自动证明识别了大级别同一形态。
- **牵连**：`yoyo/evaluation/spike_eth_yolo_entry.py`；`tests/evaluation/test_spike_eth_yolo_entry.py`；`experiments/active/exp-spike-eth-v9-yolo-entry-20260915-v1/PROJECT_PLAN.md`。模型 core4/5、post2–9、conf .25 均冻结，本笔记不产生训练或生产资格。
