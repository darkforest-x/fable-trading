# 趋势分批止盈必须显式守住右尾

- **问题**：分批止盈能改善大量回吐交易，开发期平均收益甚至会随兑现比例增加而变好，因此很容易把 40%–75% 的减仓比例选成“最优”。
- **死胡同**：只优化平均 bp、回撤或“盈利变亏损”的数量，不检查大赢家分布。ETHUSDT.P 15m 多版实验中，较大比例能救一些普通交易，却让 P95 只剩纯 runner 的 39%–81%，到时间外审计普遍转负。
- **有效路径**：冻结入场与 runner，只扫总兑现比例，并把 P95 保留率设成硬门。V16 的 10% 总兑现是 10/15/20% 中唯一在开发期保留至少 95% P95 的候选；审计仍保留 93.58%，单笔净均值 +5.19bp，但比纯 runner 少 2.17bp，诚实保留为研究版而不 promote。
- **通用规则**：趋势策略的平均值由少数极端赢家支付时，部分止盈相当于对右尾征税。选择退出参数必须同时报告平均净收益、PF、P90/P95、最大赢家、匹配随机对照和逐笔配对差；右尾门不过，即使回吐更少也不能通过。
- **牵连**：+2/+4/+8/+12 ATR 梯子、`bank_total_fraction`、SMA60±1ATR runner、114 笔非 pristine 审计、top-10% 事后诊断、`production_eligible=false`。
