# 整批分数前十分位不能直接成为历史入场门

- **问题**：High-R Entry V2的风险分数诊断比突破分数更集中地包含10R赢家，但按整批回测分数选前10%时，历史信号并不知道该批次未来的分数分布。
- **死胡同**：直接删除账本中分数排名靠后的交易，再把留下的收益说成可执行策略；这既使用了未来分布，又跳过了筛选后串行占仓改变的新机会。只提高普通净盈利胜率也不等于提高10R命中率。
- **有效路径**：另立V2.1，明确披露方向来自已暴露诊断；只用信号参考风险，按此前三个完整月的候选分布设每月阈值，先哈希固定再重放全部串行路径。以普通胜率、10R比例、召回和扣成本经济性联合验收。
- **通用规则**：诊断排名、因果决策阈值和实际成交账本是三个对象，必须分别保存。阈值不使用未来数据不能抹去研究者看过后段数据的选择偏差；真实前向验证仍不可替代。
- **牵连**：yoyo/evaluation/spike_high_r_risk_calibration.py；spike_high_r_entry_v21.py；spike_high_r_risk_study.py；两个独立实验计划。没有改原止损分母、生产默认或真钱账户。
