# 先达标签的路径歧义应自动下钻而不是人工猜测

- **问题**：15m K 线若同时穿过目标与止损，仅靠 OHLC 无法知道谁先发生；把这类样本交给人看同一根 K 线也不会增加时序信息，只会引入主观猜测。
- **死胡同**：默认 OHLC 具有固定 `O→H→L→C`/`O→L→H→C` 路径，或要求人工审核员凭蜡烛形状判断先后。两者都在制造原始数据没有提供的信息。
- **有效路径**：先按 bar open 处理 gap，再检查单边触碰；仅在 15m 双触碰时读取按时间排序的 3m 子柱。若同一 3m 子柱仍双触碰，就标为 ambiguous 并自动排除/替换，不改训练图、不让人猜。本轮 335 个真实候选没有双触碰，全部自动解析；1005 个匹配对照中 3 个缺少更细路径的歧义样本被自动拒绝并以同分层对照替换。
- **通用规则**：first-touch 标签审核的第一步是建立逐级时间分辨率解析器；“人工审核”只适合语义判断，不适合恢复不存在的 tick 顺序。最低分辨率仍冲突时 fail closed，并把歧义数作为数据质量指标。
