# 人工交易系统必须写出当下可执行的决策

- **问题**：Owner要结合个人历史和现有均线密集、YOLO、V9整理人工开单系统；此前报告主要划分研究模块、待开发门禁和回测优先级，没回答本人打开图表后如何操作。
- **死胡同**：把人工交易需求当作自动执行系统规划，容易让使用者误以为需要删除形态工具，或必须等所有工程门禁完成。只写2R/4ATR也不够，参考仓位、真实成交和用户能否读到ATR尚未衔接。
- **有效路径**：围绕盘前、候选、画结构、确认、写SL、算量、成交核对、保护与退出、复盘逐步成文。V1可人工切周期核对，YOLO分可见时间与人工认同标签；明确哪些新约束只是草案。另附开单卡，缺输入或订单状态不明时给出具体跳过/退出动作。
- **通用规则**：先确认决策者是人还是程序。人工手册每个条件都应对应可见字段、判断时刻和可执行动作；不能把研究待办或未显示的内部状态当作用户已有能力。
