# 子代理创建回执不等于实际模型核验

- **问题**：Owner 要求所有子代理实际使用 `gpt-6-luna / max`，但创建工具只返回任务名，没有返回模型字段。
- **死胡同**：不能把创建参数当成实际运行证明，也不能因为回执缺字段就断言 Luna 不可用。基础指令的模型来源字段也不等于当前轮运行模型。
- **有效路径**：先让代理等待，定向读取该代理自己的会话记录中的 `turn_context`，核对 `model`、`effort` 与当前协作设置。2026-10-24 两个新代理均明确记录 `gpt-6-luna`、`max` 后才开始工作。
- **通用规则**：配置请求、创建成功、实际运行设置是三种证据；核验只读当前已授权代理的运行元数据，不遍历或展示其他会话内容。没有可核验元数据时仍由主代理继续。
- **牵连**：仓库子代理模型铁律；不需要更换模型或修改 owner 的主模型设置。
