# 移动控件后必须重新核对旧响应式隐藏规则

- **问题**：将全站行距、主题与本机状态放入公共菜单后，桌面可用，但手机上的菜单只剩主题图标。
- **死胡同**：原 DOM ID 和监听器都在，静态测试也通过，仍不能说明控件可用；顶栏历史样式继续按类名隐藏行距与状态，并把主题 select 压成透明图标尺寸。
- **有效路径**：在实际 390px 抽屉里打开菜单，逐个检查 display、尺寸和焦点，限定新菜单上下文恢复控件可见性与原生 select 尺寸。验证 Escape 返回菜单入口，外层导航保持打开；没有全局覆盖业务的 hidden 状态。
- **通用规则**：控件搬家后同时审核事件归属、CSS 上下文、弹层裁切和焦点路径；至少在桌面与最窄断点实际打开一次，不能只验节点存在。
- **牵连**：`workspace-minimal.css/js`、`frontend_minimal_disclosure.test.cjs`；保留移动端导航模态隔离、原主题与密度存储逻辑。
