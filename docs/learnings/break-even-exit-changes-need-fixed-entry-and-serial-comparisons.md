# 保本退出改动必须同时比较固定入场和重新串行的结果

- **问题**：V9加入净浮盈2R后的0.2%保护，既会改变原有交易的退出，也会提前释放仓位、改变下一笔允许入场的信号。只看胜率或用原逐笔账本替换几个收益，无法解释完整策略变化。
- **死胡同**：将事后最大浮盈MFE当作早先已知条件，会提前移动止损；把某根先冲高再止损改成同根保本也会制造不可实现的收益。仅统计被救回的亏单则漏掉回调后本可继续盈利的交易。
- **有效路径**：在原有效止损检查后，以刚完成K线的高低点判断扣费后2R，下一根才启用保护。原版保持不变，另建版本。每个原始入场固定重放两条退出以归因，再完整串行重放以计入新增/消失交易；每个随机入场使用同一退出版本。
- **通用规则**：退出改变可能改变未来入场时，先区分“同入场退出效应”和“完整交易序列效应”；关闭新规则逐笔对齐旧引擎后再评估，最高浮盈只是结果，不是提前可见的信号。
- **牵连**：`yoyo/evaluation/spike_v9_cost_be2_engine.py`、`spike_v9_cost_be2_study.py`、`spike_v9_cost_be2_report.py`；保护触发、下一根执行、原V9原始反向信号、成本R和配置特定holdout授权。
