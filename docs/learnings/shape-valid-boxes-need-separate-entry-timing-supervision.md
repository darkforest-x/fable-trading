# 形态正确的框不能直接充当入场时机标签

- **问题**：人工确认部分检测框确实覆盖目标形态，但模型只在框右缘开火；到那一刻行情常已走完。一个 `是/不是` 形态标签无法同时表达“结构正确”和“现在仍可入场”。
- **死胡同**：把迟到但形态正确的样本改成 detector 负例会抹掉真实结构；只删最宽框也无效，因为框宽与信号前已走 ATR 几乎不相关；提高 detector 置信度同样不能把置信度变成时机分数。更不能把未来收益直接塞进实盘特征。
- **有效路径**：先保留人工确认的形态正例，再单独提出一个更早的因果入场锚点，让人工在可看未来的审核图上只判断“来得及 / 来不及”。训练图必须截到该锚点，未来只负责生成或审核标签。检测层学习形态核心，时机层学习当前是否可行动。
- **通用规则**：凡检测框跨越了“准备态→确认态→结果态”，第一步先验证框右缘是不是行动时刻；若不是，就把 object localization 与 action timing 拆成两个监督目标，不要用一个 box 同时承担二者。
- **牵连**：`scripts/analyze_eth3m_v10_yes_no_labels.py`、`scripts/build_eth_3m_v10_prebox200.py`、Label Studio 项目 53；仍须遵守 holdout、无前视、时间切分和 detector/timing 分层约束。
