# Censored positions need clocks without realized outcomes

- **问题**：组合风险账本需要把已入场但在冻结窗口边界仍未平仓的仓位保留在占用容量中，同时核验冻结交易证据。
- **死胡同**：把所有已执行交易都要求有有限的已实现 `net_r` 和 `net_return`，会将删失仓位误判为无效；丢掉它们又会让同一时段的容量和相关性约束过于宽松。
- **有效路径**：对删失交易核验入场/退出边界时钟、入场价格、初始风险和删失标记；仅对非删失交易核验并汇总已实现收益。入场纪律只读取时钟和身份。
- **通用规则**：风险状态机与收益统计分开建模：前者保留所有有时钟的暴露，后者只统计结算结果。
- **牵连**：`yoyo/evaluation/spike_correlation_risk_study.py`；冻结 V7/V8 组合风险比较。
