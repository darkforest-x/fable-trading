# 人工验真可以看未来，但模型输入必须从截止时刻重渲染

- **问题**：人工无法只凭盘口右缘判断某段均线密集是否属于目标形态；若人工也被强制裁到盘口，就失去了用后续走势确认形态语义的能力。但若把含未来 K 线的标注图片直接用于预标、训练或判断层，结果又会发生前视泄漏。
- **死胡同**：让人工和模型共用同一张 causal-tip 图片，虽然没有泄漏，却把“人工定义目标”和“模型学习目标”混成一层；反过来直接训练含未来区域的人工复核图，则会让像素、坐标缩放和均线形态共同泄漏结果。
- **有效路径**：为同一个事件维护两种视图。人工复核图展示候选前历史、候选区和右侧未来，并明确标出模型截止线；人工只框截止线左侧的密集形态，可利用右侧走势判断是否接受。导出时把框坐标还原为时间区间与绝对价格区间，再从原始 K 线重新渲染一张截止于信号时刻的训练图，重新计算框坐标。旧模型预框也只能在 causal-tip 图上推理，再映射到人工复核图，不能在含未来图上运行。
- **通用规则**：标签允许看未来，特征和模型输入不允许看未来。人工视图、模型视图和最终训练文件必须是物理隔离的产物；禁止简单复用含未来的 PNG，禁止只靠“训练时忽略右半边”的约定。验收必须断言训练图最大时间、特征最大时间均不晚于事件截止时刻。
- **牵连**：ETH 3m/5m/10m 标注包、Label Studio 导入任务、标注导出转换器、YOLO 图片与框坐标重算、判断层 as-of 特征、holdout/时间切分纪律。当前 `datasets/eth_short_tip_label2000` 只能作为 causal 模型视图或后续复核素材，不能充当面向人工的最终验真界面。
