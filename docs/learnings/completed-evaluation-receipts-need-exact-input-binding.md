# 已完成的评估回执也必须绑定本轮精确输入

- **问题**：MA3R训练负例修复预检发现，收集器只核对模型/数据哈希和completed状态，未核对评估器代码版本；已有随机对照结果的输入也未要求对应当前组的评估结果。
- **死胡同**：验证回执自己声明的文件未变化，只能证明旧结果自洽，不能证明它属于当前模型、组别和冻结方法。本轮尚未开训，此缺口由静态审阅发现，没有据此宣称已经发生结果串用。
- **有效路径**：从训练前冻结清单提取评估器和指标代码SHA，核对回执；对照输入必须精确等于本组评估回执/事件、原冻结账本及对照来源/结果文件。收集和交付都核对冻结输入代码未漂移。自包含测试证明错组回执即使自身哈希有效也被拒绝。
- **通用规则**：复用completed产物前先由当前任务推导完整预期输入集合，再和回执逐项比较；不能只相信回执列出的那部分输入。
