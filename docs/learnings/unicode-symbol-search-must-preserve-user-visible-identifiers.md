# 合约搜索归一化必须保留用户可见的 Unicode 标识符

- **问题**：回放记录已能安全读取中文合约名，但前端搜索只保留 ASCII 字母数字；输入“龙虾”会归一化为空查询，留下无关的缓存 DATA 卡片和图表。
- **死胡同**：把输入统一转为 `[A-Z0-9]` 适合旧交易所符号，却把合法的非 ASCII 合约名当作标点删除，缓存保留策略随之变成错误展示。
- **有效路径**：NFKC 后仅删除非 Unicode 字母/数字；筛选后的集合继续复用既有逻辑，在已选卡不属于集合时清除详情。
- **通用规则**：数据层允许某类标识符时，搜索、筛选和展示的归一化必须接受同一字符范围；缓存不能跨越用户当前筛选。
- **牵连**：`yoyo/monitor/static/app.js`、`tests/monitor/frontend_cards.test.cjs`；不改变冻结文件路径检查、信号、账本或通知。
