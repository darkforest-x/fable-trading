# 少亏一点不能证明入场已经具有趋势优势

- **问题**：固定特征而放慢退出检查，平均净变化略正，容易被当成“抓住趋势”的成功证据。
- **死胡同**：只数亏转盈或看净均值改善，会忽略盈利转亏、持续亏损和同样受退出改变影响的随机对照。
- **有效路径**：固定全部请求与控制，计算病例变化D及超额变化I，并保留四种盈亏转换。V9中D+1.35bp、I+0.83bp区间均跨零，新净−16.43bp；207笔持续亏损。结论是未建立可交易优势，不是找到最优退出。
- **通用规则**：只有少数回吐交易改善时，不能继续用未来赢家定义入口。先检查完整净期望和匹配超额，再决定是否回到事前入场质量；持仓内MFE不能断言离场后没有趋势。
- **牵连**：V9固定286请求、849控制、959意图；成本20bp、K1止损、原生5m SMA40均未变。结果仅为重复使用的2023–2024开发证据。
