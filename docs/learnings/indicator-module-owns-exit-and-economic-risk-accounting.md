# 一个模块管理自己的退出，图上R不能代替全单净R

- **问题**：个人持仓复盘需要与正在研究的原V9趋势、BB×Stoch v2反转及V1门禁连接；多种指标同时出现时，入场和退出容易被临时拼接。
- **死胡同**：初稿另拟通用趋势规则，没有利用Owner现有指标。把Stoch单箭头用于趋势仓退出，或将BB平半保本直接移植到V9，会改变尾部收益；把尾仓图示5R当全单5R，又会误计分批收益。
- **有效路径**：逐项核对最新用户修订与既有报告，冻结A原V9、B原BB v2和B-V1gate独立身份；开仓模块拥有退出权，账户风控单独覆盖。B按实际成交份额计算净收益，图形R保留Owner要求的展示语义。V1门禁未知不能冒充关闭，监控V9状态也不能替代V1状态。
- **通用规则**：多指标系统先规定谁能准入、谁负责退出、谁限制账户风险，再研究新增过滤。显示距离、价格风险R与含费预算R需要分别命名和固定分母。单次新研究只改变一个决策组件。
