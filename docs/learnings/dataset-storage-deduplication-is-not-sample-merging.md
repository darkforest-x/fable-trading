# 数据归并必须把存储复用与样本语义分开

- **问题**：行情与图像散落在缓存、实验输入和训练版本中；盲目重拉浪费空间，全量载入又放大内存使用。
- **死胡同**：按币名拼接不同交易所，或按相同图片删除标签和 split，会改变历史实验含义；硬链接还可能让一次写入修改多个版本。
- **有效路径**：行情原地迁移并保留旧路径兼容，逐文件核验 inode、大小与时间；训练版本保留独立入口。元数据索引与数据内容分离，回测按明确数据集、交易所、币种、周期和区间分块读取，冲突及缺口拒绝静默合并。只有全字节 SHA 相同才做 APFS 写时复制，保留独立修改语义。
- **通用规则**：存储共享不能改变标签、事件谱系、时间切分或冻结清单；目录版本和物理重复块是两件事。整理先冻结工具再执行，并用迁移日志恢复中断。
- **牵连**：`yoyo/data/dataset_catalog.py`、`yoyo/data/dataset_maintenance.py`、数据集工作台；外部只读缓存保持原位，生产写者不参与本地整理。
