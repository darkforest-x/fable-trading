# 资金曲线缩放必须保留窗口起点之前的阶梯值

- **问题**：逐笔结算资金曲线需要按月、日查看并左右移动；没有成交的时段也应显示延续的资金与原始回撤。
- **死胡同**：直接按可见时间过滤点会丢掉起点之前最后一次结算，窗口内首笔成交前的曲线缺失；按日聚合又会抹去同一时刻先亏损后补款的过程。本次没有重跑交易回测，使用已保存路径验证这些边界。
- **有效路径**：保留全部原始点，ECharts 使用 `filterMode: 'none'`；可见纵轴范围包含窗口前一个点以及窗口内全部结算。回撤直接使用原始序列，不随窗口重新计算高水位。主题与金额单位切换保留时间窗口。
- **通用规则**：缩放阶梯型账户序列前，先检查窗口起点的承接值、无成交窗口、同时间多笔结算；时间窗口是视图状态，不是收益重新核算边界。
- **牵连**：`yoyo/monitor/static/reclaim-strategy-book.js` 的 `historyAxes`、`historyWindow`、`equityOptions`；相关边界见 `tests/monitor/frontend_strategy_book.test.cjs`。
