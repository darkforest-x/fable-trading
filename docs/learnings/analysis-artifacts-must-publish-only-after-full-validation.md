- **有效路径**：先用仓库锁定的 Python 3.9 跑单元测试，修复版本不兼容；随后把所有 CSV、PNG 和 JSON 写进 `results/` 下的临时目录，只有全部计算与渲染成功才用原子替换发布最终文件，并由独立 validator 重算键、算术、哈希和汇总。
