# 区间回归的固定 2R 目标可能要求突破区间另一端

- **问题**：2026-09-20 分析 Data Trader 的首根 4 小时区间、5 分钟突破后回归策略。信号回到区间内，不代表按突破极值止损计算的 2R 目标也在区间内。本条是几何推导，没有运行行情回测，也没有验证策略收益。
- **死胡同**：本次审查排除的推理是“既然做区间回归，固定 2R 自然由回归行情覆盖”。忽略突破深度与回归确认后的入场位置，会把需要穿越对侧边界的交易也解释成普通区间回归。为让目标看起来更近而临时改用附近订单块止损，又引入了不同规则，不能据此证明原极值止损版本有效。
- **有效路径**：设下沿为 L、上沿为 H、宽度 W=H-L。多头成交价为 L+x，本次突破到确认时的最低价为 L-e，其中 e>0、0<=x<W。初始价格风险为 x+e，2R 目标为 L+3x+2e。目标不超过上沿当且仅当 3x+2e<=W。例：区间 [100,102]，最低99.8、入场100.2，则目标101；最低99.2、入场100.6，则目标103.4。第二例需要越过上沿。空头取镜像关系。此推导假定极值止损、实际成交价、无额外止损缓冲；若有缓冲，必须计入初始风险。
- **通用规则**：研究区间回归策略时，先记录入场到对侧边界的距离与初始风险之比，再区分“目标位于区间内”和“目标越过对侧”的样本。这个比值只是因果可观测的研究变量；不能未经实验就把它升级为有效过滤条件。信号收盘价与实际成交价不同，计算时必须使用后者。
