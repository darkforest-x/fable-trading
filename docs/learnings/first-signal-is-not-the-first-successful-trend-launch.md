# 同段第一个信号不等于真正趋势的启动

- **问题**：想用同一BB压缩段的首次信号降低V7噪音，同时保留大趋势。
- **死胡同**：同段任意方向首次信号消费许可，在复用验证年1H减少44.74%提示，却只原位保留63/98笔兑现10R赢家；进一步要求信号当根收盘突破压缩边界，减少62.34%提示，原位只保留25/98笔。少信号不能当作提高准确率。A/C都没有通过跨两年的预定目标。
- **有效路径**：冻结入场假设和原版退出，用同源账本逐条回放。把原位10R保留、同段替代、收益与回撤拆开，记录每笔误删时已知的原因。1H C误删73笔原位赢家中53笔在当时边界内、20笔已被前次许可占用。明确失败归因后停止向线上加入该规则。
- **通用规则**：任何基于结构段的去重，都要分别定义“出现过候选”“方向确认”“尝试失效后是否可重新进入”。研究重新许可时先验证失效状态，再比较被拒绝的后续启动；不能用未来盈利选择何时解锁。
