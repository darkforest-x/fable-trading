# 数图上的第五个点，必须先复现显示掩码

- **问题**：Owner提出RSI连续第五个同色时进场。ChartPrime源码同时存在多空状态、SAR圆点、普通菱形和强菱形，数其中任何一种都可能得到不同的入场时间。
- **死胡同**：直接把状态连续长度等于5当成“第五个圆点”会早进一根。源码在翻转根把圆点序列设为na；这根有新的颜色状态，却没有可见圆点。不能通过调整收益结果来决定该数哪一种。
- **有效路径**：从plot的实际输入反向追溯显示掩码：有限SAR且非翻转根才有圆点。分别保留state_run与visible_dot_run，合成翻转序列验证第五状态根在t0+4、第五圆点在t0+5，然后由Owner明确计数对象再评分。
- **通用规则**：策略引用图上“第几个标记”时，先明确对象、显示条件和计数重置条件。隐藏值、暖机na、普通翻转与强事件都不能被原始状态布尔值代替。
- **牵连**：`yoyo/evaluation/btc_rsi_fifth.py`、`tests/evaluation/test_btc_rsi_fifth.py`、Owner提供的ChartPrime Pine。尚未确认的入场与分批退出不应产生策略收益结论。
