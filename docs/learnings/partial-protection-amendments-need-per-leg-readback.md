# 分档保护改单要逐档回读

- **问题**　一次点击可以改止损和两个止盈价，交易所分别处理三张保护单。第二张被拒绝或请求超时时，第一张可能已经生效。
- **误区**　按整张表单报成功或失败，都会丢掉各档的真实状态。模拟器验收还发现，预存的改单参数与实际派发的止盈字段不一致会触发请求指纹冲突。
- **做法**　用原保护单标识直接改价，按档持久化指令、回执与用户指定价格，逐档回读。将部分成功返回到表单，恢复时沿原编号查询。继续按原档序保留已成交档和未修改档。
- **适用处**　纪律 App 的 `live_book.py`、`execution_journal.py` 与 iOS 持仓保护表单。开仓附带的止损被外部撤销仍会触发现有应急平仓路径。
