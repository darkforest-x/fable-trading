# 提前入场带来的更多累计R，不等于更强的每笔优势

- **问题**：V13.1四阶段完整占仓回放中，首次突破累计净R为3410.60，原再次突破为1259.71，表面上提高约171%。需要判断是否足以替换原规则。
- **死胡同**：只看总R会把交易次数增加、风险暴露增加和独立信号增益混在一起；只看前期选择在后期仍赚钱，也排除不了共同市场行情与退出框架的贡献。
- **有效路径**：同期首次突破交易106848笔，原确认21534笔；均净R由0.05850降至0.03192，PF由1.09980降至1.05028，已平仓累计R回撤由609.00增至4090.78。共享非周日匹配队列中，首次突破信号3241.97R、随机同规则6141.83R；2025后分别1546.81R、4534.09R。每次阶段变化同时检查随机队列相同变化，并把交易数、每笔收益和风险口径并列。
- **通用规则**：最高累计收益、最高每笔效率、最小回撤和独立超额是不同问题。放宽入场应同时报告成交量、毛/净收益、费用、同资格对照和时间稳定性；不能用更多投入风险的交易堆出的总R直接宣布策略升级。
- **牵连**：`exp-spike-v131-entry-stages-20261019-v1/results_v1/comparisons.json`。R回撤仅按已平仓交易累计，非账户或持仓浮动最大回撤。历史反复研究，未模拟资金费、共享资金和逐时点币池；没有新生产规则获准。
