# 因果前缀核验要比较连续性，不比较不透明段号的名字

- **问题**：完整数据的连续段可能编号 7，截短重算后同一段编号 0；逐格 trace equality 会把命名差异误报为因果偏差。
- **死胡同**：直接要求所有 trace 字段逐字相等。纯合成复现中，事件状态和可知时刻一致，唯一失败来自 segment_id。本轮在真实价格审计前发现，未靠放宽实际结果的误差修正结论。
- **有效路径**：每个事件内部按实际访问顺序独立重编码 raw/native 段名，保留缺失值和切换模式，再严格比较全部其他字段。用非 0 段号与不同字符串命名的合成对照验证，不从全历史复制段号到前缀。
- **通用规则**：先把比较字段分成经济/因果事实与标识符。标识符做有损归一前，必须证明只舍弃任意命名、没有舍弃边界或缺失。
- **牵连**：V38 `terminal_prefix_checks`、`normalize_segments` 及 runner tests。两路共用冻结 SMA 实现，所以这是独立输入截短复现，不是独立算法验证。
