# 价格路径缓存必须保留未完结交易的缺失语义

- **问题**：V13.1 规则研究为复用已验证价格路径，从 CSV 恢复缓存时统一移除 NaN，再补 `net_r=None`。原引擎中未入场收益为 None，已入场但截止时仍未结束的收益为数值 NaN；后者在逐笔数值对照时因此报类型错误。
- **死胡同**：统一删除所有空字段不能保存原对象语义。把未知收益改成零、丢弃这些合约或省略对照会改变样本与占仓结果；错误应在缓存边界修复。
- **有效路径**：保留 filled/status/exit_i，已入场未知恢复为 NaN，未入场恢复为 None；加入两种状态的独立回归测试。按明确的缓存错误条件定位50个合约并在新目录重算，原失败结果保留；合并器只接受与最终失败清单完全相同的修复子集和完整收据，逐合约记录来源版本。
- **通用规则**：复用回测缓存前核对缺失值的状态与类型，而不只是列名。未知、未发生、被队列跳过是不同概念；恢复流程必须保持它们的持仓与统计含义。
- **牵连**：`yoyo/evaluation/spike_v131_rule_study.py`、`spike_v131_rule_recover.py`；原始信号与退出规则未变，后续汇总仍将所需但未知的收益排除出成熟配对，而不是归零。
