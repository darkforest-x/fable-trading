# 黄金休市与统一回撤时钟

## 问题
将加密货币 IMACD 回测迁到 XAUUSD，旧聚合器要求每个日桶都有 1440 根分钟线，正常休市会使整根日线被删除；各周期只按自身收盘盯市又会低估高周期回撤。

## 死胡同
用前收盘补平周末会制造不存在的近零蓄势。把高周期较平滑的权益曲线当成更小风险，会混淆交易规则与观察频率。固定初始本金交易也不能一直称为当前账户的 1 倍仓位。

## 有效路径
保留真实报价，按事前固定时区分桶，不要求休市分钟存在，逐桶保留观测数量及缺口审计。信号仅在桶关闭时确认，成交到下一真实分钟开盘。所有规则用同一真实分钟收盘网格盯市，仓位以每次入场前权益计算。

## 通用规则
市场迁移必须同时审计交易日历、特征时钟、成交时钟和资金口径。缺失报价不能自动解释成横盘；相同资金并不等于相同风险观察频率。

## 牵连
旧代码 `yoyo/evaluation/imacd_indicator_audit.py::aggregate` 和 `yoyo/evaluation/imacd_profit_mechanism.py::single_position` 保留历史语义，不为这次研究修改。新 XAUUSD 研究使用独立适配器；没有改变生产或 Pine 样式。

HistData 的小型实际下载又显示 HTTP200 ZIP 可含冲突分钟，故下载成功不代表数据通过审计；严格拒绝冲突，只能显式去除完全相同的重复。档案按固定 EST 年月组织，目标窗口按 UTC 截取，两者边界不得混用。
