# 人工交易的证据从冻结当时的决定开始

- **问题**：个人交易手册已经存在，但未进入工作台；研究信号的参考收益和历史账户账单都不足以解释本人当时为何做或不做。
- **死胡同**：仅增加文档入口会重复原来的落地缺口；把信号价格当实际成交、把未知止损补成默认值，或用最新规则解释旧交易，都会制造不存在的证据。此前只有手册和空白日志模板，没有前向人工决策日志。
- **有效路径**：个人交易作为并行业务线，先登记规则版本与盘前计划，再记录观察、计划、实际成交和复盘。成交登记冻结原始决策及引用；后续更正与持仓操作追加版本。事后补录、真实交易、手工练习和未知数据各自标记。
- **通用规则**：先确定一条记录代表决定、参考信号还是实际成交，再设计状态和计算口径。初始风险不得被后来的止损调整重写，未知净收益也不等于零收益。
- **牵连**：`yoyo/research_workspace/manual.py`、`manual_api.py`、`yoyo/monitor/static/manual.js`；历史手册为 2026-09-16 v2，风险数字仍是提案；账户操作由 Owner 执行。此变更不涉及模型训练、策略 promote 或自动下单。
