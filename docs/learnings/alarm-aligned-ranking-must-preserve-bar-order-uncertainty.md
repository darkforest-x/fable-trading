# 报警落在K线内部时，筛币结果必须保留时间顺序的不确定性

- **问题**：一分钟报警配合全市场五分钟历史，报警所在K线的低点可能已经发生，不能把整根低点当作可提前挂单的未来机会。
- **死胡同**：只用触价日下载的一分钟缓存会按未来事件选样；用新鲜的大币价格对比旧的小币收盘价又会制造虚假的滞后。删除时序不明样本也会把最需要解释的快针排除掉。
- **有效路径**：保留全部固定报警，币与大盘特征同步在已完成的五分钟收盘；选择规则不读取未来。标签同时记录确定下界与包含边界可能性的保守上界，随机候选使用同报警、同波动和成交额层。先验证细时间路径聚合后真实标签落在界内，再讨论排名增量。
- **通用规则**：数据精度低于决策速度时，先明确哪些事件可确定、哪些只能给界；只有保守的选币增量仍成立，才值得追加更精细的数据。下探概率、下探后恢复和真实限价成交分开验收。
