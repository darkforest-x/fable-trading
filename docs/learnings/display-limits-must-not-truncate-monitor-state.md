# 展示条数限制不能截断监控状态

- **问题**：全市场 507 个合约、每周两个方向最多产生 1014 条触价记录；原先读取上限 1000 会使较早的方向在页面上恢复成未触及。
- **死胡同**：把最近记录列表的分页上限复用于状态计算。显示 40 条事件是界面需求，不能据此认定其余事件没有发生。
- **有效路径**：读取完整当周记录计算每个合约的状态与总数，再单独截取最近 40 条用于展示；以 507×2 的边界用例验证。历史事件按行情发生时刻排序，不用补拉时刻冒充新触价。
- **通用规则**：先在完整业务范围上计算状态，再对展示结果分页；活动记录规模应按实体数乘状态维度推导。
- **牵连**：`yoyo/monitor/monday_fib.py`、`monday_fib_service.py`、`tests/monitor/test_monday_fib.py`。
