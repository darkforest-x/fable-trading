# 推保本的收益必须扣掉被截断的大盈利

- **问题**：Notion #62 去掉反向强退后，大R机会确实存在；但更多保本退出并不自动提高净收益。
- **死胡同**：只数“救回多少止损”或“大目标保留率”，都会漏掉交换代价。把开仓价保本叫作净保本还会漏算费用；不同R分母下，点数与等风险R排名也可能不同。
- **有效路径**：在相同信号、初始风险、费用及边界上逐笔配对。V3 的20R目标、5R后推开仓价，在2804笔双方已结束交易中救回284笔原止损（+284R），同时损失13笔20R目标（−260R），保留139笔目标，毛改善仅24R／174.98点。仍有1笔边界持仓，单列浮盈，不伪装成已实现结果。
- **通用规则**：先做“挽救亏损收益 − 放弃尾部收益”的逐笔恒等核对，再报告费用、原目标保留率、时间分段与匹配随机对照。不能用全历史最优参数代替前向证据。保本价只保护初始风险，无法锁住已经出现但尚未到目标的浮盈。
