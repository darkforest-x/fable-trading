# 报告必须核对附件谱系，不能只看文件存在

- **问题**：修正实现后同时保留旧图、旧费用表和新结果，报告生成器可能混入路径有效但配置过时的附件。
- **死胡同**：只检查completion存在或沿用硬编码“上次冠军”；它既不能证明表格没变，也不能证明图表、成本和本轮事件属于同一配置。
- **有效路径**：候选从当前锁动态派生，逐阶段验证summary与selection SHA；图库验证events/history/selection及每张图SHA，成本记录输出SHA并对上本轮逐币事件。表述同时区分全部候选、匹配子集与单仓选中交易。
- **通用规则**：结果重跑后的报告也是数据管道，要在边界拒绝旧附件。不能把“都叫baseline”当作结果身份。
- **牵连**：`altcoin_trend_report.py`、`altcoin_cost_diagnostics.py`、主研究clock-v1保留产物与clock-v2正式产物。
