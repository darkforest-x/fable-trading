# 费用重算能否复用成交，取决于费用是否参与交易决策

- **问题**：Owner 暂停所有回测手续费，并把 ETH 原始触价固定 10R 从一年扩到五年。已有一年原生成交含历史费用，不能把旧净收益直接当零费用结果，也不该无差别重跑。
- **死胡同**：仅因费用参数变化而重放所有成交会浪费已验证缓存；对所有策略直接加回费用则会错过费用覆盖保本、资金约束等决策变化。本轮未走这两条路径。
- **有效路径**：先限制为纯静态目标与原止损，确认没有费用参与的退出或入场条件，再复用 138 条年度信号/对照原生成交；保留 source_fee_r/source_net_r，重算零费用账本。其余 632 条使用 NautilusTrader 1.231.0、真实零费用配置补跑，并核对原生费用为零、全部价格与时间和既有 oracle 一致。年度索引迁移同时核对原始入场、止损、方向及对照身份。
- **通用规则**：先判断费用是账务参数还是决策输入。只有前者可以重算已冻结成交；后者须另建配置回放。报告要明确哪些成交新跑、哪些来自缓存，不能把重算描述为全量重跑。
- **牵连**：`yoyo/evaluation/range_fiveyear_fixed_target.py`；`tests/evaluation/test_range_fiveyear_fixed_target.py`；`experiments/active/exp-eth-touch-fixed10r-fiveyear-20261022-v1/`。五年385笔+121R，但两个年度亏损、最长31连亏，零费用正收益不等于稳定性或实盘资格。
