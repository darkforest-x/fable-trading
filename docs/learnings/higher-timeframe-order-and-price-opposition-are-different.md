# 高周期旧排列与当前价格压制是两种不同证据

- **问题**：V8的30m事件中，固定高周期反证门几乎从不触发，看起来像时间联结出错。
- **死胡同**：因为“很少触发”而立即降低排列阈值，或把所有旧反向排列都当成当前压制，会在看过结果后改变原假设，并混淆恢复早期与持续逆势。
- **有效路径**：从已保存逐事件表分别核对时钟、排列和价格。68,136个有效同交易所1H观测没有未来收盘，20,171个反向排列≥9/12，但其中20,169个价格已经越过快组向信号方向恢复，只有2个同时满足完整反证。稀少触发是定义的覆盖结果。
- **通用规则**：多周期判断先拆成“已收盘时点是否可用”“慢排列遗留”“价格在快组哪侧”“斜率是否恢复”。覆盖率低不等于实现错误，也不允许事后放松规则；覆盖缺失更不能自动算许可。
- **牵连**：`yoyo/evaluation/spike_v8_entry_evidence_study.py`；`exp-spike-v8-entry-evidence-20260914-v1`。这些是非盲历史中的描述性检查，不证明高周期过滤有效或无效，也不改变线上规则。
