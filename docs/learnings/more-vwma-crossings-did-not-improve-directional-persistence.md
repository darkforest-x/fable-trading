# VWMA多识别的机会没有自动形成更强趋势入口

- **问题**：V26 SMA40→VWMA40使入口251变288，支持覆盖良好；但V28固定4h毛变化−3.07bp，减20bp后−23.07bp，配对超额−2.88bp，均未通过主门。
- **死胡同**：把信号变多或量加权本身当成共振有效，继而继续修退出，会跳过入口到底有没有方向优势的问题。旧V24 SMA成本门也为负；两群不同，不能把它们均值相减当成配对因果改进。
- **有效路径**：先重建新背景，再标签前固定一次随机三控；保留全部288母、283个4h有效组和24个月。四半年自身成本门全负；169个4h毛方向错误，18个小毛利被成本翻负。失败证据指向入口筛选，不只是成本或止损距离。
- **通用规则**：均线参考替换必须先证明净方向延续和背景超额，再研究退出；更多识别不算优化成功。本结论只限固定40两种参考和本开发样本，不否定所有均线或所有趋势策略。
- **牵连**：V27/V28、0.002固定成本、4h主/1/12/24描述；没有用12h较好超额替换失败主窗口，没有上线或宣称赚钱。
