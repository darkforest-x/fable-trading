# 止盈止损必须与平仓挂单共享仓位事务

- **问题**：Owner要求开仓填写止盈止损价格，触价自动平仓；同一仓位还可能有部分平仓、限价平仓和并发手动平仓。
- **死胡同**：把止盈与止损各当作一张普通限价单，买卖触发方向会出错，还可能双重锁定或重复消耗仓位；按设定止损价强行成交也会掩盖真实跳价。没有采用这些实现。
- **有效路径**：止盈止损附着于已成交仓位，限价开仓只携带参数，成交后才启用。多头看新鲜买一、空头看新鲜卖一；在同一个 SQLite 写事务里裁决触发、撤掉同仓位未成交的平仓挂单，并按当前可平仓报价平掉全部剩余数量。触发原因和对应报价进入成交账本。部分平仓后继续保护剩余数量，全部平仓后两个触发条件自然失效。
- **通用规则**：自动退出的对象是“当前仍存在的仓位”，不是初始开仓数量；触发价格与成交价格是两个事实。并发、重启和报价跳变都必须保留这个区别。
- **牵连**：`yoyo/research_workspace/paper_desk.py`、`paper_desk_limits.py`、`paper_desk_api.py`、`tests/research_workspace/test_paper_desk_stops.py`。保护仅使用开仓之后的新鲜公开报价；旧账本新增字段默认空，不给原持仓擅设价格。固定每边 0.1% 费用、独立本地模拟后台与实盘边界均保持。
