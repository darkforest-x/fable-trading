# 仓位缩小降低回撤，不代表发现了新交易优势

- **问题**：ETH4h 候选的连续窗口回撤从34.54%降到6.90%，需要判断改善来自哪里。
- **死胡同**：把低回撤或重写后的保护代码统称为“策略更有效”会混淆资金风险与信号单位期望；这批真实样本里S2–S4相对S1根本没有改变交易收益。
- **有效路径**：结果前冻结逐变量S0–S5链。S1只改风险仓位，每笔净收益仍为137.25bp，与S0相同；账户累计收益从122.92%降至17.40%。S5只平仓不反转才改变交易集合，最终18.09%、回撤6.67%。保留同成本匹配随机对照，不凭资金曲线给修复代码记功。
- **通用规则**：先对照单位名义本金收益和账户收益，再解释仓位变化；修复未在数据中触发时用合成反例证明正确性，不能宣称新增收益。正的历史收益也不是未见数据验证。
- **牵连**：`experiments/active/exp-eth4h-trend-candidate-20260907-v1/`、`yoyo/layers/l3_backtest/eth4h_trend_candidate.py`、`tests/test_eth4h_trend_candidate.py`。原始结果的JSON已保存；报告生成的NumPy布尔序列化错误用统一clean转换和report-only恢复，未重跑或改写收益。
