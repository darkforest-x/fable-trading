# 先用已有人工参考检验模型，再要求新增标注

- **问题**：Owner问最新模型能否识别目标形态，流程却变成逐页人工盲标。高规则集命中率没有回答模型是否遵守已有人工语义。
- **死胡同**：继续发随机背景图，把人工审核当作直接测试的前置条件。既增加Owner负担，也错过现成反证；旧数据集叫gold，也不代表派生裁剪框仍是逐图人工确认的几何。
- **有效路径**：冻结最新权重和0.25阈值，先对账既有判断。Owner刚判“无”的4图里，USELESS仍报0.969945多头。另测386图：202张旧渲染正例仅8张同类IoU≥0.5；172旧空头困难反例无告警；3个认可参考按当前画法，各在后1或2根匹配，但相邻帧仍出现消失或偏框。这证明验收不足，而不是证明全部失败都来自同一个病因。
- **通用规则**：用户要求测模型时，优先复用人工参考、保留的困难反例与原始连续输出；直接展示模型框和反证。新增盲标只用于填补确实缺少的证据。把渲染兼容性、时点稳定性、形态语义和盈利能力分别判断；不把旧画法的8/202当作整体召回率，也不把4张中的1次误报当作市场误报率。
