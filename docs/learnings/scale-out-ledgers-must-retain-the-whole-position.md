# 分批退出必须按完整持仓生命周期记账

- **问题**：第五个同色大菱形入场后，每个反向大菱形平初始仓位25%。部分减仓盈利不能代表整笔盈利，无止损时未平仓尾部尤其可能隐藏风险。
- **死胡同**：把四个减仓成交当四笔独立交易，会重复计数入场胜率和费用；只统计清仓单，又会删掉最久没有退出的暴露。沿用旧固定止损R，则引入根本不存在的风险分母。
- **有效路径**：以原始数量为1记录入场、四个0.25减仓、剩余数量和完整生命周期。退出累计比例守恒；实际付费与剩余假设平仓费分列；全体入场按共同边界估值。价格收益用剩余数量加权，最后退出在开盘成交后不再纳入该根后续高低点。
- **通用规则**：分批策略先证明数量、现金流和费用守恒，再计算胜率。终端未平仓、跨时间切点持仓和浮亏路径必须进入主结论，不能仅作为可选附录。
- **牵连**：`yoyo/evaluation/btc_rsi_diamond_scaleout.py`、`btc_rsi_diamond_study.py`及对应合成测试；成本仍为原始入场名义的0.2%，不包含资金费和杠杆清算。
