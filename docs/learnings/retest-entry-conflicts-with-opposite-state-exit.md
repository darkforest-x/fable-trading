# 回踩入场会与反色状态退出发生时钟冲突

- **问题**：V36 全部63个严格1h源码K1/K2事件中，47个入场时native5颜色已反向；38个首5分钟颜色退出只是反色延续，没有新翻转。加入真实主动量同向后23个事件中仍有20个入场已反向、17个无新翻转退出。
- **死胡同**：把“当前为反色”当作“持仓后趋势发生反转”，会让1h回踩信号与5m回调状态互相打架；加共振只减少交易和费用，不修复这个状态契约。V36门的改善86.5%来自省成本，保留组均值仍负。
- **有效路径**：在同一批原事件上逐笔核对入场前完整bar、首个持仓完整bar、实际颜色退出bar。将状态与边沿区分，先证实38笔确无新flip，再冻结单变量反事实。尚未证明改成真正翻转退出就盈利；旧子群类似试验的负面结果仍保留。
- **通用规则**：跨周期回踩策略先审入场/退出状态是否兼容，再加过滤器。对已反向入场的仓位，“新翻色”必须有先同向后反向的状态路径，不能由静态颜色猜测。
- **牵连**：V36 clock_audit.csv/json、原`colour`和既有`transition_colour`；初始止损/成本不改，后入场诊断不得变成入场特征。
