# 配对失败分析的前后均值必须共用已知样本

- **问题**：V12 的描述表已有“配对已知数”，但代码审查发现旧收益、新收益各自求均值，遇到单臂缺失时会用不同分母。
- **死胡同**：仅保留所有原始行并不够。分别 dropna 后展示“旧→新”，读者会自然把两者相减；这个变化可能不等于实际配对变化。此问题在实际产物生成前由合成非对称缺失检验修正，未改历史收益。
- **有效路径**：显式建立两臂同时已知的掩码，前后均值和差值使用同一掩码；总行数、配对已知数仍分别保留。极端例子也按实际正负变化命名，不能把排序最大值自动叫作改善。
- **通用规则**：任何前后对照表都增加“仅一边缺失”的反例，并验证 `paired_new_mean - paired_old_mean == paired_delta_mean`。缺失不是零，也不应隐式改变比较人群。
- **牵连**：`yoyo/evaluation/hourly_impulse_frozen_ma_facts.py`、`tests/test_hourly_impulse_frozen_ma_facts.py`。只涉及说明账本，不改变退出策略或筛选交易。
