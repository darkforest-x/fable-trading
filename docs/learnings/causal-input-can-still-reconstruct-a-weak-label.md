# 因果输入仍可能完美重建弱标签

- **问题**：L1.5 的全部特征都早于 L1 决策时刻，LONG/SHORT 验证 AUC 却同时达到 1.0。进一步检查发现，单独一个“核心末端到决策端已推进多少 ATR”的特征也能完美区分正负。
- **死胡同**：只检查“有没有看决策时刻之后的 K 线”仍不够。原弱标签用核心之后是否出现确认推进来定义 launch/no-launch，而特征也读到了同一段核心后确认 K；它虽然对 L1 决策是因果的，却直接复述了标签生成规则，学到的不是启动前全局形态。
- **有效路径**：先停止下游候选过滤与收益训练，冻结 AUC=1 的失败证据；再把形态层的输入右端物理移动到每张图自己的 `core_end`，删除所有确认段长度/推进字段，并用“修改 post-core 任意 K 不得改变特征”的测试锁死合同。重新训练后 AUC 回到 0.89–0.95 的可信范围，SHORT 误报率与经济门也诚实暴露为失败。
- **通用规则**：审计弱标签模型时，不能只问“特征是否早于交易决策”，还必须问“特征是否包含定义标签时用过的证据”。任何反常的近完美指标，第一步做单特征 AUC、正负取值区间和标签生成依赖对照；形态模型的输入右端应对齐形态语义终点，而不是默认对齐更晚的检测决策点。
