# 本地网页交付必须有独立于任务进程的服务生命周期

- **问题**：观察台当轮HTTP和浏览器验收均成功，下一轮Owner却打不开；18766无监听，serve进程已不存在，而历史快照完整且版本仍匹配。
- **死胡同**：再次在工具临时终端里执行serve只能短暂恢复；HTTP200证明此刻可用，不能证明交付后还会运行。也无需重新扫描市场来修复页面可用性。
- **有效路径**：复用本仓已有LaunchAgent模式，以独立label、绝对解释器、固定工作目录、loopback端口、KeepAlive和登录启动托管网页；清理子进程环境，只运行serve。卸载旧job是异步的，应确认旧job消失后再bootstrap。由独立调用核对PID归launchd、健康接口、原快照和浏览器画面。
- **通用规则**：交付本地URL前同时验收服务所有者、生命周期与停止方法；存量数据可直接恢复时不要把基础设施故障变成重新评估。
