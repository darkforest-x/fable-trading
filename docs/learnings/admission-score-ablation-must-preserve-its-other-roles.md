# 替换入场评分必须保留它在止盈和仓位中的其他职责

- **问题**：2026-10-31 Owner要求八个周一1.618策略只把主单入场过滤换成触价前15m排列分≥3，保留评分决定的目标和仓位。若把所有评分引用一起删除，实际就同时改变了目标、加仓和资金分配。
- **死胡同**：将“只看排列”理解成完全删掉模型，会使V3缺少目标选择规则；对低分套原线性公式再强行设正仓位，也会偷偷改仓位。只看胜率则会得出错误的统一替换结论：V2 60m胜率32.48%升至59.40%，全期1000U账户却从1360.99U降至505.21U。
- **有效路径**：先由Owner确认只替换主单准入，再固定评分时点、目标、止损、保本、加仓条件和仓位函数。排列样本1500次，其中217次缺评分：V3不能确定目标，保留缺失登记；另313次已知低分在原线性公式下仓位非正，仍不分配资金。复用Nautilus成交，对新订单补齐同规则匹配对照，再由原资金分配器计算独立成交与资金账户两套结果。
- **通用规则**：修改过滤变量前，逐项列出该变量在准入、目标、仓位、加仓和退出中的作用。单变量消融只改变已授权的作用，缺失和零仓位不能隐式修补。需要同时看胜率、受资金限制的净收益、时间稳定性和匹配对照，不因一种规则在一个策略改善就推广到全部策略。
- **牵连**：`exp-monday-order-only-20261031-v1`。全期V3账户1.04→1.65倍，V3add1.05→2.40倍，V3lock1.13→1.64倍；V3add20全期6.60→5.70倍但2026年1.33→1.89倍、回撤58.35%→26.17%；Spike全期1.02→0.20倍。八个新方案2026匹配随机检验均未达到p<0.05，规则使用过同一历史，仍不构成前向验证。原8策略笔数和胜率、7个非All-in账户指标均复现；39165笔新增原生持仓的费用及38900笔主单确认时钟通过校验。无生产变更。
