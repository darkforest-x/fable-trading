# 裸时钟会掩盖回放事件语义

- **问题**：历史事件 `2026-04-29T04:00:00Z` 被 UI 截成 `04:00:00`，用户无法判断日期、时区，也容易理解为刚刚发生的检测。
- **死胡同**：用正则只提取 ISO 字符串里的 `HH:mm:ss`。格式很紧凑，但同时丢失了判断事件新旧所需的三个关键维度。
- **有效路径**：保留完整 ISO instant，在主文案显示日期和北京时间，在次文案显示 UTC，并明确写“不是当前时间”；实时行情另设“推送接收时间”和“K 线开始时间”。
- **通用规则**：交易界面不得把历史事件显示成无日期、无时区的裸时钟；至少同时回答“哪一天、哪个时区、这是事件时间还是接收时间”。
- **牵连**：`prototypes/fable-signal-console/src/App.jsx`、L2 `available_at`、OKX candle `ts`、浏览器 `Intl.DateTimeFormat`。
