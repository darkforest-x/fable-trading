# 浮动开单面板必须独立准备入场风险数据

- **问题**：周一 1.618 快捷模拟开单复用原表单，但首次选中非持仓币种时，开仓预览返回缺少标记价或风险档位的 503；BTC 等已热缓存币种正常。
- **死胡同**：仅验证表单与下单接口复用不足以证明流程完整。原交易页的图表轮询隐式预热风险缓存，快捷面板不挂载图表；原估算请求只在限价或填写止盈止损后运行，因此普通市价单没有预热入口。放宽风险校验会掩盖缺失输入。
- **有效路径**：快捷面板打开和换币后独立轮询只读估算，登记风险数据需求；估算返回与入场同口径的缓存就绪状态。风险未就绪时显示准备中并禁用提交，数据恢复仅解锁按钮，不自动下单。原报价、幂等回执和后台风险刷新继续复用。
- **通用规则**：将完整页面拆为浮动组件时，逐一核对被移除组件承担的数据准备职责。行为验收至少覆盖冷缓存、无选填项、数据恢复和显式点击提交，不能只用已预热的主流币种。
- **牵连**：`yoyo/monitor/static/paper-desk.js`、`yoyo/research_workspace/paper_desk_api.py`；相关前端与后端回归包含没有网络同步调用、不生成执行报价或成交、过期风险不解锁、就绪恢复不会自动提交。
