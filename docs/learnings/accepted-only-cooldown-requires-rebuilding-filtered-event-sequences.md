# 接受信号才计冷却时，过滤必须重建整条事件序列

- **问题**：V3 增加均线形成过程门后，不能只在旧事件 CSV 上删行，就声称这是新指标的结果。
- **死胡同**：固定旧事件再筛选会保留被拒旧父的冷却影响，抹掉后来本应有资格的新边沿；只统计删掉多少还会隐藏新时点。
- **有效路径**：D 从原始因果特征逐根重放，原 raw 条件边沿不变，被拒不延长 accepted-only 冷却。实际出现746个原 V3 没有的父时点，及时新增捕获14个原漏例；但只保留761/1463原及时正例，因此仍是失败研究。NEAR 目标根的冷却虽然解除，形成门本身仍拒绝；下一根资格变好也不能补发旧边沿。
- **通用规则**：任何与接受事件有关的冷却、父子归属或占用状态，都要重建完整序列；同时报告旧时点保留、移除、新时点及标签保留，不能把后过滤的子集当可运行指标。
