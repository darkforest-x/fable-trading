# 订单盈亏图必须绑定冻结报价，不能反过来生成交易输入

- **问题**：Owner希望手动订单弹窗用真实K线和多空框直观看入场、止损及3R/5R止盈；新图表不能拖慢已有预览，也不能把历史形态价当成当前订单价。
- **死胡同**：直接调用旧监控`/api/chart?timeframe=5m`返回400，该入口不支持5m；仅复用旧检测快照又可能已经过时。把图表读取串进私有订单预览会重建等待链，客户端画出的价格也不能充当订单依据。
- **有效路径**：新增只读显示入口，复用现有公共K线hub，读取100根已确认且连续的5m OHLC，缺最新或缺口失败，不补造；与私有预览并行加载。图表红绿框仅取服务端本次订单的入场/SL/TP，做空时盈利框自然在下方。未来空间只画价位框、不填未来K线。使用原60秒截止，修改参数清旧框；切币/关窗中止读取，晚响应不能写入新票据。
- **通用规则**：交易图表是订单的解释，不是执行的来源；显示请求、订单有效期和确认写入分别管理，失败也要明确标注并可重试。缩放后的框必须沿同一时间/价格坐标投影，不能按截图固定像素拼接。
- **牵连**：`manual_chart.py`、`manual-position-chart.js`、`manual-live.js/css`、模块加载器及对应测试。公共数据共享缓存不改原检测、执行或VPS写者；未更改止损规则、确认权限或账户隔离。
