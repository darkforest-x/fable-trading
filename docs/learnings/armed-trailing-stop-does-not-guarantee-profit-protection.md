# 跟踪已激活不等于止损已保住利润

- **问题**：SPIKE V12.8 近两月回放中，USUSDT 15m 一笔交易曾有10.366R浮盈、收盘最高3.224R，却仍以初始止损净亏1.061R结束。
- **死胡同**：只检查2R激活布尔值，就推断退出实现有bug或已保本；只看最高价越过2R，也无法证明收盘门被触发。两种推断都省略了实际保护价。
- **有效路径**：用已冻结5m精确聚合逐柱核对。2026-07-27 04:00UTC入场0.046406，初始止损0.044872、风险0.001534。06:15柱收盘0.051351，ATR增至0.001908049，确实激活2R，但4ATR候选取整后仅0.043718，低于原止损；只收紧不放松的规则保留0.044872，11:00柱低点0.044198触发它。这是波动扩张后的原规则结果，不是激活检查失效。
- **通用规则**：分别审“盘中最高浮盈”“收盘是否激活”“实际保护价”“扣费保本价”四个量；激活标记不能替代保护价或风险会计。拟改保本/ATR倍数时另做单变量对照，不能用一个案例自动改默认退出。
