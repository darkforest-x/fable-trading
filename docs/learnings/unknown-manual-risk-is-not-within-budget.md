# 未知风险不能显示为预算内

- **问题**：手工登记允许原始止损缺失，最初的预算比较却把未知风险落为 false；净收益 R 的分母也容易与含费预算混淆。
- **死胡同**：用 `risk is not None and risk > budget` 同时表达“已知未超限”和“无法判断”，会把缺失数据伪装成通过检查。单靠入场与止损计算的价格风险也不能证明含手续费、资金费和跳空的总风险受控。
- **有效路径**：比较改为仅描述价格风险，止损或预算缺失时返回 null；显示净收益除以初始价格风险的明确口径。真实成交照常记录，超限只留事实，不清除偏离交易。
- **通用规则**：金额比较前先写清分子、分母和未计成本；已超、未超、未知必须是三个不同状态。
- **牵连**：`yoyo/research_workspace/manual.py` 的 `price_risk_budget_exceeded` 与 `outcome.r_basis`；不修改现有回测的 20bp 成本契约。
