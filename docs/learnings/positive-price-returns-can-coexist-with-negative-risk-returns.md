# 同一批交易价格均值为正，R均值也可能为负

- **问题**：Owner选定29币的V11.2 15m，409笔扣费价格均值+0.3840%，净R均值却−0.01949，若只报一列就会把“赚不赚”说成相反答案。
- **死胡同**：把价格收益和R当两种可直接换算的统一单位，或把累计R当账户百分比。每笔初始止损距离不同，不存在把整个池一乘就可互换的常数。
- **有效路径**：逐笔验证netR=net_return/initial_risk_frac，再分别报告等名义金额的价格均值和等初始风险金额的R均值。此池价格PF=1.2834，R的PF=0.9726；两种仓位权重确实给出不同结果，算式无矛盾。
- **通用规则**：汇报策略收益必须先说明每笔金额如何分配。两种权重均有解释价值，但在未建模并发、杠杆、资金约束之前，任何一项都不能直接叫账户收益率，也不能事后选正值口径冒充稳定优势。
