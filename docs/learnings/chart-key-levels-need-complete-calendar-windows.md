# 自动关键位要先定义日界与缺失行情的含义

- **问题**：自动画周一区间、Fib 和 nPOC 时，日界与缺 K 线会直接改变价位和“未触及”的结论。
- **死胡同**：把一天固定当作 96 根 K 线，无法覆盖纽约夏令时；只搜索已存在的 K 线，缺失期间可能已经触及 POC，却被误标为未触及。把 15m 汇总量当逐笔成交量也会给出过度精确的价位。
- **有效路径**：按所选时区的日历边界枚举应有时间戳；周一完整收盘后才冻结并生成 Fib。nPOC 要求该日完整且此后每根已收盘 K 线连续、均未覆盖 POC。剖面明确采用 80 档、70% 连续价值区和 K 线区间均匀分配的估算口径。结构分数遇到平价为零，缺 K 线则不可用。
- **通用规则**：先证明窗口完整，再解释价格行为。空缺是未知，不是未触及；估算指标要同时展示来源粒度与算法边界。
- **牵连**：`yoyo/monitor/market_context.py`、`static/market-sync.js`；纽约、UTC、北京日界和 DST/缺口/nPOC 测试。多空指数仅为三个条件等权的观察分数，不能解释为胜率或满仓指令。
