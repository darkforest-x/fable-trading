# 慢退出的单仓均值改善可能只是占位筛掉了后续亏损

- **问题**：V8原生15m管理的单仓净均值比5m少亏，但相同286请求的独立交易更亏；若只报单仓均值，会误判退出逻辑改善。
- **死胡同**：仅比较两组已成交均值，或只看PF／最大赢家。慢退出还改变持仓时长和后续能否入场，分母从286变262，不能把样本路径变化归给同一交易的退出收益。
- **有效路径**：固定原286请求计算D、固定283组三控制计算I；另在原959源区逐个从arm重建单仓，跳过为已知零、未知仍未知。V8 D为−2.12bp，I为−3.08bp；单仓原959意图变化+1.20bp，来自阻挡的24个入场含20亏4赢，而不是同交易普遍变好。全部区间跨零，不升格生产。
- **通用规则**：任何改变等待或持有时长的策略，同时报相同请求反事实、匹配控制增量与固定意图单仓；先解释选择分母变化，再讨论盈利。
