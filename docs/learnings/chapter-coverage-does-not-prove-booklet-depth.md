# 章节覆盖不能证明交易小册具备教学深度

- **问题**：2026-10-15，Owner 指出现有交易小册过于简单且缺少图表。核对 `trading-books.json`，四本共 92 个章节条目；正文、练习与答案合计的平均字符数分别约为 579、470、392、200，全部没有配图。这里的字符统计是诊断证据，不是新的字数门槛。
- **死胡同**：按目录为每节填入固定的四段摘要，再以章节覆盖和 `reviewed` 数量表示小册完成。它只能说明有对应条目；完整的案例推演、图表解读和辨析能力没有得到检验。尤其订单流第 7 节只有关于成交力量的概述和问答，没有逐价成交数字、图形或推理过程。
- **有效路径**：本轮确认应将原文阅读覆盖与小册教学质量分开验收。提出以完整论证单元组织精读，保留原章节映射和页码；每个核心技术单元需要解释问题、定义、证据、推理、案例、失败条件，并配能承载解释的图。此处只完成诊断和技能调研，尚未完成现有小册的重写。
- **通用规则**：先逐页核对一个代表性单元及其图表，检查读者能否根据材料完成一个新案例的分析，再批量制作。数字图表应可复算；原图、编者示意图和实际行情必须明确区分。练习隐藏后续行情时，结论只能依据当时可见信息。不能仅靠篇幅、目录覆盖、测试通过或图表数量宣布深度达标。
