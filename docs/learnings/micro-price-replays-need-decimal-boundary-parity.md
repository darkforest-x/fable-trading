# 微小币价的回放必须检查阈值与跳动价边界

- **问题**：PEPE 回放的最近 10 单与 TradingView 一致，扩展至完整窗口却多出一单；修正信号后退出签名仍差 9720。
- **死胡同**：仅看近期样本、假定 OHLC 一致就意味着信号和触价一致。微小价格的浮点减法让数学上的 K=80 变成 80.0000000000001，也会把相同 tick 的触价误判成未触及或跳空。
- **有效路径**：先分解入场时间、价格、方向、退出四种签名，定位 2026-08-04 16:15 UTC 的阈值边界；Stoch 中间值归一至十位小数，价格比较容差设为 tick 的千万分之一。完整 146 单四种签名全部一致，已有近期逐笔记录仍一致。
- **通用规则**：移植微小报价资产的规则时，先核对严格阈值和 tick 等价关系，再优化参数；通过少量样本不代表全窗口实现一致。容差必须远小于交易最小跳动，不能当作待优化阈值。
- **牵连**：`yoyo/evaluation/pepe_range_exits.py`、`pepe_range_native.cpp`、`pepe_range_audit.py`；`experiments/active/exp-pepe-range-exits-20261020-v1/parity_receipt.json`；未修改 Pine 的交易规则。
