# 周期标签用于核对来源与分组验收，不是视觉形态的类别边界

- **问题**：在准备 v6 三窗口数据时，将 Grade-A 负例全为15m、正例多为小周期，表述为不能混用的理由。Owner指出同类均线密集图在大小周期上都可能出现。
- **死胡同**：把样本来源分布不同直接当成排除条件，或者强制每张正例只能配同周期负例，会把原采样方案误当成视觉检测任务的必要定义。仅凭周期计数也不能证明模型已经学到周期捷径。
- **有效路径**：沿用一个共享形态模型，允许跨周期混合正负图；保留周期元数据用于统计误报、漏检与来源差异。是否采纳一张负图，依据目标语义、实际可见形态、渲染与均线定义、事件保护及时间切分，不能只看周期。旧困难负例仍要审标签，不能因允许跨周期而自动合格。
- **通用规则**：区分模型输入、监督类别和溯源字段。元数据分布差异是要检验的风险，不自动构成禁止合并的证据。
- **牵连**：`yoyo/datasets/ma_morphology_threeview.py::negative_inventory`；实验内保留原始审计与交付记录，新增 `evaluation_contract_v2.json` 明确替代此前的同周期硬要求。既有5,523张正图、事件分组及保护规则保持原样。
