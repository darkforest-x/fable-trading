# 手机 HTML 预览必须让核心内容在纯静态模式下可见

- **问题**：TG 手机内置预览能显示 HTML 头部与样式，却没有显示 200 张内嵌图片。
- **死胡同**：把全部图卡默认隐藏，再依赖 JavaScript 激活当前卡片；TG 预览不执行脚本时，页面就只剩头部。即使增加无脚本回退，也保留了 Owner 不需要的按钮交互。
- **有效路径**：删掉按钮、导航逻辑和全部 JavaScript，让 200 个图卡在 HTML/CSS 默认状态下依次展开，用户直接纵向滑动查看。
- **通用规则**：面向微信、TG、飞书等手机内置预览交付 HTML 时，核心内容必须仅靠 HTML/CSS 完整呈现；脚本只能增强非必要体验，不能控制首屏或主体可见性。
- **牵连**：`scripts/build_eth_3m_v10_prebox200.py`、`datasets/eth_3m_v10_prebox200/v10_prebox200_mobile.html`、TG 内置 HTML 预览限制。
