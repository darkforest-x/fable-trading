# 固定本金滚仓要同时度量成功概率和实际兑现金额

- **问题**：1000U拆成10个100U事件，假设7笔归零、3笔大赢，如何将旧高R滚仓结果用于研究目标而不混淆本金与利润。
- **死胡同**：把3笔终值直接当利润后再减700U，会多算300U本金；把原价格10R直接乘100U或把事后最优加仓均值当可执行均值，又混淆了风险分母与未来信息。
- **有效路径**：先固定成功事件终值B、失败终值0，写出账户终值3B、净利润3B-1000；再分别列纯假设、旧未来已知最优均值、因果执行实际均值。30%必须说明是信号标签命中，还是强平路径存活并兑现的联合成功概率。
- **通用规则**：先冻结每笔外部注资上限、成功定义与终值单位，再合成账户期望；原选样赢家分布不能自动迁移给新筛选器，单笔中位数的三倍也不是组合中位数。
