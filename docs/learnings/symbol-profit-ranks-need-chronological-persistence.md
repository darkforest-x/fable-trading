# 全历史币种盈利排名不能代替排名持续性证据

- **问题**：SPIKE V13.1 逐币累计净 R 榜上出现高 PF 与高单笔收益，Owner问能发现什么；需要区分真实收益分布、少数尾部交易、币种可重复性和信号相对随机入场的优势。
- **死胡同**：直接把全历史前十名解释成未来白名单并不成立（本次未采用）。名单使用了整个评价期的结果；1H 每币每方向的中位交易数只有多头3笔、空头2笔，少数单笔便可决定名次和PF。
- **有效路径**：先核对全量、最大单及最大1%盈利交易的敏感性，再只用2025年前入场且退出的交易排前十，检查2025年后的原始入场。15m多/空前十在后期分别48/77笔、-10.070769/+12.785551R，1H多/空分别28/19笔、-6.775723/+0.108347R。同期平均净R的逐币前后Spearman相关依次约+0.051/-0.014/+0.120/-0.146。原匹配随机样本仍须保留，匹配少时不能从正收益推出信号优势。
- **通用规则**：先问收益来自多少币、多少单，再问赢家能否跨时间延续，最后问是否胜过同条件随机对照。删除最大盈利单是分布敏感性检查，不是建议把趋势大单删掉；先前已看过的数据即使按时间重排也不是新盲测。
- **牵连**：`yoyo/evaluation/spike_v131_ranking_diagnostics.py`、`experiments/active/exp-spike-v131-symbol-summary-20261017-v1/results_v1/ranking_diagnostics_20261017.json`。保持原20bp成本；1H仍是固定入场退出重放并保留19笔2022年12月原交易。不改币池、方向开关、生产或训练资格。
