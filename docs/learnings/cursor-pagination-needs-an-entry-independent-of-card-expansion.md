# 游标分页入口不能被卡片展开门槛遮住

- **问题**：历史回放首屏已有 2,000 条并带下一页 cursor，但同一个按钮优先用于“显示更多 24/2,000”，用户必须逐批展开当前页才看到更早历史。
- **死胡同**：把视口内卡片数量和服务器分页共用一个按钮，虽然 API 能读取早期记录，实际浏览路径仍被 83 次无关点击阻塞，而且“共 2,000 条”容易被误读为全量。
- **有效路径**：保留视口“显示更多”，另设独立的“加载更早记录”按钮；只要 cursor 存在就立即可点。首屏计数明确为当前页，不能当作历史总数。
- **通用规则**：客户端展示切片和服务端 cursor 是两个维度；两者都可继续时，必须同时提供入口并说明各自范围。
- **牵连**：`yoyo/monitor/static/index.html`、`app.js`、`tests/monitor/frontend_cards.test.cjs`；只影响本地回放浏览，不改变信号、账本、候选或通知。
