# 更多负样本的收益必须由同数据集训练 arm 证明

- **问题**：10,000 正 + 30,000 负的新模型把静态 mAP50-95 从历史 0.332 提到 0.792，且固定阈值负例误报只有 0.845%；表面上很像“增加 20,000 负例”带来的巨大提升。
- **死胡同**：直接和历史 960 模型相减。历史权重使用另一套正例框、cutoff、split 和验证集；即使训练超参和分辨率相同，也无法把标签一致性、完成态可见性、验证难度与负例数量拆开。
- **有效路径**：先把异常高分当泄漏检查：验证跨 split 图像/事件/完整依赖区间交集全为零，再对全部空标签 val 负例以冻结阈值报告误报；最后只把新模型写成绝对结果，把旧模型明确标为非因果背景。
- **通用规则**：要声称“更多负例有效”，必须固定同一批正例、同一 split、同一配方和同一验证集，只训练 `N` 与 `3N` 两个 arm；少任一项都只能报告相关变化，不能分配因果功劳。
- **牵连**：`exp-15m-ma-launch-owner-yolo-neg30000-train960-v1`、`dataset_lineage_control`、静态 mAP、固定阈值负例 false-fire、完成态弱标签与 `production_eligible=false`。
