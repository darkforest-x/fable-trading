# 图表标注验收要保护 K 线，不只检查标签之间的重叠

- **问题**：开平仓标签互不重叠，但它们的文字底板仍盖住成交附近的蜡烛，用户无法读图。
- **死胡同**：围绕成交价上下移动标签、添加引线，只解决标签之间的冲突，没有检查蜡烛本体是否被挡住。
- **有效路径**：顶部摘要已有价格与时间，图内删除重复文字、底板和引线，仅保留细成交刻度及原始区间线段；点成交与区间成交的时间、价格保持不变。
- **通用规则**：先判断标注文字是否必须进入数据区域。已有外部摘要时，回归测试应禁止成交绘制器调用文字和背景填充，而不是只测试两个标签矩形是否相交。
