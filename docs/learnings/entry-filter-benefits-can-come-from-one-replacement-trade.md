# 入场过滤后的收益改善可能主要来自一笔替代交易

- **问题**：ETH4h方向门使连续窗口净收益18.09%→22.39%，回撤6.67%→5.07%，容易被概括为“过滤了坏信号”。
- **死胡同**：直接对照净收益或每笔均值，会忽略过滤改变仓位占用、冷却以及后续可入场集合；匹配覆盖从97.10%降至88%也让配对均值分母不同。
- **有效路径**：按signal_i逐笔连接，49个共同入场的退出时间及单位收益相同；移除20笔原合计净盈利6.74USDT，新增1笔盈利26.43USDT，共同单仓位变化增益1.80USDT，合计改善21.49USDT。开发期确实移除16笔亏损，但连续期优势又受一笔新增赢家主导。后段复核收益8.09%→7.97%，因此只保留研究候选，不宣布稳健因果优势。
- **通用规则**：入场门变动后先拆共同、移除、新增三类身份，并区分共同单退出变化与仓位变化；用完整支持率说明随机对照差异，不能用不同分母的配对超额之差冒充过滤器效果。
- **牵连**：`experiments/active/exp-eth4h-exit-exploration-20260907-v2/results/independent_validation.json`、`yoyo/evaluation/eth4h_exit_exploration_verify.py`。归因是事后诊断，不是按未来盈利选择入场。
