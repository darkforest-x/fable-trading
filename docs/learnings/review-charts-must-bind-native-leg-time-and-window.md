- **问题**：ETH 扫极值加多周期固定1R的27笔父账本保留收益，却没有完整成交价和原因；其中一笔持仓379根5m，另有一笔同K双触。
- **死胡同**：用胜负倒推止盈止损价，或强套60根15m窗口，会丢掉成交来源和远端退出。只将主图时间转换为北京时间，辅助的多周期确认字段仍可能显示UTC。
- **有效路径**：按parent_id联结原生leg0，并根据重配记录选择旧缓存或delta来源，逐项核对入场、止损、退出索引、毛R与原费用。长持仓图扩展到152根15m；同K双触保留原OHLC顺序说明。所有事件字段统一时区后再绘制。
- **通用规则**：图像不是新的交易结果。先绑定完整成交谱系和时间语义，再决定窗口与标注；不以好看的窗口代替实际持仓过程。
