# 月度归档文件名不能代替逐行收盘状态

- **问题**：OKX PEPE 部分 2023—2024 月度归档含大批 confirm=0，简单聚合会将未确认行作为历史完整事实。
- **死胡同**：假设历史月度 ZIP 中每行天然已确认，或丢弃这些行后继续回测。前者未经验证，后者造成跨月缺口并改变指标窗口。
- **有效路径**：逐行检查状态，排除未确认分钟；按时间缺口从同一交易所公共接口取得已确认原生 5 分钟 K 线，保留补齐路径和时间范围。合并后检查全序列间隔，并与已登记的原生 5m／15m／1H 缓存逐项对齐。
- **通用规则**：数据容器名称、下载成功和文件存在都不能代替行级可用性；拒绝不完整数据时，必须继续核对窗口是否连续，不能隐式压缩时间。
- **牵连**：`yoyo/evaluation/pepe_range_data.py`；`experiments/active/exp-pepe-range-exits-20261020-v1/data_receipt.json`。仅公共研究数据，无生产写入，不做内容哈希。
