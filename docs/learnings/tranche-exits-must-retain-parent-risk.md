# 分批退出必须回到原始整仓风险计算收益

- **问题**：V2.30 同时比较分批止盈和提前减半止损。减半部分的止损变近后，其框架持仓的风险分母也变小，直接平均两条原生持仓的 R 会夸大整笔交易结果。
- **死胡同**：直接平均每条原生交易的净 R 不成立。例如原仓风险为 1，第一半在 −0.5 退出、第二半在 +5 退出，整仓毛收益应为 2.25R；不能把第一半重新定义为 −1R、第二半另按自己的分母汇总。本次以合成场景明确阻断该算法，未用于历史结果。
- **有效路径**：两个原生 HEDGING 持仓分别执行各自止损和目标；汇总时用实际退出价、原仓份额及父交易风险计算。费用也按原份额与原始名义金额核对。已退出的第一半不再因另一条减仓条件重复减少余仓。
- **通用规则**：先保留父交易的初始风险、原仓份额与成交明细，再聚合收益和胜率。风险分母不随减仓或保护价调整变化；胜率数父交易，不数子仓。
- **牵连**：`yoyo/evaluation/range_v230_exit_compare.py`、`tests/evaluation/test_range_v230_exit_compare.py`；本轮34组原生运行共10580持仓、21160成交，逐条价格/时间对照及佣金守恒通过。固定20bp成本、冻结BTC131/ETH99入场，未改Pine或实盘。
