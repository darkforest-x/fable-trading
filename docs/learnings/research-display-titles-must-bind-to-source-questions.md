# 中文研究题名与原始问题绑定，不能覆盖证据

- **问题**：实验目录把英文完整研究问题当标题，技术编号和长参数掩盖了本人关心的问题。
- **死胡同**：仅缩小卡片、截断英文或按编号猜译，都不能提供可辨认的研究问题；直接重写旧登记又会改变当时记录。
- **有效路径**：逐项整理简短中文题名，以实验 ID 和原始问题 SHA-256 绑定；API 追加展示字段，正文、结果、资格仍来自原登记。问题变化后旧题名自动失效。列表展示问题与真实结论，原文与配置放详情。
- **通用规则**：展示层可以重新组织研究内容，但译名必须可追溯到具体原文；未验证的题名不能沿用到已改变的问题。
- **牵连**：`yoyo/research_workspace/experiment_labels_zh.json`、`catalog.py`、实验和 YOLO 前端；不改历史注册表或研究结论。
