# 截图形态检索先把像素蒸馏成无量纲时序合同

- **问题**：只有一张裁掉币种、价格轴和周期标签的 K 线截图，却要在历史 OHLCV 中找相似形态；直接把截图当图片近邻，既无法跨价格尺度比较，也容易只匹配背景、均线颜色和画布布局。
- **死胡同**：只用末根涨跌幅或几条人工阈值会丢掉“连续破位—放量长下影—弱回收”的顺序；整图像素距离又会被坐标轴、留白和渲染风格支配。先看结果再改窗口或权重，还会把一次探索变成事后调参。
- **有效路径**：先从蜡烛实体、影线和量柱的固定颜色连通域恢复末端 OHLCV 的相对像素序列；在打开历史结果前冻结窗口、前段/末段权重、成交量掩码和分段 DTW 半径。候选与截图都用前段典型真实波幅及成交量中位数归一化，先锁步距离粗筛，再在边界两侧分别做小半径 DTW，最后按同币事件和跨币市场时段去重。
- **通用规则**：遇到缺价格轴的行情截图，第一步不是猜币种或调收益门，而是把可见蜡烛蒸馏成“方向、顺序、相对振幅、影线、量能”的无量纲查询合同；结果只能叫形态近邻，不能叫概率、金标或交易信号。
- **牵连**：截图像素解析、OHLCV 历史检索、DTW/锁步权重、holdout fail-closed 读取、市场时段去重；不得据此改阈值、训练、promote、ACTIVE、forward 或交易状态。
