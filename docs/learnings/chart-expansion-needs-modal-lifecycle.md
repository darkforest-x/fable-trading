# 图表放大必须具备完整的模态生命周期

- **问题**：市场图表只用 fixed 和阴影放大，按 `/` 后焦点仍能跳到背景币种搜索，页面也能在背后滚动。
- **死胡同**：给按钮补 Tab 循环只能挡部分路径，不能隔离背景快捷键和其他弹窗。
- **有效路径**：把原图表节点移入原生 dialog，关闭时移回原位置，保留 chart/canvas 身份；锁背景滚动、屏蔽背景搜索、Esc 后恢复入口焦点，离开路由时清理。
- **通用规则**：视觉遮罩不等于模态。放大图同时验收背景不可操作、退出焦点、路由离开和窄屏工具栏，不重建行情图来实现放大。
- **牵连**：`market-terminal.js/css`；保留六均线、K 线数据和用户缩放视角。
