# 停控制器不能假定扫描子进程继续存活

- **问题**：在首轮结果冻结、第二批miner已启动后，向调度父进程发SIGTERM，预期只切换调度代码。其后检查发现miner也已退出，未留下master；两份源receipt完整。
- **证据边界**：能确认父进程退出后子进程没有继续完成；没有足够证据将具体退出机制归因于Python、shell或执行工具中的某一层。仅保存了PID和命令不证明子进程持续运行。
- **恢复**：确认没有活动miner，逐份核验已完成receipt的源SHA、规则binding和产物SHA；保留失败日志与退出记录，由原矿工复用两份完整结果并重算剩余23份未落盘来源，不伪造完成master。
- **通用规则**：控制器迁移优先等所有子任务结束的边界，或者预先提供显式停止边界。若确需中断，恢复依据是完整校验的源回执，不是“杀父不杀子”的假定。
