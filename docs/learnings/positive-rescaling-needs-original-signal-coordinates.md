# 复用符号门的账务代码时，必须保留并验证原信号坐标

- **问题**：V22 的四币历史位置评分变化范围为[-2,2]，已有V21账务接口只接收[-1,1]分数。直接截断或把新值冒充旧绝对均值，会混淆信号含义和边界检查。
- **死胡同**：仅凭原账务测试通过，无法证明新两时点、八评分、52小时支持正确；原模块只懂范围、符号和可用时刻。无须因此复制整套成交账务，也不能悄悄改变旧V21定义。
- **有效路径**：保存八个原整数rank、两完整小时证据及原差值；先整数求差，再除200给出原变化，除400作正比例账务适配。入场由原整数差决定。适配层逐项精确校验评分、原差、两均值及缩放，未知保持NaN，之后才允许复用冻结的旧退出路径。
- **通用规则**：只有明示且不改变决策边界的变换才能用于复用接口；转换后测试不能替代原坐标、时钟和来源验证。不要把“接口兼容”写成“新策略有效”。
- **牵连**：`yoyo/data/hourly_impulse_breadth_change.py`、`yoyo/evaluation/hourly_impulse_breadth_change_research.py`及其合成测试；V21模块和V18退出不修改，新公式必须另做因果与收益检验。本笔记记录实现契约，不是盈利结果。
