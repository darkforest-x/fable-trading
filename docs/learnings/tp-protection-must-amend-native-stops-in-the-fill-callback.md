# TP 后保本必须在成交回调中修改保护单

- **问题**：分批 TP 后立即保本必须允许同一根 K 线后续路径触发余仓保护；原 timed-only 研究没有这个触发条件。
- **死胡同**：只在 on_bar 收盘检查 TP，会错过本根后续反转；即使回调提交修改，框架默认消息队列也可能将命令推迟到整根结束。四档独立持仓也不能各自等到自己的 TP 后再保护，因为自己的持仓已平。
- **有效路径**：以 parent_id 关联原整仓，真实 TP 成交回调立即修改仍持有的同组原生 stop，禁用该策略的延后消息队列。保留单腿费用与整仓权重，定时条件先发生则不覆盖。原生多空同 K 反转、两档 TP、跳空、先止损、跨组隔离与独立整数路径逐一校验。
- **通用规则**：入场、成交、止损修改各自有时钟。口头的“立即”必须落实到框架撮合事件顺序，不能只看最终价位或单根 OHLC 同时覆盖。
- **牵连**：`yoyo/layers/l3_backtest/nautilus_independent.py`、`tests/evaluation/test_nautilus_target_breakeven.py`；新增能力限于收盘入场的四档研究，历史原生限价入场不静默复用。v1 已完成结果保留为缺少 TP 触发的旧口径，v2 独立重算退出。
