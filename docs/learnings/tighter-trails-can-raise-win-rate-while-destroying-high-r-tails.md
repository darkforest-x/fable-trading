# 止盈更贴近高点，可能提高胜率却损失大趋势

- **问题**：V9有1,164笔记录毛MFE>10的多单，但只有367笔净>10，尝试用已知最高high代替当前close作为4ATR追踪锚点。
- **死胡同**：把“曾经浮盈很大但最后回吐”直接解释为追踪不够紧，忽略同一规则会在趋势刚达到2R时就提前触发。不能只重算最终大赢家的末端，更不能以单个WIF改善代表全池。
- **有效路径**：保留原初始风险、成本和2R收盘启用，完整串行重放3,531流；净>10R从367降259，原大赢家丢173、新增65，净>20R从100降57；胜率却29.33%升30.63%。前后时间段与同退出随机对照都没有支持替换。
- **通用规则**：优化尾部目标时，把早期趋势存活与成熟后的兑现区分开；任何保护改动必须同时报告大赢家保留率、整体价格收益与随机超额。更高胜率、更小回撤不能替代高R目标。
- **牵连**：`yoyo/evaluation/spike_high_r_v1.py`、`analysis/p1_spike_high_r_20260921.md`；本轮候选拒绝，未改现行默认。成熟阶段保护仍是未验证的后续假设，不是已经成功的修法。
