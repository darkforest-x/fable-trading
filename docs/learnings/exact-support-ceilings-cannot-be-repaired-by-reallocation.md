# 精确匹配的供给上限不能靠重新分配修复

- **问题**：原小时穿均线251母样本只匹配154组，是否是贪心抢占了稀缺控制？
- **死胡同**：仅根据94条不足记录推断贪心有问题；只看到个别母有3/4候选被占用，
  就认为换分配器可以增加覆盖。这忽略了共享候选的组件总容量。
- **有效路径**：V10先复现全部旧字段、154组/462控制及分配哈希，再保存完整合法图。
  231连通组件的独立上界相加恰为154，旧贪心本身达到上界，MILP证书再次确认154。
  三个被占用母所在组件均2母，共用3/4/4候选，只能让其中1母完整配3控制。
  重新分配可换入个别母，不能增加总量。97缺配另含3母缺支持、19六键后不足、
  1期末限制、71穿线排除后不足；这些是顺序描述，不是放松规则的因果收益。
- **通用规则**：先用完整合法图的独立上界与可行下界夹住容量，再决定是否优化分配。
  若相等，停止调种子/分配器。条件对照超额只能用于有支持的母群，不能向全群外推，
  更不能用缺配标记作为自动盈利筛选器。
