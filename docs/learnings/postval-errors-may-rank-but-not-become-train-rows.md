# 事后错误可以排序训练期候选，但不能冒充训练行

- **问题**：连续canary得到254个Owner确认误报，但这些事件严格晚于冻结val；既要利用这批宝贵语义，又不能把晚期图片直接塞回早期训练集。
- **死胡同**：直接复制254张会造成训练时间晚于val；完全丢弃又浪费了Owner已经确认的错误形态；仅按模型置信度挖背景，上一臂已经证明会留下大量与目标语义无关的普通形态。
- **有效路径**：把254个误报和77个语义正例共同冻结为“参考空间”，只用决策bar及之前的OHLC与均线形态计算距离；然后在冻结train内的多个连续时间块排序相似候选。参考标签只影响候选优先级，候选K线、最终训练行和后续验证块仍保持时间隔离。
- **通用规则**：遇到时间边界之后才获得的错误标签，先区分“参考语义”和“训练样本”两种角色；允许前者指导训练期检索，但训练文件只能来自原训练截止点以内，并必须换一个未使用时间块做后续验证。
