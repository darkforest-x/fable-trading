# 摘要里的显式零样本组合不会出现在事件表分组中

- **问题**：产物校验器直接比较摘要中的 `(profile, segment) -> n` 与事件 CSV 的 `groupby().size()`，V2 被判为计数漂移；差异全部来自摘要显式记录的三个 `n=0` 组合。
- **死胡同**：要求两个字典逐项完全相等。汇总层为了显示“这一配置在该时间段零命中”必须保留零行；事件事实表不可能为零命中组合制造一条假事件，所以 `groupby` 天然没有对应键。
- **有效路径**：把摘要中 `n>0` 的组合与事件表精确比较，同时单独断言 `n=0` 的组合没有事件行。这样既保留了完整配置矩阵，也不会把空组误判为产物漂移。
- **通用规则**：验证“汇总矩阵 vs 事实表”时先区分结构零与缺失值：正计数必须逐项相等，结构零必须验证事实表中不存在，未知/缺失则应失败；不要用一次字典全等混淆三种语义。
- **牵连**：`scripts/validate_two_key_candle_artifacts.py`、V2 `results/summary.json`、V2 `results/profile_events.csv.gz`；该规则适用于任何把完整参数网格写进摘要、只把真实观测写进明细表的实验。
