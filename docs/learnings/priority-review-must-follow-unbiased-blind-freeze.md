# 模型优先修错队列必须晚于无偏盲审冻结

- **问题**：Cleanlab 28 张适合省时间找错，但不是随机样本；它与 398 张无偏主包自然重叠
  3 张。若先看优先队列，Owner 会记住这些图，随后主包的首次判断不再盲。
- **死胡同**：把 28 张直接混进主包会富集模型认为困难的样本；从主包排除它们同样会把高风险
  样本系统性删掉。两种做法都会改变错误率估计的总体。
- **有效路径**：随机分层样本先按 Gold 谱系冻结，允许与优先队列自然重叠；先完成、导出并哈希
  主包答案，之后才打开物理独立的 Cleanlab 队列。优先队列只修错，不回写首次无偏估计。
- **通用规则**：主动学习、Cleanlab、模型低置信度等优先审核只能排在随机盲审冻结之后；有重叠
  时冻结审核顺序，不要靠删样本制造“独立”。
- **牵连**：`datasets/fixed_w10_core4_confirm1_v1/review/p1_blind_audit_v1/`、Cleanlab 28、
  398 主样本、50 重复、错误率与 κ 证据链。
