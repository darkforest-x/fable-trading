# 页面滑动必须在松手前给出反馈

- **问题**：底栏已经有过渡动画，左右滑动仍然显得突然，且不同页面的玻璃材质不一致。
- **死胡同**：只延长换页动画无法补上拖动过程的空白；各页分别覆盖同名样式会让主题逐渐分叉。
- **有效路径**：使用 Stitch 的统一颜色和玻璃变量；手势在确认横向意图后通过 RAF 更新当前页位移，松手才提交导航。纵向手势锁定、首尾阻尼及控件排除独立处理。只挂载当前页，取消计时器和动画帧，避免预览相邻页启动行情订阅。检查编译后的浏览器计算样式，并通过触屏事件分别验证跟手、回弹、完成、图表豁免和减少动态效果。
- **通用规则**：先检查手势开始、移动、结束三阶段各自反馈，再调整动画时长；主题一致性以实际计算样式为证据。
- **牵连**：`mobile/src/useSwipeNav.ts`、`navigation.ts`、`appleGlass.css`、`fib.css`；IAB 不支持触屏 CDP 输入，临时 Chrome 会话完成手势验收后须精确关闭。
