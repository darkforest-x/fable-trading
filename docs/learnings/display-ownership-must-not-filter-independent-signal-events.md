# 参考归属用于显示分层，不能替代信号筛选

- **问题**：V3 在一个参考路径仍活动时继续产生结构预警，全部大标签和亮色 K 线让补充发现看起来像反复要求开仓。
- **死胡同**：直接删除已有参考期间的新信号确实能让图安静，却把新的及时启动一起删掉；一个参考覆盖了后续行情，不等于新信号按时捕获，更不等于用户仍持仓。把另一候选父的确认归给当前参考，还会虚增参考质量。
- **有效路径**：检测事件不变，以单向显示投影区分观察起点、所属确认和补充观察。确认必须匹配当前参考的原父身份。原事件使用不受 label 回收影响的连续小标记；近期标签显示真实当前时间和价格。此项只解决视觉含义，没有证明交易噪音减少。
- **通用规则**：先定义事件身份与参考归属，再决定显示层级。检测守恒和收益提升分别验收；不能用界面简化充当过滤成功。
- **牵连**：`yoyo/evaluation/pine/spike_burst_v3_layered_display.pine`、其静态/合成测试及实验计划；平台 label 限额不影响检测，但限制历史 tooltip。原生编译与视觉验证必须另外取得证据。
