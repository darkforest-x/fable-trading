# L2 之前先统一检测候选的语义合同

- **问题**：五个 YOLO checkpoint 都会输出“均线密集”框，但它们分别来自弱/强标签、960/1280 原生推理、不同窗口、核心根数和确认长度；原始 confidence 也没有跨 checkpoint 校准。
- **死胡同**：把五模型候选直接拼成一个 L2 训练池，或把“多模型同意/分数更高”当成可比特征。这样一行候选的含义随来源变化，L2 会同时学习模型身份、像素尺度、确认延迟和形态质量，无法归因。
- **有效路径**：先冻结五模型对照及哈希，再按当前 Owner Gold 几何与原生推理合同选择一个 L1 臂；L2 v1 只接这个语义一致的候选池。其他模型保留为血缘/视觉对照，不参与特征、阈值或结果选模。
- **通用规则**：多 detector 接 L2 前必须先证明标签语义、时间右端、窗口几何、分辨率和 score calibration 可交换；任一项不同就分臂评估，不能靠新增 `model_id` 掩盖合同不一致。
- **牵连**：五模型冻结对照、`exp-15m-ma-launch-l2-global-context-v1` 的 `five_model_lineage`、L1 单变量纪律、L2 score gate 与 holdout 选模风险。
