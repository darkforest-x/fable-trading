# 云带颜色连接段不能替代关键 K 收盘时的 EMA 关系

- **问题**：BTC 2026-04-08 20:00 北京关键12H看起来在绿色云带上开空。原生Pine与网页在该K收盘时却都是EMA20=68913.11019594768、EMA50=68946.30656311511；下一根才交叉。
- **死胡同**：仅靠截图断言方向算错，或者反过来只引用代码说截图看错，都会漏掉渲染时序。尝试把交叉段拆成精确交点的两个Pine polyline，虽然编译通过，原生图却把中间时间坐标吸附到K位置，破坏几何；不交付这个候选。
- **有效路径**：同时记录原生计算上下文和显示上下文的同一时间EMA，再对齐网页API与显示锚点。原生fill把下一根颜色用于整个前后连接段，故V1.5保留原EMA轮廓，仅将异号交叉连接段改为中性淡灰，避免新方向颜色回染到关键K。普通区段仍红绿；不新增绘图对象或改变信号/退出规则。
- **通用规则**：先分清K的开盘标时、确认收盘时点、均线相对位置、均线斜率和跨K填色。图形插值交点不是盘中已确认交叉时间；不能据此提前退出。编译通过不等于图形坐标正确，必须在真实图表放大验收。
