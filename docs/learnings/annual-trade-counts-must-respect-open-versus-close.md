# 年度胜率的切分也要区分开盘与收盘

- **问题**：连续资金账户在年度切点保留仓位，但年度交易笔数统一用 `(start,end]`，会把切点开盘才退出的交易算进上一年。
- **证据**：合成账户上一年末净值100000，下一年第一根开盘退出亏2000。旧统计上一年收益0%却计一笔亏损，下一年收益-2%却无退出交易。
- **修复**：保持交易和净值路径不变；开盘退出按 `[start,end)` 归属，盘中或收盘退出按 `(start,end]` 归属。用跨年开盘退出的独立例子验证。
- **通用规则**：时间戳相同不代表事件先后相同。以收盘净值分段的报告，交易分母必须沿用现金账本的收盘、下一根开盘结算顺序。
