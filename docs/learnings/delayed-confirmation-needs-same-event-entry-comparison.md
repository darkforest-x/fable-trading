# 等待确认筛出的好样本，不能按确认前的价格计算收益

- **问题**：H1区间外勾叉加入5m EMA20/50翻转后，固定2%止损的后段胜率由23.22%提高到27.16%，但净期望仍为-0.135R/笔。只看胜率或全池均值变化，容易把样本筛选和入场延迟混为一谈。
- **死胡同**：事后找出最终等到翻转的信号，再沿用它们原来的入场价。这批旧入场在2025年后平均+0.048R，但筛选条件在入场当时尚不可知，不能把这部分盈利算给云带策略。真实等待后，其平均收益变为负数。
- **有效路径**：冻结旧逐笔，新增成交只用原生VectorBT执行一次；分别展示原全池、事后同接受事件的旧入场、真实延迟入场以及同币/月/因果ATR桶随机对照。两边都完成的22,836个固定2%事件中，延迟入场平均少0.183R，计划RR中位少0.484。四档止损的同事件净收益变化均为负。等待中位190分钟，确认消耗了可交易价格空间。
- **通用规则**：新增确认条件同时改变样本集合和价格时，必须做同事件的入场时机比较；被筛中的旧收益仅作解释，不能当可执行收益。确认应按其真正可见时间成交，保留缺口、目标已触及及新价格导致止损几何无效的未成交原因。
- **牵连**：`yoyo/evaluation/h1_ema_cloud_study.py`、`tests/evaluation/test_h1_ema_cloud_study.py`；实验`exp-h1-ema-cloud-20261102-v1`，先提交builder`e27c05c089`再运行，638合约53,068原候选、41,560次可执行翻转。24h等待固定，四档旧止损/近侧周一目标/7天持仓与成本不变；这轮未测试原帖云带止损。独立重叠R不是账户收益，资金费未建模。
