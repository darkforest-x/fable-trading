# 只删掉一条腿的"改进版"，不含任何关于入场质量的信息

- **问题**：ChartArt 把 v1.1（信号反手）改成 v1.2（只做多），说明里写"改成只做多后回测更成功"。
  Owner 要求回测 BTC/ETH 永续 15m。默认的读法是"作者找到了更好的用法"，于是想去比两条曲线谁高。

- **死胡同**：先按"两个策略"并排跑，比 PF、比复利、比胜率。
  这条路能得出"v1.2 在 4/6 个格子里赢"，但**解释不了为什么**，也说不清这算不算证据。
  更糟的是它诱导下一步去调参数——既然"只做多更好"，那是不是再加个趋势过滤会更好？
  这一步一旦迈出去，就是在一个没有验证过的前提上做参数搜索。

- **有效路径**：先做**状态机对齐**，再做统计。
  把两版的多头状态转移写出来：两版都在 `long` 信号时（若当前不是多头）进多，
  都在 `close_long` 信号时离开多头；唯一差别是离开之后转空头还是转空仓。
  于是多头腿的 entry_i / exit_i / 价格 / 净收益**必然逐笔相同**，
  v1.2 的交易集合 = v1.1 的交易集合 − 空头腿。
  用一条测试断言这件事（`test_long_legs_are_identical_to_v11_which_only_adds_shorts`），
  而不是靠读代码相信它。
  钉住之后"v1.2 更好"就退化成一句同义反复：**那段被删掉的空头腿是亏的**。
  在一段上涨行情里这不需要回测也知道。剩下真正要问的问题只有一个——
  留下的多头腿本身有没有边？答案由匹配随机做多给出：12 个格子超额 −55.4bp 到 +29.1bp，
  置换 p 最好 0.361，没有边；收益是打折的多头 beta（BTC +67.9% 对买入持有 +282.5%）。

- **通用规则**：拿到同一策略的两个版本（或"改进版"）时，**第一步不是跑回测，是问它们的交易集合是什么关系**。
  如果 B 的成交是 A 的子集（或只差一类腿），那么"B 更好"只等价于"被删掉的那部分是亏的"，
  它对留下来那部分的质量**一个字都没说**。此时正确的对照组不是 A，
  而是**同环境的随机入场**和**买入持有**——前者问入场择时，后者问 beta。
  同理：任何"加了过滤器所以更好"的说法，先确认过滤后的成交是不是原集合的子集。
