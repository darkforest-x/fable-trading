# 入场筛选必须重放腾出的仓位

- **问题**：SPIKE 的新入场门要同时衡量降频、净胜率和高 R，原回测有单仓约束；某个早期信号被过滤后，后续原本因占仓跳过的信号可能实际成交。
- **死胡同**：直接从原成交表删掉不满足门的行，只能回答固定成交集合的条件表现；它会漏掉新增成交，也可能夸大胜率或大盈利保留率。让新门从预热期就运行，又会把窗口起点的持仓一起改变，混入第二个变量。
- **有效路径**：冻结原候选事件（包括占仓跳过事件），继承窗口起点相同的原持仓，独立计算所有候选的原退出结果，再按两种入场政策逐事件重建占仓。无过滤分支必须逐笔等于原回测，随后分别列固定候选、实际成交、保留/失去/新增高 R。
- **通用规则**：入场条件改变时，先确认执行器是否有状态；有状态就重放状态，不能只筛结果表。起点状态和执行成本必须固定，并验证旧分支复现。
