# 一个入场门的「改善」先拆成「少做」和「做得更好」，再按决策时刻可知的状态切，别按未来配对结果切

- **问题**：2026-09-18 审计 SPIKE V10.4（V9 多头 + 下降线突破联合）在 1h 上相对原 V9 的增益。表面数字：
  每笔净 R 从 −0.005 变成 +0.088，后段总 R 从 −466 变成 −56，看上去联合门「大幅改善后段」。

- **死胡同**：
  1. 直接比总 R：后段 +410R 的差，**约 350R 只是因为联合只做了 V9 四分之一的笔数**（在一个做多整体亏钱的阶段少做就少亏），
     每笔效应只有约 60R；前段同样的「少做」让联合**少赚 343R**。频次效应在上涨/下跌段方向相反，合起来看像改善，其实大部分是仓位暴露变小。
  2. 用影子路径按「这个 V9 事件后来有没有配成联合」分组：没配上的组里有 373 个「等待中跌回六线下/出现原始空头」事件，
     影子亏 −242R。但丢弃证据的原因和 V9 自己止损是**同一件事**（价格跌了），这部分「避开的亏损」是同因果，
     不是线提前知道的信息。按未来最多 6 根的结果分组，会把这种同因果算成筛选收益。
  3. 用月块符号翻转 p（检验的是「比随机好」）来说「联合比 V9 好」：两个问题，不能混用。

- **有效路径**：
  1. 总量差 = 每笔效应（C 总R − C笔数×A每笔R）+ 频次效应（C笔数×A每笔R − A 总R），分段各算一次，符号相反就说明是暴露效应。
  2. 按**决策当根可知**的状态切 V9 事件：当根已成联合 / 当根没有已确认线 / 挂在未突破的线上。前两类不含未来信息；
     只有「挂起」依赖之后 6 根，那部分再单独比较「全部当场进」和「等配对」两种做法（R 和名义 bp 都报，二者会因止损宽窄而方向相反）。
  3. C−A 用两臂共同的月块重抽样（同一次抽样带上两个臂的全部交易、各自分母），区间包含 0 就不叫改善。
  4. 顺手的结构性核对：V9 确认当根本身就满足联合第二事件的全部门槛，所以同根/先突破的配对在 V9 当根不可能被拒——
     实测 0 次，是一个免费的实现一致性检查。

- **通用规则**：评估任何「在已有信号上再加一道门」的改动，第一步先拆频次效应和每笔效应（分段），
  第二步只用决策时刻已知的量分组，第三步用两臂共同重抽样给每笔差的区间。任何「按事后结果分组」的表都标为描述、不当证据。
