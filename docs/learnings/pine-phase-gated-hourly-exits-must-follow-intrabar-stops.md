# 只在跟踪阶段生效的小时退出，必须排在当前保护价检查之后

- **问题**：V2.7 新增“进入趋势跟踪后，已确认的反向 1H 勾叉立即退出”。同一根 5m 内可能先触发旧止损，又在小时收盘出现反向信号；同一时刻也可能首次达到 5R。多笔独立参考的启动状态不同。
- **死胡同**：直接在全局观察方向反转时统一平掉旧框，会误关尚未跟踪的单；在检查 5m 止损前按小时收盘退出，会覆盖更早的成交。增加规则前已排除这两条实现路径，未将它们作为有效版本交付。不能把不明确的止损柱高低顺序当作最大盈利证据。
- **有效路径**：固定 5m 引擎先检查各笔既有保护价，再处理 15m 收盘启动和收紧，最后仅在完整小时边界检查反向信号。只关闭仍存续且已启动的对象，首次启动与反向信号同收盘也适用；单独记录原因 3、收盘价、结束时间及真实毛 R。原生手算路径覆盖止损优先、同收盘启动、多空、未启动同行单不退出及负 R 退出。
- **通用规则**：新增跨周期退出时，先写清每笔状态门和同刻事件顺序，再加入事件处理。显示“最大 R”应沿用可确定的持仓内极值；止损所在 OHLC 柱的先后未知时，不计该柱的额外有利极值，并在提示中说明。最大 R 与已实现退出 R 分开，不能冒充可全部兑现的收益。
- **牵连**：`yoyo/evaluation/pine/monday_range_v2_7.pine` 的 `txAdvance`、`txExitOnH1`、`txDraw`；独立复算 `yoyo/evaluation/monday_range_v2_7_reference.py`；`tests/evaluation/monday_range_v2_7_native_checks.pine`。规则来源为 Owner 2026-10-20；不是盈利优化结论。
