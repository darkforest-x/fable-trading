# Account return must preserve chart context

- **问题**：从均线密集账户点击“查看形态”使用空路由，丢失所选币种和周期；历史检测通过页签返回还会被强行切换成最新总览。
- **死胡同**：只保存图表缩放无效，返回动作已经改变了图表的身份；恢复旧视口不能修复错误币种或任务。
- **有效路径**：同一工作台内返回使用现有页签操作，保留任务、币种、周期和视角。只有本来就在最新总览时才刷新总览目录，不改变历史任务模式。
- **通用规则**：查看账户应是从当前图表临时离开，返回必须恢复同一业务上下文；导航动作和刷新动作分开。
- **牵连**：`manual-account.js`、`yolo-detect.js` 与历史任务页签回归测试；两个交易账户继续独立。
