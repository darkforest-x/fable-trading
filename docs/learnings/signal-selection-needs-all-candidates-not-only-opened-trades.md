# 优化信号筛选，不能只拿旧策略已开仓的交易作母体

- **问题**：Owner希望提高原始信号最终净R>10的命中率，前轮却主要衡量普通盈利胜率，并从旧串行已开仓交易计算筛选质量。
- **死胡同**：41,700已平仓交易是原持仓规则选择过的样本；49,207原始做多候选中7,393甚至不在原交易表里。只在交易表上挑好单，会漏掉改变入场规则后可成交的机会；提高普通胜率也可能损失大部分10R赢家。
- **有效路径**：先从原始候选逐笔独立用不变的入场/风险/退出/成本产生标签，保留失败和未知；严格以最终净R>10为主标签。同时报告命中率、覆盖率和赢家召回。较早时段已结束的交易选规则，后段时间外复核，再按原串行引擎检查实际持仓占用。独立重叠路径只评价信号，不当账户收益。
- **通用规则**：优化前先写清母体、分母、结果标签与决策时点。交易过滤改变了未来的持仓占用，旧成交表不是完整候选集；“普通胜率”不能替代稀有目标命中率。
- **牵连**：`yoyo/evaluation/spike_10r_dataset.py`、`spike_10r_search.py`、`spike_10r_serial.py`；实验`exp-spike-10r-discovery-20260921-v3`。不更改原R分母，不拿MFE或实际未来成交风险当入场特征。
