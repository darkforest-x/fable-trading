# 多周期证据必须保留发生时间，不能压成同刻独立投票

- **问题**：已知 USELESS 1H 成功案例，看起来同时满足量、动能、小周期和大周期确认，直接拼 AND 规则却会漏掉它。
- **死胡同**：把较早的动能峰值、之后的 4H 金叉和事后框中的上涨范围全部贴到启动箭头上；把嵌套周期成交量、同一套均线的 YOLO 输出各算一份独立证据。
- **有效路径**：逐根按收盘可用时钟重放。08:00 释放之前 07:00 动能已到 100；释放根动能只有 59.4，15m 启动已过去 105 分钟；4H 金叉要到 20:00 才确认。固定 YOLO 扫描没有合格多头。保留未通过的早期假设，后续确认只追加事件、不回写原信号。
- **通用规则**：给每项证据保存来源、窗口、可用时间及失效条件。用赢家提出状态记忆假设可以，用它证明该规则有收益优势不可以。
