# 单向策略必须重放占仓，不能直接筛双向账本

- **问题**：Owner问BTC RSI/六线策略只做空如何；原双向账本中空单189笔、净−54.70R，但它们曾受到多单占仓约束。
- **死胡同**：只用 `trades[side == -1]` 冒充只做空；或者把所有多头事件从信号流中删除，连“新菱形撤销旧等待”的原规则也一并变更。
- **有效路径**：保留全部大菱形事件、指标和退出引擎，只在复制的研究上下文关闭多头入场。多头事件仍撤销旧空头等待，但不会占仓。独立重放得到194闭合空单；原189笔全部成交/止损/退出一致，新增5笔贡献+1.2666R，合计仍−53.4293R。合成用例确认多头菱形仍能替换空头等待且不产生多单。
- **通用规则**：方向限制是入场许可，不一定是事件删除；报告先区分双向账本子组与独立单向序列，再对账共用、新增、失去的交易和占仓差异。
