# 翻转退出必须明确入场种子与缺失状态

- **问题**：从反色状态退出改为真翻转退出时，“先同向”究竟包括入场前已完成K线，还是必须持仓后才算，会改变首个可退出时刻。
- **死胡同**：凭模式名或口头描述实现，容易额外推迟原本已同向入场的退出；也容易把历史首次激活时间当作当前仍有效的序列。
- **有效路径**：V37先审已有引擎，再用真实SMA40合成OHLC验证。入场前闭合线有效同向则E激活、最早E+5退出；初始反色先等有效同色。管理缺失重置当前序列，原始价格缺失保留未知，两者不能混淆。
- **通用规则**：先写清进入状态机的种子、相邻要求、缺失重置、止损时序，再比较经济结果；“只改一变量”必须连观察时钟一起精确定义。
- **牵连**：V37只调用既有transition_colour；初始止损、72h、0.2%成本不变。合成镜像/正比例缩放/未来不变性测试，不构成盈利证据。
