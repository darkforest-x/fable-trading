# 改框必须先编号逐图找启动边界，不能用全局偏移

- **问题**：一批旧核心框都把启动侧 K 线吃进去了，但每张图的真正平台结束位置不同；统一把框向左挪几根，会在另一批图上重新切错语义。
- **死胡同**：把“旧框偏右”当成一个坐标误差，尝试用同一 delta 或固定中间位置修正。这样只改变几何外观，既不能说明哪根是启动首根，也会让模型继续学习位置 shortcut。
- **有效路径**：先在冻结窗口上给每根 K 线标本地序号，逐图确定启动首根，再把核心右端落在它前一根；核心左端只覆盖仍能表达平台/转折的最短 4–7 根。随后从原始连续 K 线重裁完整动态窗口，同时画新框与可见旧框做对照，并保持逐样本训练资格为 false，直到 Owner 验收。
- **通用规则**：遇到批量边界漂移，第一步不是求平均偏移，而是建立可审计的逐图边界表；只有边界表覆盖全部样本、宽度合法、位移不退化为单一模板、重渲染仍保持语义时，才进入样本确认。
- **牵连**：`scripts/rebox_owner_eth_shortdelay_review200.py`、`tests/test_rebox_owner_eth_shortdelay_review200.py`、`analysis/output/owner_eth_shortdelay_review200_rebox_v1/`；受 holdout 禁读、3–5 根确认、4–7 根核心、协议确认不等于逐样本确认约束。
