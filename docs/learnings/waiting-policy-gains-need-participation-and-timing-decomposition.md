# 等待后的成交均值更差，不代表等待时机没有改善

- **问题**：V4 直接入场 251 笔净均值 −14.02bp，等 K2 后 55 笔为 −22.92bp；容易误判为“等待把入场做坏了”。
- **死胡同**：直接比较两个不同成交集合的均值，既忽略没有成交的原始机会，也混淆了回踩类型本来难做与等待价格本身的作用。
- **有效路径**：固定 251 个母机会分摊；再在事后同样会出现 K2 的 55 个母机会内配对。它们原直接入场为 −43.15bp，等待后改善 +20.23bp。全部母机会改善 +9.00bp，由减少参与 +4.57bp 和同批时机改善 +4.43bp 共同组成，但最终仍负、仍漏掉 55 个原赢家。
- **通用规则**：带选择／等待条件的收益变化，先分解参与量与同样本时机效应。未来定义的子群仅能诊断，不能冒充入场时可识别的特征。
- **牵连**：V4 paired_change 与 VERIFICATION；原始机会／实际成交两种分母；对重复开发历史的统计不能宣称独立盈利证明。
