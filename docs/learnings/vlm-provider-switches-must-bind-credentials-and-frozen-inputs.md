# VLM 切换必须同时绑定供应商、地域与冻结输入

- **问题**：视觉工作台从单一智谱接入千问后，同一个设置框与历史回放都可能继续沿用旧供应商的假设。
- **死胡同**：仅替换模型 ID 或请求 URL 会把旧密钥发送给新接收方，或让已经冻结的观察在另一个服务地域执行；兼容 OpenAI 请求格式并不意味着身份和能力相同。
- **有效路径**：按供应商与地域保存独立凭据，端点和模型使用官方白名单；将供应商、地域和提示版本写入识别记录及冻结观察，执行前核对；用离线 transport 验证隔离和旧接口兼容性。
- **通用规则**：先确认具体托管模型的接口契约，再迁移配置与实验身份；家族宣传的上下文上限不能替代具体 API 的限额，截断 JSON 不能算成功结果。
- **牵连**：`yoyo/vision_research/{providers,settings,server,replay,comparison,qwen,zhipu}.py`；北京与新加坡百炼 API Key 不通用；实际连接与识图能力仍需用户配置密钥后验证。
