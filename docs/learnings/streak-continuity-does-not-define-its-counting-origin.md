# 连续同色只规定怎么递增，不规定从哪里开始计数

- **问题**：Owner要求同周期连续同色大菱形、异色重置、第7个退出。助手把连续计数擅自解释为指标全局计数，把XTZ开仓前的菱形纳入本仓，实际在入场后第6个就退出。
- **死胡同**：测试全局计数的前缀因果性、缺口边界和止损优先级全部通过，仍不能证明计数起点符合Owner意图。原报告将“开仓不重置”列为Owner确认口径，这个归因不成立。
- **有效路径**：Owner指出“从开仓开始算”后，将连续性和起点拆成两个独立字段：指标RSI/SAR保留完整预热，每笔实际开仓只重置自己的大菱形计数；入场bar收盘参与，入场前及信号bar不参与；异色重置。逐项列出XTZ入场后的1至7，而不是只核对全局序列。
- **通用规则**：任何“第N个事件”都要定义事件种类、递增/重置条件、计数起点及成交时钟。连续性不等于起点；不能把助手默认选择写成Owner已经确认。修正起点必须重新回算，旧比较只作为错误版本的历史记录保留。
- **牵连**：`yoyo/evaluation/spike_joint_rsi_exit.py`、`yoyo/monitor/spike_lines.py`、前端计数元数据与冻结版本。XTZ原全局第7为2026-09-19 11:30北京，本仓第7为23:45，下一开盘0.3671；该价格不是整段最高价0.3968。
