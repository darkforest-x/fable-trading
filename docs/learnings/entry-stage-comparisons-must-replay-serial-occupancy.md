# 改入场阶段时，必须先重放占仓再比较收益

- **问题**：V13.1 从再次突破提前到首次突破或首次回踩，会改变实际入场R、保护启动、退出时间和后续可接纳信号。旧订单逐笔重算不能代表新规则的完整交易集合。
- **死胡同**：此前固定原订单的追价归因可以解释价格与缩量成本，却无法评估提前退出释放的机会。把这些归因总R直接当作新策略总收益，会漏掉新入场和被替换的交易。只检查已选订单互不重叠，也发现不了漏接的有效信号。
- **有效路径**：四种入场阶段都从相同原始锚点队列独立运行；每种规则按决策时间排序，以自己的实际退出释放仓位，保留占仓时过期的确认。先完成预热再截取统计期。独立验证器从全部候选逐一重建接纳/跳过，而非只检查已成交子集。随机比较另把双方限制在事先有合格匹配的锚点队列中，各自重放占仓；与独立机会比较分开。
- **通用规则**：只要实验改变进出场时点，就先问是否改变后续可交易集合。固定订单重算是路径归因；全信号队列重放才回答策略切换后的收益。未成交和占仓跳过可记零，但未知或实际持仓被数据边界截断不能记零。
- **牵连**：`yoyo/evaluation/spike_v131_entry_stages.py`、独立验证器及 `exp-spike-v131-entry-stages-20261019-v1`。1H旧3357笔为原占仓集合的2ATR固定入场重算；新2ATR占仓基线必须另报，不可要求交易数强行相同。所有R仍为等风险交易统计，不是共享资金账户回报。
