# 匹配案例与随机对照必须采用对称的样本末尾处理

- **问题**：案例表只保留自然结束交易，而随机对照均值含样本末尾仍持有的交易，两组收益条件不同。
- **死胡同**：单独删除case的censored行以获得更干净的胜率，再把同一筛选直接搬给matched推断，造成幸存条件差异。
- **有效路径**：胜率/PF自然交易单列；主matched诊断两侧都包含相同末尾标记、相同成本。旧自然-only诊断明确保留，不能悄悄替换历史首跑。
- **通用规则**：任何case/control比较先对照双方的退出、删失与费用契约；同时披露删失数量。统一终点也不能消除重叠持仓和日历块相关性。
- **牵连**：yoyo/evaluation/mainstream_research.py，原始结果和verified结果分目录保存，信号及仓位规则不变。
