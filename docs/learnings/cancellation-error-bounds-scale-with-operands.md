# 大数相减的浮点误差界要按操作数而不是结果缩放

- **问题**：V34补充delta独立复验后，Decimal派生结果与float买量减卖量不完全一致，误报验证失败。
- **死胡同**：对接近零的delta使用相对误差再加固定极小绝对误差，会忽略两边金额很大的相消误差；不能据此宣称原始订单流数据损坏。
- **有效路径**：仍保留V33对原文本的Decimal公式，二次浮点恒等式误差界使用机器epsilon乘操作数绝对值和。合成1亿+.01减1亿应通过；把delta恶改成1仍必须失败。原结果不覆盖，补强后重跑同源验证。
- **通用规则**：把源约束精度和计算表示误差分开；相消运算的误差不由最终的小结果决定。这个计算容差不是交易筛选阈值。
- **牵连**：V34 coverage独立delta验证与合成回归；源ZIP、parser、交易成本、参数、时间窗不变。
