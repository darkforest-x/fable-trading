# 原文文件可下载，不等于页面内可以阅读

- **问题**：交易书架接入两本威科夫公版扫描件时，文件 HTTP 200、哈希及章节检查均通过，但站点统一的 `X-Frame-Options: DENY` 会阻止直接 iframe 显示本地 PDF。
- **死胡同**：只验证下载链接或 iframe 的 src，会把成功取得原件误当成阅读器可用；放宽整个工作台的防嵌入响应头又扩大了不相关页面的变化范围。
- **有效路径**：本地扫描件由阅读器按需加载，先核对 SHA-256，再生成 PDF Blob 供浏览器显示。保留原始独立打开链接和 OCR 备用文字；作者保留版权的免费教材仍加载其官网原件，并支持用户在当前浏览器选择已下载原件（核对相同哈希，不上传）。作者官网页面实际指向 `/book/`，旧 `/dl/` 在浏览器验收中失败；两个地址文件哈希相同，当前阅读地址采用页面提供的版本。章节同时保存 PDF 页码与印刷页码。
- **通用规则**：分别核验来源版本、全文覆盖、章节映射和实际阅读表面。现代资料的免费访问不自动赋予再分发权限；原文错误应在编者层标注，不能悄悄改写原件。
- **牵连**：`yoyo/monitor/static/trading-books.js`、`trading-books.json`、`trading-book-originals/`、`tests/monitor/frontend_trading_books.test.cjs`。订单流教材的 COT、trapped 命名及 ratio 算术疑点保留在相应小册节；研读完成不改变方法待验证状态。
