# 剔除亏损币要同时检查后期总收益、每笔收益和匹配超额

- **问题**：V13.1 全历史累计净 R 倒数 20 币被删除后，四个周期/方向组的收益和 PF 均提高。这种按已知亏损筛选的改善，能否支持以后屏蔽这些币？
- **死胡同**：本轮没有失败实现；被否定的推断是“删除全历史亏损最大的币后 PF 提升，所以名单有效”。筛选条件已经使用了同一段待评价收益，改善本身不能证明预测能力。另一个误读是只看后期总 R 下降：删交易也改变了收益分母。
- **有效路径**：固定原交易、20bp 成本和匹配对照，分开计算全历史事后删除与按时间选名单。只以 2025 年前已入场且已退出的交易排名，冻结倒数 20 名，再评价 2025 年起原入场。15m 空头后期总 R 从 365.327160 降至 349.791566，但交易数从 4034 降至 3843，平均 R 从 0.090562 略升至 0.091020，PF 从 1.160523 略升至 1.161628；不能简单说所有指标都恶化。1H 空头后期总 R、平均 R、PF 则均下降。合并多空选名单的 15m 后期总 R 上升 43.649640，但匹配子集超额从 -0.006629 降至 -0.009441R，池内改善也不等于信号优势增强。
- **通用规则**：任何按结果选出的黑名单，先明确排名窗和执行窗。事后删损失只回答敏感性；后期评价至少同时保留交易数、累计/平均净 R、PF 与同口径匹配对照，禁止用单个总量替代稳定性或优势结论。复用历史的单次时间切分仍不是盲测或前向验证。
