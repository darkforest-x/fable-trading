# 基础信号命中率不能转移成后置审查准确率

- **问题**：V1 已有事件精确率、历史胜率和 YOLO 工程验收，容易据此声称“AI 再审一次就能更准”，但当前没有 V1 条件下的 AI 独立预测记录。
- **死胡同**：把 V1 的 39.53% 特定事件精确率、通用 L2 指标或 YOLO 链路可运行当成 AI 开仓审查的准确率；这些数字来自不同样本池、标签、任务或仅是工程验收。
- **有效路径**：冻结 V1 raw 事件、审查时点、可见特征、成交和退出口径，把后置层注册为独立 meta-label 实验；按时间 walk-forward 生成 OOF 预测，并同 V1 全量、透明规则、同数量随机删选和匹配随机入场比较净 R、回撤、赢家保留率与校准。
- **通用规则**：任何二次过滤器都必须在同一基础事件池上证明增量；准确率只能属于自己的标签、时间切分和预测记录，不能从上游信号或邻近模型借用。
