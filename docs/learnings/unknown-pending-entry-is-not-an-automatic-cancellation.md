# 未知入场资格不能当成占仓期间的自动取消

- **问题**：延迟入场的资格在一笔已有持仓期间首次变得未知，无法确定其是否会在仓位释放后、请求过期前触发。
- **死胡同**：只因最早未知时点落在已有仓位内就丢弃该请求，会暗中假定整个后续待入场窗口都被取消，从而凭空放行后面的仓位。
- **有效路径**：区分已知未成交（贡献为零且不占仓）、未确定的首次资格（贡献未知）和已入场但退出未知。无待入场预约的账本按实际入场时点排序；首次资格未知产生明确的不确定性阻塞，不伪造成已成交。
- **通用规则**：缺数据时先列出仍可能发生的后续状态。没有明确的取消政策，就不能把最早未知时点的占仓情况推成整段请求已取消。
- **牵连**：`yoyo/evaluation/k1k2_delayed_entry.py` 的 `entry_ledger` 与 `tests/test_k1k2_delayed_entry.py`。这是保守研究账本，不是新增实盘执行政策。
