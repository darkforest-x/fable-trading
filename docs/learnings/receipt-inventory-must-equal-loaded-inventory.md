# 验过回执的文件集合必须等于实际统计的文件集合

- **问题**：回测报告逐个验证了 manifest 中的流回执，随后却用 `streams/*` 通配符读取数据；额外遗留目录可能未验证就进入统计。
- **死胡同**：单个文件 SHA 全对只能说明这些文件没变，不能证明报告没读入其他文件。交易表左联结控制表也不能证明配对完整；缺失控制会静默成为空值。
- **有效路径**：验证 identity 的整体哈希、实际目录集合与声明集合严格相等，只从已验证目录显式加载；再对交易与控制的 arm + trade_key 做双向集合相等和唯一性断言。缺失控制记录与明确记录的 unmatched 是两回事。
- **通用规则**：所有证据验证都要覆盖“内容、集合、联结关系”三个维度；不要用验证过的子集给随后扩大范围的读取背书。
- **牵连**：`yoyo/evaluation/spike_v112_support_report.py` 与 `tests/evaluation/test_spike_v112_support_report.py`。本轮在出报告前修复并用额外目录/缺失控制用例验证；未发现正式输出受到污染。
