# 退出改善必须经受匹配覆盖与尾部贡献核对

- **问题**：V37 把反色状态退出改为真正翻转退出，全 63 笔平均净收益改善 9.73bp，看起来像找到了方向。
- **死胡同**：只报全池均值，或把事后终于转为同向的交易选出来当入场过滤器。前者遮住未匹配赢家，后者使用未来。
- **有效路径**：不重抽控制、不删失败，先逐笔连回原 36 个三对照组，再检查变化分布和四半年。匹配病例自身平均反而下降 1.08bp；未匹配 27 笔贡献 652.01 event-bp，超过全池 613.02 的改善。最大两笔也都未匹配。真实增量超额仅 2.06bp、区间跨零。
- **通用规则**：延长持仓救回少数趋势，不等于入场有优势；同时报告均值、中位数、恶化笔数、匹配覆盖和大赢家贡献。入场前状态与事后激活结果必须分列，不能把结果标签倒灌为特征。
- **下一步边界**：先审入场时可知的启动状态及其匹配支持，再冻结新的入场假设；不能由这 63 笔事后找阈值、删掉止损或降低费用来宣布成功。
