# 不同持仓期限的排名需要共同的机会成熟门

- **问题**：12h 插针策略同时比较 7、14、28 天期限。如果全期表只过滤“已经平仓”，近期快速止盈会进入排名，尚未结束的持仓却被排除，各策略还会拥有不同的观察机会。
- **死胡同**：只剔除实际跨越年度切点的持仓，或把数据最后一根当作统一退出，仍然分别引入结果依赖的样本筛选和不存在的成交。
- **有效路径**：在查看策略表现前，把主要比较限定为“信号确认 + 最长挂单期 + 全部候选的最长持仓期”已结束；本轮统一为 29 天。年度选参与评价使用各自截止点，全期可保留跨年度交易。所有已观察成交另列，原始未结束仓位仍保持 open，不扣虚构的退出手续费。
- **通用规则**：先给整组候选建立与结果无关的共同机会窗，再排名；原始全历史与主要比较样本分别保留。不要为较短期限单独留下更多近期机会，又直接比较总收益。
- **牵连**：`exp-top20-12h-strategies-20261101-v1/analysis_config.json`、`top20_12h_strategy_analysis.periods`、快速赢家与未结束交易共用成熟门的行为测试。与 `label-maturity-follows-the-report-window.md` 相同，成熟门必须跟随当前表的截止点，不能把选参切点机械应用到全期。
