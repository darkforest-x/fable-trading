# 同一行情端点不可达时，缓存降级也必须有独立授权与哈希回执

- **问题**：新浪 60m 预检本身有 1,970 根完整历史，但用于交叉校验的东方财富同一 HTTPS 端点在本机 IPv4 假地址路径连续返回空响应；失败发生在个股扇出和模型加载之前。
- **死胡同**：原样重试六次、再次恢复同一配置、加浏览器请求头、绕过系统代理、查询公开 A/AAAA、强制同主机 IPv6 都试过；某个 IPv6 边缘一度返回 200，但后续轮询地址仍会空断，因此“找到一个能通的 IP”不是可复现的数据契约。
- **有效路径**：保留消费账本与所有失败回执，不把失败说成零信号；在 owner 明确授权后，只允许三份既有东方财富冻结文件作为 parity-only 降级。指数直接使用哈希锁定的 127 根 60m，两个哨兵各把 504 根 15m 按四个精确交易时段聚合成 126 根 60m，不填缺口，并继续执行原来的共同时间戳数和误差阈值。缓存路径、父回执、输入哈希、派生方式和在线失败原因全部进入预检回执。
- **通用规则**：先区分“提供模型输入的主源”和“只负责独立校验的对照源”。对照端点不可达时，先证明主源长度与时段语义，再保留失败证据；只有获得明确授权、固定缓存字节并保持原门限时才能降级，不能静默换源、跳过 parity 或把源失败当无信号。
