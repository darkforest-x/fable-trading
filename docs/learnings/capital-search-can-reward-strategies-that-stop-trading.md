# 只按期末余额选资金方案，会选中开不出单的“冠军”

- **问题**：1000U 的 ETH V8 止损后倍投开发搜索中，两条流的最佳期末余额为923.32U/885.13U，看起来显著优于同底注固定风险。
- **死胡同**：把“比基线少亏”解释为倍投有效。真正核对成交账本后，两条冠军都只接受2笔，分别拒绝742/437次；容量不足让账户停在亏损层级，低交易暴露使期末余额较高。全部34个不同开发配置仍亏损。
- **有效路径**：冻结原选择并保留失败，不在后续窗口换冠军；同时报告接受/拒绝数、资金上限和持续账户。2025验证两条仍亏，开发至2026-05-01连续余额724.82U/792.28U、只成交11/3笔。3m授权holdout #1最终876.96U低于固定风险974.92U。5m2026年前4个月独立重启有1185.38U盈利，但只4笔且固定风险1327.12U更高，不能隐去这项反例，也不能将它称持续优势。
- **通用规则**：资金方案优化至少同时报告收益、参与率和容量失效；不交易现金是必需对照。无约束地最大化期末余额可能奖励实质停摆。若以后要加入最低参与率、容量不足复位或资金裁剪，必须在新版本预注册，不能用已看过的最终评估反向挑规则。
