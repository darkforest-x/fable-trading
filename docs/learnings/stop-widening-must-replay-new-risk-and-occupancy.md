# 放宽止损需要同时重算风险分母和完整占仓

- **问题**：一笔交易先止损后上涨，容易诱使研究只把这笔止损价下移，然后沿用原仓位、原2R追踪门槛或原成交列表来计算改善。
- **死胡同**：只筛原止损单会忽略原赢家受损；只换R分母会把更大的实际亏损显示得较小；在旧账本上筛选无法还原更长持仓造成的后续机会变化。为实验复制串行引擎又会引入反向和止损优先级漂移。
- **有效路径**：在原初始化后的一个可选回调中冻结MA止损，原引擎默认路径保持不变；每组重算真实初始风险并独立串行回放，再固定原入场做反事实分解。以旧版全部逐币账本作严格零改动对照，报告新风险R、原风险R、净bp和固定风险仓位倍率。
- **通用规则**：更换止损锚点前，先写明是否改变风险、追踪启动距离与仓位；默认2R采用新的真实初始风险。未知均线不得填未来或悄悄回退，失败与删失保留。止损变宽是否有价值由全候选和对照决定，不能由一张反弹图决定。
