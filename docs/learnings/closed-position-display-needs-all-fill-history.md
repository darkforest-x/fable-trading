# 历史仓位均价不能用最后一段剩余仓位均价代替

- **问题**：先部分平仓、再加仓时，账本 entry_price 表示剩余敞口成本；历史仓位需要覆盖全部开平仓成交，两个均价语义不同。
- **死胡同**：使用最终 entry_price 会遗漏已平部分，使用最近 500 笔展示列表会截断旧成交。以文本等于 '0' 选择平仓记录还会漏掉 '0.00' 等 Decimal 合法零值。
- **有效路径**：历史卡片只读汇总全部关联成交，按各自开/平数量加权均价，累计成交金额与费用逐笔保留；收益率明确标注以累计开仓保证金为分母。仅将合法 Decimal 零值用于已平仓筛选，不改成交账本。
- **通用规则**：展示历史汇总前，先区分当前剩余成本与全生命周期成交口径；分页列表不能充当完整账本。
