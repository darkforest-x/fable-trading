# 原文与小册应共用章节定位，而非混用正文或已读状态

- **问题**：书架新增原文标签后，需要从原文直接切到同章中文小册，并保证实际显示的是完整原文。
- **死胡同**：上一版只有小册正文和外部原文链接，点击“当前小册”不能在工作台内阅读原文；长目录重绘还会回到顶部，使已选末章离开可见区域。直接把归档文本按末章读到文件结束，又会把电子版整理说明和许可当作正文。
- **有效路径**：两种视图共用书籍 ID 与罗马数字章节 ID，原文单独按需加载。按原始章节标题和正文结束标志切分，仅合并排版换行；24 章逐一比较去空白后的全文，并保留含电子版说明和许可的完整文件。重绘后把目录定位到当前章；原文页不展示小册的已读按钮。
- **通用规则**：原文、译文、提炼笔记是不同文本层，先用稳定章节键关联，再提供视图切换；内容完整性应通过正文逐字核对验证，不能用章节数量或页面能打开替代。
- **牵连**：`yoyo/monitor/static/trading-books.js`、`trading-books.json`、`trading-book-originals/reminiscences-1923.json` 与 `.txt`、`tests/monitor/frontend_trading_books.test.cjs`。来源仍为原归档 SHA-256 的 Project Gutenberg #60979；其余五本缺原文状态不变。
