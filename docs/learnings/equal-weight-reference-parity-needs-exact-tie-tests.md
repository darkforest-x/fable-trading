# 等权均线的数学等价不保证颜色判断等价

- **问题**：40 根 price=0.1、volume=0.1 时，朴素 VWMA 得到 0.10000000000000002，SMA 为 0.1；HL2 >= MA 因此可能反转。
- **死胡同**：只比较均线数值的近似误差通过，无法证明基于边界比较的颜色与入场一致。给颜色增加容差又会改动策略定义。
- **有效路径**：完整、正数且等量的窗口使用数学等价的 SMA 滚动均值，其他窗口保留实际加权公式；同时测试精确平价、侧别和异常量离开窗口后的恢复。
- **通用规则**：数值特征驱动离散门时，必须测试边界上的最终决策，不只测近似数值。
- **牵连**：V26 `hourly_impulse_vwma.py` 与合成测试；没有放宽均线侧别规则、变更价格或量的定义。
