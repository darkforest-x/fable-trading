# 匹配随机对照先按目标事件平均，再比较收益

- **问题**：同币、同周、同波动桶的严格匹配并不保证每个形态事件都有5个有效随机对照；同一根随机入场还可能服务于多个目标事件。
- **死胡同**：把所有随机对照摊平成一列算总均值，会让有5个对照的事件比仅有1个对照的事件权重高5倍。遇到UNKNOWN再补抽，或从有对照的样本重新选top-decile，也会改变原先冻结的抽样和模型排序。
- **有效路径**：先按完整候选池确定模型top-decile；再对每个目标事件的已解析随机对照取均值，最后对有配对的目标事件等权平均。候选收益必须同时报告全部请求事件与真正有配对事件，UNKNOWN、缺配、少配和原始控制复用分别计数，复用同一源坐标的收益必须一致。
- **通用规则**：开始匹配研究前，先确定分析单位和缺配处理。随机对照的行数不是独立交易次数，不用自动重采样掩盖可比性不足。
