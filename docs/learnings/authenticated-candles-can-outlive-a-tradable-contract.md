# 校验通过的K线也可能晚于合约的可交易期限

- **问题**：三年SPIKE源数据全部SHA、OHLC和真实成交额抽样通过，但独立检查发现128个合约在已知deliveryDate之后仍有官方零量占位行，部分连续段全程无交易。
- **误区**：官方来源、文件完整、每小时都有一行，并不证明该小时仍可交易。直接延续持仓会把未知的退市清算伪装为研究期末正常估值。
- **修复**：在任何收益评分前保留原数据，单独生成可交易视图；按已知交割边界保留完整K线，排除全零段和领先无量占位。正成交量早于当前onboardDate时保留并报告元数据冲突，不用当前上市快照抹去可能的旧历史。
- **验证**：原ZIP独立聚合、所有段SHA、合成交割半小时边界、零量段、正量上市日期冲突、原件不变性分别检查。数据断点存续仓只记源尾censored，不声称真实清算成交。
- **通用规则**：数据完整性、价格正确性和可交易性是三个不同的验收项；后两者不能从SHA相等推出。
