# 人工确认队列不能排在空闲账户轮询之后

- **问题**：A 的确认至执行拒绝相隔约 95 秒，超过原本 60 秒报价期限；页面轮询正常也无法让排队中的订单及时执行。
- **死胡同**：只增加刷新按钮或延长报价有效期，无法消除网络阻塞，还会扩大旧报价的执行范围。
- **有效路径**：手动账户无在途意图/系统仓位时先读本地确认队列；空闲不发交易所查询。新意图仍完整核对账户、归属、杠杆和报价。GET 复用连接，账户与挂单的独立读取并行，每一核对阶段结束即丢弃响应；POST 不重试、不复用旧的报价/余额。
- **通用规则**：先拆开确认等待、远程核对和成交回执耗时；状态轮询频率不能代表执行速度。不得用延长授权期限掩盖队列阻塞。
- **牵连**：`manual_engine.py`、`manual_client.py`、`__main__.py`；只改变均线密集专用 worker。信号中心账户与执行循环保持。没有用真实订单做验收。
