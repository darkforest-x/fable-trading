# 固定 1:3 的盈亏比必须把成本先换成 R

- **问题**：BTC 1h RSI 大菱形配5m六均线确认，91赢/265亏，25.56%胜率略高于1:3的毛盈亏平衡25%；毛收益+8R，但扣项目固定0.2%成本后净收益−97.05R。
- **死胡同**：用“1:3且胜率超过25%”直接认定正期望；或只看六均线较直接入场少亏192.31R，就认定价格择时改善。这忽略了每笔止损距离不同、20bp成本折算出的R也不同。本轮没有因此调低成本或筛选更好年份。
- **有效路径**：逐笔使用 `cost_R=0.002/risk_pct`。六均线样本平均成本0.295085R，`4×25.5618%−1−0.295085=−0.272613R/笔`，完全对账。六均线让风险距离中位数0.5541%→0.8654%，成本R均值0.5103→0.2951；但毛价格收益均值3.4196bp→1.9420bp，价格单位平均收益反而下降。固定风险与固定名义金额是两种不同加权方式。
- **通用规则**：先同时报告毛/净R与毛/净bp，再解释策略改善；固定3R目标不等于扣成本后的3:1。当前样本按平均成本推算需约32.38%胜率才平衡，只是解释式，不是新的策略阈值。
- **牵连**：`analysis/p1_btc_rsi1h_sixma5m_20260920.md`；实验 `exp-btc-rsi1h-sixma5m-20260920-v1`。仓位、杠杆及资金费没有给定，累计R不能冒充账户收益率；六均线与直接入场独立串行，占仓路径不同，不能把净交易数差冒充严格子集过滤。
