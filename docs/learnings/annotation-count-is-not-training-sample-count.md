# 标注行数不等于独立训练样本数

- **问题**：Owner-short manifest 的文件、标签和时间切分全部守恒，但独立哈希审计发现 15 组图片与标签同时逐字节重复；历史别名标注被当成不同样本计数。
- **死胡同**：只检查 `sample_id` 唯一、图片/标签数量相等和跨 split 依赖，会放过“不同 id、相同输入、相同目标”的重复记录；训练可以正常启动，却会静默提高少数事件的权重。
- **有效路径**：在时间切分和负例配对之前，按 `symbol + input interval + core interval` 合并训练目标；优先保留精确星标血缘，把所有原 Owner id 挂在 canonical 行上，并在渲染后用 `image_sha256 + label_sha256` 设置第二道硬拒绝门。
- **通用规则**：数据集开训前除主键、文件守恒和跨 split 检查外，必须同时统计“图片哈希重复”和“图片+标签联合哈希重复”；后者才是实际优化器看到的样本粒度。
- **牵连**：`scripts/build_owner_short_gold_center_dataset.py`、正负配对数量、time split 统计、训练样本权重；不涉及 holdout、阈值、模型权重或生产配置。
