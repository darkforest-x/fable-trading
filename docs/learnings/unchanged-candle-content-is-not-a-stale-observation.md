# Unchanged candle content is not a stale observation

- **Problem**: On 2026-10-17, MINA 30m closed at 11:30 Beijing and was detected at 11:33:31, but the live executor first considered it at 12:08:46 and rejected it as expired. Management of the existing USO 4H lot repeatedly reported a stale checkpoint and blocked all new entries. The scanner intentionally rewrote its compressed seed only when closed candles changed.
- **Dead end**: The earlier quote-clock repair was necessary but did not exercise hours of management after a real fill. A healthy worker heartbeat or a recent successful entry cannot prove that later entries remain reachable. Increasing the 30-minute gate or ignoring management errors would conceal genuine outages and change the approved behavior.
- **Effective path**: Correlate event close/detection/first-attempt clocks, management errors, and the scanner's unchanged-prefix branch. Keep content revision time intact and persist a separate successful observation receipt, bound to symbol, timeframe, checkpoint revision and last closed candle. The execution reader uses that receipt with the original 30-minute limit; failed reads never refresh it, and missing completed candles still fail. Offline integration reproduces an old 4H seed blocking a new signal, then permits the same management path with a current matching receipt and no trading POSTs.
- **General rule**: Cache change time measures content change, not reader health. Freshness checks on slowly changing data need an observation clock with explicit lineage. Verify both unchanged healthy data and unchanged unavailable data, including downstream admission under an existing position.
- **Impact**: `yoyo/monitor/store.py`, `v9_worker.py`, `yoyo/okx_execution/source.py`, and execution regression tests. No signal-age/quote-age threshold, strategy, size rule, or historical terminal decision changes. Existing untimestamped logs establish the failure mode but cannot prove every second of the historical blocking interval; new error/recovery logs include observation time.
