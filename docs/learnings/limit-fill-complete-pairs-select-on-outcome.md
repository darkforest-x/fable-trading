# 要求限价对照全部成交的严格配对，是按结果筛样本

- **问题**：周一1.618六均线回踩（`exp-monday-ma6-retest-20261024-v1`）的山寨组，严格配对只保留“三个随机对照全部成交且闭合”的信号（4,078/6,357）。该子集信号均值 -0.10R，而闭合对照不足 3 个的信号均值 +0.35~+0.51R；全体信号是 +0.068R。报告的主对照结论（差值区间跨零）完全建立在这个子集上。
- **死胡同**：把“三个对照都成交”当成中性的数据完整性条件。实际上回踩限价能否成交本身就是结果：价格回到均线包络 = 行情在震荡；对照挂单没成交、被撤销 = 行情直接走掉，而这正是信号大赚的那些周。要求全部成交，就系统性地删掉了趋势周，把比较限定在双方都亏的子集里。逐笔数量（6,357）也不是独立样本数，单是 2025-11-17 这一周就有 167 笔同向多单。
- **有效路径**：以“尝试”为单位配对：每个已提交挂单算一次尝试，未成交计 0R，只剔除已成交但未闭合的单，并按纽约市场周聚类做 bootstrap。复算结果与报告中的尝试级数字完全一致（+0.067/+0.081/+0.074R），按周聚类的区间不跨零（单侧 P≈0.5–1.4%），但剔除盈利最多的 5 个市场周后降到 +0.025~+0.052R。策略本身的绝对均值按周聚类后区间是 [-0.10, +0.24]R。
- **通用规则**：只要对照用的是挂单入场，就不能以“对照成交/闭合”作为配对的纳入条件。先报尝试级（未成交=0R）的周聚类差值，再把严格成交子集作为描述性附表，并同时给出被排除信号的均值，好让人看出筛选方向。
