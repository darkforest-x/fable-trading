# 持久结构方向要重放完整因果历史，不能把最后一个枢轴当成实时趋势证明

- **问题**：将 Market Break 一类结构指标接入 K1 入场过滤时，图上枢轴位置和最近21根K线都不足以说明决策时刻实际知道什么。
- **死胡同**：按回画标签取时刻会提前使用右侧确认；逐请求只计算21根又会丢掉更早已经建立、至今未反转的方向。把这个持久方向直接叫“非盘整”同样越过了证据。
- **有效路径**：逐连续小时段从冻结前缀初始化，保存枢轴来源开盘、确认收盘、前后方向和最近反转可用时刻；再精确连接各请求自己的 K1 收盘。10右侧确认意味着中心开盘后11小时才可用。缺口清空状态，并用未来后缀变异、截断和独立逐小时重算验证时钟。
- **通用规则**：先确定指标是局部窗口函数还是持久状态机，再决定需要导出多少历史。公式参数相同不代表计算历史、未知初始化、并列极值和确认时刻相同；源码近似与运行时逐点一致必须分开声明。
