# 全局历史排序必须发生在分页之前

- **问题**：2026-10-30，触价列表固定按评分排序；添加时间排序时，今日记录完整在前端，历史记录却由后端分页读取。
- **死胡同**：只改前端比较器能排好今日列表，却只能重排已取回的历史页；尚未加载的更早或更新记录仍会落在后续页。本次通过读 SQL 发现该限制，未采用这一方案。
- **有效路径**：前后端共用 `score`、`time_desc`、`time_asc` 选项；后端使用白名单 SQL，在 LIMIT/OFFSET 前排序。触价使用显示的 `candle_ms`，闭仓使用 `exit_ms`；时间与 ID 同向打破平局，空值靠后。排序加入历史请求身份，切换时丢弃旧页及迟到响应。
- **通用规则**：新增排序先确定完整数据集在哪一层，再确定用户看到的时间是哪种事件时间；不能把接收时间当触价时间，也不能把单页有序当全局有序。
- **牵连**：`yoyo/monitor/monday_reclaim_paper.py`、`static/monday-reclaim-paper.js`；保留默认评分排序、今日边界、跨日持仓与资金筛选。跨页顺序、同时间平局、切换期间迟到响应分别验证。
