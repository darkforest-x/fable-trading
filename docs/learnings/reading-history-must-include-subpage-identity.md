# 阅读历史需要章节身份，不能只记主页面

- **问题**：工作台只把顶层页面写进 hash，返回后丢失具体章节和滚动位置；异步内容出现前恢复滚动又会被短页面截断。
- **死胡同**：每次切页滚到顶部，或只记一个全局 scrollY，都会把不同页面的位置混在一起。只在资源加载完成时滚动也早于正文完成。
- **有效路径**：章节、子页、筛选与页码进 URL，滚动位置按完整 URL 存到会话；内容出现后恢复，并在用户开始滚动或操作时停止自动恢复。表单草稿不进入 URL。
- **通用规则**：恢复位置先确定内容身份，再等待该内容足够高；用户操作始终优先。
- **牵连**：static/workspace-navigation.js、阅读页、research.js、app.js。
