# ATR 等比障碍 + 固定成本 = 假的"高波动 alpha";判据是毛 PF,不是净收益

**日期**:2026-07-26
**类型**:反直觉结论(验 short-only 链路判断层时发现)

## 一句话

障碍是 **TP5×ATR / SL2×ATR**(收益按 ATR 等比放大),成本却是**固定 0.2%**。
于是"只做高 ATR"必然让**净收益**变好——但那不是选出更好的交易,而是**下更大的注**。
实测高波动分位其实是**更差**的交易:**毛 PF 1.39→1.26、胜率 0.33→0.22 双双下降**。

## 怎么暴露的

1. 100 币 short 走查:5 折里 4 折 `best_iteration=1`(LGBM 只学一轮)、`rho_mean` 为负,
   top-decile 净值却为正 → **"判断层"其实退化成一个阈值**。
2. 把边写成显式规则对照(IT-17):唯一**5/5 折全正**的是 `atr_pct_HIGH`(均值 +0.54%@0.2%);
   而**正确早停**的 LGBM 只有 -0.03%,**还不如裸池 +0.13%**。
3. 矛盾点:`Spearman(atr_pct, realized_ret)` **5 折全负**(-0.20~-0.30)——高波动**更容易亏**,
   但取最高波动 10% **却净赚最多**。两者只能同时成立于"赔率放大"机制。
4. 决定性检验(IT-18):**毛 PF 是尺度不变的**,等比放大不会改变它。
   实测毛 PF **1.39 → 1.26 下降**,胜率 **0.330 → 0.220 下降**,
   而毛均值 +0.0018 → +0.0037 上升、净@0.2% -0.0002 → +0.0017 上升。
   → **ANTI-SELECTION**:高波动是更差的交易,净值变好纯粹是固定成本被稀释。

## 教训

- **净收益不是尺度不变量,PF 是。** 凡"障碍按 ATR/波动等比设定 + 成本固定"的设计,
  任何偏向高波动的选择都会**自动**抬高净收益。判断是不是真 alpha,**必须看毛 PF / 胜率**,
  或把成本也按同一尺度归一。
- **同样的净值提升可以用"仓位翻倍"平凡地得到**,且伴随更差的毛 PF = 风险调整后更糟。
- **`best_iteration=1` 是红旗不是细节**:模型只学一轮 = "判断层"退化成单特征阈值。
  遇到就**把它写成显式规则重测**——本次正是这一步把假边拆穿的。
- **秩相关与 top-decile 净值矛盾时,别选对自己有利的那个报**;矛盾本身就是机制线索。
