# 可见K线的开盘时刻不能冒充回放的已知收盘时刻

- **问题**：Monday Range v1.10 需要随历史视窗截止取已收盘子周期样本，但回放最后一根主图K线可能还在形成。
- **死胡同**：将 `chart.right_visible_bar_time` 加主周期长度当成截止点；这只是预计收盘时刻，不能证明回放已经到达那里。只检查子周期 `time_close <= cutoff` 也无法修正错误的 cutoff。
- **有效路径**：实时视图使用当前时刻；历史及回放视图保守使用最右可见K线的开盘时刻，并把此口径写在图上及前端。最终版本在 ETH 日线冬令时回放逐日推进，5m 样本截止随开盘前移，周一起点为 UTC 05:00；仍须单独完成受套餐阻挡的分钟回放矩阵。
- **通用规则**：先确认时钟代表已发生的观察边界，再过滤特征或样本。图上有K线、预计收盘时间已知，不等于整根K线已经可见。
- **牵连**：`yoyo/evaluation/pine/monday_range_v1_10.pine`；历史小图因此有意不使用最右K线开盘之后的样本。日线主图OHLC并不改变所选时区的1H周档案边界。
