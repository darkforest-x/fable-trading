# 入场颜色全同向，只能排除旧故障，不能证明趋势优势

- **问题**：旧K2策略常在5min已经反色时开仓，迅速退出；更换为事前固定区间首次突破后，还能否把亏损归因于同一问题？
- **死胡同**：把“所有周期同向”“没有立即反色”当作有利润的替代证据，或只挑未来达到1R的交易修改退出。它们分别混淆了状态一致与经济优势、未来路径与入场信息。
- **有效路径**：V7全286笔入场5min同向、没有5min即退出，仍平均净−17.79bp。283个同条件三配对仅超额+5.04bp，月块p=.1514；959个源区中未交易673个保持独立零分母，不拿它们稀释每笔亏损。旧故障已排除，入场与退出组合仍未通过。
- **通用规则**：修复一个机制后，先确认该故障在新样本中确已消失，再核验完整交易分母、净收益和同期对照。不要把同一个已消失故障重复当作解释；下一步只能冻结机会做可证伪的退出对比，不能先筛未来赢家。
