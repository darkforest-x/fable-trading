# 滚动窗口的连续性只检查窗口内部的时间边

- **问题**：High-R Entry V2使用[t-20,t]窗口判断前20根高点突破；gap数组把缺口标记放在较晚到达的bar上。最初实现检查gap[start:t+1]，会额外拒绝一根已重新积累完整历史的信号。
- **死胡同**：把“窗口内有gap标记”直接当作“窗口内部不连续”；gap[start]实际上描述窗口外前一根到窗口首根的边，并不破坏窗口内20条时间边。
- **有效路径**：同时检查窗口内相邻时间戳与gap[start+1:t+1]。缺口位于start时可恢复；位于start+1时仍拒绝。市场回放前用成对边界测试固定语义。
- **通用规则**：缺口标记是边的属性，索引通常落在边的右端；先画清窗口覆盖的节点与边，再选择切片。不得因为看到缺口恢复后的收益而调整边界。
- **牵连**：yoyo/evaluation/spike_high_r_entry_v2.py；tests/evaluation/test_spike_high_r_entry_v2.py。原退出与数据缺口处理不改。
