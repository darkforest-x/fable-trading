# 均线排列的当前状态与转向过程使用不同的时钟

- **问题**：Owner 的 COMP 1H 盈利空头经历“密集—排列—扩散”，能否把完整空头排列作为启动准入？
- **死胡同**：静态看图会把后续扇形均线倒填到原箭头。该例 17.20 空头当根跨周期排序仍是多头 12/12，完整空序晚 28 小时才出现，收盘已为 16.52；左侧失败的 17.61 多头却早已有连续 23 根完整多序。仅加完整排列会保留这个失败样本、推迟这个盈利样本。
- **有效路径**：对齐原始 15m 与完整 1H bar、区分开盘标时和收盘可知时钟，把排序水平、三组斜率与间距变化分别列出。空头发生时三组斜率已经全负，之后排序逐步翻转；在翻转初期总宽度还会缩小，不能要求从第一根就单调扩宽。
- **通用规则**：形态特征先拆成状态、变化、持续时间；任何后续确认都记真实可用时点和等待价格代价。完整排列只是一种可观察状态，不自动证明启动或盈利。对同周期 SMA/EMA 不强加固定先后，跨 20/60/120 组比较；实体在线外也不能误写成实体一根跨穿全部均线。
- **牵连**：`yoyo/evaluation/comp_ma_sequence_case.py`、`comp_ma_sequence_chart.py`，COMP 2026 年 7 月已知案例；只是描述性反例，不能覆盖历史硬密集门与早退门的负面验证，不改变 Pine、通知或交易规则。
