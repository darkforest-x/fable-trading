# 全景形态相似仍需核对启动锚点与当时价格轴

- **问题**：Owner 提供四张“长时间横盘、六线收拢后向上展开”的截图，要求先生成 20 张相似样本。首轮真实行情检索的全景图形态相似，但 OKB 与 BTC5m 两例红圈落在较早小试探上，明显释放发生在后面。
- **死胡同**：只用后续 40 根的涨幅对前面横盘幅度排序，会偏爱最终涨得大的窗口，不能保证红圈对应所要的那次启动。后续大幅上涨还会拉大纵轴范围，使此前波动在全景里显得更平；直接裁掉右侧但保留全景纵轴仍会保留这种视觉影响。
- **有效路径**：逐张检查全景中的事件连续性，保留初版并将两例对应事件邻域从本次预览排除；同时提供物理截止于建议启动根后第 3 根、独立用历史前缀计算价格轴的早期视图。对 1H、5m、3m 各一例删除全部后续源数据后重算，早期图片 SHA 完全相同。
- **通用规则**：完成态相似度、启动锚点正确性、当时可见结构是三项不同的验收。找相似图时明确是否使用后文；早期视图必须同时隔离未来 K 线与未来决定的缩放。完成态精选正例不能冒充无偏测试集，也不自动成为 Owner Gold。
- **牵连**：`yoyo/datasets/ma_launch_preview20.py`、`experiments/active/exp-ma-launch-owner-preview20-20260921-v1/plan_v2.json`、`preview_v2/qa_receipt.json`。本次是预览样本整理，没有训练或收益实验。
