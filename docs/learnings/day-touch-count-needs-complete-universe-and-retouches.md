# 指定日期的触价数量不能直接拿首次触价账本来数

- **问题**：复盘2026年9月16日哪些币触及周一1.618；旧参数研究账本只保留每周每方向首次事件，且后续行情文件只覆盖部分币种。
- **死胡同**：直接按入场日期筛旧账本会漏掉当天再次回踩的BTC；直接数目录的非空symbol字段又会遗漏中文币名。完整时间轴也不能证明活跃行情，旧数据中有平价零量品种。
- **有效路径**：从已登记的638个原始文件建立覆盖清单，检查周一与目标日完整性及活动性，与旧数据的重叠OHLCV核对。当天实际触价要求low≤线≤high；首次触价、当天回踩、已在线外但没有碰线分别统计。
- **通用规则**：先明确“币种／方向事件／触价K线”三个计数粒度，再检查宇宙和日期覆盖；不要把为交易入场筛选过的账本当作当天全市场行情清单。
- **牵连**：`yoyo/evaluation/monday_sep16_review.py`；数据集`data-research-spike_v128_recent_20260923-8849e2f9`；复用登记数据，不重下数据、不做迁移内容哈希。
