# 日线回放也必须按事件时钟释放资金

- **问题**：A股组合回测先遍历止损卖出、再处理当天开盘买入，看起来只是代码顺序，却让盘中止损的资金和仓位被更早的开盘订单使用。
- **死胡同**：把同一日的所有卖出放在买入前，或者只验证总现金不为负；这两种检查都无法识别日内时间倒流。
- **有效路径**：拆成前日退出申请/开盘跳空退出、开盘新买、盘中初始止损、收盘决策四阶段。以占满唯一仓位、旧仓盘中止损、新仓开盘订单的最小案例验证新仓必须被拒绝。
- **通用规则**：资金何时可用由成交时刻决定，不由输入日线记录的遍历顺序决定。不能用更晚的事件资助更早的事件。
