# 主题统一要修语义变量与选中态的来源

- **问题**：顶部导航已经绿色，信号页签和筛选项仍是紫色；同一产品的二级导航还分别使用胶囊、居中菜单和下划线。
- **死胡同**：只给顶部导航或某一个按钮补绿色，不能覆盖旧的全局 mint/brand 别名、写死的选中文字颜色和高优先级页面样式。
- **有效路径**：先复用 Stitch 的统一设计稿，将品牌语义变量收敛到同一绿色，再清除选中态硬编码。二级导航共享尺寸、间距、底边和激活色；账户链接按实际路由参数设置当前页。最后读取浏览器计算样式并检查各工作区与手机视图。
- **通用规则**：颜色一致性要从语义来源修复，而非逐个可见控件补丁；品牌交互色、交易方向色和多条图表曲线颜色分别保持自己的职责。
- **牵连**：design-tokens.css、stitch-system.css、compact-workspaces.css、workspace-layouts.js。仅调整展示与导航状态，不改变交易和数据计算。
