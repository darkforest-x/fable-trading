# 回放的当前位置与已经见过的信息要分别记账

- **问题**：历史回放允许暂停、回退、冻结和改提示词，但当前光标并不表示用户只见过光标之前的信息。
- **死胡同**：只截断当前图、清空 AI 答案或重新冻结，不能撤销用户已经看过未来和答案的事实；本次设计审查排除了这些做法，未把它们当成有效盲审实现。
- **有效路径**：行情完整序列保留服务端，浏览器只收当前 120 根闭合前缀；分别持久保存当前光标、最远已揭示时间和已请求 AI 的时点。第一次人工判断不可覆盖；原图、规则和参考版本冻结，未来回访另存，不进入原推理。重复请求复用已有调用身份，超时和重启不自动重试。
- **通用规则**：先定义信息在何时被谁看见，再定义回放按钮。向后移动不能倒转信息暴露；自选历史只保证本会话的展示顺序，不能冒充独立随机评估。
- **牵连**：`yoyo/vision_research/replay.py`、`replay_data.py`、`static/replay.js` 与 `tests/vision_research/test_replay.py`。沿用原均线因果语义，训练和生产资格保持 false；收益评价是后续独立任务。
