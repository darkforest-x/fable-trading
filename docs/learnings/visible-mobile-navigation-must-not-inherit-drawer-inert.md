# 可见的手机二级导航不能继承关闭抽屉的 inert

- **问题**：2026-10-18，手机布局把二级菜单显示在顶部导航下方，但菜单仍是侧栏的子节点。侧栏关闭时整棵子树被设置为 `inert`，导致菜单可见却不能点击或键盘访问。
- **死胡同**：只检查截图、颜色和 DOM 可见性不能验证交互；`pointer-events:auto` 也无法解除祖先的 `inert`。此前移动验收没有逐项点击，漏掉了这个状态组合。
- **有效路径**：先复现点击后路由不变，再定位菜单最近的 `[inert]` 祖先。关闭抽屉时只禁用隐藏的抽屉分支，保留实际可见的二级菜单；路由更新布局属性后重新同步隔离状态。抽屉模态背景隔离、全屏隔离和既有 inert 状态恢复分别保留。
- **通用规则**：响应式布局让同一个 DOM 节点承担新角色时，要同时检查祖先交互状态、焦点顺序和事件结果。验收必须覆盖直接进入、跨工作区切换、抽屉开关和断点变化，不能以菜单可见代替导航成功。
- **牵连**：`yoyo/monitor/static/workspace-display.js`、`workspace-layouts.js` 及对应前端回归测试。本次沿用既有 Stitch 设计，补稿请求连接失败后，Owner 明确授权直接修复交互；未改变视觉设计或交易行为。
