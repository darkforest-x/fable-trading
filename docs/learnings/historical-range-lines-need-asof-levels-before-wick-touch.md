# 历史区间画线的位置不等于触价当时可见的位置

- **问题**：区间翻身 Fib 会把周一最终高低点派生的水平线画回周一起点；按这张历史图搜索影线触价，会把稍后形成的周一区间带回更早的交易。
- **死胡同**：直接读取每周最终高低点，再与全周 K 线做相交判断。它能复现历史画面，却不能证明那些线在影线出现之前已经存在。同样，“前后两根有勾叉”不能在触价时提前使用后两根信号。
- **有效路径**：触价线位冻结在该 K 线开盘前已知的周一区间；周一逐根发展，新周第一根暂无线位，其余日期使用已完成周一。勾叉与触价配对的入场时间取二者首次共同可见的收盘。用未来极值突变、周一重置、前后配对和前缀不变性测试约束实现。
- **通用规则**：从可视化研究交易规则，先查线位的形成时间和历史绘制方式，再判断价格是否接触。显示在过去的对象，不自动成为过去可交易的信息。
- **牵连**：`yoyo/evaluation/btc_range_wick_fanshen.py`、`tests/evaluation/test_btc_range_wick_fanshen.py`、`monday_range_v2_11.pine` 的 `monHigh/monLow` 与历史 Fib 绘制。止损仍只取入场前已收盘数据；没有修改 Pine 或生产规则。
