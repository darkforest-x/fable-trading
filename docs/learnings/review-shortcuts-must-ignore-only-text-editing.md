# 审核快捷键只能在真正输入文字时失效

- **问题**：双图页的 `R` 在 Owner 操作筛选框、跳转框或复选框后看似没有反应。
- **死胡同**：全局键盘监听只要焦点标签是 `INPUT / SELECT / TEXTAREA` 就直接返回；这虽然避免备注输入误触，却也让普通控件残留焦点吞掉所有审核快捷键。
- **有效路径**：只在备注文本输入时屏蔽字母快捷键；数字跳转框仅保留数字键，变更后主动 `blur()`，其余控件不阻止 K/X/?/方向键。
- **通用规则**：高吞吐审核页的快捷键屏蔽条件要按“是否正在编辑自由文本”定义，不能按宽泛 HTML 标签定义；每个快捷键都要覆盖控件获得焦点后的场景。
- **牵连**：`yoyo/datasets/fixed_w10_canonical_review.py` 的旧双图页保留为历史证据；新合同在 `yoyo/datasets/owner_positive_refilter.py`，且已彻底删除不再需要的 `R`。
