# 固定退出和总数量时，首仓比例的收益目标是线性的

- **问题**：搜索“首仓一半、另一半等回撤”的最赚钱比例，容易期待 30%、50% 或 70% 必然存在内部最优。
- **死胡同**：仅对比例反复细化网格，或把补仓后的更小风险重新定义成 1R。前者不会产生新的曲线形状，后者可能只改变分母，让收益看起来更高。
- **有效路径**：在相同机会、固定退出、固定原计划数量及成本率下，每笔净收益为 `w * original_net_R + (1-w) * delayed_leg_net_R`；未补仓时第二项为零。总收益也是仿射函数，因此只按总净 R 排名，最优比例必在 0 或 1，或整段并列。中间比例仍可在波动、资金占用或其他约束下有价值，但那是另一个目标。回收确认的开盘价还可能高于原价；数量不增加并不保证到原止损的风险不增加，需要另报原止损风险暴露及缩量敏感性。
- **通用规则**：优化仓位比例前先写收益函数、固定分母和数量定义，判断目标是否线性；保留端点，并把风险目标与纯利润目标分开。不可把全历史网格冠军称为可部署最优。
