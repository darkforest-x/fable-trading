# 趋势记忆不能替代当前趋势活性

- **问题**：一段趋势一单解决了重复信号，但已建立的 regime 会持续存在；若只检查历史状态，数小时后盘整中的 K2 仍可能借用旧趋势身份入场。
- **死胡同**：要求 K2 当下仍满足建立 regime 的完整 `1 ATR + 0.05 ATR/bar + 12 bars` 强门会把开发期 207 笔压到 9 笔，而且收益仍差；这把“趋势仍活着”和“重新证明一段强趋势”混成了同一件事。按审计结果继续搜索幅度阈值也会污染选择。
- **有效路径**：保留严格门只负责创建 regime；在入场时另加零轴活性门——快慢线关系仍与方向一致、快线斜率仍与方向一致。零轴只表达当前方向，不从审计窗口挑最佳幅度。
- **通用规则**：有滞回的状态机必须同时定义进入条件、存续条件和退出条件；历史状态可提供上下文，但每次动作仍要验证当前可执行状态。
