# 跨资产共振必须单独冻结数据可用时钟

- **问题**：把同一小时的 BTC 入场与外部币收盘共振直接联结，会隐含两个交易所的数据瞬间可用且能在同一收盘边界成交。
- **死胡同**：照搬 `request.security` 的图上同周期位置，或把缺历史的 `nz` 当成零价格，都不能证明实盘在该时刻知道信号。前者隐藏延迟假设，后者在正价格上制造虚假多头分数；本轮在真实数据评估前即排除此实现。
- **有效路径**：V21 明定外部最后一根小时线的收盘时刻等于 K1 开盘，即比入场早一小时；精确时刻联结，51 根连续完整小时、四币全部已知才有均值，零分为中性而缺失为未知。
- **通用规则**：先定义数据何时完整、跨源何时可用、何时下单，再定义相关性与强弱。时间戳相同不是零延迟执行的证据，保守滞后也不等于已验证实际延迟。
- **牵连**：`yoyo/data/hourly_impulse_breadth.py`；ChartPrime `KkoxM97D` 的50根HL2位置分数；V21 的固定 ETH/SOL/BNB/XRP 外部面板、原 OKX BTC 执行源不变。
