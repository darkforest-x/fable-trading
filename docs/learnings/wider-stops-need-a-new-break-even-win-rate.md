# 放宽止损后，必须重算盈亏平衡胜率

- **问题**：2026-09-15 阅读 Timeless 的 IB25 外部策略。作者提出把 Fib 止损从 50% 放宽到 75% 可提高胜率，但固定 25% 回撤入场、回到极值止盈时，收益与风险已不再对称。这是规则算术审查，未运行回测，也未验证作者业绩。
- **死胡同**：只比较胜率，或把不同止损方案仍称为同一个 1R 目标，会把风险扩大造成的胜率改善误当成策略优势。本轮没有先做失败实验；这一误读在规则核对阶段被排除。
- **有效路径**：令上午高低区间为 D。入场到目标距离为 0.25D；50% 止损风险为 0.25D，75% 止损风险为 0.50D。毛收益/风险从 1 降到 0.5，零成本盈亏平衡胜率从 50% 升至 66.67%。若每单位仓位往返成本为 c（与 D 同为价格单位），门槛分别为 (0.25D+c)/(0.50D) 与 (0.50D+c)/(0.75D)。固定账户风险时还需同步缩小仓位。
- **通用规则**：看到“放宽止损提高胜率”时，先固定相同信号与入场，分别算目标距离、止损距离、成本/R 和仓位，再比较净期望与回撤。胜率上升本身不能证明净期望改善；成本、滑点或路径规则变化时不能套用理想二点分布的结论。
