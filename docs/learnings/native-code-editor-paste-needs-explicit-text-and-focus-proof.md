# 原生代码编辑器写入长源码前，先用短文本确认粘贴与焦点

- **问题**：向 TradingView 原生 Pine 编辑器保存 V9，默认 paste 和 setValue 未改变源码；改用长 typeText 后超时，并触发图表快捷键、误加临时指标。
- **死胡同**：把未变的辅助功能树当作输入已进入编辑器，继续输入 872 行源码；键盘焦点与粘贴格式没有被证明。长逐字符输入既无法及时确认，也会把代码解释成界面动作。
- **有效路径**：重新读取完整控件树并结合截图恢复焦点，移除本轮误加的三个 V8 副本；在新草稿中先用短注释验证 paste(text, {format: "text"})，看到编辑器值确实变化后才一次粘贴完整源码。确认 873 行与尾部，再通过私有保存触发编译。
