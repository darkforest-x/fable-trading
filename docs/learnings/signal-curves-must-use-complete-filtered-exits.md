# 信号曲线必须先聚合完整筛选记录，再分页

- **问题**：信号中心原有分页记录和累计 R 指标；增加可视化时必须使曲线、分组和指标使用同一批记录。
- **死胡同**：用当前页绘图，会让翻页、排序改变所谓累计表现；按单笔依次处理同刻退出，会人为制造先亏后赚或先赚后亏的回撤。
- **有效路径**：服务端筛选完整结束记录后，按退出时间合并同刻净 R，再累计和计算回撤，最后分页。缺失退出 R 或时间时，整个曲线标记不完整；不补零、不拿浮动或峰值替代。验收包含 2,003 笔分页一致性、同刻聚合、缺失值与分组总数对账。
- **通用规则**：先确定图表统计总体及时间事件，再选择图表库。参考 R 与真实账户盈亏是不同度量，不能换个坐标单位冒充账户资金曲线。
- **牵连**：`yoyo/monitor/signal_analytics.py`、`static/signal-workspace.js` 与历史统计测试。图表使用本地 Apache ECharts 6.1.0；全局 SVG 图标的 stroke 样式需隔离，避免污染图表文字和区域。
