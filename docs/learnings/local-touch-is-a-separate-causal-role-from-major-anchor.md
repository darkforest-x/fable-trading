# 主高点和局部贴线点应分开定义，并按确认时刻建线

- **问题**：ONE 15m 的第三次贴线离前一主高点只有7根，几何误差很小，却被原左12/右8高点定义和24根间隔同时排除。
- **死胡同**：只缩短三点间隔仍不产生C；统一缩短所有高点窗口又改变A/B主结构，无法知道改善来自哪种角色。事后用整段已知高点重建还会把未来才确认的B偷偷放进过去。
- **有效路径**：V12保留主高点A/B，增加独立的局部C结构族；只在C右侧确认事件当根搜索，并要求B此时已确认。B可以晚于C所在K线、早于C确认时刻被确认。候选通过原历史穿线检查后才出生；之后才累计突破收盘。
- **通用规则**：为每个锚点记录“所在K线”和“最早已知收盘”两个时间。新增触点角色应有独立开关和容量预算；用截断重放验证过去事件不变，不能只比较最终图形是否漂亮。
- **牵连**：`yoyo/evaluation/pine/spike_burst_v12.pine`；`yoyo/evaluation/spike_v12_local_touch.py`；`experiments/active/exp-spike-v12-local-touch-20260920-v1/`。辅助族参考与完整Pine合并池的parity是不同验收项；识别到一个上涨案例不等于盈利策略已验证。
