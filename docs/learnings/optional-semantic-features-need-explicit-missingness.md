# 可选语义特征必须显式保留缺失语义

- **问题**：独立复验器读取候选 CSV 时，某些短确认窗合法地没有 `post5`；直接把字段转成浮点数会把 JSON 的 `null` 与 CSV 的 `NaN` 混在一起，造成复验失败。
- **死胡同**：假设所有语义特征都是必填数值并无条件执行 `float(value)`。这会把“该窗口不存在第五根确认 K 线”误当成数据损坏，也可能让不同序列化格式产生不一致判断。
- **有效路径**：先按特征契约区分必填与可选字段；对可选字段统一归一化为 `None`，只有存在有限数值时才比较浮点误差，同时仍逐项复算所有实际参与门控的特征。
- **通用规则**：复验序列化后的特征前，先恢复其语义类型；`null`、空字段与 `NaN` 对可选特征都表示“未定义”，不能强制转为数字，也不能偷偷填零。
- **牵连**：`scripts/verify_1h_filusdt_grade_a_recent5d_probe.py`、CSV/JSON 往返、`post5` 可选确认特征、CPU/MPS 重放一致性检查。
