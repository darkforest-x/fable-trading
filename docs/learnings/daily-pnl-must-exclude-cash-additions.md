# 日盈亏先核对曲线字段单位，并剔除补资

- **问题**：策略小册从月度收益下钻到每日盈亏，同一历史曲线格式服务普通账户和补资账户。
- **死胡同**：直接对曲线第三列求日差会混用单位：普通账户存累计收益百分比，补资账户存累计交易盈亏金额。直接对余额求差又会把补充本金算作盈利。最近成交列表只有50笔，也不能代表完整月份。
- **有效路径**：读取完整结算点，逐点计算 `Δequity − Δcumulative_cash` 后按 UTC 结算日累加；同一时间的先亏损、后补资保留顺序。普通账户另以日初/日末余额计算日收益率，补资账户不显示该比率。数据覆盖外日期保留缺失状态。
- **通用规则**：对累计曲线做差分前先检查字段单位和外部现金流；用所有月份对账验证日金额相加、日收益率复利与原月度口径一致。
- **牵连**：`yoyo/evaluation/strategy_booklet_metrics.py`、`yoyo/monitor/static/reclaim-strategy-book.js`、`tests/monitor/frontend_strategy_book.test.cjs`。2026-11-01，12个策略全部历史月份误差小于1e-6，另覆盖闰日、UTC午夜、同刻亏损后补资及纯补资。
