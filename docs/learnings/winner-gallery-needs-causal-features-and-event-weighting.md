# 盈利图集的共性必须先拆成入场可见信息与行情重复

- **问题**：Owner要求从周一1.618收益率前200笔里提炼入场条件。图集按事后最高净收益与最佳已测退出选择，同一币、同周、同方向可包含多个确认时刻；触价挂单时尚不知道触价柱的最终成交量和收盘形状。
- **死胡同**：把200张盈利图当200次独立成功，或把挂单成交柱的最终大成交量当开仓条件，会同时引入结果选择偏差和时间前视。只把图裁成小级别不能解决这个问题；75个币周方向组也仍有共同市场冲击。
- **有效路径**：逐笔固定最后完整5m的信息时点，触价柱另记可用时间；29笔盘中挂单的完整触价柱特征仅作事后观察。统计发现200笔只跨38个纽约周，113笔来自两周，因此同时保留逐笔、币周方向组等权与市场周集中度。候选条件回到完整框架账本，包括亏损、未决和原匹配随机；只改准入时复用原成交，不为形式再造或重复运行成交引擎。
- **通用规则**：先问某个特征何时已知、多少行属于同一行情、未成功样本里是否也常见，再问能否形成交易条件。图集里的不利波动是持仓路径描述，不能据此直接宣称扩大或收紧止损有利。
