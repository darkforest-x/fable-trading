# 交易系统导图必须保留规则的适用范围与确认状态

- **问题**：Notion #57 要把现有交易系统画成细粒度导图，但来源同时包含 Owner 原始规则、方法整理、候选草稿和未实现的产品设计。放在同一流程中很容易被读成一套已启用的统一交易规则。
- **死胡同**：仅凭任务已完成、界面已有默认值或流程完整，就推导规则已批准或已验证，证据不足。核对发现 Manual-v4 绑定 V12.8 且仍为 draft；模拟盘的仓位倍数不是风险授权；#49 的 80/20 退出比例不能套给其他模型。未采用这种合并方式，也没有据此启动交易。
- **有效路径**：先逐来源核对版本与状态，再建立共用操作流程；模型特有规则留在对应分支。缺失的风险预算、确认条件和退出细则明确待定。将自然语言规则翻译到工具动作时还要核对分母：先减原仓 80% 后，要清掉原仓剩余 20%，在按剩余仓位计算的工具中应选 100%。
- **通用规则**：汇总操作规则时，先给每条规则附上来源、适用模型、版本与状态，再连成图。图的完整性只证明信息覆盖，不证明规则兼容、授权生效或交易优势。
