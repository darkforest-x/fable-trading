# 重复贴图必须链接到当前节点的来源

- **问题**：同一原图会在计划、持仓更新、结束帖中重复出现。图库按文件路径查找第一条出处，导致后面的节点跳回更早的帖子，破坏时间语境。
- **死胡同**：仅按像素去重可节约存储，却不能确定某次出现的来源；最早出现不是当前节点的出处。
- **有效路径**：图片展示优先使用当前节点传入的原帖 URL，缺少上下文才退回文件的默认出处；用同图不同帖子的小样本测试保证后续节点不回跳。
- **通用规则**：内容身份与出现记录分开保存。图像哈希负责去重，帖子 ID 和发布时间负责出处及回放顺序。
- **牵连**：`yoyo/monitor/static/rektproof-study.js` 和 `tests/monitor/frontend_rektproof.test.cjs`；原图不重绘，不改变发布时间。
