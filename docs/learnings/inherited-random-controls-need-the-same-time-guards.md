# 继承随机对照时仍要检查时间门是否一致

- **问题**：确认研究直接复用旧随机锚点后，机会层配对覆盖接近100%，但信号原本排除UTC周日，原始控制档案却允许周日。
- **死胡同**：把“沿用同一个随机种子和档案”当作完整口径一致。后续15m汇总已过滤周日，而原始控制表及另一退出研究未过滤；表名相似不代表资格相同。只看双方都确认的交集也解释不了零成交分母。
- **有效路径**：保留首轮原抽样结果，单独对15m/1H实施同样的非周日锚点资格；不重抽被排除的控制、不要求确认成功，取消/到期仍记零。时间切分要求两侧各自成熟。完整覆盖变为约87%/89%，主要结论不变，但超额数值必须更新为对应口径。
- **通用规则**：复用控制先追踪原始抽样、后处理资格、实际入场和原锚点四层语义；共享时间门属于可比性条件。更正时保留原结果与敏感性，不能只留下更好看的版本。
