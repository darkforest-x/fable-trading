- **问题**：TradingView 对 V12.11 报 CE10213，而仓库的 3073 行文件含有多处顶层 `plot`、`barcolor` 和 `plotcandle` 调用。活动编辑器实际上只有 85 行，停在变量声明区，输出部分从未进入本次编译。
- **死胡同**：曾根据 21:26 的旧编译日志和脚本标题，误以为完整文件已载入并修复；21:31 的新日志仍报错。只确认脚本名或看到旧成功记录，不能证明当前编辑缓冲区完整。
- **有效路径**：把光标移到活动编辑器首尾核对行数，确认它从第 1 行到第 85 行；从本地文件重新全选复制并替换编辑器全文。核实 TradingView 行号到 3074（文件 3073 行加末尾空行），保存并重新编译；最新结果为“完成”，仅有 `second` 遮蔽内置名称警告，完整脚本已添加到图表。
- **通用规则**：遇到“缺少输出函数”时，除搜索输出调用外，还要核对活动编辑器当前全文的首行、末行和行数，并只采信最近一次编译结果。不要用空输出调用掩盖编辑器载入不完整的问题。
