# 周锚信号的随机对照要按挂单星期分层

- **问题**：周一1.618六均线回踩（`exp-monday-ma6-retest-20261024-v1`）的山寨组里，“触价到挂单间隔越长，胜率越低”（>48h 胜率 8.5%，其余约 15–17%）。看起来像是确认拖得越久越差。
- **死胡同**：把间隔本身当成原因去研究“最多等几小时”。其实间隔越长，挂单越落在周末：按纽约时间算，周三挂单各半 +0.45R、胜率 23%；周日挂单 -0.49R、胜率 7.9%。按周聚类后，两者差值的 95% 区间是 [-1.09, -0.39]R，前期和后期都成立。在同一个星期分组里，间隔并没有稳定的影响。而且**随机对照呈现同样的星期梯度**（周三 +0.51R，周日 -0.51R），说明这是一周中所处时点的效应，和确认规则无关。
- **有效路径**：先按挂单星期分层，再做“信号减随机”的比较。随机对照是在触价后任意合格时点抽的，所以比信号更偏向周末（周日占 21.6%，信号占 15.4%）。分层后，已平仓交易的超额收益从 +0.065R 降到 +0.015R，原先看到的“确认优势”大约四分之三其实来自挂单星期的构成差异。去掉周六、周日挂单后，信号平均 +0.237R，同样过滤后的随机对照是 +0.255R：这一步过滤让整体变好，但六线确认本身已经没有额外贡献。
- **通用规则**：凡是以周为锚的策略（周一区间、周目标、周内失效），对照组除了同币、同周，还要对齐“在一周中的时点”，或者按星期分层报告。任何关于时长的过滤条件，都要先排除星期这个混杂因素。这次的星期效应是事后才发现的，作为过滤条件使用前，需要不重叠的新窗口验证，并由 owner 批准。
