# 选币排名窗必须在交易窗之前结束；否则"高波动更赚"是自己造出来的

**日期**：2026-08-18

- **问题**：按币种波动率分档，超额收益随波动单调上升（+4.09 → +15.77bp），
  看起来"挑高波动币"是一条现成的规则。

- **死胡同**：排名用的是**所交易的那 6 个月**的 `atr_pct` 中位数。
  它没有碰未来 K 线、没有碰 holdout、每个特征都因果——
  **所有常规前视检查都通过**，因为前视不在特征里，在**样本池的定义**里。

- **有效路径**：把排名窗往前挪一格——改用**上月**波动率给币排名
  （这也是实盘唯一拿得到的榜单），其余一律不动。
  **单调性当场消失**，变成倒 U，最高波动档回落到接近最低档。
  差值就是选币前视的大小。

- **通用规则**：**任何"按 X 挑币"的规则，X 的计算窗必须在交易窗开始之前闭合。**
  便宜的诊断动作：**把排名窗从"同窗"换成"前一期"，看单调性还在不在**——
  在，是真规律；不在，刚才看到的是自己用未来选的池。
  同理适用于"当前涨跌幅榜单"：**现在的榜单是已经动完了才上榜的**，
  用它挑币等于三重前视（币还活着 + 波动已实现 + 排名用了结果）。
