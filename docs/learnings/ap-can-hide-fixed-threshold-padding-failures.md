# 总体 AP 的小幅下降可能掩盖固定阈值下的大量逐图失效

- **问题**：低延迟 v6 仅改变验证补边时，test mAP50 从96.62%降到87.63%。只看这两个数，容易低估真实使用阈值下的影响。
- **死胡同**：把mAP变化当作固定阈值漏检变化；用各自最佳置信度的P/R比较，也会把运行时冻结的阈值悄悄换掉。只展示最坏单图则又会夸大其代表性。
- **有效路径**：同一批159张规则正图逐图配对，固定conf0.25、同类IoU0.5与原验证NMS0.7。补边后40图命中变漏检、4图反向改善，110图持续命中、5图持续漏检，故命中150→114。再对按预先规则选出的最坏高置信度案例做可逆张量实验：内容像素不变，左右各16px灰边使匹配分数0.984710→0.004088，去边恢复0.984710；坐标已回到原图，不能解释为展示框错位。固定1312宽度、仅将同一内容置于左偏移0/16/32px时，匹配分数又为0.00115/0.00409/0.98443，进一步排除“只是画布尺寸改变”的解释；该单例尚不能锁定网络内部或训练数据的唯一病因。
- **通用规则**：先报全体逐图的得失转移表，再用固定输入、可逆单变量案例定位机制。AP、固定阈值召回、连续行情误报是不同指标，不能互相替代；一次位移脆弱性证明也不能单独证明全部原因都是训练位置捷径。
- **牵连**：`yoyo/evaluation/ma_early_followup.py`、`exp-ma-morphology-v6-threeview-20260925-v1/padding_followup_20260926_v1/`与`padding_tensor_probe_20260926_v1/`。沿用[真实输入张量契约](rectangular-validation-padding-can-break-chart-detectors.md)；未改权重、阈值或生产输入。
