# 背景负例证据必须覆盖整张可见窗口

- **问题**：收益非赢家不能充当形态负例；旧“easy”筛选只要求伪核心末端某个指标超过阈值，即使末端不密集，图的左侧或右侧仍可能含目标。
- **死胡同**：只替换负例来源或名称，甚至只验证伪核心，都不能证明整张图应当没有框。旧负例多数为密集但未启动的hard，这也不能直接解决Owner对背景构成的纠正。
- **有效路径**：新v6先收明确非密集背景，沿用历史easy的1.6ATR宽度界限并强化到最长可见窗每根；CLOSE发现均线和HL2显示均线同时验证。所有已知形态候选不论收益均受保护，未来收益不进入负例资格。相似/密集边界独立留作待审，不强求比例。若整个窗口无法证明不含目标，就拒绝空标签。
- **通用规则**：负例要回答“为什么全图没有目标”，且证明的时间右端必须等于训练可见右端；数值通过不是逐图Owner确认。回归验证同时覆盖窗口两端、未来极值扰动、数据缺口和保护区的收益无关性。
- **牵连**：`yoyo/datasets/ma_morphology_background.py`、`yoyo/datasets/ma_morphology_redo.py`、`experiments/active/exp-ma-morphology-negatives-20260922-v3/plan.json`。新背景的保守筛选会降低容量并使评估偏容易，不能据其mAP声称覆盖所有相似行情。
