# 事件排序不能用仅正例有的真值框筛选预测分数

- **问题**：用图像检测器排序交易候选时，若只给盈利事件标框，如何在完整候选池计算不泄漏的 AUC、top-decile 和误报？
- **死胡同**：先用真值 IoU 过滤预测，再取置信度当事件分数，会让没有真值框的失败事件天然得零分。另一处实现陷阱是只给每张图记一次命中，遗漏赢家图上的额外同向错框或重复框。
- **有效路径**：先按因果候选的已知方向，取全部同向预测框最大置信度；真值 IoU 只用于固定阈值检测 TP/FP/FN。单个真值最多匹配一个预测，剩余框全部计 FP；事件级和框级口径分别说明。完整全池 join 校验事件、split、方向、周期、源事件时间与图像 SHA；val/test 分开。常数分数的 top10% 只是 ID 平局裁决，不能声称可排序。
- **通用规则**：用于排序的分数必须能对尚未有标签的新样本以相同方法计算；正例专属的框、结局或人工确认信息只能进入评估目标。
