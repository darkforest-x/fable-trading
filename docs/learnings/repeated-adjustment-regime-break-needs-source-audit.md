# 重复出现的复权分段不能直接归因为网络串包

- **问题**：`sz.001914` 的 BaoStock 后复权请求被校验拒收：同一响应包含 `adjustflag=3` 和 `1`。它最初紧邻其他股票的超时/接收错误出现，容易把几个现象当成同一个网络故障。
- **死胡同**：仅凭时间上接近就推断复权混合来自超时连接的旧响应。连接超时后应丢弃是正确防御，但它不能证明任何后续源数据异常都由传输污染造成；此前 `timed-out-market-connection-must-be-discarded.md` 记录的001914现象不能视为该因果关系已验证。
- **有效路径**：在新目录、全新会话同源重试后，异常精确重复在同一个日期边界：2015-01-05～2019-06-05的1077条为未复权，价格等于raw；2019-06-06～2025-12-31的1597条才是后复权。应将其作为该证券复权前史不完整的源证据，而不是硬改flag或扩大网络重试。指标初始化只能使用明确连续的价格坐标，缺失前史必须披露。
- **通用规则**：先区分请求身份错配、随机传输损坏和稳定的历史语义断层。独立会话重复同一日期断层后，优先审计数据定义；不能把相邻错误拼成未经验证的统一原因。
- **牵连**：`yoyo/evaluation/ashare_data.py` 的复权校验；`analysis/output/imacd_ashare_daily_20260909/data_mainboard/source/sz.001914_1.csv`，以及保留的原请求/哈希收据。研究选股规则不得因个别数据质量问题改为换一只股票。
