# 比较止盈方式时，要同时对齐已结束交易的入场集合

- **问题**：同一批入场采用近目标和远目标，远目标可能在资料截止时尚未结束。直接比较各自已闭合均值和胜率，退出方式与样本分母同时变化。
- **死胡同**：把未决记成零收益，或只说“起初入场相同”，都不能解决退出统计分母的差异；前者还会污染盈亏分母。
- **有效路径**：保留各方案全部已闭合和未决统计，另列三方案均闭合的共同入场集合。跨时间切点时，只要某一方案跨界，该入场不能进入该期共同集合。用未决远端腿的最小样例检验三个方案一起排除。
- **通用规则**：原始结果与共同闭合结果同时报告，并说明后者是事后分母对齐，不是入场条件。无保本或其他腿间交互时，各半收益是两种全平收益的线性平均；同一闭合集合下不能超越两者均值上界。
- **牵连**：`monday_ma6_analysis.common_exit_cohort`、对应分母测试及报告共同闭合列。只处理冻结框架结果，不重复成交回放。
