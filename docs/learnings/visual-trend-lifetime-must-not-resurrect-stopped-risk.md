# 趋势还在，不等于最初那笔风险参考仍然存活

- **问题**：把释放后的大涨统一换算为高 R，容易将初始止损触及之后的走势也归给原信号；用光晕持续根数控制面板又会过早清空趋势。
- **死胡同**：延长光晕或直接把 3R 改为更远目标，都没有定义参考何时失效。同根高低同时越过止损与目标时，先算有利极值也会制造未证实的利润。
- **有效路径**：结构 episode 与风险轨迹分别维护。冻结初始入场、止损、R；风险先查止损再算极值，一旦触及永久停止该段 R。结构可以继续显示延续、回踩、整理直到自身结束条件。下一根开盘模式每 tick 重建固定 open，收盘提交，避免 rollback 丢失状态。
- **通用规则**：添加持有期视觉前先写清“谁还活着、谁已结束”，并分别测试。不用可见高点替代可执行成交，更不能让停止后的参考复活。
