# 多周期回放必须显式绑定成交时钟与期末边界

- **问题**：把原来固定 4h 的回放推广到 15m / 1h，若只替换输入 K 线，会把持仓时长、止损生效时间、月末净值和匹配排除窗一起算错。
- **死胡同**：直接复用常量 `4h`、把 bar 收盘时间当作下一月收益、用期末浮盈与已平仓交易混算。独立复核还发现，无净值序列的控制账户可能漏掉结算手续费造成的回撤；跳空到初始止损价会制造无限 R 倍数。
- **有效路径**：周期时长成为显式参数；信号收盘、下一开盘、父周期 BE 更新与子周期成交分别建模。所有账户和控制在同一边界结算并扣费，保留行政退出标记；交易账本净利与账户净值核对。零风险分母的 R 值标为空，不能当作达到 10R。
- **通用规则**：先用合成路径检验时钟、费用和边界，再读市场价格；跨周期比较采用同源完整聚合和统一日历区间。
