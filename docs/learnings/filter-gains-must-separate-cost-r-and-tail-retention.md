# 过滤收益改善要拆开成本 R、原赢家保留与新增重入

- **问题**：V9 两年净收益比 V8 改善 4779.95R 并转正，容易被误读为发现了稳定趋势优势。
- **死胡同**：将 USDC、量比与周日单门的历史改善相加；只比较净10R总笔数532→462，或者只看全期+2758.17R。这些都看不见交集、持仓重入和近期亏损。
- **有效路径**：固定同一输入完整串行重放，先逐笔复现 V8，再按事件身份联结：80803个共享事件结果不变、14388个被移除、1479个新增；原赢家保留458、丢74、新4。成本R减少3303.85占改善69.12%，毛R仅增加1476.09；后一年仍亏2089.19R，随机入场超额区间跨0。
- **通用规则**：策略转正先问“是否只是少承受了成本、少做了亏损市场”，再看身份保留、时间稳定性及匹配市场入场对照。未知值拒绝是可执行规则的一部分，若纳入检验必须明说，不能归因成已知特征的优势。
