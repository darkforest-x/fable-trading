# 用户举例中的数值不能直接升级为策略参数

- **问题**：Owner 用浮盈举例说明人工持仓判断的需求，交付却把例子中的 4R 写成固定复核节点。
- **死胡同**：为了让流程显得具体，直接把问题里的示例数字做成规则；即使注明“练习约定”，也没有解释为什么该阈值应存在。
- **有效路径**：撤回固定倍数节点，把持仓决策放回交易理由、结构、障碍与退出条件。原草稿保留为历史，工作台与 Notion 同步勘误。
- **通用规则**：先区分用户的例子、明确约束与待研究问题。示例数值只说明情景，不授权将其设为默认阈值。
