# 多个币种的盈利可能仍由同一个行情周支撑

- **问题**：5m 上插针候选加上自然针尖距离≥0.63621485%后，2026 年26笔已决交易平均扣费+0.459R、滑点压力后+0.238R，看起来有多个币种贡献盈利。
- **死胡同**：只数盈利币种或把独立交易R相加，会忽略同期行情的共同驱动。XRP贡献+13.517R，大于全部交易的+11.925R；1月12日这一周的SOL与DOT两笔合计+12.300R，移除该周后其余24笔合计−0.375R。不能把同周两个币种当成两份独立的策略确认。
- **有效路径**：直接筛选已执行的框架账本，保持止盈、针尖止损、成本和失败样本不变；并列跨年表现、周聚类区间、匹配随机及逐币/逐周剔除诊断。2025滑点压力后−0.133R，2026对照p≈0.136，绝对收益周聚类区间跨0。已有81项数值对照保持一致，不需要再跑成交引擎。
- **通用规则**：少量高盈亏比交易天然有偏斜，删除赢家不能单独证明策略无效；但若跨期表现弱、置信区间宽、一个币种或一个行情周足以翻转结论，应保留为未证实候选，不能继续堆条件把历史收益调正。剔除诊断不是前向可用过滤条件。
