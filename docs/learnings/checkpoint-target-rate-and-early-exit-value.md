# 判断提前平仓，要比较同一笔仓位从当时起还能多赚多少

- **问题**　小时线收回 1.618 后，反弹进度落后的仓位更常触发保护止损。这个差别能否支持立即平仓？
- **容易误判之处**　按“止损”计亏损，会把已经保护住利润的仓位也算成失败。只比命中率，还会漏掉少数慢启动交易剩余的止盈空间。
- **做法**　在同一决策时点保留原仓位和原止盈价，用下一根可成交开盘价测算提前退出，逐笔比较两种退出扣费后的差额。对这 46 笔慢反弹，31 次保护止损中有 26 次本来就有净利润。每笔固定 1000 USDT 名义仓位，31 笔提早平仓合计多留 370.80 USDT，另外 15 笔合计少赚 663.37 USDT。
- **复用**　评估任何“势头不足就退出”的规则时，先在相同的存续仓位上拆出救回的金额和放弃的金额，再按原仓位分配重算账户。按退出原因统计的频率回答的是另一个问题。
- **依据**　[原生替代成交](../../experiments/active/exp-live-wick-reclaim-progress-20261107-v1/fills.csv.gz)与[原交易路径](../../experiments/active/exp-live-wick-confirmed-swing-20261107-v1/events.csv.gz)按事件 ID 配对。半程阈值在新成交之前固定。
