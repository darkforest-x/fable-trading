# 月簇重采样后仍要保留每笔均值的分母

- **问题**：同一入口有多个观察时钟，行情窗口重叠，每月样本数量不同；希望估计每个入口的平均变化和背景超额。
- **死胡同**：把四时钟视作独立样本会虚增样本量；先算每月均值再等权平均，会将低交易量月份放大，回答另一个问题。把未知填零或重抽空分母样本则隐去缺失。
- **有效路径**：固定24个月整簇重采样，所有时钟/配对共用月索引；每次以重采样后的已知事件总和除以事件数。未知保留，若某次分母为零，区间保持不可判定而不重抽。
- **通用规则**：确定估计量的单位后，再选重采样单位；相关性控制不能暗中改变估计量。固定4h主结果，不按其他时钟好坏替代。
- **牵连**：`yoyo/evaluation/hourly_impulse_fixed_clock_statistics.py`；V24统计为重复开发期的探索性诊断，月间弱相关和符号交换假设仍有限制，不是随机处理试验或生产盈利验收。
