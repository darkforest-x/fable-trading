# 远端预检应只读核验冻结回执

- **问题**：Mac 冻结并上传 audit.json 后，Windows 预检若再次调用会写文件的审计函数，默认换行转换可能使等价 JSON 的 SHA 改变。
- **死胡同**：放宽 SHA 检查或接受文本“看起来一样”，会破坏冻结输入的逐字节契约；在核验函数里重写输入也让预检拥有不必要的副作用。
- **有效路径**：审计函数增加只读模式，Windows 从真实图片和标签重算审计结果并与冻结字典比较，原审计文件保持逐字节和时间戳不变。
- **通用规则**：冻结的是输入，预检产生的是验证结果。重新验证不应改写它正在验证的材料；跨平台文本编码/换行也属于字节身份。
- **牵连**：`yoyo/datasets/ma_morphology_redo.py::audit`、`scripts/windows/run_ma_morphology_redo.py::run_training`。该改动发生在全量构建完成后，不改变筛选、图片或标签。
