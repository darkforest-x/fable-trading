# 极端大赢家必须与全账户对账

- **问题**：SPIKE V1三年冻结研究确实产生RAVE 580.63R模拟净兑现，容易让个例替代系统验收。
- **验证路径**：先核对原生15m价格、真实量额及1H聚合，再独立复算下一根开盘、当根有效保护、退出区间和R。随后用固定已选交易重建全部现金和权益，不仅检查单笔收益公式。
- **结果**：RAVE贡献$53,809，但1H全账户仅净赚$7,732、最大回撤52.94%；其余已选交易静态贡献−$46,077。这里不能说“删除RAVE重新回测亏46.08%”：真正删币会改变现金与后续选单。本轮只是贡献归因。
- **对照**：同条件匹配账户没有显示爆发入场强于随机的证据；固定成交增加20bp往返成本后净贡献转负。随机是历史条件对照，不是可部署的随机系统。
- **通用规则**：分清峰值、规则兑现、账户是否买入、分配了多少本金、其余交易贡献、实际成交可实现性。每一层回答的问题不同；任一极端R都不能越过这些层直接支持加大风险。
- **范围**：`analysis/p1_spike_burst_three_year_20260910.md`，2023-09-09至2026-09-09、币安冻结COIN合约池、多头规则，已见历史第二次收益评估；没有据结果重新选阈值。
- **时钟边界**：OHLC 只能证明盘中保护价曾被穿过，不能给出精确成交时刻。报告使用账本的退出区间；区间上界是现金可重新使用的结算时刻，不可伪装为实际触发时刻。
