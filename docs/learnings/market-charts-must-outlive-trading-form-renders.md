# 看盘图表的生命周期必须独立于交易表单刷新

- **问题**：交易页每几秒刷新账户，表单交互也会重新渲染；直接把 TradingView iframe 放入同一 innerHTML 会丢失用户周期、指标与缩放。
- **死胡同**：先拆出图表后每次再移动回去也不可靠，iframe 离开 DOM 会重载。另设一套选中周期按钮会与 iframe 内原生周期状态分离，产生两个相互矛盾的选中状态。
- **有效路径**：图表容器保持原位；表单、账户、记录分别刷新，只在币种/主题变化时重建图表。周期和指标统一由 TradingView 原生控件管理。移至图表顶部的币种选择通过 form 属性继续关联下单表单；只读行情轮询不写执行报价账本，切币/离页取消旧请求。
- **通用规则**：接入有内部状态的第三方图表时，先明确挂载/更新/销毁边界和唯一交互状态来源，再改外层布局。
- **牵连**：`yoyo/monitor/static/paper-desk-market.js`、`paper-desk.js`；官方嵌入受 TradingView 网络与币种支持限制，成交报价仍来自独立 OKX 买卖价。
