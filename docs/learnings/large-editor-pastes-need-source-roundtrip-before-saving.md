# 大段编辑器输入先回读源码，再保存

- **问题**：TradingView 桌面 Pine 编辑器约 40 KB 源码粘贴未生效，逐字输入和 AX setValue 又产生缩进、字符异常；屏幕尾部出现代码不代表整个缓冲区正确。
- **无效路径**：继续在桌面重复大段输入只会叠加未保存内容，不能把工具返回成功当作源码完整的证据。
- **有效路径**：在同账号网页 Pine 编辑器通过会话剪贴板粘贴，再全选复制回读。只归一化 CRLF，要求与本地源码逐字一致后才编译保存。桌面用版本历史明确丢弃失败缓冲区，载入已验证云端版本，另外检查实际图表实例的输入组和保存状态。
- **通用规则**：编辑缓冲区、已保存脚本版本、图表挂载实例与布局是四个不同状态。一个保存回执不能证明其余三个都已更新。失败缓冲区不得覆盖已验证云端版本。
- **证据**：本轮 IMACD V2.4 云端第 9 版，`experiments/active/exp-imacd-tv-risk-box-20260908-v1/results/ui-verification.json` 保存本地和网页回读哈希；桌面新输入组和主图框另作 UI 验收。桌面刷新载回旧实例及浅色布局后，重新挂载第 9 版并恢复黑色背景与浅灰坐标。
