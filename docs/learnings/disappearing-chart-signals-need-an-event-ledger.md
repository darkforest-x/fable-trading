# 会消失的历史标记，需要用事件账本还原

- **问题**：2026-09-15 研究 iFVG＋LRL 时，核查到 LuxAlgo 的公开 IFVG 指标说明：当反转区域再次失效，相关区域、线和信号都会被删除。因此最终图表上的历史标记不能代表当时出现过的全部信号。
- **死胡同**：只向左翻图，统计当前仍显示的信号。删除规则改变了可见样本集合，即使显示中的每个形态都画得正确，也可能遗漏当时真实出现、后来失效的信号。此次在文档核查阶段发现问题，未用该错误方法跑实验。
- **有效路径**：把图形显示与研究记录分开；在每个决策时点记录区域创建、首次确认、触发、失效和删除事件及其当时可见输入，已经记录的信号不随图形删除而消失。历史验证需要从原始数据逐步重放该状态过程；执行层精度仍受可用数据粒度约束。
- **通用规则**：复用任何会清理、覆盖或回画标记的指标前，先查其标记生命周期。统计基于不可覆盖的时间事件，而不是最终画布；区域起点、首次可确认时间和可成交时间必须分开。
