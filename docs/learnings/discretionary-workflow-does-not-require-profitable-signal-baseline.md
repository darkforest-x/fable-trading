# 人工交易流程的搭建不以机械信号盈利为前提

- **问题**：Owner 要把 SPIKE 信号变成人工观察、选单、持仓和复盘流程；连续用机械回测亏损回应，把流程建设错当成盈利认证。
- **死胡同**：先证明信号本身赚钱，再允许讨论人工系统。机械基线只能说明无人工判断的结果，不能替代对人工观察流程的设计，也不能证明人工过滤一定有效。
- **有效路径**：先把环境、位置、空间、确认、执行及退出分支写成可事前记录的动作；同时记录做、等、跳过。规则先作为明确的练习约定交付，后续再分别评估选单、执行和退出的增量。
- **通用规则**：先确认用户要的是流程、历史描述还是盈利证据。用户要流程时就完成可用流程；把有效性检验嵌入复盘，不把未证实盈利设为拒绝搭建的前置门槛。
