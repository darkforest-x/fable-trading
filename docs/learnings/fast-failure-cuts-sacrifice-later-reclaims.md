# 插针后过早砍单会砍掉稍后收回的赢单

- **问题**：Owner 嫌 1.618 挂单收回规则等 60 分钟确认太久，想用"5/15 分钟没收回就走，收回了再按 60 分钟管理"来减少等待和亏损。
- **死胡同**：直觉上，早砍亏损单、晚移保本，可以兼得两头。实际在 5.9 万笔山寨币里，5 分钟检查会砍掉约 40% 的单子，其中不少在 60 分钟内会收回并止盈。结果"5 分钟砍单 + 60 分钟保本"的胜率是 19%/20%、每笔 +9/+14bp，比单纯 60 分钟确认的 24%/25%、+25/+20bp 差。在波动最高、急速插针、放量这几组里同样变差。
- **有效路径**：规则 a<b 在 a 分钟确认收盘前完全相同，所以混合规则的逐笔结果可以从两条规则的框架成交里精确拼出：a 没收回就取 a 的结果，否则取 b 的结果。随机对照按同一个对照编号用同样方法拼。这样不用重跑，就能和单一规则同口径比较。
- **通用规则**：要缩短"失败判定"时间时，先统计被提前砍掉的单子在原规则下的结局，再看砍单省下的亏损是否抵得过失去的稍后收回的赢单。插针后的头几分钟噪声很大，失败判定不宜比主要确认周期短。
