# 跳过平仓确认界面仍复用冻结报价与幂等提交

- **问题**：Owner 要求模拟平仓不再弹窗；原逻辑无论开仓确认偏好如何，都强制平仓弹窗。
- **死胡同**：不能从持仓卡片直接另写 POST，把显示数量当成交数量；后台持仓可能已变化，且会绕过现有报价时效和重试保护。
- **有效路径**：仅将平仓的确认决策设为 false，继续从当前比例取得服务器冻结数量，再进入既有直接提交分支。市价与限价均复用相同执行函数，开仓确认偏好独立。
- **通用规则**：减少确认步骤属于交互变更，报价、幂等、重复点击锁与离页取消仍属于执行契约。重点验证报价和提交之间的边界，而非只检查弹窗消失。
- **牵连**：`yoyo/monitor/static/paper-desk.js`、`tests/monitor/frontend_paper_desk.test.cjs`。98 项前端检查通过，覆盖开仓确认开/关下市价/限价平仓、多空及比例、重复点击、离页后丢弃报价、过期/失败报价不提交，以及持仓变化后的原请求重试；正式账户未用于测试交易。
