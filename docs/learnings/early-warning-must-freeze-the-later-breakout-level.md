# 预警后的确认必须对照预警时冻结的边界

- **问题**：把「均线靠拢、线下缓跌、随后破位」做成指标时，形态成立和破位发生属于不同收盘时刻。如果确认阈值每根更新，信号语义会悄悄变动。
- **死胡同**：设计中排除在预警后继续用包含当前根的滚动最低价当破位线。当前收盘不可能严格低于包含自己的最低价；把窗口右移又会让新低拖着阈值走。也不能在破位后把标记回填到此前的整理根。本轮没有据行情比较这些方案的收益。
- **有效路径**：预警收盘冻结包含该根影线的整理区最低价；只允许后续根的收盘严格跌破它。纯状态函数保留 frozenLow，确认/收回均线带/超时/数据断档分别终结等待，终态当根不重新预警。
- **通用规则**：先明确每个状态拥有哪些已经确定的事实，再决定哪些变量可以更新。后续检验的参照物如果代表「当时的结构」，应在当时冻结，而不是随结果变化。
- **牵连**：`yoyo/evaluation/pine/spike_ma_drift_short_v1.pine`；`experiments/active/exp-spike-ma-drift-short-20260914-v1/verify_synthetic.mjs`。本轮为工程实现，合成测试只验证时序与分支，不建立真实行情命中或盈利证据。
