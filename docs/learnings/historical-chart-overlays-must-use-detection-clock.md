# 历史形态的区间线必须跟随形态时钟

- **问题**：巡检弹窗需要周一高低点与双向 1.618，但其短检测窗口往往不含完整周一，查看旧形态时又可能已跨周。
- **死胡同**：检查发现现有 Monday 图表接口只提供当前周；直接拿当前周叠历史快照会错周，从短窗求高低点则会悄悄改变区间定义。两者均未用于实现。
- **有效路径**：服务端从存储的检测框取确认时间，复用 `week_window` / `baseline`，按需通过共享行情缓存读取该周完整 24 根纽约周一小时 K 线。形成中或缺失时不画线。浏览器按币种、检测 ID、确认时间核对响应，关闭/换形态时撤销请求并移除旧线。远端价位用显式“完整区间”缩放，默认保留形态细节。
- **通用规则**：叠加参考线前先确定其事件时钟、数据窗口与可用时间；图表窗口不是指标窗口，当前行情接口也不是历史上下文接口。显示图层不能修改模型输入或通知资格。
- **牵连**：`yoyo/yolo_workbench/chart_levels.py`、`yoyo/monitor/static/yolo-chart-levels.js`、`yolo-detect.js`；后端覆盖历史周/夏令时/缺失，前端覆盖错身份/迟到响应/关闭清理/缩放。未改交易参数或巡检计划。
