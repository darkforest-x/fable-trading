# 轮询更新要保留正在操作的控件身份

- **问题**：账户每五秒重建标题会丢失返回链接焦点；检测切周期重建按钮也把焦点送回 body。保留展开布尔值无法保留键盘位置。
- **死胡同**：只核对画面和展开状态，会误认为用户操作被保留；相同文字的替代节点仍是不同控件。
- **有效路径**：固定账户标题和操作按钮，仅更新数值；必须替换表格、卡片和周期控件时，按订单/信号/周期身份恢复焦点与滚动。检测栏展开状态统一从实际布局推导。
- **通用规则**：刷新前主动聚焦一个可操作元素，跨过真实轮询再核对焦点；纯数据更新不应插入动画或改变用户阅读位置。
- **牵连**：`manual-account.js`、`app.js`、`yolo-detect.js`；订单逻辑、均线和风险参数不变。
