# 懒加载依赖还包括样式组件和跨页入口

- **问题**：市场页表格复用 v130 的滚动容器样式，个人系统入口依靠别的脚本注册点击监听；全站常驻资源掩盖了这两种隐式依赖。
- **死胡同**：只检查全站顺序点过一遍后的画面会漏报，因为前一页加载的样式和监听仍留在文档内。
- **有效路径**：为市场页显式声明 v130 表格样式；跨页入口直接携带子页 URL，不依赖目标模块提前执行。每个页面从新文档独立进入验证，市场页在 320px 下表格局部滚动、整页保持 320px。
- **通用规则**：懒加载验收必须包含独立入口、共享 CSS 与冷启动的跨页链接，不能只检查脚本导入顺序。
- **牵连**：static/module-loader.js、manual.js、trading-playbooks.js、market-sync.css。
