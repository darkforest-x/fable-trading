# 内容输出必须保留知识的证据版本

- **问题**：学习笔记变成跨平台内容后，知识继续更新；若作品只关联最新知识，旧文章的依据和当时的不确定性就会被改写。
- **死胡同**：只加菜单、复制一份文章，或把“整理完成”当成“研究已验证”，都不能保留证据关系。本次没有采用这些路径；不把未实现的自动同步或自动发布列成已接通能力。
- **有效路径**：学习计划、知识条目、内容母稿共享工作区版本账本；内容明确引用知识 ID 与版本，服务端保存该历史版本的观点、证据、边界和来源快照。平台版本分别编辑，实际作品链接与时间由本人登记。Notion 保留正式知识中枢，工作台明确标示本地草稿和人工归档边界。
- **通用规则**：先区分学习进度、知识证据状态和发布状态，再连接记录；表达完成不提升研究或交易资格。查询失败、版本冲突和同步未接通都必须在界面如实显示。
- **牵连**：`yoyo/research_workspace/knowledge.py`、`knowledge_api.py`、`yoyo/monitor/static/knowledge.js`；沿用 `WorkspaceStore` 的追加版本与冲突检查。无外部发布器、无付费模型调用、无训练或交易准入修改。
