# 上级方向门应拦新入场，不能同时吞掉原始反向退出

- **问题**：5m新增15m方向过滤后，拒绝的反向信号仍可能承担“结束旧参考”的职责；若直接提前覆盖原始信号，会意外延长旧仓。
- **死胡同**：在上游确认条件里统一加入均线门，看似所有消费者都一起过滤，却把入场准入与退出证据混在一起。此次没有采用此路径；通过现有消费者审计在改动前排除。
- **有效路径**：先冻结rawSignalSide，原始反向退出继续使用它；新增门仅进入v9EntryAllowed，再生成最终signalSide供新框、标记和入场报警使用。已有框后来配突破沿用原框准入，不暗加第二次持仓方向审查。
- **通用规则**：增加任何“不开这笔”的过滤前，先区分原始事实、新入场许可与旧仓退出三个消费者，再用新旧源码还原对照保证无关路径不变。已完成高周期与EMA预热/缺口语义必须和研究定义分别核对。
- **牵连**：`yoyo/evaluation/pine/spike_burst_v12_4.pine`、`tests/evaluation/test_spike_v12_4_pine_contract.py`；V12.3的15m→1h SMA60保留，V12.4仅加5m→15m EMA120。历史相对排名不等于通过收益验证。
