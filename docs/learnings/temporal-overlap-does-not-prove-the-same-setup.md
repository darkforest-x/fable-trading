# 时间有重叠，不等于模型确认的是同一段蓄势

- **问题**：IMACD 出箭头后等待 YOLO 同方向确认，需要知道检测框是否确实对应原箭头的蓄势结构。
- **死胡同**：只要求检测核心与 `[蓄势起点, 信号 bar]` 至少重合一根，就把所有通过者解释成“原蓄势被视觉模型确认”。这条规则只保证时间区间有交集，不能保证形态身份相同。
- **证据**：固定 54 币、1H／4H 扩大实验共 425 个确认，其中 4 个核心只重叠一根。按时间选出的 ETHFI 1H 空头案例，箭头在 2026-02-05 13:00 UTC 收盘可用，模型到 20:00 才确认；五根核心从信号 bar 延伸至其后第四根，仅信号 bar 与冻结区间重叠。确认窗因果、方向一致和像素可复现都成立，但它仍可能检测的是箭头之后形成的另一段结构。这里没有收益或人工真伪标签，不能据此声称该交易亏损或该检测必然错误。
- **有效路径**：保留原始规则和所有结果，单独审计交集根数、占核心比例、核心右端与箭头的相对位置。将原始模型输入和带框审核副本分开保存，宽上下文图只画到真实确认收盘，不补未来走势。明确指出规则允许什么，不在看过结果后悄悄收紧门槛。
- **通用规则**：事件联结需要分别证明币种／方向一致、确认时钟因果，以及形态身份对应。前两者成立不能替代第三者。后续若检验更严格的原蓄势联结，应另行冻结单一改动并保留原规则对照，不能用本次案例倒推新规则已经有效。
