# Independent targets must not change other positions' matching quotes

- **Problem**: NautilusTrader 1.231.0 delayed 110 of 7,676 fixed-target exits versus independent OHLC replay. A three-short fixture isolated the defect: with entry100, stops101/102/103, target5R and next bar O100 H101 L70 C100, targets90/85 should both fill on that bar; the second waited until the following bar.
- **Dead end**: Single-position stop/target/gap tests passed. Adjusting the replay to the delayed ledger would conceal cross-position coupling rather than validate independent trades. Full-history net profit cannot diagnose this.
- **Effective approach**: Installed `engine.pyx` changes shared bid/ask to the first maker's limit in `determine_limit_price_and_volume`, restoring only after the entire matching iteration. Use its `FillModel.get_orderbook_for_fill_simulation` hook for LIMIT orders only, providing full synthetic liquidity at the order's limit. Native core still determines trigger time and native reduce-only handling cancels siblings. Market and stop orders retain default behavior. No installed framework patch or future data is used.
- **General rule**: Test same-bar multiple positions and order interaction, not only individual fill examples. Preserve independent-trade unlimited-liquidity assumptions explicitly; this is not a capacity or live-fill model.
- **Scope**: `nautilus_independent.py`, `test_range_exit_search.py`; fixed targets only. Existing trail-only results remain reusable after full ledger parity. Initial failed run logs remain preserved. API concept reference: https://nautilustrader.io/docs/latest/concepts/backtesting/fill-models/ ; implementation is pinned to installed1.231.0, whose import paths differ from latest docs.
