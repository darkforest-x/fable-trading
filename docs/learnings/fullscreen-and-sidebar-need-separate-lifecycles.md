# 页面全屏不能复用侧栏折叠状态或重建图表

- **问题**：全站桌面侧栏需要记住收起状态，手机仍是临时抽屉；模拟交易还需要全屏，退出后恢复原布局，并保留图表周期和输入。
- **死胡同**：用同一个 nav-open 标志同时控制桌面和手机，会在切页或 Esc 时错误展开/收起。只设置 CSS 全屏类而不监听浏览器 fullscreenchange，会在用户按 Esc 后留下错误布局；移动或重新渲染 iframe 又会丢失图表状态。
- **有效路径**：桌面折叠独立持久化，手机抽屉随导航关闭。全屏作用于原交易根节点，保持 DOM 原位，监听原生进入/退出；拒绝或不支持原生时提供可退出的视口布局。记录并恢复外部元素 inert 状态，异步请求加版本号，离页后迟到的原生成功不能重新打开全屏。
- **通用规则**：把用户偏好、响应式导航和浏览器控制的显示模式分别建模；验证进入、按钮退出、Esc、断点变化、刷新及异步迟到，而不只验点击一次。
- **牵连**：`workspace-display.js/css`、`app.js`、`paper-desk.js`；原生 API 需要用户点击触发，`fullscreenchange` 才反映浏览器实际状态。测试 `frontend_workspace_display.test.cjs` 覆盖拒绝与迟到场景。
