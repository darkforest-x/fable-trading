# 等待回踩的收益必须按原始机会核算

- **问题**：直接突破入场与等待回踩入场并非同一批已成交交易；只比较后者的成交均值会丢掉等待失败和错过的趋势。
- **死胡同**：复用逐 K2 反向挑最佳 K1 的旧检测器，或先选出成功 K2 再匹配随机对照，都会让未来等待结果改变母样本，无法解释“等一等”到底改善多少。
- **有效路径**：先固定原始 K1 请求与随机母对照，再各自走同样的等待状态机。完全观察到的未入场记零；缺数据和未观察完记未知。保留共同母时限，分别比较等待本身与止损来源，并报告错过的直接入场净盈利。
- **通用规则**：任何带等待、触发或接管条件的策略，先明确最早可知的机会单位，再报告条件成功者；不能反过来。
- **牵连**：V4 PROJECT_PLAN、hourly_impulse_k2_research 的母机会收益与单挂单检查；固定 20bp 成本、72h 母截止；不构成盈利结论。
