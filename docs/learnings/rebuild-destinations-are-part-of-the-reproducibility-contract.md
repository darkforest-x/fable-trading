# 重建目的地也是可复现合同的一部分

- **问题**：语义审核报告给出`--out /tmp/...`作为独立重建命令，但builder在产物生成阶段对输出路径强制调用`relative_to(repo_root)`，长时间模型扫描完成后才失败。
- **死胡同**：只验证默认仓库内输出会让builder测试通过，却没有验证报告里真正交付的隔离重建命令；哈希算法再严格，也弥补不了命令本身无法跑通。
- **有效路径**：lineage路径采用双模式：仓库内产物记录repo-relative路径，仓库外临时重建记录绝对路径；服务端和审计器都用`Path`统一解析。测试必须同时覆盖内外两类目的地。
- **通用规则**：写“从零复现命令”时，必须原样执行一次，包括`--out`、设备和临时目录；输出位置、覆盖策略与清理方式都属于可复现自由度。
- **牵连**：`scripts/build_local_signal_v2_semantic_review.py`、PRE-REVIEW报告的复现命令、外部临时重建与图片路径lineage。
