# Pine 的“已添加到图表”日志不能单独证明指标上图成功

- **问题**：V7 编译日志写着“完成”“已添加到图表”，但免费账户同时弹出指标数量上限，图表工具栏仍只有原来的三个指标。
- **死胡同**：仅按编译日志汇报“已上图”会把编译完成误当成实际显示成功；切换升级弹窗内容也不会解除数量限制。
- **有效路径**：分别核对保存名称、编译结果、图表指标列表。保存和编译通过可以独立交付；列表没有新指标时，明确记录上图未完成，保留用户原图。
- **通用规则**：外部应用每个步骤的回执只证明该步骤；写入、编译、插入与可见渲染要分别核实。
- **牵连**：`yoyo/evaluation/pine/spike_burst_v7.pine`；TradingView Basic 指标数量限制；`docs/spike_v7_bb_channel.md`。
