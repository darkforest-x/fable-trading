# 降噪先排除追高追空，不能先要求当根更猛烈

- **问题**：SPIKE V7 有 132,593 个确认信号，需要减少频繁止损，同时保住策略真正依赖的 10R 以上长趋势。
- **死胡同**：把当前成交量、真实波幅、BB 扩张或三根路径效率设成更高的硬门槛，开发段虽然能删掉 25%–93% 的信号，却会让不同周期只剩 0%–83% 的已实现 10R 交易。强烈的当根动量经常意味着价格已经走远，并不等于更早、更好的趋势入口；按整体 PF 选门槛也会让数量很少的大赢家被普通交易淹没。
- **有效路径**：先把“保留每个周期至少 80% 的已实现 10R 交易”设成硬约束，再比较能删多少信号和 PF。当前唯一通过的简单因果门槛，是确认收盘价离六均线绳索的方向边缘不超过 3 ATR；开发段删除约 12%–14% 的信号，同时保留 92%–95% 的已实现 10R 交易。冻结规则后再打开复用验证段，避免用验证结果挑阈值。
- **验证结果**：冻结后的复用验证段删除 14%–16% 的确认，按原 V7 逐笔保留 91.75%–96.77% 的已实现 10R 交易，三个周期的平均收盘回撤都下降；但 30m PF 变差，1H/4H 的 PF 小幅改善也没有转化为显著的同资产 V8−V7 收益差。因此它只能叫追高/追空降噪门，不能叫收益升级。月度结果大幅翻转又说明，下一条独立变量应是因果市场状态，而不是继续加严单根量价。
- **通用规则**：趋势策略做降噪时，第一步同时报告信号删减率、亏损删减率和大趋势保留率，并按周期设尾部保留约束；优先过滤入场位置已经过远的信号。只有在尾部保留约束通过后，才比较平均收益、PF 与回撤。
- **牵连**：`yoyo/evaluation/spike_v8_noise_study.py`、`yoyo/evaluation/spike_v8_replay.py`、`yoyo/evaluation/pine/spike_burst_v8.pine`、`experiments/active/exp-spike-v8-noise-filter-20260913-v1/selected_rule.json`；3 ATR 是本轮开发段冻结值，不能自动推广到生产监控或改作新的 ACTIVE 配置。
