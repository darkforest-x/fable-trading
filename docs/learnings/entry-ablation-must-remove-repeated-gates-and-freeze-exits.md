# 入场规则拆解须移除重复约束，同时固定退出定义

- **问题**：V13.1量能、推进幅度和IMACD同时参与旧确认与结构确认；原始反向检测又用于退出。删除一个布尔条件并不等于移除了该规则。
- **死胡同**：只把最终信号表过滤条件关掉，较早的同名门仍会拒绝机会；直接替换全局检测器，则反向退出也随之变化，无法把收益差归因于入场。
- **有效路径**：先映射同一规则的全部入场使用点，按明确规则组移除；原版raw opposite固定用于取消与退出。每个变体重建有状态锚点，再对机会并集重放各自占仓；完整版必须与原档案逐项对齐。
- **通用规则**：消融前先说明移除的是语义规则、某一次使用，还是整套检测器；有状态逻辑的放宽不保证原机会集合被保留。
- **牵连**：`yoyo/evaluation/spike_v131_rule_facts.py`、`spike_v131_rule_study.py`及`experiments/active/exp-spike-v131-rule-state-20261019-v1/PROJECT_PLAN.md`。本研究只识别入场边际贡献，不授权生产替换。
