# 滚动窗口的首个同色序列不能直接当作从1开始

- **问题**：同色大菱形的全局第7个退出，需要知道序列的真实起点。监控只持有有限行情，窗口左缘看到的第一个空头菱形可能已是第6个。
- **死胡同**：在每次入场或每个滚动窗口开始时置零，会把同一个市场事件重新编号；“只数大菱形”并不能消除这个边界错误。
- **有效路径**：指标区域开始或缺口后，首色的计数保持未知；观察到异色大菱形才确认新序列的第1个。同色大菱形递增，小菱形、圆点及无事件bar不改计数，入场不清零。界面明确显示未知，不捏造第7个。
- **通用规则**：基于连续事件次数的决策必须证明计数起点可见。完整起点不可见时，保留未知状态；若产品要求跨任意长缺失区间仍连续计数，需要另建可验证的持久化指标状态。
- **牵连**：`yoyo/evaluation/spike_joint_rsi_exit.py`、`tests/evaluation/test_spike_joint_rsi_exit.py`；当前监控保持1500根尾窗，不追加扫描或把事件退出宣传为回吐上限。
