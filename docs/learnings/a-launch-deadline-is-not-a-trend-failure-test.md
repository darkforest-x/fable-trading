# 启动缓慢不等于趋势失败，少亏不能单独证明早退有效

- **问题**：V11 给原 251 笔交易增加“60min 内完整 5m 收盘从未达到 0.5 初始 R 则退出”，平均净收益改善约 0.85bp，却仍为 −13.45bp，PF 从 0.625 降到 0.601。
- **死胡同**：只看 127 次早退平均少亏 1.69bp，会忽略右尾被截断：15 笔原赢单变亏，只有 4 笔原亏单变赢。全体平均的改善也不能代表有完整对照的 154 笔；后者平均反而恶化 1.33bp。
- **有效路径**：固定全部旧机会，拆解逐笔盈亏迁移、匹配与未匹配分层以及四个时间段，再看净收益和同组对照变化。四段仍全部亏损，改善区间跨零，因此拒绝这版，而不是根据少数被砍赢家事后调出“最佳”时限或阈值。
- **通用规则**：退出规则必须同时评估减损与截断盈利的代价。价格尚未取得进展与入场结构已经失效是不同假设；未来若研究后者，应单独冻结可因果计算的定义，不能用最终赢家或持仓后最大浮盈筛选入口。
