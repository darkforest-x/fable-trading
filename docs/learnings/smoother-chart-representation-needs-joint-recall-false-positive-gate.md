# 更平滑的图表表示必须同时通过召回与误触联合门

- **问题**：HL2 六均线在冻结 val 上让最早窗事件召回从 `81.29%` 升至 `87.10%`，视觉上像是“更平滑、更好认”；但负样本误触也从 `41/3600` 升至 `51/3600`，而且最早窗与 post2 两个正例主指标经 Holm 校正后都未达到 `p<0.05`。
- **死胡同**：只看 mAP、只看一个未经多重校正的 `p≈0.049`，或在看到结果后强调更好看的 secondary 指标。这样会把训练波动、同族指标重复检验和更激进的开火倾向误写成表示改进。
- **有效路径**：训练前固定三项主表面——最早窗事件召回、post2 事件召回、空标签负样本开火率；对正例主指标与误触一起做 Holm 校正和事件级区块不确定性估计。只有至少一个正例主表面显著改善，并且观察到的负样本误触不增加，才允许称为“已证明改进”。
- **通用规则**：平滑度、颜色、线宽、价格源等视觉表示实验，都必须把“更容易检出”和“是否只是更容易开火”放在同一预注册联合门里。召回上升是线索，不是单独的通过证据；mAP 不能覆盖固定阈值下的误触门。
- **牵连**：本轮结论只能是“HL2 有正例召回改善迹象，但未证明优于 close”。下一步若复验，必须保持单变量、增加独立训练 seed，并继续使用同一联合门；不得据此 promote、部署或调阈值补救。
