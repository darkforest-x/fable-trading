# 全景图有根数上限时必须说明账本退出是否仍在图内

- **问题**：大趋势可能持有很久，固定72根后续图无法展示真实退出；图上写完整净R却没有显示退出，容易让人误以为图内涨幅就是兑现收益。
- **死胡同**：一律拉到72根、或用MFE代替退出收益；过多K线强行压到一张图也会使结构无法辨认。
- **有效路径**：由冻结账本验证入场价、时钟和净收益，再给100根前文，后续尽量包含实际退出+12根。超过500根明确标注截断、退出是否在图外；原始事件的完整净R与可见行情分开说明。
- **通用规则**：画图窗口是展示合同，不能悄悄改写交易合同。事后最好/最差/中位选例要显式说明，不能拿成功图数量估算胜率。
