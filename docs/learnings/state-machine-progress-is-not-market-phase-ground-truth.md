# 状态机已经走到哪一步，不等于市场仍在哪个阶段

- **问题**：固定均线循环在COMP案例上能画出合理的压缩、启动和扩散，但能否据此把全部状态当作真实行情阶段？
- **死胡同**：只查看漂亮案例与汇总收益。CORE的空头盈利例子揭示：短暂触发收拢后，价格继续下跌、均线再次扩散，状态却持续143根“重新收拢”。程序没有报错，收益分组也能算完；错在把“曾触发门、正在等下一条件”解释为“市场现在确实盘整”。
- **有效路径**：独立审查状态的每条出边与每一种恢复过程，先用逐根轨迹和反例验证语义，再评价收益。保留原固定实验，不根据看到的盈利路径临时改转移，明确紫色只是收拢后锁定等待状态。
- **通用规则**：区分事件记忆、持久流程状态与市场事实标签。状态图缺少回退、恢复或失效分支时，要报告不可分类/锁定原因，不能用一个好听的行情名字掩盖；尚无逐段金标就不报阶段识别准确率。
