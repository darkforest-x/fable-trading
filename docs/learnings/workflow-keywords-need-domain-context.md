# 工作流关键字必须结合语义上下文

- **问题**：YOLO 目录以独立的 `gold` 关键字识别金标研究，误把 XAUUSD 黄金突破策略纳入样本工作流。
- **死胡同**：单纯压缩卡片和翻译标题只能让误分类更容易看见，不能纠正目录归属。英文同词并不等于同一研究对象。
- **有效路径**：显式工作流与 YOLO 标识继续直接匹配；仅靠 `gold` 命中的记录须同时具有标注、标签、审核、训练等上下文。以黄金商品反例与历史金标审核正例做回归检查。
- **通用规则**：用关键字构建研究目录时，先核对歧义词和实际列表；导航分类不能作为研究阶段通过的证据。
- **牵连**：`yoyo/research_workspace/yolo.py`、`tests/research_workspace/test_yolo.py`。不改实验原文、资格或结果。
