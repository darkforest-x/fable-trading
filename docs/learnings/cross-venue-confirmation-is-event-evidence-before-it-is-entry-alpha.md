# 跨交易所确认先证明同一事件，再证明入场优势

- **问题**：一个交易所先出现 SPIKE，其他交易所随后确认，看起来可以过滤单所噪音并形成更强入场信号。
- **死胡同**：把同根多所信号数量直接当独立票数，或用 leader 原始入场的后续收益证明等待 follower 后仍可获利。前者重复计算同一底层行情，后者没有模拟等待后的成交价格。
- **有效路径**：按基础资产、周期和方向，以收盘可用时间折叠一根周期内的跨所确认；保留 leader、follower 和确认延迟。两年全样本约 24% 的源确认属于重复事件，约 87% 的多所事件同根确认，适合前端去重和组合暴露管理；各周期方向的匹配差值反复变号，不能证明统一入场优势。
- **通用规则**：跨所证据分三层验收：先因果折叠事件，再验证连续市场覆盖，最后以 follower 出现后的可成交价单独回放。没有第三层时，只能用于事件去重、置信标签或影子研究。
- **牵连**：`yoyo/evaluation/spike_cross_venue_event_study.py`、`experiments/active/exp-spike-cross-venue-events-20260913-v1/results/`；不改变通知、入场或执行规则。
