# Recovering intermediate messages can invalidate the assumed fill price

- **问题**：A partial trading archive connected a limit plan to a later profitable exit. The intended limit was used for illustrative R arithmetic, while attachments existed only as counts.
- **死胡同**：Treating an attachment count as a missing image and treating the latest quoted plan as immutable order history both overstate the evidence. The live channel showed that some counts were reply previews, and that the limit had been cancelled before a market entry.
- **有效路径**：Reopen exact message IDs in the authorized channel, preserve rendered UTC times and neighboring decisions, then bind each attachment to its owning message. Keep initial text, corrected text, chart tool values, reported fills, and unknown execution details separate. The recovered market entry invalidated the old limit-price reconciliation; it did not provide a replacement execution price.
- **通用规则**：Before calculating realized R, establish the order-state chain and position scope. On replay sequence changes, restart an index-based cursor with an explicit notice while retaining saved answers and drafts. Retrieved current attachments are not certified historical versions without edit history.
- **身份归并**：Normalize legacy bare message IDs and prefixed archive IDs to the same platform snowflake before enrichment. Browser search caught five duplicated records caused by comparing archive wrappers; all 42 recovered nodes already existed in the text archive. Recovery adds provenance, attachments, and case context, not five new messages.
