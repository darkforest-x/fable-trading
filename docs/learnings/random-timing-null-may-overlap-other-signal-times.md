# 无条件随机择时对照允许抽到其他真实信号时点

- **问题**：回归策略审查发现少量随机控制恰好落在其他真实交易的入场bar，最初被误判为对照污染。
- **死胡同**：排除所有真实信号时点会把原定“可交易时点的均匀抽样”改成“没有策略信号的时点”，主动改变所估计的对照分布；交集本身不是非随机性的证据。
- **有效路径**：回到预注册估计对象。对照匹配币、方向、纽约年月/小时、因果波动桶、阶段与风险比例；仅排除当前parent自己的入场，其他时间保持等概率抽样。保留重复控制时间与聚类依赖的披露。审查者复核后撤回major finding，交易与结果无需更改。
- **通用规则**：评审随机对照先问零假设究竟是什么；只修违背预定抽样机制的问题，不能凭“看起来污染”在观察结果后替换对照总体。
