# 入场择时的浮亏改善必须同时核对价格幅度和原始机会

- **问题**：Stoch／WVF等待会改变成交价格、止损距离和成交集合，单看成交后的平均MAE/R不能区分真实价格改善、风险单位变化和大量弃单。
- **死胡同**：未采用只保留双方最后成交样本、只比较MAE/R再声称策略改善的办法；它会排除等待失效和漏掉的行情，并混入实际入场R分母变化。
- **有效路径**：固定原始机会、原绝对止损和退出，各策略独立重放占仓；保留已知零成交并区分未知截断。MAE同时记录实际入场R、原锚点R和价格bp，双方成交差值明确为条件描述，另报全部机会净R、成交覆盖、持仓暴露及漏掉的大赢家。止损当根MFE保留上下界。
- **通用规则**：测试更耐心的入场时，先定义“没等到”的结果和风险单位，再看成交后的漂亮曲线。
