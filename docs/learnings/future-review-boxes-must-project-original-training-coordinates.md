# 未来审核图必须投影原训练标签框

- **问题**：Owner 要看带后续走势的正负样本，并确认正例实际训练框的位置。增加未来 K 线后横轴密度与纵轴范围都会变化，原 YOLO 归一化坐标不能直接贴到扩展图上。
- **死胡同**：复用同一组归一化坐标、按核心重新计算矩形或肉眼重框，都不能证明显示的是原训练标签。本轮还发现旧 B1/B2 负例清单没有核心起点和长度；不能凭文件名推断缺失几何。
- **有效路径**：先读实际训练 TXT，将像素矩形经原训练 ChartTransform 反解为小数 bar 和价格坐标，再投影到扩展图。逐样本重绘原训练 PNG 并核对 SHA，缺失字段只从绑定 SHA 的父事件清单联结且验证事件身份。20 张审核图独立保存，正例画原框，负例保持无框，训练截止以蓝虚线标出。未来价格扰动测试确认审核图会变而原训练图与标签不变。
- **通用规则**：审核展示应保留标签身份与输入时钟。未来扩图只增加人工可见上下文，不能默默重定义标签、改变训练输入或把未来行情用于原图缩放。
- **牵连**：`yoyo/datasets/ma_morphology_future_review.py`、`tests/test_ma_morphology_future_review.py`、`exp-ma-morphology-v6-threeview-20260925-v1/review_future20_v2/review_manifest.json`。抽样展示不等于逐样本金标认可，也不构成训练或上线资格。
