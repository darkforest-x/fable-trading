# 按收益分组选案例，本身就已经泄露未来结果

- **问题**：将既有 3R/5R/10R 和亏损账本接入视觉回放时，隐藏净 R 数值仍不足以保证人工判断独立：用户已经知道所选组是赢家或亏损。
- **死胡同**：只在当前会话记录“揭晓过结果”，再允许从全部列表重开盲审，会把同一行情重新包装成未见样本。同一交易所事件在不同策略家族里重复出现，也不能重新获得独立性。
- **有效路径**：按交易所、币种、周期、信号收盘和方向记录持久暴露；浏览结果分组、揭晓账本和推进到未来都登记。冻结与实际提交判断时分别核对，避免冻结后从别页看结果。揭晓之前已经保存的判断保留原始独立性；之后的新判断标记为学习。账本净 R 和确认浮盈分开，未结束记录不归亏损。
- **通用规则**：先列出所有能让人或模型推断结果的界面动作，再定义盲审资格；数值隐藏和刷新页面不等于消除知识。系统只能记录自身可观察的暴露，不能证明用户从未在别处见过行情。
- **牵连**：`yoyo/vision_research/replay.py`、`replay_cases.py`、`static/replay.js`、`tests/vision_research/test_replay_cases.py`。既有账本结果不自动成为形态金标；训练与生产资格仍为 false。
