# 静态跨币位置同向可能错杀新转向赢家，减亏不等于入场质量改善

- **问题**：ChartPrime rank50 的四币均值方向门，把固定 BTC 小时直接 K1 的251个机会减到96个，全机会均净从−16.7690改善到−8.1576bp，看起来像“共振有效”。
- **死胡同**：只看少交易后的总亏损缩小，会忽略原55个赢家被挡掉42个，而196个亏单还留下83个。获准交易每笔均净反而降到−21.3286bp；随机对照同样通过减少出手减亏，154匹配组的额外增量I仅+1.1819bp、95%区间跨零。rank50衡量当前价格相对过去50根的位置，不是资金流或当前转向速度；均值方向也不等于多数资产投票。
- **有效路径**：固定全部251机会、462自身随机对照、154组及97个未知I；分开计算每笔、全机会、单仓和匹配增量，逐笔核对赢家/亏单保留率。由这些证据拒绝当前规则，而不是提高“共振”严格程度或把被拒绝组倒过来直接交易。被拒绝组自身平均仍亏。
- **通用规则**：评估过滤门先检查“过滤后是否更有质量”，再检查“是否只是减少风险暴露”。对穿越启动入口，另行区分外部市场的位置与变化；本轮支持静态门不适用这一配置，不证明变化门有效，也不证明一般性的因果机制。
