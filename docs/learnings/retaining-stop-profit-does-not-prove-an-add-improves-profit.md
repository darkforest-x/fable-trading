# 整仓止损利润不下降，不等于这次加仓值得做

- **问题**：连续加仓要求整仓共同止损净利润至少保留此前承诺，为什么多加几次仍可能少赚？
- **死胡同**：把“加完以后整体仍赚”当成“新增这笔提高收益”。高位新增仓位可能在较低止损退出，由旧仓浮盈补贴亏损；整体为正掩盖了增量为负。
- **有效路径**：让0次、2次、不限版本共享市场结构时钟和最终退出，直接比较新增腿的增量。固定29币研究后段4笔超过两次，1笔改善、3笔恶化；连续相对两次合计+1.6666R但月度p=0.5。WIF历史一笔同价退出时，加两次赚3.553665U，加四次只赚1.885009U，四次版止损净利润仍为正。
- **通用规则**：风险约束只证明某场景可承受；收益价值要由相同入退场下的反事实对照证明。分别报告整体盈亏与每次新增仓位的增量，不能拿盈利余额作为加仓有效性的证据。
