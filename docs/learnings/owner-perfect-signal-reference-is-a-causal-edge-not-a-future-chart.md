# Owner perfect-signal reference is a causal edge, not a future chart

- **问题**：Owner 用 2026-08-10 ETHUSDT.P 15m 全走势截图指出最终目标。截图在箭头右侧展示了完整瀑布，如果直接把整张图理解为正例，模型只能学习已经发生的下跌，无法在盘口识别启动。
- **死胡同**：把“后来跌得很大”当成 YOLO 输入语义、把大阴线本身框成信号，或用截图中的未来走势反推当前阈值，都会把结果证据混入决策时点并制造前视。
- **有效路径**：将 owner 箭头视为因果右边界：目标是均线密集完成、反抽或贴线受压、短均线刚向下张口而主跌尚未完成的 break-frontier；箭头后的下跌只证明 owner 为什么认定它完美，不进入训练图、实时图或特征。
- **通用规则**：任何带后续行情的 owner 示意图都要分成“决策时可见部分”和“事后结果部分”。检测目标由前者定义，后者只能用于人工语义说明或独立标签，不得成为模型输入。
- **牵连**：Local Signal V2 Stage B 的因果裁剪右边界、正例审核口径、未来真 tip 金标说明，以及所有把 owner 截图转成训练样本的工具。
