# 提高胜率必须同时核对兑现尾部与账户收益量纲

- **问题**：Owner 从“两万元、每单账户盈利200%”提出100%胜率目标，随后明确优先提高扣费后的盈利胜率，同时保留大盈利机会。普通赚钱概率、最终兑现5R/10R概率和账户翻倍概率不是同一个标签。
- **死胡同**：既有实验把全部退出改为毛2R全平，多头全期胜率31.42%升至34.28%，净R却从−9.61降至−90.78，原38笔净>5R和9笔净>10R全部消失。旧5R分类模型也没有通过验收。提高胜率、缩小目标或换模型都不能单独证明交易优势。
- **有效路径**：先核对具体版本、信号时间、实际可成交时间与R分母，再固定原退出做入场质量研究。以扣费净收益>0为主标签；对同一事件集合核对原>5R/>10R赢家的保留、误删和新增，并同时报告净期望、匹配随机超额和时间稳定性。SPIKE V12.6的V9参考框可能早于联合提示，必须分账。
- **通用规则**：先问清“赢”的分母和决策时点。对线性产品，在单笔、固定初始风险且成本口径一致的简化条件下，账户收益约等于账户初始风险占比×已实现净R；10R不自动等于账户+200%。筛选增加胜率但切断尾部时，仍可能更亏。
