# 检测框映射必须实测小数 K 线坐标

- **问题**：全局 K 线已显示，结果列表有真实检出，模型原图也有框，但交互图上框消失。
- **死胡同**：先怀疑绘制生命周期与图表内部表格的 CSS 污染。收窄 CSS 后仍无框；实际 draw 已执行三次，纵坐标正常，两个横坐标都是 0。不能把无控制台错误或模型原图有框当成全局图绘制成功。
- **有效路径**：在本机内置 Lightweight Charts 4.2.0 上直接测量：logicalToCoordinate(100) 返回 494.321，logicalToCoordinate(100.5) 返回 0。先转换相邻整数 K 线中心，再按小数比例插值；保留模型的亚 K 线边界，不四舍五入重画框。实图点击、原始框筛选、缩放及 PNG 导出都验收，补回归测试。
- **通用规则**：外部图表 API 的坐标契约要在实际捆绑版本验证。模型像素框→时间/价格→图表像素三个环节分别检查，时间轴与详情使用一致的时区。
- **牵连**：`yoyo/monitor/static/yolo-detect.js`、`tests/monitor/frontend_yolo_detect.test.cjs`；原始 xywh 与输入像素校验保存在独立观察记录中。
