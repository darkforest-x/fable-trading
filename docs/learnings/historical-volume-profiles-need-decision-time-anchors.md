# 历史成交量分布必须按当时的时间边界重算

- **问题**：2026-09-26 分析 Flight 三策略转述图时，成交量分布被用于解释历史突破。整屏 VPVR 可能包含决策之后的成交，不能直接证明当时存在相同的 POC、高成交区或低成交区。本次只识别方法风险，没有原始计算区间，不能断言该图已经发生泄漏。
- **死胡同**：只看历史 K 线与右侧分布是否吻合，或把工具换成 Fixed Range 就当成完成因果化。固定区间仍可能选到未来右端；完整历史的高低价还可能决定分箱边界，影响过去的分布。
- **有效路径**：核对 TradingView 官方定义：VRVP 按可见区间计算，分箱可由区间价格跨度决定。由此推导，每个决策时点必须分别约束区间右端、左端选择规则、价格分箱和底层数据；不能把最终图上的分布回填到过去。
- **通用规则**：先冻结决策时点 t，只用截至 t 已可获得的数据生成分布。左端锚点需事先可知；分箱不得由未来极值定义。保存交易所、现货/合约、量单位、底层周期、区间和行数。追加或扰动 t 之后的数据，t 时点特征应保持不变；此检查尚未在本次运行。
- **牵连**：这是一条方法审计结论，不是收益验证，不改变任何交易参数、训练资格或生产资格。原资料：https://x.com/LabSpeculation/status/2103279274056978833 。官方依据：https://www.tradingview.com/support/solutions/43000703076-visible-range-volume-profile/ 。
