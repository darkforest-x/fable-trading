# 账户远程可见性与实盘执行权限必须分开

- **问题**：Owner 要求 OKX 实盘面板不再限定本机。现有免登录公网入口被账户接口的 loopback 与代理标记检查拒绝，页面只能显示本机限定提示。
- **死胡同**：只删除前端提示不会改变接口403；反过来，开放只读账户信息也不需要扩展凭据输出、增加交易接口或启用执行进程。原“公网禁止展示”的决定被此次 Owner 明确请求覆盖。
- **有效路径**：移除账户展示层的来源IP/代理标记门，沿用既有公网入口；保留同源浏览器检查、统一字段白名单、GET缓存与no-store响应。非本机/公网代理场景测试200，外域请求仍拒绝，POST仍405，凭据和账户ID不输出。部署后直接经过真实公网入口核验显示。
- **通用规则**：访问范围、返回字段、交易权限是三个独立边界；按 Owner 指定的范围修改对应一层，并说明免登录链接的持有者能看到哪些数据，不能把只读权限变更当成执行授权。
- **牵连**：`yoyo/okx_execution/dashboard.py`、`yoyo/monitor/static/okx-execution.js`；现有公网网关免登录，不新增身份验证。此前本机限定记录是历史事实，当前口径以本次请求为准。
