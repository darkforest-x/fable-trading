# 资格比较精确，不代表盈亏分类也精确

- **问题**：V17快反转全平把开盘毛利恰好20bp归入未超过成本的分支，但100→100.2的传统float价格比减1再扣.002，会得到约+1.7e−18；按net>0统计就把打平误当赢家。
- **死胡同**：只给资格门使用Decimal，或仅在测试中approx净0，仍会漏掉下游严格正收益分类。改全仓历史会计又会破坏旧版本可复现性。
- **有效路径**：独立账本审查与执行器复核同时检查门与成交；仅对新全平分支使用Decimal方向乘报价差除入价，再转float扣同一成本。多空精确边界、紧邻边界及30bp成本压力都测，精确20bp在20bp成本下要求严格net==0；OFF继续保持V16全字段parity。
- **通用规则**：凡是规则边界与胜负门共享一个经济值，既测试是否成交，也测试该成交如何被计入盈亏分组。容差断言不能替代严格分类反例；新数值语义应局部限定，避免偷偷改旧账本。
- **牵连**：`yoyo/layers/l3_backtest/hourly_impulse.py`的新`_failed_launch_gross`、`tests/test_hourly_impulse_failed_launch.py`、V17独立保存验证器。20bp成本与分流门未改变；不说明新策略可盈利。
