# 信号共振必须按确认时间对齐，不能只对齐回标图案

- **问题**：Owner要求关键位信号与多周期观察模块同时出现才入场。两个模块共享15m勾叉，但关键位可能在勾叉后两根才触价，真实入场确认时间因此不同。
- **死胡同**：只检查勾叉当时符合小时方向，就会把先出现的多周期信号冒充当前同时新触发；只看过滤后胜率，则会忽略被删除的大盈利单和更换出场造成的影响。
- **有效路径**：分别保存原勾叉、触价、实际入场及最近已确认H1观察时间。主口径在原入场收盘严格相交，保持原出场；截图止损/跟踪另作完整对照。BTC原胜率26.7%升到41.4%，但10月1日24.28R盈利单因晚两根触价被排除，近期净R转负；截图管理下两币交集胜率反而下降。
- **通用规则**：先定义“同时”是同根新事件、既有状态仍有效，还是有限配对窗口。对齐真实可执行时点并说明共享的底层信号；筛选与风险管理分开归因，胜率和净收益一起看。
