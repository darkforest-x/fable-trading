# 参考点位图不能依赖订单通过资金检查

- **问题**：手动开仓预览因保证金不足被拒后，界面同时隐藏了已知的入场、止损、止盈和 K 线，Owner 无法看图理解拒绝原因。
- **死胡同**：只在成功 draft 上挂图表，或只把资金报错写得更详细，都没有解决失败时无法核对点位的问题；用第二次行情解释第一次拒绝也可能错配价格。
- **有效路径**：公共行情参考与账户资格并行读取，参考数据明确 display_only，既无订单身份也无数量，不能确认。失败回执携带该次计算的准确三价，并优先于独立公共报价显示。K 线在没有点位时仍可渲染，穿过止损时保留真实价格、不伪造止盈框。编辑、关闭和切换标的废弃旧结果；过期只更新展示，不延长确认期限。
- **通用规则**：先分清“用户需要看到的事实”和“系统允许提交的动作”。拒绝动作不等于拒绝展示事实；展示状态与执行状态分别建模，并验证异步先后顺序。
- **牵连**：manual.py / manual_chart.py / manual_api.py、manual-live.js / manual-position-chart.js，以及 Python 只读路由与前端竞态测试。两账户隔离、3% 风险、最大有效杠杆、已收盘 5m 止损、3R/5R 与逐单人工确认保持；本轮未提交真实订单。公共行情仍受网络和共享限速影响，不能把并行渲染宣传为固定秒数到达。
