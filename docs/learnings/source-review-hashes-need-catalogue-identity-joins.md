# 源码与审查哈希一致，还必须对上独立冻结的发布身份

- **问题**：ChartPrime审查校验器最初只让review与来源卡片/Pine互相比对，整体错换开闭源身份仍可能自洽。
- **死胡同**：只核134/14数量及源码SHA，不验证卡片权限和脚本ID/版本来自哪一条目录；两项整套交换后总数与内部哈希都能保持正确。
- **有效路径**：独立冻结完整目录字节SHA，将每个发布ID的access、script_id_part、version、预期公开URL逐项联结，再验证原始源码字节与审查引用。
- **通用规则**：哈希只证明拿到同一份内容，不证明内容属于正确对象；校验链必须接到独立的身份/权限契约，不能只让同一组可变产物互证。
- **牵连**：exp-chartprime-public-confluence-audit-20260906-v1/build_report.py 与负例测试；闭源不请求源码，错误身份不能因计数不变而通过。
