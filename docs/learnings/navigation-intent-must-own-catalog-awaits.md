# Navigation intent must own catalog awaits

- **问题**：均线密集首次结果目录尚未返回时连续切周期，先发操作可能晚到，继续清空或重载后选周期；进入尚未检测周期还遗留旧图表的加载和形态状态。
- **死胡同**：只在最终行情响应处检查币种和周期太晚，旧导航在发出行情请求之前已经修改了页面状态。
- **有效路径**：从用户选择开始生成版本，目录 await 后同时核对版本、币种、周期和当前子页；无检测结果时清空旧形态选择和加载标志。异步切币完成后，只在仍属当前选择时恢复键盘焦点。
- **通用规则**：导航版本覆盖整条异步链，包括前置目录查找；用逆序返回测试证明旧操作无权修改新选择。
- **牵连**：`yolo-detect.js`、`frontend_yolo_detect.test.cjs`；仅浏览已保存检测与行情，不运行新检测或订单预览。
