# 退出保护必须服从 K 线事件时钟

- **问题**：给 MA Shift/Stoch 增加保本、分批止盈和跟踪止损时，只有5分钟OHLC，却需要模拟开盘与盘中成交顺序。
- **死胡同**：若看到当根最高价达到保本条件，就把该根最低价按新止损成交，会使用价格先后顺序未知的信息；只改原逐笔退出价也会忽略提前退出释放的后续入场机会。这两条捷径在设计中被排除，未作为真实实验运行。
- **有效路径**：先处理开盘已生效保护和前收盘退出，随后入场与盘中保护，最后收盘更新保本或跟踪，更新从下一根生效。同根止损和目标都触发时止损先。重新串行回放固定候选入场流；合成场景核对跳空、份额和成本，再用原引擎做baseline逐笔一致性验证。
- **通用规则**：每一个保护价格都必须带“何时能被知道”和“何时开始可成交”的时间；只有OHLC时不能借未来最高/最低点给自己选择有利路径。
- **牵连**：`yoyo/evaluation/ma_stoch_exit_engine.py`、`tests/test_ma_stoch_exit_engine.py`、`experiments/active/exp-ma-stoch-exit-optimization-20260915-v1/PROJECT_PLAN.md`。成本固定20bp，原始入场不变，研究不接实盘。
