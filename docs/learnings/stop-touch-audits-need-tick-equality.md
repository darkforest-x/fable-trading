# 止损触价核对必须按交易所 tick 判断相等

- **问题**：两小时浮盈研究中，BTC 一笔原生框架止损比旧浮盈工具早一根；止损 79298.20000000001，实际最高价 79298.2，仅差约 1.46e-11。
- **死胡同**：用原始浮点数 `high >= stop` 作为框架裁判，会把同一个合法 tick 判断为没有触及，错误延长浮盈窗口。
- **有效路径**：独立核对使用 tick 尺度的舍入误差容差，同时保留跳空成交与连续触价的区别。框架成交和已生成原始文件不改、不重跑；修复核对后复用并重新验证。
- **通用规则**：交易价格有离散网格。原生成交、止损判定和研究窗口结束位置必须共享 tick 相等语义；统计误差不能反向修改正确成交。
- **牵连**：`yoyo/evaluation/range_v237_2h_scaleout.py`、`tests/evaluation/test_range_v237_2h_scaleout.py`。历史浮盈工具的精确浮点比较保留原状，新的两小时研究使用修复后的独立核对。
