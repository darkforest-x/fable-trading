# 固定时钟标签不能继承旧退出的观察截止

- **问题**：要区分入口缺乏持续性与出场太早，旧持仓内 MFE 或退出收益却会随着退出政策改变观察范围。
- **死胡同**：只看盈利单，或把旧止损后没有记录的价格当作没有趋势，都会按未来或旧策略选择样本。四个观察时钟也不能将 251 个入口变成 1004 个独立样本。
- **有效路径**：固定母身份与入口时刻，单独读取 OPEN，在原分段内观察 1/4/12/24h，4h 预定为主。完整 [入口,端点] 五分钟网格缺失则未知，不用邻近价或旧退出填补。
- **通用规则**：观察标签、因果入口特征和可执行交易收益是三种对象。先隔离旧路径，再解释固定时钟结果；扣 20bp 的 markout 不是执行 K1 止损后的收益。
- **牵连**：`yoyo/evaluation/hourly_impulse_fixed_clock.py`、未来 V24 runner；runner 另管原母身份、pre-2025 原始价格截止与 72h 分段禁入，不让纯标签模块冒充完整研究守门器。
