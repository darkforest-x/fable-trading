# 跨周期 YOLO 框不能继承原周期的业务语义

- **问题**：15m 训练的“均线密集启动”YOLO 原样扫 4h 后产生 221 个结构候选，但人工图上出现 K 线远离长均线、六均线明显发散的框。对 219 个可完整复算事件套回原训练形态合同，138 个（63.0%）至少违反一项密集门，只有 5 个（2.3%）同时通过形态门与 Owner-50 距离门。
- **死胡同**：把 `confidence`、框宽映射为 core4/5、post2–9 或输入像素哈希一致当成形态正确。它们分别证明模型确实出框、横向几何合法和产物可复现，都不证明六均线密集或价格贴近均线；提高置信度也不能把 15m 像素相似度变成 4h 语义精度。
- **有效路径**：先对可疑样本做输入像素与原框 parity，排除渲染/投影错误；再逐项复算训练时的均线包络、末端散度和参考族距离。ENS SHORT #218 的包络为 4.21 ATR（训练上限 1.50）、末端散度 3.81 ATR（上限 1.10）、参考族距离 1.895（上限 0.50），因此可确认是几何后处理放行的语义误报。
- **通用规则**：任何检测器跨 timeframe 使用时，输出默认只能叫 proposal；要升级为目标形态，必须有目标周期 Gold 或在未见数据上预注册并验证的目标周期语义门。已消费 holdout 上的复算只能诊断病因，不能据此调门后重新包装成独立验证。
- **牵连**：`scripts/scan_4h_ma_launch_yolo_latest.py` 仅用 `cx/width` 验 core/post，`cy/height` 只保存不参与语义验收；`analysis/output/ma_launch_4h_yolo_halfmonth_20260901_v1/`；15m checkpoint 的 holdout 使用 #6；延续 [几何后处理不能保留训练语义](geometry-only-postfilter-does-not-preserve-training-semantics.md)。
