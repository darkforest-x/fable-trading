# 更改退出必须重放再入场与剩余仓位估值

- **问题**：比较 0.95R/1R 保本、部分止盈和提前退出时，原始交易清单不再等同于新策略可执行的交易清单。
- **死胡同**：只修改旧交易的最终 R 会漏掉因提前空仓而获得的新进场；用最高浮盈当触发顺序会让同根止损与止盈获得不可能的成交次序；把价格保本写作净保本忽略手续费。
- **有效路径**：重新从完整收盘信号驱动状态机，原保护先执行，新的保护/部分平仓下根生效。部分数量用原仓分母，进场扣半程成本、每次退出按原仓比例扣半程。账户用剩余数量标记收盘权益，已到期但未成交的部分单列估值，不把缺口当零收益。
- **通用规则**：先验证“不改退出”的基线能重现旧账本，再验证再入场、数量守恒、费用时点与同根操作顺序；仓位风险比例与价格信号是两项独立实验。
- **牵连**：`spike_exit_policy_study.py`、`spike_exit_accounts.py`、本轮独立实验 config/PROJECT_PLAN；生产交易参数未改变。
