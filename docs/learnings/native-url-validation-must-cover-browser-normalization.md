# 本机协议校验必须覆盖浏览器实际传入的 URI

- **问题**：Windows 监控列表点击 BZ 后，入口提示链接或布局无效，尽管网页生成的地址通过了原参数测试。
- **死胡同**：原测试只把网页模板里的 `open?symbol=…` 直接交给解析器，漏掉浏览器和系统交接时会把空路径补成根路径。40 个纯参数用例通过并不证明真实点击链路兼容。
- **有效路径**：读取仍停留在错误弹窗的 SpikeChartLink 进程命令行，实际参数为 `spike-tradingview://open/?symbol=BZ-USDT-SWAP&timeframe=15m`。原代码对该参数返回 2；只增加一个可选根斜杠后，同一参数生成准确的 OKX BZ 永续 15 分钟图地址。布局文件本身合法，无需改动。
- **通用规则**：外部协议回归应包含捕获到的真实 argv，再验证等价 URL 规范化形式；不要为兼容单个斜杠而放宽任意路径或整体解码参数。参数通过与客户端主图显示仍是两项验收。
- **牵连**：`yoyo/monitor/windows_chart_link.cs`、`tests/monitor/test_windows_chart_link.py`。安装器改为先编译到版本目录再切换注册，避免旧错误弹窗锁定旧 exe 阻止修复部署；旧版本保留。
