# 参考计划换规则，不重写信号事件

- **问题**：12H 云带信号的止损从插针极值改成确认时云带外缘 ± 0.1 ATR(14)，卡片、图表、排序与通知要一致，但历史补录和已通知状态必须保持原样。
- **死胡同**：审查时排除直接覆盖历史 payload、重新入库触发通知，以及只在前端改框却沿用旧 R 的路径。用绝对值计算风险也会把错误方向的止损包装成有效计划。
- **有效路径**：保留原始事件与通知键，独立保存确认时 ATR 输入，通过带版本号的统一函数投影参考计划；ATR 使用已收盘 12H 数据和持久化 Wilder 状态。只有风险与目标方向均有效时给出 R；图表切换周期不重算该计划。历史框按实际确认顺序区分新旧，选中旧信号不改变最新身份。
- **通用规则**：事件事实、计划规则版本和界面选中状态分别存放。改计划时同时核对有符号风险、因果输入、跨表面一致性，以及事件内容和通知去重状态不变。
- **牵连**：`yoyo/monitor/cloud_signal_plans.py`、`yoyo/monitor/cloud_signals.py`、`yoyo/monitor/static/cloud-signal-chart.js`；行为验证见 `tests/monitor/test_cloud_signal_plans.py` 与 `tests/monitor/frontend_cloud_signals.test.cjs`。本次 1,010 条旧事件与渠道状态逐行相等；参考计划不代表实际成交或收益。
