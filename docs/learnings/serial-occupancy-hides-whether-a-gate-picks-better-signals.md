# 序贯占仓会掩盖入场门到底有没有挑出更好的信号

- **问题**：单仓策略加入场门后，序贯账本的净 R 差既包含"被删掉的单"，也包含"因为没占仓而多出/少掉的后续单"。BB×Stoch 加 RSI 门后 74 个候选通过，实际入场却只有 58 笔——差额全部来自占仓路径改变。
- **死胡同**：把净 R 差归因于被拦下的那 37 个候选，等于假设其余信号面对同样的持仓状态；这在单仓策略里从来不成立，见 [`entry-filters-change-the-whole-trading-state-path.md`](entry-filters-change-the-whole-trading-state-path.md)。反过来，只报告"配对随机对照超额"也不够：对照解决的是入场时点是否优于同环境随机，不回答标签本身有没有信息。
- **有效路径**：在序贯账本之外，对**每个可用原始信号各自独立回放一笔**（忽略占仓），按门放行/拦截分组，再在事件集合内做种子化标签置换检验。本轮放行组 −0.1113R/笔、拦截组 −0.2116R/笔，差 +0.1004R，9999 次置换单侧 p=0.313；**两组都是负的**，所以这个门至多是"亏得少一点"，不是把赢家挑出来。
- **通用规则**：入场门实验必须同时给三样东西——序贯账本（可执行口径）、事件级分组（信息量口径）、匹配随机对照（时点口径）。三者回答不同问题，任何一个都不能替代另外两个；事件级结果可重叠，只作诊断，不能当账户收益。
- **牵连**：`yoyo/evaluation/bb_stoch_rsi_study.py::event_level`、`tests/evaluation/test_bb_stoch_rsi_study.py`、`analysis/p1_eth_bb_stoch_rsi_filter_20260916.md`。退出侧是否也被过滤要单独冻结成一组（本轮 `rsi_both`），否则过滤会把亏损单留在场内。
