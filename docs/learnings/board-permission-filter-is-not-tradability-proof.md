# 板块权限过滤不能冒充个股可交易性证明

- **问题**：用户要求从 A 股模型命中里去掉“普通用户不能买”的股票。静态结果同时混有主板、科创板、创业板和北交所，但“账户有没有板块权限”和“这只股票此刻能不能成交”是两个不同问题。
- **死胡同**：把 `600/000` 等主板代码直接标成 `buyable=true`。这会漏掉 ST/退市风险揭示、停牌、涨跌停封单、券商账户控制、资金和申报单位，也会把模型 `SHORT` 类误导成可以买入的候选。
- **有效路径**：先根据交易所官方投资者适当性规则定义一个保守、可复现的范围——基础沪深 A 股账户只保留沪深主板，不假设科创板、创业板或北交所权限；再增加 ST/退市名称拒绝门。输出字段只叫 `retail_eligible` 的板块权限视图，同时明确 `tradability_proven=false`，实时成交资格留给券商下单前检查。
- **通用规则**：任何“用户可以买”的筛选先拆成三层：静态板块准入、账户/风险协议权限、实时证券与订单状态。离线研究产物最多证明第一层；没有券商实时回执，不得把结果命名为可交易或可成交。
