# 日历区间必须先按细周期归属，再映射到图表

- **问题**：独立周一高低点与 1.618 指标需要在 5 分钟、4 小时、日线上保持同一纽约周一范围，且历史线段在下个纽约周一到期。
- **死胡同**：按图表 K 线开盘星期汇总整根高低点，在冬令时的 UTC 4 小时图和全年日线上会跨入周日或周二；这是设计审查排除的路径，未作为已验证实现交付。固定加 168 小时也不能表达切换夏令时的日历周。
- **有效路径**：大周期通过 `request.security_lower_tf` 消费全部已收盘 5 分钟数据，按纽约当地时间归属，要求周一从午夜到次日午夜连续完整才冻结。周界分别用日历时间构造；实时所属周用当前时刻判断，不能只看尚未结束的大周期 K 线开盘时间。价格账本独立于可见窗口，绘图才裁剪。2026-10-19 的 OKX:MUBARAKUSDT.P 在 5m/4h/1D 原生日志都得到 288 根、H=0.055126、L=0.052237、上=0.056911402、下=0.050451598。
- **通用规则**：遇到按当地日历定义的区间，先核对图表 K 线是否跨越边界。价格计算、最终值的可知时间、历史显示起点是三件事；回标极值不能宣称该时刻已知最终区间。
- **牵连**：`yoyo/evaluation/pine/monday_high_low_1618_v1_0.pine`；`output/playwright/monday-1618-pine-20261026/` 原生日志；[TradingView 时间文档](https://www.tradingview.com/pine-script-docs/concepts/time/)和[细周期数据文档](https://www.tradingview.com/pine-script-docs/concepts/other-timeframes-and-data/)。完整性要求适用于连续报价市场；缺失或休市导致的缺口明确跳过，不以残缺周一冒充完整基线。
