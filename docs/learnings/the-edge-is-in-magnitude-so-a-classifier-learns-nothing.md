# 边在"赚多少"而不在"赢不赢",所以二分类器必然学不到东西

- **问题**:判断层在 25,602 行池上 AUC **0.4962**(抛硬币),
  但同一批特征里 **18/28 个**与净收益的 Spearman 相关在 p<0.01 显著,
  最强的 `atr_pct` 达 -0.278。**特征有信号、模型学不到**,两者不可能同时为真。
- **死胡同**:我先假设 `atr_pct` 是"障碍缩放的机械假象"——
  TP=5×ATR、SL=2×ATR 都按 ATR 放大,胜率 28% 时期望 = 0.28×5−0.72×2 = −0.04 ATR,
  所以 ATR 越大亏越多。**猜反了**:换成 ATR 单位后相关性不但没消失,
  还从 -0.278 **翻成 +0.4525**。
- **一张表解释了一切**:

  ```
  ATR 五分档   ATR中位   胜率     每笔净
  最低         0.34%    36.2%   +0.0685%
  最高         1.13%    37.7%   +0.3456%     ← 5 倍
  ```

  **胜率五档几乎持平,每笔净差 5 倍。** 边在**幅度**,不在**概率**。
  而生产判断层是二分类器,目标是"这单赢不赢"——**那一维没有信息,
  AUC≈0.5 是它被问的那个问题的正确答案**。
- **有效路径**:换目标。同折、同特征(28 基础 + 19 因果 alpha)对比:

  ```
  分类器 学 label    顶档 -13.91bp    3/15 折为正
  回归器 学 净收益   顶档 +22.48bp   11/15 折为正
  配对检验 平均差 +21.46bp,t=+3.21,符号检验 p=0.0074   ← 两项均过 p<0.01
  ```

  **但置换检验 p=0.32** —— 打乱目标重训,32% 的情况也能达到回归器的 +10.21bp。
  所以:**换目标修掉的是"分类器主动把好的排到后面",不是凭空造出选择力。**
- **通用规则**:定学习目标前,先看**结果的方差来自哪一维**。
  若胜率在特征上近似常数而幅度差数倍,分类目标从定义上就学不到东西,
  再多特征、再好的模型都救不了。
  推论:"AUC 低"要先排查"目标选错",而不是直接归因为"特征没用"。
