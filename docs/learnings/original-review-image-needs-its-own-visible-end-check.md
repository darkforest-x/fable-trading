# 原框时间安全不等于原审核长图时间安全

- **问题**：历史方向表全部框右端都在 holdout 前，但原图是 200 根长窗；框后可见的行情仍可能越界。旧标注复用时直接按框时间复制原图，会把未授权时段带进审核。
- **死胡同**：只检查 cut_time，或用 cut_time 加剩余根数推算原图右端。即便新短窗连续，缺根也可能发生在短窗之后，使按固定15分钟推算的旧图右端偏早。
- **有效路径**：先从纯时间字段核对原200根窗口的实际右端、连续性和框锚点，再允许打开原图。无证明或越界时只保留原框元数据，用安全的新审核画布替代；未来40图继续单独受同一边界约束。对已冻结的主窗数据作哈希，在未来读取阶段确认其内容没有漂移。
- **通用规则**：每张可见图片独立持有完整可见窗口的时间证据；不要把目标框的时间资格继承给整张图片。边界检查必须先于图像读取和OHLC物化。
