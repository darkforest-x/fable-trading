# 统一卡片样式时，共享展示规则，保留各自指标语义

- **问题**：信号中心与形态巡检已有相同的深色主题，但卡片列数、字号、内边距和信息排列仍不同。Owner 要求以巡检卡片为准。
- **死胡同**：只改圆角和背景的既有版本仍是三列大卡片，不能达到视觉一致；照搬巡检的模型分数条也不适用于信号 R 值。R 没有固定的百分比上限，不能伪装成置信度。
- **有效路径**：先读取真实巡检卡片的计算样式，再在 `yoyo/monitor/static/scan-cards.css` 用同一规则管理两类卡片的网格、表面、间距、标题和周期标签。信号仍使用原有价格、状态、R、保护价及可展开详情，只调整展示结构。
- **通用规则**：样式一致性应按实际布局和共享规则验证，不能只看颜色相近。不同业务字段保留自己的含义；数据缺失、历史来源与参考成交口径不能因紧凑排版被改写。
- **牵连**：`yoyo/monitor/static/app.js`、`index.html`、`scan-cards.css`。本次 39 项现有信号/工作区检查通过；真实桌面验证四列，390px 与 320px 验证两列且无横向溢出，详情点击展开及键盘收起正常。交易、巡检和模型参数未变更。
