# 截止结算可以复用，但必须保持原截止点并单列收益

- **问题**：ETH 五年固定10R没有截止结算，复用助手据此要求年度缓存的 boundary_weight 全零；BTC 年度最后一笔10R却在共同数据截止点结算为+3.187R，导致四档原生回放全部完成后汇总被拦下。
- **死胡同**：删除这笔会改变原始485笔机会集合；将其当10R命中会夸大收益和胜率；重新跑已完成原生成交也无法消除合法的时间边界。原错误输出保留于实验 run.log。
- **有效路径**：确认年度与五年共用同一实际数据终点；索引迁移后逐笔 end_i 与冻结候选完全一致。只允许整仓 boundary_weight 为0或1，边界成交须满足 exit_i=end_i，任何提前强平或超出终点的缓存拒绝复用。保留这笔边界标记、独立收益与费用来源；正常止盈/止损和截止结算分别解释。原生成交缓存无需重放。
- **通用规则**：缓存复用要检查成交路径的截止语义，不要把一个币种没有发生过的边界情形变成通用前提。允许合法边界不代表把它算成目标触达。
- **牵连**：`yoyo/evaluation/range_fiveyear_fixed_target.py` 的 validate_static_boundaries 与原始候选 horizon 比较；对应两项边界回归；`experiments/active/exp-btc-touch-fixed-targets-fiveyear-20261022-v1/`。年度分组仍按入场归属，不新增年度强平。
