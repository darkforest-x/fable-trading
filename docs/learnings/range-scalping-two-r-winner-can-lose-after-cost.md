# 极窄止损的2R赢家仍可能成为最大净亏单

- **问题**：首4小时区间回归BTC回测里，最差净值为−19.880019R，但该单实际命中2R止盈，乍看像成交或盈亏计算错误。
- **死胡同**：只看2R/−1R标签或把净R小于−1一律当bug，会忽略成本的计量分母；只强调总R也会掩盖等风险权重对极窄止损的放大。
- **有效路径**：逐笔核对2025-09-19 08:25Z空单：入117058.1，SL117068.8，风险距离10.7，即0.00914076%；TP117036.7，毛+2R。固定20bp成本除以风险百分比为21.880019R，因此净−19.880019R。BTC/ETH共有40/11笔完整2R赢家扣费后仍亏。独立核算成交与价格收益，两币等名义金额的平均净bp也为负。
- **通用规则**：短线研究同时报告毛R、净R、成本/R和净价格收益；先检查最窄风险与最极端净R的逐笔算术，再讨论最小止损或低成本假设。不得为好看而擅改成本、设风险下限或删极端值。
