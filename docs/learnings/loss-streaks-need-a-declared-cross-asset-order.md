# 多币种连续止损必须先声明排序与同时成交边界

- **问题**：周一1.618的山寨4h五根确认有9,041笔已判定交易，Owner要求最长连续止损；多币持仓重叠，历史账本只有5m退出区间。
- **死胡同**：直接按文件行次序、币名分组拼接，或把跨币52笔连损当作账户52次顺次交易，都会给出没有实际资金路径支持的结论。同K内随意排序也可能改变连损数。
- **有效路径**：全市场按退出区间排序并对同区间内全部排列计算最长连损的上下界；单币另按入场次序统计，未决单中断。用小序列穷举验证排列边界算法。实际全市场上下界均52，单币最大AUCTION为10；两者回答不同问题。
- **通用规则**：统计连损先定事件（触发SL或净亏）、时间轴（入场或退出）、范围（单币或跨币）和未决/并列处理。相关币同时亏损不是独立伯努利事件；独立R合计不能代替账户最大回撤。
