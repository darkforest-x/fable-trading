# 全市场模拟应冻结选币规则，而不是冻结启动时的一小份币种清单

- **问题**：模拟入口默认 BTC / ETH 且最多 20 个合约，与 Owner 要求默认 OKX 全部 USDT 永续不符。
- **死胡同**：原先用固定币种列表表达所有范围；简单扩大默认列表仍会遗漏后续上市合约，逐币逐周期预加载行情还会把全市场启动变成一次批量数据读取。
- **有效路径**：运行规格明确保存动态全市场或自选范围；全市场从已有监控信号中读取 USDT 永续，按实际信号和持仓读取闭合行情。自选列表与旧任务保持原范围，大列表通过单个 JSON SQL 参数过滤。
- **通用规则**：先区分动态市场范围与固定研究样本；默认值必须贯通页面、编排、API、运行规格及工作进程，新增标的和原名单兼容性都要验证。
- **牵连**：`paper_api.py`、`paper_source.py`、`platform_api.py`、`contracts/research.py`、`static/strategies.js`、`static/platform.js`；历史回测仍需明确合约，成本、时钟、因果行情与真实交易权限保持原约束。
