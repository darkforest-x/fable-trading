# K1→K2 距离必须跨时间稳定后才能收紧

- **问题**：BTCUSDT.P 1h 验证段显示 gap 3–5 为 +32.99bp/笔、6–8 为 -61.57bp/笔，看起来应立即把 2–8 改成 3–5。
- **死胡同**：只看最新验证段的漂亮分组就改 gap。这会把验证集变成调参集，并忽略同一关系在旧行情中的方向是否一致。
- **有效路径**：把相同分桶原样投回冻结开发段。gap 3–5 在开发为 -38.40bp/笔，6–8 反而为 +6.82bp/笔，关系几乎完全反转；因此 gap 更像行情阶段交互，而不是稳定静态阈值。
- **通用规则**：任何距离/窗口阈值至少同时展示开发与验证的同口径响应；方向反转时禁止追着验证收紧，改为研究可因果观察的行情阶段条件或等待新前向样本。
- **牵连**：gap 2–8、`results/parameter_stability.csv`、时间切分纪律、验证集不得二次调参。
