# 有限输入的BLAS告警要独立复算，不能隐藏或改依赖契约

- **问题**：IMACD月聚类sign-flip的有限矩阵乘法，在本机NumPy2.0.2发出divide-by-zero、overflow和invalid三种告警。
- **死胡同**：把告警直接忽略会留下不可审计的p值；看到告警就改NumPy或BLAS版本又会破坏本仓跨机契约。本轮未采用这两条路径。
- **有效路径**：独立最小复现使用3999×24的±1矩阵与有限随机向量，BLAS结果仍全有限，与显式逐元素乘后求和最大差1.46e-11。保留初次结果，改用不经该矩阵乘法的显式归约，再从已保存的交易/控制账本重算统计、核对账本SHA不变。
- **通用规则**：先验证输入和输出是否有限，再用独立算术路径区分数值错误与运行时告警；不能以“看起来差不多”为理由跳过经济统计复核。
- **牵连**：yoyo/evaluation/imacd_profit_mechanism.py 的 inference/refresh_statistics；exp-imacd-profit-mechanism-20260907-v2 的初次结果与统计刷新收据。未更改市场路径、参数、费用或依赖。
