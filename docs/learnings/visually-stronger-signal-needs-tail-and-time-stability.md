# 视觉更强的信号仍要检查跨期稳定性与盈利尾部

- **问题**：两张SPIKE V12.8截图看起来支持陡BB收口更容易成功，但单个成功图和失败图不能给出条件胜率。
- **死胡同**：全历史胜率略高，或某个周期平均收益很高，就把斜率变成硬过滤条件；这会忽略时间反转、少数大盈利和同环境随机入场本身的收益。
- **有效路径**：早段冻结斜率分组，保留原账本，后段同时看扣费胜率、平均净收益、兑现高R和匹配随机对照。ETH15m全期大/小组胜率32.73%/31.37%，后段却为37.5%/45.0%；后段4笔兑现至少5R都在小组。ETH1h大组7笔平均净249.00bp，低于匹配随机284.65bp；去掉最大一笔后为-111.49bp。删尾只是影响诊断，不是新策略结果。
- **通用规则**：视觉强度与收益必须分开验证。先检查早晚段、方向与标的一致性，再检查收益集中于多少独立事件。分层阈值不能使用后段收益挑选，小斜率组包含负值也不能偷换为纯水平组。缺少稳定优势不等于已经证明变量无效。
- **证据与边界**：`experiments/active/exp-spike-v128-bb-slope-20260924-v1/summary_v1/`、`verification.json`。这是两标的回顾性分层，不是前向验证或接入过滤后的重回测；高周期样本稀疏，不改变训练和生产资格。
