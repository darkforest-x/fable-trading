# 止损价上的利润为正，不代表仓位能撑到止损

- **问题**：2026-09-21 对 Owner 指定的 OKX WIF 2026-08-20 截图做 100U 条件回放。连续加仓第七次后，0.1967 止损仍对应约 3035U 净利润，但按当前档位估算的强平阈值约 0.19922，高于止损。
- **死胡同**：只验证每次加仓后保留一半止损利润，并验证加仓当时有足够初始保证金。这两条检查没有约束回撤途中因仓位档位而增加的维持保证金，不能据此称为“利润已经锁住”。小时低点同时跨过止损和强平线，也不能自行假定止损先成交。
- **有效路径**：分别核算最新价止损账本和标记价维持保证金；按仓位查档位，并补查同一小时的 1m 最新价及标记价。两条线都在北京时间 13:10 的同一分钟被越过，保留先后不明。3134.84U 只能列为忽略强减的理想止损账本，22043.18U 只能列为恰在最高价成交的事后假设；不编造强平后余额。
- **通用规则**：盈利滚仓至少有三个独立问题：加仓是否买得起、保护价上的账本是否盈利、回撤到保护价以前是否仍满足维持保证金。未来策略修订应显式约束第三项，并计入标记价偏差、资金费和成交滑点。历史档位没有取证时，当前档位只能作条件敏感性证据，不能充当历史成交证明。
