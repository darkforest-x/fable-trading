# 外部平仓证明必须覆盖同一合约的全部本地分笔

- **问题**：交易所已平仓，但本地同向多笔仍停在 `exit_needed`，导致后续手动预览被账户归属校验拦住。
- **死胡同**：只允许一笔本地仓位参与对账，无法解释合并平仓；绕过数量守门或重发平仓都会改变交易风险。直接复制外部合并单的收益也会重复归属。
- **有效路径**：同合约所有非终态分笔都必须满足相同方向、已成交、无已提交退出请求，且各自保护单均已终止。两次账户查询确认无仓、无挂单，再要求一笔晚于所有入场时间的已成交 reduce-only 订单覆盖合计数量。只据此关闭本地生命周期，收益保持未归属。
- **通用规则**：先区分生命周期证明与收益归属证明。多笔平仓不能只证明其中一笔数量，更不能用补发订单代替对账。
- **牵连**：`yoyo/okx_execution/manual_reconciliation.py`；`tests/okx_execution/test_manual_reconciliation.py`。所有证据读取均为 GET，证明不足时继续阻塞。
