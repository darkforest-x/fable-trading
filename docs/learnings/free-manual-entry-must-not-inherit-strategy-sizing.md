# 自由手动入口不能借用策略订单冒充实现

- **问题**：快捷开单的实盘标签被静态 disabled，而且没有对应模块；均线实盘现有 API 必须引用检测记录，另有 3% 风险和 3R/5R 约束。
- **死胡同**：仅解除按钮禁用会调用不存在的模块；编造 detection_id 或偷偷套用均线仓位规则，都不能实现用户选择的自由手动委托。
- **有效路径**：Owner 在 2026-10-23 明确选择自由手动。独立预览/确认账本复用现有账户和唯一写者，绑定数量、价格、杠杆与可选固定退出；现有策略管理先执行，自由票据轮询每次只处理一笔，未知写入只核对原订单。已有同币持仓或挂单时拒绝改杠杆，防止影响其他订单。
- **通用规则**：先确认真实订单语义，再接界面。每个能交易的入口都要有实际加载路径、读请求、显式确认、发送前持久化和重启核对；不能用成功提示代替成交或保护回执。
- **牵连**：`free_manual.py`、`free_manual_api.py`、`manual_engine.py`、`monday-live.js`；不改变原均线策略参数。限价未完全成交时，附带保护的等待状态单独显示。仅离线模拟交易所验收，不发送真实测试订单。
