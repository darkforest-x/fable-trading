# 固定币种的图表可以与账户快照同时加载

- **问题**　深链已经给出账户、币种与周期，首屏 K 线却要等待账户接口。给快照额外延迟 320 ms 后，桌面和移动浏览器都能复现。
- **死胡同**　把所有预取放在快照回调里，图表挂载有机会先发出同一请求，稍后执行的回调又取一次。只看最终图表能否出现，很难察觉这个问题。
- **有效路径**　从固定币种和周期直接确定行情请求，让挂载逻辑接手同一份请求。独立按账户标识交接快照。默认选币仍等待账户返回，交易回看由对应订单确定时间窗。
- **通用规则**　先检查每项首屏数据的选择条件何时齐备，再用冷启动的请求瀑布核对时间和次数。验证时故意放慢一个依赖，可以暴露仅在特定响应顺序下出现的重复工作。
- **牵连**　`yoyo/monitor/static/startup-hints.js` 决定何时预取。`tests/monitor/frontend_startup_hints.test.cjs` 覆盖选币及交易回看，`tests/monitor/frontend_paper_detail_track.test.cjs` 覆盖切换账户时旧请求晚到的情况。
