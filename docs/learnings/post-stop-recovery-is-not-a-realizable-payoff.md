# 止损后回到入场价，不等于放宽止损能盈利

- **问题**：PEPE 原方案 1,582 笔有完整一小时观察的初始止损中，935 笔后来触及原入场价；只看这些案例容易认为应取消或放宽止损。
- **死胡同**：把止损后的最高价格按原风险折成 R，直接当成错失的可实现收益；或只展示后来大涨的单子。它忽略中途逆向幅度、重入费用、右端样本不足和普通市场波动也会回来的基准概率。
- **有效路径**：冻结原始风险，分开记录持仓 MFE、最终兑现与出场后的固定窗口价格标签。排除止损当根不知先后的有利影线，保留原时间分段及完整窗口分母。相同配对中双方都止损的 1,384 对，一小时触价恢复率为信号 821/1384、随机 830/1384；恢复现象本身没有显示额外优势。
- **通用规则**：先问“收益发生时还在场吗”，再问“回来前还需要承受多少不利变化”。未来恢复只能作为待检验机制的线索；宽止损、保本或重新入场必须完整回放全部交易，保持风险和成本口径一致。
- **牵连**：`yoyo/evaluation/pepe_range_recovery.py`、`experiments/active/exp-pepe-range-exits-20261020-v1/recovery_config.json` 与 `results/recovery_v1/`。描述性后验标签不可作为入场特征；独立交易 R 相加不是账户收益。
