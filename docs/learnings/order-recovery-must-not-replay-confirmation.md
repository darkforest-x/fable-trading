# 自动恢复只能重算预览，不能重放确认

- **问题**：账户恢复后要求反复手点预览让流程陷入死路；把确认前明确拒绝和提交回执未知混为一谈又会误导订单状态。
- **死胡同**：解除所有阻塞会绕过真实仓位核验；自动重试确认会放大成交不确定性。每次状态轮询重建图表还会打断拖拽、缩放。
- **有效路径**：明确的 blocked 响应恢复到可编辑状态，GET 检查就绪后重算预览，仍等待新的人工确认。提交结果未知时只按原 ID 查询，绝不自动重放确认。相同价格与来源的图表复用原节点，状态更新不再重建图表。允许随时回到检测结果，从持仓侧栏继续跟踪。
- **通用规则**：失败是否发生在副作用之前必须有协议证据；自动恢复的边界是恢复到可审核状态，而不是替用户完成承诺。
- **牵连**：`manual-live.js`、`manual-account.js`；隔离模拟覆盖预览阻塞、确认前阻塞及返回流程，真实页面只读取已有订单。
