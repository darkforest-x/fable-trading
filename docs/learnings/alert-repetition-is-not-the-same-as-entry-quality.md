# 先量化重复贡献，别把低质量首发误诊为重复提醒

- **问题**：Owner反馈SPIKE信号像一直开单；原生图表实际是V2，而另一个离线V3广覆盖研究有170条/日，不能把两个版本混为原因。
- **死胡同**：看到退出后可再次消费旧密集证据，便假定去重能解决大部分噪音；或把旧报告的duplicates=0当成没有重复，因为原匹配只认锚点后6根。重复提醒、失败启动和匹配窗外续涨并不是同一类。
- **有效路径**：先核实用户当前版本，再对固定全池完整重放，只增加密集区消费状态，不改单笔风险和退出。V2 1414条→1381条，仅少2.33%；自然平仓净胜率33.41%→33.28%，随机超额仍为负。这个机制存在，但不是本池降噪的主要解法；不能上线并宣称修好。保留失败实验，也保留被挡45条、新增12条和70个候选根不同的分母。
- **通用规则**：先测一种噪音机制占总负担的比例，再决定是否把它作为主修复。高召回、少提醒和更好的交易结果要分别验收；纯减少箭头不等于更高质量。预警阶段的视觉也不能默认暗示开仓。
