# 筛选后浮亏较小，不能证明等待信号改善了入场

- **问题**：460 合约的 Spike 回踩研究里，等待 Stoch 金叉后全体成交的平均 MAE 从首次回踩的 0.771R 降至 0.712R，但交易数也从 18,080 降至 741；两组不是同一批行情。
- **死胡同**：只对照全体成交的平均值，会把筛选掉大量机会、风险单位变化和真正的择时效果混在一起。较低 MAE 和较高每笔净 R 不能直接解释为买价更好，也不能代替累计收益。
- **有效路径**：保留原机会身份和零成交，分别重放占仓，再补双方都成交的描述性对照。在共同 696 个机会里，等待金叉平均买贵 0.8374%，MAE 从 2.9220% 升至 3.6341%，从 0.6493R 升至 0.7091R，每笔净 R 由 0.2895 降至 0.0716。相对再突破的共同 475 笔则买便宜约 0.4461%，说明比较基准必须明确。共同成交集合仍是条件选择，不冒称无偏因果效应。
- **通用规则**：评估入场等待同时报告完整策略、原机会匹配随机、共同成交三种不同分母；分别识别筛选、入场价格、持仓占用和错过赢家。不要用筛选后均值给等待本身归功。
