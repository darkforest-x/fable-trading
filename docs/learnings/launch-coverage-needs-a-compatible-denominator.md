# 预警覆盖、形态资格与可交易确认必须分别定义

- **问题**：Owner要求识别至少80%的广泛启动，而V2用价格未来先达+4ATR的全体突破作分母，同时要求当根或下一根已经站上六条均线。
- **死胡同**：继续只放宽量比/方向效率，忽略硬结构门本身已排除492/1660个全期正例、41/144个案例夜正例；即使其他门全取消，也最多70.36%/71.53%。将分母临时缩为已密集币会制造达标。反过来，以标签同源的全量突破触发器宣称100%检测能力也只是循环定义。
- **有效路径**：先算每个保留硬门在固定分母上的覆盖上界，再区分广覆盖结构预警与质量确认；旧分母继续报告，密集/六线全上作为独立标签或明确子组，不能拿子组覆盖替代总覆盖。两个阶段保持各自实际收盘时点，不能把后来确认回填到更早预警。
- **通用规则**：召回目标首先检查分母与检测任务是否相容；召回和提醒负担、匹配随机收益分别验收，任何单项达标都不自动代表可盈利。
