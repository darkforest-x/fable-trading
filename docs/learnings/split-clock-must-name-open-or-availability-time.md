# 时间切分必须明确使用开盘时钟还是可用时钟

- **问题**：同一批 V7 两年证据中，早退实验的验证信号比跨所实验少 8 条，看起来像漏数或数据漂移。
- **死胡同**：看到总量接近就默认分母一致，或强行把两个表相加比较。4H 的信号开盘时间与收盘可用时间相差四小时，恰好跨越切分点时会落到不同期间。
- **有效路径**：逐流、逐方向对账后定位到 8 条 `2025-09-09 20:00 UTC` 的 4H 信号：按 `signal_bar_open` 属于开发段，按 `availability_time=2025-09-10 00:00 UTC` 属于验证段。两种口径各自可用，但表格必须标明切分时钟，跨实验比较先重新对齐。
- **通用规则**：因果评估优先按决策信息真正可用的时钟切分；历史产物若已经按另一时钟冻结，保留原结果并显式解释边界差异，不静默改写。
- **牵连**：`spike_early_failure_exit_study.py` 使用信号开盘时钟，`spike_cross_venue_event_study.py` 使用收盘可用时钟；差异仅在切分归属，不是 8 条信号凭空新增。
