# 周线价格正确，也可能画错时间范围

- **问题**：1.618 用本周纽约周一高低点，但图表横向拖回历史时，仍显示本周价位。
- **死胡同**：只检查数值和 week 字段无法发现显示错误；图表原生 price line 会贯穿整个时间轴，文字写“本周”不能改变线的范围。
- **有效路径**：使用服务端纽约日历给出的本周起止时间，通过图表 primitive 绘制有时间边界的线。保留历史 K 线，按实际时间轴插值，避免插入假 K 线；周切换继续校验币种、周和收盘边界。
- **通用规则**：有有效期的价位必须同时验证价格与可见时间范围，并覆盖拖回上周、拖到下周及夏令时边界。
- **牵连**：`monday_candles.py`、`monday-fib-chart.js`、`range-chart.js`；既有 Pine 继续保留，无需修改。
