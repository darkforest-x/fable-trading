# 盈利保护本身不能提取长赢家尾部

- **问题**：观察到不少 3R 盈利单之后还能继续上涨或下跌，直觉上怀疑 1.5R 启动的保本保护过早截断趋势。
- **死胡同**：只看“关闭保护后 TP 数增加”，忽略原本受保护的失败交易会重新落回完整结构止损；也不能用胜率上升判断更优，因为更早保护会制造大量接近零收益的“小胜”。
- **有效路径**：冻结信号、入场、K2 止损和 3R 目标，只扫保护触发点，并同时报告 TP / SL / protected-stop 转移、平均 bp、时间折和匹配随机对照。15m 关闭保护使 TP 79→95、SL 221→240，仅改善 0.28bp；5m TP 141→215、SL 454→534，仅改善 0.41bp，稳健分提升都不足 2bp。
- **通用规则**：保护规则管理的是“未到目标前如何处理回撤”，不是“目标之后的赢家尾部”。若问题是赢家目标太近，应单变量测试目标倍数或单独预注册 runner；不要用保护参数间接回答另一种退出问题。
- **牵连**：`profit_protection_trigger_close_r`、`target_r=3`、stop/target 状态转移、20bp 成本；仅使用 2023–2024 development，audit 与 holdout 未打开。
