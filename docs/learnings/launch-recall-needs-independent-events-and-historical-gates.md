# 启动召回需要独立事件分母和历史门槛

- **问题**：Owner指出2026-08-19晚上HYPE、NEAR、PEPE均线密集后明显上涨，SPIKE V1却没有箭头。
- **定位**：先将截图开盘时间转为UTC，并与原生OKX OHLC逐项核对；用完整预热历史重放每根信号状态。逐层区分密集资格、双线近零、方向、量价门槛、释放机会窗与参考持有去重。
- **发现**：三例密集资格均通过，但近零只有4/0/6根。HYPE量比15.31、TR扩张4.14及全部力道条件已通过，仍被12根双线近零前置资格挡住。NEAR是负动能回升，PEPE量比3.88又略低于4。价格/六MA横盘不等于IMACD双线连续贴零。
- **显示陷阱**：TradingView table显示最后一次执行状态，不随历史十字光标移动；状态字符串还可能沿用旧分支的赋值。历史判断应来自当根Data Window或独立逐根记录。失效pending的旧release时间不能展示为当前等待年龄。
- **改版方法**：新增渐进通路是一项明确的入口干预，保留原风险/退出，单独冻结和测试。不能逐个降低门槛直到三张赢家都出箭头，再称达到80%召回。
- **分母**：从全体合格OHLCV形成与指标独立的价格事件，先按时间去重、后看未来标签。没有信号的币仍在分母；延迟、误报、未知尾部、已有参考持有分别报告。事件代理不是Owner逐样本金标。
- **因果边界**：标为22:00的1H K线最早23:00收盘确认；不能把未来确认回填到22:00。新路线提前持有可能压制原版后续箭头，须同时保存原版独立轨迹并比较新增/消失/提前。
