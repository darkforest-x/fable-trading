# 一个版本同时改两件事，每一步都要有自己的事前臂

- **问题**：Owner 的 V10 =「只做多」+「趋势线突破门」。直接拿 V10 与 V9 比，V10 全期总净 R +924R 对 V9 +3,400R，结论只能是"V10 更差"，说不出差在哪一步。
- **死胡同**：只登记 v9 / v10 两臂，或只和撤回版 V10 的同方向切片对比。前者把两个变量混成一个数；后者的切片来自不同的串行账本（双向持仓会占位），不能当对照。
- **有效路径**：跑之前登记中间臂 `v9_long`（只删空头入场、出场不动），差额拆成 v9→v9_long 与 v9_long→v10 两步，各自强制对账。结果：第一步 −2,475R，全部是 V9 空头——后段 +1,654R，是后段唯一赚钱的一半；第二步 −0.3R，门在多头里基本不起作用。V10 的差距几乎全部来自「不做空」，而不是趋势线。
- **通用规则**：Owner 口径里每出现一个「并且 / 不需要 / 只」，就是一个独立变量；多变量打包要先把中间臂写进 PROJECT_PLAN 再读价格。还要检查「删掉一侧」有没有顺手删掉出场：V9 空头确认结束多单是出场，"不做空"不等于不接收空头确认。
