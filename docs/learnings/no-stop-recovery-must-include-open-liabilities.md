# 无初始止损的回本策略必须计入未平仓负债

- **问题**：收线失败后无限等待含费回本，已关闭样本容易只剩止盈和保本，无法说明全体入场的收益。
- **死胡同**：只统计 closed 的胜率或净R会把仍持有的亏损排除；把数据末尾的框架行政平仓当成策略止损也会改写规则。这两种口径都不能回答真实问题，本轮未采用。
- **有效路径**：Nautilus 每档独立成交、核对原生佣金和PnL，再用固定70/15/15权重还原原始仓位；原生reason0只作截尾标记。分别统计已实现、未平仓含退出费估值，以及两者合计。5m收盘估值曲线只读取原生交易账本，不二次推断成交。
- **通用规则**：没有初始止损时先固定收益单位并定义截尾口径，再看收益；不得把开仓价1%记账R称为真实风险预算，也不能用已平仓样本决定兜底止损。
- **牵连**：`yoyo/layers/l3_backtest/nautilus_touch_recovery.py`、`yoyo/evaluation/monday_12h_recovery.py`；静态三腿等价仅适用于某腿止盈不改变兄弟腿管理，未建模保证金、强平、资金费及成交量冲击。
