# 在线外的存量不能当成当根越线的新信号

- **问题**：观察 BTC、ETH 在自身 5m 周一 1.618 插针收回时，山寨是否同步触发自己的 1.618。42 次当根收回事件中，山寨触线或在线外的平均占比为 40.88%，但这不能回答“刚刚触发了多少”。
- **死胡同**：只看当前高低价是否越过边界，会把早已突破、连续停留在线外的山寨重复计为同步新信号。直接把 40.88% 解释成触发率，会夸大主币和山寨之间的时点关联。
- **有效路径**：分别保存当前触线状态与新越线事件。新事件还要求上一根影线完全在线内；按这个定义，当根新越线只有 3.22%。主币侧再用因果的 60 分钟冷却去重，失败收盘单独保留，避免事后按漂亮反转挑样本。
- **通用规则**：跨市场事件研究先分清“当前处在某状态”和“何时首次进入该状态”，明确前一根条件、重新入内条件及去重口径。同一根 5m 内同步只能证明同窗变化，不能证明谁先谁后；后续极值时间只能作结果，不能作为当时特征。
- **牵连**：`yoyo/evaluation/btceth_alt_response.py` 的 `own_touch`、`own_fresh_now`；`experiments/active/exp-btceth-5m-alt-response-20261101-v1/description.json`。样本为 2026 年 9—10 月固定现期币池，非历史实时排名，未证明交易优势。沿用 [市场广度须剔除共同市场暴露](market-breadth-gates-must-be-beta-adjusted.md) 的约束。
