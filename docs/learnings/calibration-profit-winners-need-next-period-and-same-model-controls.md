# 过去最赚钱的评分门槛，仍须通过同模型的下一期对照

- **问题**：ETH 周一 1.618 模型有正收益候选，但固定零分门槛可能错过机会；需要检验过去一季的偏差校准或门槛选择能否提高下一季收益。
- **死胡同**：把校准期赢家视作稳定门槛。近侧 2025Q4 的过去 q80 规则从校准 +5.53R 变为下一季 −1.66R；2026Q2 的零分规则从 +13.22R 变为 −1.50R。每次校准只有 5–10 个有候选周，最优历史门槛不保证跨期有效。
- **有效路径**：先冻结七个规则，用同一个既有模型评分校准季和测试季，以同模型零分门槛作直接对照，再保留按季度更新的原模型作外部锚点。原生成交与费用复用，由 VectorBT 处理单仓准入和记账。共同覆盖内，近侧同模型 +8.91R、偏差校准 +6.69R、过去择门槛 +2.41R；原更新模型 +10.17R。六项检验均未通过历史证据门。替代同K路径会让偏差校准升至 +9.84R，仍低于相同路径下原更新模型 +13.33R，说明微小改善也不稳健。
- **通用规则**：校准期收益只负责选规则，下一期收益才负责评估；不重新拟合模型后沿用旧分数门槛。分别报告模型新旧、映射变化、共同时间范围和路径敏感性。允许“不交易”作为规则，保留失败季度，不因事后发现较好年份或目标而换主检验。
- **牵连**：`experiments/active/exp-eth-1618-score-calibration-20261031-v1/`；`yoyo/evaluation/eth_score_calibration_*.py`；0.7% 初始止损、maker 2bp/taker 5bp、纽约下周一结算不变。结果为独立 R，非账户收益；当前周不参与评估。前提见 [门槛校准须用未参与拟合的过去分数](score-threshold-calibration-needs-unfitted-past-rows.md)。
