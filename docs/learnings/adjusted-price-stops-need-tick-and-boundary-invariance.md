# 复权倍数不能改变同一根原价K线是否止损

- **问题**：A股模拟中，只把相同原价OHLC换成1.1、1.7等固定复权倍数，刚好触及10.20元的止损有时变成未触发，模拟盈亏因此改善。
- **死胡同**：把已有浮点乘积再包进 `Decimal(str(...))`，无法消除之前产生的10.199999999999998；直接向下取整会把止损再放低一分钱。不同乘法路径还会使 `low <= stop` 在本应相等时为假。
- **有效路径**：真实价格止损取整前，以1e-12相对容差将几乎为整数的tick数量吸附回整数；边界比较也只容忍算术尾差。真实入场价直接取原始价格，数量预算用同坐标风险距离。增加多种复权倍数的exact-touch、稍高及稍低于边界的重放对照，要求退出原因与现金盈亏一致。
- **通用规则**：涉及复权、汇率或缩放坐标的交易回放，要测试经济结果的尺度不变性；不能只验证一组刚好可二进制精确表达的倍率。一个完整tick的容差会改变策略，不是精度修复。
- **牵连**：`ashare_imacd.py`与独立主板Pine。首次开发/验证结果在样本外评估之前作废并原样保留，固定候选、证券及成本不改；修复后重新进行相同选择。
