# 工作台连接状态必须独立于信号列表刷新

- **问题**：直接进入研究、数据集或模拟页面时，各模块正常加载，侧栏却持续显示连接中；菜单增多后移动端文字被挤成竖排，浏览器返回也无法恢复上一菜单。
- **死胡同**：只沿用信号页的整体刷新路径会跳过研究页状态，强制加载信号列表又会引入无关请求；仅减少菜单间距不能解决移动端所有项目均分宽度的问题。
- **有效路径**：共享状态使用独立且合并并发的请求；路由使用历史记录并聚焦主内容，当前菜单滚入可见区域；移动导航采用保留文字宽度的横向滚动。通过直接进入研究页、网络失败恢复、浏览器返回和真实窄屏验证。
- **通用规则**：模块拆分后，先区分共享外壳状态与页面数据的所有权；导航必须同时验证直接进入、前进返回和窄屏溢出。
- **牵连**：`yoyo/monitor/static/app.js`、`styles.css`、`tests/monitor/frontend_shell.test.cjs`；不改变策略、信号新鲜度或执行规则。
