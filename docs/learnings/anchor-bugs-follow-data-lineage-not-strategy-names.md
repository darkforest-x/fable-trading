# 同名点位的错误影响范围必须沿数据谱系核查

- **问题**：Pine V2.43 修正了 12h 图表开盘日错位，Owner 追问既有周一 1.618 回测与模拟盘是否同时受影响。
- **死胡同**：只凭“都叫周一 1.618”或“都用纽约时区”推断全受影响／全不受影响，都不能成立。旧 12h 研究有意复刻截图开盘日口径；主限价回测与模拟盘是另一个完整日历窗口。
- **有效路径**：核实运行源码版本，沿模拟盘 listener、回测 prepare 与小册保存成交追到锚点生成器，再核查保存窗口和同源行情。633 个标的的 86189 周主回测边界正确，6 组源价抽样一致；旧 12h 研究同源对照的 3423 个币种周中 2920 个点位变化，5128 个旧事件中 2218 个不再穿越收回。这个事件价格复核不等于新的信号全集或收益回测。
- **通用规则**：区分计算公式、日历窗口、源粒度、数据交易所、保存版本和展示周期。确认错误沿哪条输入谱系传播，再决定哪些研究需要新版本重跑；不能改旧账本或把另一个实现一起判错。
- **牵连**：`artifacts/monday-calendar-impact-audit-20261101/`；`yoyo/monitor/monday_fib.py`；`yoyo/evaluation/monday_limit_reclaim_inputs.py`；`yoyo/evaluation/top20_12h_reclaims.py`。当前账户与主回测排除的是本次锚点错位，不是其他前视／成交假设问题。
