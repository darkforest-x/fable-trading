# 爆发过滤提高近期收益，不等于降低启动失败

- **问题**：volume4和TR/前ATR≥3让近期1H组合盈利提高、回撤下降，直觉上容易说它们筛掉了假启动。
- **死胡同**：只看最近一段净收益会漏掉初损率反升、较早时段利润下降以及VELVET这类温和启动的大赢家被过滤。把少交易产生的变化直接归因给这根K线的质量，同样没有对照支持。
- **有效路径**：固定退出，报告跨时期、初损率、大赢家保留、去最大争议资产后重新配资，再加同币同周等数量稀释对照。近期改善有保留价值，但随机稀释可替换比例仅17%—22%，不能夸大区分力。
- **通用规则**：过滤器既要解释保留了什么，也要解释丢掉了什么。把爆发型与温和起步作为两种待验证路径，不能先假定只有大阳线才是大行情起点。
