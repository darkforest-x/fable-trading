# 相对随机有优势仍可能跨不过成本底线

- **问题**：Owner Causal V2 在冻结验证相对精确匹配随机入场高 11.36bp/笔，但候选自身扣费后仍为 -4.35bp/笔。
- **死胡同**：把“候选优于随机对照”直接解释成可交易。相对超额只说明过滤器比同环境随机入场少亏，不保证毛收益足以覆盖成本，也不保证显著性。
- **有效路径**：同时报告候选毛收益、固定成本、候选净收益、匹配超额和配对 p。这里毛收益 +15.65bp/笔低于 20bp 往返成本，且配对 `p=0.1994`；所以形态有微弱相对引力，但生产结论仍是拒绝。
- **通用规则**：方向策略必须过两道独立门：候选相对匹配对照为正且有统计资格；候选自身在冻结成本后也为正。任一道失败都不得 promote。
- **牵连**：0.2% 往返成本、fee_to_risk、匹配随机对照、top-decile 净收益铁律、`validation_arm_metrics.csv`。
