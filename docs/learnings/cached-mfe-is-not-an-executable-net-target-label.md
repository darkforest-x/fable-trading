# 缓存最高浮盈不能直接当成曾经可兑现的净收益标签

- **问题**：5R筛选失败后，需要区分没有大行情与有行情但退出回吐。现有候选表包含`mfe_r`，容易直接据此统计“本来能赚5R”的交易。
- **死胡同**：直接比较`mfe_r >= 5`与`net_r > 5`。前者是未扣费峰值，后者是扣费兑现收益；而引擎先检查反向开盘退出/止损，只有未退出才更新MFE，因此缓存不含退出bar的峰值。缓存MFE小于5不能直接证明整条可交易路径从未达到净5R，也不必然涵盖最终净收益。
- **有效路径**：先静态核对峰值更新与成交顺序，明确其是引擎保守记录的毛峰值。新诊断先独立确定有效、未删失的最终净收益类别；再按原固定费用换算峰值口径，并补查退出开盘和退出bar可能触及的区间。同根触及目标与止损而先后不明时保留不确定，或给出上下界，不强行归因为盈利回吐。未运行新诊断，未改变旧引擎或既有最终净R结论。
- **通用规则**：把路径统计用于策略归因之前，核对毛/净、观察截止时点、同bar执行顺序与删失四项语义。盘中高点只作诊断标签，不能回填进场或加仓决策。
