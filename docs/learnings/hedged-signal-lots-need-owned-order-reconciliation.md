# 全周期跟随必须分离信号归属与交易所聚合持仓

- **问题**：Owner 要求信号中心全币种、全周期接 OKX，明确拒绝三仓/6%组合限制。同币不同周期可能同向并存，也可能相反；交易所同向持仓仍会聚合。
- **死胡同**：按币种只留一仓会删掉 Owner 要保留的信号；用总持仓平仓接口会把别的周期一起平掉。只在请求前做客户端 ID 去重也不足够：OKX 只要求待成交订单的 clOrdId 唯一，超时后重发可能重复已成交订单。旧 L4/Copier 的风险与归属契约不能直接套用。
- **有效路径**：独立双向逐仓适配器，信号 ID → 虚拟 lot → 入场 ID/附带止损 ID/退出 ID；发请求前落盘，未知结果只查询原 ID，不重发订单。每笔核对附带保护单，聚合 lot 数量与实际持仓对账后才允许新入场或主动平仓；退出只处理该 lot 的订单和数量。离线故障注入覆盖超时后已成交、止损在撤单期间触发、外部仓位变化、部分成交及超过三笔的跨周期双向组合。
- **通用规则**：取消组合风控上限不等于取消订单身份和成交对账。先定义谁拥有多少数量，再定义如何开平。交易所同向逐仓仍共享保证金和强平边界，虚拟 lot 不代表独立清算账户；模拟断言通过不等于真实交易所验收。
- **牵连**：`yoyo/okx_execution/`、`tests/okx_execution/`；50U/2%与最高杠杆来自本次 Owner 指令，2%为初始止损价格风险尺度，不能保证最高杠杆下实际止损先于强平；交易所账户联调尚待本机凭据。官方依据 https://www.okx.com/docs-v5/en/ 。
