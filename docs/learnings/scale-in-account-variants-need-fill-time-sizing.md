# 加仓账户变体必须按成交时点区分仓位语义

- **问题**：v3add20 复用 v3add 的入场与加仓规则，但每条成交腿按成交时已实现净值的1/20、3倍杠杆独立分配；主子单共享账户，分别占仓位。
- **死胡同**：只向账户下拉框加名称，会继续显示原版按评分线性分配、加仓沿用主单名义本金上限的说明，并遗漏6061子单的平仓保证金封顶。
- **有效路径**：沿账户配置、主子单ID、待成交挂单、统计归属和平仓预估逐项核对；挂单展示成交时动态公式，已成交腿用自身剩余名义本金和配置杠杆计算分批封顶。历史资料单独绑定修正后的frac回放，保留BE0与当前保护价差异。
- **通用规则**：复用账户界面前，先确认加仓金额属于挂单时、母单成交时还是子单成交时；然后分别验证母子单、影子记录及部分退出，不由相似名称推断资金算法。
- **牵连**：monday-reclaim-paper.js、reclaim-close.js、reclaim-analytics.js、reclaim-strategy-book.js、build_strategy_booklet.py；后台V3ADD20_TRACK=6060、V3ADD20_LEG=6061。
