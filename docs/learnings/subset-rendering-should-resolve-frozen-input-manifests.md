# 子集渲染应从冻结来源清单定位数据

- **问题**：为已选出的 200 笔交易绘图时，首张图片迟迟没有生成。进程采样和中断堆栈显示，程序仍在为全部币种检查外盘上的可选尾部文件。
- **死胡同**：复用回测的全市场 jobs() 发现流程，虽然没有重跑交易，却让小规模绘图承担了数百个不存在路径的 stat 调用。在迁移后的外盘上，这些负查找可能非常慢；继续等待并不能证明行情加载或绘图本身很慢。
- **有效路径**：交易已经保留逐币 identity.json，其中记录了当次实际使用的输入文件。按选中币种读取这些清单，恢复已登记的项目软链接路径，并核对大小及修改时间，避免探测未使用的可选文件。这个修复保留原输入集合；实际渲染完成情况另见本轮 completion.json。
- **通用规则**：复盘冻结实验的子集，首先从该实验的确切来源清单定位文件。只有缺少来源证据时才重新发现数据，不能把全市场扫描视为所有后处理的必要前置步骤。
- **牵连**：yoyo/evaluation/monday_top_trade_charts.py；experiments/active/exp-monday-5m-wick-engulf-20261023-v1/symbols/*/identity.json；外盘迁移后继续使用原项目路径，不做内容哈希检验。
