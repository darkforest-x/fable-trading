# 历史差币排除少亏，不等于找到了稳定的坏币

- **问题**：V1/V8收益榜看似能把好币、坏币分开，用户希望排除亏损币提高胜率。
- **死胡同**：用同一时期最终亏损名单剔除同期交易会泄漏；只看少亏的累计R会把少做交易也当成质量改善。单笔集中度也会漏掉同一波跨交易所盈利。
- **有效路径**：将归档V1多头和V8双向身份分开，统一实际风险R与费用；每月只用过去90天已平仓影子交易形成名单，保留原进出场，和100个同资格等量随机资产名单比较，并拆出币种贡献、平均R、胜率和原10R丢失。V8双向少亏1551.86R，其中USDC解释51.27%，仍亏且漏56笔10R；V8多头平均R反而变差。前后年资产平均R排序相关接近零。
- **通用规则**：先区分成本不适配、单一行情集中、策略不适配和长期资产质量。输出事后排行榜与因果准入结果时必须分表，固定账本删除不得冒充重新运行的可执行账户。收益较好的黑名单结果还需成本归因和尾部保留核对。
