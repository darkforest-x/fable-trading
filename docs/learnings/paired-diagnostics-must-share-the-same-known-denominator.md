# 配对归因的两臂均值必须使用相同已知分母

- **问题**：当比较组里只有一臂收益未知，分别对原臂、新臂、差值使用 skipna 均值，会出现“新均值减旧均值不等于均值变化”。
- **死胡同**：仅在表上写 n/known 不能修复各列偷偷使用不同成员的问题；主显著性检验拒绝未知，也不能保证附属归因表可靠。
- **有效路径**：V39 在真实收益回放前加入合成反例。整组比较只有全部原成员已知才给数字，否则共同保留未知，同时列出原 n、known、unknown；主绝对配对超额也要求所有原组已知。
- **通用规则**：凡是需要相减或归因的统计列，都先证明分母和成员一致。不能用 pandas 的默认跳过空值代替样本口径。
- **牵连**：`owner_k1k2_delayed_entry.diagnostic_groups` 与 `tests/test_owner_k1k2_delayed_entry.py`；未修改任何入场或退出参数。
