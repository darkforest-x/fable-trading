# 形成过滤可能重复触发器已经筛过的信息

- **问题**：Owner要减少可见IMACD启动噪音，并保留大趋势。V1把收拢限定在近零段内，误删先形成密集的赢家；V2改用此前12根宽度中位数对更早120根背景。
- **死胡同**：修复误删就认为已获得降噪。V2在2025保留97.33%/97.13%/98.52%的15m/1H/4H原始箭头，净亏损与总信号削减几乎等比例；4H尾部保留恢复98.65%，但组合净收益仍16.11%→15.75%。
- **有效路径**：同时列信号留存、亏损削减、赢家保留与相同成本/退出的组合增量，发现新代理和已有近零释放条件高度重合，新增区分力不足。此结论只针对固定12/120相对宽度定义，不代表所有密集过程。
- **通用规则**：为触发器添加环境门前，先量化它在原事件集合中的覆盖及条件增量。几乎全通过的条件可能解释形态，却不足以筛选质量；不能通过不断收紧阈值来补救而不重新登记实验。
