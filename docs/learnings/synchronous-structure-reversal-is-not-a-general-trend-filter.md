# 同根结构反转不是通用趋势过滤器

- **问题**：固定K1入口持续性未证实，能否要求K1本根同时建立/反转结构来减少盘整误单。
- **死胡同**：将持久同向结构与当前结构事件都称“结构共振”，容易把完全不同的样本规模当成同一优化。冻结10/10事件仅接受首次建立或反向翻转，已有同向状态再次突破不会触发。
- **有效路径**：在不看新条件收益前，仅审支持。V25全251入口250可观察；旧持久同向137笔中128笔没有本根同向事件，只有9笔接受；四半年1/2/4/2、8活跃月，四项事前支持门均失败。9笔均来自已知相反状态翻转，并非首次建立。
- **通用规则**：先明确共振是“状态存在”还是“同一根发生事件”，再核样本覆盖与时钟对齐。过滤掉96%以上入口并不自动等于质量提高；支持不足应停止该配置收益探索，不能看9笔赢家后降低样本门或改pivot长度。
- **牵连**：V25 `results/counts.csv.gz`、`case_context.csv.gz`、`summary.json`。这是支持不足而非已证明亏损；V24负持续性结论仍在，盈利目标仍未完成。
