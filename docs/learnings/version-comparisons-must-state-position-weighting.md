# 版本比较必须说明仓位权重，不能把累计R当成所有资金口径

- **问题**：V2.21与V2.30改变了入场、信号数量和止损宽度。累计净R与等名义金额的平均净收益给出了不同的排序，ETH固定10R甚至出现相反正负号。
- **死胡同**：看到累计净R为负就概括为任何仓位方式都亏损。窄止损对应小风险分母；等风险比较会给这类交易更大的名义仓位，与每笔同金额不是同一种组合。此前V2.30“全部亏损”的结论仅适用于其明确展示的累计净R，需要补充资金权重边界。
- **有效路径**：冻结原生逐笔成交，分别汇总原始风险R与入场名义金额收益，并让匹配随机对照使用同一权重。V2.30 ETH固定10R为−39.4344R，却平均每笔+17.8487bp；匹配随机为−31.7950bp，多重比较校正后p=0.7374，不能据此升级默认。V2.21原版同目标为−30.6417R、每笔−5.2418bp。
- **通用规则**：止损或信号数量变化时，同表列出信号数、风险口径和名义金额口径；说明复利、资金占用和并发仓位是否建模。更少的负R不能单独证明新旧版本中哪一个更赚钱。
- **牵连**：`range_v221_compare.py`、`range_v221_weighting.py`及其测试；原生执行结果全部保留，不因换汇总方式重跑交易。等名义平均收益仍不是账户资金曲线；未变更Pine、仓位或实盘。
