# 趋势背景必须早于它试图解释的触发 K 线

- **问题**：想用 4h 共振区分 1h 强势穿线后的趋势与盘整，但触发 K1 本身可能改变 4h 的颜色和斜率。
- **死胡同**：在 K1 收盘后读取包含 K1 的新 4h，再说“入场前已经顺大趋势”；即使交易执行没有前视，背景解释仍混入了触发自身的贡献。只限制 4h 状态年龄也漏掉中间原始行情缺口。
- **有效路径**：背景连接时钟固定为 K1 开始，完整 4h 的可用时间不得晚于它；同时校验原始 5m 连续段。所有比较臂共享有效背景支持，控制交易也匹配该背景和同一过滤门。
- **通用规则**：先定义“背景早于哪个事件”，再做 backward join；当前可交易信息与事前解释变量不是同一个时间口径。
- **牵连**：V3 的 context_available、context_valid、共同样本支持和匹配对照；不改既有 K1 执行规则。
