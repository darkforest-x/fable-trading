# 复用负例要先对齐目标与样本分布，不能只比较图片数量

- **问题**：Owner 要求 v6 延续 Grade-A 的三窗口思路，并询问能否直接复用 Grade-A 的 24,000 张负图。清单核对发现它们只有 3,129 个独立事件，全部为 15m；v6 的 1,841 个正事件只有 58 个为 15m。
- **死胡同**：把旧负图整包搬入多周期正例，会同时改变周期分布、图像表示和位置分布。旧验证事件也不能因为换了数据集名称就进入新训练集。反过来，因旧负例含密集形态就全部判错，同样忽略了“密集”与“密集后启动”两个不同检测目标。
- **有效路径**：先按事件而非图片去重，列出周期、时间切分和标签语义；旧训练事件只进入候选池，重新验证可见窗口、核心保护区、数据源与渲染一致性。困难负例必须在可见信息中不符合目标；未来交易亏损不是形态不存在的证据。本轮仅完成兼容性清点，未把候选升级为可训练标签。
- **通用规则**：复用负例前先问“它为什么是负例、与哪些正例配对、在决策时点能否判定”。数量比例是后续选择，不能替代这些条件。
- **牵连**：`yoyo/datasets/ma_morphology_threeview.py` 的 `negative_inventory`；`experiments/active/exp-ma-morphology-v6-threeview-20260925-v1/negative_reuse_audit.json`；原始 Grade-A 负例协议和 v6 的形态标签纠错记录。负例审核未完成时保持 `training_ready=false`。
