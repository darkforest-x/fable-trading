# 图表来源必须执行它声明的查询

- **问题**：V37 散点来自已核验 CSV 和 pandas，记录了来源路径，但原生报告验证仍拒绝缺少实际 SQL 的图表来源。
- **错误捷径**：为了通过校验附上一条没有执行过的 SQL；这会把可追溯性要求变成伪造证据。
- **有效路径**：仅从已冻结的 63 个逐笔比较加载内存 SQLite，实际执行散点查询，再逐字段精确对回先前报告数据；来源记录查询、表名和执行时间。
- **通用规则**：数据算对、来源路径正确和来源查询已执行是不同的验证维度。新增展示协议所需的证据，不得重算经济结果或静默覆盖失败版本。
- **证据**：V37 artifact_reviewed 验证失败；0791e19 构建 artifact_final 后原生验证通过。最终只有结构验收，不冒充移动端视觉验收。
