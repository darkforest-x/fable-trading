# 稀有事件模型的高分不等于高胜率

- **问题**：为了从全原始信号提高10R命中率，直觉是不断抬高分类器概率门槛，只留最有把握的单子。
- **死胡同**：把模型输出当作已知成功概率。V4时间外28,982个已结束候选中，逻辑回归预测5%至10%的89条实际0个10R，LightGBM预测5%以上的107条仅2个；最高1%门槛也没有比5%至20%更可靠。
- **有效路径**：先用过去未拟合样本设分数分位，下一季度报告实际命中、覆盖、召回、概率分箱和简单单特征基线。这里两模型AUC约0.595/0.604，低于负风险距离0.626；复杂模型不能自动获得新的预测信息。
- **通用规则**：概率、排序能力和扣费经济是三个问题，要分别验证。单调概率校准可以修正数值解释，却不能单靠改概率刻度改变原有排序；低基率和少量赢家需要保留失败与不确定性。
- **牵连**：`yoyo/evaluation/spike_10r_models.py`、`spike_10r_model_study.py`，`analysis/p1_spike_10r_model_v4_20260921.md`。这些是暴露历史的探索结果，不是实盘胜率或仓位依据。
