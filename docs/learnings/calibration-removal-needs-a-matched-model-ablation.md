# 发现校准压低分数，不等于删除校准就能修好模型

- **问题**：BTC 当周三笔事后盈利交易全部被旧评分过滤，校准将原始约 23%–30% 压到约 10%；需要区分分数压缩、预测能力和实际交易收益。
- **死胡同**：把校准压缩当成唯一病因，或把币种拆开、换树模型、删除触达序号一起做，再以三笔全部放行为成功。冻结对照显示，仅删除校准，BTC 近侧净收益从 −10.19R 到 −10.58R，ETH 从 −9.72R 到 −15.59R；XAU 同一 210 候选上从 +1.43R 到 −20.69R。
- **有效路径**：复用同一原生成交与费用账本，每步只改币种拆分、校准、训练截止、模型、净收益目标或触达序号之一；按每步共同时间样本比较。最终 ETH 近侧净收益为 +7.61R，但置信区间仍跨零；BTC 近侧与 XAU 仍亏损，没有因工程重建而获得盈利资格。
- **通用规则**：先复算评分并解释两个阶段，再用固定成本、共同时间覆盖的逐步对照验证修复假设；修复评分机制、放行某笔事后赢家和证明交易优势是三件不同的事。
- **牵连**：`experiments/active/exp-btc-eth-xau-1618-models-20261031-v2/`；0.7% 初始止损、maker 2bp / taker 5bp、纽约周结算；独立 R 非账户收益。排序诊断另遵循 [同一折内比较分数](walkforward-model-scores-must-not-be-pooled-across-folds.md)，不混排不同季度模型。
