# 空标签禁入区必须检查每张图的完整可见窗口

- **问题**：旧人工正框与当前自动负例核对时，只比负例的伪核心时间会漏掉背景图右侧已经出现的目标。今回原核心比较只命中1个负事件，逐张可见窗检查命中2个、15张变体。
- **死胡同**：只比较原框与negative pseudo-core，或拿多个裁剪窗的最大包络代替每张真实输入；前者漏检，后者可能把不曾显示的间隙算成冲突。同币跨交易所也不能直接视为相同图像事件。
- **有效路径**：固定交易所与标准合约身份，再逐variant检查完整可见窗与原人工框、派生核心的时间交集；保留事件、原框和图像三层ID。NIGHT的8张负图完整包含旧核心，QTUM另有2张完整包含旧核心；这些是复核候选，时间交集本身不是重新确认形态。
- **通用规则**：空标签是在断言整张输入没有目标，因此禁入检查必须覆盖整张输入；统计按独立事件去重，原框别名保留到语义复核之后再处理。
