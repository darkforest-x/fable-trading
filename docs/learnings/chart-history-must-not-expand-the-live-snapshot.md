# Historical browsing must not expand the live analytical snapshot

- **问题**：2026-10-26，图表每个周期的 720 根限制让 BTC/ETH/XAU 无法继续回看，周一高低点和 1.618 线也只有最近一周。
- **死胡同**：只去掉渲染切片不会增加 API 数据；直接扩大共享最新快照会牵动执行上下文和周期刷新。另一个误判是把合约上市时间当成 API 最早数据：实测 BTC/ETH 日线到 2020-01-01，再往前返回空页，早于此的上市日期不能证明数据可读。空页必须保留重试而不能宣称已取完。
- **有效路径**：保留实时/分析快照 720 根，三种固定合约另走按需原生 K 线分页；刷新合并已读历史，时间戳锚点保持视野。所有币按可见周单独读取完整纽约周一的 5m 数据，复用 DST 日历；每条线拥有自己的起点和周末到期边界，缩放只考虑可见线段。请求随页面暂停，持久化仍只存有界公开快照。
- **通用规则**：先分清“最新工作集”“浏览历史”“参考线有效时间”三个范围。放宽一个范围不能隐式扩大另两个；扩展历史要验证原生周期、游标前进、空页、合约切换与追加前后的时间锚点。
- **牵连**：`monday_chart_history.py`、`chart-history.js`、`monday-fib-chart.js`、`range-chart.js`；Stitch 画板 `b6adf7933bf9478c8113d8d2d9a20660`。实测 4H 从 720 增至 1020 根后两端时间不变；图表库应用新范围是异步的，浏览器断言须等待或用预期范围计算锚点。
