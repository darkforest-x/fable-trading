# 历史行情精度与策略止损取整必须分开

- **问题**：PEPE 原生框架适配拒绝历史 OHLC：364,633 根行情中有 189,752 个价格字段不在策略采用的 1e-9 止损网格上。
- **死胡同**：把策略止损 tick 直接作为框架历史行情精度。这样会拒绝合法旧行情，或者悄悄改变开仓、跳空成交和 R 分母。
- **有效路径**：只读核对发现所有历史 OHLC 均在 1e-10 网格上。框架用 1e-10 精度保留原价，策略仍按既定 1e-9 取整保护价；两者独立配置，新增早期微小币价成交测试。
- **通用规则**：回放跨越交易所 tick 变更的历史时，先验证历史价格表示精度；策略保护价网格是另一项冻结参数。精度适配不得偷偷改成新的交易规则。
- **牵连**：`nautilus_independent.run_native` 的 `market_tick` 与 `tick`，`exp-range-nautilus-20261020-v1/config.json`。本次只补足原冻结账本语义，不推断真实历史最小下单量或资金容量。
