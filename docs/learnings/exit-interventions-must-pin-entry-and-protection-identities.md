# 测试保本退出前，先冻结入场和原有保护线的身份

- **问题**：同名 V1 已有原生回放和共同执行回放。两者入场数量接近，但原生保护以信号收盘参考 R 更新，共同执行以实际次开风险并保留另一版本的反向退出。把两个结果拼在一起会将原有退出差异误归因于新保本规则。
- **死胡同**：只寻找一张最终交易账本就判断无法改退出，或直接用方便的共同执行引擎代替原生。前者忽略了已有因果逐根保护函数；后者能给出数字，却没有回答原版本的问题。
- **有效路径**：先定位原始逐根退出函数、输入来源和状态更新顺序，复现旧账本的退出时间、价格与净 R。随后只改变 0.5R 触发保护这一项。原生和共同执行分别命名；固定原入场比较与提前退出后重入的串行比较分别保留。
- **通用规则**：退出实验需要冻结四个身份：入场事件、真实成交价和初始风险、原保护线的参考坐标、退出事件的优先级。净保本必须另外考虑成本。整单最终 MFE 只能是结果，不能用于倒推早先应当生效的保护。
