# 尚未上市造成的空分区不是数据源损坏

- **问题**：用当前缓存的山寨币合约回放早期日线阶段时，部分文件在阶段截止日前没有任何 K 线；把空结果统一当成加载失败会让正常的“当时尚未上市”中断整个研究。
- **死胡同**：仅检查阶段过滤后的 DataFrame 是否为空，无法区分文件损坏、字段缺失、时间戳异常和合约尚未上市；静默跳过同样危险，因为会掩盖真实的数据质量故障。
- **有效路径**：先验证源文件与 schema，再检查源数据最早时间；源文件有效且首根 K 线晚于阶段截止日时显式记录 `not_listed_yet`，只有格式或时间范围本应覆盖却为空时才判为错误。同时冻结当前合约清单，并在报告中声明这仍不是 point-in-time 历史上市池。
- **通用规则**：时间分区加载器必须把“合法空分区”做成一等状态并输出计数；合法为空不等于历史宇宙无偏，上市与退市偏差仍需单独披露。
- **牵连**：山寨币日线 15m→1D 聚合、分阶段读取 receipt、当前 52 币缓存宇宙、幸存者偏差与上市时间偏差。
