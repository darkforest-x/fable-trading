# 入场门零交易的月份仍属于比较总体

- **问题**：全局行情门可能让某个月没有交易。比较原策略与过滤后的每笔均值时，“共同月份”可能被误读为双方都发生交易的月份。
- **死胡同**：仅取交易月份交集，会因过滤后的结果改变抽样总体，把原策略在被彻底回避月份的交易排除；把一臂全空直接返回 months=0，则丢掉了已知的零交易事实。两种实现都不等于预定期间的策略比较。
- **有效路径**：在读取本轮门收益前澄清实验计划：由 START/SPLIT/END 预定同一日历网格，所有币在月份块内一起重抽样；每臂保留各自交易数与收益和，零交易月保留零计数。每次抽样重新计算各自总分母，仅总分母为零的 replicate 不计算均值，并报告有效重复次数和空月数。完全空臂保留网格，均值区间为未知。
- **通用规则**：定义比较总体用预定时间或事件全集，不能用处理后是否有成交来选择总体。总收益与每笔均值分开报告；均值不能给零交易臂填零充数。
- **牵连**：`yoyo/evaluation/spike_joint_btc_report.py:differences`；同模块测试中的固定日历/全空臂反例；`experiments/active/exp-spike-joint-btc-gate-20260922-v1/PROJECT_PLAN.md`。月块自相关假设仍需在报告说明，保留日历总体不意味着消除全部市场依赖。
