# 高评分尾部的胜率必须固定评分时点和计数单位

- **问题**：2026-10-31 查询八个周一 1.618 策略在评分严格大于 0.8、0.9 时的历史胜率。评分是模型输出，策略有不同退出、保本和仓位规则，不能直接把 0.9 解释为每个策略 90% 胜率。
- **死胡同**：直接读取旧策略手册会混入触价收盘后评分；把所有净收益大于零的行都当胜单又会将约 0.0085bp 的保本残差计为盈利。把加仓腿数或多个共用信号的策略相加，也不能增加独立证据。本次识别并排除了这些口径，没有重新运行交易引擎。
- **有效路径**：复用 `exp-monday-limit-paper-accounts-20261028-v1` 的原生逐笔成交，联结 `exp-monday-limit-score-leak-audit-20261027-v1/scores_causal.csv.gz` 的 `causal`。沿用逐笔较差 OHLC/OLHC 路径、原费用及非目标退出 10bp 滑点、原坏事件排除和 `net > 1bp` 胜单口径；先完整复现八个策略原摘要的总笔数和胜率，再按严格阈值过滤。全历史大于 0.8 有 127 次触价事件，大于 0.9 有 25 次；2026 年后者仅 9 次。V2 60m 为 101/127 与 16/25，V3 为 62/127 与 9/25；加仓策略按腿计数，不能将 205 腿称为 205 次独立事件。
- **通用规则**：查询条件胜率先固定评分时点、分母单位、费用和保本容差；同时给出胜单数与总数，并说明嵌套阈值、跨策略重叠和时间范围。独立成交样本不能冒充受资金约束的账户成交；分数尾部历史失效不能直接推断未来必然失效或给出新的最优阈值。
- **牵连**：原规则位于 `yoyo/evaluation/monday_limit_paper_accounts.py`；本次原始聚合和来源记录位于 `output/analysis/monday-score-tail-winrates-20261031/`。所有八个原摘要计数及胜率核对一致。仅做既有结果的描述性分组，没有重新拟合、改变门槛、重放交易、生成报告或变更生产资格；未新增完整匹配对照检验，不据此宣称策略超额收益。
