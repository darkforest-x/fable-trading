# 在自选负样本上算 AUC,量的是你的采样口径,不是你的问题

- **问题**:要回答「owner 的标注能不能只用盘口信息学出来」。
  做法是拿金标当正类、另选一批 bar 当负类,训模型看 AUC。
- **死胡同**:换三种负样本,得到三个都"很高"的答案,而它们互相矛盾:

  ```
  vs 随机 bar               AUC 0.989
  vs 机械密集 bar           AUC 0.999
  vs 同门 bar(密集+跌破)   AUC 0.994
  ```

  第一版 0.9992 是同义反复:金标由 `star_side`(跌破均线束 + 8根跌幅≥1ATR)筛出,
  而负样本只按 spread 筛,**特征里恰好含这些量**——模型重学了我的筛选规则。
  加上同一道门之后仍是 0.994,病因反了过来:负样本被要求"机械密集"(spread 很紧),
  而**正样本没有这个要求**(owner 的框只有 31% 符合机械密集),
  于是模型改用「spread 不够紧 = 正样本」分类。
  **每换一次负样本口径,答案就换一次——这个设计回答不了任何问题。**
- **有效路径**:把负样本换成**其余所有 bar**,并改问检测器真正被考核的量:
  **在给定开火密度下的精度**。

  ```
  基础率 0.0384%(1685 金标 / 4,392,738 bar)
  0.2~1.0 条/币·月(owner 自己的标注密度)  → 命中 0,精度 0.00%
  10 条/币·月                             → 0.26%,6.8x 基础率
  48.8(v9 的开火率)                      → 0.23%,召回 11.8%
  ```

  负样本不是挑的,结论就不随口径变化。**在 owner 自己的密度下,47 个因果特征
  一个金标都定位不到。**
- **通用规则**:**判别力指标必须配一个不由你选择的负样本集。**
  只要负类是挑出来的,AUC/精度就同时在量「模型」和「你的挑法」,而后者通常占主导。
  排查信号:同一个问题换负样本口径后答案变化很大,或 AUC 高得反常(>0.95)。
  推论:检测类问题优先报**固定预算下的精度/召回**(取前 N),
  N 取业务上真实允许的开火量;这个量纲无法靠采样美化。
