# 持仓历史先核币种与净额，再谈账户收益和可重复优势

- **问题**：Owner提供欧易多年持仓CSV，希望判断能否盈利并制定交易系统。正的收益额总和容易被当成净盈利，某一方向或长持仓分组盈利也容易被当成可执行优势。
- **死胡同**：初步把所有金额列直接相加会把一条BTC币本位数量混进USDT；将平仓时长当入场条件、删掉强平当作已实现改进，都使用了结局信息。累计持仓更新时间损益也不能还原账户权益或盘中回撤。
- **有效路径**：先按合约币种分账，逐行用合约面值和方向复算价格收益，明确CSV毛收益与有符号手续费/资金费/清算费。部分平仓单独说明；以年度与最大赢家剔除敏感性检查利润集中。官方API定义与CSV运行结果相互核准，但保留账户现金流与settledPnl等未知项。
- **通用规则**：个人交易复盘需要分开回答四个问题：账面发生什么、账户资金增加多少、哪种行为相关、哪套事前规则能重复。缺少权益和完整成交时，只回答可识别部分；新系统必须进入未验证模拟阶段，不能从持仓结果推导因果盈利规则。
- **牵连**：`yoyo/evaluation/owner_okx_history.py`、`yoyo/evaluation/owner_okx_report.py`、`analysis/p1_owner_okx_history_20260916.md`。本轮附件获owner授权；没有读取项目行情holdout，没有改变交易执行或训练资格。
