# Rebase the remaining position only after replacement protection is verified

- **问题**：同向加仓会改变交易所均价和剩余数量，单纯删去禁止加仓检查会令旧止损数量及 R 止盈基线失配。
- **死胡同**：按原始数量加权会把已经平掉的仓位加回来；先撤旧保护再下新保护会留下缺口；超时重发会重复生成保护单。
- **有效路径**：对当前剩余数量加权，沿用当前止损与杠杆，预览约束整笔风险及同类保证金额度。每次成交量变化持久化独立保护代次，先核对新的整仓止损与止盈，再撤旧保护，最后提交合并基线。原订单、实际累计成交、生命周期净盈亏和总成交张数独立保留。常规限价首次部分成交需服务在线补齐保护，止损覆盖剩余待成交额度；不能把附带保护的接受回执当作部分成交已受保护的证据。
- **通用规则**：数量变更是交易意图、账本和交易所保护的联合状态机；每一步须可重启恢复，禁止把 unknown 当 failed 重发。
