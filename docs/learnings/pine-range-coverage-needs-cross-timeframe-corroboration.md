# Pine 移植要核对区间覆盖，不能只核对信号公式

- **问题**：信号中心的周一范围验证完整288根5m。直接移植后，BTC参考一致，但TradingView的PENG最新周一仅282根5m，所有历史周被严格门挡住，图上没有参考框。
- **死胡同**：编译通过、BTC单币对上都不能证明多币移植完成；直接放宽“完整周一”会把未知历史缺口伪装成完整范围。也不能靠增加calc_bars_count承诺所有图表周期拥有同样历史深度。
- **有效路径**：优先完整5m；另用独立完整连续48根30m覆盖同一个纽约周一，仅当两种粒度的周边界、高点、低点完全相同才认可稀疏5m的原极值，不合成缺失K线。PENG在TV上重现首笔参考59.52348/59.61/48.65652与2.0050855–6.7438742R范围，和网页缓存核对一致。观察到缺柱，不把其原因断言为零成交。
- **通用规则**：跨平台移植按“日历边界、价格极值、覆盖完整性、确认时间、历史容量”分别验收。完整高一档聚合数据可佐证极值，但不能恢复缺失小周期路径；历史范围仍受TV数据与订阅限制。关键K缓存跟随可见窗口重建，不能用最近N根FIFO让旧框失去高亮。
