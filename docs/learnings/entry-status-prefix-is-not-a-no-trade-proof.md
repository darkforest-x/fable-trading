# 入场状态前缀不能证明没有成交

- **问题**：V36 复核发现把所有 `entry_` 状态计为零收益，会把缺少可执行价格的 `entry_missing` 当作已知未成交，进而污染完整配对。
- **死胡同**：状态名字相似并不代表信息状态相同；“看到开盘在止损外，明确拒单”和“缺开盘数据，无法判定”不能统一处理。真实源完备也不能代替这条接口测试。
- **有效路径**：只将已观察开盘风险无效的 `entry_invalid_risk` 作为零成交白名单。缺价/其他无效保持未知，完整配对不求残缺均值，单仓账本保守阻断后续占仓；增加反例测试。
- **通用规则**：现金零收益需要未成交的正面证据，不能由字符串前缀或 NaN 填充推断。
- **牵连**：V36 contribution、paired_contrasts、describe、独立单仓账本；旧引擎和历史结果不改。
