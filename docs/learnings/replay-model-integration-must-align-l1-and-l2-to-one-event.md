# 回放式模型串联必须让 L1 与 L2 对齐同一事件

- **问题**：L1 与 L2 各自成功推理并不能证明模型链已接通；若 L1 用一张训练图、L2 用另一条特征行，组合出来的结论没有事件级语义。
- **死胡同**：分别做两个 component smoke 很快，也能看到两个模型都有输出，但 UI 会把互不相关的输出并排呈现成一次联合判断，形成比报错更危险的假成功。
- **有效路径**：以 L2 ledger 的事件为唯一锚点，读取其 `input_pixel_sha256` 和方向，从哈希固定的 pre-holdout 快照重建同一根事件的 L1 输入；先逐字节验证像素哈希，再对这张图跑 L1、对同一行跑对应方向的 L2。
- **通用规则**：端到端模型 UI 的最小证据不是“两个 runtime 都返回 200”，而是事件 ID、数据快照、渲染像素和方向路由四项全部一致；不满足时只能标成组件测试。
- **牵连**：`yoyo/console/replay.py`、`yoyo/console/worker.py`、L2 feature ledger、L1 pre-holdout K 线快照、holdout 不可读约束、运行时只写 `/tmp`。
