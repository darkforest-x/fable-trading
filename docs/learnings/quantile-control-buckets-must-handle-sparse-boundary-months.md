# 分位数控制桶必须处理稀疏边界月份

- **问题**：按月构造 ATR 五分位匹配控制时，边界月只有少于 5 个合格时点，`qcut(q=5)` 生成 NA，随后转整数失败，开发回测在结果收据写盘前中止。
- **死胡同**：假设每个月都有足够样本，并无条件固定五个分位桶。主样本很密不代表经过时间窗、完整路径和信号排除后，边界月控制池仍然密集。
- **有效路径**：每月使用 `min(5, 当月合格样本数)` 个分位桶，并对单点退化桶明确归为 0；加两行边界月回归测试。匹配条件没有放宽，只让分桶在可定义范围内工作。
- **通用规则**：时间分层后的 quantile binning 必须先检查组内有效样本量；桶数不得大于样本数，并为单点/常数/重复值提供确定性退化规则。
- **牵连**：`atr_quintiles()`、月×UTC时段×ATR桶匹配、Pandas `qcut`、开发/验证边界。
