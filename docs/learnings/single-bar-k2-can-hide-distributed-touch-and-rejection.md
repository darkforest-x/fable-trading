# 单根 K2 会漏掉跨多根完成的触线与拒绝

- **问题**：Owner 指定的 BTCUSDT.P 15m 走势中，11:30 的空头 K1、后续均线下方路径和最终下跌都清晰，但 Pine 没有产生信号。逐根核对发现 12:15 完成了均线触碰，12:45 才完成强拒绝收盘；现有规则要求同一根 K2 同时完成两件事。
- **死胡同**：只看跌势结果便把漏报归因于 gap 太短、信号冷却或 TradingView 没刷新；以及只放宽 `k2_min_rejection_close_location` 或近线容差。12:15 的拒绝位置只有 0.537（门槛 0.65）且按下一根开盘计的 fee/risk 为 2.04R；12:45 虽有 0.725 的拒绝位置，但最高价仍离 SMA40 0.687ATR，按其自身高点止损的 fee/risk 为 4.38R。单项放宽仍过不了完整门链。
- **有效路径**：先固定可见 K1，再对每一根候选 K2 分开列出触线、影线、实体、拒绝位置、路径与下一开盘经济门。这样确认 K1=11:30 及 gap=3/5 均不是病因；病因是触线与确认分布在不同 K 线，之后才评估是否值得提出“两阶段 K2”。若以 12:15 为 touch bar、12:45 为两根内 confirmation bar，13:00 下一开盘入场并把止损锚定到整个 touch→confirmation 窗口高点 63455.6，则 fee/risk 约 1.20R，和单根 K2 的判断完全不同。
- **通用规则**：视觉漏报先判断形态是单根事件还是多阶段事件。不要用后续行情证明某根 K2 合格；应把 touch bar、confirmation bar、允许延迟、窗口极值止损和下一开盘经济门定义成一个新的因果状态机，再单独回测。
