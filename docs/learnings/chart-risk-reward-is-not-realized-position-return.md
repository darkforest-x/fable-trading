# 分批退出图上的盈亏比不能替代实际仓位收益

- **问题**：整理 RektProof 2020 年 BTC 案例时，结束帖自报 6.64R，图上工具也显示 6.64，容易误以为两条独立证据已互相印证。
- **死胡同**：按工具的入场、原止损和最终目标计算整段价差，只会复述同一个图示值；管理图已经注明分三批退出，且 XBTUSD 为反向合约，直接套线性加权价差也无法核验真实收益。
- **有效路径**：按公开时间联结计划、持仓、分批和结束原图，分别记录作者自报、工具值与可见仓位变化；缺数量、合约结算和费用时不计算“已验证实得 R”。旧聊天截图只在首次公开节点揭示。
- **通用规则**：看到收益数字先核对口径及来源独立性，再找成交数量和管理路径。两个相同数字可能只是同一工具值的重复引用。
