# 盈亏比参考框的价位时钟不能覆盖原信号时钟

- **问题**：Owner 希望在 IMACD 信号 K 线上恢复熟悉的多空红绿框，但历史框使用下一根开盘入场，当前信号标记使用本根确认收盘价。
- **死胡同**：未采用直接复制旧策略整个进出场分支的做法。它会把绘图请求变成信号规则变更，并可能把尚未知晓的下一根开盘价写回信号时点。
- **有效路径**：保留原信号分支，独立显示层消费已确认的可见释放。收盘参考模式在信号当根绘制；下一根开盘模式只在下一根出现后用其固定 open 绘制。Pine 实时 rollback 下每 tick 重建下一根开盘图形，避免只在 isnew 创建后消失。
- **通用规则**：复用图形样式前，先分清信号确认时间、参考入场时间与真实成交。显示输入不是经过验证的交易参数；不要让参考止损或目标反过来过滤信号。
- **牵连**：`yoyo/evaluation/pine/imacd_dense_mtf_v2_4.pine`；新增图形独立队列及完整对象预算；原副图、六均线、信号与警报代码保持一致。旧信号极值与当前 open 为下一根模式唯一价格输入。
