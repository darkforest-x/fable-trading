# 局部拥挤不能通过删除全图历史来解决

- **问题**：Owner 要减少同一区域的重叠趋势线，V12.1 却擅自设置全图最多3条，丢掉了复盘所需的历史。
- **死胡同**：把对象预算当成需求，只有最新事件和当前线，截图虽然空了却没有满足历史分析用途。上一条关于全局密度预算的笔记只能解释实现动机，不能当作用户已认可的产品规则。
- **有效路径**：V12.2 恢复多个历史区域；只在同一主高点附近按冻结的时间与价格范围整理一簇线。普通历史线淡、联合线较亮、当前候选清楚。区域范围不随新成员链式扩大；线和标记仍成组管理。
- **通用规则**：先保留用户需要的信息，再处理局部重复与视觉层次。用户说“太多”时，必须区分同一区域的密度与整张图的历史覆盖，不能替用户设全局内容删减。
- **牵连**：独立的 `spike_burst_v12_2.pine` / TV 私有脚本，旧版本保留；历史资源保留上限40组与局部3组是两种不同约束。检测、配对和风险计算不变。
