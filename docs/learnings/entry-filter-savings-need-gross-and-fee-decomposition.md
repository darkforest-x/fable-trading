# 入场过滤的净减亏必须拆成毛收益和费用变化

- **问题**：V22 外部 rank50 小时变化门让全251机会净收益改善5.5732bp，是否说明共振有效？
- **死胡同**：只看总亏损缩小会奖励任何少交易的规则。129次放弃省2580事件bp成本，却丢失1181.1392事件bp毛收益；保留122笔的每笔毛收益也由基准+3.2310降到−3.0341bp。把绝对位置改为变化方向，并未解决这个筛选问题。
- **有效路径**：用原身份逐笔对齐参加与放弃，分解净增量=毛增量−费用增量；再在同154匹配组上比较病例D与控制D。病例+7.2528、控制+7.0770，增量I仅+.1758bp，区间跨零。97未匹配仍未知。避97亏单同时漏32赢家，不能包装成只消除了震荡。
- **通用规则**：任何入场门先同时报执行笔数、每笔毛/净、全机会毛/净、实际费用变化和同分母匹配增量。持仓后发生的盈利半仓或最终赢家身份不能回填成入场特征。负面的变化门不能直接反转或继续选阈值宣称有效。
