# 整框平移的提交结果不能直接当成形态边界修正

- **问题**：2026-09-08 首批 72 份 HL2 提交中，57 份坐标变化全部保留原宽高，56 份右移。按主图实际 `plot_w/(n_bars-1)` 换算，中位右移 2.517 根；51 份保留框里 49 份至少切入一根框内中心 K 的实体。
- **死胡同**：把人工提交直接当作已校准金标，或看见右移就统一移回原框。前者混淆了操作结果和标注意图，后者把原始弱标签当成正确答案；目视复核发现部分原框本来就已经进入趋势段。也不能据此臆断右键提交有 bug 或用户故意追涨跌。
- **有效路径**：冻结原预框与真实提交，以实际渲染坐标标注 K 线编号；先核对类别/首末根，再查看纵向是否完整包络。主图后的 150 根与核心后的 3–5 根必须使用各自锚点，较晚出现的第二波行情不能全部归因于原核心。逐图给候选边界与疑难说明，保留原始答案并把建议排除在 Gold 之外。
- **通用规则**：人工框批量继承相同尺寸时，先核对交互与框义，不能自动把坐标变化解释为高质量重标注。远期涨跌、完整包住 K 线、标准平台语义是三个不同检查；任何一个通过都不能替代另外两个。
