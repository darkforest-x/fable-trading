# 分批止盈必须按整笔原始仓位加权，费用不能逐片重复

- **问题**：将V8全仓退出改为分批兑现时，容易把半仓实现1R当成整笔赚1R，或对每一片重复扣整笔往返费用；也容易在首片兑现后错误释放单仓名额。
- **死胡同**：按旧交易的最大浮盈直接拆利润，既不知道目标与止损先后，也不知道残仓的后续反向退出和跟踪止损；旧MFE还排除了止损退出bar的新增极值。
- **有效路径**：每个fill记录原始仓位份额、成交价、价差R与加权贡献，份额最终和为1。整笔毛R=qt+(1−q)s，净R再减一次按份额分配的成本c；首片平仓不解除残仓的占仓约束。保护从可观察bar结束后生效，已知开盘与未知bar内路径分别处理。
- **通用规则**：1R平一半、另一半−1R退出，整笔毛收益为0；另一半开仓价退出，毛收益才是0.5R。若前轮债务D、整笔价格风险B，要覆盖债务的残仓保护R≥(D/B+c−qt)/(1−q)，但金额公式不保证价格触及或成交。
- **牵连**：`yoyo/evaluation/spike_partial_exit.py`、`tests/evaluation/test_spike_partial_exit.py`；固定20bp研究成本、原始next-open反向、单仓容量、部分已实现与边界残仓标记。合成测试证明算术/事件顺序，不证明历史盈利或实盘fill。
