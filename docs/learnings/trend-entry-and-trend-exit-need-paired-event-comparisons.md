# 大趋势系统要固定同一批入场，才能发现退出规则切掉了什么

- **问题**：Owner要研究 IMACD 零轴横盘后启动、拿住大趋势；只统计金死叉位置和平均胜率没有回答利润从哪里来。
- **死胡同**：把所有箭头混成同一信号，或事后选大赢家再解释形态，都看不出入场与退出分别贡献多少。最高 MFE 是事后机会，不是已实现收益。
- **有效路径**：冻结34/9、收盘决策和下根开盘成交，固定每个零轴启动的身份，只替换退出：反向交叉、主线回零、主线反向。ETH4h 2025年同30次入场均值从反向交叉退出的−156.04bp变为回零退出的+88.43bp；2023–24年却从+99.90bp降至+6.76bp，必须保留这个反例。进一步按事前声明的零带根数分组，ETH4h≥9根、BTC4h2–8根出现跨时段同号的探索线索，但绝大部分中位数仍负，去掉少数最大赢家会反转结论。
- **通用规则**：先固定母群做配对退出对照，再看少数大趋势是否覆盖全部假启动及成本；记录去掉最大赢家后的变化。未来收益只能用于解释，不能变成入场过滤。匹配随机对照和多重检验不过关时，称候选机制，不能称已证实优势。
- **牵连**：`yoyo/evaluation/imacd_profit_mechanism.py`、`experiments/active/exp-imacd-profit-mechanism-20260907-v2/`。Owner已授权全部日期，每个配置本轮holdout使用1次；历史探索不能重新称为未见终验。20bp是统一成本代理，未包含资金费率与保证金清算。
