# 最平滑的均线不一定最适合密集形态检测

- **问题**：Owner 希望把 ChartPrime 的平滑观感移植成六均线，直觉上会把曲率最低的方案当成更容易被 YOLO 学习的输入；但目标形态同时依赖六线密集、相对次序和启动展开，平滑只是其中一个轴。
- **死胡同**：只比较曲线是否圆滑，或直接把 EMA 换成更慢的 RMA。这样会忽略平滑来自更长记忆和更大滞后；线虽然不抖，却可能长期分层，原来的“六线绳结”不再是同一视觉语义。
- **有效路径**：在同一 BTCUSDT.P 15m 因果前缀、同一 160 根窗口和完全相同的像素坐标轴上，同时量化平均像素曲率与六线包络。该窗口中 RMA6 曲率最低（`0.775 px/bar²`，当前六线为 `1.392`），但中位六线宽度达到 `228.5px`，是当前 `73px` 的 3.13 倍；SMA6 曲率 `0.974`、包络 `40px`，而 HMA6/VWMA6 更活跃。由此把“数值平滑”“滞后/展开”“渲染可见度”拆成独立问题，让 Owner 先看配对图，再决定后续单变量重训臂。
- **通用规则**：为密集/交叉类视觉模型换滤波器时，必须在共用坐标轴上同时检查曲率、相位滞后、线束宽度与交叉拓扑；不能按人眼平滑度单指标选 MA。先做数值不变的 1px→2px 渲染消融，再逐个替换 source 或 family。
