# TradingView 的脚本保存与图表编译必须分别验收

- **问题**：本地 Pine 静态审核通过，不能证明用户账户已保存，也不能证明原生图表可以运行。
- **死胡同**：把静态 plot 预算或编辑器已粘贴当作编译成功；把另一设备活跃提示直接等同于整个编辑器不可用。这些都缺少实际原生证据。
- **有效路径**：本次关闭提示而未点击重新连接，编辑器仍可操作。通过新建私有脚本保存，核对名称和保存版本时间，再添加到图表并观察计算后的图层、风险框和显示模式切换。另行保存图表布局。关闭提示可行是本次观察，不保证所有会话同样可用。
- **通用规则**：分别记录源文件哈希、云端保存证据、编译后图层和实际显示证据；不得用其中一个替代其他步骤。显示品牌升级也不能冒充信号策略优化。
- **牵连**：`yoyo/evaluation/pine/spike_burst_v4.pine`、原生 TradingView 私有脚本、图表布局；不创建警报、不接管另一设备会话、不更改监控和下单路径。
