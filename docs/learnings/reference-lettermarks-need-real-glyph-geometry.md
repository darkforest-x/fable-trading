# 字母图标精修应保留参考字形，而不是重新发明轮廓

- **问题**：Owner 指定沿用黑底白色常规 S，首轮生成却把字母变成细长、收腰的曲线，明显偏离参考。
- **死胡同**：提示词中的“极简”“利落”“优化”无法保证生成路径仍是常规字体。生成稿自述的宽高和居中比例也不能替代真实轮廓检查。
- **有效路径**：回到参考里的普通无衬线字母，让 Stitch 明确采用 Arial Regular，再把真实字形转曲；按字形可见边界计算 512px 高度与居中，不按字体 em 框猜位置。各端从同一矢量母版导出，适配 Android 前景安全区与黑色底层。
- **通用规则**：用户选定熟悉的字母标识时，优先保留字形身份，仅调整比例与留白；生成稿应实看小尺寸，并测量真实轮廓。正式图标不依赖设备是否装有某种字体。
