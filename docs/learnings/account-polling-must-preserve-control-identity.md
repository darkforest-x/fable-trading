# Account polling must preserve control identity

- **问题**：自动账户每 10 秒轮询时整块替换 HTML；浏览器中聚焦表格后，下一轮焦点退回 body，横向阅读位置也会丢失。
- **死胡同**：只恢复选中页签不够，表格、刷新按钮和展开的设置都属于阅读状态；仅比较账户数值也无法覆盖状态和权限变化。
- **有效路径**：固定控件骨架，按区域比较内容；明细变更时保存滚动和焦点，内容不变不替换。权限失效时清除隐藏数值，过时快照的标题与警告保持一致。请求增加超时，并在文档隐藏时终止读取，恢复后用新版本读取。
- **通用规则**：轮询更新数据，不应重建用户正在操作的控件；权限撤销与普通数据刷新必须分别测试。
- **牵连**：`yoyo/monitor/static/okx-execution.js`、`tests/monitor/frontend_okx_execution.test.cjs`；仅影响只读展示，不改变交易权限或执行参数。
