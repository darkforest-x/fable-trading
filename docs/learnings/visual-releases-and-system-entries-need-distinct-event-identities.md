# 视觉释放和系统入场必须拥有独立事件身份

- **问题**：把 Pine 指标移到全市场后台时，醒目的长零轴释放、原密集入场、高周期许可和回踩 K 线同时存在，通知不能把它们压成一个“买入”。
- **死胡同**：按图上醒目的箭头统一解释成交易信号会改变系统。V2.2 的 focus 释放可发生在六均线不密集、没有原系统入场的 bar；md 回零的默认退出也不同于黄金研究中反向才退出的 F01。
- **有效路径**：按 release / entry / exit / retest 分别输出不可变事件，再附密集和 HTF 许可。HTF 必须已在本周期 OPEN 可用，不能仅凭采样时已收盘。通知点位是确认 bar 的收盘价，不能标成实际成交价。
- **通用规则**：先冻结每种可视对象代表的事实与可用时刻，再迁移计算与通知；显示事件和交易状态不能共用一个布尔值。
- **牵连**：`yoyo/monitor/signals.py`、`yoyo/monitor/service.py`、`yoyo/monitor/telegram.py`；原始 `yoyo/evaluation/pine/imacd_dense_mtf_v2_2.pine` 保持不变。内存中保持历史起点，重启的有限预热仍不宣称与 TradingView 无限历史逐点等价。
