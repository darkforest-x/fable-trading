# Pine 入场周期选择必须放在固定源周期内部

- **问题**：在跨周期交易框指标中加入5m入场，同时保持1H观察和15m跟踪更新；用户切换图表周期后仍须得到同一套交易记录。
- **死胡同**：把图表上的勾叉直接拿来入场会让交易随图表周期改变；把原15m请求整体改成5m，又会一并改变ATR和跟踪更新频率。
- **有效路径**：保留固定5m源引擎，内部计算5m信号，只对入场资格做5m/15m路由。H1观察先更新，同刻入场继续排除；原15m管理事件原样传入旧仓推进函数。原生夹具同时检查非整刻入场、同刻排除和非整刻不启动/收紧跟踪。
- **通用规则**：多周期选项应明确只控制哪一类事件；图表周期、入场周期和仓位管理周期要独立验证，不能共用一个周期变量。
