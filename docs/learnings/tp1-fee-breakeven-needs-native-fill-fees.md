# TP1 fee breakeven must use actual fill costs before deciding the stop

- **问题**: A cached no-breakeven backtest can be reweighted into equal near/far partial exits, but fee breakeven changes the remaining leg's execution path.
- **死胡同**: Legacy entry-notional round-trip fees cannot simply be subtracted after replay: they would place the stop at the wrong price. Rejecting small TP1 distances to satisfy an old protection precondition would also silently change the entry cohort. A price touch is not the native fill event that authorizes protection.
- **有效路径**: Reuse native target-fill sibling protection with opt-in actual-fill maker/taker fees. Remaining-leg cost breakeven solves long E(1+f_entry)/(1-f_stop), short E(1-f_entry)/(1+f_stop), rounded toward profit. Only a native TP1 fill enables it. If TP1 is still inside that cost price, keep the original stop until a later observed close/open point allows a feasible amendment; retain and count these cases. Gap stop fills can still realize a loss.
- **通用规则**: Costs that affect decisions belong inside the execution model. Do not silently filter infeasible actions or backdate protection to the entry/bar start. Verify equal leg quantities, parent isolation, same-bar fill ordering, native commission/PnL, deferred actions and boundary censoring using constructed event paths. Reuse unchanged fills rather than replaying another engine.
