# 账户统计必须使用完整账本并区分平仓时刻与费用时刻

- **问题**：移动端最近 30 笔记录不能支持全账户统计；部分止盈和费用也有不同的归属时刻。
- **死胡同**：直接汇总界面列表会截断交易；把部分止盈算成胜利会抬高胜率；把已平仓盈亏曲线称作历史净值会遗漏浮盈亏和历史风险。
- **有效路径**：只读 SQLite 同一事务读取完整持仓、平仓记录与费用事件。胜率、平均盈亏比和净 R 按完全平仓归集，费用按执行时刻归集；当前账户概览保持全量口径。无样本返回空值，并明确曲线只是已平仓累计净盈亏。
- **通用规则**：先写清样本单位、时间口径和数据范围，再做图表；不存在的历史净值数据不能用已平仓收益替代。
- **牵连**：`yoyo/discipline_app/statistics.py`、`book.py`、`mobile/src/Statistics.tsx`，覆盖空账本、部分止盈、跨区间及超过 30 笔的验证。
