# 过滤后的盈利因子不能替代原策略大趋势的保留率

- **问题**：V6 加 BB200 压缩及扩张后，最近一年 1H 盈利因子由 1.126 升至 2.133，看起来改善明显，但原策略十笔实际净收益 ≥10R 的交易仅保留了同一入场的一笔。
- **死胡同**：只看更少交易、更高胜率和过滤后仍存在的两笔 ≥10R，容易误报“保住大行情”。过滤会改变单仓占用，可能产生原策略没有执行的新入场；两笔新账本大赢家不等于保留了两笔旧赢家。
- **有效路径**：先冻结不变的退出、成本和逐根回放，再以币种、周期、时间切分、方向、原信号时间联结实际入场。同一入场强校验结果一致；分别报告信号被拒、信号获准但未成交、净收益尾部保留及未来最高浮盈。
- **通用规则**：目标同时包含降噪和抓大趋势时，必须并列报告过滤后每笔质量和原策略尾部保留率；不能只用幸存交易作分母。跨币汇总 PF 与净 R 也是不同权重的诊断，不能混称账户收益。
- **牵连**：`yoyo/evaluation/spike_v6_bb_post.py`、`yoyo/evaluation/spike_v6_bb_charts.py`、`experiments/active/exp-spike-v6-bb-squeeze-20260912-v1/config.json`。本次为固定参数回顾研究，结论不能代替前向确认。
