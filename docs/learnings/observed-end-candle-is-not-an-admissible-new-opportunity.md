# 可读取截止K线不代表可以在截止时刻生成新机会

- **问题**：规则拆解的ARUSDT锚点比旧档案多一条，恰好在2026-09-23 04:00 UTC研究截止时刻。数据允许读取在该时刻闭合的K线，旧研究的机会窗却是右端开区间。
- **死胡同**：只截取原始行情结束时间，把所有得到的信号都作为候选；即便该信号无法成交，它的随机配对仍可能影响分母与对照队列，不能当成无害尾行。
- **有效路径**：原始检测事实先对齐，再对全部变体统一应用decision_clock < end。停止有问题的运行，保留失败档案；完整且不含截止锚点的流才可在来源元数据一致后复用，其他流重新计算。
- **通用规则**：分别定义数据可见边界、候选决策边界、可成交边界及结果成熟边界；不可用其中一个边界代替其他边界。
- **牵连**：`spike_v131_rule_study.py`；规则和匹配随机机会的同分母要求。端点修正不改变历史策略或成本。
