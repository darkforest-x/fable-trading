# 原则先指导行动，再由记录反馈原则

- **问题**：个人交易工作区把复杂打法表单和记账放在首页，缺少日常沉淀判断、用判断开单的主线。Owner 明确要求“原则 → 开单 → 记录”。
- **死胡同**：把七字段打法改名为原则，或把三个菜单重新排序，都不能使简短原则成为实际开单依据；把准备记录当成成交还会污染交易统计。
- **有效路径**：原则独立版本化，复杂打法留作辅助。开单核对全部启用原则，检查版本与写入准备快照放在一个事务；准备沿用同一机会的 watching 状态，成交由本人另行登记。后续原则修改不追改快照，复盘心得只回流为待确认草稿。
- **通用规则**：先确认用户的决策顺序，再安排表单与持久化边界。原则、准备和成交是不同事实；若准备与成交属于同一机会，应复用其生命周期，避免另造一套账。
- **牵连**：`yoyo/research_workspace/manual.py`、`manual_api.py`、`yoyo/monitor/static/manual.js`、对应 Python/Node 测试。OKX 链接只导航，后台没有交易所订单执行；历史打法、计划与事件保留。
