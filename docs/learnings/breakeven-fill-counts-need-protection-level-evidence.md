# 保本成交不能只按 trailing_stop 名称计数

- **问题**：在冻结引擎上增加1R保本时，保本和原ATR跟踪可能共享 `trailing_stop` 退出名称，直接计数会把两种成交混合。
- **死胡同**：仅以退出名称或曾触发保本判定保本成交。保本触发后可能先继续上移保护位，也可能跳空穿过入场价，成交并非零毛收益。
- **有效路径**：保留原撮合名称保证基线可比较；额外检查保本启用状态、退出时有效保护位是否等于入场价、实际成交价与跳空标记。先核对同一批入场的退出差，再独立报告完整串行再入场结果。
- **通用规则**：区分“触发保护”“有效保护位”“成交价”“扣成本收益”四个事实。不能用一个退出标签推断四者相等。
- **牵连**：`yoyo/evaluation/spike_v8_eth3m_be_study.py`，`tests/evaluation/test_spike_v8_eth3m_be_study.py`；本轮0.2%成本与原V8入场不变。
