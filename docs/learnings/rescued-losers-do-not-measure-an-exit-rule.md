# 救回亏单的数量不能衡量退出规则好坏

- **问题**：50 笔回看能看到先涨后亏、止损后再涨的例子，直觉上应放宽止损或提前追踪；但是它们是看到未来后挑出的损失路径。
- **死胡同**：只统计救回几个止损，漏掉同一规则伤害的盈利单；或更换止损后仍直接比较两组原生 R，忽略风险分母和 2R 激活价格也随之改变。影线达到 2R 也不等于收盘减 4ATR 的止损价已能锁住利润。
- **有效路径**：固定原始入场做逐笔反事实，再用全部候选独立重算占仓。同步给出亏转盈、盈转亏、大赢家保留、实际净价格收益，以及按原初始风险换算的 R。V11.2 样本沿用父 V9 止损救回 EIGEN/ETC/ORDI，但也使 BOME/TRUMP/LINK 从盈利变亏损；先验固定的全量回放三项改法均未通过，不能按被救回案例挑规则。
- **通用规则**：每提出一个止损/止盈修复，都同时问“伤害了哪些原本赚钱的路径”。更改风险分母时至少同时比较 bp 和原风险 R；样本救单用于解释机制，全样本与分段收益用于否证该机制是否值得采用。
- **牵连**：`experiments/active/exp-spike-v112-execution-20260919-v1/`，原50笔 sample keys，`spike_v112_execution_ablation.py` 和 `spike_v112_execution_report.py`。结论限于已有归档、冻结三项规则和成本；不构成新参数或实盘许可。
