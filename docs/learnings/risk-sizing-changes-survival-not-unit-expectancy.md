# 风险仓位改变生存路径，不改变单位期望

- **问题**：一个策略把固定 4–13x 杠杆改成每笔 2% 止损风险后，预留验证最大回撤从
  67.66% 降到 19.20%，组合亏损也从 -61.22% 缩到 -1.97%。这种巨大改善很容易被误写成
  “策略已经优化到可盈利”，但每笔净收益仍是 -1.63 bp。
- **死胡同**：只比较最终净值、最大回撤或动态仓位后的 profit factor。仓位规模会改变复利、
  破产路径和不同交易的美元权重，因此这些指标能显著改善，即使完全没有改变任何进出点；
  它们不能证明 alpha 增加。反过来，继续加杠杆追求回测收益只会放大同一个负期望。
- **有效路径**：把判断拆成两层。第一层固定交易时点，先报未加权的毛/净 bp 每笔并与匹配随机
  对照，裁决单位 edge 是否覆盖成本；第二层才比较同一交易序列在不同 sizing 下的组合收益、
  回撤、杠杆和破产风险。本例第一层仍失败，第二层只证明 2% 风险预算是有效的生存 overlay。
- **通用规则**：任何 sizing 实验先做“进出点与单位收益完全相同”的断言。若成立，只允许把
  结论写成风险/资金路径改进；只有未加权净期望和既定经济门也通过，才可以说收益策略改善。
