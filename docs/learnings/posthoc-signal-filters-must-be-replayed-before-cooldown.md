# 事后信号过滤必须在冷却门之前重放

- **问题**：在已接受交易账本上，15m 的 `K1→K2 gap >= 5` 跨两个半年都优于基线；但现有策略有六小时冷却，删掉短间隔交易后，原先因冷却被挡住的后续候选会重新获得入场资格。
- **死胡同**：直接对子集收益取均值，并把它当成新参数的回测结果。这个算法保留了旧策略的冷却占位，既可能低估替代信号，也可能遗漏新序列中的亏损，无法与真实执行顺序同构。
- **有效路径**：把事后分段只当作假设生成器，冻结唯一的 feature/operator/threshold；另开单变量实验，从完整 K1/K2 候选池先应用过滤，再依次重跑风险门、同根排序、冷却、K1 复用与退出状态机，并用更晚时间窗复验。
- **通用规则**：任何会改变信号集合的过滤条件，只要下游存在 cooldown、互斥选择或仓位占用，就必须从过滤点开始重放整个状态机；已成交账本切片不能证明可执行绩效。
- **牵连**：15m `gap_min_bars`、5m/15m K1→K2 候选、六小时 cooldown、`apply_execution_gates`、2024 单变量确认；不涉及 holdout、Pine、ACTIVE 或实盘。
