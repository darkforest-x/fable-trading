DESIGN.md — Spike Quant & Visual AI Research Terminal

1. 品牌愿景与设计哲学 (Design Philosophy)

Spike 是一款融合深度学习计算机视觉（YOLO K线形态回归识别）、高阶多周期量化（6均线密集收敛收缩算法、订单流微结构）与自动化实盘执行的专业级量化交易研投终端。

  • 高信息密度而不杂乱 (High Density, High Clarity)：专为职业交易员与量化研究员打造，一屏兼顾研报、回测、特征与实盘深度。

  • 等宽数据对齐与视觉零抖动 (Monospace Decimal Lock)：全部数字、订单量、P&L、Tick 延迟均采用等宽排版，数据跳动时界面绝不出现水平位移或布局漂移。

  • 极客暗黑与电光聚焦 (Obsidian Quantum Theme)：极深冷调灰底降低长达12小时盯盘的视网膜疲劳，辅以电光青蓝（Cyan）主品牌焦点及高对比翡翠绿/玫瑰红的多空语义。

3. 字体与排版层级 (Typography System)

  • UI 界面字体：Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "PingFang SC", sans-serif

  • 数值与代码字体："JetBrains Mono", "SF Mono", "Fira Code", monospace

  • 排版比例与层级：

    • Hero KPI / Balance: 24px - 32px / 700 Monospace

    • Section Title: 14px - 16px / 600 Inter / 字母大写或带发光指示点

    • Body / Cell Text: 12px - 13px / 400 Regular

    • Micro Tag / Metadata: 10px - 11px / 500 Uppercase Tracking 0.05em

4. 关键组件与布局范式 (Component Architecture)

  1. 常驻 App Shell 架构：

    • 顶部全能导航条：集成系统状态心跳（120ms WebSocket 轮询）、一键极速开单快捷键、风控等级安全评分与活动通知中心。

    • 左侧全局收折抽屉式功能导航。

  2. K线与形态检测标注容器：

    • 标准 6 均线系统标配：SMA 20/60/120 与 EMA 20/60/120，色阶分明，均线密集阈值带（< 0.8%）自动着色高亮。

    • YOLO 目标检测 Bounding Box：带置信度与类别标签，附带推理延迟与 NMS IoU 指标。

  3. 交易指令流与双向反馈：

    • 挂单状态即时跟踪条（排队位次、前序未挂量、可恢复操作选项）。

    • 实盘账户与图表实时穿透联动，点击任何资产即时切换行情面板。

5. 跨端适配规范 (Responsive & Mobile Strategy)

  • 桌面端 (Desktop, >= 1440px)：以三栏或四栏高密度看板为主，多屏联动，支持研报、回测因子矩阵与多深度报单同屏交互。

  • 移动端 (Mobile, ~390px)：

    • 单手拇指热区优化：核心指标悬浮卡置顶，图表与均线密集检测结合快速下单手势。

    • 简化信息流：以折叠抽屉与滑动标签展示多周期信号与持仓浮盈，保留关键止盈止损调整与一键闪电平仓。
