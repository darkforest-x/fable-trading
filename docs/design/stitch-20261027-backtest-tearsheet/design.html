1. 周期基准与形态评分门槛

• 60m (1H) 收线反转确认： 极值线击穿后必须等待 1h K 线实体反转收回。
• 准入门槛： 形态评分 ≥ 0.50 允许入场。
• 目标分档： 若评分 ≥ 0.60，终极目标锁定对向 1.618 扩展位；若 0.50 ≤ 得分 < 0.60，目标自动降维为区间中轨 0.618。

2. 防守底线与动态逆向加仓

• 硬防守兜底： 初始挂单及未收线阶段设置 -30% 价格硬兜底止损。
• 保护推进： 反转收线确认后，后端毫秒级将止损线推至 +0.17% 保本损。
• 逆向 -5% 加仓： 仅在形态评分 ≥ 0.60 时生效，且严格限制仅触发 1 次深度回踩挂单加仓。

3. 20份动态保证金与杠杆计算

• 动态份数保证金： 每笔腿保证金严格按照 成交时点已实现净值 / 20 计算。
• 名义敞口 3×： 单腿名义规模 = 保证金 × 3（3倍杠杆）。
• 加仓规模动态重算： 挂单加仓腿在触发成交瞬时，依据当时实时净值/20×3动态重算名义规模，严禁死板沿用母单开仓时的历史名义规模。

4. 槽位硬顶与忙碌阴影 (Busy Shadow)

• 20槽位容量： 全账户最大允许 20 笔有资腿（含母单与加仓腿），总保证金占用 ≤ 100% 账户净值。
• 无可用槽位时： 若 20 槽位占满或保证金不足，新信号记录为 忙碌阴影 (Busy Shadow) 并记入统计跳过数，加仓单直接取消，绝不透支。
