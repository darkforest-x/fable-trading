## 本轮回放的验收

- [x] 真实本地历史来源可追溯；缺失、断档、预热不足明确报错。
- [x] 只把当前已揭示的收盘 K 线送到浏览器和 AI；均线与纵轴不使用未来。
- [x] 支持单步、连续播放、暂停、自由模式定位，页面切换时停止播放。
- [x] 固定评测图片保存后不可被后续行情改写；AI 使用页面展示的该原图。
- [x] 独立判断模式先保存人类标签再调用 AI；看过未来的历史点不冒充独立盲审。
- [x] 每次 AI 请求记录模型、规则、参考版本、原始请求响应；重复点击不重复计费。
- [x] 回访追加后续时间与图表，不覆盖原判断；研究观察不冒充模拟交易收益。
- [x] 会话和记录可在刷新、服务重启后恢复。
- [x] 原工作台、全局参考、历史、设置及正在开发的自动识别保持兼容。
- [x] 因果性／接口测试通过；桌面与窄屏真实浏览器完成操作验收。

## 使用边界

历史案例入口读取原实验回执和行情哈希：V12.8 共 10,713 条（198 条未结束），V9 共 49,207 条（137 条未结束）。两库及重叠策略不能合并当账户样本；净收益 ≥3R、≥5R、>10R 是累积分组，浮盈另列。亏损只是原退出下的结果，不自动成为形态负例。

结果分类用于学习，混合列表用于先判断再揭晓。分类浏览、揭晓及后续行情暴露跨会话持久记录；既有先判断记录不被后来揭晓改写。原来源缺失或哈希不符会报错，不能换当前 OKX 行情替代其他交易所的历史。

案例扩展验收（2026-09-24）：253 项 Python 与 34 项 Node 通过；真实浏览器覆盖混合盲审、盈利、亏损、未结束揭晓、会话恢复与切换、390px 明暗。测试判断仅写临时运行库，本次没有付费模型调用。复核命令：`.venv/bin/python -m pytest tests/vision_research tests/boundaries/test_layer_imports.py -q` 和 `node --test tests/vision_research/*.test.cjs`。

本机交付保留一次重启后案例列表 30 秒请求超时（根因未确定，未删改来源）；随后独立加载两库约 4.6 秒，再次冷重启实测 4.895 秒返回完整分母，缓存请求约 0.12 秒，正式浏览器最终正常。不可把一次未复现的超时解释成已修复的数据问题。

自由回放是研究工具；“先独立判断”只保证本会话的展示顺序，不证明用户从未见过该行情。
用户自选历史样本不叫随机盲测集。已见 AI 或未来的记录保留暴露标志，不回填独立金标。
参考图不会因点击接受就自动学习；改参考或提示词应形成下一版本。
所有训练／生产资格保持 false；不改原成本、退出、新鲜度、仓位或账户。

验收记录：241 项 Python 检查、21 项 Node 检查通过；真实浏览器覆盖桌面、390px 明暗、播放暂停、刷新恢复、日期越界和原图 404。
正式智谱首调 `6da66b1834f54f158eb16adfc6a25613` 90 秒超时；同像素／参考／规则／模型的一次显式复测 `f61442ae934e4c479b5a352f8ea8484c` 87.37 秒完成，13,363 tokens。原失败保留，没有自动重试。两次工程调用不能证明识别效果；时延列入第 7 项继续核对。

图文对照扩展（2026-09-24，0.11.0）：借鉴 [DayTradingBench 输入设计](https://daytradingbench.com/docs/text-vs-vision)，复用同一冻结的 120 根 OHLC 与六条均线、同模型、同规则和截止时点。纯图像只发原 PNG，纯数值不发任何图片，图文两者都有；三组均不带参考示例、不画框，不接收人标、历史结果或其他组回复。普通含参考图的识别继续单独保留。输入、版本和 SHA 可展开检查并导出，准备数据免费且不锁首次人工判断。

每组只允许一次手动请求；先持久登记再发送，无效 JSON、超时与重启中断保留为未知，不当作“不符合”。盲审先保存人工判断；实际 AI 调用后登记暴露，自由模式可继续追加回访。界面显示建议／实际顺序、实际模型一致性、分类结果、用量和耗时。三组一致不等于准确，数值编码也不保证更便宜。评测需要第 5–6 项独立事件及时间切分，不能把三组当三条独立样本。

本扩展验收：299 项 Python、36 项 Node 通过，MockTransport 核对三组实际请求体与图片数量 1/0/1。真实浏览器在临时运行库验证原历史案例、先准备后判断、手动三组、失败保留、刷新恢复、图片 404、390px 明暗与数据展开；没有付费模型调用，模拟结果不写入正式运行库。仍使用上方复核命令。未移植外部的动态仓位／止损／收益排名，原成本与交易规则保持原契约。
