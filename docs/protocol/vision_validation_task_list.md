## 本轮回放的验收

- [ ] 真实本地历史来源可追溯；缺失、断档、预热不足明确报错。
- [ ] 只把当前已揭示的收盘 K 线送到浏览器和 AI；均线与纵轴不使用未来。
- [ ] 支持单步、连续播放、暂停、自由模式定位，页面切换时停止播放。
- [ ] 固定评测图片保存后不可被后续行情改写；AI 使用页面展示的该原图。
- [ ] 独立判断模式先保存人类标签再调用 AI；看过未来的历史点不冒充独立盲审。
- [ ] 每次 AI 请求记录模型、规则、参考版本、原始请求响应；重复点击不重复计费。
- [ ] 回访追加后续时间与图表，不覆盖原判断；研究观察不冒充模拟交易收益。
- [ ] 会话和记录可在刷新、服务重启后恢复。
- [ ] 原工作台、全局参考、历史、设置及正在开发的自动识别保持兼容。
- [ ] 因果性／接口测试通过；桌面与窄屏真实浏览器完成操作验收。

## 使用边界

自由回放是研究工具；“先独立判断”只保证本会话的展示顺序，不证明用户从未见过该行情。
用户自选历史样本不叫随机盲测集。已见 AI 或未来的记录保留暴露标志，不回填独立金标。
参考图不会因点击接受就自动学习；改参考或提示词应形成下一版本。
所有训练／生产资格保持 false；不改原成本、退出、新鲜度、仓位或账户。
