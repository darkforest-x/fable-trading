# SPIKE：低频、高净胜率与高兑现R的研究目标

Owner口径日期：2026-09-23。来源：V12.8近两月回测后的原话：

> 我们的目标是尽可能的降低交易频率，提高胜率和高 R

## 目标与研究优先级

将交易次数减少、扣费胜率提高和高R交易质量作为联合目标。不能将不交易、机械限单、缩短止盈取得的高胜率或少数偶然极端收益当成通过。

研究顺序调整为：先在固定原退出与成本下研究入场筛选，再研究保留大赢家的退出，最后评估真实两次加仓。上一轮提出的“收盘2R后增加费用保本下限”仍是未执行的候选，优先级后移；没有据此变更Pine或默认参数。

“高R”暂按实际兑现且扣费后的R衡量，并同步报告途中最大浮盈，二者不混用。Owner尚未给出具体胜率门槛、高R门槛或全池每天笔数上限；不自行写入订单限制。当前采用已有3R/5R/10R分档描述，不把描述档位当止盈参数。

## 每个候选必须同表报告

- 实际入场数、相对基线减少比例和单位时间频率；固定币池和观测窗口，另列每币有效覆盖，避免覆盖缩小冒充主动降低频率。
- 已平仓扣费胜率、赢/亏/保本数量和截止未结束数量；价格保本不当净赢。
- 平均净R、平均净bp、平均盈利R、平均亏损R和净R利润因子；R分母保持入场时原始风险，不能事后缩小止损分母制造高R。
- 净≥3R/5R/10R的笔数和占比；相对原版的大赢家保留/丢失/新增，区分固定同入场与完整串行回放。占比上升但大赢家大量丢失属于取舍，不自动通过。
- 相同成本、同币×方向×时间块×因果波动桶随机对照的净bp超额；前后时间段、方向和周期分别披露，并报告样本量及不确定性。

筛选只使用当时已知信息。每轮只改变一个筛选变量，既有默认入场、退出、障碍和成本的变更仍遵守Owner批准边界。本次目标澄清不授权训练、promote、真实仓位或任意调参。已反复研究的历史用于探索，不能称未见验证。
